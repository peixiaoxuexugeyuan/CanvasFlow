### 技能用途

本 Skill 提供一套可复用的风格锚定技法，将「电影级写实武侠 CG」的画风、光影、写实质感与色调滤镜叠加至任意生成任务中，确保多张图片视觉风格的高度一致性。

### 适用输入

- **角色设定**：定妆图、三视图、角色特写描述。
- **画面内容**：剧情关键帧描述、逐格分镜脚本。
- **构图要求**：横/竖构图、特写/全景等视角的文本描述。

### 操作步骤

1. **保留原意**：完整保留用户输入的内容（角色、服装、构图、台词），不进行改写。
2. **注入锚点**：在提示词末尾追加本 Skill 提供的英文风格锚点串或极简短语。
3. **配置负面词**：将本 Skill 提供的负面提示词填入 Negative Prompt 区域。
4. **风格自检**：在多图连续生成时，重复使用相同的锚点串以维持风格连续性。

### 输出要求

- **英文锚点串（推荐）**：包含 PBR 材质、UE5 质量、低调冷硬光影、皮肤毛孔细节、冷青蓝灰调色等专业描述词。
- **极简短语（备选）**：用于快速风格统一的中文短语总结。
- **负面约束**：明确排除塑料感、过度磨皮、过曝等影响质感的因素。

### 注意事项

- **仅限风格层**：本 Skill 只负责视觉风格，不涉及构图与叙事逻辑。
- **避免冗余**：英文锚点串与中文短语二选一即可，防止 Prompt 过长导致权重稀释。
- **构图解耦**：本 Skill 不带任何构图约束，构图应由用户输入决定。
