# 运镜规则

## 选择与尺度

先说明摄影机在三维空间中怎么走，再说明前后景如何改变遮挡。下列距离和角度是这套短镜头的起点，不是图中实测值；按实际通行空间与用户速度要求调整。不把距离、角度、半径三个不一致的数字同时写死。

| 镜头 | 可用起点 | 保持与变化 |
| --- | --- | --- |
| 轻微前推 | 4 秒前进约 20—30 厘米 | 高度、朝向、俯仰、焦距稳定；近物扩大较明显，远景变化较小 |
| 空间后拉 | 6 秒后退约 50—70 厘米 | 高度、方向、焦距稳定；前景和两侧自然展开，主体稍缩小 |
| 左右横移 | 4—8 秒横移约 40 厘米；宽阔走廊可适当增大 | 摄影机自身左右方向，机身不转；固定场景向画面相反方向产生位移 |
| 小幅环绕 | 4—6 秒沿短弧移动约 5—8° | 围绕明确目标，摄影机随弧线小幅转向；高度、焦距基本稳定 |
| 垂直上升 | 4—6 秒上升约 30—60 厘米 | 摄影机实际抬升；同一物体在画面中整体趋向下移，近远景出现纵向视差 |
| 快速前推 | 4 秒内明显接近，可参考 1—2 米但以可通行距离为限 | 很短的柔和起步后迅速进入稳定速度；不沿用慢推的 20 厘米与长缓入缓出 |

## 平移与推拉

纯横移明确写出“保持拍摄朝向固定”，避免变成原地摇镜。选择近处椅背、扶手或廊柱，与远处窗、墙、柜体比较视差；距离不同，位移量不同。

推拉不能用整体画面缩放、建筑拉伸或家具自行移动模拟。路线不得经过桌椅、窗玻璃、闭门、栏杆或挑空区域。推到门前结束，不穿过关闭的门。

保持主体的空间关系和辨识度即可，不要求画框边缘的所有椅子、桌角、柱体始终完整。近景可以自然退出，补充图只帮助核对真正能露出的区域。

## 小幅环绕

给出目标与行进方向，例如“围绕茶几与桌面陈设的整体中心，沿其前侧向摄影机右侧走一小段弧线，并轻微向左转向”。这样能区别于纯横移和原地转头。

只有单张细节图时，采用小角度、短弧线，保留已知侧面。不要擅自要求 180° 或 360° 绕到未知背面；用户明确要求大角度时，说明需要更多视角支撑，或按已有参考给出可行范围。

墙边壁灯、门扇和柜体适合从前方短弧展示厚度，不能把轨迹安排到墙后。前景花瓶、金属扶手与后方沙发应出现不同的相对位移；物体本身不转动。

## 上升与天空

“向上移动”首先解释为摄影机抬升，而非只仰拍或将图片向下拖动。衣帽间立面上升时，下方抽屉逐渐退出，上方层板进入，不必拉远去匹配补充图。

若用户要求“上升后看到一点天空”，结合主图上边界与补充图判断：纯抬升能实现就保持原朝向；不足时，在后半段配合小幅、连续仰角调整，并明确写出。只露出需要的天空带，不强制整座山墙完整、屋顶俯视或无人机升空。

当下方水钵与上方天空无法全程同时容纳时，可前半段展示水动，后半段自然让水钵部分退出；不能通过缩小建筑、拉伸画幅来同时保留二者。露出的云不能穿过屋檐或绘制到砖墙上。

## 快推与剪辑

“快一点”落实到更短的起步和明显接近，不只添加“快速”一词。确认用户想要的是运动更快还是切到下一镜。

用户要求快速接下一镜时，可让本镜末尾保持前进速度，供后期硬切；本镜仍然连续。没有明确多镜要求，不添加闪白、甩镜、溶解或凭空切到新地点。

## 多镜分镜

用户明确要多镜时，逐镜注明起止时间、参考图、机位、人物动作、光照和衔接，不再写“全片一镜到底”。时间段连续且总和一致，指定完整 3 秒的脸部近景必须真正占足 3 秒。

人物动作在切点连续，例如上一镜读书，下一镜仍持同一本书；结束时轻离墙面，是下一镜走向园景的起点。让采光方向、人物衣着、手中道具和出入方向连续，不为衔接改变建筑布局。
