# 场景示例

这些是写法示例，不是新图的事实。每次先核对实际图片，替换图名、方位、物件与时长，再交付完整正文。不能把示例中的水钵、女主、天窗或座椅补进没有它们的参考图。

索引：1 室内横移与全景；2 茶室后拉；3 细节环绕；4 庭院快推；5 庭院上升、天空与水；6 窗景前推与纱帘；7 衣帽间上升；8 远处倚靠阅读；9 自然微笑近景。

## 1. 地下室客厅向左横移，补充图为全景

适用事实：左侧会客区、中央石材通道、右侧茶区；天窗与上层窗采光，茶区部分位于楼板下。

```text
以图一为唯一首帧与主要场景参考，生成一段8秒、16:9横屏的写实地下室客厅展示视频，全程一镜到底。图二仅核对横移时自然露出的空间，不作为尾帧，不切换成全景。

【首帧与空间】
保持图一构图、机位、建筑比例和初始光照，保留左侧会客区、中央通道、右侧茶桌与座椅、盆栽、柜门、天窗、上层窗及弧形栏杆的布局。全景左右接缝可能包含同一茶区，不复制家具，不将全景展开的弯曲移植到建筑中。全程无人。

【运镜】
摄影机在完整8秒内向自身左侧平稳横移约40厘米，首尾轻微缓动，中段匀速。保持高度、朝向、俯仰和焦距，不前后推进。近处沙发木框和椅背在画面中向右产生较明显的位移，远处窗和墙面变化较小，遮挡连续改变。允许边缘家具自然进出画框；路线位于原有可通行区域。

【光影】
自然光来自原有天窗与上层窗，仅对日照角度变化做轻度时间压缩。首帧后立即开始，前0.5秒可辨，持续完整8秒。中央通道的柔和亮区边缘相对固定石材拼缝缓慢移动约25—35厘米，使相邻石面依次改变受光状态。
左侧坐垫、木扶手和地毯同步接受同一采光变化，阴影边缘轻缓经过固定的地毯线条，家具脚部的接触阴影保持连接。右侧茶区遵守楼板与墙体遮挡，仅变化已有自然受光及间接光，不让阳光穿透楼板。

【材质与限制】
灯带、台灯、壁灯和柜灯保持原有亮度与色温。曝光和白平衡稳定。干燥石材的倒影随视角连续更新，石纹不流动，不用反射变化替代实际光影移动。家具、盆栽、茶具和柜内陈设固定。无人物、建筑变形、二维图片平移、变焦、闪烁、切镜或转场，无新增字幕、水印。
```

## 2. 茶室后拉

适用事实：正对长茶桌、前排客椅与后方柜体，茶区为白色平顶。

```text
以图一为首帧与主要构图参考，图二仅核对后拉自然露出的空间，生成6秒、16:9横屏写实茶室展示视频，一镜到底，全程无人。

保留图一长茶桌、前排四把客椅、后方主人椅、茶盘茶具、盆景、两侧柜体、中央格栅门、左侧台阶、白色平顶及深色石材地面。全景接缝不生成第二套茶桌，茶区白顶不替换成邻近客厅木顶。

摄影机从原机位沿视线反方向平稳后退约50—70厘米，持续完整6秒，起止柔和。高度、朝向、焦距不变。桌椅逐渐略微缩小，前景地面与两侧空间自然展开，近椅背和远柜体产生真实视差；路线不经过家具或墙体。

首帧后光影立即连续变化，前0.5秒出现可辨变化。沿原有自然采光方向，对日照变化做轻度时间压缩，让茶桌前地面柔和亮区的边缘经过固定石缝，累计位移约20—30厘米。台阶边缘、平台立面与地面受光按照高差自然衔接。桌沿、椅背和茶具高光随入光与观察角度轻缓改变，家具本身固定。

柜内灯带及原有室内照明稳定，整体曝光、白平衡不跳变。石材干燥，反射真实，石纹与接触阴影稳定。柜门和格栅门保持原有关闭状态。禁止家具漂移、重复茶室、材质游动、镜头穿模、切镜和转场，无新增字幕、水印。
```

## 3. 家具细节缓慢环绕

```text
以图一为唯一首帧与场景参考，生成4秒、16:9横屏的写实室内细节视频，全程一镜到底。保持茶几、花瓶、茶盘、茶具、书本、摆件、沙发及地毯原有位置、数量和造型。

摄影机围绕茶几与桌面陈设的整体中心，沿前侧向自身右侧缓慢走一段约5°的小弧线，并配合很小的向左转向，使茶几仍是主体。保持高度、焦距与主体距离基本稳定，不绕到未知背面。前方花瓶与桌沿相对后方沙发产生真实视差，陈设保持固定，不自行旋转，不用整图平移模拟环绕。

保留原有自然采光来源，仅对日照角度变化做轻度时间压缩，首帧后立即出现柔和变化。在完整4秒内，桌面原有亮区边缘缓慢经过一处固定石纹，沙发坐垫与地毯上的明暗随同一光向协调变化；变化只发生在原本能接收到该光源的表面。金属与陶器高光随观察角度更新，但石纹、书本印刷和地毯图案始终固定。接触阴影贴合物体，不独立滑走。

原有灯光、曝光和白平衡稳定。花枝不变形，摆件不自动摇摆，书页和茶具不自行运动。允许边缘局部随弧线进出画面，不新增人物、陈设或窗户。禁止家具变形、材质游动、变焦、抖动、切镜与转场，无新增字幕、水印。
```

## 4. 庭院快速前推，木栅门首帧已为黑色

适用事实：用户已修改的主图，中间小门黑色且关闭，通道两侧有灰砖、木构和廊柱。

```text
以用户修改后的图一为唯一首帧与场景参考，生成4秒、16:9横屏的写实庭院视频，全程一镜到底。中间木栅门从第一帧起就是参考图中的黑色，保持原有木纹、格栅造型和关闭状态，全程不发生颜色转换。

摄影机沿原有石材通道快速向前推进，前0.2秒短暂柔和起步，随后稳定、明确地接近中央砖墙及黑色小门。以现有可通行距离为限，目标前进约1.5米。高度、朝向和焦距稳定，不横移、不旋转、不数字放大。近处门框、柱体与铺地明显展开并自然退出画框，远处小门逐渐接近。末尾仍在门前安全距离内，可保留前进动势供后续剪辑，不穿过关闭的小门。

首帧后日照角度同步开始缓慢变化，仅对光照做轻度时间压缩。前0.5秒内，中央灰砖墙原有斜向明暗边界就相对固定砖缝产生可辨移动，4秒内累计经过约半块至一块砖长度。地面与廊柱投影随同一光向协调移动，并在台阶、墙角和柱脚处自然衔接；接触阴影不脱离对应物体。

玻璃倒影随真实机位更新，原有灯具亮度稳定。保持明亮日景、固定石纹砖缝、稳定曝光与白平衡。不新增人物或建筑，不出现液化地面、曝光闪烁、甩镜、切镜和转场，无新增字幕、水印。
```

## 5. 庭院缓慢上升，露出少量天空，云与水动起来

适用事实：近景水钵和既有竹制出水口、左拱门、中央高山墙、右树；补充图显示同一山墙顶部。

```text
以图一为唯一首帧与主要场景参考，生成6秒、16:9横屏的写实庭院视频，一镜到底。图二仅核对上方山墙轮廓与空间，不作为尾帧，不引入图二独有的前景或切换到远景。

保持拱门、灰砖山墙、右侧造型树、石灯、水钵、竹制出水口、岩石、地被及铺地的原有布局和比例。摄影机缓慢垂直上升约50—60厘米，起止柔和，焦距稳定。前半段保持原朝向，清楚展示水钵及庭院；后半段配合少量连续仰角调整，让山墙上缘上方露出一小片天空。不要求完整展示整座山墙，不升到屋顶之上。低处水钵可在后段自然部分退出画面。

首帧后光影立即变化，前0.5秒可辨。仅对日照角度变化做轻度时间压缩，让砖墙原有斜向阴影边界持续越过固定砖缝，6秒累计移动约半块砖长度，地面投影随同一日照方向协调改变。

露出的天空中，薄云平顺地向一个方向移动，位移清楚可辨。云层及其画外连续部分带来宽而柔和的局部遮光，主要改变受光强弱与阴影软硬，不让固定檐影因云移动而突然旋转。树叶只有轻微摆动，主干和种植位置不动。

现有竹制出水口从开场持续流出细水，落入原水钵，形成正常速度的扩散涟漪与少量细小水花；落点、出水结构和水位稳定。水面反光随波纹变化，石钵与地面材质不流动。水钵仍在画面中时保持连续水动，不因镜头抬升突然静止。

灯具、曝光与白平衡稳定，保持日景。禁止新增建筑、喷泉、人物，禁止场景缩小、砖纹游动、假水面、镜头穿墙、抖动、切镜和转场，无新增字幕、水印。
```

## 9. 完整三秒脸部近景，自然微笑

适用事实：用户明确指定多镜片段中的 5.5—8.5 秒近景，女主轻靠影壁。

```text
【镜头三｜5.5—8.5秒｜完整3秒脸部近景】
主参考为影壁材质图及用户指定的女主参考图。

切至女主侧前方的头肩近景，采用自然的人像透视。摄影机缓慢靠近少许，并进行很小的侧向弧线移动。女主轻靠影壁平整立边，自然呼吸，头部仅轻微活动，不直视镜头。

她从这一镜开始就带着一点轻松自然的微笑：嘴角略微上扬，双唇自然轻合，脸颊与下颌放松，眼神柔和，像安静欣赏庭院时自然流露的笑意。笑容幅度小，随呼吸和视线连续变化，不像刻意摆拍。

不强挤嘴角，不突然咧嘴或露出整排牙齿，不僵硬凝视，不逐渐拉大笑容，不改变五官比例。保留真实皮肤、原有服装和发型。

画面保留身旁石质边框、局部浮雕或灰砖，背景适度柔化，仍能辨认她在影壁旁。人物受光与前后镜头连续，局部变化柔和，不让大块硬阴影扫过整张脸。画面没有天空时，不为展示云层改变构图。

末尾她仍带着浅浅笑意，将视线轻转向园景，肩膀轻轻离开墙面，为下一镜衔接。整段近景完整保留3秒。
```
