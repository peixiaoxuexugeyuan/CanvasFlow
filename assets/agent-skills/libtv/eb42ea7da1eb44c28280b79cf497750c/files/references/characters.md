# 建筑场景中的人物

## 人物参考、比例和首帧

沿用用户提供的人物参考，不凭空补出既定女主的五官、发型或服装。未提供可访问的人物图时，提示词可保留“沿用用户指定的人物参考”，正文外简短提示实际生成需配套上传。无需因此阻断场景提示词撰写。

建筑镜头中人物作为生活点缀；用户明确要人物近景时单独处理。用户要求“矮一些、离镜头远些”时，采用正常成人比例，并把人物初始位置安排得更深；本套案例可参考约 1.60 米，但不能覆盖用户指定的 1.66 米或其他身高，也不将全部女主固定成同一身高。

依据人物所在深度的门、桌、椅或扶手校准尺度。不要用画面高度占比机械规定身高，或拿近处人物与远处栏杆直接比较。人物从第一帧就按正确身高和位置出现，不能在片中缩小、倒退或改变身体比例来满足修改。

用户移动图中已有女主时，同一角色只保留在新位置；移除旧位置人物及其旧投影、倒影，不复制第二人。若只修改动作、微笑或身高，保留已确认的运镜、时长、人物身份及场景。

## 位置需要落到真实几何

描述“哪一面墙或哪一扇格栅、哪一侧、谁的前后、属于哪块地面”，不写“红圈内”。

可用定位例：

> 后方三扇深色木格栅中，最右侧一扇的正前方，靠近后墙与右侧浅色墙交接处，位于右侧金属网护栏远端靠走廊内侧的实体石材地面上。

这只是位置表达范例，不能无视新图自动沿用。区分墙、柜门、通道、台阶和挑空边界；人物不能从柜内、墙缝或盆栽后方直接穿出。

**不为人物添加椅子。** 用户要求坐下时，先使用图中真实存在且可坐的座面；明确不要椅子且希望坐在地面时，写落在实体地面上的坐姿。没有座面且坐姿意图不清时，只询问这一关键点，不能把窗框或门槛擅自当座位。用户改为“靠在后面”且上下文支持倚靠时，直接改成自然站立倚靠，删掉坐下、椅子及坐垫条款。

## 安静阅读与倚靠

靠在真实、稳定的墙面或实木竖框上，背部轻触，双脚踩实，体重主要由腿承受；不倚靠镂空洞口、玻璃空隙或悬空区域。身体轻转向适合阅读的方向，不必面向镜头。

打开的书由双手在腰胸之间托住，肘部自然放松，视线落在书页。6 秒可安排呼吸、一次自然眨眼和至多一次翻页；左手托书、右手翻动一页后恢复阅读。书页有连续弯曲与翻动过程，不能瞬间变书、反复翻页或与手指穿模。用户仅要求安静阅读时，也可以全程不翻页。

如姿势是双手扶栏，则手掌始终落在同一段真实扶手上，肘部微弯，轻微呼吸与重心变化即可。不要同时安排拿书、挥手或走动。

## 从通道出现与行走

首帧无人时，女主确实位于真实通道内，被原有墙体遮挡；之后以行走逐渐显露。显露顺序由墙体和身体位置决定，不固定成不符合透视的“头、肩、腿依次弹出”。

保持正常步态：支撑脚接地时不滑动，摆动脚经过连续轨迹，重心与身体起伏对应。给 4—8 秒镜头安排合理的短路程，在中远景结束，不要求快速穿过整间房。

路线绕开桌端、椅背、沙发和植物。摄影机按已定路径运动，不自动追人、转头或停顿。人物投影、衣料变化和地面反射随实际位置连续更新，不能出现独立的人影。

## 台阶和转角

只沿参考图已有踏步，不预设或新增台阶数量。脚掌先接触下一层踏面，再转移重心；膝、髋和身体高度连贯变化，接触阴影贴合当前踏面。

路线确实有转角平台时，走到可承重的平台，双脚落稳后再转向；不能在狭窄踏步或挑空边缘提前转身。只有参考足以确认平台、走向和高差时才描述具体转弯，不把某个旧案例的最大平台、90°转角套给所有楼梯。

## 脸部近景与自然微笑

保留自然人像透视和头肩距离，只做很小的前推或侧向弧线；避免超广角贴脸。画面内留少量身旁石质边框、灰砖或浮雕，背景适度柔化，仍能辨认所在空间。

优先正面描述表情：嘴角轻微上扬，双唇自然轻合，颌部和脸颊放松，眼神柔和，像安静欣赏园景时流露的一点笑意。用户没有要求从无笑到笑时，可从首帧就有轻微笑意，之后随呼吸和视线自然变化。

只加入必要限制：不强挤嘴角、不突然露出整排牙齿、不僵硬凝视、不把笑容逐渐拉大、不改变五官。不要把“自然”写成绝对左右对称、嘴角冻结或全程不眨眼。

例如完整 3 秒近景可为：前段安静微笑，末段视线轻转向园景，肩膀轻离墙面，为下一镜衔接。保持衣着、身份、人物受光和动作连续，不让大块硬阴影扫过整张脸。
