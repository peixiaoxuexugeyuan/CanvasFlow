# 梦核提示词生成器

## 执行入口与跨环境使用

本技能不依赖旧聊天记忆，也不绑定固定角色、项目或总时长。仅从本次请求及当前可访问的已确认信息确定角色、用途和限制；缺少非必要信息时作合理设计，不把其他项目的设定自动带入。

创作按以下顺序执行：

1. **识别用途与任务**：按下文确定只要图片、用于视频或两者都要，再读取对应规范。已读且未更新的文件无需反复打开；规则未读取不能声称已遵守。
2. **确定事件**：已选事件直接制作；宽泛主题且未授权代选时先给候选。按创意引擎使用素材方法，案例不作为白名单。
3. **按用途设计**：独立图片选择表现力强的一刻；视频先确定本段动作范围、必要过程和镜头安排，再选起始状态与所需道具，最后写生图提示词。两者都要时按用途规则判断能否共用。
4. **核对并交付**：出图后按实际状态核对能否完成原定过程，再写视频续接与时长安排；发现起点过晚时调整输入，不擅自删掉用户所要的动作。交付前检查末尾核对表。

目录版使用相对路径读取文件。只有主文件、缺少所需参考时，明确指出缺少哪些文件或章节；仍可完成不依赖它们的部分，但不能宣称完整执行技能。没有文件工具的模型应使用由同一源文件导出的合并文本版，不尝试访问作者电脑的绝对路径。本技能不附带参考图片，可直接按文字规范创作。任务要求分析实际图片而图片不可读取时，说明限制，不伪称看过素材。

文件中的核心规则、可被用户覆盖的默认偏好、案例必须区分：核心关系不能靠风格词补救；模型优先顺序、色彩、节奏等默认值由当前明确要求覆盖；案例只说明方法。平台功能和生成下限以实际工具为准，不能从提示词作者使用的模型推断图片或视频工具功能。

需要迁移到其他模型时，运行 `python scripts/export_portable.py --output-dir <技能目录之外的输出目录>`。脚本从当前源文件生成完整合并文本与技能 ZIP，不另维护第二套规则。不能读取 ZIP 的平台先解压，再上传合并文本；任务需要参考图时由用户另行提供；更新源文件后重新导出。

## 使用与阅读

本技能服务于一种具体的梦核创作方向：**自然、宇宙或生态对象被按日常生活的逻辑对待，角色习以为常，画面渲染可信。** 这是本技能的创作范围，不是对所有梦核作品的定义。

### 用途选择

在选帧前确定用途，不默认生成两张图：

用途设计与交付只要图片选择最能表现概念的一刻；起始、过程、结果均可，不必预留视频动作用于视频先设计本段行为，再提供支持该过程的首帧提示词；不额外附展示图图片与视频都要优先一图兼用；展示效果需要提前呈现视频结果时，分别设计展示图与首帧，说明各自用途

从当前请求和同一项目已确认信息判断。明确“只做图片”直接走图片路线；“短片、图生视频、首帧”等表述走视频路线；“生图提示词加视频提示词”通常是视频制作流程，不自动等于另要独立展示图。用户明确要展示图与视频时才按双用途处理。

同一项目继承已确认用途，后续说“写图片提示词”不重置；用户可单独切换某张图。确实无法判断时，只问一次：“这次图片用于独立欣赏、后续视频，还是两者都要？”尚未得到用途时可先做事件分析，不自行锁定选帧。若用户要求直接完成、不要提问，则按上下文判断；仅请求图片且无视频语境时按独立图片处理，简短注明用途。用途选择不等于授权调用生成工具；只要提示词就只交付提示词。

### 按任务读取

单纯评估或修改技能不经过创作选题流程。

任务读取与处理只有主题，需要发散创意创意引擎 + 图片规范的事件案例库；写提示词时再读完整图片规范与风格通则已有明确事件，只做独立图片图片规范 + 风格通则参考图反推、分析或照此风格创作先看图，再读图片规范与风格通则；区分图中可见事实与推测已有图片要动起来先看实际图片，再读视频规范与风格通则的相关材质段；需要补生图时再读图片规范为视频设计首帧，或同时规划图与视频图片、视频与风格规范均读；先设计过程再选帧，即使本轮只交付首帧提示词也保留此顺序

默认按风格通则的文字美术体系创作，无需寻找随包图片。用户提供参考图或实际首帧时，按任务查看；已看过且仍在上下文中的同图无需重复打开。需要追溯美术依据时可读美术研究来源，不要求日常创作联网。

维护或明确验收技能时使用行为验收输入与判定标准。普通创作不读取验收库，不把其中案例当成必选题材。

**美术优先顺序**：当前用户要求 → 本项目已确定的美术设定 → 技能默认风格。默认采用精致的欧洲复古生活世界，借鉴《布达佩斯大饭店》鼎盛时期的美术组织方法，但建筑与工具按本技能重新设计，不按电影逐项复刻。首次设计时按风格通则确定适用的建筑、道具和色彩锚点；同一项目继承，地点变化时按功能调整。未指定美术时直接用默认值，不额外增加确认步骤。美术不能覆盖动作路径、用途所需的起始状态、核心规模和自然物材质；纯分析只分析所问维度。

用户或项目选择浪漫暮光／夜景时，按可选光色方案处理；具体触发与边界只在风格通则维护。

**规则各有唯一维护位置**：本文件负责概念底线、结果判断、表达尺度和协作流程；风格通则负责美术设定、建筑道具、材质与色调；图片规范负责静帧、构图与提示词交付；视频规范负责状态衔接、机位、切镜、时长与视频交付；创意引擎负责发散。美术研究来源只记录观察与迁移边界，验收库只检查已有规则。案例和模板服从这些规则，不反过来创造新禁令。用户当前明确要求优先于本技能默认值。

## 四条共同底线

1. **错位一眼可读。** 不靠标题或解释，能从画面看出哪种自然对象被怎样日常化处理。不是每个道具都必须不可能，核心关系必须不可能。
2. **排除平庸解释。** 看起来只是星星灯、玩具船、普通海景浴室，错位就不足。保留自然对象的识别特征，让不可能发生在空间、尺度、接触或作用关系上。
3. **习以为常。** 人物以熟悉、平静的生活行为应对；可专注、放松或微笑，不强制面无表情。动作有明确用途；操作发生时接触可读，前置状态则交代目标和可达路径，避免只有摆姿势。
4. **材质与画面可信。** 自然物保留本体材质；超现实可以改变可触性、尺度或行为，不自动把云改成棉花、月亮改成灯笼、天空改成布。具体写法见风格通则。

事件家族是检索标签，可重叠，不是质量判决：A 世界运维；B 替换双关；C 捕捉、驯养与加工；D 现象日常化；E 容器与通道。是否需要结果、能否移动对象、是否需要运镜，都不能只凭家族字母决定。

## 视频的完成标准

视频应把梦核关系发展为有观看价值的时间过程：观众能读懂日常行为如何作用于不可能的世界，并感受到其中的尺度、质感、生命与氛围。物体发生运动、五栏齐全或写满字数都不等于完成设计。按视频规范确定观看重点、视觉变化和节奏，并落实到提示词；分析通常内部完成，不额外输出整张检查表。

视频默认采用紧凑、高有效内容密度的节奏，宁可略快也不把少量动作拖成慢放；逐镜按有效密度检查预演并交付必要时长依据。用户明确的速度、动作范围与时长要求优先，按视频规范区分操作型、持续型与湿式擦洗的具体底线，逐镜附密度证据；不能通过拆分起手或无进展重复凑数。

奇观既可以来自世界尺度，也可以来自近距离而可信的不可能接触。用户明确要奇观时强化其表现力与可见证据，但不自动把所有事件放大、加特效或改成高潮结构；安静生活感仍可成立。

## 结果判断：是否承诺发生变化

先问：**这个事件是否承诺角色的操作会改变对象或世界？** 不按“句子里有没有动词”判断，也不把 B、D、E 整类免检。

- **承诺变化**：事件方案写清操作、可见过程和承诺的结果；结果不必提前出现在视频首帧中。“洗亮月亮”要看到被洗区域变亮；“捞到星星”的收成就是结果，不必再附加改变天空的第二个结果；“掀开夜空”要看到打开后的景象。
- **呈现状态或日常互动**：“牵水球散步”“窗形风筝飘动”“冰箱里有海”只需错位持续可读、互动成立。不强加世界变化、收成或最后变满的任务。视频同样适用。
- **停止、消失、减少可以是主结果。** 堵云止雨、收风使风停都允许。要求的是可感知证据，不是必须新增一个物体。静态图靠残留痕迹、空间对照和接触关系；视频可以靠同一区域的前后变化。只有一句“雨停了”，或只有没有雨的普通天空，证据不足。
- **结果匹配承诺的范围。** “一小片月面洗净”可以完成；“洗净整个月亮”却只洗一小片，仍未兑现。局部完成与整体未完成要区分，不用固定完成百分比判定。
- **结果清晰可辨即可。** 不强制是画面最大或第二大的物体。停止类结果、细小接触变化也能成立；若宣称改变全镇、全山谷，就必须交代对应范围。

因果联系要落到**接触点、作用路径和变化发生处**，不只用因果句解释。按用途选帧见图片规范；过程与结果如何在时间中展开见视频规范。

## 表达尺度：奇观与日常

表达画面重心量级与道具奇观型世界尺度的变化、巨物或大范围现象需要足够体量和参照物，工具能覆盖实际接触或搬运需求；可用放大的家用工具、复古粉彩机器日常型一个清晰的不可能关系、手感和近距离互动人体或容器尺度成立；普通大小的工具、轻微动作、近景均可，不为合规强行放大

两者可以组合，无须向用户强制索取类型选择。先读事件的表达目的，再决定景别、量级和动作强度。奇观型避免把全镇降雪写成几粒雪；日常型不因只牵一团水、捧一朵云就判不合格。人数、场景繁简、朝向同样由表达决定。

道具尺寸首先匹配**接触点与功能**：塞子匹配漏口，不必和整朵云一样大；能处理巨大对象的工具需要合理的工作范围或明确的超现实作用。不要只凭工具小就宣判失败，也不要用现实机械过程替代梦核错位。

**规模与数量不得擅自缩水。** 用户要求大场景、大范围作用、大量对象或满载收获时，保留相应量级，不因突出角色、减少噪点或简化生成而缩成局部动作与零星对象。广阔背景不等于事件规模大：核心现象本身必须有对应体量、分布或作用范围。未指定量级时按事件承诺判断，不一律放大。

**局部尺度变化不等于全世界微缩。** 明确本镜被改变尺度的对象，其余角色、建筑、道路和植被保持项目约定的相对尺度。为方便操作而把真实山谷、街区缩成桌面模型，或把普通居民无意放大为巨人，不能兑现原有世界尺度。用户明确要求微缩、巨型角色或容器世界时按其设定处理。具体参照与构图见图片规范。

写作前确定相关的规模证据：**空间范围、相对尺度、数量与分布**；具体落笔按图片规范，数量与纹理分离按风格通则。结果只完成局部就不能命名为全域完成。字数和动作预算不足时先删无关修饰、重复动作与空等；有用途的前置动作和核心量级都应保留，必要时调整镜头或时长。

## 空间、接触与比喻

- 保留让人识别对象的空间线索。天空保持空间纵深，月亮保留月面，云有云层关系；可改变高度与尺度，使人或工具能够接触。
- 替换双关优先让本体留在其语境里，通过行为制造比喻。“伸出窗外掀开夜空”比“星空图案的窗帘”更接近目标。只写动作所需的少量位置和形变，避免补窗帘杆、包边、布料纹理等日用品结构。
- 捕捉、移动和容器世界可以改变自然物的位置；要交代捕捉或通道关系，不因对象离开天空就自动否决。家族标签不决定这种许可。
- 世界尺度结果要看得见其范围。室外是常用选择；若在室内操作，需要可见的窗、管道、通道或其他联系，使室内操作与外部变化读得通。单纯把大世界事件缩成桌上玩具不成立。
- 家务场景优先院子、天台、房间等生活空间；高空作业要有让行为可理解的工具、工作面或角色安排。不要仅因动作叫“擦”或“洗”，禁止它出现在自然空间。
- 接触朴素直接：夹、系、捞、贴、握、压。取云时冰箱门应开着，接雨时通路应通，手与工具应够得到目标。除非事件明确需要，不堆托架、软垫等削弱直接接触的部件。

## 选题与协作

先路由，再判断是否需要选题确认：

1. **用户已指定具体事件并要求写作**：视为选题通过，直接写；已在本会话确认过的事件不重复确认。与案例相似不构成拦截理由。
2. **只有宽泛主题，尚未授权代选**：按创意引擎给候选，通常 8–12 条；用户要求少量时缩减。选定后再扩写。
3. **用户说“你定”“直接写”“别问了”**：按已给偏好代选并完成，不设置第二道确认门槛。
4. **用户提供图要求反推、分析或动效**：直接处理该图。只要状态清楚，不为走流程重新发散主题。
5. **确有影响任务成立的缺口**：如用户要求逐图续接但实际图片无法读取，说明缺口；能够先完成的文本规划继续做，不假装已经看图。仅有静态提示词时的视频草案须标注“尚待实际出图核对”。

发现质量问题先尝试保留用户事件、修正可见证据与表达；需要改变核心创意时再说明并让用户选择，不擅自替换事件。

## 交付原则

- 默认中文。完整提示词优先，用户要求分析时才展开拆解；纯分析请求不额外交付提示词库。
- 静态图的篇幅、段落、色调与负向提示词格式只按图片规范；视频的五栏、镜头与时长只按视频规范。“短视频平台、紧凑”约束视频动作与剪辑节奏，不授权压缩图片正文、独立风格段或色彩与表面要求。参数侧设置的画幅与时长不混进正文。
- 同一事件的“多版本”默认只换画面处理；用户要求“不同创意”才换事件。更换事件后，接触关系、构图和动作应随之重算，不能把不适用的旧构图锁死。
- 案例可参考和改造。AI 自行发散不要只换一个动词交差；这不限制用户明确指定的案例选题。
- 参考图用于提取画面事实，不照搬字幕、水印、播放按钮，也不把某张截图的道具材质或缺陷自动升级为规则。静态截图不能证明原片的运镜、切点或时长。
