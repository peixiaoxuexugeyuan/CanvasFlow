## 爱乐之城光色参考

[Kodak 对摄影指导 Linus Sandgren 的访谈](https://www.kodak.com/en/motion/blog-post/linus-sandgren-fsf/)说明：影片通过布景、服装与灯光共同形成色彩，蓝色夜景、粉色天空及偏青照明参与浪漫氛围的塑造，色彩也随人物情绪与经历变化。这是来源的制作说明，不是所有场景通用的固定色谱。

本技能据此制定可选的暮光／夜景方案；蓝紫渐变、局部暖光及现有建筑体系的搭配属于本技能的设计转化，不宣称概括影片全部美术。此处记录访谈依据，不将阅读访谈等同于本次已观看全片。无需日常联网或下载参考图。

一次洗月亮封面实验显示这种配色可以与复古酒店布景组合，但也出现留白不足、月面偏暖的偏差；它仅是单次制作观察，不证明所有场景或模型都稳定适用。成图仍须按本次构图、角色颜色、自然材质与接触关系核对，不把实验图片固定为模板或随包素材。
