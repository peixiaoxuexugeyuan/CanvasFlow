# 梦核创意发散引擎

本文件只负责发散。是否需要选题确认、结果如何判断、奇观与日常如何选，统一按 [SKILL.md](../SKILL.md)；明确事件不重复确认。

## 从常识交叉，不从案例换皮

候选来自“自然与宇宙元素 × 人类日常行为”。案例是可参考的素材，不是限制生成范围的白名单，也不是禁止碰的禁区。用户点名案例就按其要求做；AI 自行发散应避免只把“洗月亮”换成“擦月亮”。

## 素材库的使用与发散顺序

发散前读取本文件的元素池、行为池，以及图片规范中的事件案例库；素材库的作用是提供关系方法和对照，不是只许从中选题。先拓展不同对象、生活领域与作用关系，再按下文检查筛选，最后交付候选。不以换角色、颜色、近义动词或道具外形当作新创意；也不为了显得原创而拒绝用户明确指定的案例。

筛选时比较候选的核心关系，避免整批都在清洗、搬运或收纳，只更换自然对象。新候选可以来自库外，但必须通过同样的可见性、材质与结果检查。无需按比例分配“库内/库外”，也不要求公开中间草稿。用户提供的参考图片可用于视觉校准，读取条件按主文件；无图时使用文字规范。

## 自然与宇宙元素池

- **天体**：太阳、月亮、星星、银河、流星、彗星、日食、月食、月相。
- **天象**：云、雨、雪、雾、霜、露、彩虹、极光、闪电、雷、风、晚霞、朝霞、蓝天、黑夜、月光、影子、回声。
- **地理**：海、浪、潮汐、沙滩、河流、湖、瀑布、泉、山、火山、森林、草原、沙漠、冰川、洞穴、岛屿、地平线。
- **时间与状态**：白昼、黄昏、黎明、夜晚、季节、春天、秋天、节气、潮汐涨落、日出日落。
- **生物与生态**：鸟群、鱼群、萤火虫、落叶、花开、蘑菇、苔藓、种子、麦浪、蜂群、藤蔓、羽毛、鹿角。
- **抽象自然**：重力、温度、气味、声音、颜色、光、空气、水汽、尘埃。选此类时先想清可见载体，不能只有文字概念。

- **修理工艺**：锯、钉、焊、量、换、装、拆、上油、打磨、浇铸、抛光、打蜡、拧、剪、上发条。
- **农业畜牧**：播种、收割、放牧、挤奶、剪毛、嫁接、施肥、灌溉、修剪、采摘、翻土。
- **采集狩猎**：钓、捕、网、套、挖、捡、诱、罩、笼。
- **运输物流**：搬、装车、拉、推、吊、卸、邮寄、打包、码放、铺路。
- **商业**：卖、买、称、包装、标价、摆摊、开店、拍卖、找零、进货。
- **医疗护理**：包扎、打针、量体温、喂药、听诊、体检、照料、哄睡、冰敷。

这些池子开放，可继续加入新元素。词的组合本身不等于合格创意，要过下面的检查。

## 交叉与筛选

1. **一句话写清关系。** 谁把什么按哪种日常逻辑处理，或哪种不可能状态被当作日常。先找关系，不先堆色彩和道具。
2. **错位可见。** 去掉标题，观众还能从空间、接触与对象识别出不可能吗？若只能听旁白才明白，先改成可见证据。
3. **排除普通解释。** 普通气球、灯具、玩具或真实机械操作能否解释全部画面？能则加强核心不可能关系，不靠“真正的”“神奇的”等标签补救。
4. **判断变化承诺。** 按主文件的结果规则：改变对象的要有结果证据，持续状态的查错位与互动。停止或消失类可以用前后变化、残留与对照；不要因没有新增物体而淘汰。
5. **选择表达尺度和场景。** 世界变化要交代影响范围，近距离互动保留手感；工具匹配接触点，操作通路可见。不要把所有候选都拉成巨物全景。晾晒、收获、生产等批量事件即使未给具体数量，也按图片规范的批量场景规则安排布局；不要让一次操作的对象数自动成为场景总数。
6. **检查材质。** 从云剪下的仍是云气，水球仍是水，月亮仍保留月面；不是给自然物套上棉花、橡胶、纸灯笼的外观。
7. **检查首读气质。** 危险抢修、工业流程或科幻实验若盖过平静日常感，优先改行为框架和场景；需要时才换事件。乌云写灰蓝云层与柔和明暗，不写“哑光灰蓝棉团”。
8. **自发散去重。** 连续换自然对象、生活行为与作用关系，不要全是云、全是洗。发现仅换皮时继续发散；用户指定的内容不受去重拦截。

## 结果与持续状态的候选写法

下面是判断方式示例，不是必须沿用的选题：

| 候选 | 是否承诺变化 | 需要呈现什么 |
|---|---|---|
| 修剪云冠 | 是，外形与收成改变 | 剪口、仍有云气边缘的剪下部分、接住它们的篮子；收成可为结果 |
| 堵住云底漏口 | 是，雨停止 | 木塞与漏口接触；静帧留残余水线与其他区域对照，视频水线断开、最后水滴落下 |
| 牵水球散步 | 否，持续互动 | 绳结牵动悬浮水体，水内鱼游动、液面随步伐形变；不追加“原地留下凹坑” |
| 掀开夜空露出清晨 | 是，B 家族也要查变化 | 爪或手伸出窗外接触夜空，开口露出另一时段；天空保留空间感 |
| 冰箱里有海 | 否，呈现容器中的世界 | 开门后仍有地平线与远处航船，内部世界有深度；不强制取云或海水溢出 |
| 把风收进袋里 | 取决于承诺 | 若只是收集：袋内局部持续鼓动与收集关系可作收成；若承诺让外界风停：还要呈现草叶、床单或水面的前后变化 |

“在云里播种”若还没有生长结果或可读状态，说明选题尚未完成，可以继续发展；不把一个短语永久列为禁题。“雷声装瓶”只写外面没声音，静态图难以证明，需要可见的瓶内外变化；声音可帮助视频表达，但不能替代核心视觉错位。

## 输出候选

通常给 8–12 条，每条简洁写成：**事件 — 场景 — 可见结果或持续状态**。家族标签只在帮助比较或用户要求时附上；无变化承诺的不用硬填因果句。

用户只给主题且未授权代选时，候选供用户挑选。用户已授权代选时，自行选最贴合的一条并完成提示词，不额外等确认。明确事件直接进入图片或视频规范。

长片先列事件及各自需要观众看懂的信息，再按视频规范判断镜头。独立事件可一镜讲完，同一事件也可有必要的多镜；事件数与镜数分别统计。不要为了满足镜数反复拆同一动作、复制画面，或将有效创意全换成新事件凑数。

## 打开思路的方式

更换对象、生活领域、尺度、场景或因果方向；可以让世界照料人，也可以组合两个已有关系。组合后重新检查空间、材质与信息负担，不把原案例的构图和工具机械复制过去。

候选如果只有“很大”“很多”“很粉”而没有可读的错位，继续修概念；候选已经有清晰的日常错位，就不必靠增加机器与天体证明它是梦核。
