# 梦核图片提示词

## 范围与交付

负责文生图提示词、参考图反推与静帧设计。概念、结果和协作规则见 [SKILL.md](../SKILL.md)，材质与色调见 [风格通则](style-guide.md)。不直接承担图生图编辑或生成工具参数配置。

完整静态提示词的固定结构：

1. **画面描述**：默认采用紧凑表达，每条不超过 1200 字，不设最低字数，也不必写满上限；按信息关系分成若干自然段。字数仅计每条提示词的画面正文，不含标题、制作说明、独立风格段和负向提示词，也不是整批提示词共用的预算。写当前可见的一刻，简明交代场景定位、角色姿态与接触、构图和尺度、色彩组织、照明、材质与表面状态，只保留影响画面生成的必要信息；不靠重复修饰、无关装饰或多个连续时刻凑字数。
2. 空行后为**风格段**：使用风格通则中的默认基底句，按项目覆盖项调整，再充分展开本场景的主次色、冷暖与明暗关系、成像观感及材质响应。此段独立于正文篇幅，不压成“复古梦核、电影感、胶片色调”等几个标签；不加“固定色彩基底”“动态场景色”等内部标签。
3. 再空一行，单列**负向提示词**：按当前画面的具体风险写一两句；没有必要的风险时不硬凑。

默认中文，不交付括号填空模板。只有用户明确要求图片提示词短版或指定图片文字长度时，才覆盖默认篇幅；短版以保住错位、材质识别、接触和当前状态为先。画幅、比例、模型和画质设置放工具参数侧，不进入画面正文。

### 篇幅、完整性与视频节奏

“短视频平台”“紧凑”“快节奏”“几秒完成”等要求，约束视频动作、镜头时长与剪辑节奏，不构成缩短图片提示词的指令。视频首帧仍按完整图片规范展开，其丰富程度与视频播放时长分别判断。

正文中的颜色必须落到物体和空间：说明主要色块的归属、面积与层级，以及明度、纯度、冷暖如何区分主体、接触点和环境，不能全部推给末尾风格段。表面要求按当前可见物件写进正文，包括自然物的识别特征、家具与墙面的维护状态、不同材料的反射或透光，以及与观看距离相称的纹理密度。具体美术规则以风格通则为准；负向提示词不能代替这些正向描述。

批量交付时，每条都应包含可独立使用的画面正文、独立风格段及适用的负向提示词，不用“同上”“风格沿用”省去关键内容，也不因条目多而逐条压缩。遇到单次输出容量限制时明确分批及尚未完成的条目，保持单条完整，不把提纲称为成稿。

用户要求修改完整提示词时，将修正整合回完整版本，保留仍适用的角色、色彩、材质、表面和风格信息。仅在用户要求局部修改或分析方案时交局部内容，并标明它是修正段或方案；几段空间修正不等于可直接替代原稿的完整提示词。

## 模型选择与对照测试

本技能的可覆盖制作偏好（不绑定角色或项目）：优先使用 **image2.5**；**seedream5 pro、Nano Banana 2.1** 也可进行对照测试，按实际成图选择。名称沿用用户使用平台的标注，不推断它们的底层模型身份或功能。模型选择写在制作说明中，不写进画面正文；不要求每次自动调用全部模型。

同一提示词在不同模型中的角色、光色、材质和纹理表现可能不同。对照时先保持角色参考、场景文字和可比设置一致，再针对实际失败调整提示词。当前用户反馈 image2.5 出现过量噪点、龙鳞状伪纹理与家居大规模做旧；将其记录为历史使用反馈，不断言所有版本或平台必然如此，也不把原因全部归于模型。按风格通则中的“使用痕迹与纹理密度”写清预期表面状态，实际生成后再核对，未测试不能声称已解决。

## 正向与逆向

- **正向生成**：从明确事件或已选候选出发，按用途选择状态、尺度与观察位置，再写可见画面；视频用途先设计过程。
- **反推**：先记录图里实际可见的对象、接触、材质、色彩和当前状态，再组织提示词。看不到的前后过程不得当作事实。
- **分析**：按用户所问维度回答；只有要求反推或写提示词时才附完整 prompt，不把纯分析强行变成创作。
- **照某图风格写新事件**：迁移色彩、材质观感和生活逻辑，不照搬无关道具与原图构图。

拆解需要时放完整提示词之后，用错位关系、变化承诺或持续状态、可见证据、材质、空间、角色、光色、生成风险来说明。不按家族标签断言“有因果／无因果”。

## 写图前先决定：用途、动作范围与这一刻

用途按主文件判断。**独立图片先选表现力；视频首帧先设计过程。** 不因一张展示图漂亮，就把它自动当成视频起点。

视频用途先按视频规范确定本段要保留的行为：从哪里开始、经过哪些必要动作、到哪里结束，是否需要分镜。再把起点写成姿态、接触、距离与区域状态，不能只写“首帧”“中间态”标签。联合交付时，在提示词外简记“用途｜起始状态 → 主要过程 → 结束状态”；仅交付图片提示词时，可用一句制作说明标明用途与预留动作，不额外扩写整份视频。

| 选帧任务 | 当前图应呈现什么 | 判断依据 |
|---|---|---|
| 独立展示 | 最能读懂错位与表现主题的一刻，可有局部或完整结果 | 不承担后续动作预算 |
| 拍前置与操作 | 角色仍在所选前置动作开始的位置；目标、工具、落脚点与路径成立 | 不提前画出将要拍摄的接触或收成 |
| 从过程中续接 | 已有接触、处理范围与剩余动作空间 | 保留的过程符合用户目标，不是因为展示图已画到此处就被迫省略前段 |
| 拍完成后的行为 | 已有结果及接下来可执行的收拢、搬运、放置或日常互动条件 | 不把完成图判为绝对不能做视频，也不倒演已完成过程 |
| 持续状态 | 可读的不可能关系与互动姿态 | 保留自身运动，不强加形成过程 |

**首帧要有可读的梦核线索，不必已经完成操作。** 巨月靠近梯顶、猫在梯脚准备登梯，已经能交代不可能尺度。不要为“错位一眼可读”强行让海绵首帧就贴在月面。

### 为动作布置空间和道具

计划里要用到的水桶、颜料盘、工具、接收容器和支撑面，应在起始场景中有合理位置与可达路径；当前取景看不到的部分须在方案中交代，必要时换取景或补图。不要到视频提示词才凭空增加关键道具。攀梯、双手操作和移物时同时检查站稳、扶持、工具携带及转身余量，不为“连贯”安排无法同时完成的动作。

批量劳动已有的收获可以留在周围，不要求为新一轮操作清空整个场景。例如要拍一铲水的完整搬运，空铲在水边、车里已有收获可以成立；若铲上已经有水，则已跳过本轮入水与舀起。判断对象是本段要拍的动作，而非整场劳动是否从零开始。

### 一图兼用与分别设计

双用途时，起始画面本身有表现力且能保留目标过程，就共用一张。若展示图必须呈现满网收获，而视频要拍从空网到收满，则分别设计展示图和较早首帧。两图保持角色、空间、道具与材质一致，只按用途改变状态；不强制所有任务都交两张，也不强求兼用而牺牲过程。

### 按目标选择起点：堵云止雨

若只拍最后压紧与停雨，可写木塞已进入漏口大半、缝边仍有细水；若要拍对准漏口、举塞、压入到止雨，就应把木塞留在漏口外、保持手臂路径与持续雨线。两种都合理，按动作范围选择。云保持连续体块和柔和密度边界，不因开口生成厚皮卷边。

实际出图若已超过计划起点，按视频规范处理；不能一面要求完整形成过程，一面默认只拍完成后的余波。

### 静帧的时间纪律

一张图只写一个可同时看见的时刻。接触与结果可以在空间上同框，例如刷子边缘一侧已亮、一侧未亮；不要把“抬手、擦完、转身离开”三个时刻塞进同一张图。纯状态图不用人为补上新旧两态。

独立图片若要表达“停止”的结果，用残余痕迹与未处理区域对照帮助判断，不凭空声称单张图能证明速度为零。视频首帧可以仍有完整雨线，将停止过程留给视频。

## 八环骨架：用于组织信息，不是八段填空

| 环 | 应交代的内容 |
|---|---|
| 用途 | 简短命名图像类型，如梦核风格超现实摄影；不占篇幅解释用途背景 |
| 主体 | 角色可见锚点、当前姿态、具体手部或爪部动作、接触点 |
| 构图与空间 | 从哪里看、景别、主体和环境的关系、通路、遮挡与尺度参照 |
| 风格 | 复古生活布景与制作观感；具体物体的颜色有所归属 |
| 光线 | 本场景的时间、柔和光线方向或影响可见性的照明；避免重复风格段 |
| 材质 | 被操作的自然物保留什么识别特征，工具、服装和环境各自是什么材质 |
| 文字 | 无文字需求就省略；用户要求时明确文字内容，不套通用无文字禁令 |
| 负向 | 本场景真实存在的误读或多生风险 |

按上述关系组织成自然语言，允许合并和省略无关项。用户明确限制图片篇幅时，先删同义修饰、无关背景和重复拍摄效果词；保留错位关系、当前状态、操作通路，以及必要的色彩组织和表面要求。不要堆“真正的”“运维官”等无法直接渲染的身份判断。

## 人物朝向与锚点

角色锚点分成恒定特征与当前可见特征。发色、体型、服装配色保持一致；眼睛、领口、胸袋等只在当前角度确实能看见时写。逐字复用不能压过可见性。

| 朝向 | 写什么 |
|---|---|
| 背身 | 后脑、肩背、服装背面、手臂与接触；不硬加正脸五官、胸前细节和不可见表情 |
| 正侧 | 可见侧脸、单侧眼睛和身体轮廓；不补被遮挡的一侧 |
| 四分之三侧 | 按实际可见程度写脸部和身体，不机械限定只能一只眼睛 |
| 正面 | 可见五官、胸前服装与双手；背部信息仅在镜面或转体等可见条件下写 |

多人场景优先统一工装与少量关键人物锚点；不要逐人描脸和堆相互冲突的手部动作。具体人数由故事决定，非关键数量可用“几名”“一组”等泛量。

## 场景定位与空间连续

每条生图提示词须能独立交代事件发生在哪里：根据事件需要写清具体场所、角色的落脚或作业位置、关键对象的相对位置，以及操作处与结果区域之间的空间联系。不能只依赖提示词之外的标题、分镜表“场景”栏或旧聊天提供这些信息。“花园里”“山顶上”等宽泛地点不足以替代关键作业布局。

场景设计由提示词作者完成，不把决定事件是否成立的位置、可达路径、遮挡和支撑面留给生成模型猜。位置优先采用角色、工具、门窗、工作面等可辨对象作为参照；前中远景只在有助于理解空间或规模时交代，不机械填满三层。非关键装饰可保留自由度，特写也不必强塞画外建筑和地形。用户未指定地点时可按已选事件作合理设计，不因此增加一道选题确认。

同一地点跨镜使用时，先确定少量场景锚点，例如门窗与工作面关系、主要通道、固定道具位置和外部景观方向，并在各镜正文保留当前视点能看到的锚点。改变机位时保持世界中的布局，不能机械保持物体永远位于画面同一侧；场景转换则重新说明新地点，不强行维持旧布局。实际参考图优先，未见区域只能作为新设计，不能宣称已由图片证明。

## 构图、尺度和接触

先按主文件确定量级，再记录相关的规模证据并写入画面正文：

- **空间范围**：现象从何处延伸到何处，覆盖哪些可辨区域；不能仅列远处山谷或小镇当背景。
- **相对尺度**：自然对象、角色、工具、建筑互为参照；大场面允许角色缩小，以服装轮廓等保持识别，不强求每镜面部特写。
- **数量与分布**：零星、成群、满载或连续覆盖必须有布局证据。满载写容器内聚集和层叠，大范围降落写前中远景的连续分布；不硬填无关的精确计数。

只选择事件有关的证据，不要求每张图同时“大、多、满”。构图应容纳核心现象及其作用联系，不能只用“壮观、无数”代替可见关系。减少无关条件不等于减少核心对象。

再决定观察距离：

- **奇观型**：用全景或远景交代自然对象、作业面和尺度参照；巨物可以占主导，不能把整片山谷变化缩成一个小道具。无需固定物体占比、仰角或人物百分比。
- **日常型**：中景、近景、特写均可，只要仍能识别自然本体和不可能关系。牵水球不必铺满全景；手指与水体的牵引关系可能比广阔天空更重要。
- **批量场景**：晾晒、收割、采集、生产、储存等具有批量属性的事件，用户未要求少量、单件或近距离小品，且事件本身不限定唯一对象时，优先用成排、成组、满架或连续延伸的布局呈现批量关系。不能自动采用“一个正在处理、另一个充当背景”的最小配置。数量、间距与容器容量须匹配场地及对象尺度，不设置通用固定数量，不为数量机械复制。
- **单次动作与场景总量分开**：主体可只处理一个对象，周围已有的成品、待处理对象或远处同类对象仍可丰富。只描述有用途的对象组，不强制每镜同时摆出全部工序。晾云可让主体夹最近一朵，后方多道晾绳已挂成排的大块云；云朵大小、朝向、间距有自然差异，构图兼顾近处接触和后方批量关系。用户明确要求单朵云时仍按单朵处理。
- **同一事件的不同镜头**：可分别服务接触、结果或空间，但先按视频规范确定是否真的需要切镜，再为所需镜头准备静帧。

构图变化服务于信息和节奏，不用“连续两镜必须换朝向”的轮换指标。相同构图可用于强调前后变化；更换事件后也不强行沿用原机位。

工具匹配真实接触点：绳结系在哪里、海绵贴哪块月面、塞子如何压住漏口。直接接触优先，避免无功能的托架与缓冲层；渔网、篮子等本来就是捕捉或收集工具时可以保留。跨越距离时交代梯子、船、操作台或长柄工具，不让角色隔空操作。

空间连续性要通过可见线索表达。例如浴缸中的海具有远处地平线、海岸与航船；如需要海水漫出，连续的波纹、水流与沙粒交代内外联系。若只想维持容器内世界，不额外加溢出。

### 世界尺度、对象尺度与首帧生命感

按主文件的尺度约定，在构图中保留足以区分真实世界与桌面模型的连续参照，例如角色与门窗、道路宽度与沿路植被、近处作业面与中远景建筑。近大远小本身不是微缩错误；检查角色与其所在环境的比例、地形是否连续，以及是否有模型边缘、桌面承托等相反证据。需要表现广阔尺度时允许角色较小，不为看清表情放大角色。工具可按功能放大，但不能通过无意缩小整座山谷解决接触。

跨距离的尺度错位只在当前事件采用时设计，交代近景操作与远景唯一目标的对位和后续作用，避免另造一个近处替身。它不是所有梦核画面的必选机制。

活体首帧选择支持后续自主行为的姿态、视线目标与运动余量，保留符合物种的身体结构和表面差异。不是每张图都要夸张摆动；仍需排除把活体做成均匀塑料、标本或陈列摆件的误读。具体行为续接由视频规范设计，静帧只描述当前时刻。

## 视觉秩序与非镜像均衡

默认优先非镜像均衡，不要求角色居中。视觉重量综合体量、明暗反差、色彩纯度、位置、细节及脸部、文字、发光体等注意力因素；小面积高对比元素可能平衡较大浅色区域，但不存在固定换算比例。提示词写出谁在何处、大小明暗如何呼应，不只写“平衡构图”。

按任务选择一种主要组织方式，可适度结合：

- **水平分层**：用地面、作业面和远景形成清楚区块，层数由内容决定，不强制三层。
- **重复节奏**：窗户、栏杆或工具组建立秩序，保留自然差异，不镜像复制角色或批量克隆物件。
- **框中框**：门窗限定视野，强化内外联系；框边不能切断接触点或挡住结果。
- **斜向与留白**：梯子、山坡或运动路径形成方向，对侧用现有物体或较安静区域缓和偏重；留白可以是渐变天空、水面或疏云，不必纯色。

建筑本身可对称，画面内人物与活动不必镜像；明确需要仪式感、轴线展示或用户指定对称时允许对称。不要为了配重擅增第二只猫、第二个月亮或无关道具，优先调整观察位置、取景和已有对象的布局。正面机位不等于无纵深，俯拍也不自动消除立体感；保留目标所需的遮挡、尺度和空气层次。

视频首帧还须容纳后续动作的路径与终点。运动中视觉重心可以转移，不要求每帧左右等重，不锁死物体位置换取静态平衡；机位是否跟随按视频规范判断。电影名和构图术语只可辅助，正文应落到可见对象关系。

## 提示词稳定性参考

以下是写作建议，不能作为所有模型都会如此的保证，也不能取代实际出图核对：

- 一次突出少量关键姿态或空间条件，避免大量相互争夺的约束；这不限制事件所需的对象数量、雪流体量或作用范围。
- 位置说清是画面方位、角色方位还是靠镜头一侧；改写为相对位置不保证自动解决镜像问题。
- 尺度用已知物参照，比重复“巨大”更具体；数量是叙事关键时仍需写明，并在出图后核对。
- 景深服务可读性。24–28mm 可作宽阔空间的语言参考，35–50mm 可用于生活距离；这些不是实际拍摄元数据。不要仅凭焦段断言必然深景深或浅景深。
- 默认通透成像并带细腻克制的胶片颗粒，具体强度与边界按风格通则；用户要求无颗粒时移除。柔和光色不靠整体模糊实现，不牺牲月面纹理、云气边缘与接触点。家居使用痕迹和伪纹理控制按风格通则执行。
- 正文优先描述要出现的状态；抽象的“不要 AI 味”改成具体材质、照明和姿态。否定约束是否有效取决于实际工具，不概括为模型一概不理解否定。

## 负向提示词

负向限制须区分合理数量与无依据增生：批量场景中限制悬空衣夹、同一夹持点重复增生等具体错误，不用“不要大量衣夹”等笼统数量禁令压制合理配套。

只写本场景的具体风险：洗月亮时可排除第二个月亮和灯笼；拉夜空时可排除星空印花窗帘；水球时可排除橡胶气球；有年代布景时才锁现代装置。不要每条照抄“文字、现代物品、无关角色”。

若工具有独立负向栏，放入对应栏；只有普通文本框时，以精简排除语句或正向改写适配，不假定所有工具都有负向参数。抽象审美厌恶优先改成正向具体描述，不重复堆“不过度美化、不刻意修图”。

## 事件案例库

以下是已有创意关系的文字整理，并非这些提示词已在当前模型实测。结果按主文件规则检验，案例不构成限制。

| 事件 | 静帧可见证据或状态 |
|---|---|
| 摇罐撒星 | 星流从罐口向夜空延伸，接入处已出现新星点；不只是罐中装饰灯 |
| 洗月亮 | 海绵贴月面，洗过区域更清亮，未洗区域蒙灰，两侧均保留月面纹理 |
| 机器造雪 | 原料、机器入口、连续雪流与已积雪地面有空间联系；机器运转本身不等于降雪结果 |
| 给树林染秋色 | 喷涂接触附近出现叶色分界，影响范围与“一棵树”或“整片树林”的承诺一致 |
| 卷走积雪 | 雪边被卷起，后面露出春花与地面；雪保持雪的颗粒和层次 |
| 粉刷天空 | 滚刷作用处一侧仍有云气，另一侧露出晴空，天空保留空间感 |
| 拉云浇花 | 绳与云直接联系，云下雨线落入花田，植物与土壤有可见受雨状态 |
| 吊起太阳 | 吊索与发光天体相连，太阳接近地平线，地面出现与升起方向一致的受光变化 |
| 整理极光 | 角色从高处牵引或铺展光带，带状发光现象保留光的质感；不写成纱布纹理 |
| 给漏水的云塞木塞 | 木塞压入漏口，残余细水与未封处对照；视频中水线断开即可完成止雨结果 |
| 在白天天空剪开一个口 | 剪刀与开口边缘相接，口内有星夜纵深，周围仍为白昼 |
| 推开夜空露出清晨 | 手或爪有可达路径，开口后露出清晨，边缘仍有星空的空间层次 |
| 给乌云装入闪电 | 光的分叉与云层内部的闪动联系可见；普通灯条仅是工具时，不把云改成棉花灯罩 |
| 渔网捞星 | 网中已收住星光，网外仍有星点，接触与收成可读；不强制另写天空少了一块 |
| 牵有鱼的水团 | 绳牵悬浮水体，鱼、水面折射与液体形变可见，持续互动即可 |
| 晾云、采云 | 云被夹住或收集，仍呈云气质感；若宣称晾干或收获，则呈现对应证据 |
| 云作燃料 | 采集的云气由加注口进入车辆，若宣称驱动车辆，视频需要兑现相应反馈 |
| 铲海水装独轮车 | 铲口与被舀起的连续水体、车中保有波纹的水体构成关系，不写成蓝色石块 |
| 风筝嵌窗 | 风筝在空中，窗内有人或另一空间的纵深，日常放风筝姿态成立 |
| 星星雨撑伞 | 星光落下，人物自然持伞；持续降落即可，不强制伞面最终堆满 |
| 冰箱里的海与天空 | 门打开，内部世界有地平线与云层，容器外仍是生活空间 |
| 罐子储存星空 | 罐内可见深邃星空或被收住的星光，与普通灯饰或亮片区别清楚 |

旧素材中的“荷包蛋太阳”“纱布变极光”等物件替换方向，依风格通则处理：仅在用户明确选择该设定时使用。不要因为旧案例出现过，就自动给自然本体换材质。

## 已记录失败与有条件的修正

这些是旧版记录的失败现象及修正方向，不声称所有模型都会同样失败：

| 观察到的失败 | 可能原因与修正方向 |
|---|---|
| 浴缸海变成海景浴室与玩具船 | 普通解释占主导；把海的纵深放在浴缸内部，去掉误导的海景窗，保留内外尺度关系 |
| 洗月亮变成擦灯盘，天空另有月亮 | 本体与操作对象断开；接触直接落在唯一月面，结果紧贴接触处 |
| 拉夜空变成星空窗帘 | 描述加入了布料或窗帘结构；保留伸出窗外的接触与开口，删不必要的底沿、包边、杆环等结构 |
| 榨晚霞变成榨汁机加背景晚霞 | 两件事没有可见联系；写清天空、入口与输出的连续路径 |
| 背身人物转成正脸或五官错位 | 不可见五官与背身条件冲突；裁剪角色锚点，按朝向写 |
| 夜景被画成黄昏 | 套用了暮光配色；按实际时间选色调，不能只加“深夜”标签 |
| 大范围事件只出现小设备和少量效果 | 工具、影响范围与事件承诺不一致；扩大可见作用范围，不把所有日常型事件一起巨型化 |
| 云变棉花、月亮变纸灯 | 本体材质被比喻或道具观感改写；回到风格通则中的识别特征 |
| 云体已大块但表面仍细碎，接触处出现厚皮卷边 | 分别控制轮廓、内部密度与接触边界；按风格通则用透光和遮挡代替微小凸起与实体孔壁，不只追加否定同义词 |

## 交付前核对

先检查项目美术是否落到当前可见的建筑、道具和颜色，均衡是否靠具体布局而非镜像复制；再检查正文能否独立定位场所、作业位置及关键空间联系，同一地点跨镜是否保留可见布局锚点；不能只靠外部场景栏。再逐一检查画面实际出现的材质，按风格通则触发相应正向描述；不能只在负向栏堆词。去掉标题，规模是否仍由范围、参照和分布读得出来？仅靠背景开阔或“大量”形容词不算通过。批量事件还须检查是否误把单次处理一个对象写成全场只有一两个；检查负向词是否误伤合理配套数量。再核对错位、材质、接触通路、角色可见性、当前时刻、变化承诺或持续状态、表达尺度、色调档位与具体负向风险。若供视频使用，再核对是否保留本段所需的前置、操作和收尾空间，工具与路径是否支持整段行为；双用途核对共用或分图是否有必要。所有结论以实际图片为准；尚未出图时只能说明计划，不能声称已经满足视觉条件。
