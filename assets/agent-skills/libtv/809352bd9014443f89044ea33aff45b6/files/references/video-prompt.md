# 梦核图生视频提示词

本文件维护图与视频的状态衔接、固定机位／运镜／切镜、时长和视频输出。概念与结果规则见 [SKILL.md](../SKILL.md)，本体材质与光色见 [风格通则](style-guide.md)，需要新图时见 [图片规范](image-prompt.md)。

## 一、先确定图片怎么进入工具

本流程默认为**提供起始图，再从当前画面向后生成**的 I2V 工作方式。技术上的起始图，可能描绘故事刚开始、正在进行或已经完成的状态；技术用途与叙事进度是两件事。

若实际工具使用尾帧、多关键帧或其他参考机制，应按已确认的功能安排输入，不凭某个模型名称假定其支持。没有实际图片、只有静态提示词时，可以写条件式视频草案，但注明待出图核对；不要声称已经判断图中姿态。

## 二、在生图之前规划，在出图之后核对

### 尚未生图

先设计本段行为，再按图片规范选首帧。简记：**动作范围（从哪一步到哪一步）、必要动作链、镜末状态、所需道具与路径**。机位和切镜服务这些内容，时长按第六节安排；不能先把结果画完，再为剩下的一点动作凑秒数。

“擦月亮”只命名事件。若用户要有劳动过程，可设计登梯站稳、蘸水、提起海绵、擦拭与收手；若只要看清一处月面变亮，可从海绵贴面开始。选择依据是本次目标，不默认最早起点，也不默认从接触中途开始。具体动作组织见第三节。

用户明确要拍的前置动作须进入计划。要求从梯底爬到顶部，就从底部设计，给攀爬所需时间或分镜，不能擅改成已站梯顶。动作、镜数与时长冲突时先指出具体冲突，提供保留目标的可行安排，不用加速、跳步或直接改起点掩盖。

### 已经出图

先看实际图，再参考原提示词。**实际图决定当前画面，用户意图决定想达到的目标；两者不一致时需要调整衔接。** 原提示词不能覆盖图片中已经发生的事实。

读图核对四项：

1. **接触**：手、爪或工具是否已经接上目标？接触点可见还是被遮住？
2. **状态**：处理过与未处理区域在哪里？门开了多少，塞子进入多少，水线是否仍存在？
3. **目标过程是否仍可完成**：与原定动作范围对照，哪些步骤已被画完？余下动作是否有道具、路径、余量与画面空间？不能只因还能动一点就认定首帧适用。
4. **尚不确定的事实**：单帧通常不能证明风已停、云正在上升或某件事刚刚完成；没有前后证据时不要过度推断。

原图出现材质跑偏、错位不可读或关键接触错误，先指出并修正静帧方案；不要把“视频会自动修好”作为计划。若进度变化不影响所需过程，可顺着实际状态调整；若已经跳过用户要看的步骤，应补较早首帧，不能以“顺图续接”为由删除目标。

| 实际起始画面 | 视频如何写 |
|---|---|
| 尚未接触，动作路线清楚 | 接触、施力，再出现与接触对应的变化 |
| 已经接触，结果正在形成 | 目标是续接时沿现有状态推进；目标含缺失前段时补早帧，不将动作复位重演 |
| 承诺的结果已完成 | 目标为后续行为时可用；目标为形成过程时换早帧，不以余波替代用户所要过程 |
| 本来就是持续错位 | 写角色、对象和环境的合理运动，错位贯穿始终；不强加新的世界改变 |
| 进度不明确 | 采用与可见状态兼容的小幅续接；若不同判断会根本改变任务，才询问或补充起始画面 |

**输入图的处理以目标为准**：缺失所需前段时，设计更早的首帧；只有工具确已支持相应机制时，才把完成图用作尾帧或多帧参考。保留现图作展示参考不等于强制生成另一张展示图。若用户要求只用现图，说明能正向拍摄的范围与无法还原的前段，不保证仅靠提示词即可补回。

## 梦核的视听表达与镜头生命感

在选首帧与摄影方式前，先分析本事件的梦核关系，再设计时间中的观看体验。此节负责视听表达，具体材质和色彩归属按风格通则，机位与切镜按第四节，时长按第六节。不要把本节机械扩写成每镜必填的额外栏目。

### 从错位关系确定观看重点

内部明确：哪种自然规律被日常行为改变；观众从什么可见证据读懂这种关系；最值得看清的接触、变化或持续状态是什么；结束时留下何种画面与感受。选择与本事件相称的轻盈、宁静、惊奇、辽阔等体验，并落实为体量、姿态、空间、运动和声音关系，不能只加入情绪形容词。

选择合适的奇观展开方式：直接呈现、逐步揭示、由局部扩展到整体，或以细小日常行为带动巨大环境变化。尺度反差、材质手感与微小的异常接触都能形成观看价值，不强制每镜经历铺垫、高潮和反转。持续型事件可以一直呈现安静互动，不为“奇观”擅加世界变化。

### 让主要变化有可见形态

当生长、展开、剪切、修复、汇入或色彩传播是主要看点时，结果动词不足以代替过程。按本镜需要明确起始形态、可辨的中间变化、推进方向和结束状态；形态与颜色影响辨认时，作具体美术选择。多对象变化说明同时发生或先后传播，以及近、中、远处的分布与观看层级。用户未指定的必要细节由作者设计，不反复索取偏好。

例如开花可以表现合拢花苞鼓起、花瓣向外舒展、花心显露与轻微回弹，并为本项目选择花形、花色及成簇关系；这不是所有开花镜头的固定步骤、花种或配色。用户要求迅速开满时，多个落点可交叠展开，保留可辨过程与承诺规模，不逐朵排队拖长。

主要变化需沿已建立的作用路径发生。没有明确采用剪辑省略或其他变换设定时，不用整体换色、淡出淡入、目标瞬移或另生替身，代替观众需要亲眼看到的过程。镜头预算不足，按第四、六节重排信息、取景或时长，不省略核心关系。

### 呼吸感与松弛动作

呼吸感来自注意力、动作强弱和运动密度的变化，不等于慢动作；默认密度与速度按第六节，不能用呼吸感为内容稀薄或长停留辩护。根据事件在接近、建立接触、作用发生与余波收束之间安排适当速度差；短视频可在一个连续动作内形成节奏，不用空等、重复表演或持续慢推填时长。也不强制每个动作都有停顿、蓄力和收尾。

松弛来自顺势、协调和熟练：身体重心随任务转移，手臂、肩背、步幅与握持共同完成动作；根据实际阻力或对象响应调整。接触解除、换手、转身、落脚等必要衔接须可执行，不能四肢独动而躯干僵直，或让结果无动作地自动发生。具体接触反馈与角色响应按第三节，避免重复堆写。

### 活体与有来源的细节

活体应通过符合其形态的自主行为、身体协同或受刺激后的必要响应呈现生命感。单纯位移、眨眼、表面湿润，或删除吊线，不能单独排除雕像与标本解释。用户明确要求雕塑、静止休息或睡眠时尊重设定，不为合规强迫持续游走。

选少量能证明材质、生命或因果关系的细节：受压刷毛、展开后的花瓣回弹、脚离开后水面的回拢等。细节由本镜动作或环境触发，景别下可读即可；不同时堆满摆尾、飘发、飞鸟、尘粒和水花。主要变化、辅助反馈与稳定参照有主次，不让所有区域以同样强度运动。

### 运动中的美感、氛围与摄影

美感须在运动中持续成立。考虑主体移动或现象展开时，画面的色块、遮挡、方向、疏密和视觉重心怎样变化，哪些稳定区域为变化提供参照。材质、色彩与光照随时间的规则见风格通则，不把美术只写成静帧标签。

氛围由有来源的照明、空气层次、环境运动、声音距离与角色状态共同建立，按内容选择适用因素，不默认增加雾、逆光、泛光、粒子或配乐。近处接触声与远处环境声可以建立空间；仍遵守当前音频要求。

固定机位可以通过镜内行为、前后变化和遮挡获得生命感；运镜与切镜须有第四节规定的信息或表达目的，交代观看重点如何转移。巨物不自动要求后撤，人物运动不自动要求跟拍；也不能以“稳定”为由冻结自然现象。需要近看接触又要展示广阔结果时，实际选择可读的取景、运动或必要切镜，不将相互冲突的尺度塞进同一画面。

### 交付前的表达检查

去掉“梦幻、生动、自然、震撼、电影感、氛围感”等评价词，正文仍应说明看什么、主要变化怎样展开、动作怎样衔接、必要细节为何发生、结束停在哪里。缺失时补设计，不补形容词。纯状态与简单短动作按其实际需要检查，不能为填项增加任务。

## 三、动作与结果：从这一态继续

先按主文件判断是否承诺变化。变化型按“当前状态 → 可见推进 → 约定结果”设计；持续型按“关系与总体状态持续 → 对象运动、日常互动与物理反馈 → 自然延续”设计。两者都要有时间感，不都套起手、过程、果三段。

- **结果须兑现到事先约定的范围**。洗净一小片月面可以成立；要求洗净整个月亮，就不能只擦一点当完成。部分面积完成、随后继续蔓延也可以，只要观众已经看到本镜承诺的结果。
- **停止类结果允许**。堵云时水线在封口后断成水滴，滴落结束，原落点水波渐平。云仍在、地仍湿，雨停即可；不附赠晴空或地面瞬间干燥。
- **收成就是结果的一种**。捞到的星已在网中，不必再附加天空永久缺一块；收风若承诺外界风停，才需要外界对照。
- **纯状态无需新增结果**。水团随步伐轻晃、内部鱼继续游动，足以呈现“牵水散步”；不要凭空新增水源、坑洞或取水过程。
- **运动保留材质差异**。云是云气形变，水有液面和表面张力，动物仍有毛发或皮肤，月面不自动变成海绵。包裹月亮的针织物在月面外增长，两种材质分层可读。
- **动作量服从目标与时长**。已在中途的镜头不复位重演；新设计可以从有用途的前置开始。动作超出一镜容量时调整时间或拆成有明确任务的镜头，不一律删除准备和收尾。

动作通常平静、连续，但动词速度由事件决定：雨滴断开可以短促，云体余波可以缓慢。不要把所有现象都写成持续喷涌，也不要把堵雨写成“雨不能停”。环境微动只选与本事件有关的，不每次同时加入烟、风、鸟、草与尘埃。

### 把事件写成连贯行为

先选本段需要的环节：**前置准备 → 工具或身体操作 → 对象反馈 → 收尾或下一轮衔接**。这是设计参照，不是每镜必填的四段，也不规定动作数量。

前置有助于交代目的地、建立接触条件、补充材料或表现劳动时保留；无信息的等待和重复才删。操作包含方向、施力和可见变化；收尾可由取回工具、卸下收获、放稳或检查结果构成。只为填时间的眨眼、摆尾、慢推不算过程丰富。

例如在已有梯顶作业面上洗月亮，可从海绵靠近水桶开始，蘸水、提起稍沥，再贴上月面连续擦过一片区域，最后收回。视频需要的水桶应在首帧可达处。涂彩虹可从滚筒蘸色、提起转向，到推出色带和抬离；仅当用户要看一次短笔触时，直接从接触开始。例子用于组织动作，不把蘸水、蘸色强加给所有事件。

区分**倒退重演**与**自然的下一轮**：已擦完的区域复原后再擦属于重演；擦过一处后重新蘸水、处理相邻区域属于继续劳动。下一轮需有未处理区域、材料和时间，不为延长片段无意义循环。持续型事件无需改造成任务链。

### 核心现象的自身运动

降雨、落雪、星雨、流水、飘移等运动本身构成事件主题时，须明确对象相对场景的可辨运动，不能只写其外观或笼统的“持续”。按当前现象需要选择方向、参照物、镜头内可见的位移、持续方式；涉及接触时写接触后的路径。不要求每条机械填齐所有参数，也不强加精确速度或新的世界变化。

区分角色运动、摄影机运动与核心现象运动。侧向跟拍带来的背景视差、星点原地闪烁、下落声，都不能代替星点相对山脊、屋顶或伞面的向下位移。先把核心现象写清，再补人物动作与必要的环境微动；减少次要动作不能删掉主题现象的运动。

持续型事件中的“状态保持”指不可能关系与总体状态持续成立，不是冻结其中每个对象。连续降落可保持总体密度，同时已有个体下落、被遮挡或离开，新个体从合理来向接续；流水保持通路，水体沿通路流动。短光迹随发光点运动，不默认成为固定悬挂的线条。合理补充不等于凭空增生无关对象。

例如星雨：星点相对屋顶持续向低处移动，近处光点掠过伞边，远处细密光流落向山谷；已有星点出画或被遮挡，上方新的星点接续进入，维持整体雨势。接触伞面的星点沿伞面滑向边缘，再继续下落。方向、接触与路径仍须适配实际起始图，不能无视原图重新设定。

### 运动强度、接触反馈与角色响应

**方向不等于强度。** 事件需要急促、猛烈、缓慢或轻柔的运动时，将强度落实到镜头内可见的速度、位移、通过频率或作用反馈，按需要选取，不机械填满参数。连续流动要考虑同一区域中的个体如何经过、离开和接续；数量更多、对象更大、拖尾更长或音量更高，都不能单独代替运动速度与作用强度。角色平静、机位平稳不意味着所有自然现象都慢动作。

**接触要有前后差别。** 交互是镜头重点时，交代接触位置，以及接触后相关的路径、形变、速度或受力变化；被挡住、沿表面滑动、分流、反弹或穿透应符合本镜已确定的超现实设定。不能只写“发生交互”“产生压力”，也不能让碰撞双方互不影响。需要遮挡时，接触面前后应有可读区别；无需交互的背景现象不强加碰撞。运动与反馈保持各自材质，不把自然对象一律写成硬颗粒。

**角色回应可见刺激。** 当环境确实影响角色时，先让接触、阻力、声音或视线目标成为可感知触发，再让角色调整握持、重心、姿态或步幅；调整应与刺激时间相连，身体各部位按实际承重和任务协同，避免只动四肢而躯干僵直。按当前景别和动作量选择可读的必要响应，不为表演擅自新增危险、冲突或强行堆微表情。角色可以预先防备，但须有可见来势或已经知道的情境依据。

**同一次交互按因果与时间顺序描述。** 角色主动操作时，优先沿“角色施力 → 工具传递 → 对象变化 → 角色随反馈调整”组织动作时间；从实际起始状态续接，只保留本镜需要的环节，不重演已完成的起手。不先完整写完工具与对象的效果，再把关键角色动作作为末尾附注。环境先作用于角色时，按实际因果写环境刺激、接触反馈与人物响应，不为了套模板让角色先施力。

时间顺序表达的是可见动作联系，不要求全部动作先后分段：同时发生的施力、工具运动与对象变化可用“随着、同时、随即”等简洁连接。独立并行的运动可以分开描述，不强行串成不存在的因果。物理栏补充材质与运动机制，不承担补写关键施力或角色响应的任务。不能只因角色写在后面就判失败，须检查关键动作是否已经及时、清楚地与接触及变化绑定。

**先保住关键动作链。** 短镜优先保证“核心运动 → 接触反馈 → 必要响应”可读，删减抢占注意力的次要动作、复杂运镜与重复说明。并非每镜都必须包含完整链条：纯观察保留运动，纯接触镜保留接触与反馈即可。已在强烈作用中的首帧直接续接，不无故重新从弱到强；确需渐变时，起始状态与时长应支持它。

### 生成失败后的排查

先区分三类问题：提示词是否遗漏或相互冲突；实际起始图是否支持预期运动与接触；模型是否未执行已经明确写出的要求。只凭一次失败不能确定全部原因，也不能把模型未执行一律归为“没写”。

优先做一次聚焦的修订：保留关键动作链，删去次要任务，明确最缺失的可见证据；不要堆同义词或无限加长。再按起始帧、关键接触帧和末帧检查速度、路径、反馈与响应。明确指令仍反复失效时，检查首帧构图、接触面、遮挡、图中固定拖尾等因素，按实际情况补图、拆分必要镜头或尝试已确认可用的工具控制；不能保证仅靠文字必然修复，也不臆测平台功能。

## 四、固定机位、运镜和切镜的判断

**先决定观众需要看见的信息顺序，再选择摄影方式。** 这是一项由提示词作者完成的设计工作，不把“根据故事自动运镜”留给视频模型猜。不要按“有巨物就后撤”“人物移动就跟拍”的关键词自动触发。

### 先写三个答案

内部用三句话明确：

1. 观众开头需要认出什么？
2. 哪个接触、变化或新信息必须在何时被看清？
3. 结尾需要留下什么画面？

再判断信息是否始终在当前画面内、是否必须保留空间与时间连续、是否需要在某个时刻改变观众的理解。用户要求解释方案时给一句具体理由；通常把选择直接落实到提示词。

### 固定：画面内的信息已经足够

当前取景能清楚容纳关键关系，动作与结果都读得懂，观看重点是对象自己变化时，选固定。人物在画面内走几步、云在飘、巨物占满画面，都不自动要求摄影机运动。

**例**：堵云的手、漏口和下方水线都已清晰可见，固定机位能让观众直接比较水线由连续到断开。无须再推近制造“电影感”。

可在光学栏简写“固定机位，维持当前取景”。这条是明确的创作指令，不保证模型一定执行；删掉运动词也不保证机位必然固定。发现无意漂移时，再针对实际结果精简或加强这一要求，不堆通用否定串。

### 运镜：需要连续地跟随、揭示或重新分配注意力

只有关键变化确实会出框、被遮挡或无法读清，或者故事需要观众连续发现空间关系时，才移动机位。

| 叙事需要 | 可选运动 | 不需要动的情况 |
|---|---|---|
| 结果逐渐扩展到当前画面外 | 在结果扩展后缓慢后撤或横移，让出范围 | 起始全景已经能看全结果 |
| 角色把关键对象带离画面 | 跟随移动，保住角色与对象的联系 | 行动仍在画面内，离开画面本身就是表达目的 |
| 从容器外逐步发现内部世界 | 适度推进或侧移，保留门框等空间参照 | 内部世界已经清楚，推进反而切掉容器边界 |
| 需要看清巨物的高度或路径 | 沿关键方向摇摄，逐段揭示 | 巨物全貌已可见，摇摄只会重复信息 |
| 从接触点连续看到远处效果 | 沿实际作用路径移动 | 移动途中关键因果丢失，或路线过长、超出时长 |

运动写清：**什么时候开始、向哪里、停在能看见什么的位置**。例如“雨线断开后缓慢后撤，停在能同时看见云底木塞与整片湿院子的全景”。速度与幅度服从内容，不每镜都写极缓慢，也不把推、拉、摇、环绕堆成一串。

### 切镜：下一个观察位置带来必要的新信息或叙事作用

同一事件可以切镜。判断下一镜是否完成当前镜头无法清楚完成的任务，或是否通过切点实现明确的揭示、对照、反应、时间省略或事件交接。持续运镜并非永远优于剪辑。

常见成立理由：

- **尺度不兼容**：前镜要看清手指大的接触细节，后镜要看远处整片山谷的变化，单镜无法兼顾，缓慢后撤又会耗掉有效时长。
- **需要在特定时刻揭示**：先让观众理解操作，再在操作奏效时切到先前未见的结果；直接铺开全景会提前泄露信息。
- **关键视点或反应**：角色视线指向一个新的对象，下一镜提供此前不可见的信息；平静反应也可以有意义，不自动加入惊讶特写。
- **有意省略一段重复劳动或转换时空**：通过切点明确跳过时间，不把独立镜头误写成同一瞬间。
- **独立事件交接**：前一事件的结果或持续状态已被读懂，下一事件开始。

不能只用“更丰富”“更有电影感”“补镜数”作为切镜理由。两个镜头只换角度、重复同一信息时通常合并；但有明确前后对照功能的相同构图可保留。

**保护关键因果**：如果观众必须亲眼看见接触导致变化，就让这一关键变化在某一镜中连续可见，不把所有证据都剪掉。切镜可以转交信息，不能靠剪掉过程掩盖逻辑不成立。

### 同一事件的简单对照

| 画面任务 | 选择与原因 |
|---|---|
| 月面、海绵和清洁边界都在画面里，要看边界推进 | 固定：对象自己变化已足够 |
| 清洁完成后要连续发现月光铺到脚下村庄 | 运镜：在同一空间内从月面让出村庄，建立范围联系 |
| 开头需近看海绵挤出灰水，后面要立即揭示远方整片山谷亮起，长距离运动会错过揭示时机 | 切镜：接触细节后转交大范围结果，保留同一月亮、光色与动作关系 |

这些是设计示例，不是从某张静态参考图确认出的原片运镜。三种选择都可能合理，由具体信息顺序和时长决定。

## 五、切镜如何落实为生成任务

镜头是一次连续观察，事件是一个行为或状态单元，生成片段是工具的一次输出。三者不强制一一对应。

默认按镜分别准备合适的起始图、各自的视频提示词，再在剪辑中连接。这样能分别指定每个镜头的取景与状态。只有实际工具已确认支持所需的多镜控制时，才考虑一次请求生成多镜；不假定一句“切到”就能稳定完成任意角度与连续性。

同一事件跨镜时，维护少量可见衔接信息：上一镜结束的动作或处理范围、下一镜开始的状态、角色与工具识别、运动方向、对象数量与材质。处理过的区域不能复原，工具不能无故换手，下一镜不复位重演已完成步骤；新的劳动循环按第三节处理。改变角度后，光源相对世界的位置连续，不强求它永远位于画面同一侧。

新视点需要看见原图没有交代的区域时，先准备该视点的参考画面或明确其设计；不要声称原图已证明这些细节。对独立事件之间的切镜，保留系列角色和整体风格，不强加不存在的物质流连续；若仍发生在同一地点，按图片规范的场景锚点保持主要布局一致。

## 六、时长与镜数

**内容决定有效镜长，不设通用的4秒下限。** 一个清楚的短动作可保留2–3秒；有前置、操作、反馈的连贯行为可更长。数字是内容估时，不代表任何工具的可选参数；既不统一拉到4秒，也不统一压到短镜。留够观众识别关键接触与结果的时间；默认采用紧凑、高有效密度的节奏，允许动作略快或带轻度快进感，优先避免少量动作被拉成慢放。用户明确要求舒缓、实时速度或慢动作时覆盖此默认。

分开记录：

- **剪辑保留时长**：观众实际看到的有效内容，按动作和信息安排。
- **生成素材时长**：按已确认工具的可用档位设置。若最低4或5秒，生成足够长素材，再截取其中有效的2–3秒；工具支持所需短时长时可直接生成。未确认能力时只给目标镜长，将生成参数标为待核对。

时长与画幅放在提示词外的制作说明或参数中。较长素材中仍应按本镜设定的紧凑速度完成动作，余量仅供剪除，不把一个短动作拉慢铺满整段；剪辑须保留接触、反馈与必要结果。提示词描述动作顺序和运动节奏，不混入工具参数。

内容不足时有两条路径：有意义的前置、补料、操作或收尾可丰富同一事件，并相应重设首帧；事件本就简短则保留短镜。不要为了时长新增任务、装饰动作或世界变化。用户明确固定时长时优先在该范围设计；确实无法自然容纳或支撑时说明冲突并提出可行调整，不擅自改成交付多个片段。

镜数按第四节的信息任务决定。一镜能清楚完成就一镜；攀爬与操作、细节与远处结果需要不同视点或时间省略时可分镜。不能把动作过多全塞一镜，也不能重复换角度凑镜数。总时长按剪辑时间线求和，扣除转场重叠并计入片头片尾。现有内容不足以满足总长时，先检查同一事件是否遗漏有用过程；仍不足再按主文件提供新增事件候选，不用空等补齐。

### 动作范围与场景总量

一镜只处理一个对象，不代表全场只有一两个对象。批量场景按图片规范预设成品或待处理组，本镜只推进选定操作；新一轮操作可从准备开始，已有收获与周边数量保持连续。无需为完整过程把整场劳动清零，也不在视频中凭空补出首帧没有的整批成品。

缩短镜头先减少空等和无信息重复，不减少核心对象数量或事件规模。可在符合目标时选择已运行状态，也可通过多镜交代前置和大范围结果；不能以紧凑为由跳过用户要求的过程。

### 每镜的有效密度检查

默认优先级为：核心事件与接触可读、单位时间有充分有效内容、已定镜长保持紧凑。宁可略有快进感，也不把稀少动作拉慢；速度提升不能变成瞬移、漏掉关键接触、肢体穿插或结果凭空出现。以下密度底线是交付要求，不能仅写“自然、生动、快节奏”代替；不设统一文字长度或加速倍率。

**先判断时长约束。** 有已定镜长时，在该时间内组织内容，不因补充动作自动延长。没有镜长时，先设计完整而紧凑的行为，再按路径与反馈估时。按下文选择操作型或持续型的检查方式；混合镜头按主导事件检查，另一类内容可以并行辅助，不机械叠加两套数量要求。

#### 操作型镜头的密度底线

以4秒操作型镜头为基准，默认至少有 **4个有效行为节拍，并有至少2处与操作直接相连的可见反馈**。反馈与动作并行，不另加镜长。其他镜长按实际过程与信息密度预演，不机械换算为每秒一个动作；较长镜头不能沿用同一少量动作再拉慢铺满，较短或用户明确限定单次的镜头按下文例外处理。

一个有效行为节拍须有可辨认的功能或推进：取用材料、完成一组操作、重新补料、处理相邻区域、使一段对象发生明确变化等。“抬手—伸手—靠近—碰到”属于同一次起手与接触，不能拆成四个节拍。脚反复踩动而道路不变、同一点无进展地反复刷动，不因肢体次数多就计为有效密度。动作和它的即时反馈可以分别满足行为与反馈要求，但不能重复计算时长。

#### 擦洗类的必选默认流程

刷子、海绵等进行湿式擦洗时，默认完整安排：

**蘸取清洁液 → 第一轮连续擦洗 → 再次蘸取 → 擦洗相邻未处理区域。**

- 每轮擦洗至少包含两次连贯、有方向变化的笔触，不能只贴上去滑一下。第二轮扩大处理范围或推进清洁状态，保留第一轮结果，不复原重演。
- 清洁液应能产生泡沫。工具蘸取、受压摩擦时形成清楚且适量丰富的泡沫层或泡沫轨迹，随操作发生堆积、推移、破裂或滑落等适用反馈；至少写清泡沫的来源、出现位置和随笔触发展的方式，不能只加“丰富泡沫”四字。
- 泡沫是独立覆盖层，本体仍在露出区域可辨，不能把动物皮肤、月岩或其他自然物变成泡沫造型。只用清水的既有图片不能凭空产生泡沫，须补含清洁液的容器或可见皂液来源。
- 容器就近可达，蘸取与回到工作面直接衔接；不额外安排走去拿桶、端详工具等无用途间隔。首帧应提供清洁液、可操作空间和足够未处理区域。
- 此流程专用于湿式擦洗，不自动套用到刷漆、梳理、打磨、浇水或其他操作。明确的单次、干擦、清水冲洗或不同动作范围由用户要求覆盖，并简明说明按哪个范围执行。

#### 持续型镜头的密度底线

在目标镜长内至少安排 **3个可辨认的视觉进展**，核心现象持续运动，并有至少一条清楚的作用或互动路径。进展可为对象经过不同空间层次、接触后的路径变化、连续展开范围的推进、角色与持续现象的不同互动阶段；不必新增任务、收获或结局，也不要求切镜。

保持相同状态、原地闪烁或轻微漂动不单独算作进展。连续流动须有可追踪的经过、接触或空间变化，不能仅凭“仍在动”判通过。视觉进展可以交叠发生，例如近处形态展开时远处范围继续扩大；不依次停顿展示。

#### 预演、首帧与例外边界

**逐镜预演实际时间。** 顺着目标镜长检查角色在做什么、操作在哪发生、对象同时怎样反馈、阶段结束推进了什么。可按约一秒观察窗口检查，不要求每秒切镜或新增事件。若主要内容很早完成，后面只有拖长的同一动作或等待，须补同一事件内的有意义操作或按用户范围缩短有效镜长。眨眼、摆尾、呼吸、摄影机慢推和装饰粒子不能用来补数量。

**首帧支持动作组合。** 容器、材料、工具、补料位置、未处理区域与操作路径须成立。新增必要物件时同步提出具体首帧修改条件；不能在视频正文中凭空生出，也不能忽略已上传图的当前状态。优先缩短无用取用距离、合并重复收手、安排并行反馈，不改变已选事件。

**例外不能成为默认降密度的借口。** 用户明确要单次动作、干擦、极简观察、舒缓或其他范围时，按该要求覆盖适用的数量或速度默认，在制作说明中指出依据，不强加循环或新任务。生成工具的长素材下限不要求有效内容同样长，可生成后剪短。若固定镜长确实装不下用户指定的完整过程，即使压缩无用距离、允许偏快仍无法衔接，必须说清具体冲突并给出调整方案；不得偷偷延长、跳过接触或伪称已满足。纯粹“想保持松弛”“怕太快”不能替代具体冲突说明。

#### 交付必须附密度证据

每条视频提示词在五栏之外附一行：**目标有效镜长｜有效行为链或视觉进展｜并行反馈**。没有时长时按内容给出估计，用户明确不要估时则标“未定”并列内容链。时段预算按需要提供，不能机械均分，也不能把并行反馈重复累计。五栏正文必须落实所列内容，不能只在制作说明列出数量。复杂镜头写充分，简单镜头不靠文字加长达标。

交付前出现下列任一项须修改或明确报告约束冲突，不能自称通过：
- 一个短动作被慢放、过长收手或看结果撑满目标镜长。
- 用起手细分、眨眼摆尾、慢推镜头或不推进状态的循环凑数量。
- 密度说明列出了动作或反馈，但视频正文没写，或首帧无实现条件。
- 加动作后自动增加既定镜长，或反馈逐项等待导致原有预算失效。
- 第二轮操作复原上轮结果，或在同一区域无内容地重复。
- 湿式擦洗缺少默认两轮蘸洗、每轮连贯笔触或可见泡沫发展，却没有用户明确覆盖依据。

## 七、提示词交付

默认中文，单镜保留五栏：**光学／动作时间／物理／灯光／音频**。正文从光学开始，没有总时长或画幅抬头。用户已在工具中选好起始图时，不再单列 `@镜头07晾云成图` 等图片引用占位符；在光学栏写“以所选图片为起始画面”，随后交代机位。图片与镜号的对应关系如有需要放在提示词外的制作说明中。此规则针对视频提示词，不删除图片提示词中用户需要的角色参考引用。多镜项目每镜使用同一结构，镜号与生成安排放各段提示词之外。

| 板块 | 写作要求 |
|---|---|
| 光学 | 承接输入图的取景关系，写明确的固定机位或有动机的运动；需要时写视角、景深。不能从一张图精确读出真实焦段，也不在视频首帧无故切换到新机位 |
| 动作时间 | 一段连贯叙事，从实际当前状态往后走；沿实际因果与时间顺序说明角色、工具、对象的动作联系、可见反馈与本镜结束状态；主题是自然现象运动时，明确其自身位移及持续方式，不只写角色动作。不写“接触段／过程段／果成立”等内部标签 |
| 物理 | 只写本镜相关的材质运动、重量感、形变、惯性或流动。保留核心不可能设定，不用“真实重力”把悬浮水团写坠落 |
| 灯光 | 延续实际图的时段、色调与基础光线；故事自身导致的发光变化可影响环境，曝光与色彩不无故跳动 |
| 音频 | 具体环境和接触声，默认无人声、无音乐。静默、雨停等声变化可辅助，但不代替必要的视觉证据 |

**篇幅服从设计完整性。** 视频提示词不设统一字数下限。简单短动作可以简洁，复杂镜头不能只交事件概要；“短视频、紧凑”约束动作与剪辑，不授权省略关键接触、形态变化和视觉发展。批量交付逐镜设计，不以重复的“自然连贯、曝光稳定”等句子替代具体内容。完整修改应整合回五栏，保留仍适用的要求；纯分析请求不自动扩写整套提示词。

图片规范的正文篇幅不套用到视频，五栏仍是交付结构。尚无实际首帧时的设计分析不能冒充读图事实；实际出图与计划不符时，按第二节核对再续接。

静态身份、服装与布景主要由图承担，只补对续接重要的锚点，避免整段重写静态提示词。延续实际图的建筑比例、器物连接和颜色归属；不因静态均衡要求冻结物体运动，也不为美术统一擅自给实际图换色或改造建筑。焦段数字仅在有明确设计目的时使用，不能靠重新报焦段解决起始图构图不合适。

无对白、无字幕、无音乐为本技能默认。需要传达给生成工具的关键要求可以简洁写明，不以“默认”推断工具已经知道。固定机位与物体运动不冲突；整体构图锁死却同时要求大幅后撤才冲突。

## 八、续接成品示例：堵云止雨

**适用输入**：起始图已看清工人的双手、压入大半的木塞、漏口旁的细水及下方水洼。本镜任务是看清封口与停雨，选择固定。若实际图不同，先调整输入或动作，不能照抄。

```text
光学
以所选图片为起始画面，固定机位，维持当前取景，木塞、漏口和下方细水始终清楚可见。

动作时间
工人沿木塞现有方向继续稳稳压紧，云底开口围着木塞逐渐合拢。缝边两束细水越来越细，在木塞压实后断成几滴水落下；工人的双手停在塞子上确认稳固，随后稍稍放松。原落点的涟漪逐圈散开，水洼表面渐平，湿润石板仍保留水光，云底只剩压实的木塞。

物理
木塞保持木纹与硬质轮廓，受压处的云气局部收拢，周围云层仍轻微翻卷。残余水滴向下落，水面涟漪逐渐减弱；云保留宽大连贯的灰蓝体块与柔和云气边缘，不散成细碎毛絮。

灯光
延续输入图柔和的自然光、灰蓝云层暗部与复古胶片色调，曝光稳定，湿地保留柔和反射。

音频
水流声渐弱，转为最后几声滴水，随后留下轻风与木梯的轻微响动。无人声，无音乐。
```

该例只覆盖最后封口与停雨，并非所有事件都应从中途开始。雨停即可，不另加晴天结果。若起始图已无水滴，而目标仍是拍停雨过程，应补早帧；只有目标允许后续行为时才改写为检查封口与余波。

## 九、交付前核对

1. 已读实际图，或清楚标为待图核对的草案；首帧支持所选动作范围，缺失所需前段时已有补图安排。
2. 动作能从当前状态继续，必要前置、操作与收尾按目标保留，道具和路径成立；自然下一轮与复位重演已区分。
3. 变化承诺得到兑现，或持续错位保持可读；停止类结果有证据，不强加第二个结果。
4. 自然本体材质保留；覆盖、工具与本体分得清。
5. 固定、运镜或切镜都对应具体信息任务；删去该运动或镜头后若没有信息或节奏损失，则考虑简化。
6. 关键因果没有被切掉，跨镜需要的状态与方向连续；新视点已有输入安排。
7. 有效镜长与内容匹配，允许2–3秒；生成档位与剪辑保留时长分开，未知能力未臆测；不以慢放或空等填时长，总时长按剪辑计算。
8. 核心现象需要运动时，即使摄影机和角色不动，正文仍有可观察的对象运动；方向与场景参照明确，持续方式和接触后路径按需交代。不能仅凭“持续落下”字样判通过，也不能把不需运动的稳定对象强行写动。
9. 事件有强度要求时，速度、通过频率或作用反馈是否支持该量级；交互重点是否有接触前后差别；角色响应是否由刺激触发且在当前景别可读。不能只增加数量、拖尾或音效来替代。
10. 同一次交互的关键角色动作、工具运动与对象变化按实际因果及时绑定，未先写完效果再补关键角色动作；物理栏未替动作时间补写必要操作。独立并行运动不强求串联。
11. 五栏简洁且无相互冲突指令，正文从光学及所选图片起始说明开始，没有重复的 @成图 占位行；基础照明与事件发光变化区分清楚。

12. 去掉评价词后，观看重点、视觉变化或持续互动仍具体可读；节奏和细节服务事件，未将呼吸感等同于慢动作，也未用无关运动、固定字数或强制高潮代替设计。复杂形态变化有路径与中间证据，活体未被道具化。

13. 已按第六节预演单位时间的实际内容，操作型或持续型密度底线、擦洗默认流程和逐镜密度证据均已检查；固定镜长未随加动作自动增加；没有用短动作慢放、背景微动或套话撑满。允许紧凑偏快，但接触、反馈与首帧条件仍可读；用户明确的舒缓或单次动作要求得到保留。

上述核对用于制作，不在普通交付时全量打印。只有实际生成过并检查了结果，才能称为出图或视频实测通过。
