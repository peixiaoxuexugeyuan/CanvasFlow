## 执行与记录

1. 尽量给每条用例独立上下文；资源受限时可分组，但报告注明上下文未完全隔离。执行者读取当前技能及相关文件，不读本评分表。不要把任务变成对规则的复述。
2. E04 需要维护者另行提供实际图片及可查看图片的工具。记录输入图与是否实际打开；缺图或没有视觉能力时标为“未测”，不能凭描述判通过。其余案例不得假称存在实际起始图。
3. 每条记“通过 / 部分通过 / 失败 / 未测”，保留实际回答、判断依据和问题位置。核心失败项出现即失败；非核心表达瑕疵可判部分通过。不存在唯一合法措辞。
4. 修改涉及材质、状态或镜头路由时，优先复跑相应用例；影响共用规则时再跑全部。另加至少一条不同对象或动作的迁移用例，有助于检查是否只记住例子。
5. 这些是提示词行为验收。通过不能证明生图材质、实际运镜或视频连续性已经达标。真实成片验收需另行生成，核对首帧、关键动作帧和末帧；工具能力与参数也要单独记录。
6. 比较不同模型时，应固定技能版本、输入、图片、工具权限与生成设置，每条重复多次；隐藏模型身份后评价。单轮自测或少数例子不能作为能力排名。
