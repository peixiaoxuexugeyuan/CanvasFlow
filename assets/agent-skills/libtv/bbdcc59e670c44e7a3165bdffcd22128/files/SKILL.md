# 姿势参考·情侣双人

> **一键出 CP 感**：上传两位角色 + 选一个双人姿势，就能出同人设的情侣写真、婚纱照、古风 CP 图和 Seedance 互动视频。

## 三步上手

1. 把两位角色和姿势加进对话：在资产库搜角色名、姿势名（如「耳边低语」），点资产的 `…` →「添加到Agent」；角色也可直接上传图片。不确定用哪个姿势就直接描述动作，Agent 会推荐候选。
2. 描述场景与风格：如「海边婚纱照，黄昏逆光，竖版 3:4」；要视频就写「生成 5 秒视频，使用 Seedance」。
3. 想要更多互动：双人姿势 + 单人姿势混搭（如一人单膝跪立求婚、一人站立），写清谁做哪个姿势、怎么互动。

## 注意

- 仅用于情侣/夫妻的日常与浪漫场景，角色需为成年人并穿着得体。
- 姿势图只参考姿势骨架，不参考服装、发型、画风；图片著作权归原作者ギア，仅供个人创作参考，不得商用。

人体姿势参考库：225 张 900×1200 白模姿势图（3 个情侣双人姿势 + 全身标准系日常单人姿势），图片在 LibTV 资产库「姿势参考」文件夹：每个姿势一个资产，含正面/斜侧/侧面/俯视/仰视 5 个视角。

## 用法

1. 从下方「姿势目录」找到最贴近用户描述的双人姿势，或为两位角色各选一个单人姿势混搭；拿不准时给用户 2-3 个候选。
2. 读 `references/catalog.md`，按 `姿势名称` + `角度` 取 `资产位置` 列（LibTV 资产库「文件夹/姿势资产 · 视角」，如 `姿势参考/全身标准系/站姿/站立・回眸顾盼 · 正面`），视角优先匹配用户镜头，默认正面。白模图必须作为**参考图节点**传给生成任务——只把图片地址或姿势描述写进提示词，模型看不到图，姿势会跑偏。用户已把该姿势资产添加到对话或画布时，直接引用那个节点；还没有时，**先停下来请用户添加**：「在资产库搜『<姿势名称>』，点该资产的 `…` →『添加到Agent』（或拖到画布上）」，添加后再生成。仅当用户明确要求不加参考图直接生成时，才用文字描述姿势，并提醒姿势可能不准。
3. 把该图作为**姿势/构图参考图**传给生图或生视频模型，提示词注明「仅参考姿势，不参考服装、发型、画风」。
4. 双人互动时写清谁做哪个姿势、怎么互动。

## 示例提示词

- **海边婚纱照**：用「姿势参考·情侣双人」技能：让我们两位角色按「耳边低语・手触脸颊」双人姿势拍海边婚纱照，黄昏逆光，竖版 3:4。
- **古风 CP 公主抱**：用「姿势参考·情侣双人」技能：让男角色按「被横抱」双人姿势将女角色横抱于桃花林中，花瓣纷飞，古装剧剧照质感。
- **求婚互动视频**：用「姿势参考·情侣双人」技能：男生先按「跪立」姿势单膝求婚，女生答应后他起身按「被横抱」姿势抱起她转圈，生成 8 秒 Seedance 视频。
- **银发夫妻纪实**：用「姿势参考·情侣双人」技能：让老夫妻按「耳边低语」双人姿势站在胡同口说悄悄话，暖阳纪实摄影，竖版 3:4。
