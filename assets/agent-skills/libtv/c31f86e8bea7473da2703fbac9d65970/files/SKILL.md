# 分镜资产与视频节点搭建

> 进入条件：头脑风暴已通过，**剧本/分镜清单已确认**。本 Skill 只做「把分镜变成画布节点」这一段，不做故事创作、不生成图片、不启动视频生成。
>
> 一句话概括：**先资产、后首帧、最后拉视频**。顺序错了要整条重建。

---

## 0. 两个参数（开跑前必须拿到）

本 Skill 与题材解耦，风格由用户按项目给，缺了就问，不要自己编。

参数用途说明`{{完整风格块}}`B 类首帧 + 视频 prompt 的「视频风格」段含调色、光线、颗粒、材质**以及镜头词**（广角、畸变、暗角、鱼眼等）`{{资产短质感尾串}}`A 类资产图**只保留**调色、光线、颗粒、材质、纪实质感，**绝不含任何镜头畸变/广角/鱼眼/暗角类词**

**为什么必须拆两套**：把完整风格块贴到三视图或单品定形图上，广角与鱼眼会把角色造型扭歪、把道具外形扭变形。这是实测踩过的坑。

示例（仅示范格式，实际按项目替换）：

- `{{完整风格块}}` = `冷青灰去饱和调色，老旧荧光灯冷绿顶光，暗部保留自然噪点，VHS颗粒，色差，轻微失焦，局部高光过曝，烟雾与尘埃，极端广角透视，局部鱼眼桶形畸变，圆形机械暗角，真实皮肤纹理，非CG渲染，手持DV质感`
- `{{资产短质感尾串}}` = `冷青灰去饱和调色，冷绿顶光，暗部自然噪点，真实皮肤纹理与毛发细节，粗粝写实，非CG渲染，平光均匀照明`

另需确认：`{{画幅}}`（默认 `16:9`）、`{{是否有人声}}`（有人声需逐字写台词并标说话人；无人声则在「视频风格」段末尾明写"不要人声"）。

**候选阶段模型固定为 Seedance 2.5 Draft（**`star-video2.5-draft`**，**`draft: true`**，480p，一次一条）**，不是标准 Seedance 2.5 手动调低分辨率。详见 6.6。

## 1. 铁律一：资产只有两类

类型定义管什么数量**A 类·复用资产**跨镜反复出现、**全片唯一**的主体是谁 / 什么东西（身份与外形）角色数 + 核心道具数**B 类·首帧定调画面**一镜一张起，可一镜多张构图、机位、光影调性、场景分镜数至若干张

配套的三条硬约束：

1. **场景绝不单独建锚点**。场景描述直接写进对应 B 类首帧的正文。一个「镜头N-分镜资产」组里通常只有角色锚点 + 首帧（同一镜有多个景别/切镜时，首帧可以是多张）。按「角色/场景/道具/静帧」四类建会多抽约 40% 没人用的场景图。
2. **次要道具不建 A 类**。只在一镜出现、或能被场景承载的，写进该镜首帧正文与视频 prompt 即可。
3. **A 类中的角色，全片只有一张生效锚点**。所有镜头引它，绝不每镜重抽。

判定口诀：**「这东西换个镜头还要再出现一次吗？」** 是 → A 类；否 → 写进正文。

**B 类的双重身份要记牢**：它在画布上是「首帧定调画面」，到了下游视频 prompt 里就变成\*\*「场景氛围光影质感色调参考」\*\*——这是它在视频里的唯一职责，也是它在参考声明里必须走复合长句的原因（见 6.3）。

---

## 2. 铁律二：节点顺序不可换

```
第一步  A 类资产节点（建 + 写提示词） → 停，等回填
        ↓ 用户回填、逐张确认定稿
第二步  B 类首帧节点（建 + 写提示词） → 停，等回填
        ↓ 用户回填、逐镜确认构图/光影
第三步  视频节点（参考声明 + 画面剧情内容 + 视频风格） → 建而不跑，等确认
```

**为什么不能先建视频**：视频节点的引用字段（reference_nodes / start_frame_image_node）**一经创建就无法通过 update 修改**。只要它引了空的、或后来被替换掉的资产节点，就只能整条重建，原节点作废。所以资产没定稿就拉视频 = 等着返工。

每步结束都要显式告诉用户：现在卡在哪、等他做什么。不要在等他回图的间隙偷偷往下建。

## 3. 图片提示词写法（MJ 原生描述体，与视频写法相反）

### 3.1 原生描述体，禁止参考声明

- 图片提示词**只描述画面内容**：谁、长什么样、穿什么、什么动作、在哪、什么光。
- **不许出现**「图1为猴子男面部参考，只参考五官、不参考构图」这类声明话术，也不许出现「图1」「Image 1」这类指代。
- 人物长相、服装、标志单品要**直接写进正文**（发色、发型、体型、外套、配饰、纹样），不要指望参考图替你说明。

> 注意：**图片禁止参考声明，视频保留参考声明**。两者方向相反，不要因为视频用了「图N为…锚定」就回头把图片也改成声明体。

### 3.2 参考图靠 MJ 参数挂，参数写在正文末尾

需求写法人物一致性`--cref {{角色锚点图URL}} --cw 100`（100 = 连服装一起锁；想换姿态不被参考站姿拽住，降到 60 左右）锁单品/道具外形`--oref {{资产图URL}} --ow 200`（omni reference；账号不支持就删掉，仅靠 `--cref` + 正文描述）多底图混合（如白底三视图 → 暗调派生）图片 URL **依次贴在正文最前面**，MJ 按权重混合；正文里**不解释**哪张是什么排除项`--no` 列出，同时写明要保留什么，例如 `--no CG render, plastic skin, warm tones, glossy commercial lighting, extra fingers`通用尾巴`--ar {{画幅}} --style raw --v 7`

### 3.3 自检

写完任何一条图片提示词，先自问：**正文里有没有出现图号、有没有"参考"这种元话术？** 有就删干净。

## 4. 第一步：A 类资产节点

### 4.1 分组与命名

- 分组 `人物锚点`：节点名 `{角色名}-形象`
- 分组 `场景与道具`（项目有独立核心道具才建）：节点名 `{道具名}-道具`
- 状态变体：`{角色名}-形象-{状态}`（如负伤、换装），**必须登记它是变体，不是新角色**

### 4.2 人物：两步生产

**第 1 步 · 定形（白底三视图，抽卡父图）**

正文结构：`三视图排列 + 造型描述 + 背景/光线/姿态 + 摄影质感 + {{资产短质感尾串}}`

模板（把 `{...}` 换成该角色设定）：

```
同一人物的三视图并排：正面全身、背面全身、面部特写。{体型与年龄段}，{发色发型}，{可辨识的物种或造型特征，写具体：毛色/耳形/疤痕/面具}，穿{外套/内搭/裤/鞋，写材质与颜色}，佩戴{配饰/挂件}。纯白背景，平光均匀照明，中性表情，自然站姿，全身完整入画不裁切，写实摄影，真实皮肤与毛发纹理，超清细节。{{资产短质感尾串}}
--ar 3:4 --style raw --v 7 --no CG render, illustration, cartoon, plastic skin, distorted anatomy, text, watermark
```

要点：

- **面部特写必须有**——它是后面所有镜头锁脸的来源，只有全身图会锁不住。
- 纯白/纯色背景 + 平光 + 中性表情：这一步只解决"长什么样"，不解决"什么调性"，别在这里加戏。
- 一次只抽一个角色。

**第 2 步 · 风格定调（全片唯一角色锚点）**

正文结构：`URL 前置（定形图）+ 保持同一人物 + 背景转深黑 + 统一调色 + {{资产短质感尾串}}`

模板：

```
{{定形图URL}} 保持同一人物，三视图结构不变（正面全身、背面全身、面部特写）。将背景处理为纯深黑色，人物轮廓干净分离，{服装与毛发在暗调下的可读性描述}。{{资产短质感尾串}}
--cref {{定形图URL}} --cw 100 --ar 3:4 --style raw --v 7 --no 镜头畸变, 广角, 鱼眼, 暗角, 灰雾背景, oversaturated
```

- **这张才是生效锚点**，所有镜头只引它。第 1 步的白底图只作抽卡父图，不进视频引用。
- N 个角色的定调图要**并排核一遍**：色调、颗粒、反差是否同一套。不一致就单独重跑某一个，别混着用。

### 4.3 核心道具

正文直接描述外形与关键特征（颜色、材质、磨损、捆扎方式），参数用 `--oref` 锁外形。

模板：

```
{道具名}单品定形图，{整体形状与尺寸感}，{主色与材质，写具体}，{关键特征：捆扎方式/贴纸/划痕/污渍位置}，{背景}，{光线}，微距质感，真实材质反光与磨损。{{资产短质感尾串}}
--oref {{参考图URL}} --ow 200 --ar 3:4 --style raw --v 7 --no 镜头畸变, 广角, 鱼眼, 多重主体, text
```

- 跨镜反复出现的**麦高芬**（剧情关键物）必须在正文里把**颜色与关键特征写死**，比如"牛皮纸棕色、麻绳十字捆扎、绳结沾泥、颜色不得偏白"。低分辨率下它会偏色，观众会以为换了东西。
- 只在一镜出现 → 不建节点，写进该镜首帧正文。

### 4.4 复用已有资产

画布上已有生效的角色图/道具图 → **优先复用，不重复抽**。外观有变化就登记为状态变体（`-{状态}`），并说明哪些镜头用变体。

### 4.5 自检（第一步收尾）

- \[ \] 每个角色/道具都建了节点、都写了提示词，节点内提示词可直接复制？
- \[ \] 三视图是否含面部特写？定调图是否已产出并标明为唯一锚点？
- \[ \] 有没有多余的场景锚点节点？（有就删）
- \[ \] A 类提示词里有没有误贴镜头词（广角/鱼眼/暗角/畸变）？
- \[ \] 是否已停手，等用户回填？

## 5. 第二步：B 类首帧节点

### 5.1 建法

分组 `镜头{N}-分镜资产`，节点名 `镜头{N}-首帧 {该镜内容简述}`。

- **一镜一张起**；若该镜内有多个景别或切镜，就建**多张**，命名加后缀：`镜头{N}-首帧 {内容}-A/B/C`。
- **优先带人物入画**（见第 8 节）。

### 5.2 职责记法（命名与台账按这个写）

B 类首帧在画布上是「首帧定调画面」，但在下游视频 prompt 里的职责是：

> **场景氛围光影质感色调参考**

它不是"静帧"，也不是"构图确认图"——正是「场景氛围光影质感色调参考」这个职责，决定了它在参考声明里必须走 6.3 的那条复合长句（含场景描述、排他句、融合要求）。命名与台账备注里就按这个职责记，避免后来者误以为它只是一张"确定用的静帧"。

### 5.3 正文结构（顺序固定）

```
[镜头与构图] + [主体与动作] + [场景与环境细节] + [光影] + [材质/质感] + {{完整风格块}}
--cref {{该镜角色的锚点URL}} --cw 100 --ar {{画幅}} --style raw --v 7 --no ...
```

模板：

```
{景别}，{机位高度与角度}，{角色外观关键特征（发色/外套/标志单品）} {动作与朝向}，{环境：地面材质与反光、烟雾、霓虹、杂物、背景层次}，{光线来源与方向、明暗对比}，{广角/贴身的画面暗示}。{{完整风格块}}
--cref {{角色锚点URL}} --cw 100 --ar 16:9 --style raw --v 7 --no 精致商业广告感, CG质感, 塑料皮肤, 多余人物, 文字, 水印
```

多角色镜头：把每个角色锚点 URL 都用 `--cref` 挂上（MJ 支持多 cref 时），或在正文里写清"画面左侧为 A，右侧为 B"并分别挂参数。

### 5.4 场景写进正文，不建锚点

把场景当**这一镜的画面内容**写：墙的材质、地面的水与反光、灯光位置、可辨识的空间特征。同一场景跨镜复用时，只需保证正文描述一致，靠风格块统一调性，无需建场景锚点。

### 5.5 自检（第二步收尾）

- \[ \] 每镜一张起首帧节点，命名带镜号？
- \[ \] 该镜有多个景别/切镜时，是否建了多张并加 -A/-B/-C 后缀？
- \[ \] 正文没有图号/参考声明？
- \[ \] 该镜需要的角色锚点都挂了 `--cref`？
- \[ \] 场景是写在正文里而不是单独建了节点？
- \[ \] 首帧节点在台账备注里是否记成「场景氛围光影质感色调参考」？
- \[ \] 是否已停手，等用户逐镜确认构图/透视/光影？

## 6. 第三步：视频节点

### 6.1 与图片相反：视频保留参考声明

原因：Seedance 需要先明确每张参考图"是什么"，否则会串味（把氛围图的特征吸进人物）。

**图片走 MJ 原生描述体，视频走下面这套三段结构，两者不要混。**

### 6.2 三段结构（带显式中文小标题）

自上而下三条信息块，用小标题分隔，不要省略标题——模型更好解析。

```
{{图1节点}} 图1为场景氛围光影质感色调参考，{一句话描述该场景：地点＋关键环境物＋关键光源}，画面里不要出现除图2图3以外的任何人或动物。保持角色完美自然的融入图1的环境光影色调明暗和质感，真实感，逼真的。
{{图2节点}} 图2为{角色}形象锚定。
{{图3节点}} 图3为{角色}形象锚定。

画面剧情内容：
{镜头语言起手式}{叙事本体 + 表演与气场 + 镜头推进}{镜头语言收束式}

视频风格：
风格：{2–3 个本镜定语}，{{完整风格块主体}} 不要配背景音乐，仅保留环境音效和物理音效，不要人声，
```

范本实测参数：`star-video2.5-draft`、`draft: true`、`resolution 480p`、`ratio 16:9`、`duration 6`、`count 1`、`enableSound on`、`modeType mixed2video`。

### 6.3 第一段：参考声明（三种句式，首帧走复合长句）

不写"只参考X、不参考Y"的逐项划界表。按图类型选对应句式，一图一行。**句式表只有这三种，没有别的备选**：

图类型句式**B 类首帧**（场景氛围）`{{图N节点}} 图N为场景氛围光影质感色调参考，{一句话描述该场景：地点＋关键环境物＋关键光源}，画面里不要出现除图{其他参考图号}以外的任何人或动物。保持角色完美自然的融入图N的环境光影色调明暗和质感，真实感，逼真的。`角色锚点`{{图N节点}} 图N为{角色名}形象锚定。`道具`{{图N节点}} 图N为{道具名}道具锚定。`

四条操作细则：

1. **一镜的主参考（start_frame 那张首帧）永远走复合长句**，不走任何极简句式。首帧的职责就是提供**场景氛围、光源、色调、质感**，简写成一句"确认用"等于把这条最重要的信息丢了。"画面里不要出现除图X以外的任何人或动物"中的 X 按本镜实际角色图号写；单人镜写"除图2以外的任何人或动物"即可，重点是**排除参考图里可能混入的多余人物**。
2. **「保持角色完美自然的融入图N的环境光影色调明暗和质感，真实感，逼真的」一字不能省**。这句是让人物"焊"进场景光里的关键，删掉人物就会像贴片。
3. **图号与实际引用顺序不必严格一致**。范本里出现「图4」排在图3前面，因为引用列表顺序就是那样。**以节点引用列表顺序为准**，不要为了编号好看去调整引用顺序或改写图号。
4. **一镜多张首帧（多景别/切镜）：每张都各自带完整的场景氛围复合长句描述，不共用一句**。各占一行，按引用列表顺序排列，每行的"除图X以外"都要按该行之外的其余参考图号重写。

### 6.4 第二段：画面剧情内容（镜头语言首尾 + 一段连续叙事）

标题用 `画面剧情内容：`（带冒号）。

**段首固定起手式**——先交代镜头怎么被端着：

```
镜头从{低角度仰视 / 平视 / 高角度俯视}视角，{斜角度 / 正侧}，真实的手持镜头，伴随轻微的颠簸和震颤感，真实的现场录制感。
```

**中间是叙事本体**，一段连续中文、不分阶段编号、**不写秒数**。按下面顺序铺：

1. **空间与纵深**：这是什么地方、往哪个方向延伸、多深
2. **主体位置与朝向**：谁在哪、占多大、朝哪
3. **手持物与动作**：手里拿着什么、正在做什么、身体姿态
4. **表演与气场**（不可省，见下）
5. **材质与细节**：墙面、地面、渗水与倒影、杂物
6. **镜头推进**：6s 内可写 2–3 个推进动作，用"镜头缓缓后移""随后电梯门关上"这类自然语言串联，仍不编号不写秒数
7. **空气介质与动态**：尘埃、水汽、烟、风把什么吹起、闪烁的灯

**段尾固定收束式**——补光比与后期质感：

```
{顶光 / 侧逆光}镜头，人物{轻微背光 / 半张脸在阴影里}，冷青灰调色、强烈荧光灯与局部直闪、轻微VHS失真，镜头带着运动模糊和一些运动失焦感，伴随一点抽帧效果。
```

**表演与气场必须写进剧情段**，这是画布风格成立的关键，一句都不能省。例：

> `四人神情克制没有多余动作，极度的压迫感和大佬气场，克制冷酷`

写法要点：用「克制」「没有多余动作」「压迫感」「气场」这类**状态词**，而不是「他很生气」这类情绪解释。群体镜头还要写**每个人的分工姿态**（谁抱胸、谁插兜、谁在抽雪茄、谁站中间拎包），否则模型会把四人揉成一个平均脸。

台词/旁白（有人声项目）：逐字用 `{}` 写进叙事段并标说话人。无人声项目不写台词，第三段明写"不要人声"。

### 6.5 第三段：视频风格（风格：+ 前置定语 + 风格块 + 连写声音）

标题用 `视频风格：`（带冒号）。

```
视频风格：
风格：{2–3 个本镜定语}，{{完整风格块主体}} 不要配背景音乐，仅保留环境音效和物理音效，不要人声，
```

- **以「风格：」开头**，先给 2–3 个**本镜专属定语**，再接标准风格块主体。
- 前置定语按该镜实际光比增补，例如：`昏暗无光，偏暗的场景，强烈人物阴影明暗分割`。它是对本镜光线的补充说明，**不是改风格块**。
- `{{完整风格块主体}}` **一字不改**，不改词序、不删关键词、不"优化"。
- **声音指令连写、逗号收尾、不列环境音清单**：`不要配背景音乐，仅保留环境音效和物理音效，不要人声，` 直接贴在风格块末尾。**不要**拆成两句、不要另起「本镜声音：」清单。
- 有人声项目：把「不要人声」换成台词说话人说明，前半句保持原样。

### 6.6 模型与参数（Seedance 2.5 Draft）

项值模型`star-video2.5-draft`（Seedance 2.5 Draft，样片模式）`drafttrue`分辨率`480p`画幅`{{画幅}}`（横版 16:9）时长`6`（单镜候选 4–8s 为宜）生成数量`1`（一次一条）声音`enableSound: on`模式`modeType: mixed2video`

**「480p 候选」在画布上的真实实现就是 Seedance 2.5 Draft 样片模式**，不是标准 Seedance 2.5 手动调低分辨率。这样单价低、出片快，适合先判断调性与动作。

**升正片**：入选后用 `create_final_video_node` 把样片升为 1080P 正片，正片**完整沿用样片的提示词、参考图、时长与画幅**，不重写 prompt、不重挑参考。

**不做 topaz 升清，不建「高清」节点**。链路是：样片候选 → 入选 → `create_final_video_node` → `正片 1080P: {候选原名}`。

### 6.7 先建 1 条骨架，不要一次建满

资产与首帧都回填、确认后，每镜**先建 1 条候选骨架**。图还没回填时把 4–6 条占满画布没有意义。

用户明确要开抽时，再**按同一 prompt 复制补足 4–6 条**：第二段画面剧情可微调动作/机位，**第三段视频风格一字不动**。

### 6.8 尾帧承接

- 需要承接前镜的分镜，创建时**挂不上尾帧**（前镜还没生成）。做法：在第二段开头明文写「本镜承接镜头N的结尾画面（描述尾帧内容：{人物位置、朝向、动作、光线}）开场，起始帧以镜头N尾帧为准，该尾帧节点生成后补挂引用」。
- **不假装已经连上，不伪造 node_key**。
- 前镜生效后，用 `extract_video_frames` 抽尾帧成图，登记为续镜锚点，再让后镜可运行。
- 承接链**严格串行**：一镜一镜等，同一条承接链至多一个在途调用。无承接依赖的分镜才并行。
- 场景或时间跳转的交界**独立开场，不承接**。

三条对账规则（本次最大返工来源）：

1. **用户常在外站抽卡后新拉节点回填**，而不是填进 Agent 建的原节点。发现 Agent 建的首帧节点一直是空的、而用户在别处放了生效图 → 立刻把台账和视频节点对齐到**真实生效的 node_key**，把空节点标为**废弃**，绝不继续引用空节点。
2. **提示词载体节点不要废弃**。写了 MJ 提示词但还没图的空节点，是用户抽卡的提示词来源；图回填到它或它的副本都行，回填后状态改「已生效」。

## 8. 480p 阶段的已知局限（写给下一次的自己）

这些是分辨率带来的物理限制，提示词修不了，只能靠排布规避：

1. **脸部特写容易滑回普通人脸**，物种特征（毛发、异形五官）在几十个像素里撑不住。
2. **首帧尽量带人物入画**，不要只抽空场景/空镜。实测用无人首帧跑出的视频，人物脸部稳定性明显更差。
3. **极考验脸的分镜（如正脸特写）先单独拉一条 480p 试**，验证锚点稳不稳，再决定后面几镜怎么排。
4. **核心道具颜色必须锁死**（首帧正文 + 视频第二段叙事里都写），低分辨率会偏色，观众会以为换了东西。
5. **单镜别塞太多内容**。实测一镜里塞四件事（两个特写插镜 + 主动作 + 收尾）时，特写插镜被模型放大成主镜，挤掉了主动作。一镜只装 **2–3 个镜头推进动作**，给主动作留余量。

## 10. 边界

1. **Agent 不调用任何生图能力**。输出形式固定为「写进节点的提示词」。需要图的时候 = 建节点 + 写提示词 + 停手。
2. **节点全部建而不跑**。等用户回填图、逐张确认后，再按批准卡逐批运行。
3. **白天开阔场景与暗调低照风格块冲突时**：先一句话说明冲突（"这镜是白天开阔外景，`{{完整风格块主体}}` 的低照冷调会把日光压成阴天感，需要微调"）→ 再给**只改两三处**的微调版 → 明写"仅本镜生效"。用户不同意就不改，**绝不擅自改全片调性**。
4. **画幅锁死**，要改视为新需求单独确认，不动全片。
5. 剧本内容不擅自改。分镜缺信息（时长、景别、场景）就按最合理的补，并在台账里标注"待确认"，不要沉默假设。

一套完整交付应包含：

1. **A 类资产节点清单**：节点名 + 所在分组 + 完整 MJ 提示词（可直接复制）+ 状态"待回填"
2. **B 类首帧节点清单**：镜号 + 节点名 + 职责（场景氛围光影质感色调参考）+ 完整 MJ 提示词 + 引用的角色锚点 + 张数 + 状态"待回填"
3. **视频节点清单**：镜号 + 完整三段 prompt（首帧场景氛围复合句 / 角色形象锚定 / 画面剧情内容 / 视频风格）+ `star-video2.5-draft` / 480p / 画幅 / 时长 / count 1 / sound on + 承接关系 + 状态"未运行"

5. **自检结果**：每步自检逐项打勾，有问题的明确列出
6. **明确的停手点**："现在卡在第 N 步，等你 {具体动作}，我不会自动运行任何节点"

## 12. 起手清单（拿到剧本后照做）

1. 读剧本，列分镜清单：镜号 / 景别 / 动作 / 场景 / 秒数（秒数只用于估时与拆镜，不进提示词）。
2. 抽 A 类清单：哪些角色跨镜出现？哪些道具是麦高芬？其余一律不建节点。
3. 向用户确认 `{{完整风格块主体}}` 与 `{{资产短质感尾串}}`（没有就按项目给草稿并请其确认）。
4. 建 A 类节点 + 写提示词 → 停。
5. 等回填、逐张确认 → 建 B 类首帧节点 + 写提示词 → 停。
6. 等回填、逐镜确认 → 建视频节点（每镜 1 条骨架，Seedance 2.5 Draft / 480p，三段结构带小标题，首帧走场景氛围复合长句）→ 停。
7. 更新台账、跑自检、报停手点。
