# 图片提示词规范

> 本文件对应「故事板 Skill」的图片侧规范，供阶段一生成三视图（`SKILL.md` 阶段一步骤3）、阶段二生成故事板（`SKILL.md` 阶段二步骤3、步骤4）使用。所有图片生成统一使用 **Lib Image 2.5 Pro / 低画质 1K / 16:9**。**本文件含全部模板正文、填写规则、校验口径与负面词**，直接复制使用。
>
> 🔴 **比例分两层（防止格子被生成成 3:4 竖版）**：**画布比例＝16:9**（整张故事板图的宽高比，`size/比例` 字段传 16:9，三套模板第一句都写了"生成一张16:9的…"——双重锁定）；**分镜格比例＝4:3**（图内每个分镜格的宽高比，模板正文与负面框「分镜格非4:3比例」已锁死）。负面框同时禁止"整图为竖版"与"分镜格非4:3比例"两项，双保险。
>
> 🔴 **第三道保险：末排不剩孤格（治 3:4 竖版的根，实测验证）**：3:4 竖版的真正根因是**末排剩孤格**——模型按行填格，最后一行填不满时，常把落单那格竖着拉成 3:4。因此后缀模板约束模型「保证每行格数一致、末排填满、不剩孤格」：优先选能整除镜头总数的列数；无法整除则调整行列或补空白占位格。🔴 **注意一：格数严格跟剧情走，不预设九宫格**——剧情几个节拍就几格，9 格只在剧情天然有 9 个节拍时才出现，不是目标、不得硬凑。🔴 **注意二：不是"偶数才不竖"**——3×3=9 是奇数，但每行 3 格、三行齐整，照样 4:3 不竖。判据就一句：**末排会不会剩一个填不满的孤格**。此约束已写进三套后缀模板的「网格排列」句，逐字复用即可。
>
> **执行主体（流程与禁令）在主文件**：阶段一四步、阶段二全步骤与流程规则以 `SKILL.md` 为准；全局禁止规则（28 条）以 `SKILL-rules.md` 为准。本文件只承载图片侧的模板与口径。
>
> 🔴 **模板逐字复用（防漏字）**：模板正文与后缀模板**必须从本文件原文原样复制**，禁止凭印象复述、禁止转写、禁止缩写专有名词（例：画面风格里的「柘黄」不得写成「黄」、「halation」不得写成「哈雷」）；画面风格整段照抄阶段一产出，其中**每个专名（主色名、光学术语）都算不可拆的整体**，不得因排版或字数感觉而截断。拼接完成后必须**回读比对**：把 prompt 中的模板段与本文件原文逐句核对，确认无漏字、无改写、占位符只剩已替换的三处。

> 🔴 **img2 实测边界（2026-11-08 老大实测，写进流程防再踩坑）**：
> - **能稳做**：多格宫格（6 格/16:9/编号齐全）、顶部通栏中文+序号不乱码、六种景别递进、纯 POV（只有手没脸）、单光源明暗、人/物类别识别。
> - **垫图锁脸只锁"类特征"、不锁"同一个人"**：参考图能保造型/服装/气质一致，但具体五官分布、眼神会漂。**锁脸靠三视图 + 视频侧纯脸部特写兜底，别指望垫一张脸就逐像素同脸。**
> - **🔴 产品/道具垫图务必文字点名材质颜色**：img2 会把黑色哑光漂成银色金属（只保形状轮廓、不保材质颜色）。**提示词里写"保持原图材质颜色、禁止改成银色/改材质"就能锁住**——这条直接决定广告里甲方产品会不会翻车。
> - **宫格测不出锁脸**：镜头递进天然把人越拍越远/越拍越局部，六格里只有两三格露脸，**别用宫格去验证锁脸**；宫格能做到的上限是"服装造型统一"。

## 三视图提示词模板

**使用说明（写给 agent，不发送给生图模型）**：模板正文与负面词**一经写定不得改动**，agent 只替换方括号占位符，**不得让生图模型自行决定排版或风格**；七个槽位须按 `SKILL.md` 阶段一步骤3「角色形象描述」的 9 项顺序对应填充——

- `[角色身份与气质]` = 第1项年龄感与族裔 ＋ 第8项整体气质 ＋ 第9项职业/身份/背景
- `[体态]` = 画面可见的身量、胖瘦与姿态
- `[发型与发色]` = 第2项头发 ＋ 第3项胡须（无须则写「无须」）
- `[服装]` = 第6项外套 ＋ 第7项内搭
- `[神态与眼神]` = 第4项脸型与面部年龄感 ＋ 第5项表情
- `[自然色调1]`/`[自然色调2]` = 从阶段一提炼的画面风格中取该角色的两个自然主色（**不得把角色统一压成灰黑基调**），**且两色不得同为灰系，至少一个须为暖点（如木质暖、褐暖、米暖）**

> 🔴 **三视图模板没有「画面风格」字段，只有「自然色调」两槽**：三视图定妆图**不写整段画面风格长句**（它只锁人物本体，棚拍白底、色温 5500K 已在模板正文写死），只需从阶段一画面风格里**摘出该角色的两个自然主色**填入 `[自然色调1]/[自然色调2]` 即可。画面风格的「完整长句」只进故事板后缀模板的着色指令（见下节），**三视图不填整段风格、不填短锚词**——两处职责不同，别把故事板那套「短锚词/完整原文」搬到三视图。

**涉及未成年角色时，槽位填充须遵守** `SKILL.md` **阶段一步骤3 的儿童安全约束**（不写具体岁数、不写身体围度与贴身暴露描述，年龄用学龄气质词）。若版式散架或视图不全，退回备用写法：三视图全身图与面部特写拆成两张图分别生成。

- **模板正文**（可直接发送给生图模型，全文照搬、一字不改）：

```
纯白无缝背景角色三视图定妆图，16:9 横向排版，严格分为必须同时存在的两个区域，左区三视图占 2/3、右区面部特写占 1/3。左区（占 2/3）：同一角色正面/侧面/背面三个全身视图并排站立，高度一致、脚部对齐。右区（占 1/3，必须存在、不可省略）：同一角色的大幅面部特写占据该区大部分画面，清晰呈现脸部与上胸，用于锁定脸型、眼神、年龄与皮肤——面部特写与三视图同等重要、必须渲染出来。是枝裕和电影质感，应用于[角色身份与气质]，明亮柔和均匀的棚拍正面光（约 5500K 日光色温）充分照亮面部、五官细节清晰真实，皮肤自然健康有真实血色与生活质感（不暗沉、不蜡黄、不发灰、不磨皮塑料、不刻意美白），[体态]，[发型与发色]，[服装]，[神态与眼神]，不持有任何道具书包饰品（仅人物本身），自然放松中性站姿，色彩自然真实有胶片温润密度以[自然色调1]和[自然色调2]为基调（真实鲜活不寡淡不做旧、暖色可自然保留，不做冷调纠偏），细腻35mm胶片干净质感（颗粒极细几乎不可见、干净通透不脏不做旧不像老照片），明亮均匀的棚拍干净风格，真实摄影、原片直出、无修图、保留毛孔、自然光，高细节真实面部，清晰五官，纯白无缝背景、无阴影、无文字，所有视图必须为同一角色，五官、发型、服装、体型、风格、比例与细节完全一致，不改变人物特征，三个视图与右区面部特写保持同一角色一致性
```

## 故事板提示词 = 五段式（角色板 + 道具参考 + 场景参考 + 剧情 + 后缀模板）

> 🔴 **故事板图片提示词固定五段，顺序固定、缺一不可；其中第二、三段是「有才写」的可选段**：
> 1. **第一段：角色板**（每个角色一行，锁长相）——**必写**
> 2. **第二段：道具参考**（每个道具板一行，锁道具）——**可选：有道具参考图就写，没有就整段跳过、不写**
> 3. **第三段：场景参考**（每个场景板一行，锁场景）——**可选：有场景参考图就写，没有就整段跳过、不写**
> 4. **第四段：剧情**（原文整段贴，不拆不改）——**必写**
>
> 🔴 **剧情段就是剧情，一个字的技术约束/参数都不许有**：剧情段只能放**纯粹的叙事文字**（谁、在哪、发生了什么、说了什么）。下列东西**一律不得写进剧情段**，各有各的归宿——① 光位/色温/方向等技术参数（如「约 2400K」「约 7000K」「从画左上方斜照」「为画面唯一暖点」）→ 归【画面风格】着色段，那里已完整写了「煤气灯暖点约2400K、夜雾冷底约7000K、主光硬侧光顶光」，**剧情里再写就是重复，必须删**；② 跨格锁定句（同一角色/服装/环境/光线、每格一个动作）→ 已内建于后缀模板，**剧情里不写**；③ 逐格景别/运镜 → 由后缀模板交给模型自判，**剧情里不写**；④ 专属负面词（🚫 不出现某角色/某物）→ 归【本条专属负面词追加】，**剧情里不写**。**「本条主光」不是独立段落**——环境氛围（如「伦敦街头、夜雾罩街、石板反光」）精简成纯叙事放进剧情开头，光位技术参数删掉或归画面风格。
> 5. **第五段：故事板后缀（通用模板）**（固定模板，含顶部通栏、网格、每格 4:3、序号、技术信息行、画面风格着色、独立负面框）——**必写**
>
> 🔴 **「有就写、没有就不写」是铁律**：道具参考图、场景参考图**都是按需挂载**——本片有道具参考图才写【道具参考】段、有场景参考图才写【场景参考】段，**没有就整段跳过、连标题行都不写**。不是每条故事板都必须凑齐五段；最简形态（只有角色板）仍是「角色板 + 剧情 + 后缀」三段。
>
> 🔴 **道具参考 = 每件道具一张板（实测验证）**：【道具参考】段里**每件道具单独一行、各挂一张板**（如乌头碱小包一张、撬锁细钢丝一张），**不得一张图塞多件道具**——多件混一张板时模型分不清谁是谁。每行的声明句照模板原文，把 `{{道具名}}` 替换成具体道具名。
> 🔴 **道具/场景垫图必须文字点名材质颜色（防漂材质，实测验证）**：img2 的垫图**只锁形状轮廓、会漂材质颜色**（黑色哑光会漂成银色金属）。因此凡挂道具板/场景板，声明句**必须同时用文字写死「材质 + 颜色 + 表面质感」**（如"黑色哑光钢、磨砂表面"），不得只挂图不点名。这是广告里甲方产品保真的命门——只垫图不点名，产品会"长得像但不是我的产品"。
>
> 🔴 **镜头总数、景别、运镜一律由生图模型自判（实测验证，替代旧的「分镜设计表逐格填死」）**：后缀模板里不再由 agent 预先定死格数与每格景别/运镜，而是**把判断权交给生图模型**——模型根据剧情自判镜头总数（≤9）、自填每格景别（远景/全景/中景/中近景/近景/特写/大特写）与运镜（固定机位/推/拉/摇/移/跟/手持拍摄/升降），并强制「不得保留 XX/占位符」「相邻格景别须有肉眼可辨落差」。实测结论：模型能稳定做到「每格景别运镜各不相同、无 XX 残留」。因此**分镜设计表不再服务于故事板图片生成**（图片侧已模型自判）；分镜设计表若仍保留，只服务于**视频侧**的景别/运镜取值（见 `video-prompt.md`）。
>
> 🔴 **格数严格跟剧情走，不预设九宫格（实测纠偏）**：镜头总数**严格等于剧情节拍数**，剧情有几个节拍就几格，**不得为凑格数增删、不得硬凑九宫格、不得默认 9 格**。早前写「优先 3×3 九宫格、9 格最优」是错的——它让模型一上来就默认奔 9 格去，把只有 3、4 个节拍的剧情也硬凑成 9 格。**9 格只在剧情天然有 9 个节拍时才出现，不是目标**。后缀模板只保留一条硬约束：**末排不剩孤格、不把格子拉成竖版**。
>
> **选用规则**：先看「视频风格」——**Vox 科普**时**一律用第三套「Vox 平面分镜版」**（景别/运镜失效，换成信息/转场），不看视角；非 Vox 时再按该条判定视角二选一（POV 第一视角版 / 第三视角电影分镜版），**不得混用**。每套各带一份独立负面框，按所选模板取用对应那一份。
>
> 🔴 **画面风格的两个位置，性质不同、写法不同（防"风格被画成乱码文字"）**：`[画面风格]` 出现两处，**一处是画内文字（顶部通栏短锚词）、一处是渲染指令（着色段完整原文）**，绝不可混填——
> 1. **顶部通栏里的短锚词**：这是**要被模型画成图内文字**的那一行，生图模型把文字当纹理画、不是拼字，**文字一长必乱码**。因此只填**短风格锚词**（3–5 个词封顶，如「冷灰留银 · 35mm Noir · 漂白去色硬侧光」），**不得把完整画面风格长句塞进通栏**。
> 2. **着色段的完整原文**：这是**给模型读的渲染指令、不是画内文字**，填**阶段一产出的完整画面风格原文，一个字不许少、不许缩写**（专名如「柘黄」「halation」「bleach bypass」照抄，焦段/色温/主光/对比全部保留）。
> **一条画面风格，两个位置各司其职**：短锚词进通栏（防乱码），完整原文进着色指令（一字不少）。

> 📁 **第一～三段声明句原文统一见 `reference-引用总表.md`**：角色板见「二、角色板三态 → 态一（图片侧）」、道具板见「三」、场景板见「四」。拼接时去总表逐字取原文，替换 `{{Image N}}` 与对象名。三套模板（POV / 第三视角 / Vox）的声明句一律以总表为准，不各自复制。
