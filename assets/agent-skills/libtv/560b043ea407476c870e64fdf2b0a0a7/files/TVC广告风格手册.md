# TVC 广告风格手册

> 📁 **文件定位**：本文件是故事板 Skill 的**第三条腿**——「TVC 广告（电视/品牌商业广告）」风格引擎。故事板 Skill 默认走「电影写实」风格（见 `电影风格手册.md`），当一条片子的目的是**卖产品**而不是讲故事时，电影写实那套（六档景别叙事递进、靠"影"的低调光、克制平实的凝视）会让产品淹没在氛围里。TVC 有自己一套语法，本手册就是它。
>
> 🔴 **取词铁律**：本手册所有词汇与规则都**读过正文原文才收录**，逐字复用、不得凭印象改写。来源：`tvc-director`（110 star 开源 skill，2026 上线）、`uselamina.ai` 产品广告一致性指南、`useseedance.com` 广告工作流、`astorie.ai` Seedance 产品视频指南。

---

## 0. 什么时候调用（触发条件）

1. 老大要的是**产品广告 / TVC / 品牌片 / 商业广告 / 卖货视频**——片子的第一目的是**让人记住并想买某件产品**。
2. 一条片子里有明确的「产品」这个主角（实物商品、App、软件界面、服务形态），且要求**产品保真**（包装、Logo、颜色、材质不能变）。
3. 老大提到「Hero Shot / 产品特写 / 拆解 / 材质微距 / End Frame / 快切节奏」这类词。
4. **不用本手册**：纯叙事、无产品、讲人物故事的片（走电影写实）；纯知识科普（走《Vox 科普风格手册》）。

## 1. TVC 与电影写实的本质差异（先想清楚，再动笔）

| 维度 | 电影写实（默认） | TVC 广告 |
| --- | --- | --- |
| **第一目的** | 讲故事、演人物 | **卖产品**，产品是唯一主角 |
| **产品位置** | 道具之一 | **每一帧的主角或重要配角** |
| **光** | low-key、靠"影"、明暗比 | **high-key 高调光、无影、棚拍**，产品要看得一清二楚 |
| **景别权重** | 六档叙事递进 | **特写/大特写权重最高**（产品=hero），全景降级 |
| **节奏** | 情绪弧驱动 | **精确秒数**，30s 约 8-12 镜，快切 |
| **核心资产** | 三视图锁人物 + 故事板锁画面 | **产品多视图锁产品保真** + Hero Shot + End Frame |

> 🔴 **一句话判据**：电影里主角靠剧情弧赢得特写；广告里**产品直接给特写，因为那就是重点**（storyflow 原文）。

## 2. 产品出镜率铁律（TVC 的第一硬约束，违反必返工）

TVC 是产品广告，不是风景片。以下四条来自 `tvc-director` skill 原文：

- **全片产品可见格占比不低于 70%**：所有 grid 的总格数中，产品可见的格数 ≥ 70%。
- **单张 Grid 无产品格不超过 2 格**：任何一张 3x3 Grid 中，最多允许 2 格无产品。
- **禁止连续 3 格以上无产品**：无产品的格必须被有产品的格间隔开。
- **品牌世界格中产品也必须可见**：品牌世界不等于"没有产品的风景片"，产品在品牌世界中应占画面 10%-25%，自然融入场景。

> **产品出镜验证（输出规划表后、生成提示词前必须执行）**：扫一遍规划的全部 grid，逐格标注产品可见格数。违反上述任何一条，必须先调分镜设计，再进提示词。

## 3. TVC 标准节奏（品牌世界 ↔ 产品世界的呼吸）

节奏核心是**两个世界之间的呼吸**——品牌世界（使用场景）和产品世界（特写/拆解）交替出现。来自 `tvc-director` 原文：

**30s TVC — 品牌世界穿梭型**

| 时段 | 世界 | 功能 | 情绪 |
| --- | --- | --- | --- |
| 0-5s | 品牌世界 | Hook：极限场景/生活瞬间 | 肾上腺素/共鸣 |
| 5-10s | 交叉 | 品牌世界 ↔ 产品特写交替（匹配剪辑衔接） | 惊叹/好奇 |
| 10-20s | 产品世界 | 产品电影化拆解/功能可视化 | 专注/震撼 |
| 20-25s | 品牌世界 | 回到使用场景，产品融入其中 | 向往/认同 |
| 25-30s | 产品世界 | 产品 Hero Shot + End Frame | 记忆锚定 |

**30s TVC — 纯产品电影化型**

| 时段 | 功能 | 产品状态 |
| --- | --- | --- |
| 0-3s | 产品从黑暗中觉醒 | 光线唤醒 + 材质微距 |
| 3-8s | Phase-by-Phase 功能拆解 | 零件悬浮拆解、传感器发光 |
| 8-15s | 组装回弹 + 功能可视化 | 屏幕亮起、追踪框、数字跳动 |
| 15-22s | 爆发旋转 + 多角度展示 | 旋转中光影流动 |
| 22-27s | 材质微距高潮 | 极近距离材质质感 |
| 27-30s | 定格 + End Frame | 产品 Hero Pose + Logo |

**15s TVC**

| 时段 | 功能 |
| --- | --- |
| 0-3s | Hook（品牌世界一闪 or 产品爆发登场） |
| 3-10s | 核心卖点视觉化（1-2 个功能的电影化呈现） |
| 10-13s | 产品 Hero Shot |
| 13-15s | End Frame |

## 4. 产品保真（TVC 的命门，电影写实没有这条）

来自 `uselamina.ai` 原文，这是 TVC 区别于一切其他视频的**核心铁律**：

> **"Don't waste the prompt rebuilding a package already represented correctly in the input frame."** —— prompt 只写运动/相机/环境，产品的身份由**锁定的参考图**承载。

**锁定产品六件事**（`uselamina` 原文"Which product details need locking"）：

- 干净的**正/侧/背/细节**多角度图 + 需要比大小时的手持比例图
- **材质与表面处理**（material / finish）说明
- **精确的 Logo 与文字**信息（exact text）
- **颜色规格**（color）
- **禁止变体清单**（prohibited variants）
- **一张 hero 图作为对比标准**（comparison standard）

**产品描述符块（descriptor block）**：把必须跨镜重复的属性写成一个固定块，**逐字复用**。原文警告：

> "Letting each creator paraphrase the product is how one SKU turns into several different objects."（让每个人各自转述产品，是一个 SKU 变成几个不同物体的根源。）

**产品视频 prompt 的标准结构**（`uselamina` 原文，一个饮料罐的完整示例）：

> "Use the supplied product exactly. Slow 10-degree turntable rotation. Camera makes a gentle push-in. Soft side light moves across the aluminum surface. Preserve package geometry, logo, label, color, and proportions; no deformation; no new text."

要点拆解：**① 声明产品已锁定 ② 一个主体动作 ③ 一个相机动作 ④ 一个光的行为 ⑤ 一句保真硬约束**。没有一句在"重新描述产品长什么样"。

> 🔴 **hero frame 审批是锁**（`uselamina` 原文）：每个镜头先出一张静帧，全尺寸检查产品几何、Logo 形状、标签文字、颜色、材质、比例、布光、裁切、留白区。**过了这一关动画才开始**。"That approval is the lock. Animation waits until the still passes."

## 5. TVC 专属词表（全部读正文原文收录）

### 5.1 产品镜头类型

| 词 | 中文 | 用途 |
| --- | --- | --- |
| `hero shot` | 主镜头/主角镜头 | 产品最上镜、最完整的那一镜，广告的门面 |
| `pack shot` | 包装镜头 | 产品包装正面，标签完整可读、无硬阴影压字 |
| `beauty shot` | 美感镜头 | 纯展示产品美感的镜头，无叙事负担 |
| `macro detail shot` | 微距细节 | 极近距拍材质/纹理/压纹 Logo/Logo 细节 |
| `lifestyle shot` | 生活方式镜头 | 产品在真实使用场景中（穿在脚上、戴在手腕） |
| `before/after shot` | 前后对比 | 产品带来的转变 |
| `end frame` | 收尾定格 | 片尾记忆锚定画面（见第 6 章） |

### 5.2 产品电影化拆解（`tvc-director` 原文词汇）

| 词 | 中文 | 用途 |
| --- | --- | --- |
| 零件悬浮拆解 | exploded view / parts floating | 产品零件悬浮排列，展示内部结构 |
| 精密组装动画 | precision assembly | 零件飞回合体的动画 |
| 材质微距 | material macro | 金属磨砂纹理、玻璃折射、碳纤维编织的极近特写 |
| 爆发旋转 | burst rotation | 产品高速旋转、光影流动的多角度展示 |
| 悬浮凝视 | floating gaze | 产品悬浮定格，镜头凝视 |
| 俯冲穿越 | dive-through | 镜头俯冲穿越产品结构 |
| 光影随旋转流动 | light flows with rotation | 光在产品旋转时流动，勾轮廓 |

### 5.3 光线（TVC 用高调光，与电影写实的低调光相反）

| 词 | 中文 | 用途 |
| --- | --- | --- |
| `high-key lighting` | 高调光 | TVC 标准：明亮、无深影，产品看得一清二楚 |
| `softbox` | 柔光箱 | 棚拍柔光主光源 |
| `ring light` | 环形灯 | 产品正面的无影均匀光 |
| `light tent` | 柔光棚/灯箱 | 全包裹均匀光，拍小商品 |
| `soft studio rim light` | 柔影棚轮廓光 | 勾产品边缘，不压暗（区别于电影的低调轮廓） |
| `dramatic side light` | 戏剧性侧光 | 让压纹/材质细节凸显 |
| `neutral grey backdrop` | 中性灰背景 | 产品标准棚拍背景，不抢戏 |

### 5.4 产品质感（让产品"高级"的关键词）

| 词 | 中文 | 用途 |
| --- | --- | --- |
| `glossy` | 光泽 | 高反光表面（金属、玻璃、烤漆） |
| `matte` | 哑光 | 磨砂表面（耳机、哑光包装） |
| `specular highlight` | 镜面高光 | 材质反射的高光点，质感关键 |
| `perfect reflections` | 完美倒影 | 产品映在反光面上的倒影 |
| `volumetric light rays` | 体积光柱 | 棚拍氛围光柱 |
| `floating dust` | 悬浮尘埃 | 光柱里的尘埃粒子，增高级感 |
| `seamless white` | 无缝白背景 | 电商级干净背景 |

### 5.5 相机运动（广告特有，与电影写实不同）

| 词 | 中文 | 用途 |
| --- | --- | --- |
| `slow 360-degree turntable orbit` | 慢速 360° 环绕 | 产品旋转展示的标准运镜 |
| `slow push-in` | 慢推 | 向产品缓推 |
| `180-degree orbit` | 180° 环绕 | 半环绕展示 |
| `product remains center frame` | 产品始终居中 | 防模型中途重裁切 |

### 5.6 负面词（产品保真专属，合并进负面框）

`blurry low quality、distorted packaging、incorrect logo、extra text、duplicate product、cropped package、wrong colors、watermark、deformed object、plastic texture、oversaturated colors、bad lighting、floating packaging、incorrect label、brand modification、no deformation、no new text`（来源 `markbuzz.in` + `uselamina`，逐字）

## 6. End Frame 系统（TVC 的收尾，电影写实没有）

End Frame 是观众看完广告最后记住的画面，来自 `tvc-director` 原文。

**标准构成**：产品居中或偏置 + 品牌 Logo（通常在产品上下方）+ Slogan（简短文字）+ 干净背景（纯色/微妙渐变/品牌色）。

**提示词模板**（`tvc-director` 原文）：

```
[画质锚定]，[产品描述][居中/偏置]静置于[背景描述]中央。[光影设计]。
产品下方/上方留出空间用于放置品牌标识。整体画面干净、高级、克制。[画风锚定]。
```

> 🔴 **关键**：模型不擅长精确渲染文字——**Logo 和 Slogan 文字在后期叠加**，提示词里只需**预留空间**，不写具体文字。这一条和 Vox 手册的"精确文字后期贴"是同一个道理。

## 7. 画风锚定五档（`tvc-director` 原文，生成前必须先和用户确认画风）

| 档 | 名称 | 效果 |
| --- | --- | --- |
| A | 真人实拍/摄影级 | 像真实摄影照片（产品摄影、苹果广告） |
| B | 真人电影剧照 | 介于真人和 CG 之间（漫威、权游） |
| C | 3A 游戏 CG | 高品质游戏 CG（最终幻想、原神过场） |
| D | 高精 CG 引擎级 | 追求接近真实的顶级 CG（头号玩家、UE5） |
| E | 特定美学风格 | 水墨、赛博朋克、动漫等 |

> **确认规则**：即使用户描述里看似已明确画风，也必须复述方向请用户确认；确认前不得生成任何提示词；确认后全套关键帧统一用同一画风。

## 8. 融入故事板的落地方式

- 本手册**不替代**故事板 Skill 的流程，只替换其中「画面风格」这一环的取词来源：做 TVC 时，阶段一步骤4 的画面风格、阶段二步骤4 的故事板风格、步骤6 的视频风格，**一律从本手册取词**，不再用 `电影风格手册.md` 的电影写实词汇。
- **产品多视图**取代「三视图」成为 TVC 的第一资产：锁产品保真，而不是锁人物。有人物出镜时，人物仍走三视图，但**产品多视图优先于人物**（`tvc-director` 铁律：产品多视图先于分镜）。
- 视频提示词用 **Multi-Phase 格式**（见下），不是电影写实的"分镜N（X-Y秒）"一段式。

### Multi-Phase 视频提示词结构（`tvc-director` 原文）

```
风格：[视觉风格] / [色彩基调] / [光影系统] / [约束条件] / 无背景音乐 产品@产品多视图图片 的广告

Phase 1 (0-Xs): [标题]
[景别+视角] [运镜描述]。[产品/主体状态变化]。[光影效果]。[功能揭示（如有）]。

Phase 2 (X-Ys): [标题]
[节奏变化描述]。[运镜描述]。[产品动态]。[光效变化]。

光影要求：[贯穿全片的光影系统描述]
```

> 🔴 **音频规则**：每段风格声明必须写「无背景音乐」——视频模型默认生成 BGM，不显式禁止就会有（这一条与故事板 Skill 现有的 `need_bgm: false` 同口径，两边一致）。
