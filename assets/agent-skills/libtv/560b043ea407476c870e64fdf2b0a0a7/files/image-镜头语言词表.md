# 镜头语言词表（景别 / 运镜 / 机位角度 / 悬疑构图与叙事手法）

> 本文件是  的「镜头语言词表」分册，原为 image-prompt.md 第 49–177 行，为控制单文件不超过 2 万字符而整体下沉、原字未删。写故事板/视频提示词需选景别、运镜、机位角度、悬疑手法时，先加载本文件取词，逐字复用。

## 统一景别档位表与统一运镜词表（图片侧与视频侧共用同一份）

> 本表是分镜的**唯一技术口径**：景别与运镜取值先由 agent 在 `SKILL.md` 阶段二步骤3 分镜设计表中定好，**视频提示词分镜时间轴从这里取值**；故事板图不逐镜写景别/运镜（只"剧情+后缀"拼图），但景别/运镜的技术口径仍以此表为准，视频侧与分镜设计表同词同值，不得另造第三种叫法。

**景别档位表（由远到近共六档，第三视角通用；英文锚点为准，中文是本厂叫法）**

| 序 | 中文档位 | 英文锚点（写英文提示词时以此为准） |
| - | ---- | ----------------- |
| 1 | 大全景  | extreme wide shot |
| 2 | 全景   | wide shot         |
| 3 | 中景   | medium shot       |
| 4 | 中近景  | medium close-up   |
| 5 | 近景   | close-up          |
| 6 | 特写   | extreme close-up  |
| 7 | 过肩特写 | over-the-shoulder close-up |
| 8 | 插入镜头 | insert shot       |
| 9 | 反打   | reverse shot      |
| 10 | 空镜   | establishing shot / empty frame |

> 🔴 **悬疑新增档位（7–10）说明**：这四档是悬疑/惊悚题材的补档，与基础六档并列取用，英文锚点为准——
> - **过肩特写（over-the-shoulder close-up）**：越过角色肩部拍对面人物，前景肩/头作锚点，制造对峙感与空间代入。
> - **插入镜头（insert shot）**：拍门锁、钟表、颤抖的手、钥匙、水渍等局部物件，用于暗示、伏笔、加压（希区柯克"钥匙"式用法）。
> - **反打（reverse shot）**：正反打制造对峙；**故意压住反打不切**＝最强悬念（观众渴望看到对面那张脸）。「切离镜头（cutaway）」与插入镜头区分：cutaway 是切到与主线并列的另一处，insert 是切进主线内的物件细节。
> - **空镜（establishing shot / empty frame）**：无人或环境空镜，铺垫氛围、留白、并**植入一个"不对"的细节**（远处窗有人影、院里多一把椅子）。
> - **「大远景/孤立小人」不单列一档**：中文"大远景（extreme long shot）"与"大全景"同英文锚点 `extreme wide shot`，只作为"大全景"的**悬疑语义补充**（人物占画面 10–20%、环境主导、渺小脆弱孤立），不另立新档、避免英文锚点打架。

> 🔴 **中英锚点说明（记死，别再错位）**：中文「近景」对应英文 `close-up`（胸部以上、脸部占满画面、情绪焦点）；中文「特写」对应英文 `extreme close-up`（只留局部细节：眼/手/物）。**英文是 AI 实际理解的语言，写英文提示词时以英文锚点为准，不得把「特写」翻译成 close-up 或把「近景」翻译成 extreme close-up**。中文「大特写」（头部细部、眉眼口鼻）这一档在英文里并入 `extreme close-up`，**不单列一档**——中文标准的三档「近景/特写/大特写」在英文里只对应 `close-up` 与 `extreme close-up` 两档，本厂六档表按英文权威六档锚定，不强行凑中文七档。

POV 第一视角版另含一档「**主观视角手部特写**」，**只适用于 POV 条**，不得与第三视角各档混用（沿用「一张故事板不混用两种视角」）。🔴 POV 每格都必须带**身体锚点**（手、前臂、衣领边缘入镜作身体参照），画面边缘没有「身体」就是广角空镜、不是 POV；POV 的镜头语言六维度（有身体/有头/有眼高/有注意力/会被挡/有冲击）＋三拍语法＋「动作作用于镜头」的完整口径见 `video-prompt.md`「POV 条的角色板与分镜适配」一节，图片侧与视频侧**同口径执行**。

**落差规则（按上表数档，制定分镜设计表时即须满足）**

- 相邻镜头硬切时，景别须**明显不同**（至少隔一档，如 全景→中景、中景→中近景），不能切到景别与构图几乎相同的两格。
- **同一景别**不算有效切换（切了等于没切）。
- 若剧情本就是要同一景别静静停留，则**不切、用一镜到底**，而不是切到一个几乎相同的景别。
- 🔴 **跨多档不是暴跳**：相邻镜从全景直接切到特写、大全景切到近景，只要**有叙事理由**（突转、强调、震惊、节奏需要）就是正当剪接，不是错误。判定标准不是「隔了几档」，而&#x662F;**「这一刀有没有叙事动机」**——有动机，跨几档都成立；没动机，哪怕只隔一档也显得跳。

**运镜词表（机位运动方式，取值互斥，一镜只能选一个）**

`推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 手持拍摄`

> 🔴 **运镜词只用于视频侧（图片侧不写运镜，铁律）**：运镜是"时间维度的运动"，静态单帧没有时间可执行——文生图模型对 `推/拉/摇/移/甩镜/眩晕变焦/环绕` 基本是 no-op（无效），个别词还会被硬凑（crane→俯视、push-in→近景）甚至触发有害冲突（handheld/rack focus）。**故事板图 prompt 只写「景别 + 机位角度 + 光线氛围 + 构图」，不写任何运镜词**；悬疑增强运镜（慢推/甩镜/环绕/眩晕变焦/一镜到底/抽帧慢门）与时间维度手法（拉焦/慢动作/闪切/跳切/定格/倒放/闪帧/快门角度）**全部只在 `video-prompt.md` 视频侧取用**。依据：火山引擎官方 Seedream「影视分镜」示例从头到尾一个运镜词都不写，只描述画面内容；即梦官方把运镜能力只挂在视频产品 Seedance 下。

> 🔴 **「手持拍摄」是稳定性描述，不是运动方向描述**：它说的是**机器端在人手上、握不牢，所以画面有轻微晃动**，与「镜头追不追着主体跑」无关。「推/拉/摇/移/跟/升/降」是**运动方向**，「手持拍摄」是**稳定性**，两者是不同维度。一镜的运镜值填运动方向值（记入分镜设计表与视频侧）；若要强调手持质感，可叠加描述（如「手持拍摄、镜头随她走动」），但运镜取值仍只填运动方向那个值。

- **「固定机位」是正当选择，不是禁用项**：英文 `static shot / locked-off shot` 是标准、正当的机位（StudioBinder 把它列为第一种运镜类型）。**本厂默认偏好手持的呼吸感，但需要机位完全锁死、画面纹丝不动时（如表现静止、凝视、屏息、庄重），可明确写「固定机位 / static shot」**，不是错误。默认与固定之间，按「本镜情绪需要稳定还是呼吸感」判断，不搞一刀切禁用。
- **「手持拍摄」管的是稳定性（手拿不稳所以轻微晃动）**：
  > 手持质感描述：「手持拍摄、人手握持不稳带来轻微晃动、有呼吸感、稳定但不机械」（正文依据：`slight natural sway and small reframing corrections, not violent shake`，见 `video-prompt.md` 手持节）。
  - **跟**：镜头随主体移动——这是运动方向里的一个独立取值，与「手持拍摄」（稳定性）不是一回事。
  - 二者可以叠加描述（如「手持拍摄、镜头随她走动」），但**不得写成「手持跟拍」**。
- 分镜设计表里的运镜取值只能填本词表内的**一个**值，不得自创（如「缓慢推进」「轻微晃动」都不是词表取值，应记为「推」或「手持拍摄」）。
- 词表之外的运镜需求，先归到最接近的词表取值记入分镜设计表，再写进两处。

**机位角度词表（悬疑/惊悚补档，与景别、运镜并列，取值互斥）**

| 机位角度 | 英文锚点 | 用途 |
| --- | --- | --- |
| 荷兰角 | dutch angle / canted angle | 5–15° 微妙不安、15–45° 中到强不安/戏剧化，心理失衡 |
| 正俯 | top-down / overhead shot | 完全垂直俯瞰，临床冷感、监控感、上帝视角 |
| 越轴 | crossing the 180° line / axis jump | 故意破轴线，空间迷失、心理混乱 |
| 偷窥机位 | voyeur shot | 观众成"闯入者"、被摄者不知情，恐惧＋共谋感 |
| 门缝/钥匙孔视角 | peephole / keyhole matte | 透过孔洞/遮挡物框住画面，"有人在偷看/监视" |
| 镜像机位 | mirror shot | 镜面一人变两像，隐藏视点、分裂自我 |
| 前景遮挡脏边 | dirty frame | 前景大面积遮挡主体，"偷窥/隐藏/不完整信息"暗示 |
| 极低贴地 | low to ground | 贴地机位，强化不安 |

> 🔴 **机位角度说明**：本表是悬疑/惊悚题材的补档，与六档景别、运镜词表并列取用，英文锚点为准。机位角度描述的是"机器摆在哪、怎么摆"，与"运动方向（运镜）""取景范围（景别）"是三个不同维度，可组合、但各自只取一个值。基础三机位（平视 eye-level、低角度 low angle、高角度 high angle、鸟瞰 bird's-eye view、主观 POV）属通用角度，不在本表重复；本表专列**悬疑特有的、制造不安的**机位角度。

**悬疑构图与光学手法（图片侧可吃，单帧即成立，与景别/机位/运镜并列取用）**

> 🔴 本表专列**能在静态单帧里体现**的悬疑构图/光学手法（文生图可稳定响应），供故事板图逐格选用。时间维度的运动手法（拉焦、慢动作、闪切、定格、倒放、闪帧、快门角度）与运镜（慢推/甩镜/环绕/眩晕变焦/一镜到底/抽帧慢门）**不在本表**，见 `video-prompt.md`。

| 手法 | 英文锚点 | 用途 |
| --- | --- | --- |
| 负空间 | negative space | 主体推到角落/边缘，大面积留黑，孤独、威胁、悬念 |
| 前景遮挡脏边 | dirty frame / occluded foreground | 前景大面积遮挡主体，"偷窥/隐藏/不完整信息"暗示 |
| 剪影 | silhouette | 逆光压成黑影，抹掉五官，隐藏身份与意图 |
| 阴影藏信息 | shadow as concealment | 硬侧光半脸入暗、或阴影遮住关键物，藏住信息 |
| 单光源收窄视野 | single-source lighting | 手电/烛火/台灯只照亮一小块，光斑外全黑 |
| 反射藏信息 | reflection hidden detail | 镜/玻璃/门面反光里藏主角没看见的鬼影线索 |
| 对称+单点透视 | symmetry / one-point perspective | 灭点居中、完全镜像，病态秩序感（库布里克式） |
| 软焦/失焦威胁 | soft focus / out-of-focus threat | 把危险留在焦外模糊区，逼观众眯眼去猜 |
| 深焦 | deep focus | 前后景全清晰、多层信息同框，让观众自己发现矛盾 |
| 长焦压缩空间 | telephoto compression | 近景远景压叠，拥挤压迫与紧张 |
| 移轴 | tilt-shift | 真实场景变微缩模型，世界失真、主观抽离 |
| 螺旋母题 | spiral motif | 用螺旋图形（楼梯/年轮/旋涡）反复暗示心理塌陷 |
| 杀手主观视角 | first-person killer POV | 镜头=杀手的眼，观众成共犯（slasher 细分） |

> 🔴 **分裂屈光镜（split diopter）单列说明**：一帧内前景主角+背景威胁**同时锐利**、中间留一道竖缝虚化，光学上制造"知情差"、自带人眼无法做到的诡异感。文生图对 split diopter 的响应不如剪影/负空间稳定，**建议用「前景清晰主角 + 背景清晰威胁 + 中间虚化带」的描述方式逐字写明，而非只丢 split diopter 一词**。

## 悬疑手法调用标准（该用 / 不该用 两档判据）

> 🔴 **核心原则（记死）**：悬疑手法**不能全程满铺**——手法为"情绪节拍"服务，不是为"每帧都吓人"服务。满铺 = 观众疲劳 = 反而没悬疑感。**每一格先判"该用还是不该用"，再动手选词。**

**该用（满足任一，即可上悬疑手法）**：

- **此刻有信息差**：观众比角色知道得多（如知道杀手在柜子里）→ 用**偷窥机位 / 门缝视角 / 监视器**，制造"替角色捏把汗"的煎熬；观众和角色知道得一样少 → 用**越肩跟拍 / POV / 负空间**，让观众跟着一起被吓。
- **此刻要蓄势或爆点**：埋线索、角色察觉异常、逼近真相 → 用**负空间、前景遮挡、慢推、越肩跟拍、插入镜头**；反转、真相揭晓、对峙、惊吓 → 用**荷兰角、甩镜、眩晕变焦、偷窥机位、压住反打不切**。

**不该用（满足任一，就收敛、别上手）**：

- **纯交代信息**：只是在说事、铺日常、交代背景 → **平实镜头**，最多埋一个"不对"的细节（空镜里远处多一把椅子），渲染神秘、不渲染惊悚。
- **信息差不存在**：观众和角色知道得一样多、且没有新威胁 → 别乱用，否则就是故弄玄虚。

**两条硬节奏（无论该用与否都要守）**：

1. **强刺激手法限量**：荷兰角、眩晕变焦（dolly zoom）这种"重手法"一场戏**最多 1–2 次**，用多了就廉价。
2. **松紧交替、一次只做一个镜头动作**：悬疑靠"延迟"不靠"一直紧"——慢速＋停顿，先静止再突然打破；一条视频**只做一个镜头动作**，镜头太活跃悬疑就散了。

## 悬疑叙事手法（图片侧可用的"藏与露"语法）

> 🔴 悬疑的高级功力不在"运镜机位景别"，而在**怎么用镜头藏信息、误导、延迟揭示**。以下是单帧即可成立的叙事手法，写故事板分镜时优先用这些"讲故事"，再配镜头语言词。**时间/剪辑维度的叙事手法（交叉剪辑、闪切、声先于画、拉焦、慢动作）见 `video-prompt.md`。**

| 叙事手法 | 怎么用 | 为什么出悬疑 |
| --- | --- | --- |
| 知情差（信息延宕） | 先给观众一个角色不知道的危险（凶器/埋伏/第三人） | 悬念=观众想喊"快跑"；观众知情→悬念，观众不知情→反转 |
| 误导镜头 | 焦点钉在A（脸/动作/前景），关键藏在B（背景/虚焦/反光） | 隐藏比藏不住更骗人 |
| 契诃夫之枪 | 孤立特写一件"此刻无用"的物件，后面兑现 | 观众替它记账，兑现时"早有铺垫"；反向用=红鲱鱼 |
| 反打压制 | 对峙/问询不给听者的脸，用背影/后脑勺 | 逼观众猜对方心理，比给脸更悬疑 |
| 画外留白 | 拍空楼梯/墙影/角色反应，代替拍威胁本身 | 画面外由观众用最坏想象填满 |
| 视线误导 | 正常用视线匹配；故意错位/延迟，让观众不知角色在看什么 | 制造"不知在看什么"的不安 |

> 🔴 **"不拍脸"的特殊特写（叙事用法，与景别表里的"特写"档配合）**：手部特写（颤抖=恐惧、攥紧=决心压抑）、眼睛特写（放大恐惧微表情，对峙戏轮流推多双眼睛）、物件特写（钟表=倒计时、门锁/钥匙=进入逃脱、照片=情感记忆、发光/异常道具=下毒）、背影/剪影（有人但不知谁/何意图）、门缝局部（dirty shot 挡半张脸，揭晓全脸时冲击最大）。**拍多久的纪律**：先给足空间方位再藏（否则是困惑不是悬疑）；特写克制不堆砌；物件/文字特写时长≈"读两遍"的时间。
