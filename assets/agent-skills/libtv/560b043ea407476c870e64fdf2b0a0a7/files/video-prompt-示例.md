# 视频提示词 · 正确示例

> 本文件是 `video-prompt.md` 的「正确示例」章节（为控制单文件不超 2 万字符而拆出，原文未改、只搬位置）。写视频提示词时按 `video-prompt.md` 的规则，参照本条示例逐字对照。

> 视频的负面框见 `video-prompt.md` 六组；故事板图负面框另在 `image-prompt.md` 示例节，**两者不得混用**。
>
> 本示例演示的是：**每个角色只列一行角色板、声明句只写类别名**（不附特征关键词、不加括号补充）／**参考关系开头说一次，正文与分镜行只写角色名、不再回贴任何图片 key**／**末尾写反分身硬约束句**／**整体场景与氛围不含质感正向句、不重复配色**／**分镜行以「硬切 分镜N（X-Y秒）：」硬切秒行起头**／**运镜取自统一运镜词表、相邻镜头景别明显不同**／**画面风格照抄阶段一产出**（所有视频同一句、不得改写）／**常驻声明含人物实体性声明一句**／**实拍以该条分镜设计表为准、术语与故事板同词同值**。
>
> 另请记住本 Skill 的核心关系：**故事板是视觉底本，视频按剧情取用**——**静态外观不复述**（图上有的不写），**动态信息必须写**（图上看不出动静的才写）。
