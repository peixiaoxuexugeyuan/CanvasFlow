# 引用总表（全 Skill 所有「引用」的唯一事实源）

> 📁 本文件是全 Skill 里**所有"引用"写法的唯一定义点**。
> 任何一处要写「参考某图/某音色/某节点」，一律到本文件取声明句原文，逐字复用。
> 图片侧（`image-prompt.md`）、视频侧（`video-prompt.md`）、音频侧（`audio-prompt.md`）
> 只保留指针，不再各自展开声明句——改引用写法，只动这一个文件。

---

## 一、引用对象总表（谁引谁 / 在哪个侧 / 唯一声明句）

| 引用对象 | 引的是什么 | 用在哪 | 唯一声明句 |
| --- | --- | --- | --- |
| 角色板 | 人物五官、发型、服装 | 图片侧、视频侧 | 见「二、角色板三态」 |
| 道具板 | 道具外形、材质、颜色、磨损、尺寸 | 仅图片侧 | 见「三、道具板」 |
| 场景板 | 场景空间结构、材质、陈设 | 仅图片侧 | 见「四、场景板」 |
| 故事板构图 | 场景、环境、道具、构图、景别底本 | 仅视频侧 | 见「五、故事板构图」 |
| 音色 | 角色声音 | 仅视频侧（音频侧定义） | 见「六、音色」 |

> 🔴 **两侧不越界**：图片侧不写运镜、不引音色；视频侧不挂道具板/场景板（场景道具由故事板底本承载）。

## 二、角色板三态（同一个角色板，在三种场景写法不同）

> 角色板永远是「一张图、一个 node_key」。判据一句话：
> **这个人会不会在画面里露脸？露脸→锁脸；不露脸（POV 主体）→只锁服装+手。**

### 态一：图片侧（故事板图，角色会露脸）

```
参考角色板 {{Image N}}：{{角色名}}的长相、发型、服装以此为准，全程只认这一张，不得从其他图提取，作为人物五官与身份的唯一参考；不采用图片背景。
```

### 态二：视频侧（第三视角，角色会露脸）

```
参考角色板 {{角色key}}：{{角色名}}的长相、发型、服装以此为准，全程只认这一张，不得从其他图提取，作为人物五官与身份的唯一参考；不采用图片背景。
```

### 态三：视频侧（POV，主角不露脸）

> POV 主体（镜头=他的眼睛）全程不露脸，角色板只锁「服装、随身物件、手部可见部分」，
> 绝不写「取面部/五官」。POV 条必须把职责隔离拆成两组：

```
仅以 {{出镜角色key 列表}} 作为出镜人物五官与身份的唯一参考，这些人物的面部、发型、服装只认这几张，不得从其他图提取、不得把同一人物的不同角度当作不同人物。{{主角key}} 仅用于主角的服装、随身物件与手部可见部分，不得从其中提取任何面部或五官（POV 主体不露脸）。{{故事板key}} 只用于景别、构图、运镜与动作调度；按其中各分镜格的顺序依次取景、输出为连续单镜头，禁止保留网格排版、边框、分屏或格号，禁止从故事板缩略图中提取任何人物五官、发型或服装。
```

## 三、道具板（仅图片侧，每件一张板）

```
参考道具板 {{Image N}}：{{道具名}}的外形、材质、颜色、磨损、尺寸与细节以此为准，全程只认这一张，不得从其他图提取，作为道具身份的唯一参考；不采用图片背景。
```

- 🔴 每件道具单独一张板、单独一行，不得一张图塞多件道具，不得与角色板、场景板混用。
- 🔴 垫图必须文字点名「材质+颜色+表面质感」，不得只挂图不点名（防漂材质）。

---

## 四、场景板（仅图片侧）

```
参考场景板 {{Image N}}：{{场景名}}的空间结构、材质、陈设以此为准，全程只认这一张，不得从其他图提取，作为场景唯一参考；不采用图片背景。
```

---

## 五、故事板构图（仅视频侧，视觉底本）

```
参考故事板构图 {{故事板key}}：本片的场景、环境、道具、构图与景别的视觉底本，全程以该图为准，不得自行更改、不得新增图中没有的环境元素或道具；不采用图中的缩略人物五官、发型与服装。
```

## 六、音色（唯一正确路径：引 speaker_id）

> 音色定义与注册机制见 `audio-prompt.md`「音色固定」，本文件只写视频侧落地句式。

- **有音色ID的角色（默认、唯一正确路径）**：

```
参考音色 {{speaker_id}}：{{角色名}}的音色参考，全程只认这个音色ID，不得更换音色。
```

- **有音频的角色（首次注册前的过渡态，仅一次）**：

```
参考音频 {{音频key}}：{{角色名}}的音色参考，全程只认这一段，不得更换音色。
```

- 🔴 **禁止「没音频也没ID就写一句音色描述」**：凡生成音频的角色，音色必须已注册成固定 ID；
  只有「戏份少、入口⑤约定不生成音频」的龙套才不挂音色、台词直接 `人物说：{台词}`。
- 音色句**贴在角色板句末尾、同一句里**，不另起一行。

## 七、引用铁律（所有侧通用，逐条遵守）

1. **开头说一次，全程有效**：参考约束只在最开头声明块写一次；正文、分镜行只写角色名，不再回贴图片 key。
2. **一人一行**：多角色必须每个角色单独一行，禁止「@图1到图4 分别定义四个角色」的压缩映射。
3. **「不采用」是干实活的**：参考图会把它包含的一切带进来，只想要脸就得明说「不采用图片背景」。
4. **同一人物多角度，必须声明是同一人**：多张图是同一人不同角度时，加末句「成片始终只出现一个 {{角色名}}」。
5. **反分身硬约束**（负面框之前、正文末尾固定加一句，逐字复用）：

```
视频全程禁止出现外形、着装、配饰完全一致的两个人，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻。
```
