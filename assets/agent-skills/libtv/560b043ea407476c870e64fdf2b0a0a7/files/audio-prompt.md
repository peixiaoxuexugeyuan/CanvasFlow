# 音频提示词规范（角色配音 / 音生音）

> 本文件对应「故事板 Skill」的**音频侧**规范，用于生成角色配音。音频生成统一用 **Seed Audio 1.0**（字节豆包音频生成模型），在 LibTV 画布里用 `libtv node -t audio` 实现。

---

## 一、提示词结构（五段，有用，保留）

角色配音提示词用**五段结构**：①声音层 + ②场景 + ③台词 + ④表演 + ⑤时间线。音色靠**音生音（参考音色）**垫。

| 段 | 装什么 |
|---|---|
| **① 声音层** | 音色定位：年龄/性别/音高/音色质感/咬字/语速/情绪/重音习惯/腔调 |
| **② 场景** | 环境声：地点 + 环境音（雨/CRT嗡鸣/算盘声…） |
| **③ 台词** | 引号内的对白原文 |
| **④ 表演** | 语气 + 语速 + 重音落点 + 句尾收法 |
| **⑤ 时间线** | `0-x 环境 / x-y 台词 / y-z 留白` |

**完整范例（照抄改词）：**

```
声音层：成年男性译制片配音演员，中音偏油滑、带轻微鼻音和舞台假笑；老派译制片咬字圆滑，语速中快；数字重音清晰；句尾带算计式下沉。

场景：律所账房，雨夜，CRT显示器低频嗡鸣，算盘按键偶尔轻响。

台词："第三笔罚款，从你账上走。"

表演：译制腔油滑假笑，前半句体面、后半句冷下来；重音落在"第三笔"；句尾下沉，像在核账；不要过度滑稽。

时间线：0.0-1.0s 环境CRT嗡鸣/雨声；1.0-3.0s 台词；3.0-3.5s 留白收尾。
```

**关键：台词要短，2 秒就够。**

我们做角色配音，**一条台词 2 秒的量就够用**，不用追求长对白。台词写短、语速正常，出来的自然。长对白模型会加速语速去硬塞，反而假。

## 二、音色固定（唯一口径：注册一次 speaker_id，永久复用）

> 🔴 **本文件是「音色固定」规则的唯一定义点**（`SKILL.md` 步骤6-A、`video-prompt.md` 音色参考段均指向本节）。落地句式另见 `reference-引用总表.md`「六、音色」。

**唯一正确路径（强制）**：每个生成音频的角色，音色**只在第一次注册一次**（`speaker_id` 声音复刻/主体库），之后所有视频一律引 ID 复用，**禁止每出新视频重新生成角色音频**。

- **注册接口**：`POST /api/v3/tts/voice_clone`；在 LibTV 画布里，音色上传一次进「主体库·音色」（支持传 5–30 秒视频提取音色），以后每集直接选。
- **`references` 字段（音生音 / 持久锁用）**：

| 字段 | 含义 | 何时用 |
|---|---|---|
| `speaker` | 音色 ID（声音复刻） | **注册一次、以后只传 ID** ← 长期复用 |
| `audio_data` | 参考音频 base64 | 音生音：首次注册时垫一段音频锁音色 |
| `audio_url` | 参考音频远程 URL | 音生音：引用远端音频 |

- 🔴 **禁止「没音频也没 ID 就写一句音色描述」**：凡生成音频的角色，音色必须已注册成固定 ID；只有「戏份少、入口⑤约定不生成音频」的龙套才不挂音色、台词直接 `人物说：{台词}`。

> 🔴 **删掉的旧兜底**：早期「纯文字直接生成」这条路，本质是「每次新视频现场文字造音色」，与「固定音色、永久复用」铁律直接冲突，已废弃。音色生成的正确路径只有一条：**首次注册成 speaker_id，之后只传 ID**。

## 三、LibTV 画布落地（真实用法）

> 🔴 **视频侧参数一律以 `SKILL-附录.md`「生成参数」表为准**，本节的命令示例只演示「音频节点怎么连进视频」这条链路，**参数取值不在此重复展开、不得另写一套**。

```bash
# 建音频节点：Seed Audio 1.0，五段结构提示词填 --prompt
libtv node "配音" -t audio \
  --prompt "声音层：……。场景：……。台词：\"……\"。表演：……。时间线：……" \
  --set "model=Seed Audio 1.0" \
  --run

# 音频节点连到视频节点左侧，跟参考图并列
# 🔴 视频的 model / 分辨率 / 比例 / 时长 / sound 字段，按 SKILL-附录.md「生成参数」表与本条 duration_sec 填，此处不写死
libtv node "镜头A" -t video \
  --prompt "<视频提示词>" \
  --set "model=<按生成参数表>" \
  --set modeType=mixed2video \
  --left 参考图 --left 配音 \
  --run
```

**核心要点：**

- 音频节点产出用 `--left 配音` 连到视频节点左侧，跟参考图并列。
- `modeType` 二选一，分工明确、不混用：
  - **`mixed2video`** = 全能参考（图＋音频混合输入），本 Skill 的**标准用法**——视频同时吃故事板图/角色板（画面）＋配音（声音），**有台词、有对白的视频都用这个**。
  - **`audio2video`** = 纯口型驱动（只拿音频驱动画面口型），**仅当某条视频只要"配好的音频"驱动口型、不需要图参考时才用**；本 Skill 常规流程不落到这一档。
- 🔴 **声音开关字段口径见 `SKILL-附录.md`「参数字段落地口径」**：无音乐 = `sound: on` ＋ `need_bgm: false`，**不得把 sound 设为 off**、不得另造 `enableSound` 之类的字段名。
- 具体能连几个音频/图，用 `libtv model <modelKey>` 看 schema。

## 四、铁律（判断尺子）

1. **五段结构（声音层/场景/台词/表演/时间线）是有用的，保留**，写全五段。
2. **台词要短，2 秒就够**，别写长对白。
3. **音色唯一路径：注册一次 speaker_id、永久复用**（见本章「二、音色固定」；落地句式见 `reference-引用总表.md`「六」）。
4. **生产参数（采样率/语速/音调/分轨）不进 prompt**，放 API 参数或后期处理。
