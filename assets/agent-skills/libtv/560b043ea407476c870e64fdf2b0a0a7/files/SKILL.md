# 故事板 Skill

## 这个 Skill 做什么

用户输入任意形式的剧本内容（文档 / 故事 / 要求 / 一句话），Skill 分两个阶段处理：**阶段一**建立全局锚点；**阶段二**逐条生成每条视频的故事板与视频。

> 📁 **文件地图**：本文件是流程主干，细则在分册里，用到才加载、逐字复用、不凭记忆写：
>
> - `SKILL-rules.md` — 全局禁止规则（速查总表）
> - `SKILL-流程规则.md` — 阶段二流程规则（流程弹性/账本/划分/压缩/加载时机）
> - `SKILL-附录.md` — 生成参数 / 改剧本 / 风格插槽 / 电影级词库
> - `reference-引用总表.md` — 🔴 **所有「引用」写法的唯一事实源**（角色板/道具板/场景板/故事板构图/音色的声明句原文，都在这一个文件）
> - `image-prompt.md` — 图片侧模板与后缀（POV/第三视角/Vox 三套）
> - `video-prompt.md` — 视频侧规则；`video-prompt-示例.md` — 完整正确示例
> - `audio-prompt.md` — 音频侧（配音/音色固定/配乐/LibTV 音频→视频链路）
> - 风格手册三本（电影/TVC/Vox），各带一张「风格声明卡」供步骤2/3/4 读

## 第一部分：流程

### 阶段一：全局锚点建立（整个剧本只做一次）

**工作文件约定（固定三处路径）**

产物路径压缩稿与切分摘要`scripts/<剧名>-compressed.md`锚点清单（含出镜过滤名单、画面风格、角色形象描述）`anchors/<剧名>-anchors.md`进度账本`progress/<剧名>-ledger.md`

- 三份文件在**阶段一四步串行期间即建立并写入**，**不得只存在于对话上下文**。
- 断点续做时**先回读这三份**；**不回读账本不得开始任何动作**。

**步骤0：入口问询**（一次合并选项卡问询，不逐题追问；结果写入 memory，全程有效、不重复问，每项带「自定义」输入框）

> 🔴 **统一入口原则**：本清单是「方向性全局开关」的唯一确认点——全程只定一次的开关**一次问全**，后续步骤只读已定值、不再让 agent 中途判断。新增全局开关必须加进本清单。「内容级判断」（步骤5 资产确认、角色出镜过滤）不进本清单。

⓪ **是否只搭建节点、不生成图片/视频**：同意 / 不同意。同意 = 只搭节点、建完交用户手动生成、不碰 `--run`、零积分；不同意 = 走完整生成链路。入口第一问，先定「搭还是生成」。

① **对白语言**：中文 / 日语 / 英语 / 方言 / 自定义。写进 video-prompt 的「台词语言前缀」与「语言锁」（见 `video-prompt.md`）。 ② **视频风格**：写实 / TVC 广告 / Vox 科普（三选一，全程有效、不混用）/ 自定义（触发「新增风格三步」，见 `SKILL-附录.md`「风格插槽化」）。 ③ **时长与剧本精减**：不精减 / 精减到 3 分钟 / 5 分钟 / 自定义。选「精减」触发第零阶段改剧本 + 台词压缩。 ④ **剧本内容**：未提供剧本时主动索取；已提供直接进阶段一。 ⑤ **人物音色与音频生成**（默认规则，不用逐角色问）：全程说话的角色 → 固定音色（注册一次 `speaker_id`，永久复用）；一两句龙套 → 不生成音频、文字带过。音频默认全生成。机制见 `audio-prompt.md`「音色固定」。 ⑥ **视角倾向**：逐条智能判断 / POV 优先 / 第三视角优先 / 自定义。 ⑦ **画幅比例**：9:16 / 16:9 / 4:3 ⑧ **生成参数档位**：默认档（视频 `Seedance 2.0 Fast / ≤15s`）/ 旗舰档（视频 `Seedance 2.5 / ≤30s`）/ 自定义。锚点图两档相同（`Lib Image 2.5 Pro / 低画质 1K / 16:9`）。参数口径见 `SKILL-附录.md`「生成参数」。

⑨ **道具/场景垫图**：有图要垫 / 没有图。选「有」→ 二级菜单里**道具图、场景图各自独立二选一**（四种组合都成立），agent 先建空节点占位、图由你手动后补；选「没有」→ 不出现菜单，道具/场景直接写在故事板剧情文字里。详见阶段二步骤4-0。

> 🔴 **风格引擎指路（入口②定哪套，全程只用那一套的词/分镜逻辑/资产方案，不混用）**：
>
> - **电影写实（默认）**：词库取 `SKILL-附录.md`（电影级词库）+ `电影风格手册.md`；核心资产 = 三视图 + 故事板。
> - **TVC 广告**：取 `TVC广告风格手册.md`，产品是主角，核心资产 = 产品多视图。
> - **Vox 科普**：取 `Vox科普风格手册.md`，走平面设计语言，核心资产 = 信息图/图表/地图。
> - 执行前用 `skill_file` 加载对应手册，取词逐字复用。

---

> 📁 **风格插槽化**：骨架只认「风格声明卡」，新增风格不动骨架。步骤2/3/4 先读 `SKILL-附录.md`「风格注册表」定位风格手册，再读其末尾「风格声明卡」取字段，全文见 `SKILL-附录.md`「风格插槽化」章。
>
> 🔴 **四步串行**（不得并行发图）：1 分析输入 → 2 角色出镜过滤 → 3 锚点清单写入 → 4 状态更新。四步完成才可发起图片生成。

**步骤1**：自动分析输入，识别人物、场景、风格。

**步骤2：角色出镜前置过滤（强制，先于三视图生成）**

逐角色判定是否出镜，分三类：

- **不出镜**：只被提及、本人从未出现在画面（如只被提到名字的萧淑妃、太平公主）。
- **不建图**：无名背景人群，无个体辨识度（群臣、宫女、太监等）。
- **建图**：有可辨识的出镜镜头。

「不出镜/不建图」一律不生成三视图，锚点清单登记为「角色（不出镜/不建图）」，节点Key、提示词填「—」。过滤结果以「建图名单 / 不建图名单」列出，作为步骤5 输入；未完成不得发起三视图生成。

**步骤3：生成人物三视图（角色锚点）**，全剧本复用，仅对「建图」角色执行。

- 角色形象描述按 **9 项顺序**写成一段话（细则见 `SKILL-流程规则.md`「阶段一步骤3」），模板正文见 `image-prompt.md`「三视图提示词模板」，逐字复用。
- 锚点名称用剧情原文人物原名，不用描述性称谓。
- 生图参数：`Lib Image 2.5 Pro / 低画质 1K / 16:9`。
- 三视图作为角色板 reference 传入故事板（步骤4）与视频（步骤6），锁长相服装一致性。

**步骤4：提炼画面风格** → 输出为一段统一文字（不生成色彩参考图），全剧本复用。

> 基线措辞（35mm 焦段、自然漫射生活光、**冷色调日式默认风格**、中等对比暗部干净不死黑、中等景深）的**完整原文见** `SKILL-附录.md`**「画面风格与电影级词库」章**，逐字复用。🔴 **默认是冷色调日式，不是暗调好莱坞**——`low-key / chiaroscuro` 只在用户明确点名要「暗调/悬疑」时才启用。电影级增强（可选，用户要「电影感」才叠加五变量词块）词库见同章。

**步骤5：输出锚点清单**

字段说明锚点名称该锚点的名称锚点类型角色/风格等（不含场景类型）；不出镜/不建图角色填「角色（不出镜/不建图）」节点Key对应节点的 Key；不建图填「—」提示词直接用于后续生图/生视频的提示词；角色锚点须含 9 项顺序写成的一段话外貌描述；不建图填「—」适用范围全剧本 / 某条视频

> 阶段一只建角色锚点和画面风格，不单独生成场景锚点图（场景由故事板分镜自然呈现）。

### 阶段二：每条视频生成（每条视频重复此流程）

**输入来源**：直接从阶段一输入里按台词字数自动划分，**不重复让用户输入**。

> 📁 **流程规则见** `SKILL-流程规则.md`：流程弹性（简单/满流程裁减）、进度账本与断点续做、两种执行模式（搭建/生成）、视频划分规则（75字/条）、台词压缩规则、前置过滤、模板加载时机、不索要图片确认——**这些规则正文全在** `SKILL-流程规则.md`，执行到对应环节时先用 `skill_file` 加载取用，逐字复用。

步骤1：计算视频时长

总时长只由「该条台词总字数 ÷ 5」决定（秒），作为 `duration_sec` 必传。每镜秒数只是总时长内部分配（见 `video-prompt.md`「剪辑节奏」）。

步骤2：判断视角

- 先看入口②视频风格：Vox 不参与视角二选一，账本「视角」列填其声明卡版式名。
- 再读入口⑥「视角倾向」默认值（逐条智能判断 / POV优先 / 第三视角优先），不在此重判。
- 电影写实/TVC 才判：**考虑 POV** = 有「只能以主角眼睛看」的段落（独自看/走/触摸/主观搜寻）；**一律第三视角** = 对白戏、多人同框、权力对峙。整张故事板统一、不混用。
- 🔴 判定结果必须写入账本「视角」列，空列视为步骤2 未完成。

步骤3：产出「分镜设计表」（只服务视频侧）

> 🔴 图片侧格数/景别/运镜**已由生图模型自判**（见 `image-prompt.md` 五段式），分镜设计表**只给视频提示词分镜时间轴提供每镜景别/运镜取值**。图片侧 = 模型自判（不读表）；视频侧 = 读表（agent 预判）。

- 字段读当前风格声明卡：电影写实/TVC = `镜号｜景别｜运镜｜核心动作一句话`；Vox = `镜号｜信息｜转场｜核心视觉想法一句话`。
- 景别/运镜取 `image-镜头语言词表.md`，不得自创第三种叫法。
- **落差规则**：相邻镜景别至少隔一档；跨多档需有叙事动机；同景别一镜到底不切。**逐对校验并留痕**，不得只写一句「落差按隔一档执行」。
- 表必须落文件（逐镜写入账本或工作文件），不得只内联进 prompt。

步骤4：生成故事板（模板与示例见 `image-prompt.md`）

**格数、景别、运镜由生图模型自判**（约束已写进 `image-prompt.md` 后缀模板）。agent 只把【角色板】【道具参考】【场景参考】【剧情】【后缀】五段按模板拼好，不预填格数、不逐格填景别运镜。技术信息行字段随当前风格声明卡定（电影写实/TVC = 景别/运镜；Vox = 信息/转场）。

**子步骤 4-0：道具/场景垫图（入口⑨选「有」才展开）**

- 道具/场景不是独立资产，只是 `image-prompt.md` 五段式里【道具参考】【场景参考】两段的可选输入，有才写、没有整段跳过。
- 道具图、场景图各自独立二选一（四种组合都成立）。
- 🔴 **核心机制**：agent 先建空节点占位（不填图、不生成、不等图），**图由老大之后手动上传，agent 不傻等**；建好节点继续往下走流程，不阻塞。
- 建节点前先查画布有无现成节点，有则复用、没有才建。
- 🔴 只在图片阶段用，视频阶段完全不看（视频侧不挂道具板/场景板）。

**子步骤 4-A：命名与占位符替换**

- 命名：**剧情概括（4\~8字）+ 故事板 + 两位编号**（01 起递增，只标当前编号不标总条数）；重生成时新名须与旧名明确区分。
- 加载 `image-prompt.md`，按当前风格声明卡「故事板版式指针」取后缀模板（电影写实按该条视角二选一、不混用；TVC 第三视角电影分镜版；Vox 平面分镜版），替换占位符 `[故事板名称]`、`[画面风格]`；`[镜头总数量]`、每格 `[景别]`/`[运镜]` **不预填**（模型自判）。各套模板带自己的负面框，按所选模板取用。
- 该名称同时作为图片文件名保存。

**子步骤 4-B：七维度检验、拼接并发送**

拼接前逐项核对剧情原文是否已含七个维度（场景/道具/光线/色彩/构图/摄影机/声音）——已有直接使用，缺失由 agent 按剧情语境补全。

- 🔴 **补全写法**：剧情叙述段**禁止维度标题行**（补全须自然融入叙述、写成连贯画面描述）；技术参数段允许维度标题行。判据：写「画面里发生了什么」禁标题行，写「生成技术规格」可用标题行。
- 补全后与台词合并，再拼上已替换占位符的后缀模板（正文见 `image-prompt.md`）发送，角色锚点图作为 reference 实际传入。
- 🔴 **模板逐字复用 + 回读比对**：模板从 `image-prompt.md` 原样复制，禁止凭印象复述、禁止缩写专名（「柘黄」不写「黄」）；拼完回读逐句核对，占位符只剩已替换的三处。
- ⚠️ 无时长要求时原文已有内容不得修改；有压缩需求则用压缩改编版。

步骤5：资产与分镜表统一确认（提交视频生成前的人工把关）

- 时机：故事板图已产出后、提交视频生成前。
- 打包三样：本条分镜设计表 + 已生成的故事板图 + 所引用的角色三视图（首条视频时一并展示）。
- 一次选项卡确认「确认无误 / 需要调整」，不逐项分问。需调整则修订后再次确认。
- 生成模式下强制执行；搭建模式不适用，但账本备注须写「搭建模式，步骤5 挂起」。

步骤6-A：生成音频（默认生成，规则见 `audio-prompt.md`）

**先加载** `audio-prompt.md`，提示词写法、音色固定口径、范例全部从该文件读，不得凭记忆写。音色引用的落地句式见 `reference-引用总表.md`「六、音色」。

- 只生成「生成音频的角色」的音频节点；龙套不进本步骤。
- 节点 `audio`，模型 `Seed Audio 1.0`；音频连视频用 `--left 配音`、`modeType=mixed2video`（`mixed2video` / `audio2video` 分工与完整链路见 `audio-prompt.md`「三、LibTV 画布落地」）。
- 账本登记音频节点 Key 与状态。

步骤6：生成视频（规则与示例见 `video-prompt.md`）

**先加载** `video-prompt.md`，按其中的固定格式、参考声明块、分镜时间轴、负面框、运镜规则、正确示例逐项落地，不得凭记忆写。

- 将该条故事板图节点 + 角色板图节点作为 reference 实际传入。分工：**故事板定构图、角色板定人物、视频提示词定动态**。
- 🔴 音色引用按 `video-prompt.md`「音色参考」段执行，声明句原文见 `reference-引用总表.md`「六、音色」（引固定 ID，禁止每出新视频重新生成）。
- 音频节点用 `--left 配音` 连入视频节点，`modeType=mixed2video`。
- 视频提示词必写的项（参考声明块、整体场景氛围、道具点名、@角色名、分镜时间轴、台词、环境音、实体性声明、皮肤去脏）**全部见** `video-prompt.md` **固定格式，逐字复用，此处不重复展开**。
