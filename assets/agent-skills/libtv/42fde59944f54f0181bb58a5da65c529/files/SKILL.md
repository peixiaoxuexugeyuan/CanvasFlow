# 东方幻境｜东方奇幻视觉提示词 Skill

版本：v1.1 适用范围：东方奇幻场景图、概念图、系列分镜图及其提示词优化

## 1. 任务目标

根据用户给出的场景、人物、动作和视觉意图，设计具体、可执行的东方奇幻图像提示词。工作重点是让主体、空间、光线、镜头和材质彼此支持，便于检查和逐步调整。

本 Skill 以四个视觉层为核心：场景、光影、镜头、材质。每次开始时另行明确“主体行动与画面意图”，因为四个视觉层本身不能替代叙事内容。

提示词可以降低构图、风格和连续性漂移，不能保证生成模型精确执行。图像比例、分辨率和模型等优先作为平台参数设置；只有平台要求时才写进提示词。

## 4. 四层视觉拆解

每层至少给一个明确锚点。只有会改变画面的信息才补充，不为达到词数而堆名词。

### 4.1 场景层：空间、结构与尺度

说明主体所在位置、空间如何延伸、重要地标和远景终点。建筑描述采用可见特征，不只写朝代标签：屋顶轮廓、梁柱结构、墙体材料、装饰母题和保存状态。

若用户指定朝代或地域，优先按其要求设计；若未指定，不自行默认唐风、宋风等。参考“唐风”时也要用结构与材料细节具体说明，避免混入不相容的建筑特征。

### 4.2 光影层：光源、环境光与空气

每幅图建立一个主要光线逻辑：

- 主光源：种类、方向、色温、落点及受光主体；


- 环境光：冷暖、范围、明暗层次；


- 空气效果：雨、雾、尘、水汽或体积光，说明它如何显出光路或空间层次。

“蓝绿冷调＋暖色焦点”是可选视觉预设，不是所有画面必用的规则。采用时要区分光源与受光表面：一个烛火可以同时照亮佛面和人物，不代表有两个暖光源。暖色焦点宜集中；若镜头要转移焦点，应在分镜计划中注明。

### 4.3 镜头层：景别、视角、构图与清晰范围

单张图明确一个主镜头：景别、机位高度和方向、主体位置、前中后景关系、焦点落点及景深。广角、长焦等词最好补充可见效果，例如“近处佛首显大、殿堂纵深向后展开”或“远处山门被压近主体”。

景深按画面用途决定：浅景深用于分离局部主体，深景深用于交代空间。若构图依赖门洞、佛龛或窗框，应说明框景的位置和主体在框内的关系。

### 4.4 材质层：主体、环境与空气细节

选择真正影响辨识度的材质锚点，并写清状态：潮湿石阶、剥落金漆、起翘木皮、斑驳铜绿、雨水沿檐滴落、积水映出灯火。可分别检查主体、环境表面和空气粒子，但无需机械地每类写满多个材料。

## 6. 系列镜头设计

默认不强制生成远、中、近、动四张。先根据叙事选择镜头功能，需要时可采用以下四种：

1. **空间建立图**：交代地点、尺度、气氛与主体位置；


1) **人物与空间关系图**：表现人物如何使用、穿越或受环境限制；


1. **细节或反应图**：突出关键道具、视线、表情或环境线索；


1) **动作关键帧/转场图**：截取动作受力、方向和环境响应清楚的瞬间。

系列图不必四种齐全，也可增加或合并。每张图要带来新的信息。所谓“运动镜”需说明是人物动作的关键帧、摄影机运动的视觉结果，还是两者兼有；静态图提示词描述的是动作瞬间，不是实际连续视频。

1. 全组视觉设定卡；


1) 分镜表：镜头功能、主体动作、景别/机位、构图焦点、局部光线/环境变化、与前后镜的联系；

1) 每张图对应的实际参考图与平台参数。

### 画内文字

默认避免无意生成的乱码、水印、字幕和界面元素。若用户需要匾额、石刻、符号或其他可读文字，按其要求保留，并明确文字内容、出现位置和可读程度；文字生成不稳定时提醒用户后期合成。

## 12. 使用边界与交付纪律

- 不使用“电影级、大片感、高级感、唯美”等词代替可见的构图、光线、材质和动作描述；用户若把它们作为风格意图，应翻译成具体画面结果。


- 不承诺模型必然生成指定细节；对文字、复杂手部、精确建筑和跨图一致性，必要时建议使用参考图或后期合成。


- 不擅自添加人物、朝代、宗教符号、道具或故事设定。


- 用户明确只要文字时，不调用图片生成；用户要求出图且当前环境有可用工具时，再按确认的提示词和参数生成。


- 最终说明哪些内容是用户设定、哪些是本次建议、哪些需要生成测试验证。
