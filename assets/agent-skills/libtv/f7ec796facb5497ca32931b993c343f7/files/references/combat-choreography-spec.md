# 打斗动作链规范（武戏强制项）

适用于武戏、追逐、近身冲突、法术／兵器交锋。**必须写成连续可信的动作链，禁止结果性概括**（如「两人大打出手，甲胜」「一番缠斗后乙被击倒」）。

## 一、动作链六段结构（每镜必写，可跨镜延续）

1. **起手式与意图**：本式由谁发起、用什么招式起手、意图是什么（试探距离／抢攻／格挡后退／拖住对方）。写清预备动作（沉肩、屈膝、抬臂角度）。
2. **攻防接触点**：击打或格挡落在哪个部位（小臂外侧、肩窝、膝侧、刀身中段），兵器接触的位置与角度（刀背相交约 30°、棍身中段横架），双方距离（半臂／一步／两步）。
3. **受力与物理反馈**：形变（衣袖被扯紧、兵器轻微弯曲或震颤）、位移（后退半步、身体侧旋 15°）、失衡（重心落到后脚、脚掌擦地）、尘屑飞溅、碎裂、衣物与发丝甩动方向、伤口血迹的形态与位置。
4. **重心与脚步衔接**：受力后重心如何转移、脚步如何补位（后脚蹬地回正、侧步绕开正面），写明落地脚与支撑脚。
5. **下一式过渡**：由上一式的结束姿态如何转成下一式的起手（借回正之力转劈、以受击偏移顺势转身），过渡不得跳帧式瞬移。
6. **收势或被打断**：本镜结束时的姿态（收式、僵持、被击中打断、被外力制止），要与下一镜的起手衔接得上。

## 二、力学与人体逻辑（硬约束）

- 发力链完整：蹬地 → 腰胯旋转 → 肩 → 肘 → 腕 → 器械／拳脚端，不得只写手臂挥动。
- 打击方向与受击者反应方向一致：正面推击使人后仰、斜劈使人侧偏旋转、下段扫击使人失衡下坐或跳起。
- 重量感与速度感匹配体型与武器质量：重兵器出手慢、惯性大、收势难；短刃快而幅度小。
- 受伤侧后续动作受限：右臂受击后右臂抬举幅度下降、呼吸变浅、重心偏向左侧保护，跨镜保持到伤愈或被处理。
- 同一镜头内不得出现违反惯性与关节朝向的姿态（肘膝关节反向、无支撑姿态悬停、重心悬空仍发力）。

## 三、空间逻辑（硬约束）

- 双方站位、距离、朝向在连续镜头间保持连贯；背景地标（门、柱、檐、树、摊铺）位置固定，不得在镜头间漂移。
- 守轴线：一场打斗确定一条主轴线（双方连线），同侧机位为主；越轴时用移动镜头完成过渡，或安排中性镜头，不得无理由跳轴。
- 兵器长度与攻击范围匹配距离：短刃必须贴身，长棍保持一步半；距离与兵器的矛盾视为不合格。
- 环境物件参与交互但不得凭空出现：只用场景锚点「可用打斗空间」列里登记的案几、栏杆、檐柱、街面净空等；物件被撞翻、碎裂、水花溅起后，在后续镜头中保持其变化状态。

## 四、镜头语言配合

- 写明景别切换节奏（如「近身接触用中近景与特写交替，每 0.8–1.2 秒切一次」）。
- 写明机位与运动：跟拍（贴身随动）、环绕（绕接触点 30°–45°）、低角度仰拍强化压迫感、手持微晃强化冲击。
- 写明动态模糊与快门感（快速挥击处带轻微运动拖影，接触帧锐利）、慢动作与正常速度的切换点（如「接触帧起 0.4 秒慢动作，随后回到正常速度」），以及剪辑节拍与打击帧对齐。
- 写明光线在快速运动中的变化（穿廊而过时从檐下阴影进入日光，兵器表面高光随之扫过）。
- 光效不得为追求冲击而破坏既定光线基准与色彩分级。

## 五、节奏分层（一场打斗必拆四段）

| 节拍 | 内容 | 强度 | 镜头密度 | 单镜时长倾向 |
|---|---|---|---|---|
| 试探 | 试探距离、起手被格挡，双方评估对手 | 低 | 稀（1 镜约 2–3 秒） | 5–7 秒 |
| 升级 | 招式加快、器械或身形被压制，第一次出现实质接触 | 中 | 中 | 4–6 秒 |
| 高潮 | 决定性交手，接触帧密集，出现失衡或受伤 | 峰值 | 密（0.8–1.5 秒切一次） | 3–5 秒 |
| 收束 | 一方落败／被制止／僵持收势，情绪余波 | 低至中 | 由密转稀 | 5–8 秒 |

要求：不得全程同强度堆砌；每段在分镜表「节拍段落与强度」列明确标注。

## 六、打法与角色匹配

- 每个角色的攻防方式必须匹配角色锚点「武技风格与身形条件」列：擅短刃者贴身快攻，身形壮者以压制与抱摔为主，不会武者只做躲避、护头、后退与呼救。
- 同一角色跨场打法保持一致，不得换角色打法；升级只能体现在速度、力度与招式组合上。

## 七、信息不足时的补全规则

- 剧本未写清具体招式时，允许在符合人物设定与宋代兵器形制（朴刀、棍棒、短刃、弓弩、锏鞭等）的前提下补全动作链。
- 补全不得改变剧情结果与胜负走向，不得新增角色、不得新增武器、不得改变场景地点。
- 补全的动作链要在分镜表备注中标明「补全」，便于用户查核。

## 八、示例（通用示例，非具体剧情）

```
动作链：起手式为示例·游侠（非本剧角色）左脚前踏半步、右手短刃反持于腰侧，意图抢近身切入；对手以木棍横架，棍身中段与小臂外侧相碰约 30° 夹角，距离由两步缩至半臂；受力后棍身震颤、木屑自接触点飞出，游侠右臂被荡开使上身侧旋约 15°，后退半步以左脚掌擦地止住，重心落到后脚；随即借回正之力沉肩转劈，过渡至下一式；本镜结束于双方僵持、短刃被棍身压住一瞬。
镜头节拍：接触帧起 0.4 秒慢动作，随后回到正常速度；近身接触处以中近景与特写交替，手持微晃，快速挥击处带轻微运动拖影，接触帧锐利；穿檐下时从阴影进入日光，刃面高光随之扫过。
```

## 九、反例说明（一律判不合格）

| 反例写法 | 为什么不合格 | 改法 |
|---|---|---|
| 「两人激烈打斗」 | 结果性概括，无动作链 | 按六段结构逐段写起手、接触点、受力、重心、过渡、收势 |
| 「他一拳把对方打飞出去」 | 违反力学与重量感，无接触点与重心衔接 | 写接触部位、受力方向、后仰与退步、支撑脚的调整 |
| 上一镜兵器在左手、下一镜在右手 | 违反空间与连续性逻辑 | 全链统一持械手，换手需写明动作过程 |
| 短刃在与长棍一步半的距离互砍 | 兵器长度与距离矛盾 | 改为贴身切入，或换兵器与距离匹配的招式 |
| 全程同一节奏的高强度混战 | 违反节奏分层 | 拆成试探—升级—高潮—收束，标注强度与镜头密度 |
| 右臂被砍伤后下一镜右臂高举格挡 | 违反受伤侧限制 | 改为左臂格挡、右臂下垂、重心偏左保护 |
