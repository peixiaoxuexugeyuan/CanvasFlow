# 风格锚与画面质感规范

## 一、固定风格锚（逐字复制，不得改写）

```
宋代高质量国风3D动漫电影风格，电影级3D角色建模，3D render，Unreal Engine 质感，PBR 材质，写实皮肤次表面散射，国漫3D CG电影质感
```

使用位置：所有图片提示词的第一段、所有视频提示词的第一段（作为前置风格锚）。

禁止：删减词条、调换顺序、替换为水墨／2D 平涂／赛璐璐／美式写实／日式动漫等其他风格词。

## 二、风格锚之后按镜头需要补充的质感词（选 2–4 条，不要堆砌）

- 电影级体积光、丁达尔光柱
- 次表面散射皮肤，毛孔与绒毛级细节
- 布料纤维与褶皱物理模拟
- 木作与漆器高光反射、磨损边缘（PBR roughness 变化）
- 瓦作与青石地面湿润反射
- 微尘颗粒与空气介质
- 浅景深，真实镜头虚化（bokeh）
- 电影级色彩分级（LUT），宋韵低饱和青绿／赭石／月白

写明实皮肤次表面散射时，务必将血色变化与汗光、泪膜反光写在同一处，以免面部质感描述被拆散（详见 `expression-and-action-spec.md`）。

## 三、全局负面词（图片与视频提示词结尾统一追加）

```
低模，卡通平涂，2D，贴图模糊，手部畸形，多指，脸部崩坏，五官错位，塑料感皮肤，过曝，死黑，畸变，水印，文字，字幕，logo，现代元素（电线、柏油路、塑料制品、现代服饰），欧美面孔，日式动漫脸，噪点，压缩伪影
```

## 四、朝代与地域硬约束（宋代）

- 服饰：圆领袍／直裰／襦裙／褙子／半臂，交领右衽，幞头／东坡巾／花冠，皮革与棉麻为主。
- 器物：影青瓷、汝窑天青、漆器、竹木家具（不作为单独道具图，只作为场景陈设与角色随身细节）。
- 建筑：木构架、歇山顶、飞檐、直棂窗、格子门、影壁、天井。
- 街景：青石板、幌子旗招、瓦舍勾栏、灯笼、摊铺。
- 兵器：须符合宋代形制（朴刀、棍棒、短刃、弓弩、锏鞭等）；不得出现明清及以后形制，也不得出现与宋代无关的奇幻机关兵器。
- 禁止出现明清及以后器物与建筑形制（玻璃器、西洋楼、长辫、马褂等）。
- 地域特征按剧本实际地点写（如汴京市井、江南水乡、山野村落、府邸宅院），不确定时以宋代市井／宅院通用特征描述，不虚构与剧情无关的地点。
