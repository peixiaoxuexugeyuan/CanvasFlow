# 角色锚点提取模板

角色清单在运行时从剧本正文提取，不预置名单。每个角色一行，编号一经确定不得变动；后续分镜与视频提示词只引用编号，不重写外貌。

## 二、字段填写规范

- **角色ID**：`char-01`、`char-02`……按首次出场顺序编号，全剧唯一，不得复用、不得变更。
- **姓名**：剧本中的姓名；同一角色的不同称呼合并到同一行，在「姓名」栏写主名并用括号列出别名。
- **身份／阶层**：官／商／农户／仆役／僧道／军士等，含其在剧中可识别的社会层级。
- **年龄段**：写具体区间（如 28–32），不写「年轻」「中年」这类模糊词。
- **体态身高**：高矮胖瘦、肩宽、体态特征，用可画出的描述。
- **脸型与五官**：脸型、眉形、眼型、鼻型、唇形、肤质与肤色（写实皮肤次表面散射），特征点（痣、疤、胡须）。
- **发型与头饰**：发式、发色、头饰形制与材质，须符合宋代（幞头／东坡巾／花冠／发簪等）。
- **服色与形制**：主色与辅色的色名（月白、赭石、青绿、藕荷等）、衣形（圆领袍／褙子／襦裙等）、领口形制、纹样。
- **材质与随身细节**：布料材质（棉麻、绢、皮革）、磨损状态、随身可见物件（写文字描述，不出道具图）。
- **标志性微表情**（新增，必填）：该角色最具辨识度的 2–3 个面部反应，写到可渲染层级，如「惊讶时右侧眉峰先挑起、下颌微张半秒」「被戳穿时瞳孔骤缩、咬肌鼓起后立刻松口」。全剧所有镜头的情感表演以此为基准复用。
- **习惯性小动作**（新增，必填）：反复出现的身体小动作，如「说话前以拇指摩挲掌心」「思量时食指轻叩案面两下」「紧张时右手捏住袖口」。分镜中应自然复用，不得每镜换一套。
- **武技风格与身形条件**（新增，必填）：会武者写擅长打法（如「短刃近身快攻，步法碎而緊，靠贴身上步压制」）与身形条件（臂展、腿功、体能上限）；不会武者写「无武技，遇袭时以躲避、护头后退与呼救为主反应」。分镜中的攻防动作必须与此列匹配，不得换角色打法。
- **气质与表演基调**：整体气场与表演方式（如「外憨内精，动作慢半拍，眼神先到」）。
- **标志性细节**：一眼可认出该角色的 1–2 个视觉记号。
- **定妆图提示词**：完整可执行提示词，必须以固定风格锚开头，结尾追加全局负面词。

## 四、出图规范

- 每个角色 1 张定妆图；主角经审批通过后可追加 1 张情绪特写，其他角色不加。
- 构图：三视图或半身立绘，人物居中，中性表情，纯色或极简背景，不带环境光效干扰。
- 一致性：定妆图一经审批通过即锁定为后续所有镜头的角色参考图，不得重出替换。
- 「标志性微表情」「习惯性小动作」不进入定妆图提示词（定妆图保持中性表情），仅在阶段三、阶段四复用。
