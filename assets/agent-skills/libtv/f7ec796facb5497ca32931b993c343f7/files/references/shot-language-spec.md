# 镜头语言与提示词规范

## 一、视频提示词模板（每镜一条）

```
[风格锚]，[景别]，[机位与视角高度]，[运镜]，[等效焦距与景深]，[光线设计]，[场景与陈设：引用场景锚点]，[表演：角色锚点引用 + 微表情层 + 肢体层]，[材质与物理反馈]，[氛围与色温]，[画幅与帧率]，[结束状态]，[全局负面词]
```

武戏镜头在「表演」之后插入：

```
[动作链：起手式与意图 → 攻防接触点 → 受力与物理反馈 → 重心与脚步衔接 → 下一式过渡 → 收势或被打断]，[镜头节拍：慢动作/正常速度切换点、动态模糊、剪辑节拍与打击帧对齐]
```

写作要求：必须是分镜级镜头语言，禁止写成剧情概括（如「两人争吵」这类）。每镜至少写满 8 个要素；**表演段必须同时含微表情层与肢体层（见 `expression-and-action-spec.md`），武戏必须含动作链（见 `combat-choreography-spec.md`）**。

## 二、要素词库

- **景别**：大远景／远景／全景／中全景／中景／中近景／近景／特写／大特写。
- **机位与视角高度**：贴地仰拍、腰高平视、胸高平视、过肩、越肩、俯拍、顶拍、视点镜头（POV）、正反打。
- **运镜**：固定机位；缓推（dolly in）／缓拉；横移跟拍（tracking）／侧跟；环绕（orbit，15°–45°）；摇镜（pan／tilt）；升降（crane up／down）；手持微晃；斯坦尼康稳定跟随；焦点转移（rack focus）；甩镜转场。写明运镜的起始位置、路径与终止位置。
- **焦段与景深**：等效 18–24mm（环境纵深）、35mm（常规叙事）、50mm（人物关系）、85mm（面部情绪）、135mm（压缩背景）；写清浅景深或深景深及焦点落点。
- **光线设计**：主光方位与色温、辅光比例、轮廓光勾边、体积光／丁达尔、实用光源（灯笼、烛火、窗格光）、明暗对比与阴影落点、日夜色温基准（日戏 5200–6000K，夜戏 2600–3200K 实用光源）。
- **表演（微表情层 + 肢体层）**：不再单列「表演细节」简写；直接写两层，词库与模板片段见 `expression-and-action-spec.md`。禁止写对白与语音。
- **材质与物理反馈**：布料褶皱与飘动方向、发丝与配饰摆动、皮肤次表面散射与汗光、木质与漆器反光随视角变化、地面水渍与泥点、雨丝、微尘、水汽、炊烟、纸页与帘幕的物理形变。
- **动作链（武戏专用）**：见 `combat-choreography-spec.md` 六段结构。
- **氛围与色温**：空气介质、颗粒感、色彩分级倾向（宋韵低饱和青绿／赭石／月白／暖褐）。
- **画幅与帧率**：默认 9:16 竖屏、24fps 电影感（或平台要求的帧率）；镜头运动速度写清（缓／中速／快）。
- **结束状态**：镜头结束时的画面定格状态（人物位置、视线、情绪残留、身体姿态），便于顺接下一镜；武戏镜头须写明收势姿态或僵持状态。

## 三、禁止项

- 不写对白、旁白、语音、口型念白（不发音频，也不需要为配音预留口型时长）。
- 不写音效、配乐、环境音描述。
- 不重新描述角色外貌（外貌只在角色锚点里定义），只写动作与表演。
- 不写道具特写镜头作为独立镜头目的（道具只作为陈设或随身细节出现在画面里）。
- 不用情绪名词替代微表情层与肢体层；不用结果性概括替代动作链。

## 四、合格示例（通用示例，非具体剧情）

```
宋代高质量国风3D动漫电影风格，电影级3D角色建模，3D render，Unreal Engine 质感，PBR 材质，写实皮肤次表面散射，国漫3D CG电影质感，中近景，机位腰高平视略偏人物右肩，斯坦尼康缓慢横移跟拍，等效 50mm 浅景深（焦点落在人物眼部），主光为左前方格子窗透入的漫射日光（约 5600K），右侧灯笼暖光作辅光（约 2800K），人物后侧有暖色轮廓光勾边，场景为宋代宅院正堂（引用 scene-01），实木柱与直棂窗、漆案与影青瓷茶盏在光下呈现高光与磨损边缘，人物（引用 char-01）从案侧起身，微表情层：眉头先紧锁再松开半拍，上眼睑垂落至遮住三分之一瞳孔后猛地抬起，瞳孔骤缩，鼻翼翕动两下，唇角下压后被抿住，咬肌鼓起又松口，胸口起伏变浅并屏住一拍，面颊血色先褪白再涨红至耳根，鼻尖泛起薄汗并有次表面散射反光；肢体层：右手五指收拢攥紧袖口，指节泛白，肩线先向门口转去，脊背微含，重心由后脚掌前移到前脚掌又硬生生停住，衣袖因余力轻晃两下，发间配饰有轻微延迟摆动，节奏为「骤停」；与 char-01 标志性微表情与习惯性小动作一致；材质与物理反馈：布料随起身产生自重褶皱并缓慢回落，漆案表面反光随视角扫过；空气中有细尘颗粒在光柱里浮动，整体低饱和青绿与暖褐分级，9:16 竖屏，24fps，横移速度中缓，结束时人物停于案侧半转身、视线停向门方向，全局负面词……
```

## 五、图片提示词规范

- 结构：风格锚 + 主体描述（角色锚点字段或场景锚点字段） + 构图与机位 + 光线 + 材质质感 + 氛围 + 全局负面词。
- 角色定妆图：三视图或半身立绘，中性表情，纯色或极简背景。
- 场景概念图：空镜构图，保留可调度空间，不安排主角居中。
- 每张图都必须以风格锚开头，缺风格锚即重写。
- 图片不承载微表情层与动作链（定妆图保持中性表情，场景图为空镜）；两层只在阶段四的视频提示词中强制。
