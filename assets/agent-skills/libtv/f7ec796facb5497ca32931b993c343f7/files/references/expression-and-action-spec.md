# 微表情层与肢体层规范（视频提示词强制项）

任何有角色的镜头，视频提示词都必须同时写入「微表情层」与「肢体层」。**只写情绪名词（如「他很愤怒」「神情悲伤」「十分焦急」）视为不合格产出，必须重写重跑。**

## 一、判定标准（可检查）

一条合格的表演描述必须同时满足：
1. 点名具体**面部部位**（眉、眼睑、瞳孔、鼻翼、嘴角、咬肌、下颌、喉结、胸口）与它们的**变化方向与幅度**；
2. 点名具体**身体部位**（指节、手腕、肩、颈、脊背、腰胯、膝、脚掌）与**重心位置**；
3. 写明**时间性**：变化发生的时刻与节奏（如「台词前半秒」「骤停」「持续颤抖两下」）；
4. 写明**与动机的对应**（该镜的台词情绪或剧情动机）；
5. 与角色锚点的**表演基调、标志性微表情、习惯性小动作**一致。

任一条缺失，即视为不合格。

## 二、微表情层词库（面部）

- **眉与额**：眉峰单侧上扬／下压、眉头紧锁出现竖向皱褶、额肌放松、眉毛轻微抽动。
- **眼与眼睑**：眼睑垂落幅度（半垂、全垂、快速眨动）、睑裂变窄、瞳孔收缩／放大、眼球向侧下方游移、眼神聚焦点从人脸移到地面、眼眶发红、泪膜反光与泪珠将落未落、下眼睑细纹与卧蚕收紧。
- **鼻**：鼻翼翕动（吸气时机与频率）、鼻梁皮纹收紧、抽鼻吸气。
- **口与咬肌**：抿嘴、唇角单侧上扬或下压、抿唇后松开、咬肌鼓起、下颌紧绷、下唇被轻咬、张嘴欲言又止、喉咙吞咽。
- **呼吸**：胸口起伏变浅或变深、吸气屏住（胸腔扩张后静止）、长吐气使肩线落下。
- **血色（与写实皮肤次表面散射同写）**：面颊涨红并透出皮下血色、嘴唇褪色发白、额头与鼻翼泛起薄汗且反光、脖颈青筋浮起、颧侧血色随情绪回升。
- **不对称**：一侧嘴角／一侧眉峰先动，左右脸情绪不同步（真实人脸特征）。

## 三、肢体层词库（身体与重心）

- **手势与指节**：指节发白地攥紧、手指张开又收拢、拇指摩挲掌心或器物边缘、食指轻叩、掌心贴住案面支撑、手臂垂落无力的摆动幅度。
- **肩颈**：双肩耸起、肩线下沉、一侧肩先转向门口、颈部僵硬地保持不动、微微缩颈。
- **脊背**：脊背挺直到发僵、上身前倾的角度变化、含胸后退、腰背后仰。
- **重心与脚步**：重心前移到前脚掌、后撤半步、脚跟在原地碾动、止步时脚尖外撇、猛然起身使椅凳后移。
- **跟随物**：衣袖随手臂动作的滞后摆动、下摆随转身甩出的弧线、发丝与发饰的延迟晃动、腰间系带摆动。
- **节奏**：迟疑（动作起手后停顿一拍）、爆发（瞬间提速、幅度大）、骤停（动作到一半硬生生止住、余力使身体轻晃）、颤抖（幅度小、频率高、逐渐衰减）。

## 四、提示词模板片段（可直接嵌入）

```
微表情层：{眉／额}，{眼睑与瞳孔}，{鼻翼}，{嘴角与咬肌／下颌}，{呼吸起伏}，{写实皮肤次表面散射下的血色变化（涨红／煞白／薄汗反光／青筋）}；
肢体层：{手势与指节}，{肩颈与脊背}，{重心转移与脚步}，{衣袖与发丝跟随摆动}，动作节奏为{迟疑／爆发／骤停／颤抖}，动作起于{时刻}止于{时刻}；
与角色锚点一致：延续 {char-XX} 的标志性微表情（{锚点值}）与习惯性小动作（{锚点值}）；
表演依据：本镜台词情绪为{…}，动机为{…}。
```

## 五、示例（通用示例，非具体剧情）

```
微表情层：眉头先紧锁再松开半拍，上眼睑垂落至遮住三分之一瞳孔后猛地抬起，瞳孔骤缩，鼻翼快速翕动两下，唇角先下压再被抿住，咬肌鼓起又松口，胸口起伏变浅并屏住呼吸一拍，面颊血色先是褪白随即涨红至耳根，鼻尖与额角泛起薄汗并有次表面散射反光；
肢体层：右手五指收拢攥紧了袖口，指节泛白，左侧肩线先向门口转去，脊背微含，重心由后脚掌前移到前脚掌并微微离地，未及迈出又硬生生停住，衣袖因这半途而止的动作余力轻晃两下，发间素簪随转头有轻微延迟摆动；动作节奏为「骤停」；
与角色锚点一致：延续 char-01 的「被戳穿时瞳孔骤缩、咬肌鼓起后立刻松口」与「紧张时右手捏住袖口」；
表演依据：本镜为被当面指出隐瞒之事的一刻，情绪由心虚转为惊怒，动机是先掩饰再反扑。
```

## 六、反例说明（一律判不合格）

| 反例写法 | 为什么不合格 | 改法 |
|---|---|---|
| 「他非常生气」 | 只有情绪名词，无可渲染部位与幅度 | 写眉峰下压、眉头皱褶、咬肌鼓起、下颌紧绷、颈侧青筋、重心前移、指节攥白 |
| 「她很伤心地哭了」 | 无眼睑／泪膜／呼吸／身体细节，且未写节奏 | 写眼睑垂落、下眼睑细纹收紧、泪膜反光将落未落、鼻翼抽动、肩线塌落、胸口起伏加深 |
| 「害怕地后退」 | 未写重心、脚步、跟随物 | 写重心后移、脚跟先着地再碾半步、上身含胸、衣袖与下摆向后飘、双手抬高护住胸口 |
| 「演技自然一点」 | 不可渲染、不可检查 | 换成具体部位级描述 |
| 同一角色在不同镜头里每次表达方式都不同 | 违反角色一致性 | 以角色锚点的标志性微表情与习惯性小动作为基准复用，只在强度上变化 |

## 七、一致性复用规则

- 全剧同一角色表达同类情绪时，基准动作来自角色锚点「标志性微表情／习惯性小动作」两列，只允许强度差异（轻／中／强），不允许换一套动作。
- 微表情与肢体动作的强度要与镜头景别匹配：特写侧重微表情层，中全景侧重肢体层与走位，两者都要写，只是详略侧重不同。
- 对白不进入提示词，但**台词情绪是表演依据**：分镜表的「画面内容」里保留台词要点，用于推导表演，不生成音频。
