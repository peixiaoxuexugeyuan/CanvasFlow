# 宋代国风 3D 短剧制作流水线

把一份古装剧本（以宋代为基准）做成 S 级国风 3D 动漫短剧成片。全流程六阶段、单一账本、逐批审批。

## 一、适用与不适用

**适用**

- 画布上有完整剧本（文档节点或文本节点，可含多集），需要成套产出角色定妆图、场景概念图、分镜表、逐镜视频提示词与镜头视频。
- 剧本为古代题材。若目标朝代不是宋代，只把风格锚中的朝代词替换为目标朝代，其余规范不变。

**不适用**

- 只要单张图或单条视频（直接生成即可，不要跑本流水线）。
- 需要配音、旁白、对白配音、音效或配乐（本流水线不含任何音频环节）。
- 需要道具资产图（本流水线锚点只有「角色」与「场景」两类）。

## 二、固定风格锚（前置风格锚，逐字复制）

```
宋代高质量国风3D动漫电影风格，电影级3D角色建模，3D render，Unreal Engine 质感，PBR 材质，写实皮肤次表面散射，国漫3D CG电影质感
```

使用规则：

- 所有图片提示词、所有视频提示词，**必须以该风格锚作为开头第一段**，逐字复制，不得删减词条、不得调换顺序。
- 风格锚之后接具体内容；质感词、负面词、朝代约束见 `references/style-anchor.md`。

## 三、硬性红线（违反即重做）

 1. **风格锚固定**：任何图片或视频提示词缺少风格锚，视为不合格产出，重写重跑。
 2. **不出配音**：不创建任何 TTS／配音／旁白／对白音频节点，提示词中也不写对白、语音、说话内容需求（对白只作为分镜表的剧情依据，不进入视频提示词）。
 3. **不出音效**：不创建音效、配乐、环境音节点，成片不带音频轨。
 4. **不出道具资产图**：锚点集只有「角色锚点」与「场景锚点」。剧本中的道具（信物、首饰、兵器、食器、文书、钱币等）写进场景陈设或角色随身细节的文字描述，不单独出图、不建节点。
 5. **场景不遗漏**：剧本中出现过的每个场景（含过场、回忆、梦境、幻觉、同地点不同时段的日夜戏）都要进入场景清单，并逐一产出概念图。
 6. **锚点一致**：分镜表与视频提示词只引用锚点（anchor_key），不重新描述角色外貌、不另造造型；同一角色在全剧所有镜头中形象保持一致。
 7. **无审批不跑批**：任何批量生成之前必须取得用户审批。
 8. **账本即时回填**：每完成一个节点立即回填账本；账本是断点续跑的唯一依据。
 9. **微表情层与肢体层强制**：有角色的镜头，视频提示词必须同时写入「微表情层」与「肢体层」，两层都落到可渲染的细节；**只写情绪名词（如「他很生气」「表情悲伤」）视为不合格，重写重跑**。规范与词库见 `references/expression-and-action-spec.md`。
10. **表演与动机一致**：微表情与动作必须与台词情绪、剧情动机一致，并延续角色锚点中登记的表演基调、标志性微表情与习惯性小动作；同一角色跨镜不得性格漂移。
11. **武戏必须写动作链**：凡武戏、追逐、近身冲突、法术／兵器交锋，必须写成「起手—接触—受力反馈—重心衔接—过渡—收势／被打断」的连续动作链，**写成结果性概括（如「两人大打出手，甲胜」）视为不合格**。规范见 `references/combat-choreography-spec.md`。

## 四、六阶段流水线

### 阶段一 剧本通读与拆解

1. 定位画布上的剧本节点（文档节点或文本节点），取到可读取的正文。
2. 用 read_file_v2 读取，单次上限 20000 字；超限则分段读取，**每段不超过 2 万字**。
3. 按「集」切块：优先以分集标题/集号为边界，一集被截断时以集数边界为准续读下一段，禁止跳读、抽样、跳过任何一集。
4. **必须读到剧本末尾并覆盖全部分集**（本剧为 70 集）。读完后自检：已读集数是否连续无缺口；有缺口就补读。
5. 产出「集索引表」，逐集一行，字段：集号 → 出场角色 → 场景 → 关键事件 → 关键台词 → 情绪基调 → 建议镜头数。模板见 `references/tables-and-ledger.md`。
6. 拆解时同步标记**武戏标记**：该集是否含打斗／追逐／冲突，若有则记下参与者、地点、胜负与结果走向（作为阶段三武戏动作链与节拍分层的依据；胜负走向不得改动）。
7. 拆解结果即时回填账本；用户要求时先把集索引表展示出来再进入下一阶段。

### 阶段二 锚点集（角色 + 场景，不含道具）

先汇总去重，再出图。

**汇总规则**

- 角色总表：全剧出现过的所有角色，含只出现一次的次要角色与群像主要个体；合并同一角色的不同称呼（本名、昵称、身份代称）。
- 场景总表：全剧出现过的所有场景。**同一地点在不同时间/天气/季节下视为不同场景项**（例如「宅院正堂·日」与「宅院正堂·夜雨」是两项）。
- 两个总表分别按 `references/character-anchor-template.md`、`references/scene-anchor-template.md` 的字段规范填写，缺字段视为未完成。
- 角色总表必须填写新增字段：**标志性微表情**、**习惯性小动作**、**武技风格与身形条件**。前两项供全剧微表情与动作一致性复用；第三项供武戏动作匹配该角色打法（不会武的角色写「无武技，遇袭时以躲避与呼救为主反应」）。

**命名与关键值**

- 角色 anchor_key：`char-01`、`char-02`……按首次出场顺序编号，编号一经确定不得变动。
- 场景 anchor_key：`scene-01`、`scene-02`……按首次出场顺序编号，不得变动。

**出图规则**

- 角色定妆图：每个角色 1 张。提示词 = 风格锚 + 角色字段（外形、年龄、服饰、气质、身份）+ 三视图或半身立绘 + 中性表情 + 纯色或极简背景。主角经审批通过后可追加 1 张情绪特写，其他角色不加。
- 场景概念图：每个场景项 1 张。提示词 = 风格锚 + 场景字段（时间、天气、光照、空间结构、陈设、材质、氛围、地域特征）+ 空镜构图（不安排主角居中，避免锁死人物位置）。
- 出图完成后，把每张图的节点 key 与其 anchor_key 绑定并回填账本。

### 阶段三 分镜表

每集一张分镜表，字段：

镜号 | 时长 | 景别 | 机位与视角 | 运镜 | 焦段与景深 | 光线设计 | 出场角色(anchor_key) | 场景(anchor_key) | 画面内容 | 微表情层 | 肢体动作层 | 动作链与物理反馈 | 节拍段落与强度 | 转场

约束：

- 单镜时长 3–8 秒，默认 4–6 秒；过长表演拆成两镜。
- 单集镜头数 12–20 镜，单集成片 60–120 秒。
- 每镜必须至少绑定 1 个场景锚点；有角色的镜头必须绑定对应角色锚点。
- **有角色的镜头，微表情层与肢体动作层均为必填**；只写情绪名词的行视为未完成，需重填。
- **武戏镜头，动作链与物理反馈为必填**；非武戏镜头在该列填「—」。动作链要求见 `references/combat-choreography-spec.md`。
- **武戏需按节拍分层**：一场打斗拆成「试探—升级—高潮—收束」四段，逐段标注强度（低／中／高／峰值）与镜头密度（镜/秒），避免全程同强度堆砌；节拍表填写见 `references/tables-and-ledger.md`。
- 同一场景的连续镜头尽量排在同一批，便于一致性。
- 分镜表模板见 `references/tables-and-ledger.md`。

### 阶段四 视频提示词撰写

每镜一条视频提示词，模板：

```
[风格锚]，[景别]，[机位与视角高度]，[运镜]，[等效焦距与景深]，[光线设计]，[场景与陈设：引用场景锚点]，[表演：角色锚点引用 + 微表情层 + 肢体层]，[材质与物理反馈]，[氛围与色温]，[画幅与帧率]，[结束状态]
```

武戏镜头在「表演」之后插入一段：

```
[动作链：起手式与意图 → 攻防接触点 → 受力与物理反馈 → 重心与脚步衔接 → 下一式过渡 → 收势或被打断]，[镜头节拍：慢动作/正常速度切换点、动态模糊、剪辑节拍与打击帧对齐]
```

要求：

- 是分镜级镜头语言，不是剧情概括。必须写清景别、机位、运镜路径、等效焦段、光线设计（主光/辅光/轮廓光/体积光方向与色温）、氛围、材质与物理反馈（布料褶皱与飘动、发丝、木质反光、水汽与微尘）。
- **微表情层**必须落到可渲染的面部细节（眉眼、瞳孔、鼻翼、嘴角与咬肌、下颌、呼吸起伏、汗珠与泪膜反光、面部肌肉不对称），并写出写实皮肤次表面散射下的血色变化（涨红、煞白、青筋）。
- **肢体层**必须写到身体部位级动作与重心（手势与指节、肩颈、脊背、重心转移、脚步与地面接触、衣袖与发丝跟随摆动），并写明动作起止与节奏（迟疑、爆发、骤停、颤抖）。
- 两层词库、合格示例与反例说明见 `references/expression-and-action-spec.md`；武戏动作链规范见 `references/combat-choreography-spec.md`；镜头词汇库见 `references/shot-language-spec.md`。提示词结尾统一追加全局负面词。
- 不写对白、不写语音、不写音效、不写配乐。

### 阶段五 分批生成与审批

1. 先跑 1 镜样片：用定妆图与场景图作参考，生成首个镜头视频，交用户确认风格与一致性。样片优先选**有微表情与肢体动作的日常戏镜头**，另加 1 镜武戏样片确认动作链表现（该镜同样需要审批）。
2. 样片通过后分批推进，**每批不超过 6 镜**，优先把同场景镜头归入同批；同一场打斗的连续镜头尽量同批，避免动作衔接断裂。
3. 每批运行前，用审批卡（approve_run_node_once）列出该批全部待运行节点的 node_key，取得审批后再跑；未审批不得运行。
4. 视频生成必须引用角色定妆图与场景概念图节点作为参考，保证锚点一致性；不重新生成角色、不换装、不换脸。
5. 每镜生成完立即回填账本（节点 key、时长、模型、状态、批次）。

### 阶段六 合成成片

- 按镜号顺序拼接全部镜头，统一画幅、帧率、色彩分级。
- 成片不包含任何音频轨（不加配音、不加音效、不加配乐）。
- 输出成片视频节点，账本标记该集/全剧为「完成」。
- 若用户只要部分集数，按用户指定的集范围合成，其余集保留在账本中待续。

## 五、模型与参数选择约束

- 图像模型：需支持参考图输入（角色一致性）、长边 ≥2048px、能呈现写实 PBR 与次表面散射质感。默认 {{image_model}}；用户指定则按用户指定。
- 视频模型：需支持首帧/参考图输入、可生成 3–8 秒单镜、1080p 及以上、能响应镜头运动与光线描述；武戏镜头优先选择对快速动作与动态模糊响应更好的模型。默认 {{video_model}}；用户指定则按用户指定。
- 画幅默认 9:16 竖屏（短剧平台），可按用户要求改 16:9。
- 同一部剧内，模型与画幅一经确定不得中途更换；必须更换时，从该集第一个镜头重跑并记录原因。
- 全片保持同一色彩分级与光线基准，夜戏与日戏用光线色温区分，不靠整体调色区分。

## 六、账本回填（强制执行）

账本字段：镜号 | 所属集 | 角色 anchor_key | 场景 anchor_key | 角色图节点 key | 场景图节点 key | 视频节点 key | 使用的视频提示词 | 时长 | 模型 | 批次 | 审批状态 | 状态 | 备注

规则：

- 每完成一个节点立即回填，不得批量补录。
- 断点续跑一律从账本读起点，不凭记忆重跑。
- 重跑某镜时覆盖该行，并在备注写明重跑原因（如「微表情层缺失，重写重跑」「动作链违反重心逻辑，重跑」「锚点不一致，重跑」）。
- 集索引表、锚点总表与武戏节拍表同样计入账本，作为后续阶段的输入基线。
