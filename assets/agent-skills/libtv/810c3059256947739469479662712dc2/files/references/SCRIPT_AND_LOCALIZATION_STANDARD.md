# 剧本接收与逐事件对齐

按主文件5.1–5.6执行。上传分次追加保序，用户声明结束后展示范围/说话人/对白数并确认。B必须确认具体目标语言和地区语体，WESTERN只是风格；C确认JP/KR与关系；D保留转绘剧本语言及地方话。

完整剧本按场景/台词ID记录；每个视频明确对应剧本范围与进度，不能按对白数量把不相关句子硬配在一起。源有D而目标剧本无对应句时报告差异，不删除源事件或借邻句；目标剧本多句时不静默补入无源D镜头。

| 模式 | 对齐与数量检查 |
| --- | --- |
| STRICT | 源SH/D父事件ID→制作事件；目标文字来自对应批准剧本，数量和存在性守恒 |
| USER_MODIFIED | 用户批准增删清单，保留源RAW锁值，另锁制作TARGET计数，允许有批准依据的无源新增D |

文字与窗口不匹配时提出保留事实的口语压缩、节奏调整或明确改时长方案，等用户批准新版本。D逐字合同下不能直接压缩，需先批准目标剧本修订。任何数量变更均保留理由及事件映射。

源骨架与目标剧本动作/场景不相容时先报告，按目标锚点检查空间功能映射；不能以“剧本最高优先”静默改源结构，也不能以“保留源骨架”带回源场景内容。镜头/台词/表演分别批准。C细则见[日韩](JP_KR_LOCALIZATION_STANDARD.md)，D见[中文转绘](CN_STYLE_PROFILE_STANDARD.md)。
