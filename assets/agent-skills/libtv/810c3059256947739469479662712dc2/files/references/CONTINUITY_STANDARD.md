# 连续性类型与可追溯派生资产

按主文件第8、14节。存在上一段视频不自动等于空间直连，先依据源切换、目标剧本与接受版判定：

| CONTINUITY_MODE | 继承 | 不强制继承 |
| --- | --- | --- |
| DIRECT | 适用角色位置/动作相位/视线/持物/空间关系与光色 | 用户批准改编的字段另记差异 |
| CUT | 同场适用身份/服装/道具/空间关系与光色 | 原摄影机位置、构图与屏幕左右必须相同 |
| RESET | 已明确复用的身份/道具及全片风格 | 前段站位、前段连续性色卡、原场景光照 |

DIRECT/CUT必须有真实前段接受版色卡；D只采目标转绘成片。RESET记录换场/跳时等依据，不套前段色卡；新场景影调读批准新锚点。全片统一影调参考是另一个有批准依据的资产，不冒充前段色卡。

前段素材须有accepted_artifact_id，不能从未接受候选派生正式接续。样本区间[max(0,T-5s),T]；站位/持物等分析须在既有连续性阶段核定后进入制作账本。上段站位与源下一段骨架不相容时先裁决，不要求两个矛盾状态同时成立。

衔接视频默认OFF，用户明确OPT_IN才裁真实尾部3–5秒、最多1条；T<3s则不能提供符合该约束的视频，说明并保持关闭。可关闭音轨时优先关闭；无权重参数不虚构。色卡承担光色，不控制身份或精确站位。源分析文字/调度不是上传参考。

前段返工换接受版时，旧色卡/尾段/站位分析及依赖它们的下一段批准失效，重新派生并复核。没有回片不伪造；用户明确另开RESET制作单元不等于前段已通过验收。
