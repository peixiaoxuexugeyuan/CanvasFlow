# 分阶段QA与接受门槛

按主文件7.6、12–14、16节。检查是真实证据核对，不以“检查项已列出”冒充实际完成。

## 冻结前

检查source/production/asset依赖有效；STRICT映射守恒或USER_MODIFIED批准差异/TARGET计数；所有可见主要角色含KEEP有身份参考；目标空间和交互可执行；DIRECT/CUT/RESET正确；语言/窗口/表演/分镜批准有效；Prompt确实读取批准制作状态而不是旧源值；实际schema/资产额度/规格/互斥/长度合法；模型写法正确且零BGM、无源内容污染；尾部保持和分段方案可执行。此阶段不要求尚未新建的视频节点已存在。

## 冻结后节点

真实创建本轮独立节点、冻结正文原样写入、实际支持的参数正确、全部最终参考双路径绑定且key对应、读回完整。任一失败不交接；中断先查同attempt节点后补齐，不重复创建。不得自动提交视频生成。

## 生成后

实际媒体/配置证据分开记录。先查完整有效事件，再裁切；不能由导出尺寸推断实际模型/绑定。逐项查镜头、身份、对白全文/语言/说话人/口型、动作/表演、Blocking/持物/道具、摄影、声音/零BGM、色彩/END与接续，D查目标内容及源残留。

| 状态 | 判据与后续 |
| --- | --- |
| PENDING | 必要检查尚未完成，不能宣称通过 |
| NEEDS_FIX | 有未解决制作问题；留POST_GENERATION，给修复范围，重走受影响关卡并由用户新生成 |
| PASS | 必要实际检查完成，无未解决实质偏差，可指定接受版 |
| ACCEPTED_WITH_DEVIATIONS | 已完成必要实际内容检查，用户明确接受列出的具体制作偏差/已披露配置证据缺口；保留偏差，不称QA全通过 |

缺文件不是可豁免制作差异；POLICY/HARD不可用户豁免。漏关键台词/镜头、错身份/语言、截断结局、错误接续、配乐等先NEEDS_FIX；“继续下一段”不是对全部问题的自动接受，须在同一验收交互明确接受范围。

只有PASS或明确ACCEPTED_WITH_DEVIATIONS并有accepted_artifact_id，才能派生下一段正式素材。无回片时USER_DESCRIPTION_ONLY，不裁切/验收通过/派生/推进；有片而配置不可核实时FILE_INSPECTED_CONFIG_UNVERIFIED，可做真实内容检查，但不能声称冻结一致。详见[生命周期](PRODUCTION_LIFECYCLE_STANDARD.md)。
