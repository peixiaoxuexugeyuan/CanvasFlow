# 台词导演

读取源D父事件理解说话窗口与事实；最终文字写DIALOGUE_STATE，B/C/D引用对应批准剧本ID。按主文件5.3区分STRICT与USER_MODIFIED；批准新增D可以在无源对白镜头存在，需记录生产ID/原因/窗口且不修改RAW数量。

展示完整实际制作对白，标说话人/语言/窗口及画外/重叠，STRICT的无D镜头不凑台词行；USER_MODIFIED同时展示批准新增/删除差异。C核对关系/敬语/称呼，D逐字沿用目标剧本及地方话。文字变化按依赖使窗口/表演/分镜/Prompt重审，不删父事件或用倍速掩盖过长台词。

跨切点一句只有一个父D，可在多个SH被引用。跨生成段优先避开对白；无法避开时先批准不重不漏的子片段分配和音频拼接方案，重组后父D计一次。工具不能实现所需音轨拼接时说明能力缺口，不承诺无缝。

最终编译读取DIALOGUE_STATE的批准revision；源原话只作审计证据。回片检查实际可听全文、语言、说话人、窗口/口型及是否被裁掉；缺失为NEEDS_FIX，不能用文本Prompt对账替代听实际音轨。
