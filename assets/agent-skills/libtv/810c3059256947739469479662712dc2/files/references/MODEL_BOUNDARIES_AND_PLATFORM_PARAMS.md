# 牛大师反推视频大师 模型边界与提示词导演知识库

本文件供现有「牛大师反推视频大师」的提示词导演检索和引用，兼容 Obsidian。用途：把原片镜头分析转为 Seedance 2.5、Wan 3.0 或 Kling 4.0 能接收的生成计划，识别内容准入、素材组合、时长与平台参数冲突。本文不重新定义现有 Skill 的阶段、角色绑定和验收流程。

核实日期：2026-10-30。厂商官方资料与LibTV模型schema分层记录；未进行实际视频生成、拒绝率或逐帧复刻测试。每次执行先读取当前平台schema，历史快照只作证据。

> [!important] 现有 Skill 的内部写法规则优先保留
> 当前草稿明确要求 Seedance 2.5 无时间轴、连续动作流，表情／动作／节奏三项必写；这是本 Skill 的工作流约束。官方支持时间戳这一事实，不构成自动删除该约束或其 QA BLOCK 的理由。现有节点绑定与 `{{node_key}}` 占位双路径、模型锁定、链路A/B/C/D隔离、影调层和验收关卡均继续执行。本知识库中的厂商 `@图片1` 等引用示意，不得替代平台实际节点占位机制。

## 1 提示词导演的读取约定

### 1.1 限制等级

| 等级 | 含义 | 导演处理方式 |
| --- | --- | --- |
| POLICY | 官方服务规则禁止或要求授权的内容 | 不以换词、换模型规避；指出涉及的画面和限制；需要改编时保留为待确认变更 |
| HARD | 指定入口/接口不接收的参数或素材组合 | 提交前修正计划；提示词不能覆盖接口限制 |
| SOFT | 官方明确指出的质量风险或推荐值 | 保留创作意图，减少冲突；不能说成“一定不能生成” |
| UNKNOWN | 未公开阈值、平台映射不明或尚未测试 | 不编造禁词、成功率或硬上限；在交付记录中明确未知项 |

### 1.2 规则适用范围

每条规则由“模型＋版本＋平台/入口＋任务”共同确定。同名模型在厂商网页、原生 API、LibTV 中可能有不同限制。

1. 内容规则依据实际提供服务的平台及厂商政策；平台 schema 不构成内容许可。
2. LibTV 参数和素材路径以当前 schema 为准，同时满足已核实的厂商底层约束。
3. 原生 API 字段不能未经映射直接写入 LibTV 节点。
4. schema 未声明某字段，不等于模型底层绝无此能力；只表示本次没有可用配置证据。
5. schema 的 `prompt.maxLength=0` 含义未核实时，不解释成“提示词只能为空”或“无限长度”。

以上是本知识库的应用约定，属于整理者建议。

### 1.3 反推事实与生成表达分开保存

反推账本记录原片实际切点、动作、对白和毫秒级时间；提交提示词再按模型能力编译。原片没有提供给模型时，最终提示词不得凭空引用“视频1”；必须把需要保留的画面写清。原片只是内部分析材料还是实际参考输入，应沿用现有 Skill 的既定流程。

遇到不接收或不允许的画面，保留账本事实并报告冲突，不悄悄删镜、改台词、改年龄。需要改编时另列替代方案，由原工作流确认后再执行。

## 2 Seedance 2.5 时间轴争议核对

**核实结论：当前官方指南允许镜头序号或时间轴，并没有概括性地建议“不要按时间轴写”。** 原文短引：“镜头顺序/时间轴（均可）”。指南支持整数秒时间戳，但不推荐用它控制每秒重复几次的高频动作。内容塞得过密会增加漏情节或过度切镜风险。[D1](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)

| 规则ID | 等级/适用范围 | 可执行规则 |
| --- | --- | --- |
| SD25-T01 | SOFT；厂商提示词组织 | 官方层面不强制每条提示词带秒数；当前Skill仍按其无时间轴规则编写 |
| SD25-T02 | SOFT；厂商支持的时序控制 | 若其他工作流明确选择时间轴，应使用整数秒、保持连续；当前Skill未获准改变其内部无时间轴规则时不走此分支 |
| SD25-T03 | SOFT；高频动作 | 不用“一秒摇头三次”等频率指令承担精确动作控制 |
| SD25-T04 | UNKNOWN；验收 | 支持时间戳不等于帧级切点保证；逐帧一致性必须回看成片验证 |

T01、T04是整理者的应用建议；T02、T03来自 D1 的时间控制说明。不能把它们升级为全平台硬限制。

**SD25-WORKFLOW01 / HARD（仅限本Skill）**：最终Seedance提示词不使用 `[0-3s]` 等分段时间轴，按连续动作流组织表情、动作和节奏；反推账本仍可保留原片实际时间码。禁止把这条内部规定表述成“官方不支持时间戳”。只有用户明确要求修改该工作流时才调整此规定与相关QA规则。

### 无时间轴写法示意

以下为整理模板，不是官方原文：

```text
[角色引用]确定人物外观，[场景引用]确定空间与光照。
镜头一：[主体起始位置、动作、视线、机位]。
镜头二：承接上一镜的[姿势与道具状态]，发生[动作与对白]。
镜头三：[事件结果、收束构图和声音]。
保持[需要贯穿的服装、道具和空间关系]。
```

### 3.1 平台专用规则

| 规则ID | 等级 | 条件与动作 |
| --- | --- | --- |
| LIB-SD01 | HARD | Seedance 编辑模式 `videoEdit2video` 只收1个编辑视频；可搭配最多30张图。时长控件为 `duration_auto`，写入字段 `duration` 的枚举值是 **0**，不写原生API的-1 |
| LIB-SD02 | HARD | Seedance 编辑模式画幅控件仅 adaptive；续写有 `videoExtend2video`。续写面板虽显示比例选项，底层仍有锁定规则，不能承诺能改变原片画幅 |
| LIB-SD03 | UNKNOWN | `portrait=true`、真人校验开关和自动校验素材配置说明平台有相关流程；不能据此承诺任意真人素材可直接使用，也不能把关闭校验当作绕过授权的方法 |
| LIB-W01 | HARD | Wan 全能参考合计按15限制，不能因厂商指南写20就接入20项；附件/链接是否计入同一总数需实际入口进一步确认 |
| LIB-W02 | HARD | Wan 当前比例枚举无21:9；清晰度值使用大写P。API支持21:9不能据此向LibTV填21:9 |
| LIB-W03 | HARD | Wan 智能扩写字段为 `extendPrompt`；原生API名是 `prompt_extend`，两者不能直接互换。附件最多1个、100MB；链接最多1个；底层文档/网页互斥规则仍要检查 |
| LIB-K01 | HARD | Kling 当前无4K枚举；只生成720p/1080p。不能把厂商4K能力当作本入口可选项 |
| LIB-K02 | HARD | Kling 全能参考中视频主体最多3个，且 `disabledWithVideo=true`：传入参考视频时不可再使用视频主体 |
| LIB-K03 | HARD | Kling 主体与 `imageList` 共享最多10个额度；不要把主体作为额外免费额度。编辑模式只接1个编辑视频、最多10张搭配图 |
| LIB-K04 | HARD | Kling 全能参考与编辑模式的视频须3–30秒、MP4/MOV；两种模式都要求有提示词 |
| LIB-K05 | UNKNOWN | `audioMax=3`、`allowAudioOnly=true` 是平台接入配置，不能推导成允许上传BGM/音效并逐样本复用；官方音频用途目前为音色档案 |

以上全部可在三个快照中按字段路径复核。`config.settings.text2video` 的存在与 `modeType.items` 未列出 `text2video` 同时出现，不应仅凭后者断言不支持文生视频。

## 4 厂商原生参数边界

本节是底层约束参考；使用 LibTV 时先过第3节，再检查相关底层限制。

### 4.1 Seedance 2.5 火山方舟

| 项目 | 已核实范围与注意事项 |
| --- | --- |
| 输出 | 480p、720p、1080p；4–30整数秒或智能时长；MP4/MOV |
| 输出帧率 | 模型列表列24fps；不把输入视频24–60fps当作输出可调帧率 |
| 图像输入 | 最多30张；单边300–6000px，宽高比0.4–2.5；单张小于30MB |
| 视频输入 | 最多10段合计≤30秒；普通参考每段2–30秒，编辑原片4–30秒；≤200MB/段；输入24–60fps |
| 音频输入 | 最多10段合计≤30秒；每段2–30秒、≤15MB；WAV/MP3；可仅传音频 |
| 请求体 | ≤64MB；大素材优先URL/平台支持的资产引用 |
| 提示词长度 | API建议中文≤500字、英文≤1000词，属于写作建议，不是宣称超出必报错的硬阈值 |
| 编辑 | 原生 `ratio=adaptive`、`duration=-1`；不能另定输出秒数 |
| 首尾帧与延长 | 原生要求 `ratio=adaptive`；锁定画幅 |
| Draft | `draft=true` 仅480p；不是所有正式视频参数都能照搬 |

来源：[D2 教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[D3 创建任务API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[D4 模型规格列表](https://docs.volcengine.com/docs/82379/1330310?lang=en)、[D5 通用视频教程](https://docs.volcengine.com/docs/ark/video-generation-tutorial?lang=zh&redirect=1)。

SD25-H01：不套用公共API页面里其他版本的4K、`frames`、离线 `flex` 参数；D3分别说明支持模型，`frames` 的所列小数秒控制是1.0系列能力。

SD25-U01：编辑时长不是严格逐帧保持保证。D1提示词指南提到约0.3秒偏差，D2教程/D3接口说明提到约0.4秒；应记录文档差异，交付前检测实际帧数，不能承诺“原片30秒输入一定输出完全相同帧数”。

WAN-H02：文档和网页的内容解析不是实时联网研究的保证；登录页面、私有链接不能按公开网页参考处理。

| K40-C05 / HARD | 上传BGM或音效作为独立音频参考 | 当前官方指南不支持；需要音色档案或文字描述声音需求 |
| K40-C06 / UNKNOWN | 普通剧情拥抱、无伤害奇幻动作、轻度惊悚的精确审核线 | 不作通行保证；按具体场景检查，不把所有接触/所有儿童画面都列成禁用 |

依据：[K2 社区规则，2026-09-08生效](https://kling.ai/docs/community-policy)、[K1](https://kling.ai/quickstart/kling-4-model-user-guide)。这是内容规则，不是模型技术上完全画不出的清单。

### 5.4 反推儿童/灵宠题材时的具体检查

以下为整理者针对本项目类型的应用提示：原片含儿童时，检查是否涉及受伤、虐待、危险挑战、恐惧羞辱或性化；尤其 Kling 的未成年人危害规则包括动画。正常儿童角色或灵宠角色本身不等于禁用类别。若情节需要调整，清楚记录删改了哪一镜、为什么、对原剧情有什么影响，并交回既有确认流程。

## 6 反推视频任务的编译规则

### 6.1 输入分为三种路径

| 路径 | 适用条件 | 提示词导演的工作 |
| --- | --- | --- |
| 纯分析后重建 | 原片只内部分析，不实际上传 | 根据镜头账本完整描述画面；只引用实际提供的人物/场景资产 |
| 参考原片生成 | 允许且实际提供原片做参考 | 写清借用动作、构图、节奏中的哪几项；检查输入视频预算及身份替换范围 |
| 编辑原片 | 目标是保留原片并定向修改 | 用编辑意图和对应入口；列出修改项与保留项；校验可用时长、画幅与素材组合 |

不要把三条路径自动合并。模型能理解文字中的“参考”不等于平台执行编辑。

### 6.2 遇到边界时的处理次序

1. 定位当前 modelKey、modeType、实际送入的素材清单。
2. 先查 POLICY，再查LibTV HARD，再查底层HARD，最后处理SOFT。
3. 对时长预算超限，优先在原片已有切点分段；记录分段后角色、道具、声音、位置的接续要求。
4. 对素材超限，先去掉重复视图或重用资产；不私自删掉关键角色和关键动作证据。
5. 对画面准入冲突，报告场景与规则；合规改编需要现有工作流确认，不能改写成绕审核提示词。
6. 对精确时序，账本保留真实值；模型提交使用可表达的节拍；必要时将精确切点安排为后期编辑。
7. 未经实测，不使用“百分百复刻”“绝不串脸”“逐帧完全一致”等交付承诺。

以上为知识库编译约定，不是厂商效果承诺。

## 7 易误判案例 用于接入时自查

| 请求 | 应得到的判断 |
