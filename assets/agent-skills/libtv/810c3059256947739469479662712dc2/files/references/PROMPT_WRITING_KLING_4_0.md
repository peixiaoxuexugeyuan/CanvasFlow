# Kling 4.0 写法分册

适用LibTV `kling-v4`；不套Flash或旧O3规则。来源：[官方指南](https://kling.ai/quickstart/kling-4-model-user-guide)、[社区规则](https://kling.ai/docs/community-policy)，核实日期2026-10-30；未实测生成。

## 编译顺序与写法
主体和实际参考职责→主体动作与表情→场景与环境→镜头与运镜→光线氛围→对白和实际声音→必要约束。多镜头逐镜明确上述要素，不能以全局一段“电影感”替代镜头事实。用可见光线/材质/动作代替空泛形容，减少无差别负向清单；明确无字幕/无BGM。只用已确认角色/主体绑定；不得凭名字虚构元素。

## 整理者模板骨架
```text
主体与参考：角色A绑定{{实际角色节点key}}；场景绑定{{实际场景节点key}}。
镜头一：[角色起始位置]；[动作与表情变化]；[场景中相对关系]；[景别、摄影机路径、焦点和节奏]；[可见光线]；角色A用[目标语言]说：“[批准台词]”；[拟音和环境音]；[END]。
镜头二：[承接状态，按同样要素展开]。
全片无背景音乐，无字幕，保持已批准的角色与空间/道具连续性。
```

## 任务入口和配额
当前LibTV混合参考总≤15，图10/视频5/音频3；只开放720p/1080p，无4K，无480p；时长3–30整数秒。主体与imageList共享10额度，视频主体≤3且传参考视频时禁用视频主体。编辑仅1个原视频，但本Skill原片始终ANALYSIS_ONLY，不能因有编辑功能就自动绑定原片。

音频用途依官方指南为音色档案，不把audioMax3/allowAudioOnly当作上传BGM/音效许可；独立关键帧入口只收图，需视频参考时用全能参考。官方8000tokens不等于LibTV maxLength11000。POLICY检查包含动画/数字生成未成年人被虐待或危及安全，不能用动画风豁免。详见[边界文件](MODEL_BOUNDARIES_AND_PLATFORM_PARAMS.md)。
