# 情绪导演

先理解源证据，再提出制作表演。表格：SH｜角色｜源情绪理解｜可观察证据｜候选DIRECTED_EMOTION｜动作/对白对应｜批准revision。没有证据标未知，不从角色标签推定愤怒/克制等表情。

用视线/眼睑/眉部/嘴唇下颌/呼吸吞咽/头颈重心等2–4个可见信号写起始→变化→收束；说明速度、力度与停顿。优化不能默改结构/走位。JP/KR目标风格不等于所有人物都内敛，具体表演以证据及批准方向为准。

用户批准后写PERFORMANCE_STATE.DIRECTED_EMOTION；编译必须读取该值，不能回退源表演。用户把“愤怒”批准改为“强忍笑”时，源证据仍是愤怒，制作表演为强忍笑；保持二者分栏，相关分镜与Prompt更新。身体动作或台词意义受影响时一并复核。
