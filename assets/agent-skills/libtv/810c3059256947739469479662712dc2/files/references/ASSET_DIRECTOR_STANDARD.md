# 资产与节点落地

身份/用途/批准与绑定按主文件2.2执行。KEEP与REPLACE均须独立批准的身份参考；无参考不能以“保留原演员”替代。原片/SRC截图不转为生产参考。自动拉取是发现可用素材，生产绑定只含本段所需且批准为参考的资产，不能把全部历史候选绑满。

BINDING_MANIFEST逐项记录asset_id、真实node_key、版本、用途、角色/场景ID、适用SH、批准依据、参考类型及所占额度。可选音色核对实际入口用途；辅助站位图/色卡也占真实图片额度。总额冲突先提案由用户确定最终清单，不静默删重要身份图。身份、布局、色调的参考职责分别声明。

辅助图通过本地确定性处理制作：色卡从已接受媒体实际取样并标源区间；站位图用批准空间关系绘制SVG/PNG，不用付费生图。仅创建文件不等于挂载成功，须得到真实可读资产节点。生成能力缺失不能输出假key。

冻结前确定全部真实key，Prompt和清单一起复核。冻结后13A新建独立视频节点，原样写入冻结文本/实际支持参数并绑定，读回完整正文/参数/引用/连线后交接。生产账本字段不随意写作API字段。

同一attempt的创建/写入中断后先读回：已有本轮未提交节点则修复同一节点，不因重试重复创建；已提交或新attempt另建。创建超时且未获key时按主文13A：先按已验证能力枚举/反查并核对；无法唯一定位或工具不支持时停下报告，不盲目重建。历史上游节点不可复用。生成留用户点击，不能自动提交或消耗额度。旧实际生成记录不能被新方案覆盖。
