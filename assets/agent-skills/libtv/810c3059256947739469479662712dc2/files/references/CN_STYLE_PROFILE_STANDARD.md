# 中文转绘：内容、空间与影调

D的源原片仅给影像骨架。源人物外貌/身份/服装、场景美术/道具设计/影调不进入目标内容或Prompt；角色/空间/道具来自目标剧本与CN_ANCHOR_SET。SOURCE_STATE保留分析证据，制作内容字段不从中复制。

SCRIPT_LOCALE=TARGET_SCRIPT_AS_IS，不建立HONORIFIC_MAP。普通话/粤语/台语逐字来自批准转绘剧本；语言与HK/MAINLAND/TW影调标签独立。改写/翻译/压缩需批准新script_revision及覆盖理由，不能假称仍与旧剧本逐字一致。

## 空间和交互

SPACE_PROP_MAP记录功能位置（出入口/交互面/视线目标/持物）→目标资产/物件→制作角色动作→路径/距离/遮挡/触达/持有手验证。可保留源相对关系，不复制源美术设计；目标中无对应位置/道具就报告冲突，请用户换目标锚点或批准改Blocking，先解决再画站位图。新增关键道具改变交互时回到受影响审核。

## 七维影调记录

| 维度 | 记录 |
| --- | --- |
| 色温/白平衡 | 实际目标光源与肤色中性点 |
| 主光质/光比 | 方向、软硬和明暗关系 |
| 色彩倾向 | 目标资产有证据的主辅色及允许偏色 |
| 饱和度/对比度 | 整体与肤色、画面反差 |
| 质感/颗粒 | 有证据的实拍/胶片/数码质感 |
| 高光/暗部 | 高光过渡、黑位、细节可见性 |
| 氛围 | 与上述可见信息对应的简洁词 |

## QA

检查目标内容可追溯、空间可执行、剧本逐字/地方话一致、影调七维有证据。发现源人物/美术/道具设计/影调残留或以影调改变结构即退回；源抽象空间关系经目标映射后允许，不把必要相对位置误判为污染。
