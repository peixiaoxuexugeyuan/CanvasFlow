# 时间、分段与裁切

源账本保留真实毫秒时间码，制作时间轴连续覆盖本段批准目标；提交稿按当前模型规则表达，Seedance仍不用分段时间轴。精确文本不保证精确生成。USER_MODIFIED时目标时长与原始源区间分开存，不覆盖源时长。

SEGMENT_PARTITION记录父segment_id、part_id、source_start/end、源SH/D ID集合、目标SH/D集合、part目标时长及拼接顺序。拆点优先源切点且避开一句对白，源区间无遗漏/重复；局部计数对局部分配，父段按稳定ID去重，不能把子段数量与整片RAW锁值硬比。

跨源镜头D保持同一父ID。跨生成段D如不能挪拆点，先批准子片段各自文字/窗口与音轨处理，保证句子不在两段完整重复；合并后父事件计一次，并检查没有漏词/重词、断气口或说话人漂移。工具不支持所需拼接时停下报告，提案重新分段或获批后期音轨，不承诺生成模型自动无缝续说。

输出时长先满足实时档位和总预算，再考虑2–3秒缓冲偏好。没有合法档位就提出合法缩短缓冲/拆段，用户不能批准突破HARD。缓冲是事件完成后的END保持/自然尾音，不延长正式D/F/A/C或新增SH。

正式裁切前检查最后有效对白/动作/END完成点；超过批准终点时NEEDS_FIX，保留原片，提出重新生成或批准新时长/剪辑。不能先裁坏再说验收。剪辑产物有独立ID及来源/区间，最终接受版和实际生成原片分别记录。
