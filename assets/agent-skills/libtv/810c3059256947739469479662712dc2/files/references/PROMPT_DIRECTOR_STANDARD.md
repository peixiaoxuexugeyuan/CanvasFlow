# 提示词导演编译合同

编译入口是已批准且依赖有效的制作账本，不能直接把源账本当成最终制作稿：

| 提示词内容 | 唯一制作来源 |
| --- | --- |
| SH/构图/动作/Blocking/C/F/A/END | EXECUTION_STATE批准revision |
| 最终对白/说话人/语言/窗口 | DIALOGUE_STATE批准revision，对应目标剧本版本 |
| 表情/表演/节奏变化 | PERFORMANCE_STATE.DIRECTED_EMOTION批准revision |
| 实际身份/场景/道具/音色/辅助图引用 | ASSET_STATE最终批准清单与真实key |
| D内容/空间/影调 | 目标锚点、SPACE_PROP_MAP、CN_STYLE_PROFILE |
| 模型/入口/画幅/时长及尾部收束 | 当前attempt批准参数与分段方案 |

源证据用于核对忠实度及差异来源，不覆盖用户批准的制作变更。STRICT检查源→制作守恒；USER_MODIFIED检查批准差异及TARGET数量，不因无源映射再禁止新增D。跨镜头父D不重复计数。

先读[模型总纲](PROMPT_WRITING_BY_MODEL.md)，再读对应分册。Seedance内部无分段时间轴、逐镜连续动作流，表情/动作/节奏必写；这是内部规范，不冒充官方禁时间戳。Wan结构化逐镜；Kling逐镜要素。源精确时间保留内部，不承诺模型逐帧执行。

每镜包含开场/相对位置→动作→批准表演/节奏→D/F/A→END及C。参考职责用实际{{node_key}}短句，节点字段双路径绑定；不复述源演员/素材外貌。内部站位分析不全文输出，但必要初始位置/持物/动作应从制作状态展开。全局无BGM/字幕，不添加源中不存在或未经批准的声音。

缓冲写正文完成后保持END、自然呼吸/环境尾音，不追加剧情/台词/镜头；Seedance不用时间区间模板。该指令不保证按时结束，回片必须查末事件完成点后再裁切。冻结前必须拿到全部真实key，保存compiled_from制作/资产/参数revision，展示全文与最终清单，用户批准后冻结。13A原样写入；修改需重新冻结。

历史P0/P1/P7/P8/P9仅对应全局执行约定/参考职责/无配乐/画面一致性/完整性收束，不是API参数；提交稿用清楚名称，不输出内部部门、审计日志或“参考原片”说明。官方资料无法读取时标注证据缺口，不把整理模板称为官方原文。
