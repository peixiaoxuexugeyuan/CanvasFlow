# Seedance 2.5 写法分册

适用LibTV `star-video2.5`；本Skill重建默认`mixed2video`，不是原片编辑。厂商来源：[提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)、[教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)。2026-10-30核对；部分动态正文通过官方索引核对，未实测生成。

## 必须同时保留的两层
SD25-T01：官方允许镜头编号/时间轴，支持整数秒时间戳，不建议用其指挥高频重复动作。SD25-WORKFLOW01：本Skill最终稿不用分段时间轴，以连续动作流呈现；表情、动作、节奏缺一即BLOCK。源账本仍保留精确时间码，不保证模型逐帧复刻。

## 编译顺序
实际规格与段号→全局执行约定→实际资产职责→零配乐与画面一致性→逐镜连续动作流→事件完整性与结束状态。资产职责只说明角色/场景/道具/音色等用途并使用真实`{{node_key}}`；不复述源演员或素材外貌。

每镜写：起始构图与相对位置→动作从起到止及力度/速度→可见微表情的变化→停顿/呼吸/快慢节奏→已批准对白及实际拟音/环境音→收尾状态。依次写“镜头一/二/三”，不写`[0-3s]`区间。

## 整理者模板骨架
以下方括号是填空，不是待交付正文：
```text
[段号；实际画幅与输出时长]
参考职责：{{实际角色节点key}}用于角色A；{{实际场景节点key}}用于场景。
只生成已批准的对白、表演声、同步物理拟音和环境底声，无背景音乐，无字幕。
镜头一：[开场构图和位置]。[动作的起始、发展与结束]；[表情可见变化]；[节奏与停顿]。[已批准对白和声音]。[结束构图/状态]。
镜头二：[承接状态与完整画面过程]。
保持已批准的角色绑定、服装/道具状态和空间连续性，按已批准事件顺序收束。
```

## 参数与边界
当前LibTV输出4–30整数秒、480p/720p/1080p；混合参考总≤50，图30/视频10/音频10。普通重建不套编辑Auto；编辑入口仅在任务实际改为编辑且已有明确授权时查规则。LibTV编辑duration Auto=0，原生API=-1，两者分开。原生参考视频总≤30秒、音频总≤30秒；普通入口真人人脸素材需官方可信/授权流程，平台自动校验不是授权豁免。详细检查见[边界文件](MODEL_BOUNDARIES_AND_PLATFORM_PARAMS.md)。中文≤500字是原生API写作建议，不是硬截断；保留全部关键事实比机械凑字数更重要，过密时报告可生成性冲突。
