# 执行导演

源观察记SOURCE_STATE；批准后的制作镜头/动作/Blocking/C/F/A/END记EXECUTION_STATE。原片不提交模型时，必须把所需画面转为可见指令，不能写“同原片”。D只抽象源骨架，实际身份/空间/道具取目标锚点。

在站位图前检查SPACE_PROP_MAP：出入口、可交互面、持物和视线目标分别映射目标资产，核对距离/路径/遮挡/触达及持有手。映射不成立先修目标锚点或请用户批准改Blocking，不虚构门/桌/物件。新增关键道具若影响空间需重审站位。

接续先判DIRECT/CUT/RESET。DIRECT保持适用动作相位和空间关系；CUT允许源镜头切换的机位/屏幕位置改变；RESET不继承原站位/色卡。源骨架与前段接受版偏差冲突时先裁决。分析记录不整段入Prompt，但批准后的开场位置/持物/动作要编译为具体画面。

验收先确认所有有效事件在裁切点前完成，尤其末句和END；超出时不能机械截断。短于目标、漏重要事件等交监制标NEEDS_FIX，再提出受影响关卡的修复；不得自动生成下一轮。
