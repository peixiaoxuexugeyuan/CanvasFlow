# 产品图/产品名 → 荒野时尚大片宣传片

把一张产品图或一个产品名，做成一集 30-60 秒的荒野时尚大片宣传片：产品被摆进戈壁荒野，用「不搭就是百搭」的反差套路讲完六段，配上沧桑厚重男声旁白、冷峻氛围 BGM 与写实的现场音效。

## 这个 Skill 产出什么

一支 **30-60 秒、16:9 横屏、1080p** 的成片，六段内容一一对应、一个不丢。产出以合成结果的视频节点交付。

## 输入判据

产品图、产品名**两者至少有一个**：

- 只有图：从图上提取品名、品类、核心卖点、包装器皿与配色、logo 字样。
- 只有名字：按名字补全设定（品类、器皿、卖点、拼音 logo）。
- 两者都有：以图为准，名字用于校正与补全。

**缺产品信息时先用 `ask_human` 问，不默认、不编造。** 同时确认画幅（本流程按 16:9 横屏交付，用户另有指定从其指定）。

## 一、脚本模板（固定，只做 XXX 替换）

脚本本身是固定模板，**只做 XXX 替换 + 旁白压缩以适配用户时长**，不改镜头顺序、动作、字幕点位与台词梗。六段如下（XXX 为产品占位符）：

| 段 | 画面 | 旁白 |
|---|---|---|
| 1 | 荒野戈壁上放着 XXX，画面上方出现文字「如何用时尚大片的方式宣传XXX」 | 如何用时尚大片的方式宣传XXX？ |
| 2 | 一位长发男子穿着西装走在荒野中，随后停下脚步看向镜头 | 时尚大片的精髓就俩字——不搭。 |
| 3 | 镜头俯视地面的一株植物，接着展示男子将 XXX 放在树上、埋进沙里、挂在肩上的画面 | 先选一个看似跟 XXX 不搭的地方，荒野、戈壁，越是反差大，越能体现 XXX 的张力。再把 XXX 摆在树上、埋在沙里、放在肩上，越违和越能凸显百搭属性，在哪里都能撑住场面。 |
| 4 | 男子站在岩石上手持 XXX，随后画面打出大 logo XXX(拼音)，并配有几个英文单词如「XXX SENSE」「XXX PRISM」等 | 然后模特的穿搭也不搭，总之不搭就是百搭。这时打出大logo XXX，顺便配几个英文单词。举个例子，XXX SENSE，XXX PRISM。再比如XXX 世家，划重点，字越少，逼格就越高。 |
| 5 | 男子牵着一只杜宾犬走在荒野中，随后切换到一位白胡子老头拿着放大镜仔细研究 XXX 原料或者 XXX 生长环境的画面 | 接下来给模特找个搭子，时尚不是装出来的是气场。或者找个白胡子的老头，拍他反复研究 XXX 原料或者 XXX 生长环境的画面，拍出他这辈子就做这一个 XXX 的感觉。 |
| 6 | 男子尝了一口 XXX，最后他独自站在广阔的荒野中，画面上浮现出文字「谁说XXX不能搞时尚」 | 最后镜头回到模特，此刻一定要有个时尚大片的标配，反问金句。比如「谁说XXX不能搞时尚」，一定要让想打问号的人不好意思打问号。当别人看完都在想着 XXX 是不是真的很百搭的时候，恭喜你，赞有了。 |

### XXX 替换规则

把脚本中所有 XXX 替换为上传信息，并派生：

- **产品名**：取自图上的品名，或用户给的名字。
- **拼音大 logo**：产品名的拼音大写（如 汤包 → TANGBAO）。
- **配套英文词组**：`XXX SENSE`、`XXX PRISM`、`XXX 世家` 三组，XXX 用拼音大 logo。
- **品类 / 卖点 / 包装器皿配色**：用于画面描述与锚点设定。

### 定稿与时长

- 原稿旁白常超时长。**压缩只动旁白字数，不改镜头顺序、动作、字幕点位与台词梗。**
- 改写后的完整脚本落 `drafts/`，用 `ask_human` 请用户确认后才成为唯一内容基准。
- 用户对时长有明确要求（如「压到 45 秒左右」）时按用户要求压缩，并说明成片实际会落在的区间。

## 二、锚点

- **产品图直接复用为已生效锚点**，不重复生成。
- 另建一条 **「产品·野外状态」状态变体**：棚拍白底与荒野地外观互斥，同一张图不能同时成立；只写相对父的变化（置于戈壁砾石地上、沾细沙、映冷灰天光）。
- **场景锚点**各建一条：荒野戈壁（空镜）、风蚀岩石（空镜）。
- **道具锚点**各建一条：旱生植物、杜宾犬。
- **角色锚点**各建一条：长发男模、白胡子老者。人物锚点用**身份卡写法**——中性表情、自然站姿、纯色或浅灰背景、平光，只定「是谁」，不带表情、情绪、动作与剧情场景。
- **叠加文字不建锚点**：大 logo、英文词组、两句屏幕反问文字，由分镜阶段与镜头承载。
- 站位锚与音色锚默认不建；**除非有跨分镜同角色对白**（本流程旁白由后置 TTS 统一，通常不需要）。

## 三、分镜

- 模型用 **Wan 3.0**（单次 4-30s，支持视频续写）。
- 按**贪心合并**成 3 条左右分镜，**相邻两镜预估时长之和超 30s 上限就不再合并**。
- 分镜视频**先带原声生成、验收画面**，音轨在后面单独重做。
- 跨镜承接用**「视频续写」**：前镜生效后剪出最后 5s 尾段做续镜锚点（`video_action_type=extend`）。
- 每条分镜的 prompt 里，**每个 `reference_nodes` 的 node_key 都要有 `{{}}` 插桩**，否则接口直接拦下、不落节点。

## 四、音轨后置（本流程的重点特色）

分镜画面验收通过后，再单独做声音。成片声音共三层：**旁白最前，音效其次清晰可辨，BGM 最低**。

1. **音色锚点**：建一条 TTS 节点，样句固定为「你好，很高兴认识你。」+ 声线描述。本流程声线为**沧桑厚重男声**——中年男性、五十岁上下、低沉沙哑、气息浑厚有共鸣、语速缓慢沉稳、克制有分量，像高端时尚广告大片的旁白解说。
2. **三条旁白**：按分镜各建一条 TTS，**都引用同一条音色锚点**保证是同一人。文案与成片旁白逐字一致。
3. **BGM**：另建一条**纯器乐** BGM（Mureka），冷峻氛围、约成片时长，无人声无歌词。**BGM 降 10dB**，避免抢旁白。
4. **环境声与动作音效**：另建 `sound_effect` 类型的音频节点，给成片铺一层写实的现场质感。**用英文描述声音本身**——声源、动作、材质、环境、强度、时长。音效**不要盖过旁白，也不做卡通化的夸张处理，保持写实、克制、高级**。
   - **环境声底**：荒野戈壁的风声（持续的低沉风啸 + 掠过砂砾的细碎沙沙声），贯穿全片铺底，音量压在旁白之下。
   - **动作音效按六段画面对位**：
     1. 第一段：砂砾被风吹动的细碎声、玻璃瓶/蒸笼轻放落地时的轻微磕碰声。
     2. 第二段：男子踩在砾石上的脚步声（干脆、有颗粒感）、西装与长发被风掀动的布料摩擦声、停步时脚步收住的最后一声。
     3. 第三段：俯视切镜的风声、把产品搁上枯枝时的枝干轻响、埋进沙里的沙粒滑落声、扛上肩时衣物与器皿的闷碰声。
     4. 第四段：登上岩顶的脚步与碎石滚落声、迎风衣袂猎猎声；大 logo 与英文词组弹出时配清脆的金属质感提示音（每弹一行一声）。
     5. 第五段：杜宾犬的爪垫踩砾石声、犬只鼻息与项圈皮带轻响；切到白胡子老头时放大镜开合的轻咔声、他翻检原料时的细微摩擦声。
     6. 第六段：舀取/夹取产品时的轻碰声、入口咀嚼与吞咽的细微声、尾镜大远景时风声渐强收束，最后干净收尾。
5. **合成**：`composite_video` 时设 **`video_volume=0`**，把原片旁白整轨静音，只叠新旁白、BGM 与音效；旁白轨按各分镜起点**错位铺设**，音效按六段画面对位铺在时间轴上。

## 五、必须避开的踩坑点

- **视频续写模式下成片开头会重复前镜尾段**（画面与旁白都重复）。合成前用 `analyze_audio` 核对音轨，把后镜 `start_position` 往后掐到重复句结束。
- **TTS 会漏读开头句子**。合成前必须逐条 `analyze_audio` 核对逐字完整；发现漏读**按异常处理新建 v2 节点，不在原节点重跑**。
- **`create_video_node` 的 prompt 里每个 `reference_nodes` 的 node_key 都要有 `{{}}` 插桩**，否则接口直接拦下不落节点。
- **同一轮工具调用必须是同一个工具**，不能混 `run_node` 与 `create_*_node`。
- **每批运行前用 `ask_human` 的 `approve_run_node_once` 卡片请用户审批，一次只批一批。**
