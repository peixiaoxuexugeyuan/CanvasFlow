# 附MD 2 | 欧美暗黑悬疑故事DNA

## #怎么做

### 一、 核心冲突（困兽法则）

每一个分支或高潮，主角必须面临“怎么选都要失去最重要东西”的绝境（如：保全城市失去爱人，或拯救爱人黑化堕落）。

### 二、 节奏与反转

- **前3秒**：必须用一个极具冲击力的画面（如：一道闪电劈下、一个沾血的物件掉落）直接抓住眼球。
- **中段**：动作与悬疑交织，信息量密集。
- **结尾**：必须有一个让人倒吸一口凉气的“暗黑反转”或“宿命感”收尾。

### 三、 对白与旁白

- 对白必须短促、有力，充满黑色幽默或冷酷感。
- 可以加入漫画式的“旁白框”，用旁白交代时间、地点或冷酷的内心独白。
