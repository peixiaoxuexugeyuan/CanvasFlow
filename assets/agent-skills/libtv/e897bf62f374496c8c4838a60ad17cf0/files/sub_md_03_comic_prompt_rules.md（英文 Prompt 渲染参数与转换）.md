# 附MD 3 | 英文 Prompt 渲染参数与转换

## #怎么做

### 一、 强制正向渲染词

在将中文分镜转为英文 Prompt 时，尾部必须带上：\
`Graphic novel style, American comic book art, bold black ink outlines, vivid cel shading, halftone dot patterns, high contrast lighting, cinematic dynamic angles, dramatic shadows, 8k resolution.`

### 二、 强制反向词（防崩排雷）

必须带上：\
`realistic, 3D render, photograph, anime, chibi, flat colors, low quality, blurry, deformed hands, extra fingers, watermarks, text.`

### 三、 图生视频转换注意

在跑 4 秒视频时，运动幅度必须调低，保持“漫画页活过来”的轻微动态感（如：火焰微动、头发微飘、光影闪烁），严禁出现人物肢体融化或面部变形。
