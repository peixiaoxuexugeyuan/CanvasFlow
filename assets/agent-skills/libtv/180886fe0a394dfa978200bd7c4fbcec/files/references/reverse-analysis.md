# 逆向解析与提示词诊断

## 1. 输入与操作分别判断

只有用户要求从图片重建提示词、反推画面、拆解成型描述时，才执行逆向解析。图片也可能是风格参考、被比较对象或问题证据，不自动当作需要复制的完整画面。

已有 prompt 的“优化”遵守其意图，解决遗漏与矛盾；“分析问题”先解释影响，不能未经要求把所有内容重写成自己的视觉方案。

## 2. 提取可见关系

按本次有内容的维度观察：

- 主体：数量、外形、服装、身体取景、姿态、视线与接触。
- 空间：观察位置、大小关系、距离、遮挡、必要环境与留白。
- 视觉：媒介、光线、颜色关系、材质和成像特点。
- 文字：可辨的准确内容、位置、样式和次数。

不要求八个维度都有内容。纯静物可以没有人物；扁平图形可以没有真实景深；模糊参考不应凭空补清全部细节。

## 3. 区分观察、推断与补充

| 层次 | 示例 | 如何写 |
|---|---|---|
| 明确可见 | 深色长外套、人物位于门旁、暖色区域在桌面上 | 直接描述 |
| 合理外观推断 | 近似阴天散射光、较宽视野、胶片般的颗粒观感 | 用“呈现……观感”；需要时说明是复现建议 |
| 无法确认 | 真实镜头与相机型号、准确曝光、具体地点日期、人物背景 | 不写成原图事实；用户需要时提出候选而非断言 |
| 设计补充 | 为未给出的镜头关系选择可行写法，补足目标用途需要的信息 | 不声称来自参考；显著改变原图时单独标明 |

单张图像通常不能唯一确定全部拍摄设置，也不能恢复原作者实际使用的 prompt。目标是重建可见效果与关系，不是伪造制作记录。

参考图的噪点、失焦或压缩痕迹，只有用户希望复现时才当作目标。用户只借用配色时，不把参考中的低清晰度、人物或文字一起复制。

看不清的文字、被遮挡的物体或人数，不为了“完整”补成确定内容。关键文字无法辨认时说明限制并请用户提供原文；不将猜测放进引号充当准确文字。

## 4. 输出组织

默认先给一条重建 prompt，内部按主文件“主体→景别与构图→光线→色调→镜头与成像”的五项顺序组织，正文使用无栏目标签的自然语言，并执行输出前自检；用户要求一段或指定格式时按对应规则适配。再用短表拆解有内容的维度，可以在表中合并观察与对应写法，不逐项重复整段 prompt。拆解表位于 prompt 之外，不把表头带入提示词。不为填模板编造未知细节；重要的不确定项简短说明。

| 维度 | 观察与对应写法 |
|---|---|
| 主体或空间 | 具体可见关系 |
| 光线或颜色 | 可见效果；必要推断标清 |
| 不确定项 | 只列会影响复现的重要未知，不列无关的技术空缺 |

用户明确只要 prompt 时省略表格。用户只要分析时先给分析，不强制写一条新 prompt。重要不确定性仍需简短说明，不能用输出格式掩盖。

用户需要近似复现时，保留核心构图、比例、色彩和光线关系；用户需要优化时，先区分原有特征和建议改变。不要借“补全”偷偷换时代、换身份、增加情节或重做风格。
