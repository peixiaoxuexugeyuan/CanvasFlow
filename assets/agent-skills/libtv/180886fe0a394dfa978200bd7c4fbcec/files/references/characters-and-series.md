# 人物辨识度与系列图文字设定

用于用户明确要求设计人物、多个角色，或同一人物、产品和地点的系列图。普通单图不必先输出设定表。

## 1. 先判断是保留设定，还是开发设定

- 用户提供人物或参考并要求整理、反推、改写提示词：保留已给身份特征，不为了“独特”重新设计脸、年龄、肤色、身体比例或服装。
- 用户明确要求设计角色，或允许补充外形：可开发具体方案；重要新增设定简要标明为设计补充，不声称来自原文。
- 信息不足且会改变核心身份：只澄清关键处。普通造型空缺可按明确的创作范围补充，不逐项追问。

从照片不能确认确切年龄、国籍、职业经历或性格。需要用于提示词的可见外貌可按视觉描述；不要把外观联想到的背景写成已确认身份。

## 2. 从整体到局部设计辨识度

先考虑整体轮廓和比例，再选少量稳定的局部特征。不要把所有人都写成精致对称的相似面孔，也不靠一人一条疤来制造差异。

| 层次 | 可选描述 | 使用原则 |
|---|---|---|
| 整体 | 脸部轮廓、身体比例、头颈关系、肩背与体态 | 与用户设定、媒介和需要的剪影一致，不仅换衣服颜色 |
| 面部结构 | 眉眼间距、眼睑、鼻部轮廓、唇部、下颌关系 | 选择足以区分且在本图可见的组合，不罗列全部五官 |
| 头发与整理习惯 | 发际线、分缝、卷曲或服帖、局部处理方式 | 不将特殊发色或夸张发型作为必要条件 |
| 身体与行为 | 重心、常用手、惯常姿态或与物体互动的方式 | 有用户或设计依据；单次表情不当作永久身份 |
| 服装与物件 | 轮廓、剪裁、穿着方式、材质、必要配饰或物件 | 区分常用造型与当前阶段，不强制每张图出现全部物件 |
| 生活痕迹 | 衣物实际磨损、个人修补或整理细节 | 与设定相容；不按职业、年龄或阶层自动套脏污和破损 |

伤疤、纹身、异色瞳、夸张五官都只是可选设计。未经要求不靠生理差异暗示善恶、能力或性格。普通而可信的比例组合也可以有辨识度。

服装、背景和动作不能代替人物身份设计。反过来，也不要为了证明身份把所有细节强塞进每张图。

## 3. 多角色差异检查

比较人物的整体轮廓、面部比例、体态、发型与服装轮廓。若主要区别只剩配色或配饰，检查是否需要在用户允许的范围内增强造型差异。

差异不要求每个维度都相反。同一家庭、群体或制服角色可以相似；保留用户要求的相似性，再用合适的细节区分。不要擅自改掉共同的年龄、服装、身体特征或族群设定。

## 4. 固定设定与当场状态

| 相对固定的内容 | 按情境变化的内容 |
|---|---|
| 已确认的面部结构、身体比例、发际线和稳定标记 | 表情、视线、姿势、汗水、伤势与情绪表现 |
| 当前阶段的基础服装、必要配色与物件设计 | 衣物脏污、开合状态、脱穿、携带或放置状态 |
| 产品或道具的结构、尺寸关系、图案与准确文字 | 磨损、破损、开启、装载等不同状态 |
| 同一地点的布局、出入口与固定结构关系 | 时段、天气、临时陈设、人物位置与事件痕迹 |

用户明确设定年龄变化、换装、发型改变、成长或空间重建时，建立新阶段，不能用“保持一致”否定剧情或设计要求。

## 5. 文本锚点的复用方式

系列图先维护简短的固定设定，再按当前画面选择可见模块。选用的同一特征保持稳定措辞，之后写本图的动作、场景与状态；不要每次重新用同义词改写脸部结构。

- 远景：优先身体轮廓、发型外形、服装和相对尺度，不要求毛孔和微小标记可见。
- 中景：优先身体比例、服装结构、动作与必要物件。
- 近景：优先面部比例、可见标记和细节，不把不可见的全身服装写成画面内容。
- 背影或遮挡图：使用实际可见的稳定特征，不强制正面五官出现。

锚点可以是内部设定记录，不必每次附长表。用户要批量提示词时，确保每条具备独立使用所需的上下文，不能只写“同上”或“同一个人”。用户明确使用有上下文的工具时，可按其格式精简。

文字锚点用于减少描述自身的漂移，不承诺跨生成锁脸或结构绝对一致。可描述用户参考中可见的身份特征；依赖参考图实现身份保持的工具配置、多图输入分工和图像编辑流程不在本技能范围内。

## 6. 一个设计与复用示例

用户授权从零设计一位中年修表师时，可以提出如下**设计补充**：

“偏长的脸，上眼睑较厚，鼻头圆钝，下颌较窄；头顶稀疏，两侧头发修剪整齐。身形窄瘦，灰色针织背心右下侧有细密补线。”

这只是一个方案，不成为“中年人”或“修表师”的默认模板。近景可选脸部和头发模块；全身展示可选轮廓与服装。手持什么工具、是否流汗、是否低头，应属于当场状态。
