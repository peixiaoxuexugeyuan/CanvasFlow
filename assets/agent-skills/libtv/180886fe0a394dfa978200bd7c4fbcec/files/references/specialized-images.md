# 文字、产品与功能图像的写法

按交付物选取相关部分，不把产品、海报或功能图像的内容要求强加给其他任务。内部使用主文件的五项模板及输出前自检，默认成文为无栏目标签的自然语言；用户要求一段或指定格式时按对应规则适配。本文件中的“先处理”“先写”等说明内部设计优先级，成文时仍将信息放回主模板对应位置。标志、UI、信息图等不适用的摄影子项不强填，改用相应的版式、颜色和呈现信息。

## 1. 准确文字与版式

需要准确呈现的原文用引号包裹，不自动翻译、改字或扩写。按需要说明：

- 文字位于什么对象或区域，标题与副标题的层级。
- 字体调性、字重、大小关系、颜色与背景对比。
- 出现次数，是否需要逐字准确或保持特定拼写。
- 哪些额外文字或标识需要排除。

区分画面内的包装、门牌、路标、编号、UI 标签，与额外字幕、水印和无关标志。已经要求编号，就不能再附“禁止所有数字”。用户只要求不加字幕，也不等于要删除所有场景文字。

字体名、品牌名和语言原文由任务决定，不套用普遍的禁名规则。只有明确需要无文字或无品牌时，才写对应边界。

大段正文、密集规格表或极小文字若影响可读性，可建议预留版面并后期排版。仍应完成本次能完成的 prompt，说明哪些内容待补；用户明确要尝试直接生成时，不把排版建议当成拒绝理由。不承诺提示词能保证文字零错误。

## 2. 产品、物体与道具展示

优先确定产品身份、关键结构、部件关系、尺寸比例、材质、颜色、准确标识与使用状态。不要为了美感改变产品结构或编造功能。

根据用途选择展示：

| 目的 | 合适的描述重点 |
|---|---|
| 结构与设定确认 | 可读轮廓、必要视角、部件和尺寸关系 |
| 材质与工艺展示 | 合适的光线、反射、接缝、纹理与表面状态 |
| 生活方式或情境广告 | 产品与人物、环境的真实使用关系，注意尺寸与接触 |
| 包装文字与标签 | 正确原文、位置、版式和可读范围 |

背景与光线服务用途，不默认灰背景、俯拍、极浅景深或戏剧性暗光。高光可以帮助表达材质，但不能无意覆盖关键结构或文字。新、旧、损坏、开启等状态分清，不同时写成互相排斥的状态。

## 3. 海报、封面与包装

先处理信息层级、主体与标题的占位关系、阅读顺序、留白和裁切，再描述照片、插画或其他素材的风格。封面不必高完成度商业摄影，电影海报不必胶片风。

用户未给完整文案时，只能补允许设计的短语或明确待补项，不编造真实活动日期、地址、赞助方和人物头衔。需要预留标题区时，让主体与文字区兼容，不只在结尾追加“留白”。

## 4. 信息图、科教图、图表与幻灯片

先写受众、要说明的知识点、信息层级、关系、标签与数据，再写视觉形式。可采用扁平、立体或其他适合的媒介，不将某种风格定为全部功能图像的标准。

事实、数据和引文使用用户材料或可靠核实来源；缺失的重要输入用明确待补项，不用看似真实的数字填空。用户要演示数据时可以使用清楚标明的虚构示例，不冒充真实统计。

区分布局漂亮与关系正确。流程方向、坐标、图例、单位、比例和标签需要一致；不为装饰添加会改变解释的箭头、部件或因果关系。

文字密度与版面尺度相容；不要用强虚化、颗粒、眩光或无关装饰妨碍阅读。只有用途确实需要时才限制图库素材、渐变或阴影，不附固定排除串。

## 5. UI 与标志

**UI 效果图**：明确设备或画布方向、页面类型、导航、内容区、卡片、按钮、间距、标签和信息层级。用可信的示例内容填充用户允许的空缺，真实业务数据需有依据。视觉效果图不等于可运行界面，不声称具备实际交互功能。

**标志或 logo**：根据品牌性格与用途确定图形、字标、轮廓和负空间。简洁、扁平和少笔画只是选项，不能覆盖用户要求的复杂纹章、渐变或其他方向。区分独立标志与印在包装上的展示图，不默认附加场景 mockup。

## 6. 历史、插画与多格画面

**历史题材**：采用用户已给或有依据的时间地点。只知道大致年代时不编造精确日期；服装、建筑、器物和文字与该语境一致。重要历史细节需要查证时明确处理，不用模板替代考据。

**插画与绘画**：优先造型、线条、笔触、色块、材料及空间处理。不要自动添加摄影毛孔、相机参数、镜头噪点和真实光学景深；用户希望混合媒介时可有选择地结合。

**多格漫画或指定图像分镜**：按用户已给的格数和内容组织可见节拍，每格保持动作、角色与空间可读，不把连续动作硬塞进单格。这里处理图像提示词，不主动扩展为整部影片的导演方案或视频时间码。
