# 景别、空间、景深、构图、光线与色调的选择

用于摄影、电影静帧、场景图，或需要具体分析视觉选择的任务。以下都是条件性方法；不把情绪词固定转换为某种镜头。插画可以借用取景和关系组织，但不必使用摄影参数。

## 1. 先确定信息，再选择形式

先在内部用一句话明确本图的作用，例如“让观众同时注意到人物迟疑和门锁上的划痕”。区分必须可辨、只需轮廓或环境提示、需要隐藏的内容。选择应能承载这些信息，而不是先选“85mm、浅景深、青橙色”，再往其中填主体。

内容重要性与成像显著性应协调：可用大小、明暗、颜色、清晰度、位置、遮挡等手段安排注意力，不必全部使用。用户追求含混、均等注意或有意误导时，遵守其目标。

## 2. 景别与取景边界

景别描述取景范围与主体在画面中的尺度，不等于焦段。术语划分可能有差别，关键处同时写出可检查的身体或物体边界。

| 需要的信息 | 可以考虑的取景 | 取舍检查 |
|---|---|---|
| 微小证据、文字、零件、触点 | 局部特写或极近距离取景 | 尺度、方向和物体身份是否仍清楚；不必同时看全人物 |
| 面部反应、细小视线变化 | 面部或头肩近景 | 身体动作或环境是否才是重点；避免只靠眼泪表达情绪 |
| 表情与手部操作 | 中近景，如腰部以上且双手完整入镜 | 手、工具和接触位置不能被无意裁掉 |
| 两人互动、桌面行为、彼此距离 | 双人中景或能容纳关系的取景 | 双方的朝向、视线、物体归属是否可读 |
| 完整姿势、衣着、身体轮廓 | 全身或人物全景 | 头脚及关键服装是否完整；为展示还是有意裁切 |
| 路径、出入口、场景布局 | 场景全景或远景 | 主体缩小后不能再要求微小文字和毛孔都可辨 |
| 人与巨大环境的尺度关系 | 远景或大远景 | 需要人物、门窗或熟悉物体等尺度参照 |

中景也可以紧张，远景也可以亲密；选择取决于内容如何进入画面。用户指定的景别优先保留，若它无法同时满足其他关键信息，说明取舍，而非悄悄换景别。

## 3. 观察位置、透视与镜头线索

先确定观察者在主体的哪一侧、距离与高度，再描述画面范围和前后关系。机位角度、景别、焦段是不同变量：俯视不是远景，长焦不是特写。

- 广角可容纳更宽视野；靠近主体时，近远物体的相对尺度可能更强烈。不要把广角直接等同“人物很小”。
- 较长焦距提供较窄视角；在保持主体大小相近并后退机位的常见取景方式下，前后景会呈现不同的相对尺度。不要只写“长焦压缩”而忽略位置关系。
- 透视关系与观察位置有关；从同一位置换焦段或裁切，不能当作移动机位的替代。ZEISS 对拍摄距离与透视的区别有直接说明。[ZEISS：Macro and Close-up Shooting](https://lenspire.zeiss.com/photo/en/article/macro-and-close-up-shooting-especially-outdoors/)
- 同一毫米数在不同成像画幅上视角不同。若不需要精确设备语境，用“较宽视野、自然近距观察、远距离观察”等结果描述即可。

需要摄影数字时，按目标选少量相容线索，不强制每条都有机身、镜头、光圈、ISO、快门或胶片名称。遇到“狭小房间尽收眼底，同时人物面部占满画面”一类冲突，先调整范围或观察位置，而非继续追加数字。

焦距的视角与放大程度可参考 [Nikon：Understanding Focal Length](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)。这些摄影知识在生成提示词中用于澄清外观，不保证工具按真实设备仿真。

## 4. 景深、背景虚化与焦外

景深是可接受清晰的距离范围，背景虚化程度与焦外呈现还涉及主体和背景的距离等条件；不能把三者当作同一件事。光圈数值也不能独自决定哪些物体可辨。

| 画面需求 | 建议的清晰关系 |
|---|---|
| 面部是重点，背景只需提供地点线索 | 主体清晰，背景随距离柔化，仍保留所需环境特征 |
| 人物与身后的证据都要被发现 | 明确二者同时可辨；根据距离安排较宽的清晰范围或调整站位 |
| 多人在前后不同位置且都重要 | 按人物位置描述清晰要求，避免套用单人肖像的极浅景深 |
| 场景布局或道具结构是交付重点 | 关键出入口、部件和结构关系保持可读 |
| 悬疑需要隐藏身份 | 背景保留轮廓或局部信息，明确什么不需要被认出 |
| 用户要求失焦、抽象或朦胧 | 按其要求设定柔化范围，不自动把面部改回锐利 |

可写“台前人物和两米后门锁上的破损均可辨，远处走廊逐渐柔化”，不必默认“背景完全虚化”。也不要求每张图都有复杂前景；干净设定图和无背景图可以没有多层空间。

景深涉及光圈、焦距和对焦距离等因素；f/4 不等于“主体清晰且背景可读”的通用保证。[Nikon School：Working Notes](https://static.nikonusa.com/pdf/nikonschool/sat.pdf) 主体与背景距离对焦外的影响可参考 [Nikon：Bokeh for Beginners](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/bokeh-for-beginners)。

## 5. 构图与空间关系

先安排主次、距离、朝向、遮挡和留白，再选择对称、三分法、框架、对角线或其他形式。不要求一张图同时满足多个构图名词。

| 要组织的关系 | 可考虑的方法 | 条件与风险 |
|---|---|---|
| 两个对象需要平等比较 | 平衡的双主体、接近一致的展示尺度 | 不用景深或遮挡无意削弱其中一方 |
| 秩序、重复结构或仪式 | 居中、轴线、对称 | 内容和项目风格支持；对称不是压抑的固定符号 |
| 缺席、等待或即将发生的事件 | 留白、主体偏置、视线引向空处 | 留白具有方向或信息作用，不只为了“高级” |
| 有限观察或被观察感 | 门内外、前景遮挡、反射或局部视角 | 符合观察位置；不要惯性加入窗框和栏杆 |
| 动作方向与路径 | 朝向、引导线、适当行动空间 | 有意挤压或截断时可以反向处理 |
| 角色或物体的结构展示 | 稳定取景、轮廓清楚、必要视角 | 不以戏剧性裁切损失识别部位 |
| 海报或封面排版 | 为指定文字预留干净区域 | 文字区不与必要主体互相争抢 |

左右关系以当前画面与观察方向为准；多张图描述同一空间时保留物体之间的世界关系，不把换机位简化成所有物体机械左右翻转。

减少冗余镜头风格，不删除交付必需条件。角色身份、取景边界、手物接触和指定文字可能需要同时约束。

## 6. 光线与明暗

按场景与媒介选择自然光、实际灯具、棚拍、舞台或风格化光线。自然主义摄影通常需要可信光源；超现实图像可以采用特殊规则，但要与用户设定一致。

根据任务选择有用内容，不要求填写完整灯光参数表：

- 来源和方向：窗、顶灯、台灯、招牌、棚灯，光从哪一侧照到主体。
- 软硬与分布：轮廓边缘、阴影过渡、照亮范围与明暗分区。
- 功能：显示材质、识别面部、分隔空间、控制注意力，或有意隐藏信息。
- 光色与混合：光源的冷暖、环境反射和局部色差；不默认暖主光加冷背景。

| 目标 | 可考虑的处理 |
|---|---|
| 看清结构、身份或颜色 | 让关键部位获得足够可读性，保留形体转折；不必一律平光 |
| 突出表面、起伏或形状 | 根据材质选择侧向、掠射或适当反射；不把同一种光用于所有材质 |
| 日常现场感 | 遵守时段、窗位和实际光源，合理补足必要信息 |
| 舞台、广告或超现实造型 | 明确造型方向、色彩和空间规则，不假装只有自然光才专业 |
| 需要隐藏和延迟揭示 | 明确暗处仍保留或不保留哪些信息，避免自动补亮 |

时刻、日照角度和天气互相关联；不能把“下午四点”固定等同黄金时刻。用户没有给地点或日期时，不编造精确事实来证明所选光线。

## 7. 色调与颜色关系

分开描述：物体固有颜色、光源与反射造成的颜色变化、白平衡观感、整体色彩处理。先尊重用户色板和固定资产颜色，再考虑本图的主次与氛围。

内部选择顺序：已确定方向 → 场景和光源颜色 → 信息层级与辨识要求 → 整体及局部处理。

| 需求 | 可写的内容 | 避免的机械做法 |
|---|---|---|
| 产品或服装颜色需要识别 | 关键颜色保留，环境色和光色不掩盖辨识 | 为统一情绪把所有颜色压成同一种灰 |
| 强调特定对象 | 根据场景选择局部色差、明度差或适当彩度 | 所有画面都只留一个红色点 |
| 项目统一 | 固定主导关系、黑白层次与必要强调色，局部按场景变化 | 每张图重新发明色板，或一律相同冷暖光 |
| 复古、插画或商业风格 | 按参考选择色相、对比和饱和度分布 | 复古必须泛黄、插画必须高饱和 |
| 情绪表达 | 结合剧情、材质、明暗和文化语境 | 悲伤=蓝色、幸福=暖黄等硬映射 |

需要精细描述时，从以下维度中选有意义的几项，不全部填满：

- 白：中性白、奶白、灰白等；黑：深黑、抬高黑位、带色暗部等。
- 高光与阴影：是否有明确的冷暖或色相偏移，是否需要保留细节。
- 对比：整体与局部对比、明暗分布，不将“低对比”默认为高级。
- 饱和度：全局与局部的关系，不默认低饱和或局部保色。

百分比色板只在用户需要或能对应具体区域时使用，不制造无法检查的精确感。

## 8. 材质、清晰度与成像特征

材质是对象如何呈现：皮肤、布料、金属、木材或玻璃的表面结构、反射与使用状态。根据景别、光线、用途和媒介决定描述密度；远景不要求毛孔可见，动画皮肤不自动添加摄影毛孔。

成像特征是画面如何呈现：锐度、景深、颗粒、高光过渡、镜头或媒介的外观。胶片颗粒与数字噪点不是同义词，清晰度与“是否真实”也不是同一尺度。

对失焦、拖影、过曝、漏光、脏色或压缩损伤：有明确风格、参考或表达需要才添加；写清范围和程度，不组成默认附加包。运动可以被凝固，抓拍可以清晰，旧照片可以保存良好。

ARRI 的资料将纹理与镜头、曝光、光圈、色彩外观等共同讨论，支持按目标组合而非固定添加质感。[ARRI：Textures FAQ](https://www.arri.com/en/learn/camera-systems/image-science/arri-textures/textures-faq)

若用户说“不要 HDR 感”，先判断其反感的是否是强烈局部对比、边缘亮晕、暗部过度提亮或不自然色调映射。不要把它直接改成“缩窄动态范围”或删除必要细节。HDR 与过度处理外观应区分。[Adobe：Merge photos into an HDR image](https://helpx.adobe.com/photoshop/desktop/adjust-color/hdr-and-channel-manipulation/merge-photos-into-an-hdr-image.html)

## 9. 一个选择示例

输入：“人物回到屋里，发现门锁有划痕；要同时看见他的迟疑和划痕。”

先保护面部反应与门锁证据，再选择包含两者的取景和可辨范围。可以写人物站在门侧、手停在锁旁、视线落在划痕上，适当侧光让划痕显形。若面部与锁的细节在该范围内无法同时清楚，说明取舍或调整站位，不通过堆更多摄影数字假装解决。没有下雨、流泪或复古要求，就不自行添加湿地、泪光与漏光。
