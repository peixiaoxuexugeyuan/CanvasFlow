# 一、Skill 概述

## 1.1 这个 Skill 解决什么问题

把用户意图转成可见、相互一致、适合目标用途的画面描述。专业性体现为选择有依据、约束清楚、信息可读，而不是摄影术语或技术参数的数量。

本技能处理文生图提示词写作、已有提示词优化、参考画面的文字重建，以及用户明确要求的诊断与比较。可根据一个片段写单张图，但不自动把整份剧本拆成资产库或完整分镜。

## 1.2 适用场景

- 根据文字主题编写摄影、插画、产品、海报和功能图像的文生图提示词。
- 整理或优化已有 prompt，检查画面关系、视觉选择和约束。
- 根据参考画面反推可见效果，区分观察、推断和设计补充。
- 开发人物辨识特征，维护多个角色或系列图的文字设定。
- 回答与提示词有关的诊断、比较、原理和修改建议。

## 1.3 不适用场景

不执行生图，不处理原图的换装、合图、删物、蒙版、保留清单或多轮图像编辑。不选择模型或给出 API、分辨率、质量档位等工程设置；用户问起时，区分工具参数与画面描述，不把参数语法塞进 prompt。横竖构图、画面比例和主体占比属于可描述的视觉约束，可以按需写入。

# 三、执行流程

## 步骤 1：理解需求与确认边界

1. 遵守用户明确要求、提供的事实和已确认的系列设定。参考只承担用户指定的作用；风格参考不自动提供人物身份、场景或文字内容。
2. 用途与媒介决定采用哪些表达方法。先识别摄影、绘画、动画、三维渲染或平面设计等媒介，再判断人物设定、产品展示、故事静帧、海报或信息图等用途。
3. 风格与氛围解释已知内容如何呈现，不能自行改掉时间、天气、主体、动作、文字或空间事实。不要机械套用情绪与颜色、景别、布光的对应关系。
4. 普通空缺可作与任务一致的合理设计补充；重要推断不能冒充已知事实。整理已有设定时避免重设计主体；用户要求设计人物或画面时，可以提出具体方案。

把输入区分为：明确设定、合理推断、允许的设计补充、待确认的关键冲突。这是内部工作方法，不要求每次输出表格。

遇到“夜晚的阳光”这类组合，先判断是否是有意的超现实设定或特殊光源，不自动改成月光。若明确要求之间无法兼容，且取舍会改变核心目标，简要说明并澄清；其余细节按一致的方案推进。只问会显著改变结果的问题，避免对每个细节逐项提问。

用户未说明商业用途时，只明确图像类型，不编造品牌定位、受众或投放场景。用户要求抽象、梦境或风格化画面时，遵守其视觉逻辑，不强制改成自然主义摄影。

## 步骤 2：制定画面方案

先确定这张图必须传达什么，再组织视觉手段：

- **信息**：必须看见、辨认或有意隐藏的主体、动作、物体、文字和关系。
- **取景与布局**：用适当范围容纳这些信息，确定观察位置、主次、遮挡与留白。
- **清晰与明暗**：决定哪些内容同时可读、哪些退居背景；再安排景深与光线。
- **风格与颜色**：根据媒介、场景材料、光源、参考和项目方向选择；不自动低饱和、青橙调色或胶片化。
- **约束检查**：解决互相冲突的要求，删除无关修饰，保留全部必要信息。

按任务读取第六部分列出的现有参考文件，不将所有任务统一为摄影或统一风格。

## 步骤 3：编写、优化或重建提示词

### 八类信息覆盖（内部检查）

以下八类信息用于内部检查遗漏，**不再规定另一套成文顺序**。成文按下节五项内部顺序组织为自然语言，不把内部项目名变成提示词标题。

类别检查重点用途与图像类型用户要得到什么交付物；用途未知时只确定图像类型主体与行为身份、形状、比例、姿势、视线、接触方式、相对尺度；只写本次可见且有用的特征空间、观察与布局取景边界、机位或版式、主体位置、距离、遮挡、必要背景与留白媒介与风格表现媒介、时代语境、色彩方向、用户要求的视觉特点光线必要的来源、方向、软硬、明暗分配和光色；可用于显示或隐藏信息材质与成像对象表面与画面呈现分开；颗粒、锐度、焦外或特殊效果按需选择画面文字确切原文、位置、样式、层级、出现次数；没有需求时省略限制与一致性用户真正要求保留或排除的内容、系列锚点、不可改变的事实；不附固定负面词串

八类信息映射到五项模板：用途、主体与必要环境进入“主体”；空间关系和版式进入“景别与构图”；光线单列；色彩与必要风格进入“色调”；镜头、清晰范围、材质与呈现方式进入“镜头与成像”。明确的表现媒介可在主体开头交代。准确文字的内容随所属主体写，位置与层级在构图中写；适用限制随对应栏目写，不另附固定负面词串。

同一信息不重复堆写，不为填项创造文字、背景、光效或排除项。分析时先考虑什么与最终按何顺序输出是两件事。

### 五项内部组织与最终输出

默认中文自然语言；按用户要求切换英文或中英对照。保留必要的专名、准确文字和常用术语，避免无目的中英混排。

标准版：五项内部模板，无标题自然语言

写作、改写或重建 prompt 放在回答最前面，按以下五项的相对顺序写成可直接使用的自然语言。**项目名只是内部组织和自检依据，默认不输出“主体：”“景别与构图：”“光线：”“色调：”“镜头与成像：”等标签、加粗小标题或编号。** 不把写作指令或自检记录放进 prompt。

默认可按信息量分成 2–4 个无标题自然段，不要求每项独占一段，也不把合并段落当作省略内容。用户明确要求一段时，写一个连续段落；明确要求标题、字段或表格时，才采用其指定形式。

内部项目必须检查的内容**主体**图像类型或明确用途、人物或物体、必要外形与结构、当场动作、表情、视线、接触方式及必要环境。不要额外编造出行目的或剧情来代替可见行为。**景别与构图**分别写清取景范围、观察位置与实际画面布局。摄影类不能只写“全身、斜侧面”；还需明确主体或主要信息在画面中的位置，以及适用的留白、层次、遮挡、尺度或空间关系。其他媒介写对应的取景或版式关系。**光线**根据用途交代光源或可见明暗特征、方向及适用的软硬与明暗分配。不能只写“阳光”“电影光”。可有意隐藏信息，不一律补亮。**色调**具体主要颜色关系、饱和程度、对比及必要的冷暖倾向，尊重固定颜色和用户风格。“日系”“清新”“高级”不能单独充当色调描述。**镜头与成像**摄影类写与目标一致的视角或必要焦段线索、对焦重点与清晰范围、成像方向及有用的材质细节；其他媒介写相应的线条、笔触、边缘或呈现质感，不硬填摄影参数。

摄影类五项均需实质覆盖，不能以一句空泛形容词充数。相机型号、光圈数值、颗粒等不是必填答案，依任务选择。非摄影任务真正不适用的光学或照明子项可省略；整项确实不适用时，内部注明原因，成文省略对应内容而保持其余相对顺序，不输出空栏或“无／不适用”占位。

构图不强制三分法、横构图、低地平线或前景遮挡；选适合本图的布局，并把布局实际写出来。独立图形可以写居中、主体占比和边距；开放场景可以写主体位置、行动空间和层次。

摄影类的内容覆盖

标准摄影 prompt 应分别交代主体、景别与机位、实际构图布局、光线、具体色彩关系，以及镜头观察和成像方式；清晰范围放在“镜头与成像”中。不能只靠“日系”“电影感”“清新明快”等概括词代替，不另附一串相机参数。

色彩根据场景写清主导与辅助颜色、饱和程度及明暗关系；成像根据任务明确干净数字、细腻胶片或其他适合的方向。它们是本图的设计选择，不是所有图片统一使用的答案。颗粒仅在选择胶片或其他有依据的颗粒表现时写明细密程度与强弱；相机型号只在用户指定或确有表达价值时采用。不能为满足模板强行添加颗粒、漏光、失焦或器材名。

反推摄影画面时，光线和成像可以用有依据的可见外观表达；真实光源、器材或媒介无法确认时说明不确定性，不为填栏目伪造数字、光源位置或胶片来源。插画、平面设计及功能图像使用对应媒介与呈现描述，不填摄影器材和光学参数。

短版、分节与多版本

- **一句话或一段版**：用户要求“写一段”“一段即可”“一句话”等时，按五项顺序压入一个连续段落，默认不带栏目标签，不再分段。压缩非必要修饰和术语，不将构图、色调或成像整体删掉后保留空泛形容词；极短字数限制下先保留用户硬要求和关键画面关系，不编造细节充数。
- **复杂内容与指定格式**：默认仍以无标题自然段按五项顺序承载，必要的人物、版式和文字要求融入相应位置。用户明确指定分节标题、字段、顺序、段落数或表格时优先遵守；五项仍用于内部覆盖检查，不擅自添加一套可见标签。
- **多版本**：每个版本使用相同模板和适用项顺序，便于比较；版本名称放在 prompt 外。保持已确定身份、事实与必要文字，只变化允许探索的视觉内容。未指定数量且确实需要多个方向时，通常给 2–3 个即可。

按任务交付

- **写作请求**：先交付统一模板中的完整 prompt；必要时在后面简短说明重要设计补充，不抢在 prompt 前展开分析。
- **反推请求**：重建 prompt 使用同一五项标准版、用户指定的短版或格式，随后按需附拆解表；重要的不确定项不能隐藏在确定语气里。
- **诊断请求**：先回答问题或指出影响，不为了“提示词优先”跳过用户需要的解释。

具体写清可见关系，替代空泛标签。例如“腰部以上，双手握住车把并完整入镜，视线投向前方”比“自信而有活力”更可检查。静态图描述一个可见瞬间，不把连续多步动作和相互排斥的姿势挤在同一身体上。

限制冗余风格指令，不限制关键约束数量。人物身份、双手入镜、物体接触、结构比例与文字可读可以同时是必要条件。

## 步骤 4：自检、修订与交付

对实际准备发送的内容执行第 4.2 节的完整自检。发现漏项、空泛描述或冲突，先按原规则修订；随后按用户要求交付提示词、拆解表或诊断意见，不把内部栏目名和自检过程写进 prompt。

# 四、规则与约束

## 4.1 风格规范与成像选择

真实感可来自可信的光照、材质、人体结构和空间关系。清晰对焦、受控曝光、自然色彩与严谨构图同样可以真实；也不把这些效果强加给有意模糊或抽象的任务。

区分：对象材质（如织物与金属）、成像特征（如景深与颗粒）、特殊效果或缺陷（如拖影、失焦、过曝、漏光、压缩损伤）。后两类按用途、用户要求、参考或具体表达需要选择，不成套添加。

抓拍不等于失焦，复古不等于漏光，电影静帧不等于胶片或宽银幕，街头摄影不必高反差。摄影、插画、设定图与功能图像各自服从任务。

对黄金时刻、湿地反射、眼泪、轮廓光、大光圈虚化等惯性选择，检查：是否与已知事实兼容、是否服务本图、是否遮住必要内容。有事实或设计依据就保留；无作用的填充可删。合理设计不需要伪装成输入事实，也不因怕套路而删除用户明确要求的元素。

## 4.2 质量检查点：输出前的固定格式自检（必须执行）

生成草稿后，针对**实际准备发送的最终 prompt**逐项核对，而不是只确认自己想过这些内容。多版本、批量提示词和中英对照的各版本分别检查。

自检项通过标准常见未通过情况格式与顺序五项适用内容按相对顺序融入自然语言；默认无栏目标签或编号，合并段落不漏项；一段版只有一个连续段落，用户自定格式则遵守其要求把内部项目名写成提示词标题；合并后漏掉构图、光线或色调；要求一段却分段主体必要身份、行为、物体与场景可理解，符合已给事实用“开心”“孤独”代替全部行为，或添加无依据剧情景别明确取景范围或可检查的身体、物体边界只有“35mm”，无法确定取景范围机位明确适用的观察方向、位置或角度只写“电影镜头”，没有观察关系构图在实际文字中写出主体或信息位置，以及适用的留白、层次、遮挡、尺度或空间关系只写“全身、前方斜侧面”，把景别和机位当作构图；只说“构图好看”光线有可理解的光源或可见明暗特征，适用的方向、软硬与分配明确只有“阳光”“柔美光线”，没有实际表现色调有具体颜色关系与适用的饱和、对比或冷暖处理只有“清新日系”“高级电影色”镜头与成像摄影类的视角或必要镜头线索、对焦与清晰关系、成像方向可理解；非摄影为对应媒介的呈现只堆器材名称，或整项缺失；为了填项自动加颗粒和失焦交叉一致性主体位置与运动方向、取景与细节尺度、虚实与必要文字、光色与固定设定不矛盾人物向右跑却只在左侧留行动空间；门牌必须可读却写全部背景完全虚化适用性与真实性尊重媒介和用户要求，区分观察、推断与设计补充；必要文字与身份设定稳定给标志硬加摄影参数，或从参考伪造精确器材与未知文字

内部将各项判断为“通过／需修订／不适用／不可确认”。不适用必须有题材或用户要求依据，不能把摄影构图漏写解释成不适用；参考信息不足时可记录不可确认，并在需要处如实说明，不能伪造后宣称通过。

发现漏项、空泛占位或冲突，先修订再重新核对受影响项；完成检查后才交付。原始要求本身存在无法合理消解的关键冲突时，简要说明取舍或澄清，不以虚构细节硬凑通过。用户明确字数或格式限制优先，检查的是在该限制下保留关键要求，不为凑模板突破限制。

自检默认在内部完成，不输出逐项判断、评分或思考过程，也不在 prompt 里追加“已通过自检”。用户明确要验收说明时，只提供简短的结果依据和仍存在的限制。

## 4.3 禁止事项与技术边界

需要准确呈现的文字使用引号，按需写位置、字体调性、颜色、层级和次数；照抄原文，不自行翻译或改字。无法辨认或缺失的关键文字不编造。

区分必要的场景文字与额外字幕、水印和无关标识。不要在要求门牌、编号或包装文字后，再写“禁止所有文字、数字”。用户要无文字图像时，才写对应限制。

将“不要廉价”“不要 AI 味”等模糊意见尽量转成具体画面目标；需要排除的对象可以明确说明。否定表达的效果依赖模型与上下文，不宣称必然有效或必然适得其反。优先少量、相关且无冲突的约束。

品牌和器材名称按任务处理：不自动往画面中加入无关商标；用户指定的产品或准确文字应保留。摄影器材、胶片型号若作为外观线索，需确有帮助，不作为必填或真实拍摄证明。不要以本地写作习惯强制排除用户需要的名称。

相机、焦段与光圈描述只是外观线索，不承诺精确光学模拟。数字不能取代对取景、透视关系与清晰范围的描述；避免无意义的“8K、杰作、最高质量”堆砌。

# 五、示例

示例只展示现有功能与输出形式，其中的服装、布局、配色及成像不是所有图片的固定答案。

## 示例 1：正向写作与一段输出

输入：写一段女生在草原奔跑的图片提示词，开心、阳光。

输出：一张户外人像照片，女生穿白色上衣、藏蓝色半裙和运动鞋，在草原上向画面右侧轻快奔跑，笑着望向前方。全身取景，从前方斜侧面观察，人物位于画面左侧，右边留出奔跑空间，远处草坡与天空形成开阔背景。柔和日光从左前上方照亮脸颊和衣服，背光侧保留浅淡阴影。以草地绿、天空蓝及衣服的白与藏蓝构成配色，饱和度适中、明暗对比柔和。自然透视，对焦人物，远处草坡逐渐柔化，采用细腻清晰的数字摄影成像。

## 示例 2：反推中的未知信息

输入：反推参考图，并告诉我真实相机型号和门上模糊小标签的文字。

处理方式：按图中可见的主体、布局、明暗、颜色与成像外观重建提示词；清晰文字准确引用。真实相机无法确认时说明无法确认，小标签无法可靠辨认时不猜写；必要的不确定性放在提示词外简短说明。是否附拆解表遵守用户本次要求。
