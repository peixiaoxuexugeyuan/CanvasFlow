# 附MD 4 | 日漫心理悬疑专属风格

## #做什么

专用于《PROVENANCE》等悬疑、智斗、情感拉扯题材，彻底关闭“热血大招”参数，开启“黑深残、微表情、高智商博弈”模式。

## #怎么做

### 一、 视觉风格锁定

- 强制注入：`Psychological suspense anime, Death Note art style, mature proportions, dark tone, sharp lines, dramatic shadow casting, intense character gaze.`
- 禁止：Q版、热血打斗、明亮鲜艳色彩、元气表情。

### 二、 表现力强制放大（日漫特有）

- 将真人的“微表情”放大为动漫式的“颜艺”：瞳孔骤缩、冷汗滑落、咬紧牙关、红血丝、阴影覆盖半张脸。
- 强调“光影分割”（伦勃朗式动漫打光）。

### 三、 视频生成要求

- 人物保持绝对的静止或极微小的动作（如：眨眼、呼吸、眼神的移动）。
- 镜头只做极慢的推拉，靠光影的移动和环境的压抑感来制造恐怖与紧张。
