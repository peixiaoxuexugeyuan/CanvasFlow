## 缺失资产判定

### 需要单出资产（保留）
- 阻塞拍摄的核心场景（该场全部镜头依赖）
- 特写镜头中出现、承担剧情功能的核心道具（如情感纸条、献宝金属）
- 贯穿多场的道具（多场重复出现）
- 影响因果链的 VFX（如"光球→捏碎→碎片→重组"）

### 剔除（交给模型/场景自行发挥）
- 只出现一次且不关键的通用道具（号牌、令牌、文具、烛台）
- 剧本环境装点（文书堆、常见家具）
- 可复用通用 NPC 模型的群演

### 优先级排序

| 级别 | 含义 | 例子 |
|------|------|------|
| P0 | 阻塞拍摄，缺失则该场无法拍 | 第三场核心场景、情感核心道具、关键VFX |
| P1 | 贯穿多场或承担特写 | 主角手持道具、转场VFX |
| P2 | 环境补充，可先拍其他角度避开 | 案头文书、光源道具 |
| P3 | 非特写可后补 | 远景可见的小配饰 |
| P4 | 可复用通用资产 | 群演NPC |
