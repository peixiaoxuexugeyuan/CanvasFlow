# 分镜脚本模板（定稿格式）

> 按剧本原顺序逐场拆解；角色外观一律以资产图（步骤1理解结果）为准。
> 分镜阶段**不引用 @素材编号**、不写摄影语法术语、不用"="赋值记法，只用物理动词写可见动作。

## 单段结构

段标题下**直接进镜头**，不加引用块、不加"叙事目的/尾帧衔接"行（这些属于提示词阶段的板块）。

```markdown
### 视频N｜{标题}（约Xs / N 镜）

镜N｜{起}-{止}s｜{景别}，{机位方位与运镜}
画面：{镜头里可见的人物动作、神态、道具状态；台词写作 开口{……}}
结束时：{本镜机位拍得到的结束状态——切换逻辑落在这一行，不设"切镜"行}
```

## 文件头部全局说明块（放在篇名之下、第一个场次之前）

```markdown
> {场次数} 场 / {段数} 段 / {总镜数} 镜 / 约 {总秒数} 秒
> 结构：场次 → 视频段 → 镜头；镜号全局连续，每镜写清画面与结束时状态
> 台词原文照剧本、写进画面；时长按漫剧口径「字数×0.25 秒＋每个有台词镜头 0.2 秒尾静」配平、**以视频段为容量核算单位**（段内台词总秒数≤该段时长即合格），单镜常规 {X–Ys}、连续动作弧 ≤{Zs}
> 场景：{主场景与人物布局口径}
> {主体状态链：如 无猫耳（视频1–9）→ 吞丹（视频8末）→ 长猫耳（视频10起至结尾）}
> {后期说明：如 面板任务文字全部后期叠字，画面只表现光芒动态}
```

- 段内可局部编号（镜1…镜N），也可像第04集那样全片连续编号（镜1…镜83）；两种方式都要**每镜只装一个说话人的完整动作**，加镜就顺延重排后续编号并同步核算表，**不用 7A/7B 这类子编号**。
- 场次分隔用 `## 4-N｜{地点} {时间}·{内/外}`，段与段之间用空行加 `### 视频N｜…` 起头。
- 每镜只装一个说话人的完整动作；同机位的连续动作合为一镜，不得拆成两镜各说半句。
- **跳切自检**：相邻两镜若"机位方位＋取景对象＋纵深构图"三项实际画面信息相同、只换了台词或微动作，即判跳切，必须改机位方位或合并；禁止用"轻微推近""镜头稍晃"这类画面未变的修饰冒充机位差异（SKILL 约束52）。
- **景深自检**：纵深构图每一层必须是离镜头距离可辨的独立可见物体——同一个人的手与身体合并成一层；脚下地面与人物同深度不得充当前景；身前无遮挡物时只写"主体（最近一层）＋背景"两层，不虚构前景凑三层（SKILL 约束53）。
- **方位自检**：写"画左/画右/画面深处"之前先按该场景的机位方位换算表推导（SKILL 约束49），回查两条判据——谁正对镜头、谁背后就是深处那面墙；前景若是某人后脑或肩线，该人必为背向镜头。
- **状态链自检**：分镜阶段就为每段列出跟踪物清单（每人手持/身前道具、人物位置姿态、一次性 UI、跨段颜色形态），逐镜标注其当前状态格；提示词阶段每镜据此写【连续提醒】行，状态翻转后续镜必须延续新状态（SKILL 约束54）。

## 时长核算表（放全部分镜之后）

```markdown
| 视频 | 标题 | 镜数 | 时长 | 台词字数 | 台词秒数 | 动作秒数 | 合计 | 核查 |
|------|------|------|------|----------|----------|----------|------|------|
| **合计** | | {总镜数} | {总时长} | | | | | ✅ |
```

> 表下附三行声明：总时长、单镜与单段上限是否达标、状态链（如非人主体的形态变化时点）。

## 导演备注（可选，放最后）

- 表演要点、喜剧节奏、配音反差
- 关键道具的镜头使用限制（如"简面文字需特写清晰"）

## 常见运镜写法

| 术语 | 可用写法 |
|------|----------|
| 可直接用 | 推、拉、摇、移、跟、环绕、俯冲、低机位、第一人称、大全景→特写 |
| 需翻译 | 移焦：焦点从前景A平滑转移到背景B，A虚化B清晰；希区柯克变焦：主体大小不变、背景空间拉近 |

注意：一段镜头只保留一个主要运镜；非战斗场面的大全景/横移/拉远在快节奏版中直接取消。
