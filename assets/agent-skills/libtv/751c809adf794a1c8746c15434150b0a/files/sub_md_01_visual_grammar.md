# 附MD1 | 胡金铨·写意武侠视觉语法与防崩禁则

## #做什么

锁定胡金铨写意武侠的美学底线与防崩红线。

## #怎么做

### 一、视觉底色与美学基调（融合邵氏复古质感）

- **美学核心**：禅意留白、文人画般的写意江湖。
- **媒介优先于细节（新增）**：先让画面像七十至八十年代彩色电视或VCD转制，再去刻画人物。轮廓微柔，局部微反差低，颜色浓厚偶有串色，高光有薄辉光，暗部成块（不要保留现代HDR细节）。
- **绝对禁止**：现代数字锐化、胶片齿孔/黑边、高饱和霓虹、赛博朋克、日式樱花。

### 二、构图与景别硬规则（新增）

- **占空比**：远景人物占高 5%-15%，中景占 25%-45%。
- **光影分离**：人物脸部有柔和暖补光，背景强侧逆光/冷色月光。允许牺牲物理真实，人脸绝不能死黑。

### 三、镜头语法与防崩

- 大量固定机位、长静止极短爆发、人物渺小化、留白构图。
- 武器必须是宋/明形制，严禁激光剑；发型必须是古代束发，严禁现代短发。
