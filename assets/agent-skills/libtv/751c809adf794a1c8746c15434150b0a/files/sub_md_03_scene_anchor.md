# `sub_md_03_scene_anchor.md`\
\
附MD3 | 胡金铨·专属场景资产锚点库

## #做什么

锁定场景氛围，确保全片场景100%一致，杜绝旅游外景感。

## #怎么做

### 一、五种构图母型（新增）

1. 巨树/竹拱形成暗框，人物在明亮雾中；
2. 人物作为小剪影置于横向云海/草海；
3. 双人横向舞台对谈，留大块负空间；
4. 前景草叶遮挡，中远人物动作成为落点；
5. 人物一侧，瀑布/月轮/巨松形成大背景色块。

### 二、五种色彩模式（新增，主色覆盖65%-85%）

1. 青绿瀑布（暖象牙补光托白衣）
2. 金色芦苇（雾后低逆光）
3. 钴蓝月夜（蓝黑剪影为主，禁用两个清晰太阳）
4. 雾蓝山水（阴天冷光）
5. 桃金花野（暖色侧逆光）

### 三、框中框与光影锚点

- 必须至少有一个“框中框”（门窗/竹缝）前景。
- 光影分离：人脸暖补光，背景强侧逆/冷光。\
