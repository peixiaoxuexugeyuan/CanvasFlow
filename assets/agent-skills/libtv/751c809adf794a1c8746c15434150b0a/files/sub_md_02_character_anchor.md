#  附MD2 | 胡金铨·角色锚点与造型一致性规范

## #做什么

确保全片人物形象100%一致，贯彻“反游侠化”的银幕造型。

## #怎么做

### 一、人物与服装硬规则（融合去游侠化）

- **气质**：端正匀称、轮廓柔和、神态沉静，避免网红尖脸。
- **服装**：以大块长袍为主（宽袖、长下摆、干净垂坠），禁用护腕、皮革肩带、斜挎包、多层战术腰带、金属铆钉、盔甲、现代靴型。
- **发型**：整洁束发、冠髻，女性少量旧式簪钗。

### 二、衣袂惯性锚定（胡金铨专属标志）

- 静立、爆发、收势、转身，衣角发丝必须保有惯性飘动，禁止突变定格。
