# 附MD4 | 胡金铨·分镜脚本与Prompt输出模板

## #怎么做

### 一、八要素/七要素填空公式（新增融合）

- **画面构图**：明确景别、人物面积、框中框。
- **场景层级**：前景实物、中景演员、远景雾幕。
- **质感句式**：`an actual frame from a 1970s Chinese wuxia film, live-action period film still, theatrical mist, painted distant mountains`。

### 二、双人构图法则（新增）

双人物画面采用**不等距、不等高或不同身体朝向**的平衡式不对称。严禁把两人做成镜像复制（同脸型/同发髻/同服装/同站姿）。
