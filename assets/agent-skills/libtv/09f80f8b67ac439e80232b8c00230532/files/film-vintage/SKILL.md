# 胶片复古

## 核心原则

胶片复古的本质不是"加滤镜"，而是**模拟一种有物理缺陷的化学成像过程**——光线穿过镜头、触碰感光涂层、经过不稳定的化学显影、再随时间降解褪色。每一步都留下痕迹：颗粒不均匀、色彩偏移、边缘漏光、涂层斑驳。这些"不完美"恰恰是胶片美学的灵魂。

**持久引擎（因果链）：**

题材选择 → 胶片类型匹配 → 时代色温定位 → 颗粒密度与分布 → 偏色方向与强度 → 漏光/光斑位置 → 暗角与边缘退化 → 冲扫后期模拟 → 最终画面

链上每一步都对应一个可调维度。偏离任何一环，画面就会"像数码套滤镜"而非真正的胶片质感。

**质量测试（可证伪）：**

> 如果把画面转成灰度图后，仍然能通过颗粒分布密度不均、暗角过渡方向、漏光光斑的有机形状判断出"这不是均匀数码噪点"，则胶片感成立。反之，如果颗粒均匀如静态噪点、暗角对称如径向滤镜、漏光呈几何形状，则判定为"假胶片"，必须重做。

## 输入诊断

落 prompt 前必须明确或合理假设以下维度：

1. **胶片风格路线**（四选一或组合）：
   - 60-70年代老胶卷：高对比、暖偏色（琥珀/黄褐）、粗颗粒、轻微褪色、暗角重
   - 80-90年代柯达/富士：柔和偏色（柯达偏暖金、富士偏冷绿）、经典电影感、中等颗粒
   - 过期胶卷/漏光：随机色偏、漏光光斑、涂层退化、色彩不可预测、部分区域欠曝或过曝
   - 拍立得/即时成像：白边框、色彩偏移（青蓝/品红）、柔和模糊、显影不均、边缘化学残留斑
2. **题材**：人像 / 街拍 / 风景 / 静物 / 生活记录 / 抽象艺术
3. **目标市场与语言**：默认中国大陆/中文
4. **画幅**：不锁定。常见选择——竖屏 9:16（手机端短视频）、横屏 16:9（电影感）、1:1（拍立得/社交图文）、3:2（经典胶片比例）、4:3（老式相机比例）
5. **色温基调**：暖调（黄昏/室内钨丝灯）/ 冷调（阴天/荧光灯/雪景）/ 中性
6. **时代感强度**：轻度（轻微偏色+细颗粒）/ 中度（明显褪色+中颗粒）/ 重度（强偏色+粗颗粒+漏光+暗角）
7. **颗粒类型**：黑白银盐颗粒（点状、锐利）/ 彩色染料颗粒（团块状、柔和）/ 数码噪点模拟（均匀、应避免）
8. **漏光方向与颜色**：左上角暖橙 / 右下角冷蓝 / 顶部条状 / 全画面弥漫 / 无漏光
9. **产物类型**：图片 or 视频。视频时长 ≤15s 用一次生成即可拿到完整成片
10. **合规敏感点**：不生成涉及真实品牌胶卷商标的内容；人像题材注意肖像权

## 工作流

### 第一步：诊断输入

从用户描述中提取：胶片风格路线、题材、色温、时代感强度、画幅、产物类型。用户未指定的维度给合理默认值，不要反复追问。若用户只说"胶片感"而未指定路线，默认走80-90年代柯达路线（最通用、最不易翻车）。

### 第二步：加载风格词库

按路由表读取 `references/formats/film-styles.md`，获取对应风格路线的完整描述词、prompt句式和质量参数。

### 第三步：构建 prompt

**图片 prompt 构建模板：**

```
[题材描述]，[主体动作/状态]，[场景环境]，[光线描述]，[胶片风格路线]，[色温与偏色方向]，[颗粒描述]，[漏光描述（如适用）]，[暗角描述]，[画幅比例]，[额外风格修饰]
```

示例（60-70年代老胶卷·人像）：
> 年轻女性站在老式电话亭旁，侧头望向镜头，午后斜阳穿过树叶投下斑驳光影，60年代柯达Kodachrome胶卷质感，琥珀暖色调偏色，粗颗粒胶片颗粒不均匀分布，轻微褪色发黄，左上角橙红色漏光，四角暗角明显，3:2画幅

示例（拍立得·生活记录）：
> 桌上散落着咖啡杯和翻开的书本，窗外阴天柔光，拍立得即时成像照片风格，白边框，色彩偏移泛青蓝，柔和模糊，显影不均的色斑，边缘化学残留痕迹，1:1画幅

**视频 prompt 构建模板：**

≤15s 的视频用一次生成即可拿到完整成片。在图片风格描述基础上，叠加运镜与时间轴：

```
[完整图片风格描述（同上）]，[运镜方式]，[时间轴beat：0-4s/4-8s/8-12s/12-15s每个时段的主体动作与镜头运动]
```

示例（过期胶卷·街拍视频，9:16竖屏，15s）：
> 穿旧皮夹克的男子走在傍晚老巷里，脚步踩过积水的反光，夕阳从巷口斜射进来，过期胶卷质感，随机色偏（画面左半偏青、右半偏品红），漏光光斑从顶部流入呈橙红色条状，涂层退化导致部分区域轻微欠曝，粗颗粒，四角暗角，9:16竖屏，镜头随人物步伐缓慢跟随推进，0-4s人物背影入巷脚步特写，4-8s镜头上摇至巷口漏光，8-12s人物转身侧脸被夕光照亮，12-15s人物走出巷口画面被漏光吞没

### 第四步：静默自检

对 prompt 执行质量门检查（见"静默自检"章节），不通过则修正后重出。

### 第五步：生成与交付

图片直接生成。视频若 ≤15s 则一次生成完整成片；若 >15s 则拆成若干 ≤15s 片段各自一次生成，再做后处理拼接。

## 输出契约

### 图片输出规格

| 字段 | 内容 |
|---|---|
| 风格路线 | 60-70年代 / 80-90年代 / 过期胶卷 / 拍立得 |
| 题材 | 人像 / 街拍 / 风景 / 静物 / 生活记录 / 抽象 |
| 色温 | 暖调 / 冷调 / 中性 |
| 偏色方向 | 琥珀 / 金黄 / 青蓝 / 品红 / 混合随机 |
| 颗粒 | 细颗粒 / 中颗粒 / 粗颗粒 + 分布描述 |
| 漏光 | 位置 + 颜色 + 形状（无漏光则填"无"） |
| 暗角 | 轻度 / 中度 / 重度 |
| 画幅 | 9:16 / 16:9 / 1:1 / 3:2 / 4:3 |
| 时代感强度 | 轻度 / 中度 / 重度 |

### 视频输出规格（≤15s时间轴beat）

| 时间段 | 主体动作 | 镜头运动 | 光线变化 |
|---|---|---|---|
| 0-4s | [beat1] | [运镜] | [光] |
| 4-8s | [beat2] | [运镜] | [光] |
| 8-12s | [beat3] | [运镜] | [光] |
| 12-15s | [beat4] | [运镜] | [光] |

注：≤15s视频一次生成完整成片，以上beat是同一prompt内的时间轴描述，不是分段多次生成。>15s时按每段≤15s拆分生成后拼接。

## 静默自检

落 prompt 前内部跑一遍以下检查，不通过则修正后重来，不外显给用户：

- [ ] 风格路线是否已明确（未指定则默认80-90年代柯达）
- [ ] 颗粒描述是否为"不均匀分布"而非"均匀噪点"（均匀噪点=假胶片，必须修正）
- [ ] 漏光描述是否有有机形状方向（条状/弧形/弥漫），而非几何对称
- [ ] 暗角是否为非对称渐变（胶片暗角天然不均匀），而非径向滤镜式对称
- [ ] 偏色是否为胶片化学特性方向（琥珀/金黄/青蓝/品红），而非任意颜色
- [ ] 画幅是否已确认（未指定则默认9:16竖屏用于视频、3:2用于图片）
- [ ] 视频时长是否≤15s（是→一次生成完整成片；否→拆段生成后拼接）
- [ ] prompt措辞是否全正向描述（避免"不要""不能""避免"等否定式）
- [ ] 是否未出现真实胶卷品牌商标名（Kodak/Fuji/Polaroid作为风格参照可用，但不生成商标logo）
- [ ] 全文语言是否为中文，无中英混杂
