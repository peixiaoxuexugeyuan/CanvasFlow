# 胶片风格词库

> 四种胶片风格路线的完整描述词、prompt 句式与质量参数。按路由表选用对应路线，把词库中的句式融入 prompt。

---

## 一、60-70年代老胶卷

### 核心质感
高对比度、暖色调偏色、粗颗粒、轻微褪色、重暗角。模拟早期彩色胶卷（Kodachrome / Ektachrome 早期代）的化学成像特征。

### 色温与偏色
- 主色调：琥珀黄、黄褐色、暖橙色
- 阴影偏色：深棕偏紫红
- 高光偏色：暖黄偏橙
- 褪色方向：整体偏黄褐色调，蓝色通道衰减明显

### 颗粒描述词
- 粗颗粒，不均匀分布，密度从画面中心向边缘递增
- 银盐颗粒感，点状锐利颗粒
- 暗部颗粒更粗更密，亮部颗粒较细

### 暗角描述词
- 四角明显暗角，非对称渐变，左下角通常更重
- 暗角过渡柔和但范围大，占画面边缘30%-40%

### 漏光描述词（可选）
- 左上角橙红色漏光，呈弧形扩散
- 顶部条状暖光，模拟胶片背面缝隙漏光

### prompt 句式模板
> [主体描述]，60年代柯达彩色胶卷质感，琥珀暖色调偏色，粗颗粒胶片颗粒不均匀分布，轻微褪色发黄，四角明显暗角，[可选：左上角橙红色漏光弧形扩散]，高对比度，[画幅比例]

### 适用题材
人像（复古肖像）、街拍（老街巷）、风景（黄昏/沙漠/老旧建筑）、生活记录（老式室内场景）

## 二、80-90年代柯达/富士

### 核心质感
柔和偏色、经典电影感、中等颗粒、自然对比。模拟柯达Portra/Gold系列与富士Superia系列的成像差异。

### 两种子路线

#### 柯达路线（暖金）
- 色温：偏暖，金黄色调
- 皮肤表现：肤色偏暖偏金，自然红润
- 绿色表现：偏黄绿，较浓郁
- 阴影：温暖深棕，不偏冷
- 颗粒：中等颗粒，柔和团块状

#### 富士路线（冷绿）
- 色温：偏冷，淡青绿色调
- 皮肤表现：肤色偏冷白，略带青
- 绿色表现：偏青绿，清透
- 蓝色表现：偏青蓝，浓郁
- 阴影：偏冷深蓝绿
- 颗粒：中等颗粒，比柯达略细

### 颗粒描述词
- 中等颗粒，柔和团块状（彩色染料颗粒特征）
- 分布相对均匀但仍有密度变化
- 暗部颗粒略增

### 暗角描述词
- 轻度至中度暗角，过渡自然
- 暗角较对称但不完全均匀

### prompt 句式模板

柯达路线：
> [主体描述]，80年代柯达Portra胶卷质感，暖金黄色调偏色，肤色自然红润，中等颗粒柔和团块状分布，轻度暗角自然过渡，经典电影感对比，[画幅比例]

富士路线：
> [主体描述]，90年代富士Superia胶卷质感，淡青绿色调偏色，肤色偏冷白，中等颗粒略细柔和分布，轻度暗角自然过渡，清透电影感，[画幅比例]

### 适用题材
人像（自然光肖像）、街拍（都市/旅行）、风景（自然风光/四季）、生活记录（日常/咖啡馆/旅行）

## 三、过期胶卷/漏光

### 核心质感
随机色偏、漏光光斑、涂层退化、色彩不可预测、部分区域欠曝或过曝。模拟存放多年后感光涂层化学性质退化的胶卷。

### 色温与偏色
- 主色调：不可预测的混合色偏（同一画面不同区域偏不同色）
- 常见组合：画面一半偏青蓝、另一半偏品红/橙
- 极端情况：整体偏单一色相（全青/全品红/全黄）
- 褪色方向：色彩衰减不均匀，部分色彩保留、部分色彩消失

### 颗粒描述词
- 粗颗粒至极粗颗粒，密度极不均匀
- 某些区域颗粒异常密集，某些区域异常稀疏
- 暗部颗粒严重粗化，可能出现颗粒团块

### 漏光描述词
- 漏光是本路线的核心特征，必须出现
- 顶部橙红色条状漏光，模拟胶片背面缝隙漏光
- 角部弧形光斑，暖橙或冷蓝色
- 全画面弥漫性漏光，降低整体对比
- 漏光边缘有色彩分离（漏光区域边缘出现红/青色边）

### 涂层退化描述词
- 画面局部出现涂层斑驳，色块不规则
- 部分区域轻微欠曝（涂层感光力下降）
- 个别区域过曝（涂层局部敏感化）
- 边缘可能出现化学残留痕迹

### prompt 句式模板
> [主体描述]，过期胶卷质感，随机色偏（画面[方向]偏[色A]、[方向]偏[色B]），[漏光位置]漏光光斑[颜色]呈[形状]，粗颗粒不均匀分布密度变化大，涂层退化局部斑驳，部分区域轻微欠曝，四角暗角不规则，[画幅比例]

### 适用题材
街拍（废墟/老巷/雨天）、抽象艺术、人像（情绪/暗调）、风景（阴天/雾天/废墟）

## 四、拍立得/即时成像

### 核心质感
白边框、色彩偏移、柔和模糊、显影不均、边缘化学残留斑。模拟即时成像相机的化学显影过程。

### 色温与偏色
- 主色调：色彩偏移，常见青蓝偏色或品红偏色
- 高光偏色：偏青蓝
- 阴影偏色：偏品红或偏绿
- 整体饱和度低，色彩柔和但有偏移

### 颗粒描述词
- 细颗粒至中等颗粒，柔和
- 颗粒分布较均匀但质感柔软（非锐利）
- 显影不均导致某些区域颗粒更明显

### 边框描述词
- 白色边框（经典拍立得宽边框）
- 底部边框更宽（经典600型/方形相纸）
- 边框可能略泛黄（老相纸）

### 显影不均描述词
- 画面局部出现显影不均的色斑
- 边缘可能出现化学显影残留痕迹
- 某些区域略显模糊（显影不完全）
- 色彩过渡不干净，有轻微色彩混叠

### 柔糊描述词
- 整体画面略微柔和，边缘有轻微扩散感
- 不等于失焦，而是化学显影的物理特性
- 近距离拍摄时柔糊更明显

### prompt 句式模板
> [主体描述]，拍立得即时成像照片风格，白色宽边框，色彩偏移泛青蓝，细颗粒柔和质感，显影不均的色斑，边缘化学显影残留痕迹，画面略微柔和边缘轻微扩散，低饱和度，[画幅比例]

### 适用题材
生活记录（桌面/咖啡/食物）、人像（亲密/日常/朋友）、静物（书/花/小物件）、旅行快照

## 通用质量参数

以下参数在四种路线中通用，按需在 prompt 中组合使用：

### 对比度
- 60-70年代：高对比度
- 80-90年代：中等对比度，电影感
- 过期胶卷：低对比度（漏光降低整体对比）
- 拍立得：低至中等对比度

### 暗角强度
- 60-70年代：重度暗角
- 80-90年代：轻度至中度暗角
- 过期胶卷：不规则重度暗角
- 拍立得：轻微或无暗角

### 颗粒密度对照
| 路线 | 颗粒密度 | 颗粒类型 | 分布特征 |
|---|---|---|---|
| 60-70年代 | 粗 | 银盐点状锐利 | 中心稀疏边缘密集 |
| 80-90年代柯达 | 中等 | 彩色染料团块柔和 | 相对均匀有轻微变化 |
| 80-90年代富士 | 中等偏细 | 彩色染料团块柔和 | 相对均匀略密 |
| 过期胶卷 | 粗至极粗 | 混合型不规则 | 极不均匀有团块 |
| 拍立得 | 细至中等 | 柔和染料 | 较均匀但显影不均 |

### 画幅推荐
| 题材 | 推荐画幅 | 理由 |
|---|---|---|
| 竖屏短视频 | 9:16 | 手机端平台 |
| 电影感横屏 | 16:9 | 宽银幕 |
| 拍立得/社交 | 1:1 | 经典拍立得比例 |
| 经典胶片 | 3:2 | 135胶片标准 |
| 老式相机 | 4:3 | 中画幅/老式相机 |
