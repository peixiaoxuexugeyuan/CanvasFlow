# 平台规则与画幅选择

## 画幅选择指南

| 平台 | 推荐画幅 | 说明 |
|---|---|---|
| 抖音/快手/小红书 | 9:16 竖屏 | 手机端全屏体验，短视频平台首选 |
| 微信视频号 | 9:16 或 16:9 | 竖屏优先，横屏可接受 |
| B站 | 16:9 横屏 | 横屏为主，电影感内容适合 |
| 朋友圈 | 1:1 或 9:16 | 方形或竖屏均可 |
| Instagram Reels | 9:16 竖屏 | 海外平台竖屏 |
| Instagram Post | 1:1 或 4:5 | 方形或竖版方图 |

## 胶片风格与画幅搭配建议

| 胶片路线 | 首选画幅 | 理由 |
|---|---|---|
| 60-70年代老胶卷 | 3:2 或 4:3 | 还原老式相机比例，增强时代感 |
| 80-90年代柯达/富士 | 9:16 或 3:2 | 竖屏适配社交平台，3:2还原胶片经典 |
| 过期胶卷/漏光 | 9:16 或 3:2 | 竖屏街拍效果好，3:2保留胶片感 |
| 拍立得/即时成像 | 1:1 | 拍立得经典正方形比例 |

## 默认值

用户未指定画幅时：
- 视频默认 9:16 竖屏（适配国内短视频平台）
- 图片默认 3:2（经典胶片比例，最通用）
- 拍立得路线图片默认 1:1

## 合规注意

- 不生成真实胶卷品牌商标/logo（Kodak/Fuji/Polaroid 作为风格描述词可用，但不生成品牌标识画面）
- 人像题材不指定真实人物姓名，使用通用描述
- 不生成涉及版权的胶片电影画面复刻
