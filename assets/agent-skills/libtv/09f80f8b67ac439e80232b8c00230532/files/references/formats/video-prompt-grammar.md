# 视频胶片 prompt 文法

> 在选定胶片风格路线的基础上，叠加运镜与时间轴描述。≤15s 视频用一次生成即可拿到完整成片。

## prompt 组合顺序

```
[完整胶片风格描述（从 film-styles.md 选取）]，[运镜方式]，[时间轴beat]
```

风格描述在前，运镜在后，时间轴最后。保持一条 prompt 完整描述整个画面。

## 运镜描述词

| 运镜类型 | 描述词 | 适用场景 |
|---|---|---|
| 固定机位 | 镜头固定不动 | 静物/风景/肖像 |
| 缓慢推进 | 镜头缓慢向主体推进 | 人像/情绪/特写 |
| 缓慢拉远 | 镜头缓慢从主体拉远 | 风景/结尾/交代环境 |
| 横移跟随 | 镜头随人物步伐缓慢横向跟随 | 街拍/行走 |
| 跟拍推进 | 镜头跟随人物前进方向推进 | 街拍/巷道/走廊 |
| 上摇 | 镜头从低处缓慢上摇至高处 | 建筑/全身 reveal |
| 下摇 | 镜头从高处缓慢下摇至低处 | 交代主体到细节 |
| 手持晃动 | 轻微手持晃动感，呼吸节奏 | 生活记录/纪实感 |
| 缓慢旋转环绕 | 镜头绕主体缓慢弧线运动 | 人像/静物展示 |

## 时间轴 beat 结构（15s 标准）

| 时段 | 定位 | 内容要点 |
|---|---|---|
| 0-4s | 建立 | 主体入画/环境交代/第一个视觉锚点 |
| 4-8s | 发展 | 主体动作推进/视角变化/情绪累积 |
| 8-12s | 高潮 | 最强画面/关键动作/光线最佳时刻 |
| 12-15s | 收束 | 主体出画/情绪定格/留白或漏光吞没 |

每个 beat 写清三件事：主体动作、镜头运动、光线变化。

## 胶片风格叠加运镜的注意事项

- 运镜速度要"慢"：胶片质感与快速运动不太兼容，缓慢运镜让颗粒、漏光、偏色有展现空间
- 漏光方向与运镜方向配合：镜头朝光源方向运动时漏光增强，背离时减弱
- 手持晃动仅用于生活记录和纪实风格，60-70年代和拍立得路线不用手持
- 过期胶卷路线可让漏光在运镜过程中变化（增强不确定性）

## 视频 prompt 示例

### 60-70年代老胶卷·人像（9:16，15s）
> 年轻女性站在老式电话亭旁，侧头望向镜头，午后斜阳穿过树叶投下斑驳光影，60年代柯达彩色胶卷质感，琥珀暖色调偏色，粗颗粒不均匀分布，轻微褪色发黄，四角明显暗角，高对比度，9:16竖屏，镜头缓慢向人物推进，0-4s人物侧面剪影入画树叶光影斑驳，4-8s镜头缓慢推进人物转头侧脸被夕阳照亮，8-12s镜头继续推进至半身特写暖光打在脸颊，12-15s人物低头微笑画面暗角加深定格

### 过期胶卷·街拍（9:16，15s）
> 穿旧皮夹克的男子走在傍晚老巷里，脚步踩过积水的反光，夕阳从巷口斜射进来，过期胶卷质感，随机色偏（画面左半偏青、右半偏品红），漏光光斑从顶部流入呈橙红色条状，涂层退化导致部分区域轻微欠曝，粗颗粒不均匀密度变化大，四角暗角不规则，9:16竖屏，镜头随人物步伐缓慢跟随推进，0-4s人物背影入巷脚步踩过积水反光，4-8s镜头上摇至巷口顶部橙红漏光涌入，8-12s人物转身侧脸被夕光照亮色偏加剧，12-15s人物走出巷口画面被漏光吞没

### 拍立得·生活记录（1:1，10s）
> 桌上散落着咖啡杯和翻开的书本，窗外阴天柔光透过纱帘，拍立得即时成像照片风格，白色宽边框，色彩偏移泛青蓝，细颗粒柔和质感，显影不均的色斑，画面略微柔和边缘轻微扩散，低饱和度，1:1画幅，镜头缓慢向桌面推进，0-3s桌面全景咖啡杯书本散落，3-6s镜头缓慢推进至咖啡杯口热气升腾，6-10s镜头推至书本特写页面文字模糊可辨显影不均色斑明显
