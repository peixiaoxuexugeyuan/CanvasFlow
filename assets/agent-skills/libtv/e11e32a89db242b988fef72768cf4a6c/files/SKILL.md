# 一图多风格迁移成片

把同一张城市/风景实景照片，转绘成厚涂油画、几何平面装饰、国风金箔岩彩等多种绘画风格，再合成一条「镜头微推、风格硬切、实景收尾」的成片视频。

## 适用场景

- 用户提供一张实景照片，希望得到多种绘画风格的转绘结果，并最终合成一条成片视频。
- 典型题材：城市日落河景、地标建筑群等横构图实景。

## 输入

- 一张实景照片（建议城市或风景，横构图）。

## 输出

- 一条 16:9、720P、约 5 秒、带声音的多风格硬切成片视频。

## 执行流程

### 第 0 步：底图

用户上传一张实景照片作为底图（示例：中州岛日落城市河景，中景为带穹顶的欧式建筑群、远景高楼、左侧江面与桥）。

### 第 1 步：统一画幅（得到唯一基准图）

- 新建图片节点，引用底图。
- 参数：`model=nebula-ultra`，`modeType=image2image`，`ratio=16:9`，`quality=2K`。
- 提示词：`按照实景,将图片比例变成16:9`
- 作用：把底图规整为 16:9 标准实景基准图，作为后续所有风格转绘的共同引用。

### 第 2 步：多路风格转绘（并行，三路）

三路转绘互相独立，均以**第 1 步的基准图为唯一底图引用**，参数一致：`model=nebula-ultra`，`modeType=image2image`，`ratio=16:9`，`quality=2K`。因为共享同一张基准图、只更换风格，各风格的构图与主体保持一致。

> 风格说明文本节点（素材-风格-\*）只是风格标签，不承载额外提示词。

风格特效模板的传递方式（两档，按优先级）

原画布上三路风格转绘节点的保存输入里，除 `model=nebula-ultra`、`modeType=image2image`、`ratio=16:9`、`quality=2K` 外，还各带两个特效字段：

- `effects`：数字数组，例 `effects=[22288905]`
- `effectTemplateUuids`：字符串数组，例 `effectTemplateUuids=["22ce411d43b941738d9a5b0bf5a2ef1e"]`

三组对应关系即上表。传递方式分两档：

**首选（特效模板可用时）**：把风格特效作为斜杠玩法/特效模板挂在风格转绘节点上，即向节点写入 `effects` + `effectTemplateUuids`（按上表三组对应关系）。提示词只写「依据实景图片,按照参考风格,转绘为××」这一句，风格由特效模板承载，保证跨次跑批复刻一致。

**兜底（Agent 建节点拿不到特效入口时）**：Agent 侧的 `create_image_node` 没有 `effects` / `effectTemplateUuids` 参数入口，`prompt_template` 只接受固定枚举（如 `style_display_board`、`portrait_texture_adjustment` 等），装不下这类用户自定义特效模板，因此由 Agent 直接建节点时挂不上这三个模板。此时把该风格的视觉特征逐条写进提示词来等效实现，同时**保留「共享基准图引用」这一固定锚点**。三份风格特征清单：

- **厚涂油画肌理 几何色块**：几何色块拼接天空、厚重笔触、颜料堆叠、橙金与深蓝强对比。
- **几何分割的平面装饰风格**：硬朗几何切割、纯色平涂无渐变、波普圆点纹理与漫画式云形、藏蓝/明黄/橙红/米白配色。
- **国风金箔岩彩画**：金箔流云与放射云纹铺天、青绿朱砂赭石矿物设色、描金勾线、飞鸟与传统祥云纹样。

**实测结论**：兜底路线已在商场黄昏实景底图（节点 `i-dCcBU6VAjs` → 基准图 `i-s6g67swqe2hx` → 三风格 → 成片 `v-ydkarsnm7u3y`）上跑通，四段构图与主体一致、风格切换清晰，成片可用；但风格细节的稳定性弱于挂特效模板，若要批量复刻同一套风格应走首选路线。

### 第 3 步：合成成片视频（风格间硬切、不加任何转场）

- 新建视频节点，参数：`model=wanx3.0`（Wan 3.0），`modeType=mixed2video`，`ratio=16:9`，`resolution=720P`，`duration=5s`，`enableSound=on`，`extendPrompt=1`。

- 按顺序引用三张风格图 + 实景基准图（示例顺序：厚涂油画 → 几何平面装饰 → 国风金箔岩彩 → 实景基准图）。

- 提示词采用以下完整写法（逐字保真）：

  开头一句：

  > 镜头全程微动、缓慢推进，单一连续运镜贯穿整条片子。不同风格之间硬切，切点干净利落，不要任何转场效果（无叠化、无淡入淡出、无擦除、无溶解、无闪白）。

  随后按时间轴分段列出引用，例：

  > 0-1秒：{风格1图} 厚涂油画肌理，几何色块拼接的天空与车流光斑。 1-2秒：{风格2图} 几何分割的平面装饰画风，纯色平涂、波普圆点云。 2-3秒：{风格3图} 国潮鎏金岩彩画，金箔流云、描金勾线、飞鸟与远山。 3-5秒：{实景基准图} 落回黄昏实景航拍基准画面，城市商圈与广场车流。

  结尾一句：

  > 同一座主体建筑、同一构图与同一视角在各段之间严格保持一致，画面只做风格硬切，镜头推进不断。

关键写法要点

- **必须把「不要任何转场」用括号逐项列举排除**（无叠化、无淡入淡出、无擦除、无溶解、无闪白）；只说「硬切/快速切换」不足以约束模型，实测容易被模型自由发挥成叠化。
- **必须写明「单一连续运镜贯穿」「镜头推进不断」**，让镜头运动跨越切点保持连续；否则硬切处会被误判为镜头中断而产生跳变。

**实测验证结论**：按上述写法在 `v-ydkarsnm7u3y`（Wan 3.0 / 16:9 / 720P / 5s / `enableSound=on` / `extendPrompt=1` / `modeType=mixed2video`）上重新生成，逐帧核验 0.8–3.4s 区间，三个切点均为整帧翻转、相邻帧之间无两套风格叠加的中间态，镜头从 0s 到 5s 持续缓慢推近且机位连续，符合要求。该节点为最终交付版本，旧版已被覆盖。

## 方法要点（锚点）

1. **先规整画幅再转绘**：同一张底图先统一为 16:9 基准图，后续所有风格都基于它，避免各风格画幅/构图漂移。
2. **并行多路、共享基准图引用**：多路风格转绘共享同一基准图引用，因此风格之间互相独立但主体与构图一致——首选路线靠 `effects`/`effectTemplateUuids` 区分风格，兜底路线靠提示词里的风格特征清单区分风格，该共享引用锚点在两档下都保留。
3. **mixed2video 分段硬切（逐项排除转场）+ 镜头连续推进 + 实景收尾**：把若干风格图 + 实景基准图按时间轴分段交给 `mixed2video` 模型；风格之间硬切、逐项排除任何转场效果，同时用「单一连续运镜贯穿、镜头推进不断」保证镜头运动跨越切点连续，最后落回实景收尾。

## 可替换槽位

- 实景底图（任意城市/风景横构图照片）。
- 风格种类与数量（可增删风格路数）：**首选路线需同步替换** `effects` **/** `effectTemplateUuids` **这一对值；兜底路线需同步替换提示词里的风格特征清单**。
- 视频时长与分段节奏（时间轴分配）：**调整分段时长时，开头的转场排除句与结尾的镜头连续句都要保留**。
- 视频节点引用顺序与时间轴分配。

## 固定锚点

- 第 1 步「先规整画幅得到唯一基准图」。
- 第 2 步「并行多路、共享基准图引用」。
- 第 3 步「mixed2video 分段硬切（逐项排除转场）+ 镜头连续推进 + 实景收尾」。
