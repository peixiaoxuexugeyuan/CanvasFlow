# 济公哲理 AI 对话短片 · 一键生成技能（v2.1 · 原句保真）

对标抖音 **@僧间话**（抖音号 77186372631，合集《师父，人间苦吗》，2026-10-20 时 7 作品 2.7 万粉，2026-11-12 实抓 28 作品 17.1 万粉 / 195.4 万获赞，单条峰值 22.4 万赞 / 8.0 万分享）。核心方法论：**把鸡汤从「宣讲」改成「对话」，给说狠话找一个全民都认的合法身份，用一个看得见的小物把道理带出来。** 但在本技能里，**风格可以设计，用户写下的字一个都不能动**——见 ①-B。

## ① 触发条件（双入口）

- **入口 A · 关键词**：用户输入一个哲理关键词（`内耗`、`讨好`、`放下`、`喜恶同因`……）。此时无用户原句，才允许按 ③ 语录引擎生成台词。


- **入口 B · 整段对话（优先）**：用户直接粘贴一段师徒/问答式哲理对话全文（常见 5~~6 轮、100~~200 字，形如「师父：…／弟子：…／师父：…」）。**识别到多轮对话即走入口 B，不要求用户先提炼关键词，不改写、不删减、不自造。**


- 或说「做一条济公语录」「来一集师父人间苦吗」「哲理对话短片」。


- 可附修饰：`45秒`、`60秒`、`用XX作喻`、`更狠/更温和`（只影响画面与节奏，不影响台词）。


- **只给内容即可开工，不追问风格/平台/角色**——全部走默认值。

## ①-B 语录保真四原则（⚡v2.1 硬规则，入口 B 必执行）

> 用户已明确要求：**全案语录要与输入保持一致，不要私自更改**。以下四条优先级高于本文件其余所有规则；与之冲突的旧规则（去宣讲化改写、删抽象词、每句≤15字、标题金句全片无人念出、自造主金句）**一律作废**。

\#

原则

具体含义

1

**逐字不改**

原句的每一个字、标点、语气词（`嘿！`、`傻小子`、`记住，`）、说话人、先后顺序全部保留。禁止同义替换、缩写、删词、去「渡/大彻大悟/修行/红尘」等词、拆分后重组、把长句压成短句。

2

**不增不减**

不新增任何片内台词，不新增自造金句，不把标题塞进台词，不补「愿你/共勉」式收尾。**片内台词表 = 用户输入全文的逐句转录**。

3

**不换人、不换序**

师父说的归师父，弟子说的归弟子；不把师父长句改成童子提问，不调整轮次顺序以「优化节奏」。

4

**保真优先于时长**

原文超出默认 30 秒容量时，**不删句、不加速、不改字**，自动按约 3.0 字/秒把时长扩展到能装下原文的最短值，并在开题卡写明换算式。若用户明确指定了一个装不下的时长，也只列出冲突与建议时长，**不擅自删减**。

### 标题与金句：只能「原文切片」

- 主标题、3 个备选标题、描述偈语、封面文案，**一律从用户原文逐字截取**（整句或分句），每条标注「取自原文第 X 句」。


- 禁止套六公式另写、禁止改写原型、禁止编造「对标语录原型与实测点赞数据」。


- **允许主标题在片内被念出**（原文就是这么写的）；取消「标题金句全片无人念出」这条旧规则。


- 「爆款语录引擎」在入口 B 降级为**原文切片引擎**：只做挑选与标注，不做创作。

### 长句跨镜（消化长原文的关键手法）

一句原文台词可拆成 **2\~4 镜**：**声音连续、画面硬切、字幕按镜分段上屏**。拆出来的字幕片段拼接后必须与原句逐字一致。禁止为了凑时长把长句改短，禁止用旁白代替原句。

### 起喻物

只作**纯画面锚点**（道具、手部特写、空镜），不进台词、不替代原句、不借它另造一句道理。物须与角色或场景同源（旧布鞋/破扇/落叶/茶碗/青苔石阶），贯穿 ≥3 镜。

## ③ 语录引擎（仅入口 A 启用）

入口 A（只给关键词、无用户原句）时才允许生成台词：

1. **共鸣三件套**：具体的人 / 具体的夜 / 没说出口的话 / **转给谁**，写进开题卡。


1) **来源优先级**：优先改写全网已验证的高赞断言并标注改写点 → 真实高赞评论提炼 → 最后才自造。不得编造实测数据。


1. **六公式**：否定常识 / 责任回移 / 一体两面 / 善意反转 / 时间落差 / 身份反打。


1) **五指标**：≤20 字 · 含「你」 · 反常识带锋芒 · 可截图当签名 · 有明确转给谁。


1. **三禁用**：鸡汤尾、抽象大词、佛经术语。

## ⑥ 创作铁律（必须全部遵守）

1. **原句保真最高优先**：入口 B 下 ①-B 四原则压倒一切；任何「优化、润色、去说教、压字数」都不允许。


1) **只答不问**：用户给内容就一次性交付六段式，不反问、不征询确认。


1. **不增删台词**：片内台词表与用户输入逐句一一对应，可在开题卡附「原文逐字校验表」逐句打勾。


1) **一集一哲理**：全片只讲一个道理，靠画面与节奏统一，不靠改台词。


1. **标题即原文切片**：主标题/备选/描述全部逐字取自原文并标注出处，不自造、不改写。


1) **时长保真自适应**：`发声秒数 ≈ 原文字数 ÷ 3.0`，`总时长 = 发声 + 静默/空镜`；默认 30 秒仅在原文装得下时成立。


1. **纯对话体**：全片零旁白、零口播、零说教总结、零「点赞关注 / 愿你 / 共勉 / 评论区告诉我」。


1) **两人一景**：只有师父与童子两个角色、一个主场景（可加同场景内 1\~2 个道具空镜位）；绝不出现第三人、绝不换场景。


1. **说话顺序照原文**：原文谁先说就谁先说；可在两轮之间插入师父无声小动作（摇扇/呷茶/拾物）作停顿，但不改变轮次。


1) **起喻物只入画不入词**：辣椒、落叶、旧布鞋、茶汤、破扇……用画面呼应原句意象，贯穿至少 3 镜；禁止借物另造新台词。


1. **零旁白零总结**：结尾只留空镜与静默，不补方法、不补结论、不上价值。


1) **长句跨镜不断音**：一句原文拆多镜时，配音连续、画面硬切、字幕分段，拼接后逐字等于原句。


1. **全中文书写**：分镜与 AI 提示词一律中文（英文只作术语括注，如「等效 85mm / f2.0」）；英文字幕为**意译**，中文台词字幕必须逐字等于原文。


1) **每镜三要素齐全**：提示词第一句写景别，并写明机位与运镜；运镜只允许固定 / 极缓推 3\~5% / 正反打 / 硬切，禁止环绕、摇臂、甩镜、变焦冲击、闪白溶解转场、法术特效。


1. **一致性四锁**：锁脸（三视图）、锁衣（补丁位置）、锁景（S1/S2/S3 基准图）、锁光（同一时刻同一方向）；分镜里不重新描述长相与场景，只写「沿用角色卡 / 基准图」。


1) **每片预埋评论区梗**：玩梗型 + 争论型各一，争论点从原文最可争议的那句生长出来，不改字。


1. **合规硬线**：显著且全程可见「内容由 AI 生成」；济公取民间文学形象，不复刻真实演员肖像与声音、不蹭逝者煽情；不涉宗教募捐、开光、算命、消灾改运、医疗与功效承诺；不涉在世人物、真实事件、涉灾涉警涉政；不使用真实寺院名义与标识。


1) **时间轴连续性**：每镜时间码首尾相接、无跳变倒流，末镜终点 = 设定时长；台词字数与语速、停顿秒数与总时长必须对得上。

## ⑦ 输出规格（固定六段式 · 一次性交付）

1. **开题卡**：哲理内核（用原文自己的话概括，不改写）/ 共鸣三件套 / **语录组（主标题 + 3 备选 + 描述偈语，全部原文切片并标注出处）** / 片名（取原文短句）/ 目标人群痛点 / 起喻物（纯画面）/ 体裁参数表（时长·镜数·**原文总字数**·语速·画幅·换算式）/ 合集编号 / 情绪曲线 / 观众带走的一句话（原文切片）；**入口 B 必须附「原文逐字校验表」**：逐句列出用户原句 → 对应镜号 → 字幕拼接结果 → 逐字一致打勾。


1) **语录剧本**：逐句台词表（时间码 / 说话人 / **原句逐字** / 字数 / 语气动作 / 潜台词），标注静默镜；附字数与时长复核式；附中英双语字幕文本（中文逐字原文、英文意译）；附「台词表 = 用户输入全文」校验行。


1. **分镜剧本表**：镜号 / 时间码 / 景别·机位·运镜 / 画面 / **原句片段（逐字）** / 中英字幕 / 音效；随后给**逐镜可直接粘贴的中文 AI 画面提示词**（每镜以全局风格前缀开头、只写一个动作）；长句跨镜处标注「声音连续·硬切」；表末附时间轴连续性复核行。


1) **人物角色卡**：济公、小沙弥各一组「三视图定妆照提示词 + 负面四禁止」；标注本集道具锚点。


1. **场景与风格锁定卡**：S1 石阶双人全景 / S2 木廊茶案 / S3 道具空镜位 三张基准图要点 + 全局风格前缀 + 一致性四锁 + 运镜白/黑名单 + 成片规格。


1) **音频与发布包**：双声线配音参数、三层音轨、标题三选一（**全部原文切片**）、描述、固定标签、合集编号、封面帧、发布时间建议、评论区预埋梗（玩梗型 + 争论型各一）、合规声明。
