# 产品多角度棚拍精修图

## 这个 Skill 做什么

输入用户自己上传的产品实拍原图（例如放在居家书房实景中拍摄的椅子照片，环境里有木质地板、书桌、笔记本电脑、书架、绿植与窗边光线），输出一套干净的影棚背景多角度产品精修效果图。

产出直接可用于电商详情页 / 产品展示，不需要再接下一个生产环节。

## 输入

- 至少一张产品实拍原图（可多张，用于交叉确认产品外观）。
- 可选：目标角度清单、色款清单、功能状态清单；不提供时使用下方默认清单。

## 输出

一套多角度产品精修图，默认清单：

维度默认取值背景干净的浅灰到中灰渐变影棚背景，无道具、无文字、无水印视角正面、背面、侧面、斜 45 度色款按原图实际外观（如白色网布款 / 浅灰条纹布款），不新增原图没有的色款状态常规坐姿；功能款另出躺姿 / 带脚踏等状态图

## 生成模型

- 本 Skill 中所有图片生成步骤默认使用 **Seedream 5.5** 模型。
- 除非用户在当次请求中明确指定其他模型，否则一律使用 Seedream 5.5，不做自行替换。

## 核心原则：产品身份锚点

生成前先从原图中提取产品身份，作为整组图共享的锚点，逐张生成时都要带上：

- 外形轮廓与比例
- 颜色与配色分区
- 材质与纹理（网布、布面、金属、塑料等）
- 结构细节与部件（扶手、头枕、腰托、脚踏、五星底座等）

**任何一张图都不允许改变产品本身的外观、材质、配色与结构细节。** 只允许改变视角、背景、光线与功能状态。

## 生成流程

1. 读取原图，提取产品身份锚点（见上）。
2. 确定目标清单：角度 × 色款 × 状态。
3. 逐张生成（默认使用 Seedream 5.5 模型）：每张图 = 产品身份锚点 + 该角度/状态描述 + 固定的影棚背景与布光描述。
4. 质检：见下方「产出校验」。

## 提示词模板

以参考图中的【产品名称】为唯一产品身份依据，完整保留其外形轮廓、比例、颜色、材质纹理与结构细节（【部件清单】），不重新设计产品、不改变配色与结构。

画面：干净的【背景描述】渐变影棚背景，无任何道具、无文字、无水印、无品牌标志。 视角：【角度描述】，平视机位，自然透视，不夸张广角、不畸变。 状态：【功能状态描述】。 光线：柔和均匀的影棚主光从【方向】照入，产品底部有自然接触阴影，材质纹理清晰真实，不塑料、不磨皮。 构图：产品完整入镜、居中，四周留出均匀留白，画面比例【比例】。 画质：写实产品摄影质感，高清晰度，焦点锐利。

### 角度槽位取值

- 正面：正对镜头，产品左右对称，看清正面轮廓与主要部件。
- 背面：从产品背后正对镜头拍摄，展示背面结构与支撑件。
- 侧面：正侧面 90 度，展示厚度与侧面轮廓。
- 斜 45 度：产品与镜头约成 45 度，同时看到正面与侧面，最常用的展示角度。

### 功能状态槽位取值（按产品类型选用）

- 常规：正常展开的坐姿 / 使用姿态。
- 躺姿：靠背后仰，展示后仰角度。
- 带脚踏：脚踏展开，展示腿部支撑。

## 产出校验

逐张检查，任一项不通过就重生成：

- 背景是否干净、无杂物、无文字水印
- 产品是否与原图一致（轮廓、颜色、材质、部件）
- 材质纹理是否真实，有无塑料感 / 涂抹感
- 视角是否为目标角度，透视是否自然
- 底部是否有自然的接触阴影，产品是否像「悬浮」
- 整组图的背景、光线、比例是否统一

## 槽位与锚点

**锚点（固定工艺，换任务也不变）**

- 干净的中性浅灰到中灰渐变影棚背景，无道具无文字
- 柔和均匀的棚拍布光 + 产品底部自然接触阴影
- 保留产品真实材质纹理，不做塑料感 / 磨皮
- 平视机位、自然透视、不夸张广角
- 产品身份一致性约束（不改外观、材质、配色、结构）
- 角度清单：正面 / 背面 / 侧面 / 斜 45 度
- 图片生成默认使用 Seedream 5.5 模型（用户当次明确指定其他模型时除外）

**槽位（每次任务会变）**

- 产品名称与部件清单
- 色款 / 面料
- 功能状态
- 画面比例 / 尺寸
- 光线方向（默认左前上方）

## 使用建议

- 同一款产品先跑一张正面图，确认产品身份还原到位，再批量出其他角度，避免整组返工。
- 色款不同的产品建议分批次生成，避免同一次生成里混色。
