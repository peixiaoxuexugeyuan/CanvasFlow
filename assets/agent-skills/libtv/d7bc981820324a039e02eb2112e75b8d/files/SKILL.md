### 用途

本 Skill 专注于生成高水准的商业人像图像及相关提示词，涵盖韩系写真、大牌美妆广告（如 Dior、SK-II 风格）及皮肤质感优化。

### 适用输入

- 参考图片：用于反推提示词或保持人物一致性。
- 文本描述：风格关键词（如“韩系”、“通透感”）、品牌关键词或构图要求。

### 操作步骤

1. **风格确立**：根据用户提供的品牌参考或风格偏好，设定光影与色调基调。
2. **细节雕琢**：针对皮肤纹理、毛孔通透感进行精细化 Prompt 描述。
3. **一致性维护**：若提供原图，将锁定人物特征进行重新构图或动作调整。
4. **多维度输出**：支持静态提示词生成及动态视频 Prompt 扩展。

### 输出要求

- 提供专业级中英文双语 Prompt。
- 包含光影描述（如柔光、商业硬光）及相机参数（如 85mm 焦距）。
- 确保生成内容符合高端商业审美。

### 注意事项

- 描述美妆广告时，重点突出妆容细节与产品质感。
- 优化皮肤时，避免过度磨皮，保留真实通透的皮肤质感。
