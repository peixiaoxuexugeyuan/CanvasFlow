# 角色设定卡（竖版 9:16 四分格 戏剧轮廓光）

## 功能定位

分析用户提供的角色文字描述与/或参考素材，输出一份用于生图模型的「竖版 9:16、2×2 不等高四分格、相机右后方 45° 单侧轮廓逆光」角色设定卡提示词。四格统一浅暖灰纯色摄影棚背景与统一布光，保证角色一致性，便于视频生成时锁定人物资产。

## 适用场景

- 需要竖屏（9:16）角色资产，适配短视频 / 竖屏成片
- 需要戏剧性轮廓光影（rim light）风格的统一角色卡
- 需要正脸 / 侧脸 / 无头躯干 / 背面四种视角锁定一致性

## 输入要求

用户需提供以下之一或组合：

1. 角色文字描述：年龄、性别、身形、脸型五官、发型发饰、服装配饰、气质、标志性细节，以及「固定在身上的兵器」（如有）
2. 参考图（可选）：作为身份锚点
3. 风格偏好（可选，缺省按写实摄影棚）

## 输出结构：竖版 9:16 四分格

画幅 **9:16 竖版**；**2×2 不等高四分格**；格子间细浅灰分割线；四格统一浅暖灰纯色摄影棚背景与统一布光。

- **上排两小格**（单格高度占画布 **1/3**）：脸部特写
  - 左上：正面脸部特写，锁骨至头顶，人物正对镜头，面部完整无遮挡
  - 右上：纯侧脸特写，锁骨至头顶，人物朝向画面右侧，完整展露侧面五官轮廓
- **下排两大格**（单格高度占画布 **2/3**）：全身镜头
  - 左下：正面无头无面身体图，锁骨至脚底，只保留躯干四肢，隐藏头部与面部
  - 右下：背面全身（含后脑勺），从头到脚，完整展示背部造型

## 布光规则（核心）

- 仅 **相机右后方 45° 单侧轮廓逆光（rim light）**
- 无正面光、无补光、无多余光源
- 戏剧性轮廓光影，强调边缘光与体积感

## 通用统一规则

- 四张面板为同一人物，五官、服饰、配饰完全一致
- 基础自然站立姿态，双脚与肩同宽
- 双手全程空置，不握持任何武器；所有兵器仅穿戴 / 固定在身上

## 通用禁止约束

- 画幅禁用 1:1 正方形
- 四分格不可等高（必须上排 1/3、下排 2/3）
- 禁止正面光、补光、多余光源
- 不允许任何可读文字 / 标签 / 字幕 / logo / 水印；不要畸形手指 / 多肢体 / 脸崩 / 眼神涣散 / 耳朵缺失

## 输出格式

1. 直接输出一段完整提示词（中文或英文依模型习惯），内含四格各自的描述
2. 附使用建议：建议分两张图生成（上排两脸特写为图一，下排两全身为图二）以提升模型理解；Seedance2.0 全能参考最高支持 9 张图
