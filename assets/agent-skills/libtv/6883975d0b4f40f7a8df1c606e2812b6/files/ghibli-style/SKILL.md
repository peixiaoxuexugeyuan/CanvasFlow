# 吉卜力风格

## 核心原则

不要只贴一个"吉卜力风格"标签就生成，而要从色彩、构图、质感、空气、情绪五个维度拆解吉卜力视觉基因，把每个维度的具体参数写进生成指令。一张真正的吉卜力风格画面，不是靠风格名复刻的，是靠「清透天空的光、手绘水彩的笔触质感、散点均衡的构图、空气流动的呼吸感、治愈松弛的情绪」五层叠加成型的。

持久引擎（因果链）：

**用户场景描述 → 情绪基调定位 → 吉卜力视觉基因匹配 → 色彩调色板选取 → 构图与层次设计 → 空气与质感注入 → 角色/场景元素排布 → 正向生成指令组装 → 生成 → 风格一致性自检 → 交付**

### 质量测试（可证伪）

一张画面要通过吉卜力风格测试，须满足：

**如果把这幅画的色彩饱和度降低 30%、去掉空气感（雾气/光晕/风动的痕迹）、把手绘水彩质感换成数字平滑渲染，它就不再像吉卜力。** 换言之，清透色彩 + 空气流动感 + 手绘质感是三个不可缺席的视觉基因。缺任何一个，风格就不成立，重做。

## 输入诊断

生成前，从用户文字中识别或合理假设以下维度：

- **场景主题**：用户描述的是什么场景？（田园/城市/海洋/森林/室内/奇幻世界/其他）
- **情绪基调**：治愈松弛 / 温暖怀旧 / 梦幻冒险 / 宁静孤独 / 活泼明快 / 略带忧伤？
- **角色或主体**：画面中有没有人物、动物或其他主体？数量、姿态、服饰？
- **时间与季节**：清晨/正午/黄昏/夜晚？春夏秋冬？这决定光色和植被。
- **天气与空气**：晴天积云/阴天薄雾/雨后/大风/雪天？空气感是吉卜力的灵魂。
- **构图偏好**：散点均衡（经典吉卜力）/ 中心聚焦 / 横向展开 / 仰视/俯视？
- **画面比例**：1:1 / 9:16 / 16:9 / 其他？用户未指定时默认 16:9（吉卜力电影截图感）。
- **产物类型**：单张图片 / 多张套图 / 视频短片（≤15s 一次生成 / >15s 分段生成再拼接）？
- **参考图**：用户是否提供了参考图？若有，判断是风格参考还是内容参考。
- **奇幻元素**：是否需要超现实元素（飞艇鲸鱼、巨兽、精灵、会移动的城堡等）？吉卜力擅长把奇幻自然嵌入日常。
- **合规边界**：不涉及暴力、恐怖、政治敏感、色情内容；吉卜力风格的核心是治愈与美好，任何破坏这一气质的需求应引导回正向。

若用户给的描述很简单（如"画一个吉卜力风格的村庄"），做合理假设并继续：默认晴天积云、春夏交替、散点均衡构图、16:9、无人物或远景人物。只有场景方向完全无法推断时才追问。

## 工作流（步骤）

### 步骤 1：解析用户输入

从用户文字中提取：场景主题、情绪基调、角色/主体、时间季节、天气、构图、画幅、产物类型。缺失项做合理假设，不打断用户。

### 步骤 2：读取视觉基因词库

读取 `references/formats/ghibli-visual-genes.md`，从五维（色彩/质感/空气/构图/情绪）中选取与用户场景匹配的具体参数。

### 步骤 3：组装生成指令

将五维参数 + 用户场景描述组装为正向措辞的生成指令。规则：
- 用中文书写 prompt
- 以「吉卜力工作室动画风格」起手锚定整体风格
- 依次描述：场景主体 → 色彩调色板 → 空气与光 → 质感 → 构图 → 情绪
- 用 `@图片N` 引用用户提供的参考图（如有）
- 全程正向措辞，不写否定式约束（如不要写"不要出现电线杆"，而是写"画面中只有自然田野"）

### 步骤 4a：生成图片

单张图片直接生成。多张套图（如四季系列、同一场景不同时间）逐张生成，每张在 prompt 中用 `@图片N` 引用前一张保持构图/色彩一致。

### 步骤 4b：生成视频

若用户要求视频：
- 时长 ≤15s：一次生成完整片段，不需分段。beat 结构（0-3s/3-7s/7-12s/12-15s）写在同一条 prompt 内，是同一次生成内部的时间轴描述。
- 时长 >15s：拆成若干 ≤15s 片段分别生成，再做后处理拼接。
- 视频 prompt 须读取 `references/formats/video-prompt-grammar.md`，按 beat 结构组织。

### 步骤 5：风格一致性自检

生成后内部跑风格自检清单（见「静默自检」）。不通过则调整 prompt 重做。

### 步骤 6：交付

把生成的图片或视频交付给用户。如有多张产物，可建议用户选择满意的作为后续视频生成的参考图。

## 输出契约

### 图片生成指令模板

```
吉卜力工作室动画风格，[场景主题描述]。
色彩：[从视觉基因词库选取的调色板，如「清透蓝天白、嫩草绿、浅棕木色」]
光与空气：[如「正午柔和阳光穿透积云，远处山脚有薄雾，微风吹动草地和花」]
质感：[如「手绘水彩笔触，色彩边界柔和过渡，轻微纸张纹理」]
构图：[如「散点均衡构图，前景花草自然延伸至画面边缘，中景主体居中偏左，远景层层退远」]
情绪：[如「治愈松弛，满溢夏日田园的自由元气感」]
[角色/主体描述，如有]
[奇幻元素，如有]
画面比例 [ratio]
```

### 视频生成指令模板（≤15s 一次生成）

```
吉卜力工作室动画风格，[场景主题描述]。

0-3s：[相机：如缓慢推近/固定全景] [画面：场景全貌与主体入场] [光与空气] [声音：如风吹草地的沙沙声、远处的虫鸣]
3-7s：[相机：如平移跟拍主体] [画面：主体动作展开] [光与空气变化] [声音]
7-12s：[相机：如缓缓上摇至天空] [画面：天空积云、远景层次] [声音]
12-15s：[相机：如缓慢拉远至全景] [画面：主体与环境融为一体] [声音渐弱]

色彩：[调色板]
质感：手绘水彩动画质感
情绪：[情绪基调]
```

### 多张套图规则

生成同一场景/角色的多张图片时，第一张正常生成；后续每张在 ImageList 中传入前一张作为风格锚定参考，prompt 中用 `@图片1` 引用并说明「保持与 @图片1 一致的色彩调色板和手绘质感，仅改变[变化项]」。

## 静默自检

生成后内部执行以下检查，不通过则调整重做。除非用户要求点评，否则不暴露此清单。

- **色彩**：是否包含清透的天空色 + 自然植被色 + 暖木质色？三色是否覆盖画面 70% 以上面积？
- **空气感**：prompt 中是否包含至少一个空气流动元素（风/雾/光晕/云动/水面波纹）？
- **质感**：是否指定了手绘/水彩/笔触质感描述？没有数字渲染、3D、写实等措辞？
- **构图**：是否描述了层次（前景/中景/远景）？是否有散点均衡或明确的视觉引导？
- **情绪**：是否有一个情绪锚定词（治愈/松弛/温暖/梦幻/宁静）？
- **正向措辞**：prompt 中是否有否定式约束（"不要""无""避免"）？如有，改为正向描述。
- **画幅**：用户未指定时是否默认 16:9？多张套图是否比例一致？
- **视频**：若为视频，beat 是否在同一条 prompt 内？时长 ≤15s 是否一次生成？>15s 是否已拆分？
- **一致性**：多张套图之间色彩/质感是否一致？是否用了 ImageList 锚定？
- **合规**：画面内容是否治愈美好？有无暴力/恐怖/政治敏感元素？
