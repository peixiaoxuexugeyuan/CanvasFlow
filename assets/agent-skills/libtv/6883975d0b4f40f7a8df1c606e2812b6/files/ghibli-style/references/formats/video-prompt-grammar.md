# 视频 prompt 文法与 beat 结构

> 这些是可适配的模式与句式，按场景改写，不要逐字照搬。
> 本文件规定吉卜力风格视频的 prompt 组织方式和时间轴结构。

## 视频生成方式

- 时长 ≤15s：一次生成完整片段，无需分段。下方 beat 结构写在同一条 prompt 内，是同一次生成内部的时间轴描述。
- 时长 >15s：拆成若干 ≤15s 片段分别生成，再做后处理拼接。每个片段按 beat 结构组织自己的时间轴。

## beat 结构模板

一条视频 prompt 的 beat 结构如下，每个 beat 以「相机」起手：

```
0-3s：[相机运镜] [画面内容] [光与空气] [声音]
3-7s：[相机运镜] [画面内容] [光与空气] [声音]
7-12s：[相机运镜] [画面内容] [光与空气] [声音]
12-15s：[相机运镜] [画面内容] [光与空气] [声音]
```

### beat 各字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| 相机运镜 | 镜头运动方式 | 缓慢推近 / 固定全景 / 平移跟拍 / 缓缓上摇 / 缓慢拉远 / 低角度跟拍 |
| 画面内容 | 该时间段内的主体动作和场景变化 | 孩童骑在马上望向远方，马低头吃草 / 天空积云缓缓移动，远处风车转动 |
| 光与空气 | 光线变化和空气流动 | 正午柔和阳光穿透积云，微风吹动草地 / 黄昏逆光，夕阳渐沉 |
| 声音 | 环境音或配乐提示 | 风吹草地的沙沙声、远处虫鸣 / 轻柔钢琴配乐、风声 |

### 吉卜力风格运镜偏好

吉卜力动画的运镜特点是慢、稳、静。优先选择以下运镜方式：

| 运镜 | 描述 | 适用场景 |
|---|---|---|
| 缓慢推近 | 镜头缓慢向主体推进，不急促 | 主体入场、情绪聚焦 |
| 固定全景 | 镜头不动，让画面内的元素自然变化 | 全景展示、多元素场景 |
| 平移跟拍 | 镜头水平移动跟随主体 | 主体移动、旅途场景 |
| 缓缓上摇 | 从地面慢慢摇向天空 | 从场景过渡到天空、情绪升华 |
| 缓慢拉远 | 从近景慢慢拉到全景 | 结尾收束、融入环境 |
| 低角度跟拍 | 从孩童或动物视角跟拍 | 孩童视角、动物视角 |

### 运镜禁忌

- 不用快速剪辑、闪切、变速、手持晃动
- 不用旋转、翻转、极限变焦
- 运镜速度保持均匀，不急不缓

## 视频风格锚定句式

每条视频 prompt 以这句起手：

```
吉卜力工作室动画风格，[场景描述]。
```

末尾追加：

```
色彩：[调色板]
质感：手绘水彩动画质感
情绪：[情绪锚定词]
```

## 完整视频 prompt 示例

```
吉卜力工作室动画风格，夏日田园全景，一个黑发孩童坐在低头吃草的棕马背上望向远方，画面中悬浮着卡通飞艇鲸鱼，右侧立着复古木质风车，散点分布低头吃草的牛群，前景满是漫生小雏菊的长草。

0-3s：缓慢推近 全景展开，孩童骑在马上望向远方，马低头吃草，远处风车缓缓转动 正午柔和阳光穿透蓬松积云，微风吹动草地和雏菊，远处山脚有薄雾 风吹草地的沙沙声、远处的虫鸣
3-7s：平移跟拍 镜头从右向左平移，天空中的飞艇鲸鱼缓缓飘过，牛群抬头张望 阳光角度微微变化，云朵在天空中缓慢移动 轻柔的风声、远处牛铃叮当
7-12s：缓缓上摇 从孩童视角慢慢上摇至天空，积云蓬松厚重，飞艇鲸鱼在云间穿行 天空渐变从浅蓝到深蓝，光晕柔和 钢琴轻柔旋律渐入
12-15s：缓慢拉远 从天空拉回全景，孩童和马融入整个田园画面，前景雏菊随微风摇摆 夕阳余晖给画面镀上暖金色 钢琴旋律渐弱，风声收尾

色彩：清透蓝天白、嫩草绿、浅棕木色
质感：手绘水彩动画质感
情绪：治愈松弛，满溢夏日田园的自由元气感
```

- [ ] 每个 beat 是否包含光与空气描述？
- [ ] 每个 beat 是否有声音描述？
- [ ] prompt 是否以「吉卜力工作室动画风格」起手？
- [ ] 末尾是否追加了色彩、质感、情绪三行？
- [ ] 时长 ≤15s 是否一次生成（beat 写在同一条 prompt 内）？
