# 平台与画幅参考

> 这些是可适配的模式与句式，按场景改写，不要逐字照搬。

## 画幅选择

| 画幅 | 适用场景 | 吉卜力风格适配建议 |
|---|---|---|
| 16:9 | 电脑壁纸、动画截图感、横屏视频 | 默认比例，最贴合吉卜力电影画面感 |
| 9:16 | 手机壁纸、竖屏短视频 | 需调整为纵向构图，强调天空层次和地面延伸 |
| 1:1 | 社交媒体分享、头像 | 适合室内场景或方形构图，需要均衡布局 |
| 4:3 | 复古感、老式动画比例 | 贴合吉卜力早期作品画面比例 |
| 21:9 | 宽屏电影感 | 适合大全景、地平线场景 |

## 默认规则

- 用户未指定画幅时默认 16:9
- 视频默认 16:9，除非用户指定竖屏 9:16
- 多张套图保持同一画幅
- 竖屏构图调整：前景元素上移、天空占比增大、主体缩小以适配纵向

## 落 prompt 前自检

- [ ] 画幅是否已确定？用户未指定时是否默认 16:9？
- [ ] 竖屏场景是否调整了构图描述？
