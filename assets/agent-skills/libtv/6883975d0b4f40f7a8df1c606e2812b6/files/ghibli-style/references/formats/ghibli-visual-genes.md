# 吉卜力视觉基因词库

> 这些是可适配的模式与句式，按场景改写，不要逐字照搬。
> 本词库从色彩、质感、空气、构图、情绪五个维度拆解吉卜力工作室动画的视觉基因，供组装生成指令时选取参数。

## 1. 色彩调色板

吉卜力色彩的核心是「清透」——饱和度适中、明度高、透明感强，像水彩颜料在湿纸上自然晕开。

### 经典调色板（按场景选取）

| 场景 | 主色 | 辅色 | 点缀色 |
|---|---|---|---|
| 夏日田园 | 清透蓝天白、嫩草绿、浅棕木色 | 远山淡青、积云乳白 | 小雏菊白、野花淡黄 |
| 海边小镇 | 海蓝、沙滩米白、礁石灰 | 天空浅蓝、海浪白沫 | 渔船红漆、灯塔白 |
| 森林深处 | 苔藓深绿、树干棕褐、光斑金黄 | 落叶橙红、蕨类嫩绿 | 蘑菇红、溪水银白 |
| 秋日乡村 | 稻穗金黄、柿子橙、落叶红棕 | 天空淡蓝、屋檐灰瓦 | 炊烟灰白、柿叶翠绿 |
| 雪国冬日 | 雪原白、枯枝灰褐、天空淡粉 | 屋檐积雪白、冰面浅蓝 | 围巾红、窗光暖黄 |
| 黄昏小镇 | 夕阳橙金、天空渐变紫粉、屋顶暖棕 | 远山深紫、树影墨绿 | 窗户灯火黄、电线杆灰 |
| 室内日常 | 木地板暖棕、白墙米色、窗光金黄 | 桌面深木色、布艺淡蓝 | 茶杯白瓷、绿植翠绿 |
| 奇幻天空 | 积云蓬松白、天空渐变蓝紫、光晕金粉 | 远云淡粉、飞鱼银白 | 星辰淡金、城堡暖灰 |

### 色彩使用规则

- 主色覆盖画面 60-70%，辅色 20-30%，点缀色不超过 10%
- 天空永远清透，不用灰沉色调（除非场景是暴风雨/夜晚）
- 绿色用「嫩草绿」「苔藓绿」「翠绿」等自然色名，不用「荧光绿」「电光绿」
- 木色用「浅棕木色」「暖棕」「深木褐」等暖色，不用冷灰
- 画面整体偏暖，即使在冷色调场景中也保留一个暖色锚点（窗光/夕阳/灯火）

## 2. 质感与笔触

吉卜力画面的质感核心是「手绘水彩动画」。这决定了画面的颗粒感、笔触可见度和色彩过渡方式。

### 质感描述词（按需选取组合）

- 手绘水彩笔触，色彩边界柔和过渡
- 轻微纸张纹理，颜料在湿纸上自然晕染
- 赛璐璐动画质感，色块平涂但边缘有手绘温度
- 背景层水彩湿画法，前景层干笔勾勒细节
- 色彩层次通透，无多余拼贴边缘
- 笔触可见但不粗糙，保留手工温度
- 光影柔和过渡，不用硬边阴影

### 质感禁忌词（不要写进 prompt）

- 3D 渲染、CG、数字绘画、照片级写实、油画质感、赛博朋克、像素风

## 3. 空气与光

空气感是吉卜力画面的灵魂。没有空气流动的画面，即使色彩对了也不像吉卜力。

### 光线类型（按时间选取）

| 时间 | 光线描述 |
|---|---|
| 清晨 | 斜射金色晨光，草地露珠折射微光，远处薄雾未散 |
| 正午 | 顶光柔和穿透积云，光线均匀但不过曝，云朵投下移动的阴影 |
| 午后 | 侧光温暖，长长的树影铺在地面，空气中有可见的尘埃微粒 |
| 黄昏 | 夕阳橙金色逆光，人物和建筑轮廓镀金边，天空渐变从橙到紫 |
| 夜晚 | 月光银白偏蓝，窗内透出暖黄灯光，萤火虫或星光点缀 |

### 空气元素（每张图至少包含一个）

- 微风吹动草地、花、旗子或人物发丝
- 远处山脚或地平线的薄雾
- 云朵在天空中缓慢移动的体积感
- 阳光穿透树叶形成的光斑
- 水面波纹或倒影
- 烟囱炊烟或篝火烟雾
- 花瓣或落叶被风吹起
- 萤火虫或浮空光点

### 光与空气的组合句式

- 「正午柔和阳光穿透蓬松积云，微风吹动草地和雏菊，远处山脚有薄雾」
- 「黄昏逆光，夕阳给人物轮廓镀上金边，空气中有飘散的蒲公英」
- 「清晨斜射金光穿过树林形成光斑，地面露珠微亮，远处雾气弥漫」

## 4. 构图与层次

吉卜力构图偏爱散点均衡和纵深层次，不用强烈的中心对称或极端透视。

### 经典构图模式

| 构图模式 | 描述 | 适用场景 |
|---|---|---|
| 散点均衡 | 各视觉元素错落分布互不遮挡，前景花草自然延伸至画面边缘 | 田园、全景、多元素场景 |
| 三层纵深 | 前景（花草/道具）→ 中景（主体/建筑）→ 远景（山/天空），层层退远 | 风景、全景 |
| 横向展开 | 画面从左到右依次展开场景，像画卷徐徐铺开 | 全景、旅途场景 |
| 框景透视 | 通过门框/窗框/树洞看向远方，前景形成自然画框 | 室内向外、林间窥景 |
| 低视角色 | 从孩童或动物视角平视世界，建筑和大人偏高 | 孩童视角、动物视角 |
| 仰视天空 | 低角度仰望天空，强调云的体积和光 | 仰望天空、飞空场景 |

### 层次构建规则

- 前景层：花草、栅栏、小道具，自然延伸至画面边缘，不裁切
- 中景层：主体（人物/建筑/动物），画面视觉重心
- 远景层：山峦、天空、云朵，色彩偏淡偏冷以表现距离
- 三层之间用空气（雾/光/风）过渡，不用硬边切割

## 5. 情绪锚定词

每张吉卜力风格画面需要一个情绪锚定词，写进 prompt 的最后一行。

| 情绪 | 锚定词 | 配色倾向 |
|---|---|---|
| 治愈松弛 | 治愈松弛、满溢夏日田园的自由元气感 | 清透蓝绿暖棕 |
| 温暖怀旧 | 温暖怀旧、午后阳光里的童年记忆 | 暖黄橙棕 |
| 梦幻冒险 | 梦幻冒险、远方有未知的奇遇在等待 | 蓝紫金粉 |
| 宁静孤独 | 宁静而略带孤独、一个人也很好 | 冷蓝灰白暖光 |
| 活泼明快 | 活泼明快、风和日丽的欢笑时刻 | 鲜亮多彩 |
| 略带忧伤 | 温柔而略带忧伤、离别前的最后温暖 | 暖橙渐变紫 |

## 6. 场景元素库

吉卜力画面中反复出现的标志性元素，可按场景选取写进 prompt。

### 自然元素
- 蓬松积云（经典积云造型，底部平直顶部蓬松）
- 远山淡青色轮廓
- 漫生小雏菊的长草
- 蜿蜒的乡间小路
- 老式木质风车/水车
- 石砌小桥
- 参天大树（樟树/楠木/橡树）
- 流淌的小溪或河流

### 生活元素
- 晾晒的白色衣物
- 老式自行车
- 木栅栏
- 菜园和花圃
- 烟囱冒出的炊烟
- 窗台上晾着的柿子串
- 木制邮箱

### 奇幻元素
- 漂浮在天空中的飞艇或鲸鱼
- 会移动的城堡
- 巨型友善的生物
- 精灵或小人族
- 古老遗迹中的发光植物
- 天空中的浮岛

### 动物元素
- 低头吃草的马或牛
- 蹲在屋顶的猫
- 飞过的鸟群
- 水边的青蛙
- 田间的龙猫式生物

## 7. 落 prompt 前自检

写完生成指令后，逐条检查：

- [ ] 色彩：是否选取了具体调色板？主色/辅色/点缀色比例是否合理？
- [ ] 质感：是否指定了手绘水彩/赛璐璐质感？是否避免了 3D/数字/写实等禁忌词？
- [ ] 空气：prompt 中是否包含至少一个空气流动元素？
- [ ] 光线：是否指定了时间/光线类型？是否有光的具体描述？
- [ ] 构图：是否描述了层次（前景/中景/远景）？是否有构图模式？
- [ ] 情绪：是否有一个情绪锚定词？
- [ ] 正向措辞：是否全部用正向描述？有无否定式约束？
- [ ] 元素排布：场景元素是否错落分布、互不遮挡？
