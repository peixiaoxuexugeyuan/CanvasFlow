# 冰蓝磨砂图标生成（ice-blue frosted icon）

## 用途

用户只说一个图形/物体名称（如"补贴""盾牌""纸飞机"），就按固定设计语言生成同风格图标图片。风格描述全部内置，用户不需要每次重复。**默认在一个图片节点上产出一张图，图内以 2×2 均布四个不同方案的造型变体**，供用户挑选；用户看中某个方案后再单独生成为一张独立的单主体图。

## 设计语言（内置，不需用户重复）

- **造型**：单一居中主体，几何简化、轮廓圆润饱满，所有转角大圆角，无尖利感。
- **造型简化**：整体简化细节，形状不要太复杂。主体用最少的几何块面概括，去掉多余的褶皱、装饰、小配件等次要结构，一眼能认出是什么即可。
- **一体成型**：形状的可见外轮廓尽量是连在一起的单一连续形体，不要拆成几个分离部分拼在一起（例如钱袋不要画成"袋口 + 束带 + 袋身"三段分离结构，而是一个连贯的外轮廓）。
- **构成**：粗壮实心色块造型，不使用描边线条；内部细节用负空间/镂空表达（参考：皇冠中心的白色对勾、仪表盘的白色刻度与指针、火焰中间的白色裂口）。
- **镂空单层**：中间可以有负空间/镂空，但必须是单层镂空——一次穿透到底，禁止"层套层"的嵌套结构（反例：袋身镂空一枚圆钱、圆钱里又套一个方孔，这就是两层嵌套）。除非用户特殊要求，否则镂空只做一层。
- **色彩**：冰蓝到近白的单向渐变，左侧/左上浅蓝（约 #A9C9F5–#BBD6F7）过渡到右下接近纯白（约 #F2F7FE）；低饱和高明度，单一色相，无第二色相、无暖色。
- **质感**：柔和磨砂/雾化半透明感，边缘轻微羽化与光晕，像磨砂玻璃或果冻；无高光反射、无投影、无描边。
- **背景**：纯白 #FFFFFF，无装饰、无纹理、无阴影。
- **构图**：主体居中，四周留白约 15%–20% 安全边距。
- **禁止项**：黑色描边、写实材质、多色渐变、3D 立体透视、文字、数字、字母；货币符号仅限「¥」且必须遵循 `{{i-8xWDUdlCNv}}` 的统一样式，禁止其他货币符号（$ € £ ₪ 等）；背景装饰。

## 生成形式

- **默认**：在一个图片节点上产出一张图，图内以 **2×2 均布四个不同方案**的造型变体，供用户挑选。版式参考画布节点 `{{i-5wsg834q2dhh}}`（补贴四变体，即这种形式）。
- 四个变体为同一主题、同一套设计语言下的不同外形构思，彼此不重复（补贴 → 钱袋 / 信封 / 硬币 / 手托钱币）。
- 四个变体之间留出清晰间隔，不加分隔线、边框、编号、阴影或任何排版装饰，每个变体各自保持纯白背景与充足留白。
- **后续挑选流程**：用户看中哪个方案后会说"要第几个/这个"，此时再把该方案单独生成为一张独立的单主体图（仍是 1K，除非用户明确要高清放大）。**不要主动替用户放大。**
- 若用户明确说"只要一个/单张"，则直接出一张单主体图，不走四宫格。

## 货币符号「¥」统一样式规则

- 凡主题涉及价格、金钱、补贴、费用、优惠、充值、账单、收益等金融含义时，图标内部的镂空细节**统一使用「¥」符号**，不再用箭头、圆环等其他负空间，保证跨图标一致性。
- 「¥」的造型以画布节点 `{{i-8xWDUdlCNv}}` 为唯一样式参考，形状描述如下：
  - 整体由**极粗的圆头笔画**构成，所有笔画两端均为完整的**半圆胶囊形端头**，绝无平切或尖角。
  - 顶部是两笔粗短对称的斜向笔画构成**开口较大的 V 形分叉**，V 形两笔的下端汇聚于中心。
  - 中部是**两道彼此分离、也与竖笔断开的独立水平胶囊形短横**（上下等长、平行排列，横杠左右两端圆头，横杠与中间竖笔之间留有清晰缝隙，不相接）。
  - 竖笔为一根粗短的胶囊形立柱，位于两道横杠之间的中心位置并向下延伸，底端为半圆收尾。
  - 整体几何简化、无衬线、无尖角、笔画间距宽松透气，比例接近正方。
- **关键点（务必遵守）**：**两道横杠是与竖笔断开的独立短横，不是贯穿连接的长横**（这是新旧参考的核心差异）；此前生成的图里 ¥ 的横杠是连通贯穿的，那种写法作废。
- 「¥」属于单层镂空的一部分（一次穿透到底），仍然禁止层套层嵌套（例如不要在 ¥ 外面再套一圈圆环形成两层）。
- 非金融类主题（如盾牌、纸飞机、闹钟）不使用 ¥，内部镂空按主题自选简洁形状。

## 默认参数

- 宽高比：4:3
- 图像模型：Lib Image 2.5 Pro
- 质量：**resolution 1K + quality low（禁止 2K）**
- 生成形式：默认一张 2×2 四方案图；用户挑中或要求单张时出单主体图

### 分辨率必须显式钉死为 1K（重要）

`quality_spec = "resolution 1K, quality: low"`

**无论四宫格还是单主体，都必须显式写出** `resolution 1K`**，不可省略、不可只写"不做 2K"之类的否定表述**，否则运行时会把 resolution 缺省为 2K（实测同一批四张里有两张变成 1152x864 / resolution=2K，另两张才是 1024x768 / resolution=1K）。请用肯定式、显式指定分辨率与质量。

## 执行方式

1. 用户说出图形名后，直接套用四宫格版 Prompt 模板生成，**无需再次确认风格**。
2. 用户挑中某方案（"要第几个/这个"）时，用单主体版模板单独生成该方案（仍为 1K，不主动放大）。
3. 用户明确说"只要一个/单张"时，直接出单主体图，不走四宫格。
4. 若用户临时提出改动（换颜色、换画幅、加细节），在其改动基础上覆盖对应项，其余设计语言保持不变。
5. 一次只围绕一个主体主题生成。
