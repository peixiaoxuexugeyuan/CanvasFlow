# 投喂清单（用户侧输入需求单）

> 本文件回答一个问题：**除了上传这套 SKILL，用户还要给什么，方案才能从 70 分做到 90 分**。按 A→D 四层给。A 缺了做不了，B 决定片子成不成，C 决定要不要返工，D 是给了反而扣分的东西。

---

## A 层 · 底线三件（缺一件无法开工）

项给什么为什么必须产品参考图至少 1 张清晰图；**建议 3 张**：正面全貌 / 45 度侧向 / 关键细节（接缝、金属件、标识位置）Seedance 的形态一致性全靠参考图锚定。只给一张正面图时，任何侧面、背面、俯视镜头都会开始漂——不是提示词没写好，是没有可锚的信息一句卖点用户原话即可，不必工整卖点决定「价值证据」那一镜拍什么。没有卖点，方案只能拍成产品图轮播成片时长 + 画幅例：`15 秒 / 9:16 竖屏`；不确定就说投在哪时长决定镜数与分段（30 秒是 Seedance 单次上限），画幅决定构图与产品占画比例。这两项错了，整套分镜要重排

**参考图的三条硬要求**（不满足会直接降低一致性上限）：

1. 主锚图必须**产品完整、无遮挡、无手指**。手挡住的部位，模型会自己编。
2. 细节图要拍**产品上唯一的非对称特征**（单侧按钮、偏心的接口、特定位置的金属环）。四视角一致性、跨镜连续性都靠这个特征当判据；产品真对称时，连续性无从校验。
3. 多角度图**必须是同一件实物、同一光线**。不同批次或不同光下拍的图，模型会当成两件产品，正式镜头里就开始换形。

---

## B 层 · 决定片子成不成的五项（最高杠杆）

用户最常漏的就是这五项，而它们恰好是 Seedance 翻车率最高的地方。

### B1 产品的物理规格

给：**尺寸或大致高宽比、结构件数量、拍摄时的开合状态**。

```
哑光白瓷护手霜，瓶身约 15 厘米高，高宽比约 2:1，共两件（瓶身 + 瓶盖），拍摄时瓶盖旋开放在台面右侧。
```

为什么：广告必然要用「尺度递进」——微距 → 中景 → 全景。不知道真实尺寸，手和产品的比例会失真（护手霜被拍成洗发水瓶）。结构件数量必须写进约束句，否则「三件套」在第二镜变成两件。

### B2 产品实际怎么用（动作路径）

给：**一句动作描述，只说最核心那一下**。

```
用食指和中指从瓶口挑起一坨，沿前臂外侧单方向抹开一次。
```

为什么：**手与产品的接触是 Seedance 最弱环节。** 动作路径越具体，越能被改写成「单主体单动作」的安全版本；用户只说「涂一下」，模型就会自由发挥，糊成一团。如果这个产品的用法必须双手精细配合（拧、扣、卡扣、插接），要**主动说明**，方案会改成静态构图 + 轻微运动来绕过。

### B3 真实使用场景

给：**一句话，具体到可以做美术**。

```
清晨厨房台面上，窗光斜切过一片面包；或：出差酒店洗手台，镜子有水汽。
```

为什么：「在家里」这种描述等于没给。场景越具体，光线、道具、景深才定得下来，也才拍得出「人真的在用」。场景含糊时，模型会给一个通用白背景 —— 广告的质感就在这一步丢的。

### B4 能不能出现人

给：`无人物` / `只手部` / `有背影` / `可正脸`，四选一（可多选）。

为什么：这是唯一一条会影响**整条片子结构**的输入。无人物 → 全靠产品与材质撑，微距镜头权重提高；只手部 → 必须规避手指与产品的精细接触；可正脸 → 要考虑肖像与合规，且 Seedance 的人脸跨段不稳，方案会倾向少给正脸特写。

### B5 绝对不能出现的东西

给：竞品元素、特定颜色、宗教或地域符号、真人面孔、特定材质（如真皮、真毛）、任何不能碰的合规红线。

为什么：这类约束**必须在写提示词时就知道**，不能等成片出来再删。违禁元素一旦混进参考素材（图里带了竞品包装、背景里有不相干品牌），模型会一路带到底，且后期擦不干净。

## C 层 · 决定要不要返工的三项（省来回）

项给什么缺了会怎样投放平台抖音 / 天猫主图 / 私域朋友圈 / 线下电梯屏 / 官网 TVC会按 9:16 + 15 秒默认做。投在电梯屏（16:9、静音播放）时要全部重排，且必须补「静音也成立」的视觉自洽检查品牌调性三个形容词，或一个对标品牌创意路线只能给两条通用路线，选哪条的推荐理由会失准已有素材现成 BGM、现成配音、现成 LOGO 版式、必须沿用的片头影响交付接口：有现成 BGM 就要反过来按它的节拍分镜；没有就按画面节奏走

**优先级说明**：C 层里「投放平台」实际是 B 级——它同时改画幅、改节奏、改钩子时长。如果只能多给一条信息，给这条。

---

## D 层 · 不要给的东西（给了会伤效果）

别给原因写好的旁白稿 / 广告文案会把结构绑死在文案上，且旁白本来就是后期配的，Seedance 出的人声音色跨段不一致风格关键词堆（电影感、8k、高级感、大师作品）2.5 是运动说明书，形容词没有对应参数。质量感来自具体的光位、材质、动作，不来自形容词生成参数（分辨率、帧率、采样器、种子）本 SKILL 输出的是拍摄方案与提示词正文，参数在工作流侧设，写进来只会占篇幅「画面里要有品牌名 / 价格 / 卖点文字」模型出字必糊，错字比没字更糟。全部文字走后期超过 6 个「必须拍到」的镜头单段镜块上限就是 6。给 10 个必拍镜头，只能拆成两段，或砍掉重复信息的那几镜——提前说清哪几个可以砍，比事后砍更省事一句「随便你发挥」等于把 B 层五项全部留空，方案会退回默认值，也就是通用款

## 一句话投喂模板（复制填写）

```
产品：___（品类 + 具体形态 + 尺寸感 + 结构件数量 + 拍摄时开合状态）
图：___（正面 / 45 度 / 细节三张，标明哪张作主锚）
卖点：___（一句原话，不用工整）
必拍：___（1–3 个一定要出现的画面）
禁拍：___（不能出现的人、物、色、符号）
时长画幅：___ 秒 / ___（9:16 竖屏 / 16:9 横屏 / 1:1）
平台：___（抖音 / 天猫主图 / 私域 / 线下屏 / 官网）
人：___（无人物 / 只手部 / 有背影 / 可正脸）
场景：___（一句话，具体到光线与道具）
调性：___（三个形容词，或一个对标品牌）
已有素材：___（BGM / 配音 / LOGO 版式 / 必须沿用的片头）
```

填不满的空着即可，SKILL 会按默认值补齐并在方案里标注「补」。但**B 层五项空得越多，方案的通用感越强**。
