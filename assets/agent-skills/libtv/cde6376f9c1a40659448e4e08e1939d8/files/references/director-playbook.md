## 一、时长结构对账表

镜数、段数、秒数必须同时成立。**先定成片时长，再定段数，最后分镜。**

成片时长推荐镜数节奏结构适用场景Seedance 段数每段镜块6 秒3–4钩子 → 单卖点 → 产品与 CTA信息流补投、再营销1 段415 秒6–8钩子 → 痛点/欲望 → 产品证据 → 场景 → CTA短视频种草、电商转化1 段630 秒8–12钩子 → 冲突 → 证据 → 意义 → 场景 → 英雄镜头 → CTA新品发布、品牌与转化兼顾1 段（临界）或 2 段660–75 秒16–24钩子 → 世界观 → 工艺/功能证据 → 当代转译 → 多场景 → 情感 → 品牌收口品牌片、非遗文创、节礼广告2–3 段每段 6

### 三条硬规则

1. **单段不超过 6 个镜头块**。超过 6 个，模型在后半段会丢镜、并镜，或者用一次莫名其妙的大幅运镜糊过去。
2. **每段时间码之和必须等于该段时长**。15 秒段里写 `0-3s / 3-7s / 7-11s / 11-15s`，和必须是 15。
3. **30 秒是 Seedance 单次上限**。成片超过 30 秒，宁可多分一段，不要试图一条提示词出 60 秒。

## 二、分段续接的三种方式

60 秒以上的片子要拆段，段与段之间必须缝合，否则第二段的场景、光、产品全变。

### 方式 A：尾帧续首帧（最稳，首选）

- 做法：上一段生成后截最后一帧，作为下一段的首帧参考图。
- 写法：在下一段提示词首层声明 `以提供的首帧为起点，保持原始构图与光线，不改变原始构图`。
- 优点：形、色、光、场景全部锁住，跨段几乎看不出缝。
- 代价：下一段开场的构图被锁死，不能换机位——所以**必须在上一段的结尾就把机位设计成下一段想要的开场**。

### 方式 B：同一参考图 + 同一圣约重写（灵活）

- 做法：两段都用同一张产品图作参考，但构图各自重排。
- 写法：参考层显式声明"参考图只提供产品形态、材质、配色，不提供构图"，并用文字重建场景层。
- 优点：换机位自由。
- 代价：产品一致性全靠约束句撑，**连续性圣约五项必须逐字重复两遍以上**，不能复用上一段的措辞就省。

### 方式 C：同段延长（不推荐）

把 30 秒段拉到 40 秒——超出上限，模型会截断或后半段开始漂移。**只在 30 秒以内做，不要跨过 30。**

### 选择建议

情况用哪种同一场景连续叙事（如使用场景 → 情感）A换场地、换时间、换光线（如工艺 → 当代生活）B只是不够长、内容同质先砍镜，不要延长

## 三、"针下山河"可复用方法（扩写为十条）

只复用导演方法，不复制具体品牌、台词、产品或画面。

 1. **用极近景动作制造第一眼悬念。** 第一镜不交代产品全貌，只给一个局部在动——针尖落下、水滴将落未落、布料被拇指压出一道褶。观众的第一反应必须是"这是什么"。
 2. **把微观材质或工艺变成宏观世界，完成视觉升维。** 微距下的纹理要看起来像地貌：纤维像山脊、釉面像湖面、拉丝像风蚀岩。这一条决定了片子有没有"电影感"，而不是"产品图轮播"。
 3. **用可观察的制作过程证明价值，而不是只靠旁白宣称。** 说"手工"没用，要拍到手指如何捏、如何收边、如何留一道不修整的痕。过程本身就是证据。
 4. **从传统或技术来源过渡到现代产品设计。** 前半段给源头（老工艺、老材料、老场景），后半段必须回到当代使用。**转场要有一个共同的视觉母题**（同一束光、同一条曲线、同一种节奏），否则会显得生硬拼接。
 5. **展示真实使用、佩戴、通勤、家庭或赠礼场景。** 场景要具体到可以做美术：不是"在家里"，而是"清晨厨房台面上，窗光斜切过一片面包"。
 6. **用一段克制的人际情感把功能变成记忆。** 克制是关键——递过去、接过来、对视一眼即可。大哭大笑会把广告推向廉价。
 7. **以产品英雄镜头、品牌句、卖点与 CTA 准确收口。** 最后 2–3 秒必须只做一件事：让产品被看清。此时不加新信息。
 8. **对比要发生在同一画面里。** 前后、新旧、有无、干湿——放在同一帧的两侧，比用两个镜头做对比稳得多，也不会因为跨镜导致产品变形。这是 Seedance 版新增的一条，跨镜对比是产品漂移的高发区。
 9. **用尺度递进代替景别切换。** 微距 → 中景 → 全景，用一条连续的运镜走完，比切三个镜头更稳、更贵气。前提是时长够（至少 6 秒），且中途不硬切。
10. **结尾留半秒静止。** 产品停稳后画面近乎不动（只留极轻呼吸晃动），给 CTA 一个落点。不留这半秒，观众来不及读最后一帧。

每一镜填满，缺字段的镜头在生成阶段一定出问题。

字段要求Seedance 版补充镜号 / 时间连续且总时长准确写 `S03 / 07-11s`，时间码必须落在所属段区间内画面目标本镜唯一主要信息一句话，超过一句说明这镜该拆画面内容主体、动作、环境、道具与结果动作只写一条连续弧，15–25 字景别 / 机位 / 运动景别、角度、焦段感、运动速度和方向运镜最多叠两个，写清方向×速度×终点参考分工这张产品图在本镜提供什么形态 / 材质 / 配色 / 光感，写清提供哪几项产品连续性外观锚点与本镜不可变化项重复圣约五项，逐镜复述不能省旁白 / 字幕口语化、可朗读、与画面互补不写进提示词，进后期音乐 / 音效节奏、环境音、拟音与转场声只写同期声，BGM 进后期分镜提示词静态构图、光影、材质、风格与画幅用来先出定帧图确认这一镜镜头提示词主体动作、镜头运动、物理变化、时长按七层结构写，这是提交给 Seedance 的那段负面约束错字、变形、结构漂移、风格跳变等写在提示词最后单独一句，不散落中间转场与前后镜头的动作、形状、颜色或声音衔接优先动作接、形状接；避免叠化与花式转场

## 五、投放类型选择（四类）

### 品牌心智

放大世界观、情绪和品牌记忆。产品必须在开头或前 10 秒出现一次，并在结尾用英雄镜头收口。

- **结构**：氛围开场（2–3 镜）→ 产品第一次出现（不解释）→ 工艺/材质证据 → 生活场景 → 情绪 → 英雄镜头 + 品牌句。
- **Seedance 写法**：氛围镜头允许纯环境无人，但要写至少三条同步环境运动（光斑移动、尘埃漂浮、水面微动），否则固定机会像静止图片。
- **易翻车**：氛围开得太长导致产品没出场。**前 10 秒必须看见产品，这是硬指标。**

### 即时转化

优先展示痛点、使用动作、可验证结果、价格或权益与明确 CTA。避免长时间铺垫。

- **结构**：痛点（1 镜，1.5 秒内）→ 产品介入（1 镜）→ 使用动作 → 结果对比（同画面）→ 价格/权益 → CTA。
- **Seedance 写法**：全程单主体单动作，尽量少用手部精细操作。**手与产品的接触是最高翻车点**——写"手指轻触瓶身中段，不遮挡主标签"，不要写"双手拧开、倒出、抹匀"。
- **易翻车**：想在 15 秒里塞完整使用流程。15 秒只够一件事做透，选最有说服力的那一个动作。

### 非遗与文化产品

让传统成为"产品为什么值得买"的证据。文化镜头之后必须回到当代使用，不把广告拍成与商品脱节的纪录片。

- **结构**：工艺源头（微距 + 手）→ 材料/工具证据 → 一道关键工序 → **当代转译（必须出现）** → 使用场景 → 品牌收口。
- **Seedance 写法**：转场用共同视觉母题缝合（同一条弧线、同一种节奏、同一束光）。微距镜头要写清被拍材质的具体表面细节，只写"微距"会变成"稍微近一点"。
- **易翻车**：拍成纯工艺纪录片，产品到最后 3 秒才出现。**当代使用场景不能省，它是"文化"变成"商品"的那一步。**

### 节日与礼赠

同时交代送礼对象、时机、情绪价值、包装体面度和到手后的真实用途。

- **结构**：包装特写（体面度）→ 递出/接过的动作（人际）→ 拆开（期待）→ 使用（真实用途）→ 双人同框（情绪）→ 产品 + CTA。
- **Seedance 写法**：人际动作只用"递、接、看"三个动词，不要写对话与表情特写。**包装盒的开合状态必须逐镜锁死**（开着的不能下一镜变合上）。
- **易翻车**：只拍包装不拍使用，观众记住了盒子没记住产品。

## 六、交付命名

镜头包与素材统一命名，后期才能按序拼。

```
01_hook
02_problem_or_desire
03_product_proof
04_meaning_or_transition
05_usage_scene
06_emotion
07_packshot
08_cta
09_endcard
```

**扩展规则**

- 同一节拍有多个备选时，用字母后缀：`03_product_proof_a`、`03_product_proof_b`。
- 分段生成的，段号放前缀：`seg1_01_hook`、`seg2_05_usage_scene`。
- 定帧图与视频分别加后缀：`03_product_proof_still.png`、`03_product_proof.mp4`。
- 命名一旦确定，中途不改。后期按名字排序，改一次全乱。

## 七、交片前自检（十条）

 1. 成片时长 = 各段时长之和 = 各镜时间码之和，三处一致。
 2. 每段镜块数 ≤ 6。
 3. 前 3 秒有视觉钩子，且钩子镜头不交代产品全貌。
 4. 产品首次出现不晚于成片 1/3 处（品牌片可放宽到前 10 秒）。
 5. 每一镜都复述了连续性圣约五项，没有一镜漏写。
 6. 每一镜只有一条动作弧，没有出现"同时……并且……然后……"。
 7. 运镜没有超过两个动作叠加。
 8. 画面内没有任何文字、字幕、LOGO、价格、水印。
 9. 产品标识区在每一镜都是空白且未被遮挡。
10. 分段处写清了续接方式（A/B），并指定了用哪一帧作为下一段起点。
