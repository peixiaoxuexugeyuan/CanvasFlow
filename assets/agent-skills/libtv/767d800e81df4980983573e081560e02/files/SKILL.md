### 技能用途

ShotSheet 将分镜表直接转化为剪辑脚本，解决 AI 视频创作中素材管理与手动剪辑的低效问题。通过 CSV 配置文件控制镜头顺序、时长、景别、台词及转场，实现自动化渲染成片。

### 适用输入

包含以下字段的 CSV 项目文件或文本描述：

- 镜头基本信息：镜号、景别、画面描述。
- 剪辑指令：时长、顺序、转场方式（淡入、叠化等）。
- 视听细节：对应素材路径、台词字幕、调色偏好、变速设置。

### 操作步骤

1. **初始化项目**：使用 `init` 命令生成标准分镜表模版。
2. **编辑分镜表**：在 CSV 中填入素材路径、设置每个镜头的入出点与视觉效果。
3. **快速校对**：运行 `check` 命令秒级生成时间线预览，确认节奏而不渲染画面。
4. **自动化渲染**：运行 `render` 命令，调用 FFmpeg 自动完成画幅归一化、转场合成、字幕烧录及 BGM 混音。

### 输出要求

- **成片效果**：生成符合预设画幅（如 2.39:1）与帧率的 MP4 视频。
- **时间线精度**：转场消耗的时长需精确计算，字幕必须准确对齐镜头入出点。
- **占位逻辑**：缺失素材时自动生成带描述的占位卡片。

### 注意事项

- 仅支持基础转场与调色，精细特效仍需专业 NLE 软件。
- 单个镜头时长建议不要超过 30 秒。
- 环境需安装 Python 3.9+ 及 FFmpeg。
