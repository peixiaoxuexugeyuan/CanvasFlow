# 镜表 ShotSheet

> **一张表就是一支片，改表即重剪。**

## 它解决什么

AI 生成视频最大的堵点不在"生成"，在"生成之后"。

你得把二三十个片段从下载文件夹里捞出来，一个个塞进时间线，对时长、排队列、调转场——
而这一切，你在写分镜的时候就**已经想过一遍**了。想完还得用手再做一遍。

ShotSheet 把这一步去掉：**分镜表本身就是剪辑脚本。**

一张 CSV，一行一个镜头。填好时长、顺序、景别、台词、转场、调色，一条命令切成片。
表里任何一个数字改了，重跑，片子自己重剪。

## 怎么用

```bash
python scripts/shotsheet.py init   我的项目            # 铺一张表
python scripts/shotsheet.py check  我的项目/分镜表.csv  # 只看时间线，不出片
python scripts/shotsheet.py render 我的项目/分镜表.csv -o 成片.mp4
```

`check` 是秒级的——调节奏的时候你会跑它几十次，每次都看到真实的入点出点，不用等渲染。

## 三个关键设计

**1. 表就是 EDL。** 不是"导出成剪辑软件"，是直接渲染。改「剪辑序」就改叙事顺序，改「时长」就改节奏，不用重新编号、不用回 NLE 拖。

**2. 没素材也能出片。** 素材列空着，自动生成带镜号/景别/画面描述的占位卡。所以可以先定节奏、再填画面——不用等素材齐了才敢动手。这对 AI 生成流程尤其重要，因为素材往往是一段段陆续出来的。

**3. 转场会吃时长，而且算准了。** 四镜各 2 秒、三处叠化，成片是 8 − 3×0.4 = 6.8 秒，不是 8 秒。`check` 打印的就是扣完重叠之后的真实时间线，字幕也按这个时间线生成。

## 示例片

`examples/trailer-150/` 是一支 23.7 秒、9 个镜头的短片，**完全由 `分镜表.csv` 生成**：

| | |
|---|---|
| 画幅 | 1920×802（2.39:1） |
| 时长 | 23.70 秒 |
| 镜头 | 9 个，平均 2.75 秒 |
| 转场 | 1 处叠化 + 1 处黑场 + 1 处开场淡入 |
| 字幕 | 5 句，各自落在对应镜头的入出点 |
| 调色 | 冷调 / 暖调交替 |
| 变速 | 第 6 镜 0.75 倍速 |

表里用的手法：淡入、叠化、黑场、冷暖交替、慢放、五段台词。
**没有一处在时间线上手拖过。**

## 技术栈

- Python 3.9+，零第三方依赖（分镜表是 CSV，Excel 双击就能改）
- ffmpeg：逐镜归一化（分辨率/帧率/画幅/时长统一）→ 硬切走 concat、转场走 xfade → ASS 字幕按真实时间线烧入 → BGM 循环淡出混音
- 出片速度：1080p、9 镜、23.7 秒，约 27 秒

## 边界（诚实说明）

- 不做精细调色、多轨音效设计、特效包装——那些交给 NLE
- 变速只影响画面，音效仍按入点原速混入
- 单镜超过 30 秒会提示拆镜

## 适合谁

AI 短片创作者、短剧团队、广告分镜预演、任何"素材比想法多"的人。
