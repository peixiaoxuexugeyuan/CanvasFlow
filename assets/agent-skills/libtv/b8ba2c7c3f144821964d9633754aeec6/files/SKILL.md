## 技能用途

本 Skill 专门用于生成具有“鸦阁魔域”（Ravenloft）暗黑奇幻风格的图像资产，支持透明背景角色立绘（Character）和全景叙事插画（Narrative）。内置五种核心画风：经典油画、叙事厚涂、绮丽线描、民俗粉彩、史诗暗奇幻。

## 适用输入

- **画风选择**：提供 1-5 编号或指定参考风格名称。
- **输出模式**：选择 `character`（透明背景素材）或 `narrative`（完整背景插画）。
- **提示词/参考图**：输入角色描述、身份参考图或场景需求。

## 操作步骤

1. **确认风格**：引导用户从五种内置画风中选择，若用户未指定则默认使用“1 经典明暗油画”。
2. **解析模式**：根据需求设定输出参数。角色模式强制开启 `transparent_background`；叙事模式设定为 16:9 或用户指定比例。
3. **提示词合成**：整合“共享质量核心”（电影级画质、低噪点）与“风格绘画核心”，构建中英文提示词。
4. **调用执行**：使用 `image_gen` 能力生成图像。生成的图像需保存至工作区 `output/gothic-art/` 目录下。
5. **质量检查**：运行脚本验证 Alpha 通道（立绘）或画面比例，确保不含脏污感或塑料感。

## 输出要求

- **立绘**：必须为真正透明的 Alpha PNG 格式，主体清晰，背景无残留。
- **插画**：构图具有叙事性，背景细节适度简化以突出氛围。
- **记录**：同步生成 `.prompt.md` 记录所有生成参数、提示词及检查结果。

## 注意事项

- 严禁使用圆形 Token 工作流，必须生成完整立绘。
- 无法通过提示词代替成图，必须执行实际的生成动作。
- 修改已有图像时需保持身份一致性，仅调整要求的变更项。
