# 生成结果验收

每项明确记为通过、失败或未验证。自动像素检查与人工视觉观察分开记录，不用脚本结论替代审美与解剖检查。

| 检查 | 实际查看的内容 |
| --- | --- |
| 风格一致 | 与选中画风主图并排比对：对应的线条/笔触、色面塑形、明暗深度、边缘与细节层级；选项3不能因缺少厚涂而被误判失败，选项4不能因较明亮而被强压暗。题材和配色相同不足以证明画风一致 |
| 人体与手 | 人形肩肘腕、骨盆和重心合理；手指数量及连接可信；握持、遮挡与透视连贯。异形、骷髅或义肢按身份参考和用户设计检查，不能强改成人类结构。看不清的部位记为无法判断，不猜测通过 |
| 身份与装备 | 身份图中的脸、发型、身材、服饰、标志性装备保留；不被风格图人物替换 |
| 材质与笔触 | 皮肤、布料与金属遵循已选画法：厚涂色面、线描平涂或粉彩干笔；布料大面连续、折痕顺形，亮点克制。无塑料高光、照片皮肤、3D PBR 或机械重复纹理 |
| 焦点与密度 | 主体清晰，整体细节克制且有层次：脸、手、关键道具清楚，主要材质大面连续，次要衣纹与背景适度简化；背景不以细碎纹理或高反差抢主体，不平均铺满浮尘、珠宝碎光 |
| 材质连续性 | 大面积皮肤、布料、石材等平滑、连续自然，明暗转折顺形；无无意义的碎小纹理、颗粒、斑点、随机锐化痕迹，不用重度模糊或蜡质磨皮替代自然笔触 |
| 干净通透 | 低噪点、低颗粒感，无脏污染感、无塑料感，主体清晰、暗部有层次、形体可读；无脏污覆盖、彩色噪点、锐化光边和背景底色污染。电影级干净画质需实际视觉检查，不等于磨皮、抹平笔触或技术认证 |
| 主体占比 | character 人物充分占画幅且留轮廓余量；narrative 主角与故事焦点突出，环境服务剧情 |
| character 边缘 | 查看头发、肩、披风、手指、透明材质及武器轮廓；无白边、漏底、假棋盘、缺失肢体。可在深浅预览底色上检查，但最终仍交付原 Alpha PNG |
| narrative 空间 | 实际环境、前中后景、透视与建筑尺度连贯；光源位置与受光方向对应，薄雾不吞没人物 |
| 文件与归档 | PNG 签名/解码、实际尺寸、Alpha、目标比例、源文件未被覆盖、同名实际提示词和检查记录齐全 |

对照 [固定画质限制](style-anchors.md#固定画质限制) 逐项观察。噪点、材质连续性与细节层级由实际看图判断，不以PNG结构或Alpha检查通过代替。

## 像素检查

`scripts/check_alpha.py` 依赖 Pillow；使用已具备该依赖的 Python。命令例如：

```text
python <skill-dir>/scripts/check_alpha.py output/gothic-art/character.png --expect transparent --aspect 3:4 --output output/gothic-art/character.qa.json
python <skill-dir>/scripts/check_alpha.py output/gothic-art/scene.png --expect opaque --aspect 16:9 --output output/gothic-art/scene.qa.json
```

返回码：0 通过，1 像素要求不满足，2 输入/解码/依赖错误。默认透明检查至少 1% 全透明像素、5% 可见像素、5% 近不透明像素（Alpha ≥250）和非零全不透明实体；比例相对误差最多 1.5%。工具可能返回主体 Alpha 252–254，因此同时报告完全不透明与近不透明占比，不把主体轻微透明谎报为全为255。这些是空白/伪透明的基础防线，不是构图评分。合法的特殊透明主体可明确调整阈值并记录原因，不为让失败图过关随意放宽。

JSON 包含真实通道、Alpha 范围、透明/半透明/不透明比例、可见像素 bbox、四角 Alpha 和各边可见比例。边界数据只供审阅：半身下方裁切合法，全身脚或头顶撞边通常需要修正。脚本不自动证明背景语义、人物身份、手指数、无白边或风格一致。

## 失败后的处理

保留原始输出与失败记录，针对可观察问题使用内置图像工具修正/重生一次。新版本重新运行像素与视觉检查。若仍失败，如实交付状态与限制，不伪造 PNG、透明 Alpha、比例或“通过”记录。保守色噪处理仅在确有需要时进行，保留原始文件；不重度模糊或替换身份特征。图库R04隐藏RGB色带不能移植为纹理；正确Alpha合成时它们不显示。其脚下地面与其他原图的颗粒、局部Alpha性质也不是新成图应复制的交付标准。
