# 3 · 绮丽线描平涂

默认主图：[R02 赛德拉](../../assets/art-library/saidra-dhonaire.webp)；可指定 [R15 维克特拉](../../assets/art-library/viktra-mordenheim.webp)。

## 可见画法

赛德拉用细而连续的暗线描绘衣褶、面具、建筑与人物轮廓，大面积青绿、洋红和紫蓝以平涂/有限阴影分区，布料的飘动依靠轮廓节奏。维克特拉的脸、手和短发同样以清楚线描、少量色面转折塑形，镜子裂缝与反射构成图形叙事；没有写实毛孔与复杂PBR反射。

这组选项属于线描主导的二维插画，不应被强行解释为油画厚涂。可保留极轻纸感，但减少源图可见的密集颗粒。配色可变，清楚线条与平涂层级不能丢。严肃表情和自然结构不等于改成通用萌系动漫脸。
