# 品牌 LOGO 设计

## 用途

把「我想做个 LOGO」变成可落地的品牌标志：有概念、有结构、有配色依据、有单色适配、有交付规范。

特色在于**不做黑白极简**。默认输出有色彩主张的多色方案（≤5 色，潘通锚点，符合色彩关系法则），同时保证单色可读、小尺寸可辨。

## 何时使用

- 用户要为品牌 / 店铺 / 公司 / 活动 / 个人 IP 设计标志
- 用户上传参考图并说「照这个感觉做」
- 用户上传色系图并说「用这个配色」
- 用户上传策划书 / 商业计划书并要求提炼品牌视觉
- 用户已有 LOGO，要求优化、年轻化、多色化、简化

不适用：纯 UI 图标集、插画、海报、包装设计。若用户要的是这些，直接说明并转常规能力。

## 工作流

### Stage 0 · 接收

先判入口，再决定问什么。**不要让用户填表。**

入口动作只给行业 / 品牌名查 `reference/04-industry.md` 直接给默认判断风格参考图读图，拆成「构成类型 + 风格谱系 + 容器 + 线条」四层并说出来色系参考图跑 `scripts/extract_palette.py --image <path> --top 5 --ignore-bg`，取量化结果策划书 / 文档只提取：品牌名、理念、目标人群、差异化、禁忌多者并存优先级 策划书 &gt; 色系图 &gt; 风格图 &gt; 口述

必需信息五项：品牌名（必需）、行业（必需）、理念/人群、风格偏好、禁忌。缺的用行业默认值推断并标注，不要空着等用户填。

### Stage 1 · 品牌解码

必须显式输出解码卡，让用户可否定：

```
【品牌解码】<品牌名> · <行业>
· 核心关键词：3 个（附推导）
· 行业原型：该品类需要什么 + 同行普遍在做什么
· 差异化缝隙：换哪个结构才能一眼区分（换色无效，换结构才有效）
· 风格候选：从 01-typology 选 1 主族 + 1 辅族
· 色彩主张：冷暖 + 为什么这个主色比同行更合适
· 禁忌：不可用的图形 / 颜色
```

收尾一句话：「按这个理解往下走，如果判断错了现在纠正还来得及。」

### Stage 2 · 偏好锁定

一次性问完，用选择卡片，每项给 3-4 个具体选项并标出推荐。只问这四项：

1. **版本形态**：纯图标版 / 图文组合版 / 两版都要（新品牌默认推「两版都要」）
2. **主色调**：冷 / 暖 / 中性偏冷 / 中性偏暖（按行业与参考图给默认）
3. **字体**：几何无衬线 / 现代人文无衬线 / 高对比衬线 / 定制字母标
4. **设计方向**：从 24 式中选，**上限 5 式**。先列全表（见 `reference/02-methods.md`），再给 3 式推荐并标 ★

其余全部由本技能自行决定，**不再追问**：辅助色与强调色、对比度标准、单色适配、容器、线条、质感、图文比例、字重字距。

用户选超 5 式时，指出哪些在抢同一件事，收敛到 3 式主 + 2 式备选。

### Stage 3 · 概念方向

出 3 条，**必须用不同方法、结构上真的不同**（不是同形换色）。按风险度配比：

- A 稳：最贴合行业最佳实践
- B 平衡：最有记忆点与辨识度
- C 大胆：最有态度

每条按固定四段写：图形逻辑 / 结构（几个形、什么关系、负空间在哪）/ 配色（HEX + 潘通）/ 字体，再加一句「一句话记忆点」。

### Stage 4 · 配色与出图

配色必须过脚本，不要凭手感：

```bash
python scripts/palette_builder.py --primary "<潘通号或HEX>" --temperature cool --harmony split --roles 4
```

输出含：色值表、潘通最近邻、白底/黑底对比、单色灰度、可直接粘进提示词的 `colour palette:` 行。若体检提示某色白底对比 &lt;2:1，出图时必须改为「深色图标 + 亮色块」。

提示词按 `reference/06-prompting.md` 的七段式组装（SUBJECT / MARK / STYLE / COLOR / TYPE / COMPOSITION / CONSTRAINTS），用 `ImageGen` 生成。

硬性要求：

- 纯图标版必须写 `no text, no letters`
- 必须写形状数量上限与 `must stay legible at 32 pixels`
- 必须写 `no more than N colours` 与 `flat solid fills`
- 三版对比时，每条提示词只改 MARK 段，其余六段完全一致
- **图文组合版不要指望模型写中文**：先出纯图标，文字部分按 `reference/05-typography.md` 的比例后期排版合成
- 单色版与深底版**从彩色成品派生**，不重新生成（重生成会导致形态不一致）

### Stage 5 · 质检与交付

```bash
python scripts/check_spec.py --file spec.json
```

12 项硬检见 `reference/07-quality-gate.md`：色数 ≤5、深色支点、浅色基底、主色白底 ≥3:1、文字 ≥4.5:1、形状 ≤3、线条统一、单色可辨、32px 可辨、5 秒可述、版本完整、光学修正。

交付包：纯图标（白底 + 透明底）、图文组合（白底 + 深底反白）、纯黑版、纯白版、App 图标版、设计说明、色值表、最小尺寸与留白规范。

## 硬性约束

- **配色总数 ≤5**（含中性），必须有 1 主色 + 1 深色支点（明度 &lt;32%）+ 1 浅色基底（明度 &gt;86%）
- **色彩关系必须成立**：每色都要能说出它与主色是类似 / 互补 / 分裂互补 / 三角 / 单色相关系，禁止随机配色
- **禁止彩虹渐变**：渐变只用 2-3 色单向过渡，且必须备纯色替代版
- **禁止纯黑** `#000000` **当品牌黑**：用 `#1A1A19`（419 C）
- **禁止中性灰** `#808080` **当辅助色**：用带倾向的中性（冷灰 `#53565A` / 暖砂 `#D6D2C4`）
- **形状数量 ≤3**（极限 4），一个标内只用一种线条语言
- **不抄竞品**：参考图只取四元组中的风格与容器，图形逻辑必须换
- 已过时的做法见 `reference/08-trends.md` 第二节，不得使用

## 脚本

脚本用途`scripts/palette_builder.py`配色引擎：锚点色 + 冷暖 + 法则 → 3-5 色方案（含对比度体检、单色适配）。`--list` 看 16 套预设`scripts/extract_palette.py`参考图取色：主色占比、冷暖判定、彩度档位、最近潘通锚点`scripts/check_spec.py`方案质检：色数、深浅支点、对比度、形状数、版本完整性、最小尺寸

## 反模式

出现以下任一情况即为失败：

- 三个方案只是颜色不同
- 输出只有黑白或纯灰度，没有色彩主张
- 配色超过 5 色，或用了彩虹渐变
- 说不出「为什么是这个形」
- 只有彩色版，没有单色版 / 深底版 / 透明底
- 没写最小尺寸与留白规范
- 让模型直接写中文品牌名，出了乱码
- 拿竞品图直接复刻
