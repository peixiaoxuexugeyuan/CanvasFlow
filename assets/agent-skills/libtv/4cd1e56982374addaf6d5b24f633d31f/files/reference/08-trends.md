# 08 · 2025-2026 审美坐标

「紧跟时代审美」不是追热点，是知道**当下什么东西已经过时**。以下为本次技能内置的时代判断依据，更新于 2026 年。

---

## 一、七个正在发生的转向

### 1. 从「极简到没有」到「极简但有细节」
2018-2022 的极简是把所有东西删掉，结果是所有品牌长得一样。2025 起，主流回到**一个强骨架 + 一处精心设计的细节**：一个不对称的缺口、一处手绘痕迹、一个只有放大才看到的笔画变异。

**实践含义**：不要出「一个正圆」或「一个正方形」。每个方案必须有且只有一处「活口」。

### 2. 从无彩到「有节制的多色」
黑白极简已经饱和到无法区分。当下的主流是**2-3 个有关系的色**，而不是单色。年度代表色的商业带动让色彩重新成为品牌资产。

- 2026 PANTONE 11-4201 Cloud Dancer 云上舞白 —— 结构性白，托底用
- 2025 PANTONE 17-1230 Mocha Mousse 摩卡慕斯 —— 暖棕回潮
- 2024 PANTONE 13-1023 Peach Fuzz 柔和桃

**实践含义**：主色必须有色彩主张，中性色必须是「带倾向的中性」，纯灰等于没做完。

### 3. 大地色取代荧光色
可持续叙事进入主流后，配色从「合成高能荧光」转向 **moss green 苔绿、terracotta 陶土、sun-bleached sand 晒白砂、deep ocean teal 深海青**。这类颜色传达真实与责任感，而且不需要画一片叶子。

**实践含义**：环保类品牌不要再画叶子。用苔绿 + 陶土 + 砂白，比叶子高级十倍。

### 4. 轻 3D 回潮，但拒绝 90 年代斜面
不是浮雕，不是高光球。是**哑光表面 + 极轻的环境光遮蔽**。轮廓依然干净，只是有了体量。

**实践含义**：如果做 3D，阴影只在一侧，且不超过 15% 强度。一加高光就过时。

### 5. 字体的「运动感」
大量品牌采用前倾结构、斜体、速度感字形；同时反向操作也存在——后倾字形制造张力。另一个明确趋势是**字母内部嵌入元素**（心、蛋、锤子、圆、方块）。

**实践含义**：字母融合（M09）与字图同构（M10）的权重在上升，纯几何图形标的权重在下降。

### 6. 响应式与可变成为默认要求
LOGO 不再是一张图，是一套规则：一个不可变的锚点 + 三级简化（完整/中等/16px）。可变字体让同一套字形在不同场景改变字重而不断品牌。

**实践含义**：每个方案都应回答「它缩到 16px 是什么样」。

### 7. 生成式与动态
品牌的视觉语言开始由规则实时生成（声音转图形、数据转渐变）。设计师的角色从「造形者」转为「定规则者」。

**实践含义**：至少准备一版「如果它会动，怎么动」的说明。

## 二、已经过时的做法（不要再做）

| 过时做法 | 为什么过时 | 替代方案 |
|---|---|---|
| 纯黑白极简、无任何色彩 | 无法在信息流中区分 | 1 主色 + 1 中性 + 1 强调 |
| 彩虹渐变 / 多色渐变绕圈 | 2016 年的 Instagram 遗产 | 2 色单向渐变 |
| 蓝色渐变 + 电路板线条 = 科技 | 最廉价的科技刻板印象 | 参数化几何、超椭圆、留白 |
| 叶子 = 环保 | 语义饱和 | 大地色系 + 有机形态 |
| 盾牌 + 地球 = 金融 | 90 年代企业形象 | 网格几何 + 单一强调色 |
| 斜面浮雕 + 高光 | 2000 年代 Web2.0 | 平涂，或极轻 AO |
| 做旧纹理 + 复古字 | 廉价复古 | 复古结构 + 当代干净度 |
| 过度描边贴纸风到处用 | 2020 潮牌泛滥 | 只在真正的街头品类用 |
| 字距收紧 | UI 习惯误用 | 品牌标默认加宽 |
| 用 `<br>` 式多行堆叠名字 | 缩小即失效 | 横排 lockup 或缩写 |

## 三、当代语汇表（写提示词时可直接用）

**可用的当代形容词**
`restrained`、`precise`、`quietly confident`、`warmly engineered`、`crafted`、`grounded`、`deliberate`、`tactile`、`architectural`

**已失效的形容词**
`vibrant`、`dynamic`、`sleek`、`cutting-edge`、`futuristic`、`eye-catching`（这些词在模型里会触发 2015 年的视觉套路）

## 四、行业审美的当下偏移

| 行业 | 三年前的做法 | 现在的做法 |
|---|---|---|
| 科技 | 蓝色 + 渐变球 | 中性色 + 一个参数化结构 |
| 餐饮 | 红黄 + 手写体 | 单色徽章 + 高质感衬线 |
| 美妆 | 粉金 + 花体 | 裸色 + 极简字标 + 一处金属 |
| 咖啡 | 棕色 + 咖啡豆 | 去咖啡豆，用字体与留白 |
| 运动 | 斜体 + 速度线 | 粗重字标 + 极简符号 |
| 教育 | 蓝 + 书本铅笔 | 抽象几何 + 明亮单色 |
| 金融 | 深蓝 + 盾牌 | 墨黑 + 哑金 + 网格 |
| 文旅 | 山水剪影 | 在地几何转译 + 大地色 |

## 五、如何自检「是否过时」

三个问题：
1. 这个配色，2019 年的作品集里是不是到处都是？是 → 换。
2. 把这个 LOGO 和三家同行放在一起，能一眼分出来吗？不能 → 换结构而不是换色。
3. 把颜色全去掉，它还是一个好图形吗？不是 → 结构不够，别靠色救。

> 趋势报告的作用不是让你跟随所有趋势，而是让你知道哪些语言已经被用尽。真正的差异化来自「理解趋势背后的逻辑，然后走另一条路」。
