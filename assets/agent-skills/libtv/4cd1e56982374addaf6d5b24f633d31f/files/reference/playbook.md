# 品牌 LOGO 设计 · 完整版 Playbook

> 这是全链总纲。其余 `01`-`08` 是它的零件库，本文是装配线。
> 目标：从用户一句「我想做个 LOGO」，走到可直接落地的品牌标志 + 交付说明。

---

## 0 · 全链地图

```
[Stage 0] 需求接收      收素材 / 判入口 / 补齐缺口
      ↓
[Stage 1] 品牌解码      输出 Brand Decode Card（关键词 / 行业原型 / 风格候选 / 色彩主张 / 差异化缝隙）
      ↓
[Stage 2] 偏好锁定      4 项用户选择（形态 · 冷暖 · 字体 · 设计方向≤5）
      ↓
[Stage 3] 概念生成      3 条方向（每条含方法、符号逻辑、配色、字体）
      ↓
[Stage 4] 提示词与出图  七段式提示词 → 逐版生成 → 选优
      ↓
[Stage 5] 质检与交付    12 项硬检 → 多版本 → 说明文档
```

**轮次预算**：Stage 0-1 一轮完成（不要让用户填表），Stage 2 一轮（一次问完四项），Stage 3-5 一到两轮。全程 3-4 轮对话内交付。

**铁律**：每个 Stage 结束必须给出「我的判断 + 理由」，再进下一步。不要让用户面对空白提问。

## Stage 0 · 需求接收

### 0.1 五种入口，先判入口

| 用户给的东西 | 入口 | 立即动作 |
|---|---|---|
| 只说了行业 / 品牌名 | 极简入口 | 直接查 04-industry 出默认判断，不要追问 20 个问题 |
| 上传了参考图（风格） | 风格入口 | 看图，识别「构成类型 + 风格谱系 + 容器 + 线条」四元组，说出来让用户确认 |
| 上传了色系参考图 | 色彩入口 | 跑 `extract_palette.py`，量化取色后再判断冷暖 |
| 上传了品牌策划书 / 商业计划书 | 文档入口 | 提取：品牌名、理念、目标人群、差异化、禁忌，不要通读全文 |
| 组合（多个都有） | 混合入口 | 优先级：策划书 > 色系图 > 风格图 > 口述 |

### 0.2 必需信息清单

无论哪个入口，开始设计前必须拿到这五项（缺的用推断 + 确认，不要让用户填空）：

| 项 | 必需度 | 拿不到时怎么办 |
|---|---|---|
| 品牌名称 | 必需 | 直接问，这是唯一不能推的 |
| 行业 / 品类 | 必需 | 从名称与描述推断，然后确认 |
| 品牌理念 / 人群 | 推荐 | 按行业默认值给一版，标注「暂按…处理」 |
| 风格偏好 | 推荐 | 看参考图；无参考图则按行业给默认 |
| 禁忌 | 可选 | 主动提醒一句「有没有绝对不能用图形或颜色」 |

### 0.3 参考图的读法（不要只说「参考了这个风格」）

按四层拆解，逐层说出来：

```
我看到这张参考图的：
· 构成类型：组合标，图形在左、字在右
· 风格谱系：B5 复古（70s 暖棕）+ 一点点 B4 手作
· 容器形态：圆形徽章，细边
· 线条语言：粗描边，圆头
我打算保留【风格 + 容器】，把【构成类型】换成纯图标，
因为你的主要使用场景是 App 头像，字在下面会糊掉。
```

这种拆解会让用户立刻信任你的专业度，也避免「照抄竞品」。

### 0.4 色系参考图

```bash
python scripts/extract_palette.py --image "<路径>" --top 5 --ignore-bg
```

读它的输出：
- `temperature = warm / cool / neutral` → 对应 Stage 2 的冷暖选项默认值
- `saturation_avg` → 判断用户审美是「低彩度克制」还是「高彩度张扬」
- `nearest_pantone` → 直接作为主色锚点候选

**注意**：不要直接用参考图里的 HEX，要用它的**潘通最近邻**重新配一套完整方案。原因：截图颜色通常偏色、且缺少深色支点与浅色基底。

## Stage 1 · 品牌解码

这一步的产物是 **Brand Decode Card**，必须显式写给用户看，不能只在心里想。

### 1.1 解码卡模板

```
【品牌解码】云知 · 在线教育

· 核心关键词（3 个）：轻盈 / 连接 / 开启
  推导：名「云」→轻盈、无界；「知」→知识、光；理念「流动」→连接
· 行业原型：教育 → 需要「可信 + 生长 + 不幼稚」
  同行普遍在做：蓝色 + 书本/铅笔/学士帽
  → 差异化缝隙：避开书本与学士帽，走「抽象几何」而非「具象教育符号」
· 风格候选：B1 极简克制（主）+ B2 几何结构（辅）
  → 理由：教育行业已过度使用柔和的圆润体，走几何能显得更「有效果」
· 色彩主张：冷调，主色用比常规教育蓝更深的经典蓝
  → 理由：避开 #4A90E2 级别的通用蓝，深蓝更稳、更像机构
· 字体方向：几何无衬线（Montserrat / 思源黑体 Bold）
· 禁忌：不要在图形里出现书本、铅笔、学士帽、灯泡
```

### 1.2 差异化缝隙（最关键的一步）

同行都在用的视觉语言不能再用。判断方法：

1. 列出该行业最常见的 3 个视觉套路（查 04-industry 的「禁忌」列）
2. 找出一个「没人用但合理」的替代方法（查 02-methods）
3. 用一句话说出为什么这个替代更好

**换色是没用的，换结构才有用。** 如果三个方案只是颜色不同，等于只有一个方案。

### 1.3 解码卡要给用户确认

一句话收尾：「按这个理解往下走，如果我判断错了你现在纠正还来得及。」
不要问「你觉得对吗」，要给一个可被否定的具体判断。

## Stage 2 · 偏好锁定

一次性问完四项，不要分四轮。用选择卡片，每项给 3-4 个具体选项 + 一句推荐。

### 2.1 四项选择

| 项 | 选项 | 默认/推荐逻辑 |
|---|---|---|
| **① 版本形态** | 纯图标版 / 图文组合版 / 两版都要 | 新品牌一律推荐「两版都要」 |
| **② 主色调** | 冷色调 / 暖色调 / 中性偏冷 / 中性偏暖 | 按行业 + 参考图定默认 |
| **③ 字体** | 几何无衬线 / 现代人文无衬线 / 高对比衬线 / 定制字母标 | 按行业 + 气质定默认 |
| **④ 设计方向** | 从 M01-M24 中选，**不超过 5 式** | 推荐 3 式（标 ★），其余全列出 |

### 2.2 其余项由 SKILL 自行决定（不再问）

- 辅助色、强调色、中性色的具体色值与数量
- 对比度标准（图形 ≥3:1，文字 ≥4.5:1）
- 单色适配方案
- 容器形态、线条语言、质感
- 图文排布比例、字重、字距

**为什么**：用户不具备判断这些的专业知识，问了只会得到「都行」，然后拿到一个平庸的结果。专业判断由 SKILL 承担，只需在交付时说明理由。

### 2.3 设计方向的呈现方式

先给一句总览，再上表，最后给推荐：

```
LOGO 设计有 24 种主流方法，分 5 族。你选不超过 5 式，我建议 3 式。

【结构化几何族】
M01 网格构图 · M02 黄金比 · M03 抽象几何 · M04 参数化 · M05 模块化 · M06 超椭圆
【语义符号族】
M07 符号学 · M08 负空间双关 · M09 字母融合 · M10 字图同构 · M11 超级符号 · M12 文化转译
【形态简化族】
M13 极简还原 · M14 具象简化 · M15 单线 · M16 有机仿生 · M17 渐变 · M18 轻立体
【表现风格族】
M19 手绘 · M20 复古现代 · M21 解构拼贴 · M22 徽章印章 · M23 吉祥物 · M24 动态可变
【（M24 亦属系统族）】

针对「在线教育 + 冷调 + 几何无衬线」，我推荐：
★ M07 符号学（云与知识的双重编码）
★ M08 负空间（用空隙形成向上的箭头，暗喻成长）
★ M13 极简还原（教育品牌需要 10 年不过时）
另可选：M01 网格（更精密）、M16 有机（更亲和）、M10 字图同构（名字即卖点）
```

### 2.4 用户选太多 / 选太少

| 情况 | 处理 |
|---|---|
| 选了 >5 式 | 「这 5 式里有 3 式在抢同一件事，我先按最强的 3 式做，其余作为微调备选」 |
| 只选 1 式 | 直接做，但在方案里悄悄补 1 个辅助式（交付时说明） |
| 选了互相冲突的（如 M13 极简 + M23 吉祥物） | 明确指出冲突：「吉祥物必然带细节，和极简打架。要么走极简符号，要么走吉祥物，你更想要哪个？」 |
| 全选「你决定」 | 按 02-methods 的「方法组合配方」表直接给 3 式，不再问 |

## Stage 3 · 概念生成

出 3 条方向，每条必须**用不同方法**，且**结构上真的不同**（不是同一图形换颜色）。

### 3.1 每条方向的写法（固定四段）

```
方案 A · [方法名] 
· 图形逻辑：一句话说清"为什么是这个形"
· 结构：几何描述（几个形、什么关系、负空间在哪）
· 配色：主色 HEX（潘通号）+ 辅助用什么、只出现在哪
· 字体：字族 + 字重 + 字距
· 一句话记忆点：别人会怎么向朋友描述它
```

### 3.2 三条方向的差异化配比

| 位 | 定位 | 风险度 | 方法倾向 |
|---|---|---|---|
| A | 最稳、最像行业最佳实践 | 低 | M07 / M01 / M13 |
| B | 最有记忆点、最有辨识度 | 中 | M08 / M10 / M11 |
| C | 最大胆、最有态度 | 高 | M21 / M04 / M12 |

这样用户无论选哪个，都有「保守—平衡—激进」的判断依据。

### 3.3 不许出现的东西

- 三个方案都是「一样的圆 + 不同颜色」
- 三个方案用的都是同一个方法
- 方案描述里出现「象征」「寓意」却不解释具体对应关系
- 出现「简洁大方」「国际化」「有活力」这类空话

## Stage 4 · 提示词与出图

### 4.1 组装顺序

1. 从 Stage 2 拿：形态、冷暖、字体、方法
2. 从 Stage 1 拿：品牌名、行业、理念、禁忌
3. 从 03-color 拿：主色潘通 + HEX（或跑 `palette_builder.py` 生成）
4. 按 06-prompting 的七段式拼装
5. 逐版生成，每版只改 MARK 段

### 4.2 调色（一行命令）

```bash
python scripts/palette_builder.py --primary "<潘通号或HEX>" --temperature cool --harmony split --roles 4
```

输出直接包含：色值表、潘通最近邻、白底/黑底对比、单色灰度值、以及可粘进提示词的 `colour palette:` 行。
若体检结论里有「白底对比 <2:1」，必须在提示词里改为「深色图标 + 亮色块」。

### 4.3 出图策略

| 目标 | 做法 |
|---|---|
| 纯图标版 | 单独一条提示词，`no text, no letters` 写死 |
| 图文组合版 | 图标与文字分开出，再排版合成（模型写中文必错） |
| 三版对比 | 三条提示词各出一张，其余六段完全一致 |
| 单色版 | 对选定的彩色版做去色，不重新生成 |
| 深底版 | 对选定版反相重设底色，不重新生成 |

### 4.4 迭代判据

出图后先自检，不合格直接重出，不要把不合格的图交给用户选：

- 有渐变/阴影/立体 → 重出
- 出现了文字或字母 → 重出
- 图形顶满画面，没有留白 → 重出
- 形状数量明显超过 3 个 → 重出
- 颜色与指定 HEX 明显不符 → 重出

## Stage 5 · 质检与交付

### 5.1 硬检

按 07-quality-gate 的 12 项逐条过。可自动化的部分：

```bash
python scripts/check_spec.py --file spec.json
```

### 5.2 交付包

- 纯图标（白底 / 透明底）
- 图文组合（白底 / 深底反白）
- 纯黑版、纯白版
- App 图标版（超椭圆容器）
- 设计说明（概念 / 方法 / 配色 / 排版 / 禁区）
- 色值表

### 5.3 说明的写法

见 07-quality-gate 第四节模板。核心原则：**每个决定都要有理由**，理由要能对应到品牌本身，而不是「这样好看」。

## 6 · 两个完整案例

### 案例一 · 花店（C 端、小预算、要温度）

**输入**：「我开了一家花店，叫『野蔷薇』，主要卖给年轻人，想要不太俗的。」

**Stage 1 解码**
- 关键词：野生 / 带刺 / 不当乖乖女
- 行业原型：花店 → 同行都在做「细线花朵 + 豆沙粉 + 手写体」
- 差异化缝隙：**不做花**。做「刺」——用一条带尖角的曲线，比画花更「野蔷薇」
- 风格：B4 有机（主）+ B8 锐角（辅）
- 色彩主张：暖调，但避开豆沙粉，用「浆果洋红 + 陶土」

**Stage 2 用户选**：两版都要 / 暖调 / 定制字母标 / 选 M16 有机 + M21 解构 + M19 手绘

**Stage 3 三方向**
- A（稳）：单线蔷薇枝，三朵花苞简化到只剩轮廓，M16 + M15
- B（记忆点）：一个「R」字母，笔画在一处变成带刺的藤，M10 + M19
- C（大胆）：两段弧线交叉成花萼，交叉处留尖角缺口，M08 + M21

**Stage 4**
```
python scripts/palette_builder.py --primary "18-1750 TCX" --temperature warm --harmony analogous --roles 4
```
主色 `#BB2649`（非凡洋红）+ 辅 `#DC8661`（陶土）+ 亮 `#D6D2C4` + 暗 `#4B2E2B`

**Stage 5**：选 B 方向。交付 6 个文件 + 说明，指出最小尺寸 28px，四周留白 ≥ 图形高 25%。

### 案例二 · AI SaaS（B 端、要专业、要不像「又一个科技蓝」）

**输入**：上传了色系参考图（深蓝 + 青绿），品牌名「Tidegraph」，做潮汐数据分析。

**Stage 0 色彩入口**
```
python scripts/extract_palette.py --image "ref.png" --ignore-bg
→ temperature: cool, saturation_avg: 46, 主色候选 #12507F / #2E8B94
```

**Stage 1 解码**
- 关键词：潮汐 / 周期 / 可读
- 行业原型：数据 SaaS → 同行都在做「蓝色 + 节点网络 + 渐变」
- 差异化缝隙：**不做节点网络**。做「等距的潮汐线」——一组由参数化规则生成的平行曲线，密度渐变，像潮位图
- 风格：B2 几何结构（主）+ B12 数字原生（辅）
- 色彩：冷调，深蓝为主，青绿只用于「涨潮」那一段曲线

**Stage 2**：两版 / 冷调 / 几何无衬线 / M04 参数化 + M01 网格 + M13 极简

**Stage 3**
- A：5 条等距曲线，间距按 1:1.618 递减，M01 + M04
- B：一条曲线在中间被「折断」成两段错位，M21 + M04
- C：超椭圆容器内 3 条曲线，密度从左到右递增，M06 + M17

**Stage 4**
```
python scripts/palette_builder.py --primary "#12507F" --temperature cool --harmony split --roles 4
→ 主 #12507F、辅 #2E8B94、强调 #C9A227、亮 #F0EEE9
```

**关键判断**：数据类品牌的图形必须能「被讲成一个规则」，而不是「看起来像数据」。所以最终选 A，因为「间距递减」这条规则可以被客户复述。

## 7 · 话术库

**开场（不要问「你想做什么样的」）**
> 我按「花店 + 面向年轻人」先给你一版判断：同行基本都在做细线花朵 + 豆沙粉 + 手写体，这套已经不区分了。我建议反过来，用「刺」做符号——更贴合「野蔷薇」这个名字。往下走之前，先确认三件事…

**给默认值**
> 火锅这个品类我建议走徽章 + 高饱和红橙，因为要传达聚会感和食欲；蓝色会压制食欲，不建议用。如果你想要「不像传统火锅店」的调性，我们也可以走黑白 + 一个朱红强调，但那是另一种定位，你选。

**解释为什么不用黑白极简**
> 黑白极简在 2018-2022 是主流，现在的问题是信息流里完全无法区分。我的做法是：结构上保持极简，但给一个有主张的主色 + 一个只出现在关键部位的强调色。这样既当代，又有记忆点。

**用户说「再大气一点」**
> 「大气」通常指三件事之一：字距更宽、留白更多、图形更少。我按这三条改一版，你看是不是这个方向。

**用户给的参考是竞品**
> 这张图的构成类型和容器我可以借鉴，但图形逻辑必须换——不然就是抄。我保留「圆形徽章 + 粗描边」这个语言，把里面的图形换成你自己的符号。

## 8 · 异常处理

| 情况 | 处理 |
|---|---|
| 用户什么都不说，只发一句「做个 LOGO」 | 用行业默认值直接给一版完整方案 + 3 个待确认点，让用户改而不是让用户填 |
| 用户要求「要像 XX 品牌」 | 拆解 XX 的四元组，保留风格、换结构，并明确说明「结构必须换，否则是侵权」 |
| 用户要求超过 5 色 | 解释记忆原理，给出「5 色内最接近的效果」，若坚持则在交付说明里标注风险 |
| 用户要求纯黑白 | 可以，但必须同时给一个有色彩的推荐版，说明为什么 |
| 品牌名是生僻字 / 超长 | 优先缩写或字母标（A2），并说明取舍 |
| 策划书内容与口述冲突 | 以策划书为准，明确指出冲突点 |
| 用户反复改但说不出要什么 | 停止改稿，回到 Stage 1 重新确认「核心关键词」，通常问题出在定位而不是设计 |
| 上传的图是别人的 LOGO | 只做「结构分析」，不做「复刻」。明确告知边界 |

## 9 · 自检清单（每次交付前默读一遍）

- [ ] 我是否说出了「为什么是这个形」，而不只是「这个形好看」
- [ ] 三个方案是否在结构上真的不同
- [ ] 配色是否 ≤5 色，是否有深色支点与浅色基底
- [ ] 主色是否通过了白底 3:1
- [ ] 是否给了单色版、深底版、透明底
- [ ] 是否写了最小尺寸与留白规范
- [ ] 是否有任何一处「通用素材感」
- [ ] 把颜色全去掉，它还是个成立的图形吗
