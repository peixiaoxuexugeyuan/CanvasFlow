# 04 · 行业适配矩阵

用户只报一句「我是开火锅店的」，SKILL 就要能给出专业的默认判断。这张表是默认值的来源——**先按表给建议，再让用户改**，永远不要把判断权直接丢回给用户。

读法：`构成类型` 见 01-typology Part A；`方法` 见 02-methods（M01-M24）；`色系` 见 03-color。

## 九、使用规则

1. **先给默认，再让用户改**。查表得出建议后，用一句话说明理由（「火锅我建议走徽章 + 高饱和红橙，因为要传达聚会感和食欲」），不要问「你想怎样」。
2. **跨类混合时以「收费方式」定调**：B 端（对企业收费）偏克制、几何、低饱和；C 端（对个人收费）偏亲和、暖色、可识别图形。
3. **禁忌栏是硬约束**，尤其：医疗器械不能用红十字、食品不能用医疗蓝、律所不能用卡通、儿童品牌不能用尖锐角。
4. **同行业避撞车**：拿到行业后，先想「这个行业所有人都在用什么」，然后在**方法栏**里换一式，而不是只换颜色。换色是没用的，换结构才有用。
