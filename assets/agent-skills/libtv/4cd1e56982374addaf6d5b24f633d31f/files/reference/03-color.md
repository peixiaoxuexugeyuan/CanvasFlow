# 03 · 色彩系统

色彩是这个 SKILL 与「只会出黑白极简」的分水岭。规则只有三条，但每条都必须执行：

1. **总数 ≤ 5 色**（含中性色）。超过 5 色，品牌色就失去记忆功能。
2. **必须有 1 主色 + 1 深色支点 + 1 浅色基底**。缺任一，小尺寸与印刷场景必崩。
3. **色值以潘通为锚**。屏幕 HEX 只是投影，正式落地以实物色卡为准。

---

## 一、色彩结构：四角色制

不要把颜色当平等的一堆色块。每一色必须承担角色：

| 角色 | 数量 | 面积占比 | 职责 | 举例 |
|---|---|---|---|---|
| 主色 Primary | 1 | 40-70% | 承载品牌第一印象，出现在图标主体 | `#0F4C81` 经典蓝 |
| 辅助色 Secondary | 0-2 | 15-35% | 与主色形成关系（邻近或对比），负责层次 | `#7BC4C4` 水天蓝 |
| 强调色 Accent | 0-1 | 3-10% | 唯一的高亮，用来「点一下」 | `#F5DF4D` 亮丽黄 |
| 中性色 Neutral | 1-2 | 15-50% | 底色、文字、留白，保证呼吸 | `#F0EEE9` 云上舞白 |

**面积定律**：主色 : 辅助色 : 强调色 ≈ 60 : 30 : 10。反过来（强调色占大面积）会立刻显得廉价。

---

## 二、冷暖：用户只选这一项

用户只决定「主色是冷还是暖」，其余由 SKILL 推导。判断标准看 HSL 色相：

| 色相区间 | 归类 | 心理效应 | 典型行业 |
|---|---|---|---|
| 0-20°（红）、330-360°（品红） | 暖 | 强烈、食欲、紧迫 | 餐饮、零售、运动 |
| 20-45°（橙） | 暖 | 亲和、活力、年轻 | 餐饮、亲子、快消 |
| 45-70°（黄） | 暖（高明度） | 乐观、高可见，但白底不可读 | 零售、物流、警示类 |
| 70-160°（绿） | 冷 | 自然、健康、可持续 | 有机、环保、健康 |
| 160-200°（青） | 冷 | 洁净、科技、精确 | 医疗、SaaS、美妆 |
| 200-250°（蓝） | 冷 | 可信、专业、冷静 | 金融、科技、政企 |
| 250-300°（紫） | 冷 | 创意、神秘、高级 | 美妆、文化、AI |
| 300-330°（紫红） | 冷（偏暖感） | 前卫、女性、潮流 | 时尚、潮牌 |

**中性偏暖 / 中性偏冷**：当用户选「中性」时，不要给纯灰。用带色相倾向的中性——
暖中性用米、砂、驼（`#D6D2C4` 7527 C），冷中性用蓝灰、石灰（`#53565A` Cool Gray 11 C）。
纯灰 `#808080` 是设计上最偷懒的选择，会让 LOGO 显得没做完。

## 三、六种配色法则（数学关系）

选定主色后，用以下法则推导辅助色。运行 `scripts/palette_builder.py --harmony <法则>` 可直接得到结果。

| 法则 | 色相关系 | 效果 | 什么时候用 | 风险 |
|---|---|---|---|---|
| `mono` 单色相 | 同色相，只变明度/彩度 | 最克制、最贵气 | 高端线、建筑、极简 | 层次不够会显单薄 |
| `analogous` 类似色 | ±30-32° | 和谐、舒服、有呼吸 | 生活方式、食品、健康 | 对比不足，易「温吞」 |
| `complementary` 互补 | +180° | 最强张力 | 运动、潮牌、儿童 | 生硬，必须降饱和一侧 |
| `split` 分裂互补 | +150° / +210° | 有张力但耐看 | **当代品牌默认首选** | 三角关系需控制面积 |
| `triadic` 三角 | +120° / +240° | 活泼、跳跃 | 儿童、创意、活动 | 三色等权会乱，必须定主次 |
| `neutral` 中性主导 | 主色 + 大面积中性 + 一点强调 | 高级、专业 | 律所、金融、奢侈品 | 强调色选错就全盘失焦 |

**为什么默认 `split`**：它同时具备「对比」（不像类似色那样温吞）与「稳定」（不像互补那样刺眼），是 2020 年代品牌设计中使用率最高的关系。

### 反彩虹原则
一个 LOGO 里出现 4 个以上色相且彼此没有主次，就会变成「调色盘」。如果一定要多色，必须是**同一色相家族的不同明度**，或**一个主色 + 一个强调色 + 中性**。

## 五、对比度标准

LOGO 与界面文字的标准不同，别混用：

| 对象 | 最低对比 | 依据 |
|---|---|---|
| 图形标（纯图标） | **≥ 3:1** | 图形非文本，WCAG 非文本对比标准 |
| 图文组合中的文字 | **≥ 4.5:1** | 正文级可读性 |
| 大字号品牌名（≥24px 粗体） | ≥ 3:1 | 大文本豁免 |
| 深色界面上的反白 | ≥ 3:1 | 反白不是自动安全 |

**硬规则**：任何「浅色 + 白底」组合（对比 <2:1）都**禁止**作为主识别元素。浅黄、浅青、浅粉只能出现在深底色块上，或作为大面积背景而图标改走深色。

> 例：P13「柠檬薄荷」主色 `#F5DF4D` 白底对比仅 1.35:1。这类方案不是不能用，而是**必须**配套「深色图标 + 亮色色块」版本，否则白底场景直接失效。

## 六、单色适配（强制）

每个配色方案必须能无损转为纯黑与纯白两个版本。检查方法：

1. 把全部色块换成灰度，看形态是否还能读
2. 只用一个墨色，看层次是否靠**形**而不是靠**色**成立
3. 纯白版放在深色底上，看边缘是否粘连

运行 `scripts/palette_builder.py` 会自动为每个色给出灰度等价值与纯黑/纯白对照。

**最容易翻车的三类设计**：
- 两个形状靠「颜色不同」区分 → 单色后糊成一团
- 用渐变表达立体 → 单色后扁平如纸
- 用极浅色描边做分隔 → 单色后消失

修法一律是把区分**转移到形状、间距、留白**上。

## 八、行业色彩心理（速查）

| 行业 | 首选主色 | 慎用 | 说明 |
|---|---|---|---|
| 科技/SaaS | 蓝、青、靛 | 棕、土黄 | 蓝=可信，青=精密 |
| 金融/保险 | 深蓝、深绿、墨黑 | 荧光色 | 要「稳」，不要「刺激」 |
| 餐饮/火锅 | 红、橙、朱红 | 蓝、紫 | 红橙促食欲；蓝抑制食欲 |
| 咖啡/烘焙 | 棕、米、驼、奶白 | 高饱和粉 | 材质感优先 |
| 茶/东方 | 墨绿、砂白、黛 | 荧光色 | 留白比配色更重要 |
| 美妆/护肤 | 裸粉、豆沙、紫、金 | 纯黑大面积 | 肤色系安全，紫=高级 |
| 运动/户外 | 高亮橙、荧光黄绿、深黑 | 粉、浅紫 | 需要「能量值」 |
| 母婴/亲子 | 奶油黄、薄荷、浅粉 | 深黑、正红 | 高明度低对比 |
| 医疗/健康 | 青、浅蓝、白 | 红（除非急救） | 洁净感优先 |
| 律所/咨询 | 墨黑、深蓝、哑金 | 亮色 | 克制即权威 |
| 潮牌/音乐 | 黑 + 荧光撞色 | 米色系 | 要有对抗性 |

## 九、五个必查错误

1. **纯黑 `#000000` 直接当品牌黑** → 屏幕过硬、印刷死板。改用 `#1A1A19`（419 C）。
2. **用中性灰 `#808080` 做辅助色** → 显廉价。改用带倾向的灰（冷灰 `#53565A` / 暖砂 `#D6D2C4`）。
3. **配色靠「好看」定，不靠关系定** → 每种色必须能说出它与主色是什么关系（类似/互补/分裂/三角）。
4. **忘了深色版** → 深底场景直接失效，且单色印刷无支点。
5. **超过 5 色** → 无论多好看，都是配色失败。
