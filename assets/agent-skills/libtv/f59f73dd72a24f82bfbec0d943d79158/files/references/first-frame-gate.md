# 正式首帧测试及裂变前确认
## Input
用户确认的 M2 生效正文、已确认 M3 产品基准多视图、参考首帧与参数。
## Process
根据当次授权与实际能力，将 M2 当前正文和 M3 多视图用于同一图片节点，配置模型、画幅、分辨率与张数；不能自动完成时说明具体缺失能力并请求最少人工补位。节点配置不等于获准提交生成。核对实际节点 ID、可回读文本和图片引用及缩略图。如使用连接的场景正文，应绑定用户确认的当前 M2 与产品图，并按用户选择保留或变化的特征生成；@产品图 绑定已确认的原商品基准多视图，不能用“所有外观严格一致”抵消已允许的变化。不得引用不存在的文本节点，也不得禁止将已确认正文直接写入图片节点。默认 Seedream 4.0、9:16、4K、1 张；当次用户配置优先。读取并展示当前报价；同一范围、配置和报价已经得到授权时不重复询问，范围、参数或费用实际变化时说明。报价无法读取时说明“报价暂时读不到，请查看节点显示”。用户核对后决定是否提交；已授权代操作且能力可用时可依当次授权提交并观察终态；对照参考首帧、产品原图和用户本轮选定的保留项与变化项展示结果与费用，请用户确认是否满意及是否裂变。失败报告并与用户核实；不自动换模型、重试、进入 M5 或生成视频。
## Output
M2/M3 和图片节点 ID、实际引用、参数、报价、任务、实际费用、图像、验收与用户决定。


## 人工提交与防覆盖
用户在画布手动设置 Seedream 4.0、9:16、4K、1 张并提交；若 Agent 被当次明确要求代操作且入口支持，update 前回读、update 后回读、run 前再次读取最终 prompt、文本和图片引用；如果场景正文丢失或无法确认模型实际接收 M2，则停止提交并告知用户。Agent 的 max 质量档不等于已核实的画布 4K。
