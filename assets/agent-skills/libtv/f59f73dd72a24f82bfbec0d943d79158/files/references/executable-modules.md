# 执行模块 M0—M7

所有模块输出状态 PASS / FAIL / UNKNOWN / NEEDS_HUMAN、证据和下一步。失败立即报告并与用户核实；仅停止依赖失败环节的后续工作，独立工作在能力、授权和用户约束允许时继续。不得自动重试；不伪称节点、模型输入、数值检测或生成已验证。费用流程：读取当前报价，展示单张、本批及适用的总价；已确认的相同范围、配置和报价不重复询问，变化时说明；报价读不到时请用户查看节点显示。收费任务经用户选择后提交，记录任务和实际费用，失败费用未知时如实说明。

## M0 场景配置
### Input
用户要求、参考首帧、产品图、已有节点和当次授权。
### Process
识别素材 ID、需要替换的对象、用户需求和可见画面；新商品隔离旧任务参数。IF 无法识别必需信息 THEN NEEDS_HUMAN。画幅按用户指定；未指定时标待确认。不得推断不可见动作、用途、功效。先探测实际工具能力并分别记录 Agent、插件、CLI 和画布 UI 可用范围。
### Output
素材及配置、来源、能力证据；M3 和 M1 可在授权及能力允许时独立执行。

## M3 产品多视图
### Input
产品原图、用户已认可的多视图、模型参数、报价和授权。
### Process
IF 用户认可且已核实现有多视图身份、来源和引用 THEN 复用；ELSE 读取 `product-check.md`，使用 Seedream 4.6、16:9、2K、1 张及用户原版提示词；用户当次配置优先。核对实际引用、模型、设置并展示当前报价，用户决定后提交。IF 模型不能自动设置 THEN 指出节点请用户手动设置并回读；在允许条件下继续独立的 M1。比对原图，未展示角度标未知；展示结果等待认可，不自行重试。
### Output
选定多视图 ID、模型、任务状态、报价/费用、验收和用户确认。

## M1 反推与原文保存
### Input
用户指定首帧 ID、确认的完整反推指令、Qwen 3 VL Flash。
### Process
核对首帧与原指令，读取 `scene-prompt.md` 和 `visual-analysis.md`；原样输入指令，连接首帧，核对模型与引用，展示当前报价，用户决定后运行。只描述可见信息，保留实际结果及来源；不擅自改模型。当前 Agent 报告无文本节点创建、编辑和运行工具：输出完整指令与正文，由用户手动创建节点并粘贴；画布 AI 结果与对话结果必须标明实际来源，不冒充画布 AI。IF 本入口不能回读 THEN 标未验证。
### Output
original_node_id、original_text、输入图 ID、模型、任务 ID 和结果；成功进入 M2。

## M2 独立复制与优化
### Input
M1 原文、参考首帧及用户删改要求。
### Process
保留 M1 原文，按用户要求形成完整 M2 副本；按 `scene-prompt.md` 明确保留项、允许变化、作用部位、禁止新增物和来源，已明确的不重复询问。展示完整正文和差异供用户确认，记录来源与版本；画布文本节点是可选方式，不能回读时如实说明，不把文件路径冒充画布节点。删除内容及同义新增结构不得从旧摘要或模板回流。
### Output
original_node_id、optimized_seed_node_id、original_text、optimized_text、copy_match、user_confirmed、confirmed_version；需真实证据。

## M4 产品分析（可选）
### Input
用户提供的产品资料、评论以及分析请求。
### Process
IF 缺资料 OR 用户未要求分析 THEN 跳过，不编造洞察、不自动推荐裂变方向；ELSE 按 `product-insight.md` 与 `product-insight-source.md` 分别标明事实、评论和推断及来源。建议不能代替用户决定变化方向。
### Output
可追溯分析或跳过原因。

## 正式首帧测试
### Input
用户确认的 M2 正文与 M3 多视图、参考首帧、参数。
### Process
按 `first-frame-gate.md` 使用确认的 M2 正文及 M3 原商品多视图，按用户选择处理外观；能力允许时配置节点，不等同获准生成。按当次授权和报价执行并观察结果，等待用户决定是否裂变，不自动进入 M5。
### Output
节点及实际引用、参数、报价、任务终态、图像、用户决定。

## M5 种子锁定与裂变
### Input
已确认 M2 版本与全文、用户明确的裂变决定和变化方向、必要原句、可选 M4。
### Process
IF 首帧未确认 OR 用户未决定裂变 THEN 等待；读取已确认 M2 当前全文、版本及变化要求，不回退旧摘要。按 `action-variation.md` 记录用户保留、允许变化和禁止新增的内容及来源；不把产品本体的光学效果变成独立实体。按用户指定数量生成各组独立完整正文，记录实际来源；不依赖画布文本节点。逐组检查编号、内容与用户要求及已删除内容，展示完整正文等待确认；缺项或冲突报告，不自动重试。
### Output
optimized_seed_node_id、confirmed_version、实际种子全文、实际指令、variation_node_id、约束及每组验收与用户确认。

## M6 节点与生成
### Input
经确认的真实 M5 输出、已确认 M3 节点、用户选择的编号与比例。
### Process
按 `action-variation.md`，用户确认后优先由 Agent 通过当前图片节点工具逐组创建或配置节点，将对应完整确认正文直接写入提示词并绑定已确认产品图。回读镜头编号、全文、引用和可读取的模型、画幅、分辨率及张数；不使用不存在的 M5 节点或外部文件路径。引用不能更新时保留旧节点并按已确认方案新建正确节点。能力不足时说明具体缺口并请求最少人工补位。

配置不等于获准生成；用户先看提示词、先别跑或先修改时停止提交。生成前核对当前正文及删除内容，逐张或分批遵循当次选择，分别记录已提交和未提交；相同范围、配置和报价已确认不重复询问，有变化时说明。不得自动收费重试。默认 Seedream 4.0、4K、每节点 1 张、比例由用户选择，用户当次设置优先。
### Output
variation_node_id、variation_slot_id、图片节点 ID、文本和多视图引用、正文写入和回读证据/未知、参数、任务状态、报价和费用。

## M7 验收与交付
### Input
实际生成图、确认的 M2、M5 对应正文、M3 多视图、模型参数与用户反馈。
### Process
根据当前任务动态检查产品、数量、主体、方向/姿态、空间、接触承托、尺度、构图、变化项与禁止项。按 `dynamic-visual-params.md`、`execution-parameters.md` 记录证据；视觉模型的描述不是精确测量，缺检测器时为 UNKNOWN/NEEDS_HUMAN。仅在用户要求清洁任务时读取 `cleaning-stain-check.md` 和 `visual-intensity.md`。用户反馈后定位相关维度，保留其他固定项，展示修改前后并等待确认；重新生成须在当前授权范围内；范围、配置或报价变化时说明并由用户决定，不自动重试。
### Output
逐图实际证据及 PASS / FAIL / UNKNOWN / NEEDS_HUMAN、用户选择、参数与费用；用户确认前不生成视频。


## Agent 入口的实际操作边界与任务记录
本节为 2026-11-07 Agent 报告，不是本轮已验证的官方能力；运行前以当前工具 Schema 为准。该报告称 IMAGE 可创建/更新/运行但 update 不能修改 reference_nodes；TEXT 无创建/编辑/运行工具；模型枚举无 Seedream 4.0/4.6，count 无参数，image2image 的 4K 曾被拒而 quality_spec 可用 max。用户手动选择 Seedream 并核对 count=1、画布显示 4K；Agent 可按实际支持写“最高画质（max档）”，但 max 不等于已验证 4K。只能读取到的参数才标已核实；其他标 UNKNOWN。

创建图片节点后立即记录 node_key，不向用户索要自己已保存的 ID。每次 update 前读取原 prompt 与引用，update 后回读，run 前无条件再次回读最终 prompt、模型和引用；检查人工编辑未被覆盖。若该入口不能更新引用且引用错误，保留旧节点，标废弃并新建正确引用节点；若其他入口确实支持，以其真实契约为准。引用节点变化时标下游可能失效并交用户决定。失败保留原节点，不盲目在原节点重跑；必要时经用户决定新建 v2/v3，不自动收费重试。

当次 Agent 报告称 run_node 必须使用真实审批卡、纯文本授权无效，每轮最多五次且同一种工具；以本轮真实工具要求为准，未经验证不当作其他入口规则。互不依赖且允许的调用可并行，依赖操作顺序执行。用户决策及时记录到环境实际可回读的任务记录；如无法持久记录，说明缺口，不把任务记录称为画布节点。
