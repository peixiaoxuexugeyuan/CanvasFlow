# 参考画面共性识别与复刻核对

这些维度是观察清单，不是每张画面都必须填满的模板。若用户已明确替换对象和保留范围则记录；未指定时先按可见画面完整反推，留待后续开放式询问确认，不预设替换对象；记录最终画幅（未指定时待定）；多张素材先区分不同参考画面、同一产品多角度与分别待处理的图片，不能混成一张。画面有多个产品时确认具体替换对象，其他产品按用户要求保留。图中无对应元素写“不适用”，无法看清写“待核”，不要编造。用可见证据支撑判断，不能从单张静帧推断镜头运动、前后动作、声音或隐藏结构；用户提供完整视频时可基于视频另行分析，不把推测标为已见。本 Skill 面向参考首帧商品替换；纯场景复刻或整段视频复刻需另行确认范围。

## 观察与记录

1. **主体与层次**：有哪些可见人物、产品、道具和环境；主体数量、前景/中景/背景、相互遮挡。区分待替换对象和应保留的其他主体。
2. **空间与构图**：画幅、主体相对位置和画面占比、朝向、留白、裁切、透视、地平线或主要线条；记录产品与手、桌面或其他物体是否接触、悬空、支撑、遮挡。用大致区间或相对位置描述，不虚报像素精度。
3. **镜头与景深**：从可见画面判断景别、视角、焦点及虚实层次；无法判断具体镜头焦距、运动或拍摄设备时不猜。
4. **环境与材质**：场景中可见的表面、纹理、背景和与叙事有关的细节；区分新旧产品表面与周围环境。不要将旧商品的颜色、材质、包装或部件转写为新商品属性。
5. **光影与色彩**：观察光的方向、软硬、明暗关系、阴影及反射，区分环境色和旧产品本身色彩；保留有依据的氛围和整体色调，避免编造具体光源。
6. **动作与瞬间**：只写可见姿态与接触状态；静物没有动作就不添加人物或动作。视频分析时区分已见的时间变化与单帧无法确认的运动。
7. **风格与画面文字**：描述有证据的摄影、插画或其他视觉表现，不强制所有图都是写实或工业风。区分环境中应保留的文字、旧产品文字和新产品标签；不确定文字标记待核，不用泛化负面提示一并删除。

## 转成提示词和验收

- 按“保留 / 替换 / 不确定”整理要点，再写自足的完整场景文本；产品的画面位置和相对尺度可作为构图锚点，但外形、颜色和部件以新产品素材为准。
- 新旧产品差异可能使原来的握持、遮挡、相对大小或构图无法同时成立。阴影、倒影和与产品紧密相连的遮挡也可能依赖旧产品形状：保留其光照逻辑和画面作用，按新产品与场景的真实关系适配，不复制旧瓶轮廓或颜色。标出冲突及取舍，不虚构产品结构、不静默重设计；由用户决定优先项。
- 重要关系比固定字段数量更重要。先写主体和空间，再写镜头、环境、光影、色彩、风格与关键细节；负面提示只针对实际风险，不能与新产品的标签、结构或用户目标相冲突。
- 生成后用同一清单对照参考图和产品原图，逐项标记“一致 / 有偏差 / 不可判断”，说明证据；细节看不清不视为通过。只有实际出图和用户验收后才能报告画面结果。

## 本版补充规则


只观察当前素材实际存在的元素，按用户需求和可见证据识别吸睛点与视觉骨架：主体身份和数量；主体朝向、运动方向、镜头观察方向分别记录；姿态动作、遮挡、接触、支撑承托、空间上下左右前后、相对大小、景别、透视、构图、环境、光影、色彩和风格。上述为观察维度，不强制填满；看不清为 UNKNOWN，不存在为 NOT_APPLICABLE。静帧不能证明隐藏结构、先后动作或产品功效；不可凭手部外观确认族裔。

按用户原话与已确认种子动态生成 MUST_KEEP、ALLOWED_CHANGE、MUST_STRENGTHEN、MUST_NOT_APPEAR；只改变授权维度，方向、接触和主体关系不得随场景或机位默默变化。互相冲突先说明并等待用户决定。不得自动引入汽车、清洁球、人物或污渍等其他案例；用户决定是否裂变及变化方向。


## 锁定与用户选择
集中呈现有实际证据的保留、变化、环境开放及自定义事项；已有明确答案不重复询问。建立可回读的任务记录；没有持久记录能力则说明缺口。视觉方向以当前可见事实与用户要求为准。
