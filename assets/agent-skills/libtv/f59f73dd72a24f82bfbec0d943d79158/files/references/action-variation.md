# 通用场景与动作裂变

## 输入与种子锁定
用户决定裂变及变化方向后，读取用户确认的当前 M2 完整正文、版本和本轮要求；可来自真实可读取的节点或已确认正文，不依赖画布文本节点。不得以旧 M1、旧摘要、标题或案例替代。用户指定已认可历史镜头时记录完整来源，并应用当前删改和确认，不让已否定内容回流。记录实际执行者及来源；用户未明确变化方向时询问，已明确则不重复。M4 仅在用户要求时作为资料。

## Seed Lock：动态识别
只按当前 M2 和实际参考素材识别适用的主体身份和数量、主体朝向、运动方向、镜头观察方向、姿态、动作、遮挡、接触/支撑/承托、上下左右前后、相对尺度、景别、透视、构图、环境和视觉特征。三种方向分别记录；不可见或不确定标 UNKNOWN，不存在标 NOT_APPLICABLE，不编造，不固定任何案例。动态记录 MUST_KEEP、ALLOWED_CHANGE、MUST_STRENGTHEN、MUST_NOT_APPEAR 及来源和用户原话；仅变化明确允许的维度，其他默认继承。用户允许自由组合时仍不越过固定项。固定和变化冲突则说明具体冲突并等待用户决定。

## 文本生成
用户原版或已确认指令优先且逐字使用；没有时采用以下模板，填入实际全文及经确认边界，不修改用户逐字原句：
> 基于【已确认完整种子全文】，生成【数量】组独立中文场景，标题依次为单一场景-M1镜头至单一场景-M【数量】镜头。每组依次包含主体与关系、场景、光影、色彩、构图、风格、2—4 项关键细节、负面提示；用户另定细节数量时按其要求。保留【MUST_KEEP】；只变化【ALLOWED_CHANGE】；避免【MUST_NOT_APPEAR】；保留用户指定原句【原句】；不以同上、公共段落或摘要代替正文，不编造不可见事实或产品特性。

展示当前文本生成报价由用户决定运行。数量按用户当次选择；未指定时可建议九组。核实各编号各一次，八项结构逐组独立、固定项未变、变化项获授权、禁止项未出现、主体与空间/动作/接触逻辑无冲突，用户原句一致；只检查可适用的项。任何缺失/冲突、模型错误或来源未验证均保留原始结果并报告、与用户核实，不自动重试、不进入图片生成；全部通过后展示完整结果等待用户确认。

## 图片节点与正文写入
用户确认各组正文后，Agent 优先使用当前真实可用的图片节点创建或配置工具，为每组建立对应节点，将该组完整确认正文直接写入提示词并绑定用户确认的产品图；不得将多组写入同一节点或引用不存在的 M5 文本节点。只为实际素材绑定替换必要占位符，除此和已获准修改外不缩写、扩写或重新创作。独立文本节点仅为用户需要的可选复用方式。留档文件路径不能代替画布输入；用户要看正文时直接展示。

回读节点实际编号、完整正文、产品引用及可读的模型、画幅、分辨率和张数，区分读取不到与已确认。创建或更新未证明实际绑定；若入口不能更新已有引用，保留旧节点并按已确认方案创建正确的新节点。缺能力时说明具体缺口，仅请求最少人工补位；不能因为缺少文本节点工具就放弃自动创建图片节点和写入。保留历史，不得把旧摘要中已删除的底座或未经确认的颜色变化带回；检查同义新增结构但保留用户允许的产品本体效果。

配置节点不等于运行授权。先看提示词、先别跑或先改句子时只处理获准内容，不提交生成；逐张或分批依当次选择，分别记录已提交与未提交。展示当前报价，同一范围、配置和报价已获确认时不重复询问，变化时说明；无授权不提交、不收费重试。默认 Seedream 4.0、4K、每节点 1 张，画幅由用户选择，用户当次配置优先。图片排布保持可读，不自动生成视频。

## 清洁及姿态案例（仅用户要求时）

当用户要求清洁前画面：每组文字明确接触物及其接触区域的污渍，依据材质选用日常可见的灰尘、水垢、水渍、锈迹等；以用户选择的视觉不适程度控制纹理和气氛，参阅 `references/visual-intensity.md`，优先写清希望呈现的污层，不累积无休止的排除词。干净的动作参考图仅借用用户认可的姿态及构图，污渍按当次需求设定。创意画面不作为产品功效实证。用户未要求污渍的任务不套用此条件。

用户要求“非常脏”时，明确污渍大面积覆盖接触处和周围、污层层次及可见纹理，例如积灰颗粒层、干涸油垢或锈迹；结合材质选择，使用侧光凸显层次。以用户选定的强度描述希望看到的质感。逐图检验真实脏污面积、清晰度、所在区域，而非只看画面有无污渍。

对于用户明确要求极脏且后续需要对比的案例，主体物应清晰可辨并有足够大、可见的连续表面。本清洁球案例目标为该表面 100% 覆盖，污层延伸至产品接触点附近；底材结构通过污层纹理和轮廓辨认，首帧呈现擦拭前状态。用与底材有明确明度差异的污层，例如浅色瓷砖上的深灰褐积灰；参数和判定按 `visual-intensity.md` 配置。依据材质及选定档位描述污层质地，视觉创意不作为实际清洁功效的事实。其他任务遵循当次需求。

如果首帧是用户计划的擦拭视频起点，先明确画面中**目标物可见且计划擦拭的表面**：它不是整张画面，也不是背景墙或仅一个污点。依据用户指定的覆盖强度，将该表面划成主体接触区及相邻区域，每一部分在首帧均有连续、自然附着的污层；本案例 100% 是目标，并非已经精确测量的结果。通过底材形状及透过污层的纹理保持可辨，呈现擦拭前状态。

分别在每组的主体、场景、色彩及细节中写清同一个目标物、接触区、污层材质与覆盖、污层和底材的对比；负面提示排除大片洁净区域、局部污斑及脏污颜色融入背景。提示词应逐组独立完整，避免仅在统一附加段落提要求；检查旧文中“洁净、光亮”等与污层目标冲突的描述并按用户目标修正，不靠追加互相矛盾的指令。对于用户指定的清洁球案例，逐字保留其要求的按压句，使用用户认可的握姿与产品引用，不把旧案例的场景与动作强制套用到其他任务。

验收要在生成图片上分别看接触点、表面中央、边缘、各可见面：记录连续污层、洁净区域、色差、物体可辨性以及用户主观评价的不适程度。覆盖不足或色差弱标记不通过并列出位置；模型不一定服从覆盖比例。用户提供的视频可说明视觉设计意图，不能证明产品或锈迹在现实中能被擦除；首帧检查不等于视频效果已验证。

每组明确实际产品数量；若用户要求一个，则整幅画面只出现一个实物。产品多视图只用作同一产品外观参考；姿态参考图中额外的产品也不照搬。优先使用产品已知实物尺寸、手掌或其他可靠尺度锚定比例，逐张检查，不能依赖模糊的“大小一致”。用已认可的姿态图参考握持时，说明只参考动作，并检查姿态图是否引入错误数量或场景。用户后续修改动作或接触关系时，检查每组主体、场景、细节与负面提示并清除被替代的旧约束；不能将悬空与接触同时写入。输出检查中标明数量、产品相对尺寸、握姿、接触区域污渍及用户确认状态；文本合规不代表图像通过。

用户指定手部或人物外观时，把手的外观要求和握持动作分别记录：例如本次用户要求亚洲成年人的手、手臂体毛少、男女均可，同时保留认可的手掌及手指包住产品本体并与表面接触的握姿。姿态参考图只借用姿态，不照搬与用户要求冲突的人物外观。不能只凭手部外观确认族裔；未指定时不为其他任务固定族裔、性别或体毛。



## 人工补位与引用绑定
按当前工具 Schema 绑定真实产品图并回读，不能凭自然语言提及或工作文件路径冒充实际引用。若当前入口不支持变更引用，保留旧节点并创建正确新节点；记录实际能力、已完成步骤和必要的人工补位。创建后及运行前回读当前正文、引用与可读参数。模型和画幅不可读取时如实报告；max 档不等于已核实 4K。执行范围和批次依据本次选择，失败不自动收费重试。
