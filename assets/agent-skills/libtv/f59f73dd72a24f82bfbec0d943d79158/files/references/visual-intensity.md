# 污渍覆盖与视觉不适：测试标尺

这是为创作沟通设计的主观标尺，不是科学量表，不预测所有观众的感受。与其他模板共享评分方法，不共享固定场景、污物种类或必须覆盖 100% 的设定。

分开记录：①覆盖率：污层占指定可见目标表面的比例；②明度差：污层与干净底材的 CIELAB L* 中位数之差；③视觉不适度 0—4。覆盖率高可以是不适度低。目标是可配置的视觉约束，不是假称模型精确控制或已经测量。

## 可调整参数与可执行检查

下列阈值是当前案例的**试用参数**，不是经过校准的行业标准；用户可更改，记录参数版本和来源。其他模板复用参数结构而不自动继承清洁球的数值。

| 参数 | 当前案例值 | 判定与必要输入 |
|---|---|---|
| `coverage_target_pct` | 100 | 指定目标面掩膜 T 为可见、可擦拭的砖面及砖缝，排除手、产品和画外遮挡；污层掩膜 D 必须具有可追溯来源。覆盖率 = 100 × 面积(T∩D) / 面积(T)。实测达到 100% 为 Pass，否则 Fail；无有效掩膜或 T 为空为未验证。100% 是严格目标，测量噪声或分割误差可能造成误判，须保留掩膜供复核。 |
| `region_coverage_pct` | 100 | 将目标面按其外接矩形等分为 3×3 网格，仅对包含 T 的格分别计算上式，各格均须达到 100%；手与球可见接触点邻域在有效图像范围内另作区域检查。无可靠接触点定位或有效掩膜则相应项未验证。 |
| `contrast_min_Lstar` | 20 | 目标是污层中位 L* 至少比无污底材样本的中位 L* 低 20（L* 为 0—100）。需要同材质、同光条件下可追溯的底材与污层样本；差值达到阈值为 Pass，否则 Fail。底材未展示或光照不一致则未验证，不从污层自身臆造底材亮度。阈值 20 是便于试验的初始值，不保证主观观感；用户可调整。 |
| `target_product_count` | 1 | 可见真实产品主体数量为 1 时 Pass，其他数为 Fail；主体识别不可靠时未验证，多视图参考中其他视角不计入输出数量。 |
| `hand_contact` | 本体接触且目标表面接触 | 需可靠的手、产品、目标面与接触证据：两个关系都确认则 Pass，任一明确缺失则 Fail，遮挡或检测能力不足则未验证。复用已认可握姿作参考，无法只凭节点引用证明姿态一致。 |
| `aspect_ratio` | 用户选择 | 节点设置与用户选择一致为 Pass，否则 Fail；未指定则标记待定，以参考比例建议，场景正文不固定 9:16。 |
| `discomfort_grade` | 本案例先参考第 2 档 | 算法无法直接测量主观恶心感；用户对实际图给 0—4 分，目标与实际评分相符为 Pass，否则 Fail。未收到用户评分则未验证，不假装可自动判定。 |

自动化优先于主观判断，但阈值本身不会自动识别污渍、接触点或感受；必须有经过验证的分割、检测或用户提供的参考样本。缺少工具或证据时输出未验证及原因。检查输出同时标注“原描述 → 参数 → 实测 → Pass / Fail / 未验证”，展示证据；最终画面仍由用户选定。

| 档位 | 建议视觉锚点 |
|---|---|
| 0 | 画面整洁或仅有几乎不可察觉的使用痕迹。 |
| 1 | 大面积也可成立：薄层干燥灰尘、水痕或锈迹，视觉易接受。 |
| 2 | 大面积陈旧污层，色差明显，干涸斑驳与细颗粒有较强质感，稍有脏感。 |
| 3 | 附着表面的旧污更厚、更粗糙，少量潮湿光泽或粘附细屑，带轻微不适，但主体可辨、具生活真实感。 |
| 4 | 密集、强烈的湿黏或腐败质感，明显令人不适；仅在用户明确选择时使用。 |

测试时固定产品、场景、目标平面、镜头、动作、污层覆盖及底材色差，仅将污层质感写成 1、2、3 档；每档同数量、相同模型与用户选定规格。每张独立描述所选质感。由于生成波动，面积或手部可能不同：生成后逐一比较目标表面的实际覆盖、明暗色差、产品、动作和场景；任何混杂因素都标明。向用户展示图片，由用户给每张打不适分并选择目标；不要把计划档位当实际评价。将用户选择应用于此项目，其他模板按任务调整尺度与素材。
