# 清洁球案例配置

## Input

用户指定清洁球案例、产品图和参考画面。

## Process

IF 用户确认相关素材 THEN 配置产品数量=1、直径约8.5cm（以规格图为依据）、手接触球体且球接触表面、挂带松弛；女性或男性亚洲成年手臂、体毛少仅为本案例要求。IF 清洁前画面需对比 THEN 目标物可见表面污层覆盖=100%，目标与底材色差阈值试用20 L*，用户可调；不适度测试先参考2档，由用户评价。IF 用户指定逐字细节 THEN 使用“手掌按压清洁球时施加的压力导致球体压缩，手臂肌肉紧张，手腕略显用力”。IF 画幅有指定 THEN 写入节点设置而非场景正文。

## Output

记录本案例参数、素材和来源；L* 阈值未校准，未测量或检测器不可用标记 NEEDS_HUMAN；新商品不自动继承本配置。

历史价格仅供对照，不作为当前报价。展示当前页面报价、数量和预计费用，由用户决定；无法读取标 UNKNOWN。实际费用单独记录。


## 入口限制
仅本案例适用；手动模型/张数、max 与 4K 的区别和报价确认按通用模块执行，不将清洁规则带入其他项目。
