# 执行参数和量化检查

每次任务记录 M1 原文及来源、用户确认的 M2 正文和版本、保留项/变化项/部位/禁止新增项及决定来源、M5 各组编号与确认正文版本、实际图片节点及产品引用、模型、比例、分辨率、数量、回读范围和证据。M5 是裂变阶段，裂变第 5 组是镜头编号。节点 ID 仅在真实存在时记录，不要求中转文本节点；未验证项如实标记。记录已提交与未提交的任务、用户当次授权和批次、人工补位及实际费用。

M3 默认 Seedream 4.6、16:9、2K、1 张；正式首帧默认 Seedream 4.0、9:16、4K、1 张；M6 默认 Seedream 4.0、4K、每节点 1 张、比例用户选择；M1/M5 Qwen 3 VL Flash。用户当次配置优先。实际值须回读，不能凭配置文字判通过。

当前报价单价 × 数量 = 预计总价，展示本批及适用总价；同一范围、配置和报价已经确认不重复询问，实际变化时说明。实际费用另记；报价读不到时请用户查看节点显示。无自动费用门槛，无自动重试。检测方法不可用时不伪造百分比或色差；生成成功与质量验收独立。


## 受限 Agent 记录
除节点与来源外记录实际执行者、人工选择模型证据、画布 4K 与 quality_spec=max 分别状态、当次张数的实际确认依据、可见 prompt 与完整回读范围、审批卡与任务 ID。以当前 Schema 判断能否改 reference_nodes；若不能则新建正确引用节点。记录被变更上游影响的下游结果，标待核。
