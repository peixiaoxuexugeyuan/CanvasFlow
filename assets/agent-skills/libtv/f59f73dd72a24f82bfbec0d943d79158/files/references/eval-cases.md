# 验证案例与记录
测试真实结果，不因 Skill 中写有要求就判通过。记录版本、输入、实际节点及连线、输出、模型设置、积分、结果证据和用户反馈；以旧版结果或实际原始流程作对照。未经授权不产生额外收费。

1. 现有锈蚀场景 + 沐浴球：核对产品多视图和首帧反推可独立推进，保留反推原文；M2 由 Agent 输出完整副本并经用户确认，保留原反推记录；如使用独立文本节点，核对其内容和来源。环境锈层、孔洞、管道、构图没有因删旧产品而消失；首帧新图实际使用确认的优化正文并真实引用第一步的产品多视图。
2. 其他材质或包装产品：用用户提供的实际素材检验规则是否通用；检查外形体积、图案与标签，原图未显示的背面标明未核实；不得套用锈蚀场景。没有素材时标记待测，不编造通过。
3. 受限能力或错误连线：若真实入口无法自动配置图片节点、写入正文或绑定引用，准确报告缺失能力并只要求最少的人工补位；未通过多视图时停止依赖操作。不把工作文件当作画布节点、不重复生图。核实积分记录和用户确认点。
4. 清洁前首帧、后续拟展示擦拭：在实际生成图上检查目标物各可见表面、接触点与周边的污层是否连续、覆盖是否达到用户目标、污色是否明显区别于底材，检查是否有大片提前擦净的区域、脱落团块或异常晶体。结合用户提供的视频理解前后对比意图；污层面积仅凭文字不能判通过。记录具体未达标位置并由用户确认视觉效果，视频不能作为现实功效证据。

对照记录旧版和新版、成功与失败证据、文本细节、商品准确性、画布执行、用户评价、时间、积分与重试次数。某一案例通过不代表所有商品均稳定。

5. 首帧确认：检查实际生成 1 张并向用户展示；记录明确问题和真实回答，可选“可以／不可以／提出修改”及自由答复。无回复、拒绝或修改尚未再确认时不得进入裂变；已有确认不重复问。
6. 裂变文本：以用户确认的 M2 当前全文及本轮变化要求为来源，按用户指定数量生成完整、独立的正文并展示确认；检查缺组、重复、摘要替代正文和已否定内容回流。用户要求看正文时直接展示。生成涉及费用时按当前报价和授权执行，未经明确许可不收费重试。
7. 图片节点与批次：用户确认正文后，以真实可用工具逐组创建或配置图片节点，逐一写入该组完整正文并绑定确认的产品图；回读镜头编号、正文、引用与可读取参数。无 M5 文本节点也能使用确认正文，不把留档文件当画布输入。节点配置不等于运行；按用户当次的逐张或批次选择以及授权范围提交，记录已提交与未提交的任务。


8. 模型不可调用：模拟工具清单没有 Seedream 4.6 或其实时对应标识，即使有 Seedream 5.0 Pro，也不得自行替换或运行；按真实能力创建待手动设置的节点，提示用户设置，并允许无依赖工作继续；记录工具限制。
9. 模型可调用：选择平台真实的 Seedream 4.6（需要标识时使用实时查询结果） 并回读实际模型、16:9、2K、1 张和选中的产品图引用，任一不符或不可核实即停止；仅配置通过且报价与授权通过才提交。实际未生成不得报告生成成功。


## 回归测试 T01—T24（不触发收费生成）
每项记录输入、实际入口、节点、证据及 PASS / FAIL / NOT_RUN；文件规则存在不等于真实节点操作通过。
- T01 M1 原文完整保留，节点和来源准确。
- T02 M2 副本完整优化并用户确认；若使用画布文本节点，核实其内容、来源和可回读范围，不强制建立中转节点。
- T03 先看提示词或先别跑时，只处理获准内容，不提交生成。
- T04 M3 规格正确，模型和 count 由用户手动确认，参数真实回读。
- T05 M4 无资料或无请求时跳过。
- T06 M5 正文实际来源为已确认 M2，不回退 M1。
- T07 种子视觉骨架未被擅自改变。
- T08 非汽车场景不注入汽车规则。
- T09 用户允许随机变化时维度开放且固定项保持。
- T10 固定项与变化项冲突能识别并等待确认。
- T11 裂变组数与用户当次要求一致，各组结构与语义独立完整，区分阶段 M5 与裂变第 5 组。
- T12 长正文完整读取和展示；截断时分段核验实际正文，不把工作文件路径当模型可读取的画布输入。
- T13 回读每个图片节点，核对对应编号、完整确认正文、产品引用和可读参数；连线本身不证明正确写入。
- T14 没有中转文本节点仍可直接写入每组确认正文；自动能力缺失时只要求必要的最少人工补位，明确限制。
- T15 Seedream 4.0 手动设置并回读可见证据。
- T16 max 和真实画布 4K 分别记录，不推断二者等同。
- T17 按当次选择核对每节点生成张数；不可回读时记录未核实，并以中文向用户说明。
- T18 Agent 不支持更新引用时保留旧节点并新建正确引用节点。
- T19 更新后及运行前回读当前生效正文和引用，确认已删除描述及其同义新增结构未回流；冲突则停止。
- T20 报价真实、单张/本批/总价分开，由用户决定。
- T21 审批卡与调用节奏按当前入口实际契约核实，未具备证据 NOT_RUN。
- T22 清洁案例隔离，不污染其他商品。
- T23 失败保留现场与费用状态，不自动收费重试。
- T24 上游节点变化后标记下游可能失效并由用户决定。


## 外观选择与直接写入回归 A—I
以下为待执行的行为案例，不以写入本文件或关键词匹配作为通过证据。每项分别记录文件规则检查、真实节点写入和真实生成效果的结果、证据及未测试项。

- A 完全保真：用户选择保持产品外观时，不擅自改变颜色、材质、结构或标签；M3 多视图仍以原商品为依据。
- B 局部风格化：用户保留瓶型、颜色和文字，允许产品本体的钻石切面、材质观感及光泽变化；目标画面执行允许的变化，M3 基准多视图不因此风格化。
- C 属性与实体：钻石感附着于产品本体，不扩展为独立宝石或底座；不把钻石切面与光泽全面禁止，也不将生成效果宣称为原产品真实工艺。
- D 删除传播：用户否定底座或未经确认的颜色减淡后，检查当前 M2、M5 正文、图片节点提示词与待提交输入、旧摘要和模板引用；同义新增结构不得回流，但允许的切面与光泽仍保留。历史 M1 和旧结果保留为历史，不再作为当前生成输入。
- E 自动写入：用户确认后，Agent 逐组配置对应图片节点、完整写入该组正文并绑定已确认产品图，回读编号、正文、引用与可读参数；不要求用户到外部文件复制粘贴。
- F 无中转节点：没有 M5 画布文本节点仍能从真实确认正文构建对应图片输入，不引用不存在的节点或工作文件路径。
- G 忠实传递：节点正文与确认版本一致；仅允许实际素材引用绑定及用户已获准的修改，不擅自缩写、扩写或创作。
- H 暂停与授权：用户说先看提示词或先别跑时不提交；逐张测试只提交当次获准镜头，其他批次按当次选择；已提交和未提交状态分别记录。
- I 中文交互：用户看到中文节点名称、参数、报价状态与执行状态；技术标识留档，不以 UNKNOWN 或节点 ID 代替普通说明。
