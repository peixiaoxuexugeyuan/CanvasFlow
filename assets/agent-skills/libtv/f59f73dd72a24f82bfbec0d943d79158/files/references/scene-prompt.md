# 场景反推与甄别

## 反推指令
用户提供或已确认的完整指令优先，逐字输入并回读；以下仅在用户未提供时使用：根据参考图片反推完整中文场景提示词，准确描述主体及其关系、场景、镜头与构图、光影和色彩、风格、关键细节及必要负面提示。只描述可见内容，保留位置、动作和遮挡，不猜隐藏结构、用途、前后动作或效果；原始结果完整保存，不预设用户删改对象。

## 复制并优化
M1 原文保留，不覆盖。Agent 以完整原文建立 M2 可编辑副本，只按用户指示逐句修改：删除用户要求替换的旧商品专属属性及用户否定的文案或关系；其余有画面依据的内容尽量保留，不误禁新产品标识、标签和附件。展示完整副本与修改摘要供用户确认，记录来源和确认版本。可以使用可回读的画布文本节点或其他实际可用的编辑方式；确需人工补位时说明缺失能力并提供当前交互中的完整正文，不把工作文件路径当作画布输入。不能回读全文时标明未验证。

## 产品外观选择
进入 M2 时，根据本次任务确认产品哪些外观保持、哪些允许变化；用户已经说清楚则整理执行，不重复提问。可以简短询问完全保持、保留指定身份特征并局部变化、或更大范围风格化，并允许自由描述；只追问实质影响结果的歧义。记录每项决定的来源、保留和允许变化的特征、作用对象及部位、禁止新增的物体或结构、尚未确认的内容。未确认既不是自由发挥，也不是默认全部锁死。产品图约束用户选择保留的特征，不用“所有外观完全一致”抵消明确允许的变化。

不为补全提示词擅自扩写颜色、材质、透明度、结构、附件或标签。用户要求保持颜色、文字或标签时，以确认的产品图为依据，不自行改色、改写或移动文字；新增物体与结构须有用户要求或确认依据。目标画面的风格化效果不得描述成已证实的产品真实材质或制造工艺。

区分产品本体的视觉属性和画面中新实体。例如本轮保留瓶型、颜色及文字，允许用户指定的产品表面呈现钻石般切面反射和璀璨光泽，不新增独立宝石或承托底座；不因此禁止用户允许的钻石感。这是本轮案例，不是通用商品默认值。M3 的原商品基准多视图仍依据原产品，不自动继承目标镜头的风格变化。

用户删除或否定的内容须从当前 M2 生效版本、后续 M5 正文、对应图片节点提示词及待提交输入中检查并清除同义表达；检查旧摘要和默认模板，防止再次引入。只排除被否定的内容，保留用户明确允许的效果。保留 M1 原文和旧结果作为历史，不再作为当前生成输入；无法核实来源时如实说明，不猜测责任。
