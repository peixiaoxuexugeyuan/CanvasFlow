# 清洁场景已有检查（条件模块）

IF 用户选择清洁类场景 THEN M5 为每组动态参数记录污渍类型（1—3种）、覆盖目标（未指定时55%—80%，用户已有目标优先）、中央及至少两个边缘区域、材质对应的污渍状态、干净留白上限30%；同一对象材质的适用性以用户信息为准。候选条件包含中央和边缘、避免仅角落轻污的约束；清洁球案例按用户要求保留指定原句。IF 用户限定污渍状态或不适度 THEN 优先使用用户要求，不机械加入结块、渗出。清洁场景只是可选案例，不把这些字段加入通用参数固定结构。

M7 IF 目标面与污层可靠分割 THEN 面积=100×area(T∩D)/area(T)，面积≥55%为基础检查PASS，实际覆盖目标及干净留白≤30%另行判断；用户指定100%时100%为独立目标，不降至默认区间。将目标面划为3×3格，检查中央及四个上下左右边缘中至少两个；无有效可见边缘或阈值不能验证时NEEDS_HUMAN。视觉冲击需污层状态与整体观感两个证据，主观观感不能冒充客观测量。IF 污渍面积不足 THEN 生成建议覆盖+10个百分点上限85%，已指定目标≥85%时不降低原目标；保持构图、手部和产品位置。IF 分布不足 THEN 生成建议突出从边缘延伸到中央和接触区；IF 冲击不足 THEN 根据用户允许的状态和与底材的色差加强。每个 FAIL 写参数调整历史，验收目标保持；失败后展示当前报价并等待用户决定是否重新生成，不自动重试。检测证据不足或仍不通过则NEEDS_HUMAN。
