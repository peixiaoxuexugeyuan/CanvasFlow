## 多视图操作

M3 是原商品基准：以用户确认的产品原图为依据，不自动继承 M2 或目标镜头的风格化变化。目标画面再按用户选择的保留项和允许变化项处理；不要用基准多视图的保真要求抵消用户对目标画面的明确变化要求。若用户明确要求更改多视图本身，则以该次要求为准。

使用 LibTV 现成图片节点，连接用户选定的产品原图；已有且用户要求复用的节点直接使用，否则新建。选择平台中的 Seedream 4.6，16:9、2K、1 张，填入以下提示词；核对节点的模型、设置、引用，展示当前报价并由用户决定生成或调整后重新报价；报价不可读取时用中文说明“报价暂时读不到，请查看节点显示”。无法使用指定模型时停止说明，不自行切换其他模型。生成后展示结果并等待用户确认。

下列原有内容保留为补充验收标准；如与用户当次明确要求冲突，以用户最新要求为准。

严格按照产品，生成一张专业级产品三视图展示图，用于商品详情页或产品展示。画面整体为纯白背景，风格简洁、干净、高级，采用专业产品摄影灯光，光线均匀柔和，产品边缘清晰，质感真实，细节突出，无杂乱元素、无道具、无阴影干扰。

版式要求：左侧区域横向依次排列产品的正面图、侧面图、背面图，三张图大小统一、间距整齐、对齐规范。右侧约四分之一画面区域放置一张产品正面局部细节特写图，突出产品的关键材质、工艺、结构或功能细节。整体构图像专业电商产品图 / 工业设计展示图，信息表达清晰，视觉规范。

优先级：产品与原图的一致性高于排版。三个角度是同一个真实三维物体的旋转，不是改变厚度后的三个造型；侧视图要呈现原产品合理的前后纵深，保持体积，不能因“侧面图”压缩成薄片。以原图可见的花纹形态、分布和附属件相对尺寸为准，勿重新设计。未提供的侧面和背面细节仅作合理示意，不作为已核实事实。

画面要求：产品主体完整、比例准确、透视自然。三视图保持统一角度逻辑与一致的灯光表现。细节特写需更清晰，体现材质纹理、做工和品质感。纯白背景，画面干净，适合直接用于详情页、宣传页或产品手册。

产品一致性与审核要求（优先于通用排版要求）：以产品原图为唯一的可见外观依据。保持原图可见的整体轮廓、立体体积、厚度与长宽深比例，保留颜色、纹理、图案的形状、方向、相对位置、分布和比例；各视图必须表现同一产品，不得压扁、拉长、改变结构或随意重新设计。完整保留产品原图中的可见部件及附属物，保持它们的位置、方向、长度、宽度、形状与主体的相对比例。可识别的标签、图形和文字尽量忠实保持；看不清的文字和未展示的角度不得编造成确定事实。白底、正面侧面背面加局部特写的版式不能牺牲产品准确性。

验收：逐项对照原图，记录形状体积、图案、颜色、附属件、标识文字：一致／不一致／原图不可判断。缺少侧背参考时标待确认；明显失真不得进入首帧，展示结果并等待用户决定，不自动付费重试。用户满意的沐浴球多视图测试 v2 可在得到确认后复用；不保证其他产品同样效果。

无法自动设置指定模型时，说明具体节点及模型，用户手动设置后回读模型、参数和产品引用；不擅自换模型。用户已确认的多视图可核实身份后复用。
