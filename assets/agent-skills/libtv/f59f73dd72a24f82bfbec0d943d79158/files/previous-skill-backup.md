# 参考视频首帧商品替换

目标：根据参考首帧和新产品图片生成替换产品后的首帧，交用户确认；不制作视频。只修改这一原有 Skill，不新建同名技能。

输入：明确画布上用户指定的参考首帧和新产品原图。先识别选中节点和已有结果，避免混淆相似图片。已有正确的反推结果、可编辑副本或经用户选定的产品多视图则复用，不重复付费生成。缺少产品背面时不可把推测细节当成事实。

画布操作：从相应素材节点的加号拖出连接线，新建对应的文本或图片节点；在节点中填写指定提示词，选择指定模型、比例、分辨率和数量，核对连接、引用缩略图、模型及闪电积分，再提交。创建节点或打开菜单不等于生成完成；须观察生成结果。Agent 自身不提供某模型不等于画布节点无法选择该模型，应先检查对应画布节点模型菜单。确实无法操作或不可用时停止并说明，不自行换模型。

1. 首帧反推：使用参考图连接文本节点，选 Qwen 3 VL Flash；如已有用户认可的结果则复用。提示词：根据图片反推图片场景中文提示词，不描述任何产品颜色、材质、规格以及产品名称，统一称作“产品”。精准描述主体、场景、光影、环境色彩、构图、风格、2-4个细节维度以及负面提示。仅描述可见内容，手与产品的动作不得猜测接触部位，不描述产品附属结构。输出前检查所有段落是否残留旧产品特征。不设独立清理模型节点。

2. 保留文本：生成结果完整复制至新建文本节点“自己编写内容”，不覆盖原结果；若用户修改，则使用用户修改的副本。

3. 产品多视图：产品原图连接图片生成节点。默认 Seedream 4.6，16:9、2K、1张、组图模式开启、智能引用开启；用户指定其他模型或设置时按其指定；不擅自换模型。用户原版提示词：严格按照产品，生成一张专业级产品三视图展示图，用于商品详情页或产品展示。画面整体为纯白背景，风格简洁、干净、高级，采用专业产品摄影灯光，光线均匀柔和，产品边缘清晰，质感真实，细节突出，无杂乱元素、无道具、无阴影干扰。 版式要求：左侧区域横向依次排列产品的正面图、侧面图、背面图，三张图大小统一、间距整齐、对齐规范。右侧约四分之一画面区域放置一张产品正面局部细节特写图，突出产品的关键材质、工艺、结构或功能细节。整体构图像专业电商产品图 / 工业设计展示图，信息表达清晰，视觉规范。 画面要求：产品主体完整、比例准确、透视自然。三视图保持统一角度逻辑与一致的灯光表现。细节特写需更清晰，体现材质纹理、做工和品质感。纯白背景，画面干净，适合直接用于详情页、宣传页或产品手册。 产品图片是外观依据；生成结果需核对附属结构和标签，不能保证小字准确。用户选择或确认已有多视图后复用。近期用户授权一次 General image Pro 16:9、2K、1张，约14积分，仅限这次测试，不作为未来自动授权。

4. 生成首帧：将可编辑文本副本和用户选定的产品多视图连接到同一图片节点，确认引用无误；选 Seedream 4.0，9:16，4K，默认1张，按用户当次要求调整。提示词：“根据提示词生图片，产品 {{Image 1}} 严格按照图片生成。”将 Image 1 绑定到产品多视图。保持参考场景及自然动作。

5. 展示新首帧给用户确认；满意则结束，不满意则用户自行修改提示词后按指示继续。不要自动重试、自动换模型或生成视频。

费用：确认每步页面显示的价格和数量，记录实际消耗。尊重用户明确授权的范围，已批准的特定生成无需重复询问；超出预算或新收费动作须先取得批准。只在确认结果成功后报告完成，出错先定位，至多一次有依据的修复尝试。

## 产品多视图一致性与审核（适用任何商品，优先于通用排版要求）

生成提示词补充：以用户产品原图为唯一的可见外观依据。保持原图可见的整体轮廓、立体体积、厚度与长宽深比例，保留颜色、纹理、图案的形状、方向、相对位置、分布和比例；各视图必须表现同一产品，不得压扁、拉长、改变结构或随意重新设计。完整保留产品原图中的可见部件及附属物，保持它们的位置、方向、长度、宽度、形状与主体的相对比例。可识别的标签、图形和文字尽量忠实保持；看不清的文字和未展示的角度不得编造成确定事实。白底、正面侧面背面加局部特写的版式不能牺牲产品准确性。 出图后必须对照产品原图逐项检查：整体形状与三维比例、厚度和结构；图案形状与布局；附属件数量、位置及相对尺寸；颜色、文字和标识。每项标记一致、有偏差或原图不可判断；原图不可见的角度标为待确认。若形状、花纹或附属结构存在明显偏差，不得称为通过，也不得自动用其制作首帧；展示问题并等待用户决定。文字精度不确定时如实说明。

## 场景文字甄别

复制原反推结果至可编辑文本节点后，结合参考首帧检查全部段落，移除旧产品名称、形状、颜色、材质及附属部件，不凭空猜测握持位置；负面提示不得误禁新产品标识或标签。保存优化文本，原文保留。无法创建画布文本节点时明确报告，不要把保存为文件称为画布文本节点。

执行产品多视图生成与验收前，读取 references/product-check.md。若文件不能读取，停止并如实说明；不要假装已经读取。文件读取验证时仅回报文件中的核验标记及两条验收标准，不生成图片。

## 已确认的产品多视图方案（优先执行）

模型 Seedream 4.6；16:9；2K；1张；组图模式开启；智能引用开启；引用用户的产品原图。2026-11-02 测试实扣4积分，用户确认结果非常满意；价格可能变化，每次以页面为准。该结论只针对本次测试，不保证任何商品均相同。

执行时使用第3步保存的用户原版提示词，并将以下原文插入“整体构图像专业电商产品图 / 工业设计展示图，信息表达清晰，视觉规范。”之后、“画面要求”之前： 优先级：产品与原图的一致性高于排版。三个角度是同一个真实三维物体的旋转，不是改变厚度后的三个造型；侧视图要呈现原产品合理的前后纵深，保持体积，不能因“侧面图”压缩成薄片。以原图可见的花纹形态、分布和附属件相对尺寸为准，勿重新设计。未提供的侧面和背面细节仅作合理示意，不作为已核实事实。

## 首帧连接与验收（画布操作验证）

将用户确认的产品多视图接入新的图片节点；新建文本节点并选择“自己编写内容”，保留场景反推原文，复制后对照参考首帧清理旧产品特征及错误动作，再把优化文本节点右侧加号拖至图片节点输入。检查图片节点中同时显示文本和产品图两个引用，产品图须为用户确认的最新版本。生成指令：根据连接的场景提示词生成图片，产品严格按照引用的产品多视图生成。首帧默认 Seedream 4.0、9:16、4K、1张，费用以当时页面为准；生成后对照参考画面的主体位置、场景、动作、光影、构图，并对照产品原图检查外观，由用户确认。画布可手动创建文本节点并连线已验证；LibTV Agent 能否自动执行同样操作仍未验证。

## 场景反推文本的保真优化规则（优先执行）

先将反推全文逐字复制到可编辑文本节点，原节点留作备份；再对副本逐句处理，不得以简短摘要代替原文。只删除或改写旧产品的名称、形状、颜色、材质、规格、图案及附属结构；与产品无关且参考图支持的场景、镜头、光影、构图、物体、材质与细节应尽量原样保留。逐条核查原文细节，删除涉及旧产品的条目时，可以补充参考图可见且有用的场景细节，保持2—4条，不能凭空编造；不确定的部位或动作使用中性描述或标注待核，不把推测当事实。负面提示不得误禁新产品标签、品牌、图案及附件。完成后确认文本节点仍与首帧生成节点连接，列出保留、删除和改写的关键内容供核对。
