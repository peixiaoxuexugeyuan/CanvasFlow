# 去噪点干净成图

把一张画面较脏、碎细节杂乱的原图，通过「提取结构线稿 + 提取空间深度」两条支线，再合成回一张干净、无噪点、结构清晰的成图。

## 适用场景

- 原图噪点多、碎细节糊成一片，需要一张干净的成图。
- 需要保留原图构图与空间关系，但去掉脏噪纹理与无意义细节。
- 典型产出：概念场景图、插画底图的净化重绘。

## 链路总览

```
原图（内容来源）
  ├─→ 黑白线稿图（提取构图 / 轮廓 / 结构 / 透视）
  ├─→ 深度图（提取近中远空间层级）
  └────────────┐
               ▼
        合成干净成图（以原图为内容基准，用线稿约束结构、用深度图约束空间）
```

三个生成节点都以**原图**为唯一内容来源；合成节点同时接收原图、线稿图、深度图三路输入。

## 步骤

### 步骤 1：准备原图

- 节点类型：图片
- 作用：作为整条链路唯一的内容来源，构图、主体、空间关系都以它为准。
- 输入：用户提供的原始图片。

### 步骤 2：生成黑白线稿图

- 节点类型：图片（生成）
- 上游输入：原图
- 提示词（以画布节点记录为准）：

> 以 {{原图}} 为唯一内容来源，生成纯黑白线稿，仅提取构图、轮廓、结构与透视：{{主体与场景结构描述}}。只保留干净连续的轮廓线与结构分界线，不添加任何灰度渐变、材质、明暗、纹理填充或碎细节，白底黑线，无阴影。

- 槽位说明：
  - `{{主体与场景结构描述}}`：把画面里的关键形体逐一列出，例如"画面正中偏上一名悬浮的长袍人物剪影、左上方斜贯画面的飘带、远方右侧破败城堡群轮廓、两侧雪山山脊、前景战场废墟与多面竖立战旗的形体边界、地平线位置"。
- 锚点（固定工艺，不要改）：纯黑白、白底黑线、只留轮廓与结构分界线、不加灰度/材质/明暗/纹理/碎细节、无阴影。

### 步骤 3：生成深度图

- 节点类型：图片（生成）
- 上游输入：原图
- 提示词（以画布节点记录为准）：

> 以 {{原图}} 为唯一内容来源，生成灰度深度图，建立准确的近中远空间层级（默认近亮远暗）：{{前景最亮 / 中景中灰 / 远景偏暗 / 天空最暗}}。深度沿地面由近及远连续渐变、无跳变、无孤立斑块，不表现材质与颜色，只表现空间距离。

- 槽位说明：
  - `{{前景…/中景…/远景…/天空…}}`：按画面实际内容填写各层级对应的元素，例如"前景战场废墟与战旗最亮（最近），中景悬浮人物与近处旗帜为中灰，远景破败城堡与雪山偏暗，天空与最远云层最暗"。
- 锚点（固定工艺，不要改）：灰度图、近亮远暗、沿地面连续渐变、无跳变、无孤立斑块、不表现材质与颜色。

### 步骤 4：合成干净成图

- 节点类型：图片（生成）
- 上游输入：原图 + 黑白线稿图 + 深度图（三路都要连）
- 作用：以原图为内容基准，用线稿约束结构轮廓，用深度图约束空间层级，重绘出一张干净、无噪点的成图。
- 提示词（画布上此节点未记录提示词，以下为按链路意图的通用写法，请按实际需要调整）：

> 以 {{原图}} 为内容基准，参照 {{黑白线稿图}} 的结构与轮廓、{{深度图}} 的空间层级，重绘一张干净无噪点的成图：保留原图的构图、主体与近中远空间关系，去除所有脏噪纹理、杂点、碎细节与无意义笔触；轮廓清晰连续、边缘干净，画面整体整洁统一，不出现噪点、斑块与浑浊过渡。

- 锚点（固定工艺，不要改）：以原图为内容基准、用线稿约束结构、用深度图约束空间、输出干净无噪点成图。

## 槽位与锚点

类别内容槽位原图本身；各步骤中描述画面具体内容的文字（主体、场景元素、各深度层级对应的元素）锚点线稿的"纯黑白 / 白底黑线 / 只留轮廓结构 / 无灰度材质明暗纹理"；深度图的"灰度 / 近亮远暗 / 连续渐变无跳变"；合成步的"以原图为基准 + 线稿约束结构 + 深度约束空间 + 去噪点"

## 使用要点

- 三个生成节点都必须以原图为唯一内容来源，避免线稿或深度图自行发挥改变画面内容。
- 合成节点必须同时接入原图、线稿图、深度图三路，缺任何一路都会导致结构或空间约束丢失。
- 换一张原图时，只需替换原图，并同步更新线稿与深度图提示词里的画面内容描述。
