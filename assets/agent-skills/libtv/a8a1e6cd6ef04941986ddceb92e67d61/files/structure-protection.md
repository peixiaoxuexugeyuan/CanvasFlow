# 结构保护分级

这是编辑优先级，不是模型参数。等级S最优先。清理等级C伪影若会破坏等级S/A，保留该细节并说明不确定性。用户明确要求改变某项结构时，单列为“本次授权例外”，不要默默降级其他项目。

| 等级 | 保护对象 | 允许操作与边界 |
| --- | --- | --- |
| S：严格锁定 | 构图、画幅、镜头透视、主体轮廓、姿势、身体比例、人物身份、骨骼、五官位置、服装版型与接缝、配饰数量位置、文字图案、主体背景空间关系 | 不移动、增删、重塑；“修脸”“清理褶皱”不能成为改骨骼或改服装设计的理由 |
| A：高度保留 | 原画风、主光方向、明暗分区、色彩关系、空间层次、真实纹理和合理反光 | 只可在原逻辑内局部微调；不全局调色、换光、加景深或改成游戏截图 |
| B：限定优化 | 已指定皮肤/布料/金属等材质、局部反射、阴影过渡、伪影造成的边缘质量 | 改表面表现不改几何；边缘清理不得移动真实轮廓，布料修复不得重排结构褶皱 |
| C：有证据才清理 | 孤立噪点、重复伪纹理、锐化光晕、异常颗粒、无材质依据的碎细节 | 只清理确认错误；雀斑、痣、皱纹、织纹、拉丝、雕刻、颗粒胶片风格不能一概视为噪点 |

## 人物身份与骨骼锚点

以实际原图为准记录：头部朝向与比例、颧骨/颧弓、下颌角与下巴、面中部比例、眼距、眼裂走向和眼睑形态、鼻梁与鼻翼、唇形与人中、耳位、发际线、自然不对称、可辨识痣/疤痕。保持表情、视线、年龄呈现和肤色关系。

用户指定东亚人物时，明确禁止“提质”自动带来的加深眼窝、增高鼻梁、放大眼睛、削窄下颌、改变颧骨、套用统一网红脸或西化五官。东亚人之间存在广泛个体差异：不得新增所谓标准东亚特征，也不根据图像断言民族、国籍或现实身份。

## 真纹理与伪影判别

看纹理是否随表面方向、透视尺度、焦平面和光照变化；是否在平面无规律爆发；是否出现重复碎符号、双边缘或不连续反射。单凭“细”“乱”“高频”不能判定错误。原图模糊时保留模糊程度，不用均匀锐化造出超出分辨率的细节。

## 区域边界

按自然材质边界定义区域，避开眼睑/唇线/发际线/服装接缝等结构锚点。半透明材质、头发与背景交界需连同邻近区域检查。使用选区时过渡应自然，具体工具支持未知则只给位置描述，不假称已画蒙版。
