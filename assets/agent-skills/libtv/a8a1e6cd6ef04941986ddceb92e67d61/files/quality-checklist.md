# 验收与迭代

## 验收状态

没有修复图：仅提供清单，状态为“未验收”。没有原图：无法验证保真度。收到两者后，以原图为基准，在一致显示尺度检查全图，再检查面部、边界和材质局部；常用100%查看，放大图不作为新增细节的依据。

每项记录“通过 / 失败 / 不确定 / 不适用”，附区域与可见证据。不要在没有对比图、测量工具或身份真值时编造相似度百分比、SSIM、身份识别分数或宣称100%保真。

## 必查项目

1. 等级S：画幅、构图、透视、轮廓、主体位置、肢体姿势、五官位置、骨骼比例、表情视线、服装/配饰/文字图案是否保持？
2. 人物个体：是否出现脸型模板化、年龄改变、眼窝加深、鼻梁增高、眼睛放大、下颌削窄、痣/疤消失、原有不对称消失？人物不适用时跳过。
3. 等级A：是否保留画风、主光方向、色彩关系、空间层次及合理高频细节？
4. 清理效果：目标噪点/伪纹理是否减少？是否误删毛孔、细纹、发丝、织纹、刻纹或艺术颗粒？
5. 材质：皮肤是否自然而非蜡像或塑料？反射、粗糙度与纹理尺度是否符合原材质？是否引入均匀假毛孔、油亮、强AO或锐化光晕？
6. 局部融合：边缘是否出现接缝、色差、双影、轮廓移动或背景错位？未编辑区是否发生变化？
7. 双语提示词：允许项、禁止项与区域是否语义一致？是否仍含未填槽位或虚构参数？

## 判定

- 等级S任一项失败：该结果不可作为最终版本，即使更“漂亮”。身份或结构不确定时暂不通过，索取可比较原图/局部图。
- 等级A漂移或误删有效纹理：回退相关区域；不得用“降噪成功”抵消。
- S/A通过且目标缺陷减少、没有明显新增伪影：该区域可通过。模式C还须确认没有未经授权的风格转变。
- 若原图缺陷并无确定证据，保留原图也可以是合格决策。

## 迭代纪律

列明保留的已合格改进、唯一待修偏差、缩小后的区域和禁止项，然后生成语义一致的中英纠偏提示。身份/骨骼漂移时回到原图重新编辑，不继续“修补”变脸结果。连续两轮同区域无改善则停止并报告限制；建议人工局部合成时说明需用户实际使用支持该功能的工具，不假称已经执行。用户明确要求继续时重新约定区域与目标。
