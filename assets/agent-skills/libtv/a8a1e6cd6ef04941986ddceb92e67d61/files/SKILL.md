# Image-2 高保真图像修复

保留原图的身份、结构和审美，只作最小必要修复。默认输出诊断、方案和提示词，不直接生成或编辑图片；用户明确要求编辑时才使用环境实际提供的图像工具。不得把其他图像工具的结果声称为 Nano Banana 的结果。

## 输入与边界

- 先查看用户提供的原图。缺图时请求上传；仅能提供标明“待实图验证”的通用模板，不虚构观察结论。若只有文字描述，将其与视觉证据分开。
- 多图时标明原图、身份/材质参考图、候选修复图的角色；身份和结构以原图为准，除非用户明确另选基准。
- 使用可观察的图像特征，不凭外貌推断民族或现实身份。“东亚人物”在用户如此描述时采用，保护该人物实际骨骼、五官和个体差异，不套用族群脸型模板。
- 分辨率不足或压缩严重时标为不确定；不补造毛孔、发丝、文字或纹样来假装恢复真实信息。

## 模式选择

保护等级与修复模式是两个不同维度，使用“等级S”“模式A”等完整称呼避免混淆。

模式使用条件编辑边界A：低破坏性去噪异常噪点、锐化光晕、无意义高频细节只清理已确认伪影；保留正常纹理与原画风B：人物真实材质修复用户要求或诊断显示蜡像、塑料皮肤等材质缺陷仅修复相关皮肤/头发/服装材质，锁定身份与骨骼；不自动换脸、美颜或改年龄C：受控 UE5/PBR 提质用户明确要求材质提质只优化指定材质的反射、粗糙度与局部光影过渡；UE5只是可选视觉目标，不代表实际使用引擎

未指定时推荐满足需求的最低干预模式，说明理由；不默认升级至模式C。混合需求按区域选模式，不整图套风格。用户未授权时不新增全局灯光、景深、镜头或色调。

## 工作流

1. **诊断**：说明原图优点；按区域记录可见问题、证据、严重度、置信度。区分正常纹理、明确伪影和不确定细节。无需修复的区域明确保留。
2. **锁定**：读取 结构保护，列出等级S/A/B/C清单。结构保护高于去噪和材质提质；不可兼得时降低修改范围。
3. **分区修复**：用“区域｜问题及证据｜保护等级｜模式｜允许修改｜禁止修改｜验收标准”形成操作清单。模式B/C读取 材质修复。以单个问题、局部区域为一次编辑单位；蒙版、选区或裁切仅在目标工具实际支持时使用。裁切需保留邻近结构上下文，避免改变透视。
4. **提示词**：读取 双语提示词，将实际观察填入模板，输出语义等价、可独立复制的中文和英文版本。每版都包含原图基准、锁定项、局部修改、禁止项、停止边界；移除未适用的模板选项。
5. **验收与迭代**：读取 质量验收。有候选图才报告通过/失败；仅有原图时输出待执行的验收清单。失败则生成一轮局部纠偏双语提示词；保留原图和上一版合格结果，避免在漂移图上连续全局重绘。同一区域连续两轮无改善或身份漂移时停止，缩小范围/回退并说明限制。

## 输出

依次给出：视觉诊断；结构保护清单；推荐模式与区域方案；Nano Banana中文提示词；语义等价英文提示词；验收结论或待验收清单；必要时下一轮局部纠偏。
