# 材质修复标准

模式A不主动重建材质；模式B针对人物真实表面；模式C需用户明确选择，且不自动启用UE5视觉目标。PBR在此指视觉上合理的材质响应，并不产生真实材质贴图、测量值或引擎资产。

## 皮肤与人物（模式B）

- 降低蜡像般均匀高光、厚重油亮和无层次的平滑渐变；保留原光向、肤色、局部明暗体积和自然色差。
- 保留可见毛孔、细纹、痣、雀斑和细小绒毛，尊重原图分辨率与景深。不要铺满统一毛孔噪声或虚构皮肤病变；无法辨识的细节不“恢复”为确定事实。
- 皮肤可有柔和透光与不均一反射，但不要强加红光边缘、夸张次表面散射或湿润塑料高光。
- 只修表面，不改变颧骨、下颌、鼻形、眼睑、五官比例、年龄、表情与身份。禁止全局磨皮、提亮美白、脸部对称化和商业美颜模板。
- 眼睛保持虹膜、瞳孔位置和视线，不放大眼球、不新增高光；唇部保留自然唇纹及边界。头发保留发型、发际线、发束流向与体积，只清理明显重复丝线和断裂伪影，不改发量。

## 布料、金属及其他表面（模式B/C）

| 材质 | 合理优化 | 禁止误修 |
| --- | --- | --- |
| 布料 | 按原布种保持织纹尺度、受力褶皱与哑光/丝绸反光差异 | 不将棉布变皮革、磨掉刺绣、改接缝或增加无因褶皱 |
| 金属 | 保持金属种类与原有粗糙度差异，反射随曲面连续 | 不把所有金属变镜面铬，不改高光对应的几何轮廓 |
| 皮革 | 保留有尺度变化的细纹和局部反射 | 不均匀压花、不变湿塑料、不新增裂痕 |
| 玻璃 | 保留原厚度、边缘、背景位置及既有透射关系，清理明确伪反射 | 不凭空重建不可见场景，不移动透视背景 |
| 木石等 | 保留纹理方向、块面、尺度和已有磨损 | 不随机添加裂纹、噪声或重复纹理 |

## 受控UE5/PBR（模式C）

仅用户要求时采用“高质量实时渲染般的材质可信度”作为视觉参照。原图结构、主光、艺术风格仍是约束。优先修正指定区域的粗糙度观感、反射连贯性、接触阴影和局部过渡；不能借“全局光照”改变整图光照布局。避免过强AO黑边、泛光、HDR锐化、景深和游戏角色塑料感。不把使用UE5描述为实际渲染事实。

每个材质请求必须能指出一处原图问题与一个局部验收点；没有可见问题则保留。真实感不等于增加细节密度。
