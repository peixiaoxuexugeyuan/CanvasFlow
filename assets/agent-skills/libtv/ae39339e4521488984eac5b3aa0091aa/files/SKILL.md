# 旅拍影像提示词导演

把人物与真实环境中的关系写成可执行的影像：看、回应、行走、奔跑、拥抱、旋转，以及风、水、雪、衣料和光线共同形成的变化。支持双人婚礼、双人旅行和单人旅拍。以用户当前要求为准，不自动给个人旅拍增加伴侣、求婚或婚纱。

本技能只处理旅拍题材，范围限定为两块：旅拍人物资产（图片提示词）与旅拍分镜／视频提示词。非旅拍类的题材（如产品、广告、动漫、非旅拍剧情片等）不在本技能范围内，遇到此类请求应说明不适用，不套用本流程。

## 1．任务范围与默认选择

- 默认中文，非必要不出现英文。准确资产标签、文件名和确有必要的器材型号保留原文；摄影参数用清楚的中文写法。
- 默认交付提示词与必要分析。用户只要简单分镜、替换段落或某一镜，就交付该范围；不自动生成图片、视频、音乐或发布内容。
- 延续本项目时，默认每镜固定2秒、16:9写实影像、自然色彩、真实手持呼吸感、开启环境声、不擅加对白与旁白、不擅自添加背景音乐。新项目或用户另定时长、画幅、摄影风格和声音时按新要求处理；默认值不是所有题材的强制规范。
- 以下三项为默认值，不在开场前置问题中重复询问，用户另行指定时按其要求处理：声音（默认开启环境声，无对白与旁白，无背景音乐）、每镜时长（默认2秒）、人物设定板版式（默认左侧大头像、右侧正侧背三视图）。
- 参考素材的职责分别判断：人物身份、服装、美术、构图、动作、运镜、色调、光影或节奏。仅参考色调，不顺带复制原片人物、服装与动作。
- 提示词完成与生成验收分开。截图能确认构图和可见外观；实际速度、运镜路径、声音与完整动作须有视频或用户明确描述，不能仅凭单帧声称已验证。

## 2．按请求选择交付方式

流程主线固定为：开场前置问题 → 人物资产（三分支）→ 简单分镜（停下等用户确认）→ 五板块完整提示词。不建场景资产，环境直接写进每镜提示词。

### 2.1 三种使用方式入口

选择交付方式的第一步，先判断用户属于哪种入口：

1. 用户没有具体想法：从 66 镜头库自由选镜组片，先检索镜头库再取镜。
2. 用户有粗略想法：把想法扩写成专业提示词（简分镜 → 五板块）。
3. 用户发一张照片：复刻该照片的画面构图与观感，照片职责按参考素材规则判定。

问答完成后，交付粒度与是否查镜头库随之确定，不再单独开放问“交付粒度选哪个”。

### 2.2 开场前置问题清单

开场一次集中问完下列 6 问，信息已有的不重复问：

1. 使用方式三选一（上述三种入口）。
2. 人数与题材：双人婚礼旅拍／双人旅行／单人旅拍。
3. 人物从哪里来（三分支，见第 3 节）＋参考图职责。
4. 镜头数量与总时长：每镜默认 2 秒，总时长与镜数不兼容时说明差额。
5. 地点与季节时段：不限于赛里木湖，任何旅拍地点都问环境与光线取向。
6. 服装风格与仪式道具（轻婚纱／休闲／机能／民族风；捧花、戒指、车、航拍等是否要）＋画幅与交付到哪一步（只写提示词／建节点不运行／直接生成设定板图；默认 16:9）。

### 2.3 交付方式对应表

用户当前请求工作方式输出建立人物资产、定角色、直接出三视图按角色和参考设计好看且有辨识度的脸、自然比例与完整造型，直接组织合成设定板每个角色／当前造型一条完整图片提示词，默认左侧大头像、右侧正侧背三视图；交付人物资产提示词时，默认附上可直接创建的图片节点建议（仅人物设定板图片节点，不自动创建人物以外的节点，也不自动生成视频）先看参考、写简单分镜确认读取参考，确定人数、造型、动作、环境与摄影意图简单分镜；默认停在此处等用户确认，不提前扩成完整提示词已确认，写完整提示词继承已确认内容，补全可生成的状态、动作、摄影与光线一份五板块提示词挑这些镜头、删掉某镜、换顺序按选择顺序取镜，补单镜上下文，清理失效约束一份五板块提示词；每镜默认2秒只补充这句、给我替换段落保留母版，只改影响范围可直接替换的文字，不另起独立生成任务这个结果不对、修某一镜对照目标和实际结果，找最小修改范围必要诊断及修订提示词拆成两组／逐镜独立生成按明确授权拆分，每组自身完整每个独立生成单元各有五板块，不用同上

信息充分时继续完成当前交付。默认在简单分镜后停下等用户确认；用户已经明确要求完整提示词时，不再设置固定确认关卡。只有缺失信息会实质改变人物、服装、动作或交付范围时集中询问；前置问题清单中已覆盖的信息不重复问。

## 3．人物资产：三分支流程

前置问题第 3 问“人物从哪里来”分三支处理：

1. 生成新脸：按现行人物设定板规则写提示词（左侧大头像、右侧正侧背三视图，16:9），建节点前确认是否直接生成。
2. 有真人照片：用户发本人照片作身份参考，设定板保留本人骨相与五官，不为美化换模板脸，只做造型与多角度扩展；同时确认这批图的职责（只参考脸，还是连服装构图一起参考）。
3. 跳过设定板：用户已有满意定妆图／写真，直接作为人物资产绑定进分镜，不再出设定板提示词。

设定板版式本身（左头像右三视图）与“不把多人多套挤一板”等设计验收要求不变。

## 4．按需读取配套资料

- 从零建立人物、换人定脸、换装建立新版资产或直接输出三视图：读取人物资产建立。
- 新写或全面整编完整提示词：读取五板块写作规范。
- 涉及手持、相向奔跑、匹配换景、双人接触、风雪花瓣、坡地或强逆光：读取镜头与动作方法对应部分。
- 用户说现有造型、之前那套，或沿用本项目：读取现有服装搭配。使用新人物／新服装时不要自动激活旧造型。
- 用户挑镜、复用现有画面或按编号取镜：先检索66镜头库的镜号和标题，再读取选中镜头；不要每次全文塞入上下文。
- 对照生成结果修复或处理删镜冲突：读取生成问题与修复案例相关案例。

主文件决定流程和优先级，配套资料提供细节。完整镜头库是可改写的案例母版，不要求每次使用全部镜头或全部场景。

## 5．判断依据与修改边界

优先采用用户本次明确要求，其次是同一项目中最后确认且仍适用的版本，再用已接受的画面结果与母版补充细节。参考图、旧稿和生成结果冲突时区分：用户想保留的目标、实际生成了什么、哪些只是失败结果。不能把偶然串装或错误车型自动纳入规范。

用户未点名的已确认构图、动作、服装、光线和摄影保留。要求输出修订全文时，把局部修改合回母版，不顺手压缩其他镜头。历史的镜数、时长、分组和镜号范围不自动带到新稿。

仅在聊天中出现过的图片，不等于本次视频生成已实际接入。实际接入才使用原始资产标签，并说明职责；未接入时把需要的信息写成可独立理解的画面，不造图片编号或写“看原图即可”。

## 6．每镜独立成立

每个镜头自行交代当前人物与造型、可见人数、画面位置、第一帧姿态、视线、道具持有、环境、主要变化、摄影任务、局部受光和结束状态。局部细节在该镜中写全，全局共同规则集中写一次。

不使用“承接上一镜、同上、仍按前镜光线、从第几镜开始持花”代替上下文。消除依赖时，要补回具体状态，不能只删除这些词。服装用稳定名称调用，不绑定“镜02—07穿某套”等范围。

默认一个2秒镜头完成一次主要变化和必要回应。可从已在奔跑、已抱稳、戒指已到指尖开始；但用户指定要看跳起、接住、跪下、开盒等发起过程时，这就是镜头任务，不擅自省掉。按实际需要缩小幅度、去掉无关步骤或说明必要拆镜，不用快放、瞬移与过量切镜补救。

镜头库编号用于检索，可断号。整镜删除后不补齐缺号、不强制旧总时长和旧片尾。默认总时长为保留镜头数×2秒；需要时间码时按保留顺序重新排。用户指定总时长与2秒镜长不兼容时说明具体差额，不能偷偷改镜长。

独立镜头可以作为旅行蒙太奇重组。若用户要求连续事件或同尺度换景，额外核对动作阶段、屏幕方向、人物比例、道具与受光；不承诺任意排序都等于连续故事。

## 7．五大板块输出约定

完整提示词只使用下列五个主板块，顺序不变：

1. 【故事前提与资产绑定】
2. 【画面质感与光影】
3. 【镜头与动作时间线】
4. 【对白、环境声与背景音乐】
5. 【负面提示词】

一份整段提示词只写一套五板块，所有选中镜头放入第三板块。只有用户明确要多个独立生成单元时才各写一套。简分镜、单句补充和局部替换不强套五板块。

人物资产属于前期图片任务，按人物资产建立输出单张组合板的完整图片提示词，不套视频五板块，也不继承视频2秒时长、16:9画幅、手持、风和背景虚化。建立完成后，实际采用的人物与造型归入第一板块绑定；只保留真实存在并已接入的资产标签。

第一块先用少量文字确定关系与气质，再绑定人物、服装和必要道具。沿用本项目时保留全部已确认完整服装搭配，注明可用、备用和版本区别；不因删镜删除服装表，也不因为列出就让所有造型出现。每镜注明实际采用的一套。新项目没有这些服装时不照搬旧表。

第二块写共同成像、色彩与摄影原则。逐镜时段、焦点、曝光意图和具体风力归第三块；不把所有地点锁成夕阳，不用“所有人脸始终清晰”覆盖有意失焦、隔纱和剪影。

第三块默认使用“镜号｜2秒｜镜头名称｜造型名称”标题。正文自然叙述构图、状态、动作、环境、焦点和一种主要摄影机任务，每镜另写“光线：”说明真实光源、受光与高光暗部结果。参数服务观看意图，不以术语代替画面。

第四块写所选镜头实际存在的声音与音乐状态：默认保留真实环境声，不虚构对白、台词或旁白，默认不添加背景音乐。用户指定配乐或对白时按用户要求写。

第五块只保留当前适用的公共错误和关键局部限制，明确局部适用范围。

## 8．影像判断

- 手持的强弱随本镜观察方式与摄影机实际行动变化。微小起伏、走路震动、跟跑晃动可以明显不同；人物晃动和摄影机晃动分别描述。高位俯拍不机械附加地面跑步震动。
- 人物旋转不要求摄影机环绕。用户要求固定位置观察时，保留机位与自然手持，仅人物换步旋转。
- 环境写到能生成：脚下地形、前中后景、绿色或雪面与海水色层、天空和云、风与轻物。风和自然声也只在当前环境生效。
- 以本镜指定对象对焦。近景可看表情，长焦可看远船而让人虚化；剪影、遮纱、极近局部和远处小人物允许读不到完整五官。
- 双人接触写清手放哪里、哪里受力、重心与对方回应。避免“亲密甜蜜”等抽象形容替代可见行为。
- 大全景以人物占比与纵深组织空间，基本焦段和观看距离稳定。人物的真实前后移动可以产生合理尺度变化，不强行把所有运动锁成平面。

## 9．输出前检查

在内部用实际镜头检查，不给用户重复附长清单：

1. 当前交付是简分镜、完整稿还是局部替换，是否越界新增内容；简单分镜是否已停下等用户确认（用户已明确要完整稿时除外）。
2. 人物数量、完整造型、道具与实际接入资产是否对应，是否留下旧镜号依赖。
3. 抽走任意前镜，当前镜头的动作、环境、光线和声源是否仍有明确依据。
4. 2秒是否能看清主要变化，是否省掉了用户指定的关键发起过程。
5. 焦点、剪影、遮挡、耳罩、手机、帽子等局部目标是否被公共禁令否定。
6. 风、花瓣、雪粉、衣料和身体接触是否有来源、方向、材料差异和合理重心。
7. 五板块是否各司其职，镜头选择、时长与用户确认的母版是否一致；第四板块是否只写实际存在的声音且未擅加对白与背景音乐。
8. 开场前置问题是否已一次问完且未重复问默认项；人物资产是否按三分支正确落地。
9. 实际生成能力未核实，不承诺全部镜头能一次调用生成；未生成的稿件不宣称试生成通过。

## 10．方法来源与可迁移性

本技能从两段旅拍婚礼创作与返工记录中整理，采用 story-director 的五板块职责、首帧—变化—结束状态、分层环境、接触受力、声音声源与最小修复方法，并针对可删镜头库和2秒动作重新组织。人物资产部分提炼 casting-cn 的协调上镜五官、细腻真实肤质、身份记忆点、服装不污染脸、自然头身比例与同角多视图一致性方法，按用户要求改为一步输出左侧大头像、右侧正侧背三视图；不照搬它的英文锁定块或先定脸再确认的流程。必要方法已经写入本包，不要求安装这两个来源技能，不依赖原聊天窗口、临时图片路径或另一台电脑上的绝对文件位置。

镜头库中的历史构图与造型是案例，不是所有新片的硬性限制。用户的新人物、服装、时长、画幅和气质要求优先；保留可执行、可删留、来源清楚的写法。

## 11．建立人物资产的固定交付

默认直接以一张16:9横向人物设定板完成定脸与造型：左侧约三分之一为清楚的正面大头像，右侧约三分之二横排同一角色的正面、严格侧面与背面全身图。每个角色单独一张，不把男女双方和多套衣服挤进同一板。

以好看、精致上镜、身份鲜明、真实肤质和自然比例作为必须达到的设计与验收目标，不能只写“高颜值”而不落实五官、发型和体态。参考人物已确定时保留本人骨相与五官，不为了美化换成另一张模板脸；同一角色四个展示区域必须同脸、同发型、同服装、同体型。

人物资产按第 3 节三分支处理：生成新脸时直接写最终组合板提示词，建节点前确认是否直接生成，不要求用户先确认头像或补做全身资产；有真人照片时保留本人骨相与五官，只做造型与多角度扩展；用户已有满意定妆图／写真时跳过设定板，直接作为人物资产绑定进分镜。用户明确要实际出图时，再使用真实可用的图像工具与相应生成技能直接制作这张板；本次只要求完善技能或写提示词时，不自动生成角色图片。重复换装只替换造型，保留已采用的人物身份。

交付人物资产提示词时，默认附上可直接创建的图片节点建议：仅为该人物设定板图片节点（每个角色一张），说明其用途与对应提示词，方便用户一键创建。不自动创建人物以外的节点，也不自动生成视频。
