# 生成问题与最小修复案例

用于对照参考、提示词和实际生成结果修订。先分清用户目标、实际可见错误和需要保持的内容；不把推测根因当事实，不把失败结果自动升级为新资产。

## 1．修复工作方式

1. 定位问题层：身份、造型、人数、姿态、接触、运动、地形、摄影、对焦、光影、材料或声音。
2. 找最小影响范围：一句、一个镜头或确实受影响的一组。没有证据时不全面重写。
3. 保留已确认内容：尤其是构图、动作强度、机位、服装、道具和局部光线。用户只修地形，不顺便重设人物身份与情绪。
4. 用正向可见条件解决问题，补少量当前高风险限制。不要只堆“不要出错”。
5. 检查公共规则是否否定局部目标，删除或限定范围，而非继续叠加互相矛盾的禁令。
6. 按用户交付：只补充就给可替换段；要求全文就合回母版；要独立生成单镜时才带齐五板块。

如果只有一张截图，只诊断它能确认的结构、构图与颜色；完整速度、时间段、声音和接触过程需要视频或明确说明。提示词修订完成不等于实际生成已经通过。

## 2．两段对话中的典型问题

| 观察到的问题或明确纠正 | 修改重点 | 保持什么 |
|---|---|---|
| 人物脚下变成陡坡碎石 | 人物脚下写连续平坦草甸，林坡只在后景 | 原抱合、双人数量、衣装和观察方向 |
| 车窗互动男生太清楚，女生表情僵 | 长焦、男生前景虚化，女生歪头调皮看他 | 窗框、车内外关系与原造型 |
| 女生镜变成平稳微笑慢推 | 较快倾斜推进，中近景到面部近景，女生大笑，风动头发 | 推进的主体和结束景别 |
| 草地整体枯黄、天空空 | 每镜写鲜活绿、地形层次，可见晴日天空写白云 | 真正需要的暖阳边缘，不全改冷光 |
| 越野车长成加长礼宾车 | 按要求写橙色正常短轴、短车身与指定外观 | 人物动作、暮色与车辆停放关系 |
| 双人背靠背变单人抱花 | 第一帧两人全身，背贴背、面朝相反、微闭眼仰头 | 略倾斜仰拍与山地背景 |
| 前景人失焦被全局规则拉清 | 改公共对焦句，本镜明确远船／窗外合焦 | 远处景物的观看重点 |
| 骑肩扬花瓣只有零星几片 | 第一帧空气已有大量花瓣，手中继续扬出，分前中后景 | 两人承重、造型和自然笑容 |
| 风吹掌心花瓣变主动抛撒 | 掌心已有花瓣，风从指间卷走，手臂不甩 | 男生仰头笑、女生转身与强风 |
| 巨纱只有纱边微动、雪不明显 | 长焦全景、上半身蒙纱、强横风鼓面翻卷，大量分层雪粉 | 单人数量、人物小比例和真实固定点 |
| 雪地婚纱与针织混穿 | 每镜完整指定双方同一搭配，雪地便服为两人蓝围巾版本 | 已接受的动作、雪雾和机位 |
| 自拍增加第三个摄影师 | 手机由人物真实持有，前置画面无第三机位；需要时手机在取景外 | 两人贴近、自然笑与耳罩 |
| 剪影被补亮成平光人像 | 本镜用天空作亮背景，保留轮廓和暗脸 | 晚霞、云带、转圈与透纱 |
| 删镜后要求补回原镜数 | 去掉旧总镜数与范围禁令，按保留镜头计算长度 | 稳定库号和每镜2秒 |
| 后段因镜数过密而漏镜 | 核对每镜动作负担，按用户要求划分实际生成批次 | 全部已选镜头和目标结构，不擅自删镜 |

表中车型、服装和强风等是特定项目的目标；不要让所有新任务都变成橙车、蓝围巾或强风。

## 3．可直接替换的局部示例

以下示例只展示修改层级。没有收到新增要求时，不整段替换母版。

### 3.1 只补平地

人物脚下是一块宽阔、连续、近乎水平的绿色草甸，两人双脚站在同一平坦地面上。树木密集的山坡从人物后方才开始上升，近处低草自然铺展，不出现斜切画面的陡坡、裸露碎石或人物倾斜站立。

这段补地形，不新增舞步、抱起或运镜。

### 3.2 只改车窗焦点与视线

采用长焦观察车窗内外关系，男生肩背和侧脸位于近处前景，保持柔和虚化；焦点落在窗外女生面部。女生前臂自然搭在窗沿，轻轻歪头，带调皮笑意看向男生，目光落在他的脸上。摄影机保留细微手持，不拉焦回男生，也不让女生改看镜头。

### 3.3 保留快速倾斜推进

摄影机从女生中近景较快向前靠近，带小幅倾斜、呼吸起伏和自然手腕摇晃，结尾到面部近景。女生正在自然大笑，眼睛随笑意眯起，风持续吹起散发并掠过脸侧；身体与脸形保持稳定。不是稳定器式滑行，不改成缓慢微笑慢推。

### 3.4 只改短轴橙色吉普

车辆为橙色正常短轴硬派吉普，车身短而方正，正常前后轮距与轮胎比例，黑色轮眉、黑色硬顶、外露式后备胎，只有正常乘用车长度。保持原有停放方向和人物动作，不出现多排加长车窗、礼宾车车身或复古长轿车。

这些外观属于本次修复的明确选择。用户给定具体车型图片时，以其结构为准，不用此示例覆盖。

### 3.5 只改骑肩的大量花瓣

第一帧空中已经有大量天然白色与浅粉花瓣，女生跨坐在男生肩上，男生双手承托她的小腿。她把掌心预备的花瓣向上扬出，随后张开双臂大笑。近处大花瓣柔和失焦，中景花瓣有清楚薄片与卷曲，远处小花瓣密集散开；风把不同纵深花瓣带向同一下风方向。不要只留几片花瓣，也不让花瓣持续盖住两张脸。

不将这段套到“风吹掌心”的镜头；两者发起方式不同。

### 3.6 只改风吹离掌心

两人摊开的掌心第一帧已经盛有红粉花瓣，男生在左侧仰头大笑，女生在右侧自然转身。持续强风从掌心和指缝卷起花瓣，花瓣脱离手后四散并向下风侧飘远；两人不甩臂抛撒，不再凭空增加一束花。发丝、围巾和衣角回应同一阵风，但厚针织不与花瓣同步翻飞。

## 4．删镜和换人后的实际检查

用真实请求试读规则与对应镜头，不只检查标题数量。以下可用于本技能修改后的行为核对；没有调用视频生成时，只能说明文字检查通过。

### A．仅保留戴戒指

请求：沿用本项目，只保留镜66，其他都删，输出完整提示词。

应做到：一套五板块；保留全部现有服装表但只激活婚纱礼服；只有2秒戴戒指镜；女生左手、男生托手和戒指初始位置完整；不补求婚、开盒或原片片尾，不保留车辆和海浪声音。

### B．混选三种摄影目标

请求：按镜09、14、61顺序选，人物失焦、覆纱和剪影都保留。

应做到：3镜共6秒；本镜各自有海岸、雪坡与暮色山地环境；远船合焦、覆纱蒙脸、暗脸剪影不被全局人脸清晰覆盖；不因海边便服进入服装表就把雪地女生换装。

### C．只补充地形

请求：镜23脚下还是坡，只补一句，我直接复制替换。

应做到：只给地形替换段，保留原双人、动作和机位；不输出五板块，不创建新的单镜生成方案，不改其他镜头。

### D．换成个人旅拍

请求：用新角色和新服装，参考镜36草坡抱花，只要一个人。

应做到：用新身份和服装，保留草坡、花与合理风动；不自动套针织旧脸，不增加男生、婚纱和求婚；当用户要完整提示词时给一套五板块。

### E．要求跳抱过程

请求：两秒，女孩跳上男孩身上，再开始转；镜头不跟着转。

应做到：写清起跳、接住腰背、承重和开始小幅转动；摄影机原地手持，不改成从头到尾已抱稳，不强塞完整多圈与放下。

### F．匹配换景只取一镜

请求：相向奔跑只留白昼版，不要金山版。

应做到：白昼镜自身人物左右、大小、奔跑状态与背景光线完整；不出现“继续上一镜”或金山必须先出现的条件。

### G．改变默认画幅时长

请求：新片16:9，每镜3秒，安静固定机位，三个镜头。

应做到：按新要求9秒，重新组织动作，不能仍锁4:3、2秒或明显手持。五板块和必要独立上下文继续成立。

### H．总时长约束不相容

请求：15秒，所有镜头固定2秒。

应做到：指出整数镜数无法满足，给出14或16秒的具体选择；不偷偷写1.5秒，不假称7.5个镜头。

### I．从零直接建立人物资产

请求：帮我做一男一女旅拍角色，要好看，直接一边大头像一边三视图。

应做到：男、女各一条完整图片提示词，分别指向一张16:9组合板；左侧大头像、右侧正面、严格侧面、背面3个完整全身视角。同人四区统一身份、发型、服装和比例，有具体五官、细腻真实肤质和审美设计。不先只交头像、不开定脸确认关卡，不把两人挤成一张板，也不把视频2秒与手持规则套到资产图。用户明确要求实际出图时再按可用工具执行，不把仅写好提示词说成已经生成。

### J．已确认人物只换婚纱

请求：用刚才这个女生，换成现有婚纱那套，仍然大头像加三视图。

应做到：已有图实际接入时锁定本人骨相和五官，换低盘发、白花、头纱与完整婚纱造型，4个区域穿同一套；不重新抽一张更漂亮但不同的脸。没有实际接入时不伪造图片标签；视频后续调用时不把4个展示区域当成4个人。

## 5．修复后的范围核对

修复结果要回答：目标错误是否被具体条件纠正；原来已接受的画面是否保留；新限制会不会误伤别的镜头；删掉相邻镜后是否仍完整；是否把未证实的动态或旧失败当成事实。

用户只改局部时，不为了更新本技能而改动既有项目文件或建立额外长期日志。只有新的实际使用问题证明规则需要调整，才做范围明确的修订。
