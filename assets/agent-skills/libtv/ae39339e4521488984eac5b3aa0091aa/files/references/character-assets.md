# 人物资产建立：大头像与全身三视图同张

用于从零设计旅拍角色、将现有人物做成稳定资产，以及同一人物换装。提炼 casting-cn 的五官审美、真实肤质、身份记忆点、身材比例和同角一致性方法，按用户要求直接交付一张组合设定板。必要规则已写入本文件，不依赖来源技能的安装或原聊天记录。

## 1．固定交付与任务边界

默认每个角色、当前一套造型对应一张16:9横向人物设定板。左侧约三分之一为正面大头像，右侧约三分之二并排正面、严格侧面、背面3个全身视角。用户只说一边头像一边三视图时采用这个布局；明确指定相反方向时按其要求调换。

这张板同时承担定脸、全身比例、发型服装和三视图资产职责。没有先前定脸图也直接输出最终组合板，不先要求单独生头像、确认头像、生全身、再确认全身。只有实际结果需要局部修复时才修相应区域，不把多阶段制作设成固定前提。

默认交付完整中文图片提示词。用户明确要求实际出图时，使用当前可用图像工具和适用的生成技能直接制作最终板；只要求修改技能或提示词，不擅自生成图片。使用真实可用的参考机制，不编造模型接口、图像编号或资产归档标签。

双人项目默认男、女角色各1张板，每张只包含同一个角色的4个展示区域。不得把两人合成一张身份混杂的设定板。若要求多套衣服，每人每套各1张，保留同一人物身份；没有要求时不自动遍历服装目录。

图片任务不套视频五板块，不套视频2秒与4:3默认，也不加入手持、奔跑、风吹、海岸或浅景深。后续视频再用五板块绑定实际采用的人物资产。

用于后续视频时，组合板只负责人物身份、身材与服装。大头像和3个视角不是4个人，白底、分区、展示站姿和资产光线不进入旅拍场景；视频内的人数、姿态、构图和受光按本镜执行。

## 2．把“必须好看”落实为设计与验收

高审美、协调上镜、真实自然是本任务的成稿要求。不能只用“美女、帅哥、高颜值、电影感”几个词代替人物设计；要落实以下可见条件。生成结果未达到时不能当作合格母版继续套用。

### 2.1 五官与辨识度

- 先确定人物的年龄感、脸型骨相、眉眼形态、鼻唇比例、发际线与气质，再决定服装。没有额外设定时，旅拍新人按成年年轻人设计，气质自然、清爽、亲近；用户指定年龄、族裔和五官时优先采用。
- 脸部轮廓流畅，额头、颧部、下颌与五官量感协调。双眼形态稳定且有神，眉形配合骨相，鼻梁与鼻头比例自然，唇形清楚，肤色健康。避免脸形过度收窄、眼睛夸大、鼻梁刀刻、下巴尖削和统一复制的模板脸。
- 女性可以用精致眉眼、自然杏眼、流畅颈肩与柔和而清楚的骨相表达好看；男性可以用清楚骨相、干净眉眼、自然鼻唇和舒展肩颈表达帅气。它们是可选设计方向，不替代用户给定的圆脸、方脸、单眼皮等特征。
- 每人提炼1—3个具体身份记忆点，例如略上扬的眼尾、鼻尖轻圆、明显眉峰、特定唇峰或稳定发际线。记忆点不要全部靠衣服、发色和配饰承担。
- 多角色在脸型、眉眼、鼻唇或发型轮廓中有清楚区别；每人自身四区保持完全一致。不能只通过换衣服把同一张脸当成两个角色。

### 2.2 肤质、妆发与清晰度

皮肤细腻、干净、温润通透，有轻微自然纹理与细小毛孔，像真实人物经过克制的专业修饰。保留眼睑、鼻翼、唇纹和脸侧细节；不粗糙坑洼、过度锐化，也不磨成塑料、蜡或完全没有结构的平滑面。

妆容以适合旅行摄影的清透上镜为基础，保留个人特征，不默认浓妆或强修容。发型明确分缝、长度、固定方式与发际线，大头像和三视图一致。婚纱低盘发不在背视图自动变披发，半扎发不在侧面解开。

头像眼睛、鼻唇、耳部、发际线与发丝清楚，全身图的脸、衣料和鞋完整可读。靠精细呈现与合理对焦表达，不用过强锐化、过曝或平光去换清晰。

### 2.3 体态与比例

根据年龄、体形与角色定位选择自然比例。缺少具体要求时，成年女性可用约7头身、成年男性约7.5—8头身作为协调方向；明确头部约占全身高度的相应比例，不靠无限拉长腿和缩小头制造高级感。用户真实参考和体形要求优先，不为满足数字重塑本人。

肩宽、颈长、躯干、骨盆、腿长和手脚尺寸互相协调。站姿舒展、轻松挺拔，肩颈放松，不僵硬端肩、塌腰或用扭胯掩盖比例。侧面与背面保持相同体型、头身比和真实高度。

## 3．构图与三视图规范

| 区域 | 需要的画面 | 保持与避免 |
|---|---|---|
| 左侧大头像 | 头顶到锁骨或上胸口，正面水平，眼神平视，表情自然轻松 | 发顶完整，少量安全留白；不切额头，不变半身小头像，不用大笑变形掩盖五官 |
| 右侧第1图 | 从头到鞋完整的正面全身，双脚平放，手臂自然下垂略离躯干 | 不插兜遮手，不交叉腿，不用动态走姿 |
| 右侧第2图 | 严格90°侧面全身，默认面向画面左，完整显示侧面轮廓 | 不做四分之三侧面，不把头转正看镜头 |
| 右侧第3图 | 严格背面全身，头与身体都背向镜头 | 不回头露正脸；后脑、服装后片、裙摆或裤型清楚 |

右侧3个全身人物等高、等比例，脚底在同一基线，头顶高度相同。三图之间有适当间隔，四肢、衣服与鞋不重叠；不把其中一图裁成半身或局部。头像区本来尺度更大，不为了与全身图等大缩小头像。

4个展示区域是同一个人的不同视角，面部骨相、肤色、发型、衣服、鞋、配件、头身比与身体量感一致。背面不需要凭空露出脸，但头型、发际和发型结构须与正侧面对应。

默认干净纯白背景，边缘清楚，脚下允许很淡的真实接触阴影。柔和棚拍光形成自然体积，鼻梁、颧部与发丝有适度高光，脸侧有柔和阴影。白衣、白纱与背景通过材质、边缘和褶皱明暗区分，不把人物抠成发光白边。

不添加姓名、英文视角标签、品牌、水印、尺标、坐标、复杂边框或装饰场景。用户需要文字标签时另按要求。设定板清楚展示身份和造型，不承担故事剧情。

## 4．已有参考、换装与身份锁定

有实际接入的本人或已接受角色图时，明确它只锁定该人物的脸型骨相、五官位置、眼型、鼻唇、发际线与身份特征；服装参考单独负责衣料、颜色、剪裁和配件。可改善布光、整洁度与上镜状态，不把“变好看”解释成换脸。

同一人的新造型板复用同一身份，四区穿当前同一套衣服，不让头像穿便服、三视图穿婚纱。衣服不改变骨相、年龄、肤色与表情类型。用户明确换妆发时只改造型层。

没有实际接入参考时，不写“使用之前那张脸”“以图一为准”或伪造标签。把人物外貌与完整服装直接写进当前提示词。已有图仅供分析、未传入实际生成时，也要用文字落实所需特征。

服装定义至少包含上装、下装或裙装、鞋、必要配件与发型。沿用本项目可从[服装目录](wardrobe-catalog.md)选择一套，不默认全出。衣服穿法按实际设计和用户参考，不照搬来源技能中上衣一律不塞下装等无关规则。

没有既有定脸图，不是阻止制作组合板的理由；角色信息充分就直接写最终板。缺少服装或年龄等非关键细节可作合理补全并简短说明，不开启长表单询问。

## 5．完整中文图片提示词的组织

每个角色一条可直接复制使用的完整提示词，通常按以下顺序自然分段：

1. 单张横向设定板、左右分区与同一人物4区的明确任务。
2. 年龄、身份特征、具体五官、气质、妆发与肤质。
3. 一整套服装、自然体形与头身关系。
4. 头像构图、正侧背角度、三图尺度与统一身份。
5. 纯白背景、自然体积光、清晰细节与本次高风险限制。

最终提示词不要出现未填写占位符、英文锁定块、未绑定图片编号或原技能的流程说明。内容可以有自然段，不强加视频五板块。简短角色说明与参考职责放提示词外或其开头，避免让模型把说明当设定板文字印出来。

## 6．两条完整示例

以下只展示成品密度和布局。五官与年龄属于示例新角色，不是所有人的固定长相；用户已有身份时用其特征替换，不能直接套示例脸。

### 6.1 成年女生，海边便服造型

生成一张16:9横向写实人物设定板，同一位成年中国女生。左侧约三分之一是一张正面大头像，右侧约三分之二横向并排她的正面、严格90°侧面、背面3张完整全身图。整张图只展示同一个角色，不是4个不同的人。

女生约24岁，长相精致、清爽上镜，气质温柔自然，有明确辨识度。流畅协调的鹅蛋脸，柔和而清楚的颧颌结构，眉形自然舒展，清澈有神的杏眼、眼尾轻微上扬，鼻梁自然挺直、鼻尖轻圆，唇峰清楚、唇部柔润；眼尾与鼻尖是稳定身份特征。肤色健康温润，皮肤细腻干净，有微小真实纹理与自然光泽，淡妆不遮盖骨相。深褐长发中分半扎，固定位置明确，其余发尾自然落下；四区发型和发际线完全一致。

穿白色方领泡泡短袖上衣，胸前小蝴蝶结和细褶；彩色花卉短裙、白色中筒袜、蓝色平底鞋、细银项链。4个展示区域同一完整造型，不增加帽子、婚纱或花束。自然协调的约7头身，头部约占全身高度七分之一，颈肩舒展，躯干与腿长真实，手脚大小自然，站立放松。

左侧头像保留完整发顶至锁骨，头部水平、正面平视，唇角轻微放松，五官和发丝清楚。右侧依次正面、面朝画面左的严格侧面、完全背面；3图从头到鞋完整，等高等比例、脚底同一基线，手臂自然下垂略离身体，双脚平放，互不遮挡。背面不扭头，侧面不转脸，四区同脸同肤色同体型。

纯净无缝纯白背景，柔和棚拍光塑造鼻梁、颧部和脸侧体积，白衣保留褶皱、材质与边缘，脚下只有淡接触阴影。真实人像质感，脸、发型、衣料、手和鞋都清楚，不用浅景深模糊某一区。不出现文字、水印、额外角色、四区换脸、大小眼、尖削下巴、塑料皮肤、过长腿、重叠肢体、裁头或裁鞋。

### 6.2 成年男生，海边便服造型

生成一张16:9横向写实人物设定板，同一位成年中国男生。左侧约三分之一为正面大头像，右侧约三分之二横排正面、严格90°侧面与背面3张完整全身图。同一角色在4个区域反复展示，不能成为4张不同的脸。

男生约26岁，干净俊朗、自然上镜，气质松弛温和。脸型流畅稍长，颧部与下颌结构清楚不过分刀刻，眉形略平直、眉峰适度，眼睛明亮，内眼角清楚、眼尾自然延伸，鼻梁挺直、鼻唇比例协调，唇形清楚略有柔润感。平直眉形和自然延长的眼尾为固定身份记忆点，不用女性示例的脸改造。肤色健康，真实细腻肌理与极轻微毛孔，面部不过分磨皮。蓬松黑色短发，刘海有自然层次，发际线、鬓角和后脑发型在各视角一致。

穿米白短袖衬衫，一侧为浅色花卉拼接，宽松水洗蓝牛仔裤、米白休闲鞋。衬衫版型和花卉拼接的位置在正侧背面有合理对应，不随角度交换左右。自然挺拔的约8头身，头部约占全身高度八分之一，肩宽、颈长、腰胯和四肢协调，健康清瘦，站姿放松，不通过缩头或拉腿改变比例。

左侧头像从完整发顶到锁骨，正面水平、平视镜头，表情自然轻松，不大笑。右侧3图等高同尺度、脚底同基线，从头到鞋全在画面，依次正面、面朝画面左的严格侧面、完全背面；手臂放松下垂略离躯干，不插兜、不交叉腿、不回头。四区保持同一骨相五官、肤色、发型、服装、鞋和体型。

纯净无缝纯白背景，柔和棚拍光保留面部立体塑形与自然高光，衣料纹理、头发、手和鞋清楚，脚下淡接触阴影。精致真实的摄影质感，不加场景、道具、姓名、英文标签或水印，不出现多个人、侧面偷看镜头、背面露正脸、衣服换色、肩宽漂移、塑料脸、过长四肢、裁脚和过度锐化。

## 7．交付与结果检查

提示词交付前检查：是否直接是最终组合板，是否一人一板，是否左大头像右正侧背，是否同一整套造型与自然比例，是否有具体审美设计而非空写高颜值，是否使用了真实参考标签。

实际生成后另看：五官是否协调好看且符合身份，头像与正侧面是否同一个人，侧面是否严格90°，背面是否真实背面，3张全身是否等高完整，衣服和发型是否一致，皮肤是否细腻真实。换装后不得重新选另一张脸。

缺图、视角错、脸漂、身材失衡或不符合审美目标时，只修失败的变量并保留满意部分。输出提示词本身不算生成通过；也不以技术检查代替实际人物好不好看的视觉验收。不能自动把失败兜底升级为每次都先单独定脸再确认的固定流程。
