# 镜头、动作与环境方法

按本镜任务读取相关部分。这里的方法来自旅拍实际修订，并吸收单镜状态、分层环境、动作接触与声源设计。它们服务当前画面，不要求每镜同时使用全部方法。

## 1．先确定观众要看什么

先确定可见结果，再选景别、观看距离、焦段、光圈和摄影机运动。例如：长焦看远船、两人自然笑出的瞬间、薄纱罩住上半身、跳抱接触点、广阔雪山前的小人物。不要先填一串摄影参数后再补动作。

内部按“第一帧已经是什么—发生什么主要变化—结束时看见什么”组织。一个主要变化可以包含自然连贯的小动作和对方回应；不是强制人物只能动一个关节。

背景因虚化不可辨时不要求读出全部山峰细节；人物很小时不要求近景级眼神。每镜保留看得见且有作用的设计。

## 2．真实手持与摄影机任务

| 观察方式 | 合理手持 | 需要避免 |
|---|---|---|
| 安静肖像、手部、极近局部 | 细小上下起伏、左右微摆与手腕细抖 | 画面缩放呼吸、脸形变化、每帧大甩动 |
| 并肩行走、倒退走 | 实际脚步起伏、短距离视差，振幅稍大 | 无落脚的漂浮、背景贴图平移 |
| 跟随狂奔 | 明显不规则脚步震动与合理短暂动态模糊，仍能读主体 | 全程糊掉、地平线翻滚、人物结构变形 |
| 原地观察人物抱转 | 机位留在原处，手持有自然摆动，主体在视野内旋转 | 自动环绕、摄影机和人一起高速转 |
| 长焦远景、大全景 | 细微角度晃动，焦段和观看距离基本稳定 | 连续变焦、突然推近、用虚拟防抖拉伸地形 |
| 高位或垂直俯拍 | 与实际拍摄平台相容的细微漂移和角度起伏 | 地面跑步式震动、把高位镜误写成贴身追拍 |

“越动越晃”根据摄影机真实行动与本镜观察方式解释。人物激烈运动但远处机位原地观察时，不要求同幅度跳动。手持感可以与清楚主体共存，不需要全片同一种振幅。

摄影机原则上一镜一个主要任务：原地观察、短推近、上移、横移、跟走或跟跑。呼吸微动是其上自然存在的扰动，不算必须再加一次摇镜。复杂复合运动只在用户明确指定且空间成立时使用。

## 3．长焦、清晰范围与近景

### 3.1 长焦的观看关系

写清观看距离、主体前后位置和远近压缩关系。焦段不单独决定背景清晰度，也受对焦距离和光圈影响。需要具体数值时可参考85—135毫米，超长焦环境镜可更长，仍以实际构图为准。

远船镜：两人头肩在左右前景柔和失焦，中间形成观看通道，焦点落在远处移动白帆和港湾；不自动拉焦到人脸。

车窗镜有两类：人物表情合焦、景物滑过；或近处帽边下颌失焦，窗外草原雪山合焦。选定一种，不同时要求近处面孔和远山全部锐利。

车窗互动：男生近处肩背和侧脸虚化，女生在窗外中景合焦；女生歪头、调皮看男生。长焦压缩和浅清晰范围服务视线关系，不默认让女生直视摄影机。

### 3.2 极近局部与头部移动

下半脸特写只取鼻尖以下、嘴唇、下颌和部分颈部，允许双眼不在画内；不要被公共“眼神清楚”破坏。

蒙纱从脖子向上：第一帧由颈部和下颌开始，摄影机贴近纱面上移并上仰，带自然手持小摆，经过鼻唇与额头，结尾到头顶部。写清纱在人物前还是盖在头上、固定点和透光，不要求全脸始终同框。

快速倾斜推进女生：从中近景较快靠近到面部近景，过程中有明确小幅倾斜和呼吸摇晃；女生大笑、风持续动散发。倾斜、速度、终点距离是任务，不能改成稳定缓慢推镜。

## 4．人物大小、大全景与地形

用大致占比说明空间，例如全身高度占画面十分之一、四分之一或三分之一。占比是构图方向，不要求模型像素级测量。

大全景保持固定焦段与基本观看距离，容许真实走动引起的小尺度变化。避免持续推近让人物从小变大，或拉远把人物缩成不可辨的点。用草地、山谷、水面与云层的纵深形成宽阔感。

区分实际斜坡、摄影机倾斜和地平线倾斜：

- 平地森林相拥：人物脚下是连续平坦草甸，双脚支撑同一平面；林带和山坡从后景升起，不铺到人物脚下。
- 草坡倒退：真实草坡向一侧上升，女孩面对摄影机倒退小步；重心随坡度调整。机位可以略倾斜，但坡度不只靠歪画面表示。
- 背靠背：两人完整可见，背部轻贴，面朝相反方向，微闭眼仰头；低机位略仰拍、小角度倾斜。不能漏成单人抱花肖像。

俯拍倒地要写相对画面方向：两人第一帧站立、脸朝画面右、背朝左，然后同时向左后方倾倒。高位大全景人物小，不为读脸而推近。落地中景另镜独立交代两人的姿势与雪地，不依赖“接上镜”。

## 5．同尺度人物换环境

此方法适用于相向奔跑、抱转等匹配剪辑。先锁人物，再写环境变化：

1. 同一人物身份、完整造型与身高关系。
2. 同一画面左右、大小、视点高度、机位侧别与拍摄方向。
3. 可匹配的动作阶段、身体朝向与运动方向。
4. 背景环境改变；人物表面受光随新环境合理调整，身份与结构不变。

相向奔跑：女生左、男生右，均已在向对方跑；人物尺寸基本一致，地面留出路径。日照金山、白昼雪山与森林草甸分别写环境，不把三镜都变成不同距离的人物。

抱转换景：承托位置、女生弯腿方向、裙摆展开程度和转动阶段相配；不要求新镜先补一次抱起。

用户明确要硬切换景时采用匹配切换；只有明确要求连续变景时才设计环境连续转换，不自动把硬切改成山体融化。各镜仍有独立起始状态，单独取用也成立。

## 6．双人接触与受力

先写参与者位置、面向、接触点、承重者与结果，再写自然表情。接触动作不必一律拆5镜，准备、发起、接触、结果、恢复是内部物理检查。

### 6.1 抱腰旋转与跳抱

竖直抱腰：女生身体竖直贴近男生，双臂环肩颈，双膝弯向身后；男生双臂承托腰背、双脚换步。女生衣料和头发有向外摆动与滞后。避免变公主抱、身体横躺、男生脚不落地。

只看旋转的2秒镜可从已经抱稳开始。用户要跳抱时，先留短距离起跳，男生屈膝接住并抱住腰背，随后开始小幅转动；不要额外塞完整360度旋转与放下。摄影机是否随人转由用户决定，海边跳抱案例采用原机位观察。

### 6.2 骑肩、背人与倾身

骑肩：女生跨坐肩上，双腿在男生身体两侧，男生双手分别握稳小腿；女生上身动作自然牵动两人平衡。扬花瓣用手中预备花瓣，其他道具不同时占手。

背人：女生在男生背上，男生承托大腿，女生可以短暂张臂；男生步态有承重，不能只靠头发和围巾漂浮暗示奔跑。

倾身亲吻：先建立背部与腰部支撑，女生双脚或一脚有稳定接触，倾角有限。2秒镜从支撑已建立开始，除非用户明确要看发起过程。

### 6.3 微动作与亲密回应

自然关系写成触发和回应：男生笑，女生看他后笑出声；指尖点鼻后收回，对方稍后笑；背后拥抱时肩颈放松，女生手覆在男生前臂。不是两人同时对镜头做统一表情。

## 7．风、花瓣、纸片与碎雪

### 7.1 同一风源，不同材料

每镜先给风的来向、强弱、是否持续，再分层写反应。发丝、薄纱、花瓣反应快；围巾有重量与尾端摆动；厚毛衣主要动边缘；缎面裙摆在受力褶皱和自由边运动。

固定点保留：盘发不散成披发，半扎不被吹开，头纱仍固定在头部。强风可以大幅鼓纱，但不让头纱变成烟、金属片或脱离人体飞走。

世界风向保持一致；反打后屏幕左右可反转，不能按“画面永远向右”破坏实际空间。

### 7.2 三类轻物来源

| 指令 | 来源和运动 | 关键区别 |
|---|---|---|
| 奔跑中撒纸 | 第一帧手中已有纸，手臂随狂奔扬开；纸离手后被尾流和风带散 | 保留狂奔动力与跟跑呼吸，不改轻跑慢撒 |
| 骑肩扬花瓣 | 手中有花瓣，抬臂扬出；空气第一帧也可已有大量天然花瓣 | 前景大瓣虚化、中景瓣清楚、后景密小；不是少量孤立碎片 |
| 风吹离掌心 | 手掌展开已有花瓣，持续风从指间卷走，人物可张臂或转身 | 不主动甩手、抛掷，不凭空生成大量新花瓣 |

花瓣保留真实花瓣的弧形、薄片与颜色，不变塑料亮片、蝴蝶或大纸屑。空气中大量花瓣不等于持续全屏遮住脸。

碎雪写松散颗粒，扬出后分成近处较大粒、中景半透明雪雾、后景细粉；男生与女生的投掷方向各自明确。不要变压实雪球、喷水、烟雾或棉花团。自然冷空气白气来自口鼻，一团短暂形成再散开，不全画面持续冒烟。

## 8．巨型头纱与雪地氛围

长焦全景，小人物全身可见，上半身被多层白纱蒙住，包括头、脸、肩胸。头顶固定点明确；强横风让纱面鼓起、折回和翻卷，长尾横向展开，不只是纱边轻飘。

前景有近处雪粒、中景是透光纱面、后景可有暗色雪林或青灰山脊。风将大量雪粉带过不同纵深，近粒较快、远粒较细密，空中有层次但不盖成纯白墙。暗色背景能衬出薄纱与雪粒，不需额外加雾。

光穿过单层纱与重叠纱的亮度不同。上半身被覆纱是目标，不用全局人脸清晰将它拉开。只在用户要求时改变纱量、覆盖或露出面部。

## 9．海岸、草原、雪面与云

海水按水深和状态分层：港湾可浅青绿通透；翻涌浪面有深青蓝、孔雀蓝和浅青色浪脊，破浪泡沫冷白，薄水回流偏浅青。不要整片水面染成高饱和电蓝，也不因夕阳就全部变橙。

波浪从浪脊抬起、卷折到泡沫展开，选2秒内清楚的一段。高位浪镜保留整体流向与泡沫纹理，不机械附加贴身跑步式抖动。

草地写鲜活绿、低草和野花，山体可有天然黄绿变化；避免统一枯黄泥灰。脚下、远坡与林带地形分开描述。

白雪有细颗粒、脚印、冷暖阴影与高光纹理，婚纱与雪面用材质和明暗区分。海滩镜即使原参考有积雪，也按用户要求改成沙滩，不留下雪地鞋印或雪林背景。

晴日出现天空时有白云，云的体积和密度服务空间。夕阳有暖云边，蓝调有灰蓝层云，剪影有橙色地平线和灰紫云带；不全部变成无云色纸。

## 10．局部光线的写法

每镜独立回答：主要光源在什么方向，哪些表面受光，人物需要读到什么，背景和高光怎样保留。写结果，不强制所有镜头同一灯位。

- 白昼：开阔天空光配自然日光，皮肤与绿色中性温润，云雪不过曝。
- 金山：暖阳落在高峰，谷地与人物可处冷侧光或柔和天空光；不是人物脸也必须通体橙红。
- 逆光：发丝、纱边与肩线有亮缘，脸由天空或地面反射保留所需细节。
- 星芒：太阳真实经过两脸或帽沿间隙，随遮挡开合出现，不贴固定发光图案。
- 提灯：暖光由灯体照向近处面部与手，背景海面保留冷蓝；远处不被小灯照亮。
- 剪影：天空是主要亮背景，轮廓和姿态清楚，暗脸无需提亮，纱可局部透霞。

## 11．声音跟随观看位置

先识别真实声源，再判断远近、强弱和同步。近处可有呼吸、衣料和脚步，远处小人物不出现贴耳喘息；发动机只属于实际车辆，浪声只属于相应海岸。

笑声要与可见或合理画外人物对应，不让嘴闭着的静态肖像持续笑。默认无配乐与旁白；用户单独要求独白时另行设计，不从历史成片自动继承。
