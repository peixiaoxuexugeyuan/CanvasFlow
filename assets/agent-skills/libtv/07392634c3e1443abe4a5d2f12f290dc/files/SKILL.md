# 糖豆风图标生成

## 这个 Skill 做什么

用户给出一个图标主题（如"优惠券""安全认证""新车上架""骑手订单""增长数据"），产出一张与参考图组风格完全一致的糖豆风 ICON 成图。

产出是**一张**带浅灰白实色底的 ICON 成图，直接可用，不需要接下一个生产环节。

## 触发时机

**该用**：用户给了一个图标主题／业务场景词，要一张风格统一、可放进同一套图标体系里的糖豆风图标。

**不该用**：用户要的是扁平／线性／写实／拟物图标，或者要的是整页 UI、插画、海报等非单个图标产出；这类需求不要套用本 Skill 的风格规范。

### 快捷唤醒词（免显式 @）

**主唤醒词**：**糖豆风格**

**同义／简写唤醒词**：**糖豆**、**糖豆风**、**按糖豆来**、**用糖豆**、**糖豆图标**

唤醒规则：

1. 当用户消息包含上述任一唤醒词，且意图是生成／优化图标或图形时，默认套用本 Skill 的全部规范（含 L1／L2／L3 档位机制），**等价于用户显式 @ 本 Skill**。
2. 唤醒词只负责"启用本 Skill"，**不替代内容判断**：主题、色系、档位仍按本 Skill 工作步骤（第 0 步定档、第 1 步定色系…）正常判定；用户在同一条消息里若另行指定档位或配色，**以用户指定为准**。
3. 若用户消息含唤醒词但意图明显不是图标生成（如纯咨询、闲聊），**不强行套用**，可正常对话。
4. **默认档位仍为 L1**；唤醒词不改变"拿不准默认 L1、同批同档禁混批"的规则。
5. 保留原有的**显式 @ 调用方式**，唤醒词是新增的便捷入口，二者并存。

## 强度档位：L1 糖豆档 / L2 轻写实档 / L3 全立体主视觉档

### 定位

- **L1 是默认档**：本 Skill 现有全部规则原样保留，一字不改。
- **L2 是在 L1 基础上的"有限松绑"档**：仅用于主题本身是真实可识别物件、需要质感支撑的场景。
- **L3 是全立体主视觉档**：用于主题本身就是完整立体物件、需要强体量感／空间感／3D 冲击力的主视觉图标（星球、地球、球体、带环绕结构的科技物件、首页大图标等）。
- 三档共享同一套"体系的根"。**L2／L3 绝不是"写实 3D"**。

### 三档速览

| 档位 | 适用主题 | 核心特征 |
|---|---|---|
| **L1**（默认） | 抽象符号／营销／榜单／补贴／入口（券、奖杯、星、心、上传、PK、补贴等） | 严格水平正视、轻量扁平、极简到只剩轮廓、**完全平面剪影、零高光零微光** |
| **L2** | 真实物件需轻质感支撑（车型、实物商品、设备、硬件） | 正面微侧浅立体（≤约 8°）、平面内嵌面通透、克制自发光、少量功能性细节 |
| **L3** | 需要完整三维体量的主视觉（星球、球体、带环绕结构物件、首页大图标） | 真三维体量、**正面均匀清亮**、立体靠边缘过渡、**柔雾哑光＋一处弥散柔亮微光**、**轻写实·轻量（形体克制、配件纤细、内凹浅）**、环绕件前后遮挡、可感接触阴影、**固定亮蓝＋黑灰配色** |

**拿不准默认 L1；同批必须同档，禁止 L1／L2／L3 混批。**

## ⚠️ L3 三铁律（最高优先级，凌驾一切）

> 本节优先级高于本 Skill 内**任何**其他配色、色系、参考图、形体规则。与任何条款冲突时，以本节为准。
> L3 的最终调性 = **配色固定（铁律一）＋ 材质中间态（铁律二）＋ 轻量反肉（铁律三）**，三者并列、缺一不可。

### 铁律一：L3 配色铁律（固定，永不换色）

1. **L3 只有一套配色，永远不变**
   - 主体＝星球亮蓝 **`#54AEFF`**（明度浮动 **±6%**，以 `#54AEFF` 为中心，**不取 `#4DA6FF`／`#5FBFFF` 极值**）
   - 配重＝黑灰偏蓝 **`#3A3F4B`～`#33363C` 哑光**
   - 符号＝白色渐变
   - 全图颜色上限严格三类（亮蓝主色系 ＋ 黑灰偏蓝配重 ＋ 白），**不得出现第四种色相**。
2. **优先级排序（写死，逐条覆盖）**
   `L3 配色铁律 > 主题语义色系 > 用户临时参考图的配色 > 色系分层表`
   - 不论主题是补贴（橙）、安全（青蓝）、销量（正蓝）还是任何语义，**只要定档 L3，配色一律是亮蓝＋黑灰，不随主题换**；
   - 若用户为 L3 任务提供的参考图是别的颜色（如橙票券、青蓝汽车），**只继承其造型／结构／构图，配色强制转换为亮蓝＋黑灰**，绝不沿用参考图色相；
   - 色系分层表、定色映射表对 L3 **不生效**——那些是 L1／L2 的取色依据。
3. **取色锚点锁死**：主体蓝与黑灰配重的唯一取色基准为星球 **`i-tCL6hHsbFc`**；L3 成品基准为 `i-FlbaxDXjs3`、`i-29V7p5VgqJ`。凡生成 L3，`reference_nodes` **必须含 `i-tCL6hHsbFc`** 与这两张成品基准中的**至少一张**作为配色锚。
4. **换色即判不达标、退回重做**：L3 出现橙／青蓝／正蓝／炭黑以外配重／绿／紫／粉／金属色等任何非铁律色相，或配重未用黑灰偏蓝、主体未用 `#54AEFF`，一律判"**L3 配色越界**"，**不交付、按铁律重出**。
5. **需要主题色就走 L1／L2**：当主题必须用自身语义色（如补贴必须橙、安全必须青蓝）时，**改用 L1 或 L2 档**，不得为保留 L3 立体而破坏配色铁律。**L3 是"亮蓝＋黑灰专属主视觉档"，不是通用立体档。**

### 铁律二：L3 材质铁律（柔雾哑光 ＋ 一层柔和漫射微光）

**一句话口径**：L3 材质 = **柔雾哑光 ＋ 一处弥散柔亮微光**，"有质感的温润半哑光"——**既不是纯平死哑光、也不是打光抛面**，介于两者之间、**偏哑光一侧**。

- **基调仍是柔雾哑光**：像高级磨砂陶瓷／粉饼的温润质感，无塑料油亮、无金属镜面、无玻璃反光、无环境反射、无过度光滑的完美 AI 塑料感。
- **但允许一层"柔和漫射微光"（soft sheen）**：受光面（如柱面左上、杯顶、球体上侧、机身上侧）可以有一片**温润、弥散、无硬边界的柔亮过渡**，让立体物件有质感与透气感，**不是完全平的死哑光**。观感是"**半哑光釉面陶瓷／柔焦软胶**"——偏哑光、但带一层薄薄的反光。
- **微光的硬边界（越界即判抛面／塑料，退回）**：
  1. 微光必须是**大面积、边缘连续、无明确边界**的柔亮区，**提亮上限不超过主色点 +12%**；
  2. **严禁点状镜面高光、严禁窄条状高光带、严禁反光斑、严禁边缘镜面反光、严禁过曝亮点、严禁镜头眩光、抛光亮面**——这些是"塑料球／打光 CG"的特征，一律不继承；
  3. 微光**只出现在受光面一处、不弥漫全身**；暗部仍守 −15% 上限、不侵入正面。
- **与 L1 的区别**：**L1 糖豆档是完全平面剪影、零高光零微光**；**L3 因为是真立体物件，允许这层柔和微光来撑立体透气感**——这是 L3 相对 L1 在材质上唯一的一点松动，且仍远不到镜面高光。
- **反向边界**：L3 也不是"完全平、零微光的纯死哑光"——那属于"修过头、丢失立体透气感"，同样不达标。

### 铁律三：L3 轻量铁律（反肉感）

**一句话口径**：**L3 = 有立体但克制，轻写实、轻量、通透；宁可偏平偏轻，不可偏肉偏肿。**

1. **形体克制、利落、轻量**
   主体保留三维体量与哑光质感，但**鼓胀度收敛**——边缘仍大圆角，却**不做充气膨胀的肿感、不做软胶玩具吹起来的肉感、不做圆滚滚的臃肿**。参考星球球面与收音机机身：是"干净、克制、有厚度但利落"的立体块面，不是"鼓到极限的气球"。**形体厚度浅、轮廓清晰、透气。**
2. **配件一律纤细**
   提手、环、杆、旋钮、星环、耳、挂环、天线等所有附属结构件，做成**细圆管／细杆／小圆柱**——截面小、纤巧、轻盈，**严禁粗厚、肥大、笨重**。星环是细管、提手是细拱、旋钮是小圆柱，这是轻量感的关键来源。
3. **内凹结构做浅**
   陨石坑、孔洞、屏幕、撕口等内凹件一律**浅内凹**——是表面浅浅的凹点／凹槽，**不做深洞、不露厚内壁、不做强烈凹陷阴影**。星球陨石坑是浅圆点、收音机屏幕是浅凹面板，都极克制。
4. **白色文字／符号允许"浅浮雕"（L3 专属）**
   L3 的白色文字（如 `NEW`）与符号允许**极浅的浮雕凸起**（轻微立体 ＋ 顶白→底冷白渐变 ＋ 柔和发光细边），比 L1／L2 的"纯平面印在表面上"略立体一档，但**仍是克制的浅浮雕，绝非厚贴片、非积木块、非重投影**。这是 L3 因真三维而给文字符号的一点松绑，与"形体轻量"不冲突（浮雕要浅、要轻）。
5. **轻量来自"形体克制 ＋ 配件纤细 ＋ 明暗轻"三者叠加**
   明暗跨度本就小（材质铁律），加上形体不鼓、配件不粗，整体才"轻写实、透气、不肉"。
6. **反向边界**：轻量 ≠ 退回 L1 纯平剪影——L3 仍要有真三维体量、边缘过渡立体、一处弥散微光、可感接触阴影；只是体量要"瘦"、配件要"细"、内凹要"浅"，**不是把立体取消**。

### L2 相对 L1 放开五项（越界即退回 L1）

1. **立体度**：允许主体呈现"正面微侧"的浅立体——可见极窄的一侧厚度边与顶面收边，用于暗示体积。
   - **侧转角度不超过约 8°**
   - 禁止真正的 3/4 透视、禁止明显灭点、禁止展示内部结构
   - 厚度只用于"暗示体积"，不得变成"展示构件"
2. **内嵌面材质**：挡风玻璃／屏幕／窗口等内嵌面**允许真实的通透渐变与明暗**（顶部受光偏浅、下部偏深）。
   - 不再执行 L1 的"内嵌面严禁偏白、必须给明确深色值"
   - **适用范围仅限平面内嵌面**（玻璃／屏幕／窗口／镜面）；**容器内壁除外**，见下方「容器类专项约束」
3. **发光件**：车灯、灯带、指示点等**允许自发光白 ＋ 柔和光晕溢出**。
   - 不再执行 L1 的"必须是印在表面、无厚度无投影的渐变薄片"
   - 光晕范围必须克制；**禁止霓虹、禁止过曝、禁止镜头眩光**
4. **机械细节**：允许少量功能性结构刻画（格栅横纹、进气口分层、镜面分件）。
   - 不再执行 L1 的"极简到只剩轮廓"
   - 细节总量受限；**禁止写实纹理、禁止密集零件堆叠、禁止品牌 logo 与真实结构还原**
5. **阴影与环境**：**允许一层浅接触阴影 ＋ 极弱环境光反弹**以增强落地感。
   - 仍**禁止投影拉长、禁止地面反射、禁止景深虚化、禁止彩色溢光**

### L3 相对 L2 再放开三项（越界即退回 L1／L2）

> **注意**：放开立体强度的同时**必须受「轻量铁律」约束**（形体克制、配件纤细、内凹浅），不得因放开立体就跑成鼓胀肉感。

1. **视角与体量**：允许真正的三维体量与 3/4 视角、允许球面／曲面的完整明暗转折、允许环形部件绕主体前后遮挡（环在主体后段被遮、前段覆盖）。
   - **取消 L2 的"侧转 ≤8°、禁真 3/4 透视、禁灭点"上限**——L3 允许单一主体的立体转向与合理空间关系
   - 仍禁止：多灭点广角畸变、鱼眼、夸张透视拉伸、展示与主题无关的内部剖面结构
2. **体积表达方式**：允许通过**主体外轮廓的一圈柔和明暗过渡（边缘光／边缘暗）**塑造立体，而非只靠平面渐变；允许凹陷孔洞（陨石坑、内凹圆点）具有真实的内凹体积与边缘明暗（**但按轻量铁律做浅**）。
3. **接触阴影**：允许**一层更明确、更可感的落地接触阴影**增强立体落地感（强于 L2 的"浅接触阴影"）。
   - 仍禁止：投影拉长变形、地面镜面反射、景深虚化、彩色溢光、盘状展台

### L3 标准配色（铁律·固定，不随主题换色）

**唯一权威基准**：`i-FlbaxDXjs3`（亮蓝电池·黑灰上下帽盖·白色渐变闪电）、`i-29V7p5VgqJ`（亮蓝奖杯·黑灰双耳杯颈台阶底座·白色渐变数字 1）。取色锚点另见「铁律一」。

- **主体＝明亮天蓝，锚定主色点 `#54AEFF`**，允许明度浮动 **±6%**（约 `#4DA6FF`～`#5FBFFF` 的窄中带，但**以 `#54AEFF` 为中心，不取区间两端极值**）。
  - 这两张的蓝是"**清亮通透的明亮天蓝**"，正面几乎是一个均匀亮面。
  - **关键纠正确立**：主体蓝必须**整块均匀清亮**——正面主视区保持接近单一明度的亮蓝；**立体感不得靠"顶部提亮＋底部大幅压暗"的大跨度明暗来做**。
  - 仍严禁：漂入青蓝 `#35C4F5` 域、偏正蓝 `#2E7CF6`、偏紫偏绿、泛白到近白、取到 `#5FBFFF` 上沿极浅色做整块平铺。
- **配重＝黑灰偏蓝（深蓝灰）`#3A3F4B`～`#33363C` 哑光**——结构性配重件（电池的上下帽盖、奖杯的双耳＋杯颈＋台阶底座、星环、凸台、底环）一律用此色，与亮蓝主体形成明确的"**亮蓝＋黑灰**"强对比。
  - 配重件本身也是柔雾哑光、边缘有极轻明暗过渡、无镜面高光；**不得用亮蓝或正蓝充当配重**。
- **符号＝白色渐变**（带柔和发光细边；L3 文字符号可为浅浮雕，详见「铁律三」）。
- **全图颜色上限三类**：明亮天蓝主色系 ＋ 黑灰偏蓝配重 ＋ 白色符号；**不得出现第四种色相**。
- **L3 不使用橙等异色点缀**（点缀色 5%–30% 阈值主要适用于 L1／L2 的补贴金融类等场景）。

### L3 立体与明暗口径

- 三维体量感**主要通过主体外轮廓的一圈柔和明暗过渡（边缘光／边缘暗）来体现**，**正面主视区保持均匀清亮**；允许极轻的大面积漫射，但**明暗跨度压到最小**。
- **提亮上限：+12%**（给"柔和漫射微光"留出空间，但仍远低于镜面高光）。
- **暗部上限：−15%**，暗部**只出现在底缘与背光侧边，不侵入正面**。
- 一句话口径：**L3 的立体靠"轮廓边缘的柔和明暗过渡"，不靠"正面大跨度明暗渐变"；正面越均匀通透越对。**

## 容器类专项约束（各档通用护栏）

**问题背景**：生成"橙黄补贴券盒"v1（`i-396dbu645kaw`）时，prompt 沿用了 L2 的"内嵌面允许真实通透渐变"松绑、并写了"盒口内侧呈现浅暗渐变、盒内壁偏深"，结果模型直接画出了**从上往下俯视的开口**——露出盒口开口面、盒内壁与盒底，形成真 3/4 俯视透视，触发 L2 风险刹车，判定不达标。修正版 v2（`i-d5w2v5p23a8v`）取消该松绑、改为容器只呈现外壁正面剪影 ＋ 内容物从顶边探出被外壁遮挡，视角达标。根因是"内嵌面通透渐变"这条松绑对容器类是危险的：容器要表达"容纳感"不能靠露内壁，只能靠遮挡关系。

### 规则

- 凡主体属于**容器类**（盒／袋／篮／箱／钱袋／票券夹／收纳盒／礼盒等有"可装东西"属性的物件），**无论 L1、L2 还是 L3，都只呈现容器外壁的正面剪影**。
- **盒口／袋口只是容器顶部的一条边线**：禁止看到开口面、禁止看到内壁、禁止看到盒底、禁止开口呈椭圆／圆形开口、禁止任何"从上往下往里看"的俯视透视与灭点。
- **"内嵌面允许真实通透渐变"这条 L2 松绑对容器类不生效**。该松绑的适用范围收窄为**平面内嵌面**——挡风玻璃、屏幕、窗口、镜面等本身就是平面的内嵌区域；容器内壁不在其列。
- 容器表达"容纳感／装载感"的**唯一合法手段是遮挡关系**：内容物从容器的顶边向上探出、下半截被容器外壁正面遮住，只露出上半截。内容物数量、外露比例仍受"容器＋内容物外露"合法模式的既有限制（内容物不超过两件、只做纯色块不刻画实物、外露面积不超过容器高度的合理范围）。
- 容器的体积感只靠**边缘大圆角 ＋ 柔和渐变 ＋（L2／L3 允许时）极窄的一侧厚度边**表达，**不得靠露内壁**。

## 全局硬约束：统一风格

以下规范是**固定锚点**，任何一次生成都必须完整遵守，不因主题、不因用户额外给的参考图而改变。（标注 L1 的条目为 L1 档标准；L2／L3 档按上方放开项有限松绑。）

### 材质（柔雾哑光，去塑料感，高级细腻）

参考图的真实质感是**细腻柔雾的哑光质地，像高级磨砂陶瓷／粉饼**，完全没有塑料感。必须做到：

- 表面细腻柔雾、哑光，明暗过渡极其平缓细腻，**几乎看不到硬转折面**
- 形体边缘**饱满鼓胀**，转角保持大圆角，看上去圆润充盈
- 厚度浅而干净
- 追求"**高级、细腻**"的观感

**明确禁止**：塑料感、油亮渲染光泽、金属镜面、玻璃质感、环境反射、过度光滑的完美塑料质地、不自然的完美对称、多余装饰细节、景深虚化。

**反向边界（形体）**：不干瘪、不扁平，也不臃肿浮夸、不要充气膨胀的肿感（**L3 按轻量铁律进一步收紧鼓胀度**）。

整体观感应该像**手工设计的高级柔和图标**，而不是"CG 渲染作品"或"软胶玩具"。

### 打光（无任何明显高光，但亮度不降）

- **不要任何明显的高光**：禁止点状镜面高光、禁止窄条状高光带、禁止反光斑、禁止靠上的那道亮带
- 亮度**依靠大面积柔和通透的色彩渐变本身来维持**，整体必须依然**明快清亮**，不得因去高光而发灰、发暗、发闷
- 明暗过渡极其平缓细腻，几乎看不到硬转折面
- 接触阴影浅淡，低对比、无硬边阴影

> **L3 口径**：L3 允许"边缘光／边缘暗"的**哑光大面积柔和漫射明暗**，并允许**一处弥散柔亮微光（≤ +12%）**——这不是镜面高光；点状镜面高光、高光带、反光斑仍严格禁止。详见「铁律二」。

### 视角（严格水平正视，最高优先级）

参考编组**全部是严格水平正视的纯正面剪影**。必须做到：

- **严格水平正视图**：相机与主体中心等高、光轴水平正对主体，**不俯不仰**
- **完全不显示顶面，也不显示任何侧面**——主体只呈现正面的圆角剪影，像平面贴纸一样立在画面里
- **多部件并排／堆叠时也必须保持同一水平正视线**，不得让任一部分露出立面
- **该规则覆盖到零件级**：每一个小部件（挂环、提手、扎口、袋耳、孔洞、撕口、角标、后层、底座边等）都**只呈现正面轮廓，不得露出立面厚度、内侧、环壁、孔壁**
- 形体的圆润饱满只靠**边缘大圆角 ＋ 柔和渐变**表达，**不靠可见的立体面**

**明确禁止**：3/4 透视、斜侧视角、俯角、仰角、可见顶面厚度、可见左右侧面、透视收缩、任何灭点。

> **L2 例外**：立体度一项允许"正面微侧"浅立体（侧转 ≤ 约 8°、极窄厚度边），但禁止真 3/4 透视、明显灭点、展示内部结构。小部件在 L2 放宽为"允许极窄暗示厚度"，L1 仍严格执行。**容器类不适用立体度松绑的内壁部分，见「容器类专项约束」。**
>
> **L3 例外**：允许真正的三维体量与 3/4 视角、球面／曲面明暗转折、环形部件绕主体前后遮挡；取消"侧转 ≤8°、禁真 3/4 透视、禁灭点"上限。仍禁止多灭点广角畸变、鱼眼、夸张透视拉伸、展示与主题无关的内部剖面结构。

### 全局圆润度（最高优先级硬规则，各档同标准）

本体系的一切轮廓转折都必须圆润。覆盖范围**不限于矩形四角**，明确包括：

- 多边形顶点（五边形、六边形、星形、盾形、花边牌、价签肩部等）
- 锥体与心形的尖端
- 弧线的起止端点
- 孔洞与撕口的边缘
- 所有小部件的外沿

**量化下限**：圆角半径**不得小于该部件最短边的 25%**；主体轮廓不得出现任何视觉上"尖锐／直角／硬折"的转角；**宁可过圆，不可不够圆**。

**与「轻量」的关系**：**圆角 ≠ 鼓胀**——转角要圆、面要利落瘦，不做整块充气球面（L3 尤其）。

**造型取向**：形体应当是"**饱满鼓胀的软质块面**"，而不是"硬边几何切块"。任何带尖角的传统符号形（星形、心形、价签、盾牌、皇冠）在落入本体系时，**必须先做圆化处理再使用**：

- 星形的五个角 → 改为圆头瓣
- 心形尖端 → 改为圆润收拢
- 价签的梯形肩部 → 改为连续的大弧度圆角
- 盾形下尖 → 改为圆角

**禁止**：硬折肩、锐角顶点、直角转折、平切端面、棱角分明的工业切割感，以及"圆角只作用于四角而保留其他硬边"的偷懒做法。

  - 仍禁止引入机械结构、线缆、手柄、飘带等写实配件

## 合法造型模式（两种扩展）

以下两种结构属于合法造型，不算违反"单一主体"规则。

### 模式一：容器 ＋ 内容物外露

- 允许"容器类主体（购物袋／钱袋／礼盒／票券）＋ 少量内容物从开口外露"的结构
- **容器只呈现外壁正面剪影**：盒口／袋口只是容器顶部的一条边线；禁止看到开口面、内壁、盒底，禁止开口呈椭圆，禁止俯视透视与灭点（详见「容器类专项约束」）
- **容纳感靠遮挡关系表达**：内容物从容器顶边向上探出、下半截被外壁正面遮住，只露出上半截
- 限制条件：
  - 内容物**不超过两件**
  - 内容物只做**纯色块／圆角色片**，不做实物细节刻画（不刻画商品、logo、纹理、条码）

## 常见错误（务必避免）

- **L3 偏肉（鼓胀肿感）**：反例为旧 L3 成品（`i-FlbaxDXjs3` 电池、`i-29V7p5VgqJ` 奖杯、`i-53f2c53w8fh6` 购物袋、`i-6k2v5s76brvv` 福袋、`i-7cfm8renkecq` 花边牌、`i-z8jpcpzakvbj` 手提袋、`i-zqe966rduu66`／`i-963enb8pnj2m` 票券）——形体鼓胀过度、充气肿感、软胶玩具式肉感、配件偏粗厚，分量重、不透气。正例：`i-f3TsmPTICR`／`i-a3GQ5xCS68`——形体克制、配件纤细、内凹浅、轻写实透气。
- **L3 配色随主题换色（铁律级反例）**：用 L3 出橙黄票券／橙黄手提袋等——**后果＝不交付、按铁律重做**。L3 的配色**固定为星球亮蓝 `#54AEFF` ＋ 黑灰偏蓝 `#3A3F4B`～`#33363C`**，与立体强度绑定，**不随主题换色、不继承外部参考图色相**；需要橙黄等主题色时走 L1／L2。
- **L3 材质两头跑偏**：
  - 反例一（**过亮**）：把 L3 做成有明显高光／窄条亮带／抛光塑料面——判**抛面越界**。
  - 反例二（**过平**）：把 L3 修成完全平、零微光的纯死哑光——判"**修过头、丢失立体透气感**"，同样不达标；**L3 不是 L1，不该一点光都没有**。
  - 正例：`i-FlbaxDXjs3`、`i-29V7p5VgqJ`——柔雾哑光基调 ＋ 受光面一处弥散柔亮微光，无点状高光无亮带无镜面。
- **L3 主体明暗跨度过大**：反例 `i-5f9yc4p67sw5`（电池）与 `i-ebgmaa58u866`（奖杯）正面明暗跨度过大、主体偏闷偏沉、通透度不足，判不达标。**L3 立体靠边缘过渡，不靠正面大渐变。**
- **L3 同批不一致（主体蓝不同档）**：反例 `i-ebgmaa58u866`（奖杯）顶部提亮过强、主体蓝取到区间上沿，与同批并排时明显更亮更浅更抛，判定同批不一致。
- **L3 主体蓝偏色**：主体蓝必须锚定 `#54AEFF` ±6%（以 `#54AEFF` 为中心，不取区间两端极值）；不得取 `#5FBFFF` 等上沿极浅色，不得漂入青蓝 `#35C4F5` 域、不得偏正蓝 `#2E7CF6`、不得偏紫／偏绿／泛白到近白。
- **L3 顶部集中亮区（抛光）**：微光须为无边界的大面积柔和过渡，最高不超过主色 +12%；暗部不超过主色 −15% 且只出现在底缘与背光侧边。
- **L3 白色符号发光细边缺失或过硬**：应保留"可见的柔和发光细边"（让符号亮而不硬），但不得霓虹、过曝、镜头眩光或形成集中高光带。
- **盘状展台**：反例 `i-5f9yc4p67sw5`（电池）与 `i-w3yguc9ahzwk`（购物袋）底部出现浅色圆盘展台／淡蓝白底座盘。落地感只靠贴合主体底缘的浅接触阴影表达。
- **L3 配重色用错**：L3 的配重**必须是黑灰偏蓝 `#3A3F4B`～`#33363C`，不得用同色系亮蓝或正蓝 `#2E7CF6` 充当配重**。反例 `i-mx8hteuuyshu`；正例 `i-FlbaxDXjs3`、`i-29V7p5VgqJ`。
- **L3 结构件被压平抹掉**：识别性结构件（帽盖／双耳／杯颈／台阶底座／星环／提手／天线／旋钮等）必须完整、有体积地呈现，不得为压平而缩小或抹掉；**但须按轻量铁律做细做浅**。
- **L3 失控**：把 L3 做成塑料镜面球、带点状高光／高光带、渐变背景、主体色漂出锁定域、出现景深虚化等——均判定"滑成写实 3D 渲染／塑料玩具"，退回 L1／L2 或重做。
- **容器俯视开口**：反例 `i-396dbu645kaw`（橙黄补贴券盒 v1，盒口俯视开口、露出内壁与盒底，触发 L2 风险刹车）；正例 `i-d5w2v5p23a8v`（券从顶边探出、外壁遮挡、无内壁）。
- **圆润度不足**：`i-gcmk7jpy3f65`（折扣价签-双层错叠）牌体肩部呈两个明显硬折角、整体偏方偏硬，判定圆度不达标；需按「全局圆润度」重制为肩部连续大弧度圆角、轮廓整体圆润饱满。
- **白色符号做成 3D 立体件**：有厚度、有侧面、有内凹浮雕边的塑料贴片（反例：早期"新能源电池"的白色闪电）。
- **符号占比过大**：早期版本白色闪电／`¥` 符号占比过大，轻盈感丢失。
- **视角出现透视**：多部件图标（领奖台、奖杯等）被做成 3/4 透视、露出顶面与侧面。反例：领奖台图标三块台面全部露出顶面与侧面、呈 3/4 透视，判定不合格；修正版 `i-d4tvf3dctsz7` 只保留正面剪影、层次改由三档明度差承担，达标。
- **小部件露出厚度／内侧**：反例一 `i-6a8sd2w6u7hn` 顶部橙色挂环做成了立体环，露出环壁厚度与内侧；反例二 `i-haanaaj3rnma` 票券撕口凹槽露出孔壁厚度。
- **`¥` 字形不达标**：以下图标的 `¥` 均为笔画偏细、横杠偏短的标准字体，需按「货币符号 ¥ 的统一字形」重制：商城补贴购物袋 `i-2a9exjybhdmx`、福袋 `i-n3u5r7wba53y`、礼盒 `i-g8hsn2dmqcbm`、国家补贴券 `i-vd98kqwb27vs`、凭证卡 `i-rcusvb6skdwr`、钱袋 `i-pfdpw25b2neq`。

## 生成后复检清单

1. **档位判定**（三档）：本次档位是否与主题性质匹配？同批是否同档？L3 是否误用于需要橙黄等主题色的主题？
2. **L3 配色铁律（仅 L3，置顶硬判据）**：**配色是否恰为亮蓝 `#54AEFF` ±6% ＋ 黑灰 `#3A3F4B`～`#33363C` ＋ 白三色**？**有无任何第四色相**？**有无被主题语义或外部参考图带跑换色**？配重是否未用亮蓝／正蓝？
