# 黑白水墨动作插画：提示词指南

## 风格要点

这类画面像一帧具有电影感的二维动作动画：纯黑、白与炭灰构成强烈明暗；人物用有粗细变化的墨线和干刷笔触塑造；头发、衣物、烟尘和动作线朝明确方向飞扬；亮部以少量锋利的白色笔触提神。轮廓不必处处闭合，部分边缘可以融入墨雾或暗部。画面要保留手绘感和清楚的视觉焦点，避免照片感、3D 金属渲染和过度平滑的数码渐变。

参考图里的人物是长发、盔甲、近景，这些只是那张图的内容，不是每张新图都必须照搬。换成其他人物或场景时，只保留黑白墨绘、强反差、笔触和动势等风格特征。

## 中文正向提示词模板

```text
【主体与外观】，【正在进行的动作】，【场景与关键道具】。【景别、视角与构图】；【表情或情绪】。
画面采用电影感二维黑白动作插画风格，像手绘动作动画中的关键帧。纯黑、白与炭灰的有限灰阶，强烈明暗对照，明确的侧向光线，深黑投影与干净锐利的白色亮部。富有表现力的粗细变化墨线、干刷飞白、破碎笔触与少量刮擦纹理；头发、衣物、烟尘和动作痕迹顺着运动方向挥扫，形成有力的斜向节奏。人物轮廓和面部表情清晰可读，背景用简洁墨雾、速度线或留白衬托主体。保留纸面与墨迹质感，画面有冲击力但主体不被特效遮挡。遵循本次描述的主体、动作和构图。
```

## 中文负向提示词

```text
彩色画面，照片写实，3D 渲染，游戏建模质感，镜面金属，塑料皮肤，柔光美颜，平滑渐变，矢量图标，均匀描边，过度干净的线稿，低对比度，杂乱背景，过多细碎装饰，特效遮住脸部，五官模糊，脸部畸形，多余肢体，多余手指，文字，字幕，标志，水印
```

## 参考图使用方式

若软件支持上传风格参考图，可把参考图作为风格参考，并补一句：

```text
只参考这张图的黑白墨绘质感、强烈明暗关系、干刷笔触和动作张力；人物身份、服装、场景、镜头和构图以文字描述为准，不要复刻参考图中的角色。
```

不同生图工具对提示词、负向提示词和参考图的处理方式各不相同。若结果太像照片，增加“二维手绘、墨线、干刷笔触”；若画面太乱，减少烟尘和速度线，并明确“脸部清楚、主体轮廓完整、背景简洁”。
