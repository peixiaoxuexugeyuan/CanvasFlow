## 二、第 1 阶段：剧本解析与分场分镜表

### 2.1 识别剧本格式

本类剧本的固定格式，解析时必须逐项识别、不得丢项：

- **分集**：以「第N集」划分。
- **场号**：集内以「N-M」编号（如 1-3）。
- **场头三行**：
  - `景：` 地点（如 海上 小渔船 / 渔村 海岸 / 何家 石屋 外间 / 里间）
  - `时：` 夜/日 + 内/外
  - `人：` 本场出场角色
- **正文**：
  - `△` 开头 = 动作与画面叙述
  - `角色名：（情绪/表演提示）台词内容` = 台词行

### 2.2 括号表演提示必须保留利用

台词括号里的提示是**表演依据**，不是可省略的注释。必须原样提取并转写为第 3 阶段的表演说明。典型提示词（按剧本实际出现提取，以下为示例）：

（微弱）（惊疑）（倒吸一口气）（喃喃）（尖声）（越说越气，拍着大腿）（断然）（嘴硬）

**规则**：

- 括号提示 → 转为该镜头的**表演起点**，并据此推导微表情、呼吸、重心变化。
- 台词本身**逐字保留，不得 paraphrase、不得改写、不得省略**。
- 括号提示不得进入台词文本，只进入表演说明。

### 2.3 情绪弧线逐场标注（强制）

**每场必须写「情绪起点 — 转折 — 落点」三段式。** 情绪必须服务剧情，不得为表演而表演。

人物弧线按剧本实际出场提取。以《文鳐》为基准的既定弧线：

角色弧线文鳐鱼海中守护神兽，鱼身鸟翼、通体金鳞；被风暴与渔网所困、内元虚弱；一生只哭三颗泪珠，每颗损耗本源；赠珠报恩，遇背信则警告、渐趋冷厉何水生赤贫渔户、孝子；起初「不要钱财只求救母」；经逼迫与贪念侵蚀，从恳求、羞愧转为恼火、嘴硬，走向失控；弧线：算计→贪婪→恐惧→失控林氏何水生之母，久病蜡黄，被归墟珠治愈后返老还童；醒转即算账，为一颗珠子的价值掌掴儿子、坐地嚎哭、以头撞墙相逼；强势、利益驱动、慌乱又泼辣周村长威严→算计→狂热→恐惧阿澜善良、坚韧、悲痛

> 运行时以剧本实际出场角色与台词提示为准；上表是基准，不是硬编码清单。

### 2.4 关键设定物识别

按剧本实际提取并**严格区分、不得混用**：

- **归墟珠**：文鳐鱼泪所化，月白柔光、晶莹温润的珍珠，表面有细腻内部流光；可换万贯家财或生死人肉白骨。
- **千年内丹**：凝练纯粹的金色能量光球。**与归墟珠严格区分，颜色绝不可混淆。**

### 2.5 场景池

按剧本实际提取。基准场景池：海上小渔船、礁石浅滩、渔村海岸、何家石屋（外间水缸／里间木板床）、海塘街巷、海神庙。

### 2.6 分镜表字段（每镜一行）

镜号 / 场号 / 景别 / 机位角度 / 运镜 / 时长 / 画面内容（△转写）/ 出场角色 / 台词（逐字）/ 表演说明（括号提示转写）/ 情绪起点-转折-落点 / 特效要点 / 连续性继承项 / 音效。

## 四、第 3 阶段：逐镜视频提示词

**每镜提示词固定五段结构**，缺一不可：

1. **表演段**（微表情与微动作）
2. **动作段**（物理逻辑）
3. **特效段**（分级用法）
4. **运镜段**（电影级镜头语言）
5. **连续性段**（继承上一镜状态）

### 4.1 表演层：微表情与微动作清单

**表演自然克制，重点在微表情与微动作。** 每镜至少落实 2–3 项：

- **眼神**：焦点变化、瞳孔收缩、视线游移/回避/定住、眼睑下垂、眼眶泛红、泪光积聚不落
- **眉头**：轻蹙、紧锁、瞬间舒展
- **嘴角**：收紧、下压、抽动、强撑笑意、抿唇
- **吞咽**：喉结滚动、干咽、被噎住
- **呼吸**：起伏加快/变浅/屏住、胸腔起伏、鼻翼翕动、叹息
- **手指**：蜷曲、抓紧、指节发白、无意识搓动、颤抖
- **身体重心**：前倾/后仰、重心下沉、踉跄、僵住、后退半步

**情绪必须服务剧情弧线**，每镜写清「情绪起点—转折—落点」。

### 4.2 动作层：打戏与肢体冲突的物理逻辑

适用于掌掴、拉扯、跪地、抱持、翻船、挣扎、摔倒、逃生等。

- **人体骨骼结构**：关节活动范围真实，不反关节、不肢体粘连、不手部畸形。
- **四段式**：每个动作必须有 **启动 — 运动 — 减速 — 停止** 的完整过程，不得瞬间到位。
- **重心与惯性**：发力前重心先转移；受击后身体按受力方向移动、有回弹与余震；衣摆、发丝、随身物件有真实惯性。
- **接触关系**：掌掴有接触点与面部受力变形；拉扯有手部抓握与布料牵拉；跪地有膝盖与地面接触；抱持有身体贴合。**不穿模、不滑步、不穿透。**
- **地面关系**：脚掌与地面接触真实，不漂浮、不失重。

### 4.3 特效层：玄幻粒子分级用法

**华丽但有层次、克制不廉价。** 按强度分三级，按剧情需要选用，禁止满屏无规律粒子。

级别用法元素L1 环境级常态氛围，最克制细小灵光粒子（少量）、柔和光晕、空气透视L2 交互级神异物出现/被触碰真实折射、能量波纹、水下光束、水体扰动、珠体内部流光L3 爆发级剧情高潮，短时集中灵光汇聚、光柱、能量扩散环；**必须集中在视觉主体，不得铺满全屏**

**流体与海啸灾难特效的递进节拍（严格按序，不得跳步）：**

1. 水面震荡
2. 鱼群异动
3. 海风增强
4. 浪头抬升
5. 环境声音变化
6. → 发展为巨浪
7. → 发展为海啸

巨浪必须有真实体积、速度、惯性、泡沫、飞溅水滴与冲击力；人物、木船、渔网及周围物体受海浪影响必须符合物理逻辑。禁止水体瞬间无规律生成、浪潮方向前后矛盾、人物漂浮失重、物体穿透或灾难特效缺乏空间尺度。

### 4.4 运镜层：电影级镜头语言

**按场景类型选配方：**

场景类型运镜配方人物情绪镜头稳定缓慢推进、细微侧移、精准焦点变化对峙场面强调人物视线关系、空间距离与构图张力；过肩镜头；正反打文鳐鱼神异出场有节制的环绕、跟随与纵深运动海啸场面逐步拉远、低机位追随、横向移动、大尺度全景展现灾难规模

**通用规则**：

- 构图有明确主体与前景、中景、背景层次。
- 合理使用特写、近景、中景、全景、远景、低角度、高角度、俯拍、仰拍、过肩镜头。
- 所有镜头运动平滑、连贯且**有明确动机**。
- 保持人物屏幕方位、视线方向、动作衔接与空间位置连续。
- **禁止**：无意义旋转、突然变焦、镜头抖动、无原因跳轴、不符合空间逻辑的瞬移。

### 4.5 连续性层：每镜必须继承上一镜

每镜提示词必须显式声明继承以下 6 项：

1. 人物状态（情绪、伤势、湿身、呼吸）
2. 道具位置
3. 服装状态
4. 环境光线
5. 海面状态
6. 事件进度

## 五、第 4 阶段：合成

- 分镜顺序按分场分镜表。
- 转场方式：以**动接动、视线接视线、动作接动作**为主，硬切为主，避免无动机花式转场。
- 节奏表：标注每镜时长与情绪曲线，高潮段（海啸、神异出场）可适度延长。
- 音画对位：台词口型与音频对齐；特效节拍与音效对齐。

## 六、全局画面规范（十段，必须完整执行）

### 【整体画面风格】

高质量国风3D动漫电影风格，东方写实CG与中国古代海洋神话美学相融合，影视级3D动画制作水准，电影级角色建模与场景渲染，整体画面精致、真实、唯美且具有东方神话的神秘感。采用自然真实的人体比例与精细的东方五官设计，人物皮肤具有细腻的SSS次表面散射效果，保留真实皮肤纹理、自然面部细节与细微表情变化；头发具有清晰的发丝分组、自然飘动与真实的物理惯性；服装采用符合古代中国沿海渔村生活背景的交领衣袍、粗布衣裙与传统发式，布料纹理清晰，褶皱自然，材质具有真实的物理质感，避免现代服装、现代发型及不符合时代背景的装饰。

### 【时代与美术统一】

整体采用中国古代架空渔村世界观，建筑、街巷、木船、渔网、木桶、陶罐、木制门窗、石阶、海塘、渔村民居与海神庙统一遵循古代中国传统建筑和生活器物的视觉逻辑。建筑以木材、石材、夯土和传统瓦片为主要材质，保留自然使用痕迹与生活质感，既有真实的沿海渔村氛围，也具有电影级美术设计。村庄不能一味破败，贫民住宅、普通民居、村长住处、商铺和海神庙应当在建筑规模、材料、整洁程度与陈设上体现合理差异。严禁出现现代玻璃幕墙、现代路灯、塑料制品、现代电器、现代交通工具及其他现代生活元素。

### 【角色统一】

所有人物保持稳定的面部结构、五官比例、年龄感、身材、发型、服装颜色与服装结构。人物动作符合真实人体骨骼结构与物理规律，表演自然克制，重点表现眼神变化、眉头轻蹙、嘴角收紧、吞咽、呼吸起伏、手指动作、身体重心变化等细腻微表情与微动作。人物情绪必须服务于剧情：阿澜表现善良、坚韧与悲痛；何水生表现从算计到贪婪、恐惧和失控的递进；林氏表现强势、利益驱动与慌乱；周村长表现从威严、算计到狂热和恐惧的变化。禁止角色无理由改变外貌、年龄、发型、服装或身材，禁止人物脸部漂移、五官错位和动作僵硬。

### 【文鳐鱼与奇幻视觉】

文鳐鱼始终保持统一的东方神话异兽形态，以修长鱼身、精致鳞片与层次清晰的羽翼为核心特征，生物结构自然，游动、转身、摆尾、振翼与浮沉动作符合水下运动规律。正常状态下鳞片光泽温润、羽翼完整、灵光柔和；衰弱状态下鳞片逐渐黯淡、羽毛受损、动作无力；濒死状态下仅保留微弱金色灵光，形成连续的视觉变化。归墟珠统一为晶莹温润的月白色珍珠，表面具有细腻的内部流光；千年内丹统一为凝练纯粹的金色能量光球，与归墟珠严格区分。奇幻特效采用精致、克制、有层次的电影级CG效果，包括细小灵光粒子、柔和光晕、真实折射、能量波纹、水下光束与水体扰动，避免廉价游戏特效、过度曝光、满屏光效及无规律爆炸。

### 【场景光影与色彩】

采用电影级布光与自然环境光照逻辑，强调主光、环境光、轮廓光之间的协调关系。日间沿海场景以自然日光、海面反射光与柔和空气透视为主；室内场景以门窗透入的自然光、油灯或火把的暖光为主；夜间海边以冷色月光、深蓝环境色和局部暖色火光形成冷暖对比；神异场景以月白色归墟珠光与金色内丹光作为视觉重点。整体色彩统一、层次丰富、明暗关系明确，保留暗部细节与高光层次，避免过度饱和、死黑阴影、惨白过曝及廉价滤镜效果。海水呈现自然的深青、蓝灰与银白反光，浪花具有真实的透明度、泡沫结构和水体厚度。

### 【海洋与灾难特效】

海水、浪花、鱼群、暴雨、海雾与海啸均采用电影级真实流体模拟效果。海面具有符合风力、潮汐和船只运动的波浪变化，鱼群受到歌声吸引时，应形成由远及近、逐步汇聚的运动层次；文鳐鱼歌声引发异常潮汐时，先表现水面震荡、鱼群异动、海风增强、浪头抬升与环境声音变化，再逐渐发展为巨浪和海啸。巨浪具有真实的体积、速度、惯性、泡沫、飞溅水滴与冲击力，人物、木船、渔网和周围物体受到海浪影响时必须符合物理逻辑。禁止水体瞬间无规律生成、浪潮方向前后矛盾、人物漂浮失重、物体穿透或灾难特效缺乏空间尺度。

### 【摄影与运镜】

采用电影级摄影语言，画面构图具有明确主体、前景、中景和背景层次。根据剧情合理使用特写、近景、中景、全景、远景、低角度、高角度、俯拍、仰拍与过肩镜头。人物情绪镜头以稳定的缓慢推进、细微侧移和精准焦点变化为主；对峙场面强调人物视线关系、空间距离与构图张力；文鳐鱼的神异出场采用有节制的环绕、跟随与纵深运动；海啸场面采用逐步拉远、低机位追随、横向移动与大尺度全景展现灾难规模。所有镜头运动平滑、连贯且有明确动机，保持人物屏幕方位、视线方向、动作衔接与空间位置连续。禁止无意义旋转、突然变焦、镜头抖动、无原因跳轴和不符合空间逻辑的瞬移。

### 【动画与物理规律】

人物动作具有合理的启动、运动、减速与停止过程，身体重心、衣摆、发丝和随身物件具有真实惯性。奔跑、摔倒、挣扎、拉扯、跪地、抱持与逃生动作必须符合人体结构和地面接触关系。水下生物受到水流阻力影响，羽翼、鱼尾与身体动作相互协调。所有角色与道具保持正确的接触关系，不出现穿模、滑步、肢体粘连、手部畸形、道具无故消失、物体穿透或动作瞬间跳变。

## 七、执行流程

1. 读取剧本全文，识别分集、场号、场头三行、△叙述、台词与括号提示。
2. 提取出场角色、场景、关键设定物；为每个对象建立锚点图提示词。
3. 逐场标注情绪弧线（起点—转折—落点）。
4. 逐场拆镜，填写分镜表全部字段。
5. 逐镜生成五段式视频提示词（表演/动作/特效/运镜/连续性）。
6. 每镜完成后校验：台词是否逐字保留、括号提示是否已转为表演说明、连续性 6 项是否声明、是否触碰禁止清单。
7. 输出合成方案（顺序、转场、节奏、音画对位）。
8. 全片通检：角色一致性、设定物区分、物理逻辑、镜头连贯、色彩统一。
