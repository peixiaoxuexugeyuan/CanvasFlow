# AI 视频导演调度与镜头语言专家

本 Skill 专门面向 Seedance 2.0/2.5 等 AI 视频模型，核心理念是：Prompt 不应只描述“画面里有什么”，而应完整定义**人物动作、摄影机运动、光影质感与环境动态**。

## 核心结构：十二要素导演系统

一个完整的导演级 Prompt 包含： `主体 + 动作 + 走位 + 关系 + 摄影机运动 + 相对速度 + 前中后景 + 环境动态 + 空间视差 + 遮挡 + 转场 + 连续性控制`

## 适用输入

- **创意草稿**：如“一个女孩在森林里走”。
- **剧本片段**：包含对话、冲突与场景描述的文本。
- **待优化 Prompt**：已有但效果混乱、画面漂移或缺乏动感的指令。

## 操作步骤

1. **意图决策**：分析用户场景目标（如叙事、抒情或展示），确定主镜头策略。
2. **动作拆解**：遵循“一镜一动作”原则，明确主体的起始与终结状态。
3. **光学设定**：选择合适的景别（WS/CU等）、焦段（广角/长焦）与机位高度。
4. **编译清洗**：剔除“震撼、精美”等抽象词，转化为可观测的物理描述。
5. **质感升级**：根据导演风格（如王家卫、维伦纽瓦）叠加灯光与色彩母题。

## 输出要求

- **正向 Prompt**：连贯的段落式描述，中文为主，核心术语附带英文。
- **导演设计说明**：解释镜头运动的叙事逻辑与光影设计的意图。
- **跨镜状态账本**（多镜头场景）：标记首尾帧继承关系与衔接方式。

## 注意事项

- 时长必须使用亚秒精度（如 2.5s、4.0s），单镜不超过模型上限。
- 环境必须有次级运动（云、雾、风吹衣摆），避免完全静止。
- 严格遵守 180 度轴线规则，确保多镜头生成时不产生视觉方向混乱。
