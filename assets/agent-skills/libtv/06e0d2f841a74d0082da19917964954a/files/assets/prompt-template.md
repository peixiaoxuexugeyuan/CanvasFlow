# Seedance 2.0 / 2.5 导演 Prompt 模板

可直接复制使用。生成输出时将【】占位符替换为具体内容，并改写为连贯段落。

---

## 模板一：单镜头七层导演 Prompt

```
【主体与场景】
主体：___（人物/产品/建筑/生物）
场景：___（地点、时间、天气、光线氛围）
主体位置：___（画面中央/左侧/右侧，前景/中景/远景）

【第一层：人物动作】
___（明确动作 + 方向：从左向右/向镜头/远离镜头/沿纵深）
动作速度：___（缓慢/平稳/中速/快速）
微运动：轻微呼吸、自然眨眼、细微重心转移（防僵尸式静止）

【第二层：人物走位】
___（入画方向 → 运动路径 → 停留/出画位置）
人物关系（多人物时）：___（面对面/追逐/围绕/聚拢，保持稳定距离关系）

【第三层：摄影机运动】
主镜头：___（推/拉/摇/移/跟/升/降/环绕/穿越/变焦/甩镜/希区柯克变焦，仅选1个）
辅助运动：___（0~2个，如轻微环绕/轻微变焦）
景别与机位：___（EWS→ECU + 平视/仰拍/俯拍 + 35mm/50mm/85mm）
人物与摄影机速度关系：___（如"人物向前走，摄影机同步向后跟拍保持稳定距离"）

【第四层：环境动态】
___（至少2~3种：云层缓慢流动、衣摆随风摆动、光束缓慢移动、粒子漂浮）

【第五层：前后景配合】
前景：___（树枝/花瓣/烟雾/人物/建筑/光影，最好产生运动）
中景：___（主体）
背景：___（远山/城市/天空/云海）
空间要求：前中后景形成明确空间层次与自然视差；前景偶尔掠过镜头形成自然遮挡。

【第六层：转场】（多镜头序列时）
进入下一镜头：___（前景遮挡/人物擦镜/烟雾遮挡/穿越空间/甩镜/动作匹配/光影变化）

【第七层：连续性与稳定性】
整体动作连续自然，运动轨迹稳定，符合真实物理规律；
摄影机运动平滑稳定，不出现突然跳跃和不自然位移；
保持人物身份、比例、服装、发型一致，保持建筑结构与空间透视稳定；
保持光影方向与运动方向一致，避免人物变形、突然位移、瞬移、镜头跳跃和不自然加速。
```

## 模板二：多镜头分镜表

镜号时长(s)景别/机位主动作（每镜头仅1个）主镜头运动辅助运动前景/中景/背景环境动态转场（进入下一镜）完整Prompt013.0s远景/低机位\_*\_推轻微环绕\_**\_前景树枝遮挡\___022.5s中景/平视\_\_跟—\_**\_人物擦镜\___034.0s特写/平视\_\_推轻微变焦\_*\_\_*\_甩镜\_*\_

**时长设定规则**（必读，决定节奏生死）：

- 单镜时长建议 **2–5s**（快节奏短剧 2–4s，极少 &gt;6s）；用**亚秒精度**（如 2.5s / 3.0s / 4.0s）控制节奏，不要用整 2 秒块。
- **单镜时长须 ≤ 生成模型单次最大时长**（Seedance 通常 5s / 10s）；超过须拆镜或分段生成后拼接，不要写 15s 单镜。
- 相邻镜时长须有**起伏**（如 3.0→2.5→4.0），禁止全 5s 的平板节奏；钩子镜可压到 1.5–2.5s 抢注意力。
- 时长与剪辑切点对齐：每个时长终点 = 一个明确的 Cut Point，不要在镜中"空转"。

分镜三查：

1. 方向连续：相邻镜头人物运动方向不无故反转（180度规则）
2. 外观一致：人物服装/发型/建筑结构跨镜头一致
3. 转场闭合：每个镜头结尾 = 下一个镜头的转场入口

## 模板三：图生视频衔接六句式（I2V，多镜接力用）

```
① 首帧锚定：保持首帧中的【人物/服装/发型/构图/光位/色彩基调】完全不变，
② 运动启动：随后【主体】以【速度】向【方向】【动作】，
③ 镜头声明：摄影机【完全固定/缓慢推进/同步后退跟拍/平行横移】，与主体保持【距离关系】，
④ 环境激活：同时【2~3项环境微动】，
⑤ 收束定型：动作结束时【结束姿态与构图】稳定停住，为下一镜留出可延续状态，
⑥ 一致稳定：全程人物身份、比例、服装、发型一致，光位方向与色彩基调不变，运动轨迹连续自然。
```

规则：图里已有的不再描述（重复描述 = 模型重绘 = 换脸）；首帧取动作 60\~70% 中段，不从静止起步。

## 模板四：跨镜交接分镜表（图生视频链式生成）

镜号首帧来源首帧评级主动作摄影机End State（姿态/方向/景别轴/光色/道具/环境/情绪）尾帧评级下一镜接法Prompt 增量关键词01母图生成—\_________A/B/C/DT2 动势交接从运动进行中继续，保持向【X】0201尾帧A_________A/B/C/DT3 遮挡桥接遮挡物移出，揭示\___03母图回注—\_________A/B/C/DT4 出画入画从画【左】入，向【右】走

衔接三查：

1. 接缝七要素：姿态/方向/景别轴/光色/道具/环境/情绪（各 0-2 分，≥8 分可直接，≤4 分重设计）
2. 30 度法则：相邻镜机位角度差 ≥30° 或景别跳 ≥2 级（否则像跳切）
3. 方向接力：出画方向 ↔ 入画方向匹配（右侧出画必须左侧入画）；每 3\~5 镜做一次锚点回注

## 模板五：时间轴式（长镜头/复杂动作）

```
0.0–1.5s：___（建立空间，如：远景固定机位）
1.5–3.0s：___（人物进入，如：跟拍）
3.0–4.5s：___（摄影机变化，如：缓慢推进）
4.5–6.0s：___（人物动作节点，如：转身 + 移焦）
6.0–7.5s：___（环境/背景揭示，如：升镜）
7.5–9.0s：___（视觉高潮，如：环绕）
9.0–10.0s：___（收束停留，如：Hold Shot）
稳定性：全程动作连续自然，摄影机运动平滑，保持主体一致性。
```

规则：单镜头总时长须 **≤ 生成模型单次最大时长**（Seedance 通常 5s / 10s），超长须分段生成后拼接；时间轴用**亚秒精度**（.0 / .5 节点）控制节奏，禁止整 2 秒块的粗放切分；每个时间节点对应一个明确的"动作 / 摄影机"变化，不要空转。
