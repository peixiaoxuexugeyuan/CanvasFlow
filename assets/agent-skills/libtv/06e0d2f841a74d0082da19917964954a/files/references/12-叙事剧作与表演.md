# 12 叙事剧作与表演词库

解决"画面很美但没有故事""情绪一条线""对白很深但人物空"——AI视频最常见的假深度问题。本词库包含：叙事七层结构、因果链公式、结构法、场景设计公式、信息控制、人物弧线、关系动力学、对白潜台词、表演八层、情绪强度分级、母题系统、叙事变量、Master Prompt、假深度修复。

**核心原则：表演不是做表情，情绪是内部结果，行为是可被摄影机观察到的证据。**

## 叙事七层结构（深度自检）

表层事件（发生了什么）→ 因果层（为什么发生）→ 欲望层（谁想要什么）→ 关系层（权力/依赖/误解在变化）→ 主题层（讨论什么价值冲突）→ 潜台词层（说的不是全部）→ 余韵层（结尾后观众继续思考）。

## 因果链公式（每个镜头的叙事骨架）

`状态 → 刺激 → 选择 → 行动 → 结果 → 新状态`

模块定义常见错误AI写法示例状态人物/世界当前平衡只写地点不写关系状态两人互不信任，桌上留着未拆的信刺激迫使反应的新信息凭空转折门外传来三次固定敲门声选择面对代价后的决定只发生事件人物没选择她没有开门，先把戒指藏进袖口行动选择外化为行为动作只是装饰她熄灭烛火并后退三步结果行动造成的新变化结局被下一镜取消门被撞开，她失去藏匿时间新状态进入下一段因果链每场戏回到原点她必须从逃跑改为对峙

**AI生成最容易出现"漂亮但没有因果"的镜头——每个镜头都应能回答：当前什么状态？什么打破状态？人物做了什么？产生什么不可逆后果？**

## 剧作结构法速查

结构适合核心节点AI应用三幕商业叙事、短片建置—对抗—解决快速规划全片五幕人物成长、悲剧开端—上升—转折—崩溃—结局强化中段复杂度八序列90-140分钟每序列有目标与小高潮分段生成与剪辑英雄旅程成长冒险神话召唤—试炼—危机—归来东方神话/修仙题材碎片/倒叙悬疑心理信息重排而非事件重排建立时间轴和观众知情矩阵环形回环寓言宿命结尾重新定义开头重复意象产生意义变化

## 场景设计公式

一场戏≠有对白的地点。高质量场景必备：**场景目标+关系目标+阻力+信息变化+选择+视听记忆点+退出状态**。

变量问题技法场景目的删掉这场戏故事损失什么？信息损失测试/因果损失测试角色目标谁主动想得到什么？主动角色原则阻力谁/什么阻止他？人、制度、时间、空间、身体、信息反目标另一方想阻止什么？目标对撞而非单向表达升级冲突是否越来越贵？代价递增、时间压缩、空间收窄转折观众判断在哪里被修改？Reveal / Reversal / Reframe出口人物离场时什么新状态？状态必须改变

## 信息控制（观众知道多少）

模式观众信息量效果适用神秘型比人物少悬念、猜测悬疑、恐怖戏剧型与人物同步共情、期待人物片讽刺型比人物多焦虑、黑色幽默喜剧、犯罪延迟揭示先现象后原因重新解释前面记忆、家庭、历史错位揭示先事实后动机道德判断摇摆反英雄、复杂关系

### 角色六维卡

维度写到什么程度示例表面目标公开追求找到失踪弟弟真实需求真正要学的接受弟弟拥有独立人生核心恐惧最怕失去什么被再次抛下错误信念导致错误选择的认知"控制别人才能留住别人"底线什么条件下突破自己弟弟面临真实危险转变方式通过哪些不可逆事件改变失去控制后主动放手

### 弧线四类与视觉化

类型变化AI视觉化方法正向弧线错误信念被修正动作越来越主动、空间越来越开放负向弧线恐惧/错误信念强化镜头越来越封闭、重复动作越来越严重平坦弧线人物不变，世界被改变角色成为价值锚点循环/悲剧看似改变回到原点重复同一意象但语义反转

### 关系动力学（写成向量不写标签）

不写"朋友/敌人/夫妻"，写动态变量：**信任、控制、依赖、羞耻、亏欠、竞争、吸引、恐惧**。每场戏至少改变一个变量。

关系变量正向负向AI视觉提示信任主动透露秘密隐藏信息距离缩短、遮挡减少控制命令并执行失去控制站位高低、通道封锁依赖等待对方许可被迫服从跟随、停顿、回望羞耻回避目光自我暴露脸被物体遮挡、动作缩小吸引主动接近欲言又止共同构图、视线交汇敌意试探攻击前景切割、空间对撞

## 对白与潜台词

**对白三层**：表层（说了什么）→ 意图层（要达成什么）→ 潜台词层（不愿直说什么）。判断标准：删掉这句对白，动作/停顿是否仍能表达？

**信息七通道**：把信息拆给对白、动作、视线、道具、声音、空间、剪辑——七通道越互补越有电影感，对白不要承担所有信息。

**无对白叙事工具库**：看门把手不看人（回避关系）｜反复整理同一件物品（焦虑外化）｜准备开口改成喝水（压抑表达）｜走进光里又退回阴影（心理立场变化）｜声音先出现画面后出现（观众先获威胁信息）｜物件放错位置（伏笔）。

## 表演八层（写人物动作时逐层自查）

层级核心问题可视化元素目标我现在要从对方那得到什么？靠近、阻止、试探、说服策略我打算怎么得到？讨好、威胁、回避、诱导身体身体是否支持语言？重心、肩颈、手部、脚步目光我真正想看哪里？看人、看物、躲开、偷看语气语言如何改变意思？快慢、音量、尾音、气息节奏什么时候停？停顿、抢话、延迟回答潜台词没说出来的是什么？动作替代语言关系反应对方一动我如何改变？微反应、呼吸变化、姿态变化

## 情绪强度分级（1-5）

**情绪强度≠表情强度。** 高手用低强度演高情绪：

强度表演方式AI描述1/5极微变化呼吸轻微变化、视线停留0.5秒2/5身体小动作手指收紧、吞咽、短暂回避3/5动作与语气改变语速变化、重心前移4/5明显失控声音裂开、步态紊乱、呼吸急促5/5爆发/崩溃喊叫、哭泣、倒地、剧烈动作

**表演节奏曲线**：不要一个镜头同一情绪到底。真实电影表演="进入—压制—泄漏—重新控制—决裂"。AI提示应**指定变化节点**而非只写"悲伤"：`开头克制（2/5）→中段手指收紧泄漏（2/5转3/5）→结尾下颌绷紧重新控制（3/5回落）`。

## 视觉母题系统

叙事深度来自重复出现并改变意义的视觉/声音/动作。母题必须有"**首次定义—中段变形—结尾重解释**"：

母题第一次中段变化结尾意义门阻隔人物开始主动开门选择与自由水平静被污染/暴雨创伤被释放镜子自我确认镜中出现差异身份重构火温暖失控燃烧爱与毁灭双义钟秩序停止/错时时间与死亡

## 叙事 Master Prompt 模板（可复制）

```
【项目主题】明确主题句与核心价值冲突。
【故事状态】当前世界处于什么状态，什么事件打破平衡。
【人物目标】主角此刻具体想得到什么；阻力是什么；失败会失去什么。
【潜台词】人物嘴上说什么，心里真正想说什么。
【行为】用具体动作表达关系与情绪，不依赖夸张表情。
【关系变化】本镜头前后，信任/控制/依赖/敌意/亲密至少改变一项。
【空间叙事】场景中的建筑、光线、道具、站位体现阶层、历史或心理。
【服化道连续】继承上一镜头的服装、发型、妆容、伤口、污渍、道具状态。
【声音】对白、呼吸、环境、动作音、设计声音、音乐分别描述；指定声源距离与进入时间。
【摄影】画幅、景别、焦段、机位、运动、景深、镜头节奏。
【剪辑连接】明确与上下镜头的动作/视线/声音连接点。
【情绪曲线】开始强度→中段变化→结尾状态。
【结尾】镜头必须停在可用于下一镜头的清晰状态。
【禁止项】禁止人物身份漂移、服饰漂移、空间重构、无因果动作、无目的表演、随机镜头运动、随机新增道具、随机改变时间天气。
```
