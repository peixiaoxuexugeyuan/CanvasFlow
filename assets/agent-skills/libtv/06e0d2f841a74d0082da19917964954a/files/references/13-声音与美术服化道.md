## 美术设计：让空间参与叙事

### 世界观视觉圣经

模块内容时代年代、科技水平、社会制度地域地理、建筑、材料、气候社会层级不同阶层空间尺度与材质文化系统纹样、宗教、符号、禁忌色彩规则主色、禁色、权力色空间规则门、窗、走廊、楼梯、庭院如何构成叙事老化规则哪些物件新、哪些旧、谁在维护

### 场景叙事五层

1. **功能层**：人物在这里做什么
2. **社会层**：谁拥有这个空间（医院走廊=体制所有，谈漾只是过客）
3. **心理层**：空间让人物舒服还是压迫
4. **时间层**：空间承载过什么事件（墙上的旧痕、磨痕的地面）
5. **象征层**：这个空间代表什么价值（铁笼=囚禁，急诊门=生死边界）

### 空间连续性规则

系统规则动线人物从哪来往哪去必须可追踪入口/出口重要场景至少一个可退出通道视觉锚点每空间设2-4个固定参照物尺度门高、桌宽、人物与建筑比例稳定空间声场同一空间混响与底噪一致光源逻辑窗、灯、火、霓虹方向可解释
