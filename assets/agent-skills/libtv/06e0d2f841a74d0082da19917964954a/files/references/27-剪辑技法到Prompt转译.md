# 27 剪辑技法到 Prompt 转译词库

把「用户描述的剪辑技法 / 后期手法」翻译成 AI 视频生成（Seedance / I2V）**生成期可执行的 Prompt 约束**。这是 ai-video-director 技能里唯一一层「剪辑语法 → 生成控制」的转译层。

## 0. 为什么需要这一层（核心理念）

传统剪辑发生在**时间线 / NLE 后期**：你已有素材，靠切点、转场、声画关系重组。 AI 视频生成发生在**逐 clip、无时间线**的环节：每个镜头是独立生成的短片段。

因此，同一个剪辑技法在 AI 流程里要分两块落地：

落地位置你能控制的举例**生成期（本词库职责**）每个 clip 的首帧/尾帧、运动向量、机位/轴线、遮挡、时长、慢放/冻结、声音提示Match Cut 的「上镜尾帧动作 = 下镜首帧动作」靠首尾帧约束实现**后期（NLE，标注边界**）精确切点、Cross Dissolve、声画错位、叠化、变速曲线、字幕J-Cut 的精确声先入、Dissolve 时间过渡

> 一句话：**剪辑技法 → 先判断「AI 生成期能拿住多少」，再决定「哪些只能留给后期」。** 本词库给每个技法三样东西：①AI 可达性分级 ②生成期约束 + Prompt 片段 ③后期边界。

## 1. 三级可达性模型（一切技法卡的基石）

分级含义在本词库怎么给**完全可达**仅靠生成期 Prompt 即可呈现，无需后期直接给 Prompt 片段 + 关联词库**部分可达**生成期搭好结构/素材，后期补精度（切点、过渡、声画）给「生成期约束」+「后期必须做」**仅后期**生成期无法呈现，纯 NLE 操作标注「仅后期」，给后期操作要点，不强行生成

## 4. 核心技法卡详解（高频可转译族，模式 H 直接套用）

> 下列卡为「最值得在生成期拿住」的技法。其余技法见 §3 映射总表，按同类策略套用。

### 4.1 Match Cut / Match on Action 匹配剪辑（动作·图形·色彩·形状）

【分类】匹配剪辑 / 基础切剪 【可达性】完全 【定义】前后两镜用视觉/动作相似点连接，观众不察觉切点。 【生成期约束】上镜**尾帧**停在与下镜**首帧**同动作/同形状/同色的位置；运动向量、方向一致；景别可跳但语义连续。 【Prompt 片段】

- 动作匹配：`上镜尾帧：人物右手向右挥至半空；下镜首帧：同一只手从半空继续向右挥完，身体重心随之转移，背景不动。`
- 图形匹配：`圆形落日（上镜尾）↔ 圆形灯笼（下镜首），构图同位于画面右上三分之一，光线方向一致。`
- 色彩匹配：`上镜尾帧红色披风 ↔ 下镜首帧红色宫灯，主色温一致，避免色相跳变。`【后期边界】无，纯生成可达。若需极致精确叠化，可用 Dissolve 软接。 【关联词库】26 T1 动作匹配 / 21 Match Cut / 09 色彩 / 03 构图

### 4.2 Invisible Cut + Fake One-Take 隐形剪辑 / 伪一镜到底

【分类】转场 / 连续性 【可达性】完全 【定义】多个镜头用遮挡物藏切点，伪装成一条长镜。 【生成期约束】遵守 26 §13 伪一镜到底协议：**机位高度 / 方向速度 / 焦段三锁**；每个「全遮挡接缝」= 免费锚点回注点（人物/墙/门/柱/暗部/过曝/快速运动/镜头甩动）。每镜 End State 停在遮挡物填满画幅。 【Prompt 片段】`镜头跟随人物向右走，一根柱子从画左快速掠过填满画面（全遮挡），下一镜从柱子后继续，人物保持同向同速走出，机位高度与焦段不变。`【后期边界】无；若某段遮挡不足，后期用黑场/模糊补。 【关联词库】26 §13 伪一镜到底 / 05 遮挡转场 / 02 运动

### 4.3 Jump Cut 跳切

【分类】基础切剪 / 时间 【可达性】完全 【定义】同主体同机位相近空间直接跳跃，压缩时间/制造不稳定。 【生成期约束】用同一母图（I2V）生成多个 clip，机位/构图/服装严格一致，仅动作态跳变（坐→站→门边）。相邻 clip 间允许轻微景别跳（≤2 级）防跳切感过强时可加 30 度。 【Prompt 片段】`以同一张人物坐姿图为首帧，生成：人物突然站起走向门边（跳过中间起立过程），机位与服装完全不变。`【后期边界】无；纯生成可达，靠首尾帧同图。 【关联词库】26 链式/同图 / 21 Jump Cut / 24 一镜一变量

### 4.4 Cut on Action / Cut on Look / Cut on Emotion 切点系列

【分类】基础切剪 【可达性】完全 【定义】在动作/视线/情绪变化的瞬间切，让切点「有动机」。 【生成期约束】上镜尾帧落在动作/视线/表情变化的**进行中**，下镜首帧从该状态续接或展示结果。 【Prompt 片段】

- 动作中切：`人物关门，门刚合上一半 → 切 → 下一镜门已完全关闭，人物已转身。`
- 视线切：`人物抬头看向画外右上 → 切 → 右上方的窗外火光。`
- 情绪切：`冷静表情尾帧 → 切 → 下一镜瞳孔微缩、脸色骤变（前/中/后切点心理效果不同，按需选）。`【后期边界】无。 【关联词库】21 Cut Point / 18 动机 / 17 微表情

### 4.5 Shot/Reverse Shot 正反打 + OTS 过肩

【分类】连续性 【可达性】部分（正反打各生成，视线/肩位反向；精确对切后期） 【定义】A 看 B → B 看 A，建立对话/冲突关系。 【生成期约束】**正反打不链式继承**（26）：反打用母角色图单独生成；视线反向、前景肩位反向、光位反向；锁 180 度轴线同侧。 【Prompt 片段】`镜A：过B右肩拍A，A看向画右（看B），35mm中近景；镜B：过A左肩拍B，B看向画左（看A），同焦段同光位反向。`【后期边界】精确对切节奏、插入反应镜头在后期。 【关联词库】26 正反打 / 15 站位轴线 / 17 反应

### 4.6 J-Cut / L-Cut 声画错位

【分类】声音剪辑 【可达性】部分（生成搭结构，精确错位后期） 【定义】J-Cut 声音先入画面后切；L-Cut 画面先出声音延续。 【生成期约束】J-Cut：下镜 Prompt 写明「下场景环境声（火车/海浪/人声）在本镜尾段已隐约可闻」；L-Cut：上镜尾帧写明「台词/音乐延续至切走后」。生成只能给「提示」，精确 lead/lag 在后期。 【Prompt 片段】`本镜尾帧：人物仍站在家中，但远处火车轰鸣声已 faintly 进入；下一镜为旧上海火车站台。`【后期边界】必须在 NLE 做精确声画错位（声音提前/延后 0.5–1.5s）。 【关联词库】13 声音剪辑(J/L-Cut) / 26

### 4.7 Wipe / Object Wipe 划像 / 遮挡划像

### 4.9 Dissolve / Fade 叠化 / 渐隐（时间过渡）

### 4.10 Parallel / Cross-Cutting 平行 / 交叉剪辑

### 4.13 Freeze Frame / Slow Motion / Speed Ramp 冻结 / 慢放 / 变速

### 4.14 Reaction Cut / Micro-Expression Cut 反应切 / 微表情切

### 4.15 Rhythm: Beat / Acceleration / Staccato-Legato 节奏剪辑

### 4.16 Emotional Hold / 情绪停留

### 4.17 180-Degree / Screen Direction / Eyeline 轴线·方向·视线

### 4.18 Smash Cut / Abrupt Cut 暴切 / 突兀切

### 4.19 Whip Pan 甩镜转场

### 4.20 Split Screen / PiP 分屏 / 画中画

【分类】空间 / 类型 【可达性】仅后期（生成两/多镜，NLE 拼） 【定义】同屏多视角/同时事件/电话两端。 【生成期约束】各分屏内容单独生成，锁各自一致性；标注布局（左右/上下/画中画）。 【Prompt 片段】`左屏：人物在客厅打电话（生成）；右屏：对方在街头行走（生成）；后期并置为分屏。`【后期边界】必须用 NLE 分屏/画中画合成。 【关联词库】22 / 02 分屏系统（见 02 词库）

### 4.21 Tilt-Up Reveal 上摇揭示（巨物专族）

【分类】转场 / 空间 【可达性】完全（本族是**纯生成红利**——Prompt 写对即得 80% 以上，后期零操作） 【定义】机位不动，镜头沿垂直轴向上摇，让巨构「从下往上」被逐段揭露，**永远不给顶端**，制造「人类无法理解其巨大」的压迫感。 【生成期约束】**三条反向铁律（巨物镜命门，必须写成负数指令的正向表达）**：

1. **顶端必须留在画框之外**——Prompt 明写「顶端始终位于画框之上，不可见」，禁止出现「完整」「全貌」「全景呈现」。
2. **不能被完整照亮**——只允许 1\~2 条局部光带（如冷白结构灯 + 红色警示灯），其余沉入暗部，**禁止全局照明**。
3. **主体不能被拍清楚**——前景必须留一个极小人形（占画面高度 &lt;1/20）作尺度锚，随摇镜上移。 补充约束：摇速「起慢→中段匀速→尾帧略加速」，让「看不到头」变成生理体验；保留一根垂直缆索/导轨作视觉标尺；尾帧不停在顶端，**不给答案就是答案**。 【Prompt 片段】

- 首次揭示：`机位固定于地面仰角，镜头沿垂直轴缓慢上摇，揭示柱体向天空延伸；表面仅有两条光带（冷白结构照明 + 暗红安全标识），其余沉入青灰阴影，顶端完全位于画框之上不可见；画面下方一名站立背影剪影，占画面高度不到二十分之一，随摇镜上移出画。`
- 压迫峰值（允许升+摇复合运动例外）：`机位固定，镜头缓慢上升与上摇同步，12 秒不中断；全画面只有一条冷白线（钢构接缝反光）和一条红线（警示灯带），顶端永远不在画框内；塔基下方两名极小人形缩小到几乎不可辨。`【后期边界】无，纯生成可达。仅可选在镜前/镜后各留 0.5s 静止或黑场增强「启动感」；**禁止后期变速**（摇速已在生成期调好）。 【关联词库】02 摄影机运动（摇镜/升降）/ 08 灯光（局部照明）/ 05 转场 / 24 反抽象形容词

### 4.22 Tilt-Up on Information Wall 信息墙上摇（密度揭示）

【分类】空间 / 基础切剪 【可达性】完全 【定义】镜头沿刻名墙/名录墙/档案墙向上摇动，揭示密密麻麻的「名字」——**「名字的密度」本身是信息，不是「某一个名字」**。 【生成期约束】**AI 文字处理的关键规避**：

1. **不要可读，只要密度**——Prompt 明写「刻痕细密到无法辨认，只呈现文字密度与质感」，**绝不能要求文字清晰可读**（AI 会渲染乱码）。
2. **材质优先**——把文字处理成**凹陷的物理刻痕**，有金属反光与阴影，让它像「纹理」而不像「字幕」。
3. **摇速比 4.21 慢得多**（「阅读」节奏而非「震撼」节奏，8\~10 秒）。
4. **墙体必须真实**——混凝土/金属板质感，有接缝、污渍、局部打光不均，**防止 AI 生成「纯平面文字墙」这种假东西**。
5. **人物绑定**——画面角落保留人物的一只手或半个肩膀贴墙滑动，随摇镜同步。
6. **尾帧不停在墙上**——落在「墙面延伸出画框」的位置，暗示多到看不到头。 【Prompt 片段】`一整面混凝土刻名墙，表面布满细密凹陷刻痕，密到无法辨认具体内容，只呈现为连续的文字纹理带；镜头沿垂直轴缓慢上摇；墙体被冷白顶灯斜向照亮，刻痕产生细微阴影，光感不均匀，局部有污渍与磨损；画面左下角一只女性的手贴墙缓慢上移；刻痕文字保持不可辨认状态，不出现可读字符。`【后期边界】基本无。可选轻微暗角（vignette）。**绝对不要在墙上叠任何可读字幕**——会破坏「密度即信息」的设计。 【关联词库】09 色彩与质感 / 24 反抽象形容词 / 03 构图

### 4.23 Same-Setup Callback 同机位复现（首尾呼应）

【分类】蒙太奇 / 连续性 【可达性】部分（各镜生成，意义在后期并置） 【定义】刻意重复同一机位与构图，让观众「自己发现」变化——**零成本的高级感**。 【生成期约束】**唯一技术命门 = 机位卡逐字复用**：

1. 建「机位卡」（机位点 / 高度 / 焦段 / 构图占比），两组镜头**逐字复制**，差 10cm 或 5mm 即穿帮、不成复现。
2. 只允许「叙事变量」变化（人物位置/状态/光色/道具缺失），**背景结构、家具位置、窗框比例、画面留白比例全部不变**。
3. **光色可以且应该变**（有人=暖黄 → 人去楼空=冷青）——这是「变化」的主要载体。
4. **生成顺序**：必须先做**母镜**并确认，再以母镜为参考图做 I2V 生成复现镜；母镜首帧登记进「母图清单」作锚点。
5. **进阶技巧**：在复现镜的同一位置放一个母镜里有、此时已不在的道具（母镜桌上有碗 → 复现镜碗没了），**一物之差胜过千言**。 【Prompt 片段】

- 母镜机位卡：`机位：屋内东南角固定机位，高度 1.4m；焦段 50mm；构图：门框居中，人物坐于门框左侧三分之一处。`
- 复现镜：机位卡**逐字相同**，仅改内容——`同一间屋子，同一旧桌，同一个铁盒已合上；人不在画面中，椅子空着；光色改为清晨冷青。`【后期边界】1. 并置位置要**间隔足够远**（相隔多场），让观众先忘记再被击穿；2. **不要用叠化连**——这两组不是转场是呼应，靠观众记忆完成连接；3. 复现镜环境声要**比母镜更静**（缺席感）；4. 建议建「母图清单」统一管理所有机位卡。 【关联词库】26 锚点回注与母图 / 15 空间一致性 / 05 视觉叙事语言（Bookend / Callback）/ 21 §3.3 图形/位置匹配

### 4.24 Sound Bridge / Leitmotif Sound 声音桥与声音母题

【分类】声音剪辑 / 蒙太奇 【可达性】部分（生成期埋声，后期同源铺轨） 【定义】用「同一个声音」穿过全片所有空间（如机械低频轰鸣、钟声、水声），是所有场景的**隐形连接物**，也是「那个东西还在运转」的存在证明。 【生成期约束】

1. **每场至少留一次**——每个空间的 Prompt 都要求「该声音存在于背景」，**音量极轻但不为零**。
2. **按场次写强度递进**（用「提示」而非精确混音）：地面段「极轻机械感」→ 巨构/地下段「浑厚+长混响」→ 高空/真空段「极干净，只剩结构振动的体感低频」。
3. **设计一个「归零段」**——全片唯一没有该声音的段落（如闪回），**反差本身就是叙事标记**。
4. **收束要求「极缓淡出」而非切断**（至少 6 秒以上）。
5. 声音提示统一句式：`背景存在极轻的[某声音]，音色偏[X]，几乎与环境底噪融为一体。`——**务必用「极轻/渗入/faintly」等弱化词，写强了会喧宾夺主**。 【Prompt 片段】`背景存在极轻的低频机械轰鸣，来自远处结构，音色偏金属，几乎与环境底噪融为一体，始终存在但不压过人物对白。`【后期边界】1. **必须建一条贯穿音轨**，用**同一段素材**按场次调 EQ/混响（同源才能形成母题，不能每场找不同素材）；2. 强度曲线应为 `近→强→浑厚→(归零段静音)→干净→极长残响→淡出`；3. 归零段必须**彻底静音**；4. 结尾淡出 ≥6 秒；5. **配乐要给这条声音让路**——它是全片的「心跳」，被盖住整片会散。 【关联词库】13 声音五层结构 + 音乐动机系统（记忆动机）/ 12 母题 Leitmotif / 21 第十节

## 4.25 AI 巨物镜反向铁律（跨技法通用资产）

> 由 §4.21/4.22 提炼出的**独立通用条目**。凡涉及「巨构 / 巨型机械 / 巨型建筑 / 巨型天体 / 超大尺度场景」的镜头，无论走哪个模式，都必须主动在 Prompt 里写**反向指令**——因为模型的默认倾向与导演意图**恰好相反**。

**模型三大默认失败倾向 vs 应对**

模型倾向后果反向指令（写进 Prompt）把巨物**完整照亮**失去神秘与压迫，像产品渲染图明写「只允许 N 条局部光带，其余沉入暗部」，禁止全局照明把巨物**完整展示**一旦看见尽头，压迫感立即消失明写「顶端/边界始终位于画框之外，不可见」把**主体拍清楚**主体变大，尺度对比失效明写「人物占画面高度不到 X 分之一」（如 &lt;1/20）

**配套四原则**：

1. **写负数指令的正向表达**——不写「不要拍全」，写「顶端位于画框之上不可见」（符合 05 号词库「直接正向描述希望出现的结果」原则）。
2. **给视觉标尺**——保留一根垂直/水平的连续参考物（缆索、导轨、地平线），观众靠它丈量「到底有多大」。
3. **给体感线索**——气流、尘埃、白雾、结霜等被巨构扰动的小尺度物理现象，让「大」变得可感。
4. **音画同步**——低频轰鸣随尺度揭示同步抬升（联动 §4.24 声音母题）。

> 适用范围：科幻巨构、基建奇观、灾难场面、神话尺度、城市天际线、大型工业场景。**只要 Prompt 里出现「巨型」「巨大」「难以理解的巨大」这类词，就套用本节。**

### 6.1 模式 H 标准交付结构（四段式，固化模板）

模式 H 的输出**必须**按下列四段组织，缺一段用户就拿不动：

```
【第一段】可达性总览表
  一行一技法：技法名 | 落地场次 | 分类 | 可达性(完全/部分/仅后期) | 主战场(生成期/后期)
  结尾给「一句话结论」——哪族是生成红利、哪族必须后期。

【第二段】逐技法卡（每卡按 §2 格式）
  【技法】【分类】【可达性】【定义】【生成期约束】【Prompt 片段】【后期边界】【关联词库】
  生成期约束尽量用「约束表」呈现（约束项 | 具体锁法），比段落好读。

【第三段】生成期 vs 后期 责任划分表
  两列：生成期必须拿住 | 后期必须补。技法多时这张表是全篇最有价值的部分。

【第四段】施工警示（3 条以内）
  写「最容易做错的地方」——每条给「错误行为 → 后果」。
```

### 6.2 交付时的必备话术

**必须显式回答用户一句话**：

> 「哪些已在生成期拿住、哪些必须后期 NLE 完成。」

这是 AI 视频剪辑技法落地的关键边界，也是模式 H 存在的意义。不要在输出里含糊带过。

### 6.3 三条高频施工警示（先自查）

1. **上摇/巨物镜**：最容易犯的错是「想给观众看清楚」。**越给越不高**。检查 Prompt 有无「完整」「全貌」「全景呈现」——有就删。（联动 §4.25）
2. **声画错位族（J/L-Cut）**：最容易犯的错是生成期把声音写太强。**生成期只要「提示」，精度留给后期**。写强了 J-Cut 变泄底、L-Cut 变音频故障感。
3. **同机位复现**：最容易犯的错是机位卡「差不多就行」。**必须逐字复制**，差 10cm/5mm 复现即废。（联动 §4.23）
