# 30-歌舞·卡点·音乐驱动剪辑

**定位**：本库管「镜头怎么跟着音乐走」——卡点（Beat Sync）、踩点运镜、歌舞戏编排、音乐动机与视觉母题互文。它是 Mode D 分镜编排的一个**音乐驱动设计透镜**，也可独立触发（用户说"这段卡点剪/音乐驱动/歌舞"）。核心是：把音乐结构翻译成分镜的**切点位置、镜头时长、运动落点**。

**与既有词库的关系**：

- `21` 蒙太奇五层 / 节奏曲线（节奏基底）
- `27` 剪辑技法（匹配剪辑 / 平行蒙太奇 / 冲击剪，卡点的技法底座）
- `13` 声音五层 / 音乐动机系统（音乐结构 → 视觉动机）
- `12` 母题系统 / `09` 色彩叙事（音乐动机 × 视觉母题互文）
- `29` 剪映交付（卡点在剪映精确对齐，生成期只做"内在节奏"）
- `28` 空镜（副歌/段落分隔的母题空镜）

## 一、音乐结构基础（分镜前必读）

结构段英文剪辑策略前奏Intro定场/空镜铺陈，慢切建立空间主歌Verse叙事推进，中速切，信息密度中预副歌Pre-Chorus加速，切点加密，张力累积副歌/高潮Chorus / Drop**卡点爆发**，硬切/Hit，母题视觉全开间奏Bridge情绪转折，可慢/可器乐 solo 卡点尾奏Outro收束，回归空镜/母题回扣

**节拍术语**：BPM（每分钟节拍）、Beat（一拍）、强拍（重音）、弱拍、小节（4 拍）、Drop（电子乐爆点）、Hit（音效重音）。

## 三、BPM → 镜头时长映射表（设计用）

镜头时长应是**节拍的整数倍**，才能天然卡点（剪映再精确对齐，见 `29`）。

BPM1 拍(s)单镜=1拍单镜=2拍单镜=4拍(1小节)建议900.6670.5–0.7s1.3s2.7s抒情/叙事1000.6000.5–0.6s1.2s2.4s中速1200.5000.5s1.0s2.0s主流卡点1280.4690.5s1.0s2.0s电子/舞曲1400.4290.5s1.0s1.5–2.0s快节奏

**规则**：单镜时长 = N × 拍长（N=1\~4）；服从铁律 8（亚秒精度、≤模型上限 5s/10s、相邻起伏）。BPM 高时 N 取 1（0.5s 碎镜），BPM 低时 N 取 2\~4。钩子/副歌爆发段可压到 N=1 抢注意力。

## 四、踩点运镜设计（镜头运动跟拍）

- **运动加速到拍点**：镜头运动（推/摇/甩）在重音前加速、重音瞬间定格或切走（Speed Ramp into beat，联动 `27` 速度相关技法）。
- **动作落点对齐切点**：人物动作（踏地/挥手/转身）的落点 = 切点位置，剪映切走瞬间正好是动作砸下。
- **运动相位与节拍同步**：周期性运动（走步/摆动）频率 = 节拍频率，画面"自带节奏感"。
- **镜内卡点**：单镜内用 `27` 的 Freeze Beat / Bullet Time 在拍点定格，制造"卡点感"而不靠剪。

## 五、歌舞戏编排（分镜模板）

歌舞段是"动作卡拍 + 镜头组覆盖"：

歌舞元素分镜策略镜头群舞全景建立空间与队形广角/远景固定或慢移（Master Shot）动作卡拍单人/小组动作踩拍中景跟拍，动作落点对齐鼓点表情特写情绪峰值特写，定格在重音队形变化段落切换匹配剪辑（图形/运动 Match Cut）衔接旋转/环绕Drop 爆发环绕/升降，速度随 Drop 加速

**Coverage（联动** `22`**）**：歌舞段确保 全景(队形) + 中景(动作) + 特写(表情) 覆盖，后期剪映才有卡点剪辑自由度。

## 六、音乐动机 × 视觉母题互文（高级）

联动 `13` 音乐动机系统 + `12` 母题系统 + `09` 色彩叙事：

- **主旋律动机 → 核心母题视觉**：主题旋律出现时，母题空镜/母题色彩回扣（如《云孝心》青蓝光在副歌全开）。
- **副歌/ Drop → 母题爆发**：段落升级时母题视觉强度翻倍（更饱和/更大面积/更密出现）。
- **乐器音色 → 视觉质感**：弦乐→柔光暖色；电子→冷光硬切；打击乐→冲击剪（Hit）。
- 用 `28` 空镜作"音乐段落分隔符"，每段音乐结构切换插母题空镜。

## 七、Prompt 设计：让 AI 生成"踩点感"

**重要边界**：Seedance 生成期**无法精确跟外部音乐节拍**——它只能生成"动作有内在节奏"的画面。精确卡点必须在剪映（`29`）靠自动踩点对齐。所以生成期 Prompt 只做两件事：

1. **动作节拍化**：写"每一下鼓点身体下压一次 / 手臂随节拍摆动"（让动作有可被剪映对齐的内在点）。
2. **运动落点对齐收束**：用 End State（收束定型句）让动作停在可切点（"动作在最高点定格"），方便剪映在定格处切。

**Prompt 片段示例**：

> 人物随隐形的强节奏律动，每一下重拍身体下沉一次、手臂随拍点向外甩出，动作干净有爆发力；在最强一拍瞬间定格（Freeze on Beat），姿态凝固；节奏感强烈，Motion Video 风格。

可叠加英文关键词：`Music Video / Rhythmic / Beat-synced motion / Freeze on beat`。

## 九、常见翻车与修复

失败原因修复卡点漂移误以为 AI 能跟拍生成期只做内在节奏，剪映自动踩点对齐（见 `29`）动作不跟拍Prompt 没写节拍化动作加"每拍一下"的周期性动作描述卡点过载全程 0.5s 碎镜按结构段调 N（副歌密/主歌疏）音乐压对白音量未分层剪映音轨分层（见 `29` 第四节）母题断线副歌没回扣母题按第六节做动机×母题互文

## 十、工作流（When to use）

1. **用户明确要求**：说"卡点剪/音乐驱动/歌舞/踩鼓点/BPM" → 进入本模块（或路由模式 K）。
2. **Mode D 自动触发**：分镜检测到"卡点/音乐驱动/歌舞/MV"需求时，加载本库。
3. **步骤**：定 BPM 与音乐结构 → 按第三节映射镜头时长 → 按第二节选卡点类型 → 按第四节设计踩点运镜 → 歌舞段走第五节 Coverage → 按第六节做动机×母题互文 → 写"节拍化动作"Prompt（第七节）→ 填第八节交付表 → 编译质检（`24`/`25`）→ 剪映精确卡点对齐（`29`）。
4. **协同**：节奏曲线复用 `21`§15；匹配剪辑/平行蒙太奇/冲击剪复用 `27`；声音动机复用 `13`；母题复用 `12`/`09`/`28`；精确对齐复用 `29`。
