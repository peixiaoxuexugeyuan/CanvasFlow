# 展览展示竞赛板万能生成技能（Exhibition & Showcase Universal Board）

by wxyz AIGC

> 适用对象：单个产品、IP/潮玩、家具、雕塑、公共艺术装置、景观构筑物、建筑、规划/城市/社区、室内空间、品牌展位，以及一切需要"竞赛板 / 提案板 / 成果展示板 / Pitch Board"形式呈现的设计提案。\
> 覆盖阶段：概念设计 → 方案设计 → 深化设计 → 落地实施 → 评奖参赛。

---

## 0. 核心输出原则（最高优先级，必须严格遵守）

本 SKILL 的**唯一输出物**是「文生图提示词（Image Prompt）」：

1. **只输出提示词**：加载本 SKILL 后，Agent 只输出用于生成图片的提示词文本；禁止输出 JSON、禁止输出思考过程、分析、建议、排版说明、技术参数表、自查清单等任何与文生图无关的内容。
2. **纯文本 Prompt**：每条提示词用自然语言书写，可直接粘贴到 Midjourney / 即梦 / ComfyUI / Stable Diffusion 等工具使用，不使用 JSON / YAML / 代码块包裹字段。
3. **自动命名**：若用户上传的主体内容没有起名字，AI 必须依据主体的造型、材质、主题、气质自动识别并为其起一个贴切的中文名 + 英文名，并自然融入提示词中（如"将这件作品命名为『云泊 · Cloud Harbor』"）。起名应克制、有画面感，不堆砌辞藻。
4. **多图覆盖**：默认为一套竞赛板输出 6 \~ 9 条提示词，每条对应一种视觉元素——高精度 3D 逼真渲染主视觉 / 三维爆炸图（Exploded Views）/ 正交视图（平立剖面）/ 轴测图 / 材质面板（Material Swatch）/ 数据可视化图表 / 带引线注释的排版文本；全部以严谨网格系统（Grid System）融合编排，不采用九宫格式分区堆叠。
5. **提示词结构**：每条提示词必须包含「题材 + 主体描述 + 视角 + 构图 + 光源 + 材质 + 色彩 + 风格 + 分辨率」，缺一不可。

## 1. 技能定义 (Skill Definition)

- **技能名称**：`Exhibition_Showcase_Board_Universal`
- **版本**：v2.2 万物通用版（输出物=文生图提示词 + 自动命名 + 网格系统出图）
- **核心目标**：在用户输入（关键词 / 参考图 / 文案描述 / 设计草图）之后，自动识别项目类型与题材；若主体未命名则自动为其起中英文名；并按统一的"竞赛板视觉语言"输出一组可直接用于文生图的提示词（Image Prompt），覆盖主视觉、概念、总图、设计过程、立剖面、爆炸图、节点、材料、应用场景等竞赛板板面。
- **覆盖场景**：
  1. **A. 单体作品类** —— IP/角色、潮玩、家具、单品雕塑、艺术装置、纪念雕塑、奖杯、灯具、首饰、产品等单个物件。
  2. **B. 公共艺术与景观构筑物类** —— 户外雕塑、地标装置、景观亭、桥、广场雕塑、互动装置、夜景艺术装置。
  3. **C. 建筑与室内类** —— 公共建筑、地标、文化馆、展馆、商业空间、室内艺术装置、品牌旗舰店。
  4. **D. 城市规划与社区类** —— 未来社区、产业园区、特色小镇、城市更新、TOD、文旅景区、生态修复。
  5. **E. 万物展览展示类** —— 任何需要"讲解项目全貌"的可视化提案，包括但不限于上述四类的混合体。

## 2. 出图视觉体系：严谨网格系统 × 高精度渲染 × 技术图表

> **整体视觉诉求（出图核心纲领）**：整体呈现出极其严谨的排版逻辑（网格系统），将核心的高精度 3D 逼真渲染图与多种技术性图表深度结合，以实现"一键出图"的专业视觉诉求。视觉元素包括三维爆炸图（Exploded Views）、正交视图（平立剖面）、轴测图、材质面板（Material Swatch）、数据可视化图表以及带有引线注释的排版文本。无论是暗色调的科幻数字风格，还是明亮极简的现代白模排版，都强调设计的工艺流程、结构解析和空间氛围。整体质感追求商业级表现力，光影精准、细节丰富，展现从概念到落地的全景式设计推演过程。

任何题材、任何项目，都统一收敛到上述这套视觉语言，保证输出风格一致、专业、可直接参赛。**出图以"高精度渲染主图 + 技术图表环绕"的网格化融合排版呈现，不采用九宫格式的分区堆叠。**

### 2.1 叙事节奏（三段论）

段落名称作用承载视觉第一段**概念建立** Why让评委/观众秒懂"是什么、为谁、做给谁看"1 张高精度主渲染 + 1 段概念文案 + 1 行 slogan第二段**设计推演** How展示"怎么做到的"：逻辑、形式、结构、节点、材质三维爆炸图、正交视图、轴测图、材质面板、工艺流第三段**价值与落地** What for证明"值得做"：参数、影响、运营、奖项数据可视化图表、技术参数、奖项、可持续

### 2.2 视觉元素库（Visual Elements）

所有竞赛板的"出图素材池"由以下视觉元素组合而成，AI 应**按项目类型挑选、以严谨网格系统编排**，而非简单堆叠：

1. **高精度 3D 逼真渲染主视觉**：黄昏 / 夜景 / 蓝调时刻的高质量渲染，电影感构图，光影精准，1 \~ 2 张
2. **三维爆炸图（Exploded Views）**：分离的部件层，标注材质与装配关系
3. **正交视图（平立剖面）**：平面 / 立面 / 剖面，含尺度与材质标注
4. **轴测图**：等距 / 分层轴测，体现结构组织与空间逻辑
5. **材质面板（Material Swatch）**：5 \~ 6 种主材样本平铺 + 编号 + 工艺说明
6. **数据可视化图表**：能耗 / 碳排 / 容积率 / 流线 / 空间算法等数据图
7. **带引线注释的排版文本**：双语标题、关键词气泡、slogan、引线标注

> 说明：第 3 节的模块表用于确定"要讲什么内容"，本节视觉元素库用于确定"用什么视觉形式呈现"，两者配合使用。

## 5. 标准命令范本 (Standard Command Templates)

以下 5 个范本涵盖"竞赛板"常见的核心需求，按需取用：

### 范本 A：侧重【材质与质感】的衍生（Material Focus）

> 适用：希望保留造型但换材质（如石头→玻璃、青铜→冰雕）。

```text
参考 [参考图 URL/描述] 中的{对象类型}，保留其 {核心造型特征}，
将其材质重绘为 {用户指定材质，如：半透明磨砂玻璃 / 流动的水银 / 粗糙的红砖 / 高反光不锈钢}，
整体色调 {用户指定颜色}。
生成一张同系列但动态为 {新动态，如：静止伫立 / 向前奔跑 / 旋转悬浮} 的衍生作品，
保持原作神韵，8K 分辨率，极致细节。
```

### 范本 B：侧重【色彩与光影】（Color & Lighting Focus）

> 适用：希望改变氛围与配色（季节/节日/不同气候）。

```text
基于 [参考图/描述] 的{对象类型}造型，提取其 {核心造型特征}，
重新渲染为 {用户指定颜色组合} 的色彩体系，置于 {用户指定环境/光源} 中。
强调光影对材质的折射效果，同系列风格，电影级构图。
```

### 范本 C：侧重【动态与叙事】（Dynamic & Narrative Focus）

> 适用：静态雕塑"激活"，生成有故事感的瞬间。

```text
以 [参考图/描述] 为原型，复刻其 {核心造型} 与 {核心材料} 特征，
将其转化为 {新动态，如：跌倒瞬间 / 拥抱姿态 / 飞翔} 的动作。
背景模糊以突出主体，高动态范围、慢动作摄影风格。
```

### 范本 D：侧重【全过程推演】（Process & Workflow Focus）

> 适用：方案/竞赛板，强调从概念到落地的完整轨迹。


## 6. 视觉语言规范（美学系统）

### 6.1 色彩

层级推荐色（暗夜电影感）备选色（明亮日常感）背景`#0E0E10 ~ #1A1A1D`（墨黑到深炭灰）`#F4F1EC ~ #EFE9DD`（米白到暖灰）主色（亮部）`#E8B36A` / `#F0C58E`（琥珀金）`#C8553D`（赭红）辅色（高光）`#5DB7E0` / `#7BD3F0`（冰蓝）`#4F8C5F`（苔绿）文字`#F5F5F5` 主 / `#9B9B9B` 副`#1C1C1C` 主 / `#5C5C5C` 副强调线`#E8B36A` 1px`#C8553D` 1px

> 默认采用**暗夜电影感**配色；若用户明确"明亮/学术/可持续"等关键词，切换到备选色。

### 6.2 字体

- 中文：思源黑体 / 阿里巴巴普惠体 / 站酷高端黑
- 英文：Inter / Space Grotesk / Neue Haas Grotesk
- 数据/参数：JetBrains Mono / IBM Plex Mono
- 标题字号：36 \~ 72 px；副标题：18 \~ 24 px；正文：12 \~ 16 px

### 6.3 排版网格

- 横向 3600 × 2400 px（或 2400 × 3200）
- 网格：12 列 × 6 行，外边距 60 px，内间距 24 px
- 模块之间用 1 px `#3A3A3A`（暗色版）或 `#D5D5D5`（亮色版） 分隔线
- 模块标题字号统一，左对齐 + 1 px 主色装饰条
- 关键数字（如高度 / 面积）使用 3 倍字号突出

### 6.4 图像风格与出图形式

- **整体形式**：极其严谨的网格系统（Grid System）排版，将高精度 3D 逼真渲染图与多种技术性图表深度结合，实现"一键出图"。
- **两种风格（二选一并全程统一）**：
  - 暗色调科幻数字风：深色底 + 霓虹/发光高光 + 冷色科技感
  - 明亮极简现代白模风：白色/米白底 + 黑白灰线稿 + 低饱和点缀色
- **主视觉**：黄昏 / 蓝调时刻 / 夜景，35mm 广角、低饱和电影感构图，光影精准、细节丰富。
- **渲染**：建筑可视化（ArchViz）+ 产品级 Keyshot 渲染，商业级表现力。
- **技术图表**：三维爆炸图、正交视图（平立剖面）、轴测图、材质面板、数据可视化图表、带引线注释的排版文本。
- **工程图**：白底黑线 / 深底白线统一，标注使用颜色编码、字体等宽。
- **节点图**：等距 / 透视爆炸，标注字体等宽，引线注释清晰。

## 7. 排版与叙事规范（避免硬伤）

1. **概念双语**：每个竞赛板必须有中英双语项目名与一句核心 slogan。
2. **数字必须真实**：所有尺寸、重量、容积率、年份、客户等不要凭空虚构，可在不确定处用 \[TBD\] 占位。
3. **奖项要谨慎**：未真实获奖的项目不得使用具体大赛名（如红点、IF、IDEA、缪斯），可标注"NOMINEE"或"SHORTLIST"。
4. **设计过程真实**：推演图不能伪造手稿，可使用 AI 生成"概念草图"风格说明。
5. **节点必须可读**：同一张图最多标注 6 个引线，避免信息过载。
6. **可持续维度**：建筑/城市类必须有能耗、碳排、材料循环的设计说明。
7. **运营逻辑**：含商业空间、社区、未来聚落等议题的竞赛板必须回答"为什么可持续运营"。
8. **避免文化冒犯**：历史名人、政治符号、宗教象征相关项目，按主流叙事谨慎处理。

## 9. 工作流 SOP（Agent 调用时如何执行）

当 Agent 加载本 SKILL 后，应按以下步骤工作，**最终只输出文生图提示词**：

1. **意图识别**：从用户输入中识别项目类型（A/B/C/D/E），置信度高则选用对应模板；不确定则启动 E 兜底。
2. **信息盘点**：对照 4.2 Schema 的最小可用输入做一次"字段审计"，缺失字段（如尺寸、材质、场景）在提示词中用合理假设补齐，不单独列出。
3. **自动命名**：若主体无名称，依据造型、材质、主题、气质自动起中英文名，并自然融入提示词。
4. **提示词编写**：按所选类型的"提示词输出清单"生成 6 \~ 9 条提示词，每条必须包含：题材、主体描述、视角、构图、光源、材质、色彩、风格、分辨率。
5. **仅输出提示词**：将上述提示词按序号直接输出，纯文本、非 JSON；不得附加任何思考过程、分析、建议、技术参数表、排版说明或自查清单。
6. **格式要求**：每条提示词一行或一段；禁止使用 JSON / YAML 结构包裹；禁止出现"方案一 / 建议 / 备注 / TBD"等元信息。
