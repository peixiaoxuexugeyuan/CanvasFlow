# 口播场景设计

将模糊的“想要好看的口播背景”转成能容纳人物、可快速复用的具体虚拟场景。默认中文沟通，用户不用懂摄影术语。核心是先安排人物，再设计环境。本 Skill 只负责生成虚拟口播背景图，不做实体搭景或真实布景方案，也不涉及口播文案与视频剪辑。

## 开始与提问

先读当前对话和用户已给的图片、素材、用途。只询问会改变方案的缺项，不重复询问。用户只要求创建或修改本 Skill 时，完成 Skill 本身，不自动启动设计问卷。

- 全新需求：通常两轮就能进入交付，每轮 1–3 个短问题；问题数量随已有信息减少，不把轮次当门槛。
- 已给参考图：先实际看图，说清会保留哪种空间关系、哪里需要适配人物；不凭文件名猜图，也不重新问已知风格。
- 已确定方向：直接细化；局部修改只改指定部分。
- 用户说“你决定／快速出方案”：用下述默认值推进，简短注明假设，不再等选择。

优先用当前可用的提问工具；没有则在回复中提问。问题包含 2–3 个易理解选项，首项为结合上下文推荐的选择，也允许自由回答。设计所依赖的问题提出后等待真实回答，不能把工具立即返回或等待超时当作用户选择；等待期间可整理参考，不替用户确认方向。

第一轮优先确定用途与人物。问题示例及分支见 下文的“提问与交付模板”。不要一上来问焦距、色温、材质编码。

根据回答，推荐一个方向并解释它如何服务人物，必要时给一个有实质区别的备选。第二轮只补最关键的风格或使用方式缺项；信息够就交付，用户可以在交付后修改。

默认值仅作可修改假设：竖屏 9:16、单人居中、胸部以上近景、先交方案和提示词；无风格线索时采用明亮克制的创作者工作室。光线先拟柔和侧前光，有人物素材时以实际光向为准。已有人物、比例、风格、工具或出图指令优先于默认值。

## 形成场景

本 Skill 只处理 AI 虚拟背景／数字人环境。用户想要真实搭景、实体布置或施工方案时，说明本 Skill 不覆盖该范围，可改为帮助设计虚拟背景图，不输出可落地布置或施工建议，也不将 AI 渲染图当作施工验证。

用一句话说明“谁在什么画面里，给观众什么感觉”。然后确定：

1. 人物占位：坐姿或站姿、近景或半身／全身、居中或偏侧、手势范围、字幕及演示素材区域。没有人物素材可先做暂定布局；涉及实际合成时再需要真实素材。
2. 空间关系：人物前景、家具中景、墙面后景。近景少留无用地面；全身才重点处理站立区域、接触阴影。自然透视与人物机位一致，不给所有场景套固定焦距或大广角。
3. 风格与身份：主色、主要材料、家具、少量与内容相关的道具。道具应表达真实或明确虚构的使用场景，不虚构奖项、客户背书等身份凭证。
4. 光线与层次：光向、软硬、明暗与人物匹配；深色背景检查黑发黑衣分离，亮色背景检查人物是否过曝。按镜头景深处理背景，避免以整体模糊掩盖结构问题。

可复用原则：人物附近视觉安静，复杂度向外围分布；低柜和完整墙面常适合口播；材料提供细节、有限主色维持统一。它们是本组样本提供的方法，不是禁止高柜、户外、丰富背景或非居中构图的规则。

需要快速风格启发时读 下文的“五类口播场景参考”，本版本仅提供文字参考，用户另附图片时再实际查看。用户的新参考优先。不要把五类当作完整风格清单，也不要宣称用户永久偏爱某一类。

## 交付与执行

信息足够后直接交付：

- 一段具体方案：人物位置、墙面、家具、道具、光线以及这样设计的原因。
- 一条已填好变量的中文生图提示词，可直接复制；不要把方括号留给用户继续填。
- 一张简短复用表：哪些构图和人物条件固定，哪些颜色／材料／道具可换。需要不同景别时分别建立母版。
- 最多三项本方案最相关的实看检查。没有合成人物时，标明人物适配尚待实测，不宣称已验证。

用户仅要求设计或提示词，到这里完成。用户已要求“直接生成／出图／修改这张”时，设计所需信息足够便继续使用可用图像工具，不额外设置确认关卡。

生成背景图默认使用 Seedream 5.5 模型；用户明确指定其他模型时以用户指定为准。遵循用户指定工具；未指定则使用当前环境合适的图像生成能力及其适用说明。不要在 Skill 中写死价格或宣称未调用的工具已出图。工具缺失时明确交付到哪一步。

编辑或保持参考构图时，把实际参考图片传给支持参考的工具，并说明其职责（构图／风格／材质）；文本提及文件名不等于已引用。处理用户人物素材时保留用户要求的身份和外观。素材不足不阻止先交场景方案，但不能伪称完成合成检查。

实际生成后打开结果检查：人物区域是否干净；高对比横竖线是否穿头；光向、透视、尺度是否一致；字幕区域是否可用。发现问题优先局部修正，不能无限追加生成。完成用户要求的数量并报告剩余问题；额外付费与重试遵循所用工具和用户授权。

用户需要长期复用时，将选定背景、实际提示词、人物构图和用户确认意见一起保存到授权的交付位置；区分用户选择、AI判断和观众效果。仅一次喜欢不写成全局偏好，静态画面质量不等于流量或转化率。

## LibTV 使用环境

在 LibTV 中直接通过对话提问；若平台提供可用选项组件，可用该组件减少输入。生成时使用当前可用的 LibTV 图片能力，背景图默认用 Seedream 5.5，用户指定其他模型时以用户指定为准；不要求用户安装本地工具或提供本机路径。本版本只包含文字方法，不附原图。需要具体视觉匹配时请用户提供参考图。

# 提问与交付模板

## 空白需求的第一轮

开场：“我先确定你在画面里的位置和想传达的感觉，再搭配背景。”

仅问未知项，按需求选用：

- “这个场景主要讲什么内容？”建议选项按上下文写，如 AI／工具教程、商业／观点分享、生活／经验分享。内容已知时不问。
- “你希望人物怎么出镜？”胸部以上近景（适合日常口播）、半身并保留手势、全身站立。坐站姿仅在影响家具或机位时追问。
- “这次先做到哪一步？”场景方案＋生图提示词、直接生成背景图。用户已指定交付时省略。

最多三个问题，不把上面问题机械照搬。已有口播画面可邀请用户附一帧以便匹配；异步文本提问工具不支持附件时，在普通回复中说明，也允许先按默认占位推进。

## 第二轮根据答案缩小选择

先推荐：“你是做 AI 工具教程、人物近景，我建议用明亮的原木工作室：脸后面保留整块浅墙，道具放两侧，方便叠加演示。”

然后只问决定性缺项，例如：“你更喜欢哪种感觉？”

- 明亮亲切：暖白墙＋浅木柜＋少量蓝色。
- 安静有辨识度：绿色墙＋金属低柜＋少量作品。
- 正式克制：深色格栅＋低柜＋侧边灯光。

如果用户已有黑色衣服、低调风格或其他约束，重新推荐并说明适配，不固定把明亮方案放首位。用户都不喜欢时，问希望更生活化、户外化还是别的具体方向，开放新方案。

用户选完不追加常规第三轮。缺少光向等细节可作为暂定条件写入方案，实际合成前再核对。仅关键冲突需要追问，例如既要求全身又指定脚下不能出现任何地面。

## 成品提示词骨架

以下是内部组装骨架；交付时填完所有内容，删除无关分支。

“生成一张用于真人口播合成的【比例】写实背景。【人物景别与位置】将是视觉主体，为对应头肩和手势范围留出自然、低干扰的背景。

空间为【具体风格与用途】。后方是【墙面颜色与材质】，配置【与人物尺度相称的家具】。在【具体位置】安排【少量身份道具】，避免装饰集中在人物脸后。前后层次清楚，【近景压缩地面／全身保留站立空间】。

镜头【与人物素材相匹配的方向和高度】，透视自然。主光从【实际或拟定方向】柔和照入，背景明暗和清晰程度与人物镜头匹配。【针对黑发、黑衣或其他素材的条件】。

【字幕和演示素材区域】保持简洁。画面无人物、无水印、无多余文字。陈设像有人使用的真实空间，少量生活痕迹，不堆砌无关装饰。【如提供参考：保留参考的具体构图／仅借鉴材质，不照搬其余部分。】”

仅制作背景时用“无人物”；用户要求人物合成成品时删除此约束并写清人物参考。不要在同一提示词同时要求没有人物和保留人物。

## 复用表例子

固定可替换人物占位、镜头方向、头肩后的安静区域墙面色、材料家具的大致尺度与遮挡关系家具样式、少量道具与人物素材匹配的光向在匹配范围内调整背景氛围

不要为了系列变化同时改变所有变量。优先沿用一张用户选定的母版，每次替换少量项目，出图后重新实看。

## 常见请求的行为边界

- “帮我做个口播背景”：先问关键问题，不立即堆五套长方案。
- “参考绿色那张，半身，直接给提示词”：看绿图，直接给成品提示词，不重问内容／颜色，不自动生图。
- “我不懂，你全定”：声明默认条件后直接交付，不把用户拉回问卷。
- “用我上传的人物直接出背景”：先看人物及参考，沿实际景别光向设计，再执行已授权出图。
- “改为户外庭院”：接受新场景，保留人物优先的方法，不强行限制五类室内场景。
- “帮我布置家里的两米宽角落”：说明本 Skill 只做虚拟背景图，不提供实体搭景或施工方案，可改为设计对应的虚拟背景图。
