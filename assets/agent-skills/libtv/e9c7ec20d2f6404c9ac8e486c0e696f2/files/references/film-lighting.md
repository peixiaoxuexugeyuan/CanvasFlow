# 电影布光、色彩与时序光效

## 场景光感卡
先确定情绪和可见信息，再确定灯光；把光源绑定世界位置，不绑定画面左右。每个新场景填写以下卡，同场各镜继承，必要变化单列说明。

| 字段 | 填写要求 |
| --- | --- |
| 场景基准 | 集/场、季节、时间、天气、场景与角色参考版本 |
| 情绪和视觉中心 | 观众首先看到的人/物，喜剧/日常/温情/紧张 |
| 空间和光源 | 窗户、太阳、灯具的世界位置，角色运动路线和机位朝向 |
| 主光 | 来向、高低、软硬、照亮哪侧脸；给出光源依据 |
| 填充与反弹 | 天空、墙、地面或雪的反光；暗部要保留哪些表情 |
| 轮廓分离 | 是否需要侧逆光，或用背景明暗/色彩对照分离人物 |
| 冷暖和曝光 | 暖冷主次、肤色基准、高光上限、暗部细节 |
| 空气和光效 | 有无尘雾、光束、雾深；无依据不添加 |
| 动态与延续 | 人物进出光区、阴影移动、实景灯变化；下一镜继承项 |

数字照度、色温、光比没有实测或明确制作需求时不编造精确值。用“柔和主光、暗侧仍看清嘴角、背景稍暗”描述可见目标；这些是生成意图，不代表物理渲染参数已经设置。

## 布光方法
- 主光建立体块和方向；用柔和侧前光表现脸颊、眉弓与鼻形，保留眼窝信息。喜剧镜头让眼神、嘴角和手势都可读。
- 填充控制暗部而非抹平明暗。以天空、浅墙、土路和积雪作可信反弹；需要更深暗侧时减少填充，以场景遮挡为依据。
- 轮廓光用于从背景中分离发梢或肩线，须有太阳、窗或灯具来源。不强制三点布光，不让每个人都有一圈无来源白边。
- 优先用人物与背景的亮度、色相和清晰度分离；深色头发可衬浅墙，明亮衣服可衬较暗植被。避免只靠大光晕强调主角。
- 保留接触阴影和环境遮蔽，让鞋贴地、手托篮、孩子坐稳椅面；阴影不涂黑鼻孔和嘴角，不在脸上生成脏斑。
- 控制皮肤柔软透光、哑光粗糙度和眼球小高光；耳缘可稍透暖，整张脸不蜡化，汗珠只在剧情需要时出现。
- 眼镜保留镜片厚度和微反光，避免镜片持续泛白遮眼。水面、金属与玻璃高光数量有秩序，不覆盖表演。
- 强光保留白衣、雪和窗外层次；暗景留黑位但不吞没主体。避免曝光随人物转身抽动。
- 光束只在光路、空气颗粒和背景反差支持时出现；乡村晴天不默认浓雾、漂浮闪粉和满屏丁达尔光。
- 光晕、镜头炫光、景深和运动模糊适量使用；关键手势和快速笑点不能被强散景或拖影抹掉。

## 全片色彩递进
建立场次关键色图：每场选主体色、环境色和一个强调色，保存批准的基准帧。春季桃花粉、嫩绿和柔和天光；夏季清透绿与自然肤色；秋季草黄、土色与冷暖平衡；冬季冷雪和局部生活暖光；结尾春天呼应开篇并扩大空间。

这些是起点，不是强制滤镜。悲伤不自动变蓝，温馨不自动变橙；让动作、构图和声音承担情绪，光线作支持。剧本未写日落，不为每场强加黄金时刻。

## 常见场景和可复制光效模块
把下列模块按场景修改后加入每镜正文；保留当前场景已批准的光向。模块只描述光，不替代人物、动作和摄影信息。

| 场景 | 光效目标 | 必须避免 |
| --- | --- | --- |
| 春日村路/公鸡追逐 | 天光填充，柔和太阳侧光，动作轮廓清楚 | 大片树影遮眼、逆光过曝 |
| 白天教室 | 同一侧窗主光，室内墙面柔和反弹，后排稍暗但可读 | 反打后窗光无故换边 |
| 夏日河滩 | 阳光与天空冷暖自然，适量水面反射 | 碎白点爬满脸和河面 |
| 萤火虫沟 | 低照度天空与月色建立基本可见度，萤火虫为微弱光点 | 几只虫把整张脸照成绿灯笼 |
| 树屋守瓜 | 月夜环境暗部、树屋实际小灯形成局部暖光 | 夜景变白昼或人物全黑 |
| 秋日松林/骤雨 | 林下柔光转为云层漫射，湿面反光逐渐形成 | 无过渡瞬间换色、每帧雨量漂移 |
| 雪地 | 大面积天空和雪反弹，侧光塑形、雪面有层次 | 雪纯白无细节、肤色青灰 |
| 泥火盆 | 火为近地局部暖光，冷窗光保留室内空间 | 火盆把整室照成通红、频闪闪脸 |
| 医院/承诺 | 柔和窗光、安静中性色，手与眼神清晰 | 舞台追光、病人脸恐怖绿光 |

### 春日喜剧
柔和春日阳光从院门一侧斜照，天空和浅墙给暗侧少量填充，眉眼、门牙与手势清楚。人物脚下有柔软接触阴影，身后植被比面部略暗，发梢只有与太阳方向一致的细薄侧光。桃花保留粉白层次，肤色自然，曝光在转身和跑动时稳定，不增加无来源轮廓光。

### 教室与反打
建立空间基准：主窗在教室东墙，太阳从窗外照入，浅墙柔和反光。朝西看的机位，窗在画面左侧；朝东反打时窗可在画面右侧或进入背景，但人物受光仍来自同一扇窗。角色走动时依位置改变明暗，鼻影和桌影方向符合世界光源。保持同场曝光与肤色，不为每张脸复制相同的画面左侧高光。

### 夏夜萤火虫
低亮度偏冷的开阔天空光与树叶间月色形成可辨认的脸部体块，暗处仍看清眼神和嘴角。萤火虫在不同距离缓慢明灭，只在靠近手背时贡献极微弱局部暖绿反光，不承担整个人物主光。背景保留深浅层次，无满屏绿色泛光，不把夜景提亮为白天。

### 冬日温情与火盆
窗外雪地反射的冷白光从固定窗侧进入，泥火盆仅给附近手掌、衣服下缘与面颊少量柔暖反光，亮度自然衰减。暖光变化细微缓慢，不强烈频闪，面部曝光稳定，盆沿和皮肤高光不过曝。远处墙面保持中性偏冷，冷暖同框且肤色自然，温暖感来自空间关系，不套整屏橙色滤镜。

## 时序与验收
光源变化必须有原因：人物经过窗边、被树遮挡、云层移动、灯被打开。亮度改变要有连续过程；除明确设计，禁止自动曝光抽动、阴影跳动、轮廓边闪烁和亮点游走。

检查同场宽景与近景、正反打、跑动和转头：世界光向一致；肤色不随镜头变色；眼睛和关键动作可读；白衣/雪/窗不溢出；黑发/暗衣保留轮廓；玻璃和水的高光不乱闪。先看正常播放，再查最亮、最暗和遮挡过渡帧。

针对光效返修时保留角色和动作，明确仅调整光源方向/填充/曝光中的主要问题；若生成工具不能独立重打光，则重新生成或标注后期调色范围，不能声称已获得可分层灯光通道。
