# Seedance 2.5工作流

## 能力核对
官方检索入口（2026-11-09查阅）：
- https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh
- https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh
- https://docs.volcengine.com/docs/ark/video-generation-tutorial?lang=en

检索摘要能找到Seedance 2.5及视频编辑相关说明；本次模型介绍页面直接打开超时，因此不据此固化参数范围、输入数量或音频规则。具体制作时读取当前官方页面或用户平台实显能力。第三方入口可能提供不同功能，不能把一个入口参数当所有入口参数。

## 输入准备
1. 每名角色提供清楚的脸与全身造型；多人合照说明人物位置和对应身份。无脸三视图不能单独担当人脸参考。
2. 场景图说明地形、可行走路线、桌椅及出入口；尽量提供不被人物遮住的结构。
3. 首帧摆成动作能够合理开始的状态，不把大幅扭转、手持关系矛盾或悬空姿态交给模型补救。
4. 使用尾帧时确保位移、朝向、光线和道具状态能在所设时长内达到；不合理则改尾帧或拆镜。
5. 动作参考只承担节奏或动作功能，不允许覆盖角色面孔和服装。
6. 若支持音频参考，标清配音/表演/音乐用途，说明是否要求对应口型；不要擅自假设全部音频都会用于说话。

## 生成与迭代
先验证单个角色反应和同场光感，再验证双人互动，最后做群戏。角色接触、道具交接或水面动作各做重点抽查。先选动作最清楚的一版，再增加环境细节。

长场景按戏剧节拍拆分，不按固定秒数机械切割。每镜保存起始状态、末尾状态、使用素材版本、提示词和实际问题。把上一镜确认的末尾状态作为下一镜的连续性依据；不默认末帧自动适合作为下镜首帧。

重生成时保留已正确部分，只改主要问题；复杂动作不稳定时优先减少同时发生的动作，再考虑改景别。用反应镜头或物件特写组织剪辑，不靠乱切掩盖因果缺失。

## 参数与后期
平台参数独立记录：已选模型、任务类型、画幅、实际允许的时长与分辨率、声音开关及已绑定素材。没有查看界面或文档时以“待平台确认”标注。

对白校对、字幕、片名、需要准确文字的黑板、漫画图标、精细声音混音优先作为可控后期任务。若入口没有负面提示词栏，把少量关键约束写进主提示词，不虚构negative_prompt接口。

提示词中的分秒只表达导演意图，不保证逐帧执行。最终以输出视频为准检查、剪辑和返修；不因写了“严格同步”就宣布嘴型准确。
