# 逐镜提示词与返修实例

以下为依据剧本情境的导演化示例，节拍与秒数属于制作建议，不是原稿的固定分镜或模型硬参数。实际使用前绑定批准的角色和场景图，填写服装版本，并按平台能力设置时长。示例均不要求模型自动生成准确字幕。

## 示例一：第一集，公鸡追逐的反应镜头
参考绑定：嘎蛋本场春装角色图锁定脸和全身；芦铁锤资产图锁定动物结构；村路图锁定空间与光线。

剧情目的：让嘎蛋嘴硬与身体退缩形成反差。本镜为追逐前反应设计，不改变后续被啄的剧情。

建议6秒，16:9。原创中国农村3D卡通动画电影，现代辽西桃花吐的干净村路，春日柔和阳光，墙后桃花形成柔软色块。嘎蛋严格采用已绑定本场春装参考，圆方脸、小蒜瓣鼻、两颗大门牙、短硬黑发和衣服保持一致。芦铁锤采用已绑定公鸡资产，正常双足站立，翅膀为翅膀，保持同一体型。

固定机位，中全景、儿童视线高度。嘎蛋在画面右侧，公鸡在左侧，二者相距约两步，镜头全程保留嘎蛋双脚。前段，嘎蛋挺胸、右嘴角扬起，手指刚要朝公鸡点过去；公鸡压低头、单眼盯住他，向前重重迈一步。中段，嘎蛋伸出的食指慢慢蜷回掌心，笑容停在脸上，眼皮抬高，身体还努力挺着，右脚却悄悄往后挪半步并落稳。后段，公鸡再短促上前一步，嘎蛋肩膀一缩，迅速转身向画面右侧起跑；身体先走、书包略迟摆起。公鸡随后起跑，保持同一方向和距离逻辑。切在嘎蛋已经完成第一步落地、第二步抬起时，衔接下镜侧向追逐。

无对白。保留鸟鸣、轻风、鸡爪踏地与鞋底摩擦；嘎蛋收回手指时音乐短暂留空，起跑时用轻短节奏承接。笑点来自身体背叛嘴硬，不添加屏幕大字，不全程抖镜。角色结构、脚底承重、眼神目标、世界光源保持稳定。

验收：先看清嘎蛋自信，再看到手和脚退缩；两眼看公鸡，不斗鸡眼；结束姿态可接追逐。

## 示例二：第六集，金鑫第一次打水漂
为了避免同镜同时处理教学、投掷、连续水漂与多人表演，拆成三个镜头。延续同一下午、同一河滩和人物站位。

| 镜 | 建议时长 | 核心动作 | 接口 |
| --- | --- | --- | --- |
| 6A | 5秒 | 金鑫努力摆姿势，嘎蛋一本正经示范站位 | 金鑫右手持扁石，侧身准备 |
| 6B | 4秒 | 金鑫投石，石头直接沉水，留出水面安静瞬间 | 小水花消失，切金鑫反应 |
| 6C | 5秒 | 金鑫保持投掷姿势愣住，嘎蛋把鼓掌的手收回 | 两人准备重来 |

### 6B可复制正文
建议4秒，16:9。中国农村3D卡通动画电影。夏日下午的小凌河岸边，使用已绑定河滩场景；金鑫采用本场夏装参考，保持圆脸、粉白肤色、柔软黑短发和儿童比例。侧后方中全景，金鑫在近景岸边，投掷区是画面右侧一小片清楚水面；嘎蛋在左后方安全站定。机位固定，保留金鑫身体与投掷目标。

开始时金鑫侧身，右手在身后捏着一块扁石，双脚一前一后。先认真抿嘴、压低身体，把动作摆得像参加大赛；随后重心移到前脚，右手一次向前挥出，扁石从手中脱离，以略陡的角度落入近岸画面右侧水面，只发出一次小小的“咕咚”，出现一圈涟漪，没有连续水漂。金鑫手臂停在出手后的方向，等着后续水花，水面却安静下来。末尾保留半拍等待，接下镜反应。

无对白，保留水声和一声清楚的入水音；不加连续弹跳音。石头离手后掌心为空，右手不再生成第二块石头。人物不入水，嘎蛋本镜不抢动作。光线、服装和银幕方向与前镜一致。

### 6C可复制正文
建议5秒，16:9。沿用已绑定夏日河滩和金鑫、嘎蛋夏装角色参考。中景、岸上儿童视线高度，金鑫在右、嘎蛋在左，二人看向画外右侧的同一处落石点；固定镜头。

金鑫仍保持前脚承重、右手投出后的姿态，眨一下眼，先看水面，再转眼看嘎蛋，下巴慢慢收回，眉毛一高一低地困惑；肩膀逐渐松下来。嘎蛋原本已把双手举到准备鼓掌的位置，看到结果后停住，眼神先追一下水面，抿住笑，缓缓把手分开放低，再一本正经地点一下头。两人的动作错开，不同时做夸张反应。金鑫轻声说原剧本台词：“咋回事？”嘎蛋本镜不接话，留给下镜“姿势不对。再来！”的空间。结尾金鑫右手自然放下，嘎蛋准备示范。

水声、风声持续；金鑫发问时音乐减弱，不用罐头笑声。保持同一脸型、发型和服装，双眼聚焦，不让金鑫突然变成一直哭泣的表情。

## 示例三：第四集病房承诺的反差原则
若用户要求“病房也更搞笑”，保留承诺核心，以进病房前想打喷嚏却忍住等轻微生活反应承接；进入老校长病情与拉钩段落后收敛。用手指犹豫、轻轻勾住、呼吸变慢和看向老师表达情绪。不要在老校长说承诺时插Q版、弹簧音或夸张大哭。只提表演处理，不擅自改台词或给病情作医学判断。

## 返修模板
原镜问题：{观察到的具体问题与时段}。
保留：{角色身份、衣服、场景、机位、光源、已经正确的动作}。
本轮调整：{一项可见改变}。
重新描述：{明确起点→主动作→接触或结果→末尾状态}。
验收：{可观看确认的条件}。

例：原镜嘎蛋脚滑。保留人物脸、春装、固定中全景和村路。将后退改为右脚抬起、向后落地承重，左脚随后收半步，鞋底触地后固定，不保持双脚贴地平移。书包只在身体移动后轻摆一次。验收看完整脚底接触过程，而不是增加更多“禁止滑步”的重复句。
