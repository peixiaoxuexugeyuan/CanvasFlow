# 剧本制作依据

来源：用户上传《AI漫剧剧本〈嘎蛋班长〉（终版1021）.docx》，正文标题“14集AI漫剧剧本”，编剧李铭。完整正文见 script-1021.txt。不要从文件名推导未经正文支持的剧情。

## 基础锁定
时间为现代；地点为辽西丘陵桃花吐，核心地理为桃花山和小凌河。故事由嘎蛋当上班长、兑现对老校长的承诺推进；照顾吴老师、留下金鑫和诺诺、照顾全班是责任主线。

正文编辑提示优先：人物衣服不能老土或默认破洞，四季换装；农村校园和环境必须干净整洁，有新农村气象。正文局部出现旧衣、破口或泥迹时，保留故事需要的状态，但设定板默认不据此添加破损。若用户明确要求全程无破损，使用衣褶、积雪和姿态表现劳作。

## 人物造型识别
嘎蛋10岁，五年级，圆方小黑脸、双酒窝、小蒜瓣鼻、两颗大门牙、硬密短黑发。诺诺10岁，偏长鹅蛋脸、奶白偏冷、粗黑一字眉、浅褐眼、小虎牙、齐耳短发。金鑫10岁，小圆脸、偏粉白净、深双眼皮、眼尾略垂、柔软短发。李山杏11岁，长圆脸、单眼皮略下垂、沉静，原稿长辫；若批准图有不同发式则以批准图锁定。巴根11岁，蒙古族、长脸、暖棕皮肤、细长单眼皮、银色细框眼镜。穆羊羊10岁，瘦长、黑红皮肤、近视眼镜、厚唇、硬板寸。李小满10岁，圆脸、瓷实偏胖、粉红脸颊、小眼、小翘鼻、轻自然卷。

吴老师28岁，孕期随剧情推进，不能每季肚子一样大；第13集生产后不能继续沿用孕晚期造型。老校长59岁，病情和体力按场次区分；不把所有出场做成同样虚弱。爷爷70多岁，耳背、编筐手艺，温厚有生活经验。

芦铁锤是体型偏大的芦花公鸡，红鸡冠、墨绿尾羽，四趾足结构按批准资产保持。朱美丽是粉白色圆厚母猪，四足正常承重。动物语言仅用于原稿梦境、主观表达或彩蛋的特定段落。

## 明确的改编边界
原稿有漫画格、分屏、Q版豆豆眼和冲击波。制作连续电影3D风格时，先标为风格化插入；可以提出以表情、动作、音效替换，但不能未经说明删除关键情节。原稿多次出现“六个孩子”而主要孩子有七人：具体场次先列出实际出场名单，不默认删掉穆羊羊或另补一人。
