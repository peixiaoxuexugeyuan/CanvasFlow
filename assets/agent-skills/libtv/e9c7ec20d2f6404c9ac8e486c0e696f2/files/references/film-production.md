# 动画电影制作补充流程

## 1. 故事节奏与动态分镜
先确定场景的进入信息、欲望、阻力、转折、情绪落点及离场钩子，再拆镜。14集剧本不自动等于一部长片；用户要求长片改编时先整理段落取舍、主线和时长结构，再写镜头，不把各集直接拼接后宣称完成长片剧本。

在视频生成前，用分镜静帧、临时对白、音效和占位音乐剪成动态分镜。逐场核对总长、对白可说完、笑点前置信息与反应余量。普通喜剧节拍可按“铺垫—重复—升级/反转”组织，但不为凑三次重复拖慢剧情。让吵闹后有安静，搞笑后留情绪余味。

没有剪辑工具时交付带时码的动态分镜方案，标注尚未形成可播放样片。不能把分镜表叫作已制作的动态分镜视频。

## 2. 资产与尺度
制作前建立角色脸部/全身/侧背参考、表情表、动作表、四季服装、主要道具多角度、场景平面关系和关键色图。缺少参考时列缺口，先用占位方案继续规划；不擅自重设已批准角色。

用孩子身高、课桌、门、球台等建立相对尺度，同一空间各镜继承。镜头资产清单记录版本、角色体型差异、眼镜、头绳、鞋、书包、道具持手及湿/干、完好/临时损坏状态。命名建议“集_场_镜_资产版本_候选版本”，以当前批准状态为准，禁用尚未批准候选覆盖基准。

## 3. 动画表演与关键姿势
把动画原则落实到可见运动：清楚的动作线与剪影、反向预备、缓入缓出、弧线、重心转移、惯性跟随、身体不同部位错峰到位。第二动作服务主动作，例如说谎时搓衣角，不能同时挥手、蹦跳、转圈抢占注意力。

为关键动作规划起始、预备、峰值/接触、收势四类姿态；这是供设计和检查的姿态，不要求每个入口都支持四张关键帧输入。平台只支持首尾帧时，保留中间姿态作校验参考。

对白镜先设计听与想，再开口；目光领先转头，头和身体依意图跟上。情绪不靠每句点头、每字眨眼。保持呼吸、重量和角色习惯，动作空隙不等于完全冻结。

跑跳、追逐和摔倒保持起跳、腾空、落地、缓冲因果；攀树和交接先固定支撑点。动物保持物种骨架，幻想变形与现实明确分层。

## 4. 布局、群戏和摄影
先画出人物站位、通道、主轴与前中后景。群戏确定谁拥有当前注意力，主动作发生时背景只作低幅反应。不要为了七人都出镜让每人同时做招牌动作，也不要让角色随机复制成群。

根据叙事选视角和透视；儿童场景以儿童视线高度为常用基准。特写保留肩颈或环境线索，景深保留关键道具，动作镜不要把手脚切出画面。焦点转移只用于明确的信息揭示，不全镜来回抽焦。大幅广角贴脸容易改变造型，需要参考约束和近景校验。

维持世界坐标、银幕方向、视线匹配、动作接点和遮挡关系。拍下一个机位前检查前镜末态；需要省略时间时给明确转场依据，避免误把动作跳变当正常连续。

## 5. 环境动画、特效与遮挡
风驱动树叶、头发和衣摆时方向统一，按材质和重量错峰运动。大树主干不随微风摆成橡胶；背景保持空间稳定，不随推镜融化。

水、雨、雪、泥、火、烟与尘各选主要效果：雨滴与湿面形成过程连续，雪地脚印与行走路线对应，水花来自具体接触，火光和烟量服从场景尺度。控制粒子密度，不用闪粉、漂浮灰点或白噪点冒充电影细节。前景植被可作遮挡，但关键动作和表情转折时须可读。

有精确物理关系的碰撞/接力优先拆镜和使用清楚接触姿态。需要单独合成的效果列为后期任务，不声称普通生成视频自动提供深度、运动矢量、透明或特效分层。

## 6. 声音、口型与音乐
建立角色声线卡：年龄感、音色、语速、情绪范围、常用停顿；保持同角色跨镜稳定，嘎蛋“嘎”读三声。东北生活语感自然，避免全员夸张喊话和同一腔调。原台词不擅自改写；压缩需求先标明改编。

先用实际朗读或音频长度确认对白能否装进镜头，再安排动作，情绪停顿另留余量。标明说话者、说话区间、闭口聆听者，防止多人嘴同时动；角色转身或遮嘴时仍保持发声归属。需要准确口型时核对实际音轨和嘴形；支持音频输入不等于自动通过验收。

区分对白、动作拟音、环境底声、音乐及必要静默。声源远近和左右位置跟随场景；反应停顿可减音乐但不断掉全部环境音。喜剧音效对准动作关键接触，不每步都加弹簧音；亲情、道歉、病房保留呼吸和空间。全片音乐用主题和变奏建立情感，不持续铺同一种欢快曲。

## 7. 剪辑、合成与调色
按动态分镜先组场景，优先保证因果和表演完整。动作高潮不随意切走，反应镜留够理解时间；对白可声音先行或延后，确保关系清楚。片段接点保留可用余量，必要时以环境镜或物件特写衔接，但不要用空镜填补未完成剧情。

先校正同场曝光、白平衡和肤色，再进行全片风格调色；不同季节保留差异，同一角色仍是同一肤色。去噪、锐化、补帧、放大均先检查头发、眼睛、牙齿和快速动作，失败时回源修复；不要把补帧或高分辨率当电影质感的替代。

文字、黑板、片名和字幕需单独校对；准确文字优先后期添加。合成元素的透视、遮挡、景深、模糊与光线匹配。没有实际分层时不要交付虚构的工程通道。

## 8. 审片关卡与交付
| 关卡 | 必须确认 | 未通过时处理 |
| --- | --- | --- |
| 剧本/资产 | 主线、场次目的、角色版本、季节和相对尺度 | 先补清楚，不盲目批量生成 |
| 动态分镜 | 总长、对白、空间、节奏、笑点与情绪 | 调整镜头长度/顺序，重新预览 |
| 单镜 | 身份、表演、接触、光向、背景、口型 | 按主问题返修，记录候选 |
| 场景 | 接点、方向、光色、声音连续 | 组接后看，不只看独立镜头 |
| 全片 | 成长弧线、节奏变化、音乐发展、画质一致 | 按影响排序修复 |
| 导出 | 画幅、实际分辨率/帧率、音轨、字幕、片尾和播放 | 实测文件后才声称可交付 |

导出前根据实际播放场景确认横竖版、分辨率、帧率、容器/编码、声音和字幕要求；未指定时给交付建议，不把建议宣称为影院放映标准。检查缺帧、黑帧、闪烁、声音削波、字幕错字及首尾截断。影院DCP、多声道等另按院线交付规格制作，普通MP4不能称为影院母版。

保留批准版、镜头清单、参考版本、提示词、实际生成参数、可用原视频、配音/音效/音乐来源和最终工程；能获得多少保存多少，缺项如实说明。没有视频生成/剪辑工具时，交付的是制作方案与提示词，不能把文档校验等同于成片验收。
