# 《嘎蛋班长》｜Seedance 2.5 3D卡通动画导演

## 工作目标与依据

把剧本转成可拍、可生成、可剪辑的中国农村儿童3D卡通动画。让观众先看懂人物的愿望和误判，再看到动作与结果。以机灵、童真、友情和兑现诺言统领笑点。

- 默认16:9横版、电影级风格化3D；用户指定其他画幅时服从。
- 以用户本轮明确要求、最新批准的角色/场景图、指定剧本段落为依据；剧本负责剧情，批准图片负责造型。出现冲突时列明冲突，不静默改剧情或换脸。
- 先读 `references/project-bible.md`。处理具体集数时查阅 `references/script-1021.txt` 的对应集，必要时用“第X集”定位。该文件为用户上传DOCX正文提取，不替代原文件中的插图和版式。
- 对照最新上传剧本；存在新版时先读取新版，不把1021版本当永久真相。
- 写提示词时直接交付可复制文本；只有用户要求生图或视频才执行生成。没有视频工具时交付提示词，明确尚未生成或验证视频。
- 不把此Skill描述为Seedance可执行插件或模型权重；它在助手侧规划并编写Seedance提示词。

## 一、制作输入与任务分流

收集或从上下文确定：集/场、剧情目的、角色图及服装版本、场景图、季节时间、片段总长、对白或音频、生成平台和已有素材。缺少非关键项时标注合理假设并继续。

1. 做人物设定：先写人物本体，再写服装和风格模块，最后写设定板布局。
2. 做单镜视频：锁定起始状态，指定一个主动作、一个表情转折和一个落点。
3. 做连续场景：先出简明调度与连续性表，再逐镜提示词。
4. 做画面返修：明确问题、需要改变的局部和必须锁定的条件；优先修复身份、动作、接触、光线。
5. 做全流程：依次交付剧本拆解、资产清单、表演设计、分镜、关键帧、视频提示词、声音方案、剪辑和验收要求。

## 二、中国农村3D卡通美术

- 建立原创中国儿童面孔；保留不同脸型、眉眼、肤色、牙齿和发型，禁止全员同一模板脸。
- 采用清楚的体块、柔软轮廓、简洁面部平面与有弹性的动画表情；保持儿童年龄感。不要用真人毛孔堆积或成人肌肉代替电影细节。
- 优先锁定上传图片的头身比与体型，不另套统一头身比，不把所有儿童拉高、压扁或缩成大头娃娃。
- 让皮肤哑光，保留少量有组织的微纹理；衣服有厚度、缝线与柔软垂感，头发以发束概括。控制塑料高光、颗粒和锐化。
- 使用明亮清透、温暖自然的色彩关系；保留冷暖和明暗层次，避免全画面黄滤镜。夜景、雪天和阴雨分别建立光线逻辑。
- 表现当下辽西丘陵桃花吐：桃花山、小凌河、干净平房校园、整洁院落、炕、菜园、塑料大棚、小卖部和电商生活痕迹。只在剧情需要时出现对应物件。
- 衣服朴素合身、现代、无默认破洞；学校窗明几净，场景不豪华但整洁。剧情造成的临时湿衣、泥点记录为状态，不扩展成常态贫困滤镜。
- 植被依生长关系成簇，近中远细节递减。避免重复叶片贴图、白色碎高光、黑三角、脏斑、马赛克和噪点；不以磨平全部材质解决噪点。

## 三、角色喜剧表演签名

角色动作节奏与轮廓表情与喜剧方法需要避免嘎蛋先挺胸拍板，身体先冲，脑袋后知后觉；心虚时挠后脑、脚尖磨地右嘴角提起露门牙→单眉抬起→笑容卡住→眼神偷瞄；嘴硬与实际退缩错位全程挤眉弄眼；成长后仍毫无责任感诺诺短促利落，叉腰、前跨半步、突然刹住粗眉压低、下巴抬起；一句直话打断嘎蛋的自我陶醉只会生气的暴力女孩；所有段落都薅头发金鑫动作先试探，缩肩抓书包带；熟悉后逐渐舒展先看结果，再看同伴，迟半拍理解后露笑；认真模仿造成小偏差永远哭泣、持续软弱；成长后突然换脸巴根站得笔直、推眼镜、整理姿势，出手前程序齐全正经脸讲规则，结果出乎意料时动作停住，努力维持体面反派化、成人官腔、依靠民族刻板印象搞笑李山杏安静准确，拢碎发、轻轻抬眼，少量动作就有重量无奈侧目、压住笑、平静的一句话；关键情绪渐进释放强行大嘴尖叫、全程愁苦或泛化农村打扮穆羊羊瘦长轮廓，身体先前探，眼镜稍滞后稳定憨直跟随、认真附和、看到结果后才醒悟以视力或家庭处境作羞辱性笑点李小满重心低、步幅短，跑停时腹部和衣摆略跟随肚子先抖后笑，踮脚围观，努力摆权威姿势无休止摔倒或把体型本身当唯一笑点芦铁锤挺胸慢走，偏头单眼观察；攻击前压低身子再短冲小身体配大气势，与嘎蛋虚张声势对照普通鸡任意变手、变四腿；除梦境/彩蛋外随意说话朱美丽四足承重、缓慢转身，体积与惯性可读慢节奏打断孩子快计划，侧身一靠造成局面变化无支撑漂浮、重量消失、反复伤害动物

把签名当选择库，一镜只选相关动作，不让每人机械重复招牌动作。群戏分配主角动作、对手反应和背景小动作，错开节拍。

## 四、夸张表情规范

先写“角色在想什么”，再写眉、眼睑、瞳孔目标、脸颊、嘴角、下颌、头颈的可见变化。

- 日常强度：小幅眉眼变化、呼吸、视线与嘴角传达关系。
- 喜剧强度：眉眼拉开对比、左右不对称、短暂僵住；保留脸型、门牙、虎牙和眼镜等记忆点。
- 峰值强度：在惊吓或反转的瞬间短暂放大口周和脸颊弹性，随即回到锁定模型。用“短暂挤压回弹”表达，避免永久改脸或拉长脖子。
- 情绪强度：病房、思念父母、道歉、兑现承诺时降低动作幅度，让停顿、吞咽、手指收紧和目光转移起作用；不配滑稽音效拆掉情绪。
- 两眼看同一空间目标；近鼻尖物体用侧目、僵住或切物件特写表达。即使原稿写“斗鸡眼”，默认转为上述表演；用户明确保留时仅短暂设计，避免成为常态。
- 让情绪顺序发生，例如“得意→听见名字→眼皮抬起→笑容停住”；不要在同一帧同时要求哭、笑、惊恐和愤怒。
- 保持眼球在眼眶内、牙齿数量稳定、下颌连续；禁止五官融化和表情切换时身份漂移。

## 五、搞笑动作与时间设计

对每个笑点填写：目标→观众已知信息→角色误判→预备→主动作→结果→反应。

1. 给动作清楚的预备：视线确定方向、重心压低、肩膀反向蓄力。
2. 把主动作沿明确动作线执行，保留手脚和道具的轮廓。用中景或全景让观众看清原因与结果。
3. 加惯性与重叠：头先停、书包稍后摆停；脚落地后身体轻微下沉；衣摆再回落。
4. 留反应空隙：让角色先维持自信，察觉结果，再补救。笑点停顿可以是呼吸和眼神活动，不是整段冻结。
5. 用对照增笑：嘎蛋动作大、巴根几乎不动；诺诺一句话，嘎蛋缓缓收回迈出去的脚。
6. 一个生成片段默认一个主要因果链。多人接力、碰撞、道具交接或大幅位移复杂时拆镜，分别锁定接触点。
7. 建议先做约4—8秒的单镜表演测试；这是制作建议，实际时长服从平台支持，不宣称为模型限制。
8. 给每段时间表留首尾呼吸；动作密度过高时延长或拆分，不用加速把多个笑点挤进同一片段。

保持体积、重量和关节结构。短暂挤压拉伸用于峰值，之后恢复；脚不滑步，手不穿物，道具持握关系不断。摔倒先给失衡原因，落地有承重点，恢复姿态有过程。

## 六、导演、摄影与连续性

- 先交代空间，再展示动作；用中全景承载肢体喜剧，用中近景承载反应，特写只抓关键线索或表情转折。
- 每镜一个主要运镜。写明机位高度、景别、运动方向与停点，避免同镜同时环绕、变焦、俯冲和甩镜。
- 固定镜头也必须有表演层次；镜头运动服务信息揭示，不替角色乱晃。
- 追逐先建立路线与障碍，再保持银幕方向；越轴前用中性机位或明确过渡。
- 对话保留视线高度、人物位置和过肩关系。观众应知道谁在看谁，避免所有人看镜头。
- 同场锁定世界中的太阳/窗户/灯具位置、曝光和白平衡；反打时光在画面左右可变，但实际光源不能跟着机位跳动。
- 保留必要环境全景与情绪长镜。漫画分屏、Q版、乌云、灯泡等仅用于剧本指定的主观或漫画桥段；默认保持主体3D比例，图形效果可后期叠加，不整片切成另一风格。
- 转场优先动作接续、声音先行、视线承接与匹配剪辑；不默认叠化、闪黑和随机快切。

每场至少维护：角色及服装版本、发型、道具持手、道具数量/完损、座位与站位、进出方向、光源、天气、季节、吴老师孕期/产后状态、镜头首尾动作。

## 电影布光与全流程补充

制作新场景或调整光感时，读取 `references/film-lighting.md`，先建立场景光感卡，再将可见光效写进每镜。明确主光、填充、轮廓分离、冷暖、曝光、空气层次和动态变化；同场继承世界光源，不机械套用三点布光。喜剧看清眉眼和肢体，温情保留柔和体块，夜景保留暗部，雪地控制高光。用正常播放检查光影连续，防止闪烁和曝光抽动。

制作整场、整集或长片时，读取 `references/film-production.md`，依次执行故事节奏、动态分镜、资产尺度、关键姿势、群戏布局、环境动画、声音口型、剪辑合成、调色和导出验收。仅要求单镜时按需加载相关部分，不强制交付全套表格。先完成低成本节奏验证，再批量生成；不能跳过实际视频审查就宣称电影制作通过。

## 七、Seedance 2.5执行策略

先读 `references/seedance-workflow.md`，再按当前平台能力选择文生视频、图生视频、首尾帧、参考素材或编辑工作流。

- 区分导演指令、平台参数和后期任务；不把“4K、24fps、严格每帧锁定”写进正文就当平台已设置。
- 把角色身份、场景空间和起始姿态交给清晰参考图；把动作因果、表情变化、运镜和声音重点写进正文。
- 为上传的每份参考说明用途。仅在平台支持并实际绑定后使用该平台素材标记；本文的花括号是待填写占位符，不是通用接口语法。
- 每镜提示词自足，包含当前服装和状态；不要只写“同上”。不把多页角色设定全文塞进每镜。
- 使用具体可见动词，少写形容词堆叠。优先级为身份稳定→关键动作→表情转折→摄影→声音→装饰。
- 带对白时先确定字数与语速能否容纳；使用准确台词，标明说话者、起止时段、听者反应。音频驱动仅在入口支持时启用，否则分离生成与配音后期。
- 不承诺时间码是逐帧硬约束。生成后检查实际节拍、口型和时长；失败时缩短因果链、减少角色或拆开动作，不继续堆同义禁令。

## 八、标准交付格式

短任务只交必要部分；连续场景按以下结构：

1. 场景目标：剧情信息、笑点和情绪落点，各一句。
2. 参考绑定：角色、服装、场景、动作或音频素材用途。
3. 分镜表：镜号｜建议时长｜景别/机位｜运镜｜动作与表情节拍｜台词/声音｜首尾衔接。
4. 每镜可复制提示词，使用以下骨架：

```text
镜号：{镜号}；建议时长：{秒数}；画幅：{已设画幅}。
风格与身份：原创中国农村3D卡通动画电影。{角色及服装}严格依据已绑定参考，保持同一脸型、年龄、身材与造型。
场景与起点：{季节、时间、地点、光源、人物位置、道具及起始姿态}。
摄影：{景别、机位、一个主要运镜、停点}。
电影光效：{有来源的主光与填充、人物背景分离、冷暖与曝光、必要动态变化；继承场景光感卡}。
表演：{角色动机}。{前段的预备和目光}；{中段主动作及承重/接触}；{后段结果、表情转折和停顿}。{次要人物错峰反应}。
声音：{指定说话者与准确台词/无对白}；{与接触同步的音效}；{环境音和音乐意图}。
结束：{明确姿态、道具持手、视线和下一镜接口}。
保持：造型稳定，动作重量可信，眼神聚焦，背景空间与光线连续。{最多几条本镜高风险约束}。
```

5. 单列平台设置建议与后期任务：只填写已知可设置项，不虚构接口字段。
6. 列出本段最重要的两三项验收条件。
7. 整场/整集任务另附总时长、光感卡、关键姿势、声音分工、制作缺口及当前通过的审片关卡；未执行部分标为待制作。

制作实例、拆镜和返修模板见 `references/prompt-examples.md`。不要把实例自动当作剧本原镜头或批准改编。

## 九、成片验收与返修

优先检查身份、因果、动作可读性和关键帧，再检查装饰细节。

- 看首帧、中段峰值、末帧及连续播放：人物是否还是同一人，发型服装是否漂移，四肢与道具是否增减。
- 静音看动作：能否看懂笑点；有没有预备、结果、反应，是否连续扮鬼脸却没有信息。
- 看接触帧：脚承重、手持物、座椅支撑、镜片和眼睛是否正确，水与布料是否闪变。
- 看剪辑接点：方向、持手、站位、光线、道具状态是否匹配，是否留出可剪余量。
- 听音画：台词归属、发音、口型、笑点音效、环境声是否准确。嘎蛋的“嘎”读三声。
- 检查农村生活与季节：干净、现代、不猎奇；第8集涉水仅小腿深；第13集吴老师已产后，第14集转入来年春天。
- 对剧本中的自然科普、野外食物和健康相关说法，分清人物说法与已核实事实；需要改成旁白科普时先查证。不要把“蘑菇按颜色辨毒”等对白升级成真实教学。
- 标记问题为身份/动作/时序/接触/摄影/音画/质感，针对一类问题修改一轮；未生成时只报告提示词层面检查，不能声称视频测试通过。
