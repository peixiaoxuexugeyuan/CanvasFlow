# 角色无头三视图设定卡

## 这个技能做什么

为**任意人物**生成一张影视/游戏用的角色设定卡（character turnaround sheet）。固定排版、固定工艺，人物身份完全来自用户输入——本技能与任何具体角色题材（如白衣仙侠）无绑定。

## 固定排版（写死，不随人物变化）

1. **左侧约四分之一**：人物头部与肩胸近景定妆特写，完整面部、真人质感。
2. **右侧四分之三**：横向等分为三个**等宽竖栏**，自左向右依次为**正面、左侧面、背面**全身视图。
3. **正面栏与左侧面栏 = 无头素体**：头部与面部完全不存在，脖颈在衣领上方平切收尾，颈部断面被衣领自然遮挡；但双肩、双臂、双手、躯干、双腿、双脚全部完整保留，自然直立站姿，双手垂于身侧，脚穿鞋。这两栏内不得出现任何头发、发丝、发冠或发饰。
4. **背面栏 = 带头部的背面全身视图**：背对镜头站立，保留完整头部与发型背影（头发自然垂落的后部形态、发饰后部结构），不露出任何面部五官。
5. **三视图比例一致性（最高优先级）**：三栏严格同比例、同缩放系数，如同服装工艺单上的等比三视图；正交平视视角，无透视变形、无镜头推拉、机位距离与焦距完全一致；对齐以身体为准——三栏的肩线、腰线、裙摆下缘（或衣摆下缘）与脚底分别落在同一组水平线上，身形体量完全相同，背面栏在肩线之上额外向上延伸出完整头部与发型；任何一栏的身体都不得比其他栏更大或更小。
6. **背景与光线**：纯浅灰色摄影棚无缝背景，柔和均匀顶光，地面轻微投影，剪裁、面料与发型结构细节清晰可读。
7. **禁止项**（必须逐条写进 prompt）：禁止任何文字、字母、数字、标注线、水印、Logo、界面按钮、边框；**禁止画面中出现分割线、栏间分隔线、竖线、网格线、白线或任何将三个视图隔开的线条**（三个视图之间只靠留白与背景过渡自然分隔）；禁止正面栏与侧面栏出现头部、面部、头发、发冠或发饰；禁止背面栏露出面部五官；禁止三栏身体大小不一、比例不同或透视远近差异。

## 变量部分（由用户输入决定，需引导填充）

- 人物：性别 / 年龄 / 气质
- 发型与发色
- 发饰
- 服装款式与结构
- 面料材质
- 配色
- 纹样细节
- 鞋履

若用户提供了参考图，则以参考图为**唯一人物与服装依据**，并在 prompt 中注明忽略参考图内可能存在的播放器界面、关闭按钮、左右箭头等任何 UI 元素。

## 技术默认值

- 图像模板：`character_turnaround_3view`（角色三视图）
- 宽高比：`16:9` 横版
- 模型：`Lib Image 2.5 Pro`
- 节点 tag：`character`

## 执行流程

1. **接收素材**：拿到用户的新人物参考图（若有）或文字描述。
2. **填充变量**：把用户输入填进下文的变量槽位；未提供的项可自行合理补全或向用户确认。若给了参考图，prompt 中以 `{{参考图节点key}}` 引用，并写明忽略 UI 元素。
3. **创建 image 节点**：`tag=character`，挂载 `character_turnaround_3view` 模板，宽高比 `16:9`，模型 `Lib Image 2.5 Pro`，prompt 用下方模板。
4. **申请用户批准后运行生成**（运行节点需用户批准）。
5. **生成后自检**，重点看三处：
   - 是否出现栏间分割线 / 竖线 / 网格线；
   - 正面栏、侧面栏是否残留头发、发冠或发饰；
   - 三栏比例是否一致（背面是否比正侧更大或更小）。
   若有问题，**在原节点修正 prompt 后重新生成**。

## 已知易翻车点与对策

- **正/侧栏残留头发**：模型会把长发当角色识别特征保留。对策：正向描述「这两栏内不得出现任何头发、发丝、发冠或发饰」，并在禁止行重复一遍，双向夹住。
- **背面栏露出五官**：明确「背对镜头、不露出任何面部五官」，只描述发型背影与发饰后部。
- **三栏比例不一**：靠「等宽三栏 + 正交同焦距 + 肩线/腰线/裙摆/脚底四条同一水平线」三重约束；仍不行时可拆成三个独立节点分别生成后再排版合成。
- **出现分割线**：禁止行里逐项列出「分割线、栏间分隔线、竖线、网格线、白线」，并说明只靠留白与背景过渡分隔。
