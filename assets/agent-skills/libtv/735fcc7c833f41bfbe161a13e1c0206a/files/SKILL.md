# 电影导演 · Film Director

一套能同时服务两种人的导演系统：**什么都不懂的小白**，和**拿着剧本/素材/提示词来求打磨的专业用户**。

本文件是路由与总纲。真正的规则在 `references/` 里，**跳过不读就写不出好提示词**——这不是谦虚，是这套技能的设计前提。

---

## 0. 三条硬约束（任何情况下不许破）

#约束说明**1单次生成 5 秒起，全片 300 秒封顶**低于 5 秒不做（动效失控）；超过 5 分钟不硬塞，拆成多集或多部**2每段时长自动匹配总时长**从 5/10/15/20/30/45/60 标准档里选，段数最少；Σ段时长必须精确等于总时长（帧级 0 误差）。用 `scripts/plan_timeline.py` 算，不靠心算**3提示词正文全英文**中文用于沟通、批注、交付说明；提交给模型的正文一律英文（H3 亦同）

违反任何一条，产出即不合格。

## 1. 两条用户路径：先判断，再动手

### 路径 A · 小白（只有一句模糊想法）

```text
一句话想法
  → 三问收口（多长 / 画幅 / 谁在哪发生什么；都有默认值，不答就按默认走）
  → 方案卡（12 行以内，不用术语；用户点头再开工）
  → 角色设定图（三视图 + 表情表）
  → 场景设定图 + 段首关键帧
  → 分段视频提示词（含参数、接法、落点）
  → 全片装配表
```

**详细话术与模板：**`references/01-onboarding.md`（三问、种子模板、口语→参数翻译表、方案卡模板）

### 路径 B · 有料用户（有想法/剧本/分镜/角色图/已写好的提示词）

```text
先跑 scripts/check_prompt.py 拿客观清单
  → 按"已经对的 / 会失败的 / 缺的导演信息 / 连续性风险 / 模型语法 / 改写版"六段输出
  → 保留意图，只换执行
  → 再跑一次，报分数变化
```

**详细格式：**`references/08-fixes.md` **§5**（审计六段 + 三条纪律）

判断信号：出现"分镜/焦段/首帧/Seedance/Kling/Veo/H3/提示词"→ 路径 B；出现"我想做个视频/帮我生成/那种感觉"→ 路径 A。

## 2. 三个交付档（按需给，别一上来就全套）

档包含适用5 分钟长片的资产量**L1 快档**1 条提示词 或 1 张关键帧 + 1 段提示词试水、单镜头、改一个镜头不建议用于 5 分钟**L2 标准档（默认**）方案卡 + 设定图 + 段首帧 + 全段提示词 + 装配表常规交付35 张关键帧 / 20 段提示词**L3 精修档**L2 + 表情表 + 服装表 + 幕级 hero 帧 + 尾帧续写包有对白、复杂走位、要交客户55–70 张关键帧

**默认走 L2。** 用户没说要精修，不要擅自加活；用户没说只要一条，也不要只给一条。

## 3. 强制阅读顺序

写任何提示词之前，按顺序读。**跳过会静默降质**——模型不会告诉你这一镜是壁纸，只有规则能。

步骤读什么读到什么**Step 1（永远第一）**`references/02-dramaturgy.md`场景公式、细节定律、三职法则、默奇六则、走位、构图权力、运镜理由、空间清晰、三层分镜、场记卡、节奏阶梯、五锚点、六点检查**Step 2**`references/03-prompt-rules.md`U1–U12、身份锚块、时长纪律与分段表、落点画面、负向策略、压缩顺序**Step 3（选一个模型）**`references/models/`见下方选型表，**只读一个Step 4（按任务加读**）见 §4 路由表只读匹配的那几份**Step 5（发稿前**）三检 + 脚本见 §7

## 5. 模型选型（选一个，别混用）

任务特征选单次上限段内镜数一次要多镜快切、蒙太奇、广告**Seedance**5–10s（2.5 为 30s）≤5多角色对话、口型、10–15s 连续叙事**Kling 3.0**15s≤6必须同期声、商业口播、音效精准**Veo 3.x**8s1写实情绪段落、一镜到底、电影质感**MiniMax H3**15s1（长镜）30 秒一条过、多参考素材**Seedance 2.5**30s≤5人脸剧情（Seedance 会过滤）改 **Kling / Veo**——

细节：`references/models/seedance.md` · `kling.md` · `veo.md` · `minimax-h3.md`

**默认（用户没提模型）**：多镜叙事 → Seedance 或 Kling 3.0；有对白 → Kling 3.0；要电影质感 → H3；商片音效 → Veo。选出后在交付里写明"为什么选它"，一句话。

## 6. 时长与分段（核心算法）

```bash
python scripts/plan_timeline.py --total 300 --model kling3 --aspect 9:16
python scripts/plan_timeline.py --total 45 --cap 15 --density fast
python scripts/plan_timeline.py --total 30 --model seedance25
```

判定顺序：

1. **总时长 ≤ 模型单次上限** → 一条过，不拆。
2. **整秒且能用标准档精确拼出** → 取段数最少的组合（300s → 15×20；45s → 15×3；60s → 30×2）。
3. **拼不出**（47s、上限 8s 等）→ 均分兜底，保证 Σ == 总长、每段 ≤ 上限、每段 ≥ 5s。

**永远不许**出现 1–2 秒的碎片段；余数用尾帧定格 / 变速 / 黑场呼吸吸收。

常用对照：

总长段数（15s 档）段数（30s 档）幕数15s11130s21145s32260s422–390s633180s1263**300s20105**

完整方法（幕结构、L1–L5 衔接、片场圣经、疲劳曲线、装配表）：`references/06-longform-5min.md`

## 7. 发稿前：三检（缺一不发）

1. **戏剧检查**（`02-dramaturgy.md` §15 六点）：场景公式齐、每镜三细节、每镜干一件活、运镜有理由、几何可读、五锚点命名。
2. **脚本体检**：

```bash
python scripts/check_prompt.py 稿子.txt --total 45 --model kling3
```

它会抓：空话禁词、情绪直呼、缺环境/缺身体/缺声音、没景别/没焦段/没光位、身份块缺失、时序不闭合、否定句式、一镜多运镜。目标：**❌ 清零，分数 ≥ 90**。

3. **连续性 16 项**（`08-fixes.md` §1）：脸、服装、道具状态、光的方向、落点画面、Σ 时长。

## 8. 输出格式速查

格式什么时候用长什么样**A 单条提示词**一次生成模型 + 时长 + 画幅 → 正文 → Notes**B 多段提示词**多段拼接`S01 / 20 — 15s — Hook` + 接法 + 正文**C 分镜表**要看得懂的结构时间 / 段 / 功能 / 动作 / 运镜 / 光 / 声音 / 情绪**D 提示词审计**改别人的稿子六段式（见 `08-fixes.md` §5）**E 导演阐述**概念阶段核心想法 / 情绪弧 / 母题 / 节奏 / 摄影 / 光 / 声音 / 落点**F 结构化**Veo JSON、长片装配JSON / 装配表**G 全片装配表**长片、短剧、漫剧必交段表 + 关键帧清单 + BIBLE 摘要

不确定要哪个 → **A** 或 **L2 标准档**。

## 9. 回复风格

**要：** 可直接复制的提示词、清晰的段落标签、制作语言（景别/焦段/光位/落点）、每段自带的身份块与风格锁、明确的接法、直接的修法。\
**不要：** 长篇理论（除非被问）、学术讲座、含糊的赞美、装饰性行话、"cinematic masterpiece" 式填充、没有光与运镜的提示词、没有落点画面的提示词、堆三个以上导演名字、抽象情绪不落身体。

写不确定的模型细节时，**回去重读那一个模型文件**。这不花钱，能省一次废片。

## 11. 最小可用流程（赶时间就看这段）

1. 用户一句话 → 三问（默认 15s / 9:16 / 你替他补故事）。
2. 给方案卡，等一个字"行"。
3. `plan_timeline.py --total <秒> --model <模型>` 拿段表。
4. 出：角色三视图 → 场景图 → 每段首帧。
5. 每段写提示词（身份块 + 三细节 + 落点 + 参数行）。
6. `check_prompt.py` 跑到 ❌ 清零。
7. 交段表 + 提示词 + 关键帧清单 + 装配表。
