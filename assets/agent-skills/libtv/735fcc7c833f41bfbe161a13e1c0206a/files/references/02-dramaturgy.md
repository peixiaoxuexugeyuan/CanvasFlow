# 02 · 戏剧法：让画面有戏，而不是壁纸

## 1. 第一定律：场景公式

一个场景成立，必须五个元素全在：

```text
场景 = 主角的欲望 + 障碍 + 空间几何 + 被控制的视线 + 剪辑节奏
```

缺一个，场景就塌成装饰。

- **欲望**：这一秒他想要什么（不是"他想要幸福"，是"他想让这句话不被说出口"）。
- **障碍**：谁/什么挡着。物件、人、恐惧、距离、规矩。
- **空间几何**：谁站哪儿，谁占权力位，哪个方向是威胁，哪个方向是出口。
- **被控制的视线**：观众的眼睛被强制看哪一点。一帧只能有一个焦点。
- **剪辑节奏**：每个镜头活多久，停顿落在哪，切口咬在哪。

**写提示词之前，先用一句话把五个元素说出来。说不出来 = 这场戏还没想好。**

## 2. 第二定律：细节即情绪，偷懒毁提示词

场景公式告诉你"什么是场景"；细节定律告诉你"每个镜头怎么写"。跳过后，即使结构完美，出来也是糊的。

> **每个镜头必须拥有三个具体物理细节：一条环境压力、一个身体微动作、一个声音锚点或视觉母题。**

### 三细节规则

写每一镜之前，先认领这三样：

1. **环境压力**——空间里承载情绪的物理事实。 冰箱冷白光 / 湿沥青 / 老化的日光灯在闪 / 水壶蒸汽 / 只湿了一扇的窗 / 空调外机在嗡 / 走廊太窄 / 镜面反射。
2. **身体微动作**——情绪只能落在身体上，落不在名词上。 牙关咬紧 / 指节发白 / 嘴唇压成一条线 / 视线下移半寸 / 吞咽一次 / 手指在门框上收紧。
3. **声音锚点或视觉母题**——挂在情绪脊椎上的可复现感知钩子。 胃叫，全片出现三次 / 每次转场都是暗玻璃里的倒影 / 每次"裂"那一拍都有同一声低频 / 秒针 / 空走廊的脚步。

**零条 = 废镜，删掉。一条 = 太薄。强镜头三条都有。** 这件事模型不会替你做。

### 禁用词（写了就是偷懒）

- `cinematic`、`professional`、`high quality`、`masterpiece`、`stunning`、`epic`、`amazing`
- `beautiful lighting`、`dynamic camera`、`intense moment`、`powerful scene`
- 「他很伤心」「她很生气」「他害怕」——只命名情绪、没给身体
- 中文同义系列：电影感、大片感、高级感、氛围感、唯美、震撼、质感拉满

每一条都必须换成具体物理事实。换不出来 = 这场戏还没想透。

### 细节与戏剧层的对应

戏剧层默认细节寄存器场景公式环境压力（障碍的几何与气氛）三职法则身体微动作（情绪/行动/压力变化时，身体先动）五锚点声音与视觉母题（母题就是锚点，落点镜头承载母题）

镜头的细节集和它的戏剧功能不匹配，功能就不会在屏幕上发生。

## 3. 三职法则：每个镜头必须干一件事

三件事至少干一件，一件都不干就删：

- **改变情绪**（主角的、观众的、或两人之间的动态）
- **推进动作**（新的物理事件、新信息、新位置）
- **增加压力**（赌注升高、时间逼近、空间收窄、目击者出现）

「漂亮的空镜」「产品英雄镜头」都不是职业。要么它对上面三件事之一有用，要么它是**只有包装没有糖**。

## 4. 沃尔特·默奇剪辑六则

《现代启示录》《教父 2》《英国病人》的剪辑师给出的优先级。**每一条都比它下面所有条加起来更重。**

1. **情绪（51%）**——这个切口是否忠于此刻的情绪真实。
2. **故事（23%）**——是否推进故事或揭示人物。
3. **节奏（10%）**——是否落在这一场戏的音乐拍点上。
4. **视线轨迹（7%）**——切的那一瞬观众在看哪，新镜头能不能接住这道视线。
5. **二维平面（5%）**——是否尊重画面左右方向的轴线。
6. **三维空间（4%）**——是否尊重真实空间的几何。

**实际后果**：为了「节奏爽」而切，只排在第 3 位。不服务情绪和故事就猛切，得到的是给注意力缺陷做的广告。

## 5. 走位 = 欲望的编舞

走位不是「演员站哪儿」，而是「他想要什么、从谁那里要」的视觉回答。

给场景里每个角色回答：

- 此刻他要什么？
- 他向谁/什么靠近？
- 他远离谁/什么？
- 他把谁逼到角落？
- 他把空间让给谁？
- 哪个手势泄露了隐藏欲望？

❌ 差：「他站在窗边。」 ✅ 好：「他往窗边挪，但肩膀始终斜着朝她，好像这场对话还拽着他。」

## 6. 构图调度决定潜台词

人物、物件、摄影机在画框里的排布，在台词出现之前就已经说完了冲突。

**构图的权力信号：**

- 站着的人压过坐着的人。
- 站在门口的人控制整个房间。
- 隔着玻璃或出现在倒影里的人，心理上是远的。
- 在阴影里的人携带威胁或悲伤。
- 人物周围的负空间 = 孤立。
- 紧画框 = 窒息。
- 同框但没有眼神接触 = 亲密关系已断。

写提示词之前，先说出这个构图揭示的权力关系。

## 7. 运镜必须有理由

芬奇规则：每个运镜都要回答「什么变了？」答案是"没变"，镜头就该是定镜。

**运镜的合法理由：**

- 角色做了决定，镜头跟着这个转变走。
- 画面里出现了新信息。
- 压力升级，镜头收紧。
- 角色看了一眼，镜头给出他看见的东西。
- 一个动作把焦点拉走，镜头跟着变焦。
- 空间变了（门开了、有人进来）。

❌ 差：「电影感的滑轨运镜。」 ✅ 好：「推镜从她说'我不知道'开始，停在她的牙关咬紧那一帧。」

---

## 8. 空间清晰 &gt; 剪辑癫狂

斯皮尔伯格原则：再乱，观众也必须知道——主角在哪、威胁在哪、哪个方向是逃、哪个方向是决定。

**高手是又快又慌、但依然可读。** 没有地理关系的甩镜和频闪切，会直接杀死戏。影史最快的动作场面（斯皮尔伯格、乔治·米勒、早期迈克尔·贝）都建立在一条清晰的几何地图上。

写快切段落前，先用一句话画出地图：「主角从左往右移动，威胁从画面上方进入，出口在画外右侧。」

---

## 9. 环境是演员

黑泽明原则：天气与环境是角色，它们放大状态。

短片的做法：**一场戏只挑一条环境压力，让它扛情绪。**

环境压力承载的情绪荧光灯闪衰败、官僚、不祥窗上的雨忍住的悲伤水壶蒸汽压住的愤怒空调嗡鸣抽离、解离夜里的湿沥青内疚太窄的走廊墙在收拢镜子 / 玻璃自我审判顶部冷白办公灯被审视

## 10. 三层分镜法

按顺序做三层。跳过任何一层，产出漂亮但空洞。

### 第 1 层 · 戏剧节拍

60–90 秒片的可靠节拍图：

```text
00–05s  钩子    主角已在紧张中，不做铺垫，问题直接上屏
05–15s  语境    我们在哪，谁在附近，赌注是什么
15–30s  加压    主角试图维持控制
30–45s  裂缝    一个细节出现，打破主角的位置
45–60s  加速    镜头变短，呼吸变紧
60–75s  冲击    决定、崩断、坦白或动作
75–90s  余味    短暂的静，或视觉残留
```

**30s / 15s 按比例压缩，但"裂缝"和"冲击"永远不许省。**

### 第 2 层 · 镜头功能

每个镜头打一个功能标签（与 `references/05-storyboard-keyframes.md` 同一套）：

标签回答的问题**Establish 建立**我们在哪**Reveal 揭示**什么出现了，新信息进入画面**Power 权力**现在谁控制这场戏**Pressure 压力**什么在往下压**Detail 细节**物件、手、眼、门缝、收据——宏观锚点**Reaction 反应**事件之后的脸**Shift 转变**内在变化被看见**Impact 冲击**决定性的那一帧**Aftermath 余波**动作之后的空**Exit 离场**观众带走的最后一帧

一场完整的戏通常走：Establish → Power → Pressure → Detail → Reaction → Shift → Impact → Aftermath → Exit。

### 第 3 层 · 剪辑节奏

不是随机剁碎，是一座节奏阶梯：

```text
长 —— 短一些 —— 更短 —— 停顿 —— 冲击
```

8–10 秒蒙太奇的内部结构示例：

- 4s 全景，主角进入
- 2s 中景，他注意到那个东西
- 1s 特写，眼睛
- 0.5s（12 帧）物件微距
- 0.33s（8 帧）手
- 0.25s（6 帧）细节 / 声效点
- 2s 突然安静
- 1s 决定

**规则：冲击前的停顿，比切得多快更重要。** 没有停顿的速度只是绞肉机。

## 11. 场记卡（14 字段）

分镜每一格都填满。空字段暴露的是"没想清楚"。

```text
1  镜号        01 / 02 / 03
2  节拍        故事在这里变了什么
3  情绪        恐惧 / 羞耻 / 愤怒 / 内疚 / 决意 / 释然
4  景别        远景 / 中景 / 特写 / 微距插入
5  构图        中心 / 边缘 / 负空间 / 倒影 / 剪影 / 前景遮挡
6  运镜        定镜 / 推 / 手持 / 跟 / 甩
7  运镜理由    什么变了才让镜头动
8  动作        精确的物理事件
9  视线轨迹    前 0.3 秒观众的眼睛应该落在哪
10 时长        0.5s / 1s / 3s
11 切法        动作接 / 硬切 / 跳切 / J-cut / L-cut
12 声音        呼吸 / 低频撞击 / 街噪 / 电话铃 / 静音
13 光与色      冷 / 高反差 / 闪 / 阴影 / 具体色板
14 执行备注    道具、场景、演员指令
```

空一项就填，填不出来就砍掉这个镜头。

## 12. 节奏阶梯

戏的节奏不是均匀的，是台阶式的。

类型镜头长度序列慢燃烧的剧情4s, 4s, 3s, 2s, 1s, 停顿, 2s广告产品弧3s, 2s, 1.5s, 1s, 0.5s（产品微距）, 2s（英雄镜头）焦虑累积2s, 1s, 1s, 0.5s, 0.5s, 0.3s, 停顿, 1s冲击场景停顿, 0.2s（闪现）, 2s（静止的余波）

**永远在最大的那个切之前，插一次停顿。**

## 13. 五锚点原则

任何短片，只认领五个锚点，不多不少：

- 一个主情绪
- 一个视觉母题
- 一个锚点物件
- 一次断裂
- 一个落点画面

示例：

- 情绪：愧疚
- 母题：他反复被玻璃反射（窗、手机屏、电梯门）
- 锚点物件：一条未读消息的手机
- 断裂：他把消息删了
- 落点画面：他的脸留在暗下来的手机屏上

这五样可以分镜、可以提示、可以剪在一起，重量远胜堆一万遍"cinematic, professional, masterpiece"。

## 14. 完整案例：30 秒，愧疚

### 五锚点

- 情绪：愧疚 / 母题：玻璃上的倒影 / 物件：有未读消息的手机 / 断裂：他删掉它 / 落点：他的脸留在暗掉的手机屏上

### 第 1 层 · 节拍

- 0–3s 钩子：手机在暗桌上震动，他的脸被屏幕从下方照亮。
- 3–10s 语境：加班后的小办公室，空工位，冷白荧光，显示器里有他的倒影。
- 10–18s 加压：他盯着消息预览，下颌收紧，手悬着。
- 18–22s 裂缝：他开始打字，停住，一个字一个字删掉。
- 22–26s 加速：快切——手指、屏幕、眼睛、呼吸、窗上的倒影。
- 26–28s 冲击：他按"删除对话"。一下。静。
- 28–30s 余味：屏幕黑掉，他的脸留在暗玻璃上。

### 第 2 层 · 镜头功能（部分）

- 03 Establish 空办公室 ｜ 05 Power 他独自一人，房间压着他 ｜ 07 Detail 手机屏特写 ｜ 09 Reaction 下颌收紧 ｜ 11 Shift 手在键盘上犹豫 ｜ 13 Impact 拇指按下删除 ｜ 14 Aftermath 黑屏里的倒影

### 第 3 层 · 最后 10 秒节奏

```text
2.0s  手指悬在"删除"上方
1.0s  他的脸
0.5s  拇指
0.5s  确认弹窗
1.0s  他的眼睛
0.5s  拇指按下
3.0s  静音，屏幕黑掉
1.5s  暗屏上他的倒影
```

到这里每个节拍都可以翻成模型提示词，见 `references/models/`。

## 15. 发出前的戏剧检查（六点，不许跳过）

1. **场景公式齐了吗？**（欲望 + 障碍 + 几何 + 视线 + 节奏）
2. **每一镜过了三细节吗？**（环境压力 + 身体微动作 + 声音或视觉母题）
3. **每一镜干了一件活吗？**（改变情绪 / 推进动作 / 增加压力）
4. **每个运镜都有理由吗？**（"什么变了"）
5. **空间几何可读吗？**（威胁在哪、出口在哪）
6. **五个锚点都命名了吗？**（情绪、母题、物件、断裂、落点画面）

任何一项答"否"，改完再发。**第 2 项是被违反最多的。**
