# 01 · 入口：从一句话想法到可交付方案

这一份文件解决一件事：**不管对方懂不懂电影，你都能在 2 分钟内把需求收敛到可以开工的状态。**

---

## 1. 先判断：你面对的是哪类用户

类型他给的东西他真正想要的你的动作**小白**一句模糊想法、一张参考图、"我想要那种感觉"看到成片，不想学理论走 §2 三问 → §4 方案卡 → 全流程代劳**有料用户**想法 + 剧本 / 分镜 / 已写好的提示词 / 已有角色图专业级打磨，不要被改坏走 §6 体检式优化，只改该改的地方

判断信号：

- 出现"分镜""焦段""首帧""Seedance/Kling/Veo/H3""提示词"→ 有料用户。
- 出现"我想做个视频""帮我生成""大概就是那种感觉""朋友圈能发"→ 小白。

两类用户都会撞到同一个上限：**单次生成 ≤ 5 分钟**，见 `06-longform-5min.md`。

---

## 2. 小白三问（一次问完，不要连环追问）

只问这三个，每个都带默认值。**用户不答、或说"你定"，就按默认继续，不要卡住。**

#问题为什么必须问默认值1**要多长？**（5s / 10s / 15s / 20s / 30s / 45s / 1 分钟 / 3 分钟 / 5 分钟）时长决定分段、镜数、工作量**15 秒**2**发哪儿？**（竖屏手机 / 横屏 / 方形）画幅决定构图和信息带**9:16 竖屏**（短视频/短剧默认）3**一句话说清：谁、在哪儿、发生什么**？这是唯一的创作输入从种子模板里挑一个，替他补全

提问示例（照抄即可）：

> 我给你做。三个问题就够，答不上来我就按默认走： ① 多长？默认 15 秒；② 竖屏还是横屏？默认竖屏；③ 一句话：谁、在哪儿、发生什么？

**禁止**：一次抛 10 个问题、要求用户先写剧本、要求用户先选模型。模型你选，剧本你写。

---

## 3. 零想法启动：种子模板

用户连"谁在哪儿发生什么"都说不出时，从下面抽一个改两个字就能用。每个都是已按戏剧法校过的结构。

种子一句话天然含有的东西**A. 深夜发现**深夜，一个人发现自己家里有别人进来过的痕迹。环境压力（走廊灯/门锁）、锚点物（划痕）、裂缝（照片）**B. 最后一通电话**她给一个不会再接的人打电话，留言说到一半停住。单一情绪、声音母题（忙音）、落点（没说完的半句）**C. 手艺人的手**老师傅做最后一件活，手抖了，他停下来重新开始。微动作富矿、无台词、适合 15–30s**D. 雨里等一个人**他在雨里等，等到伞下换了另一个人。天气即角色、反转落点**E. 反杀三秒**弱者被逼到墙角，用一个日常物件反转局面。短剧/漫剧常用、节奏阶梯清晰**F. 门后的世界**推开一扇不该推的门，里面不是他以为的东西。悬念钩子、适合系列化

用法：直接告诉用户"我先按 A 给你做一版，不喜欢我们再换"。

## 4. 导演方案卡（交付物 0 号）

写完先给这张卡，**不超过 12 行、不用术语**。用户点头再动手，避免做完被推翻。

```text
【方案卡】
一句话故事：<谁 + 在哪儿 + 想要什么 + 被什么挡住>
情绪走向：<开始的感觉> → <中间> → <最后>
一个反复出现的画面：<母题，比如"每一次都是玻璃上的倒影">
关键道具：<一个能改变状态的物件>
转折点：<第几秒，什么变了>
落点镜头：<最后一帧看到什么>
节奏：<前段慢/后段快；或全程压着一口气>
声音：<只有环境声/有心跳/有一段静音>
时长与画幅：<15s，竖屏>
怎么拆：<15s 一条过；或 10+5 两段>
```

填好的例子（对应种子 A）：

```text
【方案卡】
一句话故事：深夜，独居的她发现房东开过自己上锁的门，她压住恐惧反问他。
情绪走向：疑惑 → 压住的恐惧 → 反守为攻的冷
一个反复出现的画面：所有画面里都有一道门缝里的冷白光
关键道具：门锁上的新划痕
转折点：第 8 秒，她把手机屏幕转向他
落点镜头：她的眼睛，瞳孔在冷光里缩了一下
节奏：前三镜压着不动，最后一镜才推进
声音：只有灯管嗡鸣、钥匙串、楼道脚步，无配乐
时长与画幅：15s，竖屏 9:16
怎么拆：15s 一条过（Kling 3.0 / H3），4 镜
```

## 5. 口语 → 参数翻译表

小白说的每个词，你都要翻成模型听得懂的物理事实。**这是本技能最常用的表。**

用户说别写成要写成电影感cinematic35mm 或 40mm anamorphic，冷蓝灰调，皮肤降饱和，黑位压死，浅景深，一个可见光源高级感premium / luxurious单一主光 + 大面积暗部，材质写实（丝、黄铜、水磨石），色板不超过 3 色唯美beautiful逆光轮廓、发丝边缘光、薄雾透视、暖色高位光很有氛围moody具体到一种环境压力：湿沥青反光 / 日光灯闪 / 蒸汽 / 灰尘在光柱里有故事感storytelling给一个"之前发生过"的痕迹：新划痕、两副碗筷、没挂掉的电话燃epic短镜快切 + 低频撞击 + 低角度 + 慢动作只用在关键一拍恐怖scary信息不全：画面外声源、门缝、被遮挡的视线、光源不解释治愈healing柔光 + 暖色 + 微动（风、水、呼吸）+ 无人声干扰赛博 / 未来futuristic一个主色霓虹（洋红或青）+ 湿地面 + 密集实景光源 + 硬阴影日系 / 二次元anime明确风格锁：cel-shaded anime、干净线稿、平涂、瞳孔高光、色彩不超过 5 色像某导演like Nolan / Fincher**最多一个**参考，且必须翻成焦段、光位、节奏三项具体指令，不要只写名字要多机位multi-cam写死镜数与景别差：4 镜，景别必须从 中景 → 特写 → 微距 递进

## 6. 有料用户：体检式优化（不是重写）

对方已经有提示词 / 剧本 / 分镜时，你的角色从"导演"切成"剪辑台上的资深导演"。

**流程：**

1. 先跑 `scripts/check_prompt.py`，拿到客观问题清单（空话、缺细节、时序不闭合、身份块缺失）。
2. 按下面五段输出，**不要直接甩一版新的把人家的东西盖掉**：

```text
① 已经对的（3 条以内，点出对方做对的具体动作，不要空夸）
② 会直接导致生成失败的点（按严重度排，每条给出改法）
③ 缺的导演信息（景别/光位/运镜理由/落点镜头，缺哪条补哪条）
④ 连续性风险（跨段身份、道具状态、光的方向）
⑤ 改写版（完整可复制，标注改了哪 4 处）
```

3. 改写原则：**保留他的意图，只换执行**。他想慢，你别给他快剪；他写了两句台词，你别删成一句。
4. 改完再跑一次 `check_prompt.py`，把分数变化告诉他（"72 → 96"），这比形容词有说服力。

## 7. 小白最容易踩的 5 个坑（提前替他挡掉）

1. **一上手就要 5 分钟**，但只有一句话故事 → 先做 15 秒验证风格，再扩到 5 分钟。5 分钟 = 20 段，成本是 15 秒的 20 倍。
2. **想要"电影感"但不肯给具体** → 你替他做 3 个具体决定（焦段、主光方向、色板），写进方案卡让他选，别问他"你想要什么感觉"。
3. **角色换了三个镜头就变脸** → 先出设定图，再出视频，见 `04-image-chain.md`。这条不许省。
4. **希望一条过 5 分钟** → 除 Seedance 2.5（30s）外没有模型支持；5 分钟必须分段，见 `06-longform-5min.md`。
5. **堆 8k / masterpiece / 电影级画质** → 这些词会把人脸推向 AI 感。跑 `check_prompt.py` 会自动抓出来。

---

## 8. 什么时候该停下来问

只有这三种情况值得打断用户：

- 时长 &gt; 300s（超出上限，必须让他选：缩到 5 分钟内 / 拆成多集）。
- 内容涉及真实人物肖像、品牌标识、平台合规红线。
- 他给的关键素材互相矛盾（比如"要真人写实"又"要二次元角色图"）。

其余一律按默认值推进，做完给看，让他改比让他答快。
