# 07 · 短剧与漫剧：竖屏、钩子、分集

> 短剧和漫剧不是"短一点的电影"，是**另一套语法**：竖屏、每 3 秒一个信息、每 15 秒一个转折、每集结尾一个钩子。
> 上限不变：**单集可以做到 5 分钟，但一次生成仍受模型单次上限约束（5–30 秒）。**

## 1. 短剧 / 漫剧的六条铁律

1. **第一秒就得有信息**。不要建立镜头，不要片头，不要"很久以前"。开门就是冲突。
2. **竖屏是近景的艺术**。手机屏幕小，全景看不清脸，能用中近景就不用全景。
3. **每 15 秒必须有一次转折**（新信息 / 新威胁 / 立场反转）。
4. **台词必须短**。一句 ≤ 8 秒自然语速；长台词拆成两句，中间给反应。
5. **每集结尾留一个未完成动作**。不是"说完一句话"，是"话到一半/手刚抬起/门刚开"。
6. **角色一致性优先于画面好看**。脸变了，观众立刻出戏，再美也没用。

## 2. 竖屏构图专门规则

| 项目 | 规则 |
|---|---|
| 画幅 | 9:16（1080×1920） |
| 主体位置 | 眼睛落在上三分之一线；脸不要贴顶 |
| 底部安全区 | 下 20% 不放关键信息（平台按钮、字幕会压） |
| 字幕带 | 下 15–18%，一行不超过 12 字 |
| 景别倾向 | 中近景 / 近景 / 特写为主，全景只用于交代空间（且不超过 1.5 秒） |
| 运镜 | 优先**纵向**运动（俯冲、上升、跟入），横向留给情绪停顿 |
| 深度 | 竖屏容易平，必须给前景遮挡（门框、肩膀、雨帘）制造纵深 |
| 双人对峙 | 上下构图或过肩，不要左右平分（竖屏左右分太窄） |

**竖屏最常见的废画面**：大远景 + 人物居中 + 无前景。看不出是谁，也看不出情绪。

## 3. 短剧：钩子与转折的时间表

### 3.1 单集 60–100 秒的标准节拍

```text
00–03s   钩子      冲突已发生。一句台词 / 一个动作 / 一个反常画面。
03–15s   建立      谁、在哪、赌注什么。用动作交代，不用旁白。
15–30s   加压      对方施压 / 规则显现 / 主角退让。
30–45s   裂缝      破口出现（证据、失误、第三者）。
45–60s   加速      短镜快切，代价开始支付。
60–80s   反转      立场翻转 / 弱者反杀 / 秘密揭开。
80–90s   悬念      未完成动作，切黑。
```

### 3.2 三种高效钩子（第一秒就用）

| 钩子类型 | 写法 | 例 |
|---|---|---|
| **反常动作** | 一个不该出现的动作正在发生 | 她在给自己的门锁拍照，然后从里面反锁 |
| **错位台词** | 一句话与画面矛盾 | "我没开过你的门"——手上还攥着钥匙 |
| **被目击** | 有人正在看，而被看的人不知道 | 门缝后的一只眼睛 |

**不要用**：天气空镜、城市夜景、主角走路、旁白自我介绍（这四种占了烂短剧的 80%）。

## 4. 台词与口型

**能用画面说的，绝不写台词。** 必须说时：

| 规则 | 做法 |
|---|---|
| 长度 | 一句 ≤ 8 秒自然语速；超了拆两句，中间插一个反应镜头 |
| 格式 | 双引号 + 引导动词：`She says in a low steady voice, "..."` |
| 声音描述 | 写在说话者标签内：`[Character A, low steady voice]`，不写就得到通用嗓音 |
| 两句之间 | 加过渡词（`Immediately,` / `Without looking up,`），否则两句会重叠 |
| 视觉锚定 | 台词前先给一个唯一动作：`He pulls the note from his pocket and reads aloud:` —— 口型才不漂 |
| 内部独白 | 任何模型都渲染不了。翻译成身体：停住、视线偏轴、吞咽、继续 |

**模型选择**：要口型优先 Kling 3.0（多角色对话最稳）或 Veo（同期声最准）；只要画面不要声，用 Seedance / H3 更便宜。

## 5. 漫剧：风格锁与二次元专章

漫剧（漫画风短剧 / 动态漫画）与真人短剧最大的差别：**画风一旦飘，全片作废。** 所以风格锁必须写死并每段重复。

### 5.1 漫剧风格锁（必写，逐段粘贴）

```text
Style lock: 2D cel-shaded animation, clean uniform line weight, flat color fills with exactly one hard shadow tone per surface, no photorealistic skin texture, no 3D render look, no painterly blending, large expressive eyes with a single specular highlight, hair drawn in solid shapes with one highlight band, backgrounds painted in the same limited 4-color palette (#12161C, #E8E3DA, #C0392B, #4A90C2), impact frames and speed lines permitted only where specified.
```

### 5.2 漫剧专属表现手法（必须显式写，否则模型往写实靠）

| 手法 | 提示词写法 | 用途 |
|---|---|---|
| **冲击帧** | `single-color inverted impact frame, 4-6 frames only` | 打击命中那一拍 |
| **速度线** | `radial speed lines, high contrast, background only` | 冲刺、挥击 |
| **形变夸张** | `exaggerated perspective distortion on the fist, anime-style squash` | 力量感 |
| **情绪符号** | `a single sweat drop, a vein mark on the temple` | 替代微表情 |
| **定格姿势** | `charged pose held, weight slung forward, eyes locked` | 出手前 |
| **网点/留白** | `halftone texture on shadows, white negative space` | 漫画质感 |

### 5.3 漫剧的四条硬规则

1. **先出角色设定图**（三视图 + 表情表），一次都不许省。见 `04-image-chain.md`。
2. **表情表就是你的"表演库"**：每段视频提示词里直接引用 `same face as the ANGER panel`。
3. **禁止真人化词汇**：不写 `photorealistic`、`skin pores`、`cinematic realism`。
4. **动作可以夸张，光逻辑不能乱**：光的方向和色板仍然要一致，否则会像两集不同动画。

## 6. 分集结构（5 分钟 = 3–5 集）

| 总长 | 集数 | 每集 | 每集钩子 |
|---|---|---|---|
| 60s | 1 | 60s | 单集自洽 |
| 90s | 1–2 | 90s / 45+45 | 中段一个小反转 |
| 180s | 3 | 60s × 3 | 每集尾未完成动作；第 3 集收 |
| **300s** | **4–5** | **60–75s** | 第 1 集钩身份，第 2 集钩威胁，第 3 集钩背叛，第 4 集钩代价，第 5 集收 |

**分集铁律**：
- 每集必须能独立看懂（新观众从第 3 集进来也能跟）。
- 每集结尾的钩子类型要变（动作钩 / 台词钩 / 信息钩轮换）。
- 第 1 集不要解释设定，用一次冲突把设定演出来。

## 7. 交付格式

短剧/漫剧按**集**交付，每集一份：

```text
【第 N 集 · 75s / 竖屏 9:16 / 5 段】
本集任务：<一句话>
本集钩子：<未完成动作>
转折点：第 32 秒，<什么变了>

| 段 | 入点→出点 | 时长 | 功能 | 镜数 | 台词 | 接法 |
|---|---|---|---|---|---|---|
| S01 | 00:00.000→00:15.000 | 15s | Hook | 2 | "这扇门，你什么时候开的？" | — |
| ... |

每段提示词：P01–P05
关键帧：KF01–KF08
风格锁：<一行，全片复用>
```

## 8. 常见崩点

| 现象 | 原因 | 修法 |
|---|---|---|
| 观众 3 秒划走 | 前 3 秒是空镜/走路/旁白 | 换成反常动作或错位台词 |
| 中段掉人 | 30–60s 没有新信息 | 加一次转折或一次反转 |
| 脸每集都变 | 没走设定图流程 | 出三视图 + 每段贴身份块 |
| 台词糊在一起 | 两句连着写、无过渡 | 加 `Immediately,` 并各自绑动作 |
| 漫剧看着像 3D | 风格锁没写 `no 3D render look` | 补进风格锁，重新出图 |
| 竖屏像横屏裁的 | 全景太多、无前景 | 改中近景 + 加前景遮挡 |
| 竖屏看不清脸 | 人物太小 | 景别整体推近一档 |

## 9. 验收清单

- [ ] 第 1 秒有信息（无空镜 / 无片头 / 无旁白自介）

- [ ] 每集结尾是未完成动作，不是一句说完的话
- [ ] 台词每句 ≤ 8 秒，且有引导动词 + 声音描述
- [ ] 竖屏安全区、字幕带、上三分线都遵守
- [ ] 漫剧：风格锁每段都在；角色设定图已出；无真人化词汇
- [ ] 每段首帧已出图，且与上一段落点帧一致
- [ ] 集与集之间的接法（L1 硬切 / L5 声桥）已标
- [ ] 全集时长 ≤ 300s，Σ 段帧数 0 误差
