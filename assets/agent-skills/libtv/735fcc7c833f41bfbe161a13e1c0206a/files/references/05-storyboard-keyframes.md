# 05 · 分镜与关键帧：让一张静帧自己会说话

> 分镜里的**一张图不是一帧截图**，而是一张必须独立扛住一个叙事节拍的画。
> 只好看的画是壁纸；好关键帧要在一张静帧里同时报告：**故事节拍、功能、情绪、以及它无法表演出来的那个运动**。

这份文件把 `02-dramaturgy.md` 的节拍表变成可生成的关键帧，再变成图像提示词，最后交给 `references/models/` 去运动起来。

## 1. 关键帧必须做到的四件事

一张合格的关键帧，一眼之内完成四件事：

- **一个可读的故事节拍**：一句话能说出来。说不出来 = 这张还没想好。
- **一个功能标签**：Establish / Reveal / Power / Pressure / Detail / Reaction / Shift / Impact / Aftermath / Exit。标签就是这个画面要回答的问题。
- **一种情绪**：通过物件状态、光、材质、身体传导，**绝不靠形容词**。
- **一个被暗示的运动**：静帧无法执行的运动，冻结成它的物理残留（见 §4）。

四样缺一，就是只有包装没有糖。**纪律是：你没法把"运动"和"情绪"提示进一张静帧——你只能提示它们留下的物理后果。**

## 2. 关键帧卡

比场记卡多三个只有静帧才需要的字段（★）：

```text
KEYFRAME CARD
- 画号 Panel ID        01 / 02 / 03
- 时间码             在片中活多久（例 00:10.5，HOLD 2s）
- 功能标签            Establish / Reveal / Power / Pressure / Detail /
                      Reaction / Shift / Impact / Aftermath / Exit
- 节拍                这一张里故事变了什么
- 景别+焦段           ECU / CU / MCU / 中景 / 全景 / 微距 + 24mm…100mm
- 锚点主体            观众 0.3 秒内落到的那**一个**物件或身体部位
- ★ 三层景深          前景干什么（框/遮/把我们放进去）·中景干什么（主体/动作）·背景干什么（赌注/语境/对手）
- ★ 被暗示的运镜      这张是哪个运动的第一帧（推/甩/俯冲/跟随）
- 光与色板            一个被动机的光源 + 方向 + 它勾出的表面；具体颜色
- ★ 情绪-物件映射     脸才会表达的那个情绪，映射到物件的什么状态（见 §5）
- ★ 静止中的运动      六条冻结线索里的哪一条（见 §4）
- 字幕/标签           一个词：setup / commitment / mistake / recovery / result
- 声音                这张静帧底下压什么声，切口咬在哪
- 执行备注            道具、机位、连续性锚点
```

带 ★ 的三个字段是普通场记卡不会强迫你想的，也恰恰是让画面不塌的三个。

## 3. 密度阶梯：一个节拍要几张

**声音有多响，画就有多密。** 静音给一张长hold，爆点给一串快切。

| 节拍类型 | 密度 | 张数 | 原因 |
|---|---|---|---|
| 仪式 / 铺垫（安静） | 一张主角画，长 hold | 1 张，活 1.5–2.5s | 安静的节拍是整块的，不要细分——它的力量就在于世界屏住呼吸。 |
| 压力爬升 | 递进单张 | 3 张，长度收窄 | 每张比上一张更紧，切长向高潮坍塌。 |
| 爆发 / 冲击 | 3 张微爆 → 最多 6–9 张 | 6–9 张，8 帧 → 4 帧 | 声音的爆点渲染成**画面密度**，不是一个巨大的画面。 |
| 对抗（持续轰鸣） | 交替 | 碎片簇 ↔ 一张长 hold | 不许两个爆簇背靠背，每个爆之后必须有一张安静的 hold。 |
| 余波 / 离场 | 一张主角画，长 hold | 1–2 张，约 2s | 落在后果上，不解释。 |

**分配规则**：15 秒片落在 8–14 张；30 秒片落在 18–26 张；60 秒片落在 30–45 张。
整块板子读起来应该像一根加速的转速表，**静音看也能看出节奏**。

## 4. 怎么在一张静帧里写出"运动"

静帧不能推、不能切、不能甩。每个缺失的动作，只能落在**六条冻结线索**之一上。**永远不要写 "motion"，写运动留下的痕迹。**

| 线索 | 静帧里长什么样 | 暗示的动作 |
|---|---|---|
| **方向性动态模糊** | 背景沿运动轴拖成条，主体实。栏杆、车道线、路灯被拉成横向光棒。 | 跟随、奔逃、甩镜余波 |
| **局部冻结模糊** | 一个运动元素糊（指节、衣摆、烟团），锚点依然锐利——证明这是被截住的一瞬。 | 变速峰值、发力瞬间 |
| **全幅拖影** | 整张被拉成流线，只留一个可读形状（一只手、一个轮弧）。 | 甩镜、两镜之间的过渡 |
| **姿态 / 轨迹向量** | 身体锁在一个只能向前解开的姿势：手腕抬到一半、重心压在脚尖。眼睛替它完成动作。 | 蓄力、定格、起跑 |
| **主体实 / 环境虚** | 浅景深微距：指节、针、锁舌锐利，其余化开。 | 插入链、快速推近的到达感 |
| **绝对静止** | 刻意零模糊、硬边、屏息——在周围一片模糊中像一只停摆的钟。 | 冲击前那一拍、压满的弹簧 |

**速度预算规则（动作戏用）**：一张图要卖出"快"，下面五条里至少共存三条——
① 机位在膝盖或更低；② 下半幅有地面被拖出的条痕；③ 近景有一件参照物擦过画边；④ 主体实、背景虚；⑤ 有一个机械震颤线索（抖动的后视镜、双影的指针、糊成盘的辐条）。
一条 = 一张汽车照片。三条 = 速度。凑不出三条，就把机位放低、把地面拉进画面、往近景扔一件参照物。

## 5. 没有脸，情绪怎么落地

脸干四件事：表达情绪、指出视线、显示代价、显示决定。**脸不在时，重新分配：**

- **决定** → 动作中的身体部位（只给"正在决定"的手）
- **内在状态** → 一个正在跨过阈值的物件
- **视线 / 对抗** → 空间关系

两条承重规则：

- **身体部位只用在"决定"上。** 静止的手是填充；**正在决定**的手才是镜头。画任何手部特写前，先说出那个动词：grip / latch / shift / preload / release。**没有动词，就别画这张手。**
- **物件只在"变状态"时入画。** 一个静止的钥匙扣等于什么都没说。画**跨过阈值之后**的状态，之前的状态是暗示出来的（针已经压进红区，而不是怠速；灯已经亮起，而不是黑的）。

**替代对照表：**

| 情绪（脸会表达的） | 物件替代 | 景别 | 静帧渲染要点 | 标签 |
|---|---|---|---|---|
| 恐惧 | 指节上的汗珠；镜面里的震颤（不是眼睛） | 微距 / ECU | 一颗硬质高光，冷色轮廓，四周压黑 | Pressure |
| 决意 | 握紧的拳；踩死的脚；抬到一半的手腕 | CU / MCU | 肌腱凸起、皮革起皱，单侧硬光 | Shift |
| 专注 | 光源在漆面 / 玻璃上的反射（不是人眼） | MCU | 冷色点状高光，居中、静止 | Detail |
| 极限 | 指针压进红区；衣料绷到最紧；嘴角渗血 | ECU / CU | 明确到顶，静止但满 | Pressure |
| 失控 | 物件被握错、变形、方向与意图相反 | CU | 形状不对，运动方向与画面冲突 | Impact |
| 释然 | 松开的指；垂下的肩；门半开 | CU → 全景 | 手指从握到松，冷色逆光 | Aftermath |
| 预感（爆发前） | 手指悬在按钮上一毫米；灯刚亮；屏息 | ECU / CU | 一切都冻住——"静音"那一张 | Pressure |

## 6. 构图：三层景深 + 一个焦点

> **装载好的画面法则：一个焦点、一种情绪、三层各司其职的景深、零个死物。**
> 一眼给出答案，二眼给出奖励。

**三层景深（FG / MG / BG）**，每层写清它的职责，并且**必须不同**（同模糊同比例 = 只有一层）：

| 层 | 默认职责 | 常见选择 | 服务功能 |
|---|---|---|---|
| **前景 FG** | 框住 / 遮挡 / 把观众放进场景里 | 门框边、后视镜边缘、雨帘、湿玻璃、栏杆 | Pressure、Power |
| **中景 MG** | 主体 / 动作本身 | 手在锁上、脸、正在落下的杯子 | Detail、Shift、Impact |
| **背景 BG** | 赌注 / 语境 / 对手 | 闪烁的灯管、逼近的车灯、走廊尽头的人影 | Establish、Reveal、Pressure |

**其余三条构图纪律：**

- **功能 vs 装饰（证据测试）**：留下一个物件的唯一理由是——(1) 它是状态指示器（替代脸：指节发白、针进红区）；(2) 它是动作的一级台阶（推进一步）；(3) 它是通往下一张的桥（为匹配切做铺垫）。死物（咖啡杯、装饰品、桌上的无关纸片）删掉。
- **角度即情绪**（没有脸时角度就是情绪）：低机位 = 权力、威胁、爆发（Power/Impact）；眼平侧向 = 对等、僵持（Establish）；高机位 / 顶拍 = 审判、渺小、余波（Aftermath/Exit）。
- **先建中线再破对称**：先给一张完全对称的"呼吸"画面（中线居中、左右镜像、等量负空间），下一张立刻打破它（一侧压过、中线滑到三分线）。这一对只用一次，用在转折点上。

## 7. 从关键帧卡到图像提示词

**开头写权重最高的四样：景别+焦段 → 锚点主体+状态 → 三层景深 → 静止运动线索。** 然后才是光、质感、约束。

```text
[景别 + 焦段]                Low bumper-height macro, 24mm, shot past a blurred door frame.
[锚点主体 + 阈值状态]         A rear-side door lock plate with a fresh brass scratch, metal dust still hanging.
[三层，三个职责]              FG: the door edge, dark and soft, framing the shot. MG: the lock and a fingertip, tack sharp. BG: the hallway, one cold tube light blooming, defocused.
[静止运动线索]               Sharp subject against a horizontally motion-blurred background, the fingertip caught mid-scrape with a slight smear.
[光 + 色板]                  Single cold fluorescent key from upper frame-right, hard quality; warm amber rim from inside; #1B2430 / #C9B8AE / #D08B3E.
[质感]                       Fine 35mm grain heaviest in shadow, soft halation on the tube, crushed blacks.
[人物规则]                   Face out of frame — only the hand and wrist.
[画幅/参数行]                Ratio 9:16.
```

四条让静帧诚实的规则：

1. **明确写出"差分模糊"**。模型默认过度防抖，会把速度磨掉。要写：主体锐利、背景有方向性模糊、近景参照物被拉成光条。
2. **脸要么不在，要么不完整**。必须出现时，转成剪影 / 逆光轮廓 + 一处高光，不给五官。
3. **声音只写成物理后果，不写声音名词**。"引擎很响"是禁用的空话；要写排气口的热浪扭曲、尾焰、车身下蹲、轮胎侧壁起皱。
4. **反塑料守卫**。如果这张图可以被形容成"干净""光线漂亮""高清"，它就失败了——写清颗粒、光晕、压死的黑、一处硬质高光。**一个被动机的光源主导，约 70% 的画面不亮。**

## 8. 完整示例 A：15 秒悬疑短剧（有脸，竖屏 9:16）

| 时间 | 画号 | 功能 | 画面（锚点 + 静止运动线索） | 景别·运镜（被暗示的） | 光 | 声音 | 情绪-物件 |
|---|---|---|---|---|---|---|---|
| 0.0–3.5 | K01 | Establish | 门锁铜面上新划痕，指尖刮到一半（局部冻结模糊） | 微距 100mm，定镜 | 走廊冷白顶光压下，暖黄从门缝溢出 | 荧光灯嗡鸣 | 疑惑 |
| 3.5–7.0 | K02 | Power | 房东挡住门，钥匙串在腰侧晃（条状拖影） | 中景 35mm，缓移 | 侧逆光，半边脸在暗处 | 金属相碰、楼道脚步 | 被压 |
| 7.0–11.0 | K03 | Detail | 手机屏亮起，锁的照片占满画面，屏幕冷光打亮两只手的下半截 | 过肩双人 50mm，定镜 | 屏幕冷光作底光 | 解锁轻响 | 抓住把柄 |
| 11.0–13.0 | K04 | Shift | 他的喉结动了一次，退了半步（姿态向量：重心后移） | MCU 85mm，定镜 | 顶光在眼下留硬阴影 | 静一拍 | 失守 |
| 13.0–15.0 | K05 | Impact / Exit | 她的眼睛，睫毛不动，瞳孔在冷光里缩（绝对静止） | ECU 100mm，缓推 | 冷光 + 背景一团暖黄虚化 | 一声门轴轻响 | 反守为攻 |

板子读法：前两张几乎不动（世界屏住），第三张爆出信息，第四张是"裂"，最后一张停在绝对静止。**15 秒 5 张，恰好是密度阶梯给的 8–14 张的下限偏紧版本，适合单段生成。**

## 9. 完整示例 B：10 秒漫剧打斗（风格化，竖屏 9:16）

风格锁：`2D cel-shaded, clean line weight, flat two-tone shading, impact frames allowed, speed lines permitted, palette limited to 4 colors (#12161C, #E8E3DA, #C0392B, #4A90C2)`。

| 时间 | 画号 | 功能 | 画面 | 景别 | 光 | 声音 | 备注 |
|---|---|---|---|---|---|---|---|
| 0.0–2.0 | K01 | Pressure | 对手的影子先入画压住整面墙，她只露半个肩 | 全景，固定 | 单一顶光，剪影 | 低频渐入 | 影子比人先到 |
| 2.0–4.0 | K02 | Detail | 她的脚跟碾过地面，一块碎砖翘起（局部冻结） | 微距，固定 | 硬光，边线高光 | 碎裂声 | 只画"决定"的脚 |
| 4.0–5.5 | K03 | Action | 碎砖在空中翻，背景拉成速度线（全幅拖影） | 中景，横移 | 逆光勾边 | 空气被切开 | 漫剧允许速度线 |
| 5.5–7.0 | K04 | Impact | 命中一帧：全画面单色反相 + 冲击白线（impact frame） | 特写，固定 | 纯白闪 | 爆音 + 静音 | 只给 4–6 帧 |
| 7.0–10.0 | K05 | Aftermath / Exit | 尘埃落，她松开的拳，指节还在抖 | 近景，缓推 | 顶光收窄 | 只剩呼吸 | 落在"代价"上 |

**漫剧与真人最大的差别**：允许 impact frame、速度线、单色反相、夸张形变。这些必须写进风格锁块，**否则模型会往写实靠**。

## 10. 关键帧验收清单

交付前逐条过，有一条不过就重画：

- [ ] 功能标签写了吗？没有 → 删。
- [ ] 节拍能用一句话说出来吗？说不出 → 它没有糖。
- [ ] 情绪-物件映射在吗？（替代脸的那个状态）
- [ ] 六条冻结线索里至少有一条吗？
- [ ] 物件在跨阈值吗？（不是静止摆设）
- [ ] 三层景深各有职责吗？只有一个焦点吗？
- [ ] 被暗示的运镜写得出来吗？（这张是哪个运动的第一帧）
- [ ] 色板在锁定的 4–5 色内吗？约 70% 未受光吗？有一处硬高光吗？
- [ ] 有多余的手、多余的人、多余的字吗？
- [ ] 声音栏填了吗？（静帧也要写）
- [ ] 它接得住下一张、接得住视频段的运动吗？
