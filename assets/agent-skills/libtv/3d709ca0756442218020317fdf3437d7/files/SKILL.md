# 水墨武舞动作短片生成

## 这个 Skill 做什么

输入**一张抽象背景图**和**一张角色设定图**，输出两样东西：

1. 一份字段完备的**多镜动作分镜脚本**（默认 6 镜 / 15 秒）；
2. 一条**双图混参、带音效的成片视频**。

核心思路是「双锚点分工 + 脚本驱动」：背景图定色彩与空间，设定图定角色造型，两者一起作为视频生成的 reference 输入；脚本先写全，再一次性喂给视频模型生成成片。

## 输入

输入说明必需背景图抽象背景，决定色彩体系与空间质感（如明黄纸质底 + 黑墨飞舞线条）是角色设定图角色三视图/设定板，决定角色造型（发型、面部、纹身、服装、气质）是片名 / 主题用于脚本头部规格可选时长 / 镜头数默认 15 秒 / 6 镜可选

## 双锚点分工（核心可复用要点）

- **背景图锚点** → 定**色彩体系与空间**：主色调、材质质感、抽象元素（如墨线），对应脚本「风格基调—色彩体系」与「场景设计」。
- **角色图锚点** → 定**角色造型**：性别年龄、发型、面部特征、头饰、纹身、服装、整体气质，对应脚本「角色设计」逐项。
- 生成视频时，两张图**同时**作为 reference 传入，顺序固定为 `[背景图, 角色图]`。

## 脚本五段式骨架（固定结构）

脚本按以下五段组织，顺序与字段固定：

1. **头部规格**：片名、画幅、时长、镜头数、无字幕/无文字叠加声明、备注。
2. **一、风格基调**：影像质感、色彩体系、光线基调、音频配乐、动态质感、特效元素、剪辑手法、镜头运镜。
3. **二、角色设计**：性别年龄、发型、面部特征、头部配饰、颈胸纹身、服装、整体气质（逐项对齐角色图锚点）。
4. **三、场景设计**：主场景引用背景图锚点、环境特征、空间变化、地面表现。
5. **四、分镜脚本**：逐镜展开，见下方模板。

### 每镜十字段模板（固定字段）

每个镜头必须写全以下 10 个字段：

`镜号` · `时长区间` · `景别` · `场景地点` · `画面内容` · `运镜` · `画面特效` · `音效设计` · `旁白声音` · `衔接方式`

其中「场景地点」在**首镜显式插入背景图节点引用**、**第二镜显式插入角色图节点引用**（用 `{{nodeKey}}` 形式，不要复制媒体 URL）。

### 默认镜头节奏（6 镜 / 15 秒）

镜号时长内容010–2s大特写睁眼起势022–4s中景转身甩臂034–7s全景连贯武舞047–10s中近景腾空旋子落地0510–13s特写快剪组接配饰与纹身0613–15s中景骤停单膝跪地直视镜头定格

## 视听一体设计（风格锚点）

- **墨线与打击节奏对位**：墨线如鞭抽打、脚步处墨渍炸裂，频闪配合打击节奏。
- **音乐**：低频电子鼓 + 日本太鼓 + 尺八，节奏递进后骤然收束。
- **转场**：极短黑帧或墨渍扩散转场。
- **运镜**：环绕 / 低角度仰拍 / 急速推拉。
- **无字幕纯画面表达**：情绪全靠画面、动作、光影、音乐传递。
- **动作融合舞蹈与武术**，末镜冷酷 pose 停留约 2 秒。

## 落地层参数（可调，默认值来自原画布实测）

视频节点参数分两类：默认值来自原画布实测，用户指定时以用户为准。

参数默认值是否可调说明模型`star-video2`否固定工艺，保证 mixed2video 双图混参能力生成模式`mixed2video`否双锚点混参的核心，不可换reference 顺序`[背景图, 角色图]`否顺序颠倒会导致色彩体系与角色造型串位有声`enableSound = on`否墨线对位打击节奏依赖音频轨，关闭即失去视听一体设计生成数量`count = 1`是需要多版挑选时可加大画幅`21:9`是可换 16:9 / 9:16 / 4:3 等；换画幅时需同步调整脚本「头部规格」的画幅字段与构图描述（竖屏宜加强特写与纵向动作，横屏保留环绕与推拉）分辨率`480p`（约 992x432 @21:9）是可升到 720p / 1080p；分辨率提高不改变脚本结构时长`15` 秒是与镜头数联动：15 秒对应 6 镜；改时长时按同一节奏密度重排分镜区间镜头数`6`是建议保持 2\~3 秒/镜的节奏密度，避免单镜过长导致动作糊化

**调参原则**：只动「可调」项；动画幅或时长时，脚本「头部规格」与「四、分镜脚本」的时长区间必须同步改写，二者不一致会破坏墨线与打击节奏的对位设计。

## 执行步骤

1. 接收背景图与角色图，确认片名/主题/时长（缺省用默认）。
2. 读取两张图，分别提取「色彩与空间锚点」和「角色造型锚点」。
3. 按五段式骨架撰写脚本，分镜部分用十字段模板逐镜填全；首镜插入 `{{背景图nodeKey}}`、第二镜插入 `{{角色图nodeKey}}`。
4. 调用视频生成：模型 `star-video2`、`mixed2video`、`21:9 / 992x432 / 480p`、15 秒、`count=1`、`enableSound=on`，reference 顺序 `[背景图, 角色图]`，prompt 为第 3 步的完整脚本。
5. 输出脚本与成片视频。

## 可替换槽位 vs 固定锚点

- **槽位（每次会变）**：片名、主题、具体角色形象与服装细节、背景图具体配色与元素、镜头内容细节。
- **锚点（固定工艺）**：双锚点分工、五段式骨架、十字段模板、6 镜节奏、墨线与打击节奏对位、无字幕表达、`star-video2` + `mixed2video` + 21:9 + 有声参数组合。

## 五、已验证素材组合

以下两组已按本 Skill 完整跑通成片，验证「固定工艺不变、只换槽位」即可迁移：

**组合 1｜墨武（原始配方，暖色）**

- 背景锚点：明黄色纸质底 + 黑色泼墨飞舞线条（16:9，2560x1440）
- 角色锚点：黑色短发、金色弯角、红色面纹、颈胸与手臂红黑纹身、黑色 V 领上衣 + 暗红花纹宽松裤 + 黑厚底靴的女性角色三视图
- 成片：15 秒 / 21:9 / 480p / 有声 / 6 镜，双图混参按 \[背景图, 角色图\] 顺序输入
- 效果：高对比戏剧光、明暗频闪，墨线随打击节奏抽打炸裂，末镜单膝跪地定格成立

**组合 2｜霜青（反向槽位，冷色）**

- 背景锚点：月白色宣纸底 + 墨青色（深蓝黑）水墨线条与泼墨飞溅（16:9）
- 角色锚点：及腰白发、赤红瞳孔、左颊银色面纹、银月牙冠、银白项圈配蓝晶吊坠、锁骨与右臂银蓝纹身、白色交领宽袖上衣 + 红色腰带 + 月白暗蓝云纹裤 + 白厚底靴的女性剑者三视图
- 成片：实际时长 15 秒，与脚本区间一致；21:9 / 480p / 有声 / 6 镜，双图混参同上
- 效果：色彩体系自动切换为冷调（暗青↔冷白频闪），红腰带成为唯一暖色点睛；十字段分镜与 6 镜节奏逐镜落地无遗漏

**迁移结论**

- 换槽位不影响工艺：片名、配色（暖↔冷）、角色形象（牛角妖异↔白发清冷）全部替换后，五段式骨架、十字段模板、6 镜节奏、墨线对位打击、无字幕表达均正常复用。
- 配色反转时，脚本「色彩体系」与「光线基调」两段随之改写为主色/辅色/点睛色的对应关系，其余段落结构不动。
- 角色配饰（冠饰、吊坠、纹身、腰带）在镜头 05 的快剪组接里天然成为特写素材，选设定图时优先挑配饰层次丰富的。
