# 附MD 2 | 魔法特效物理化引擎

## #做什么

专治 AI 生成魔法时的“塑料发光感”，强制把特效写成物理与光学现象。

## #需要什么输入

- 剧本中的魔法/战斗动作。

## #怎么做

### 强制拆解为“聚能 -&gt; 释放 -&gt; 消散”三阶段，并写出可见后果：

- **雷电系**：分叉电弧（≥3个分叉点）+ 空气焦味辉光 + 蓝白色电火花 + 击中后地面放射状焦黑裂痕 + 脸部被瞬间照成惨白蓝。
- **暗影/诅咒系**：黏稠黑雾（流速比正常烟雾慢40%）+ 中心纯黑边缘半透明暗紫涡流 + 吸光现象（光线靠近变暗）+ 被触碰表面呈现黑渍腐蚀。
- **冰霜系**：不均匀蔓延（0.3秒冻结）+ 六角形枝晶 + 霜雾沉降 + 表面应力裂纹 + 角色呼出的浓重白气。
- **烈焰系**：三色分层（底层暗红-&gt;中层橙红-&gt;顶部黑烟）+ 热气流托举 + 环境热浪扭曲。

### 严禁词汇

严禁写“光芒四射”、“魔法爆炸”、“绚丽的特效”，必须写具体的物理表现。
