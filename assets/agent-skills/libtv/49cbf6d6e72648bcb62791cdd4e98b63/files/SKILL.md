# 游戏引擎实机质感 · 角色设定图

把手绘 2D 立绘、概念原画或插画风格的角色，转换成「游戏引擎实时渲染 + 三渲二（cel-shading）」观感的三视图设定图（turnaround sheet）。

**定位**：流程类环节工具。输入一张立绘 → 产出一张三视图设定图，供后续视频生成与其他画布复用。文中的质感判据段（色阶硬判据、体积三件套、金属八条、四灯布光、材质分档）是**可摘出的模块**，同样可叠加到场景、道具、武器、视频片段的生成任务上——主体是流程工具，技法段可复用。

---

## 一、什么时候用这个 Skill

**触发信号**
- 用户要求「转成实机质感」「三渲二」「游戏引擎画面」「做三视图／turnaround 设定图」
- 用户抱怨成品「像插画」「像纸片」「没有立体感」「金属不够硬」「质感太软」
- 用户给出角色立绘，要求做成可用于后续生成的角色锚点

**不适用**
- 只做纯设计参考、不要求引擎质感的普通三视图
- 用户明确要手绘 2D 或写实 PBR 路线

**先判断输入齐不齐**：需要 ① 一张角色立绘（设计源）② 1–2 张真实游戏引擎截图（质感靶子）。缺靶子时先向用户要，不要用自己写的风格板代替（原因见第七节避坑条款一）。

---

## 二、准备步骤

### 1. 拉取并核对设计源
- 调出原立绘，逐项记录：五官、发型、头身比例、全部装束、配饰、道具造型、配色关系。
- **判断部件结构、装配顺序、造型细节前，必须先调出原图对照**，不能凭第一遍观察下结论（见第七节避坑条款四）。

### 2. 选质感靶子
- **必须用真实游戏引擎截图／实机渲染图**，不要用自己写的风格示范板。自制风格板的观感会把成品拉回插画档。
- 靶子图的分工要写到排他级：「只锁美术风格、上色方式、光照氛围与镜头虚化质感，不从这张图里提取任何角色长相、道具造型或场景内容」。

### 3. 比例一律跟角色自己的原图走
不从风格靶子借用头身比。7 头身角色会被 Q 版靶子压成 3 头身。若靶子是 Q 版而角色是正常比例，必须在 prompt 里显式写「沿用其约 N 头身比例，不做 Q 版压缩，也不从靶子图提取头身比」。

### 4. 确认引用节点有产物
引用节点必须是已生成出产物的节点；空节点无法作为图像引用。此时改为把风格文字原样搬进 prompt。

---

## 三、Prompt 编写规范

### 结构顺序（影响命中率）
1. **质感靶子与硬判据放最前**（模型对末尾内容权重最低）
2. 其次是体积／色阶／材质／布光等约束段
3. 角色身份与设计源放后段
4. 版面构成最后

需要压过参考图时**去掉预设模板（preset）**，避免模板把自己的风格段挤到后面。排他约束写成名词短语逐条点名（纸纹、水彩边、线条呼吸感、喷枪晕染、球面镜面反射、PBR 次表面散射、厚涂……）。

### 段落模板

**① 质感靶子段（最高优先级）**

> 【质感靶子，最高优先级，逐条严格执行】本图的渲染质感一律取自 {{靶子图A}} 与 {{靶子图B}} 这两张游戏引擎实时渲染截图，照搬它们的三维相机成像、体积塑造与光交互，不是插画、不是厚涂、不是手绘二维、不是概念原画。

**渲染路线要写成可验证的物理事实，不能只写「3D」**。有效表述：立体建模、有真实体积与厚度、明暗随光源角度连续变化、前后景按真实距离分离。只写「3D」「实机感」这类标签，模型只会理解成「立体一点的插画」。

**② 色阶层数硬判据（治「质感太软」的关键）**

> 【色阶层数硬判据，先于一切其他描述】所有部位的明暗必须是可数出来的离散色阶台阶，不是连续渐变：
> 一、每一处环绕明暗至少 4 个、最多 5 个界限分明的色阶台阶，从受光最亮收到暗部最深；相邻台阶的亮度落差必须肉眼可辨（相当于一次明显跳档），不许出现中间调的平滑过渡带。
> 二、每个台阶是一整块均匀色，台阶之间的分界线清晰锐利、沿形体转折走向弯曲；绝不允许喷枪式晕染、柔和平滑渐变、连续色带或模糊的明暗过渡区。
> 三、自检标准：把画面缩小后，每一处圆润部位都应看出几个明暗档位（亮／中亮／中／中暗／暗）；若某处只看出亮暗两档或看不出档位，即为不合格。
> 四、柔和边缘只允许两处例外：接地投影与 AO 闭塞阴影。其余一切明暗必须是硬边台阶。
> 五、色相保持不变：本色相一律不改，明暗只靠明度跳档实现，不许偏色模拟体积（防止撞色被染脏）。

**③ 体积三件套（治「纸片感／没有立体感」）**

> 【体积塑造，逐条严格落实】禁止纸片感、剪纸叠贴感、扁平感：
> 一、按部件形状分档设定层数——**不要一刀切**：
> ・圆润部件（脸颊、颈、手臂、大小腿、躯干转折、袖筒、裙褶、飘带、发束、绒球）走 4–5 层环绕收暗，沿圆柱与球体的环绕方向一层层收暗；
> ・块状／片状硬质件（金属头冠、胸饰、带扣、武器护手、靴饰片）走 3–4 层刀切分面；
> ・两档必须一眼可辨：圆润处是层层包裹的体积，硬质处是刀切的分面。
> 二、明暗交界线（terminator）＋亮边（light wrap）：每个受光面与暗部之间一条随形体弯曲的交界线（不许是直线），靠光一侧带一窄条被光绕过的亮边——这是塑体积最有效的一刀，缺了就退化成「亮块＋暗块」。
> 三、环境光遮蔽（AO）逐点点名：不要只写「加 AO」，要按该角色的实际部件列出 11–20 处交接位，统一压一层暗度高于普通暗部、边缘柔和的闭塞阴影。
> 四、暖冷色温分离：受光面偏暖、暗部偏冷，色温差本身就是深度线索；AO 闭塞处冷调最深。
> 五、骨点顶亮：肩胛、髋骨、膝、肘等骨点顶到受光面最亮处。

**对所有部件统一写「2–3 层」是错的**，那会让手绘系角色的四肢被切成扁片（仅对岩石类块状造型适用）。

**④ 金属判据（治「金属不够强」）**

诊断：金属变弱通常不是没修，而是**修得太克制**——变成中性灰阶块（跨度小、色温和石头同系、无环境反射、高光偏大偏软）。解法是在三渲二框架内把光学特征推到极限，而不是退回 PBR。

**先分档判断金属占画面面积**，两档适用条件不同：

#### ④-1 金属八条（小面积金属件，稳定有效）

适用于铆钉、带扣、坠饰、铃铛、靴扣、盾包角、umbo、剑身等**小面积金属件**：

> 一、明度跨度拉到全图最大：高光顶到近纯白带冷蓝、暗部压到深冷灰（比相邻布料岩石更黑更冷）、中间只留一层过渡灰。
> 二、色温分离：金属整体冷蓝灰（金色件为高饱和暖金但同样锐利），与相邻部件拉开色温。
> 三、**硬边色块式环境反射**：暗部映一小块邻近光源的彩色反光＋一小块地面反弹，位置固定、边缘一刀切、面积小、亮度低于主高光——像引擎里烘进去的反射探针。
> 四、高光收小收锐：菱形／三角／窄长条，边缘一刀切。
> 五、描边加重：金属件外缘描边比其他部件更深更实，不因反光丢边。
> 六、棱脊一线亮：沿棱脊打一条极窄纯亮线。
> 七、小型件（铆钉、扣件、坠饰、铃铛）写成六／八面低多边形切面：每面一层灰阶、顶端一块锐利亮斑、暗部一刀切。
> 八、片状／曲面件写成三段式硬边高光：棱脊窄亮带／正面冷中灰／暗侧深冷灰，根部与相邻材质相接处一圈深色阴影环。

#### ④-2 大面积金属加码两条（金属占画面面积过半时叠加）

当金属**占画面面积过半**时（如全身板甲、大型金属武器），会触发一种新的失效模式——模型倾向于做整图明度均衡，导致金属被稀释，**八条单独套用压不住**。此时在原八条之上**叠加以下两条加码判据**：

**加码一·弧顶三明治亮线（专治宽柔亮带）**

> 每一件曲面或片状金属的弧面最高处，必须有一条沿弧顶走向的极窄纯亮线，其宽度不超过该件高度的十分之一；紧挨这条亮线靠暗侧的一侧，再压一条更窄更深的暗线（高光跌落的截止线）；由此形成「极窄纯亮线—深暗细线—中灰面—深冷暗面」四段锐利并列，段与段之间一刀切、界限分明。绝不允许出现宽而柔的亮带、柔和高光、连续渐变过渡——那是塑料与锡纸，不是钢。

**加码二·每块金属强制两块硬边反射色块（专治暗侧纯灰）**

> 每一片金属的暗侧中部，必须映出至少两块边缘一刀切的硬边色块反光，色块来源从场景中实际存在的邻近材质里逐一点名（例如：甲缘贴花的蓝、木盾的暖棕反弹、地面反射板的暖米、金发的暖黄、水晶的冷蓝），位置固定、面积小、亮度低于主高光、形状为锐利的四边形或三角形。绝不允许金属暗侧是一片均匀的纯灰。

#### ④-3 大面积金属的两条配合判据

> **跨度压过全图**：金属的明暗跨度必须大于图中任何其他材质，全图第一眼最亮最锐的地方就是大面积金属；同时给相邻材质反向定档（如「木材／布料的跨度必须明显小于金属」），用对比把金属的地位顶出来。
> **受光侧不丢描边**：金属件外缘描边背光侧略粗、受光侧略细但绝不允许丢边——通体亮银的金属尤其靠这圈描边保住每片的剪影可读性。

#### ④-4 关键切分与排他

**关键切分**：排他段必须区分「允许并鼓励边缘一刀切的硬边色块反射」与「禁止球面连续镜面反射、放射状高光渐变、抛光柔滑过渡」。若只写「禁止镜面反射」，模型会把反射整个删掉，金属反而变弱。

**大面积金属场景下，排他段除上述三项外，追加禁止**：**哑光塑料感、锡纸感、均匀的纯灰暗侧**——这三者正是大面积金属被稀释后的实际观感。

**⑤ 四灯布光（比背景更能决定质感）**

> 【布光结构，四灯，逐盏落实】一、顶侧主光负责受光面与明暗交界线；二、冷蓝天空补光染在受光面边缘并决定暗部的冷调；三、暖米色地面反射板把暖色反弹送进暗部下缘；四、背光轮廓灯沿发丝、肩线、外缘勾出一圈清晰明亮的边缘光（rim light），把剪影从背景里剥出来。四项一律保留。

**决定质感的是布光结构写没写全，不是背景有没有内容。** 只写一句「晴朗白日顶侧光」时，纯白底会退回插画；四灯各自命名并指定作用面后，纯白底照样撑得起整套光交互。

暗色生物需按明暗关系适配：主光改高位冷白、地面反射板换成与角色呼应的彩色（如紫红），并写明「暗部不许糊成死黑，必须带两个色相」。

**⑥ 背景与空间**

纯白无影棚会削立体感（人物贴在纸面上）。推荐浅灰渐变＋一条地面透视线＋周身极淡大气雾；侧视与背视比正面多加一档雾与景深衰减，形成前后层次。

若用户明确要白底：保留白底，但必须把四灯写全，并加一句「不许因白底把光照退化成无影平涂或单一正面光」。

**⑦ 材质分档**

多材质并存时（金属／皮革／布料）分档写清各自明度跨度与高光形态，并禁止混成同一种手感：
- 金属：跨度最大、刀切分面、最冷最硬最亮
- 皮革：跨度中等、高光是一条沿弧面走的窄亮带（比金属宽、比布料锐），甲片边缘切出浅亮边表示厚度
- 布料：靠暖冷阶梯、柔软环绕色阶、褶根压闭塞

**⑧ 角色身份段（后段）**

逐项点名，并写明「只改渲染质感与体积塑造、不改设计与结构」。

**⑨ 排他段**

> 不采用 {{设计源}} 的任何绘制笔触、插画纸纹、水彩晕染、细密排线与柔和平涂手感，只从它提取角色设计信息（五官、发型、头身比例、装束、道具造型、全部配色关系）。

## 四、按角色难点定制专项判据（范例库）

| 角色类型 | 专项判据 |
|---|---|
| 大面积纯白服装 | 「白不是无色」——受光暖白／中间中性白／暗部冷蓝灰／最深带紫深蓝灰，绝不允许通篇一片死白。袖筒按中空筒身、裤腿按圆柱、靴子按硬质件分别指定档数 |
| 大面积披风／蓬裙／飘带 | 每道垂褶走环绕明暗＋褶根压 AO＋下缘硬边；蓬裙每道褶从腰部向裙摆辐射、裙摆下缘一圈被自身厚度撑出的暗边，写明「显出悬挂的重量与前后遮挡层次」 |
| **大面积金属（全身板甲、大型金属武器）** | 金属占画面面积过半时，在金属八条之上叠加 ④-2 两条加码判据（弧顶三明治亮线＋每块金属两块硬边反射色块）与 ④-3 两条配合判据，排他段追加禁哑光塑料感／锡纸感／均匀纯灰暗侧 |
| 修长体型 | 四肢必须是筒状圆柱体积，禁止扁平两条线；背视要有脊柱沟与肩胛起伏 |
| 动态姿势 | 三视保持同一套姿势的对应朝向；跳跃离地要在鞋底与地面投影之间留出明显空隙 |
| 多材质并存 | 分档写清各自明度跨度与高光形态，禁止混成同一种手感（见三·⑦） |
| 非人类／复合生物 | 枝杈部件（八条腿等）每段要有自己的环绕色阶与棱脊亮线、关节内侧压深闭塞、腿间有前后遮挡远近虚实，写明「绝不允许画成扁平线条或剪影」；两套结构的接合缝要压最深闭塞 |
| 武器类大件 | 写清装配链与各段比例、宽度突变位置、与身体相接处的受力闭塞 |
| 宽檐帽／大帽饰 | 帽檐在下颌、颈侧、锁骨、肩头投下一圈边缘清晰的影，是最有效的体积线索之一，不许省略 |
| 高饱和撞色布 | 明暗靠色阶层数实现、不改色相，防止模型为做体积把紫色染蓝、黄色染橙 |

## 五、版面模板（三视图设定图）

> 【版面构成】游戏角色设定图（三视图 turnaround sheet），16:9 横版。
> 主体为三个全身等高并排立绘：正面、侧面、背面，三者脚底同一水平线、头顶齐平、体型完全一致，共享同一套布光方向、明暗交界线走向与边缘光走向；
> 右上角两颗头部特写（正面与四分之三侧面）；
> 右侧竖列单独展示武器或关键道具的正反两面大特写；
> 下方一行三张服装／部件细节分解；
> 各区域之间用极细分隔线划分，不加任何文字、字母、数字、编号、色卡或标注。

**注意**：三视等高线以最高部件为准（如角色头顶托球时以球顶端对齐）；动态姿势三视保持同一套姿势的对应朝向；侧面朝向可设为与配对角色相对，便于后续同框对峙。

## 六、质检清单

生成后**放大（view_image + crop）逐项核对**，再向用户汇报，并如实指出未达标之处：

- [ ] **色阶可数**：缩小画面后，每处圆润部位都能数出 4–5 个台阶；不是连续渐变
- [ ] **交界线＋亮边**：受光面与暗部之间有随形体弯曲的交界线，靠光侧有窄亮边
- [ ] **AO 清单**：逐点核对开列的 11–20 处交接位是否都压了加深闭塞
- [ ] **金属八条**：明度跨度／冷蓝色温／硬边色块反射／高光收小／描边加重／棱脊亮线／小型件切面／片状件三段式

## 七、避坑条款（本次实战踩过的坑，全部保留）

**一、自制风格示范板反而会把成品拉回插画档。**
本次自制的「软胶 Q 版」风格板，观感反而把成品拉回插画。目标质感请直接用真实游戏截图／引擎渲染图。参考图的绘制技法权重会压过文字风格描述——文字打不过参考图时，改用一张目标质感的截图当靶子。

**二、纯白底容易退化。**
白底之所以退回插画，根因往往不是背景，而是只写了单一句「晴朗白日顶侧光」。四灯各自命名并指定作用面后，纯白底照样撑得起整套光交互。**决定质感的是布光结构写没写全，不是背景有没有内容。**

**三、金属修得太克制反而变弱。**
只写「禁止镜面反射」，模型会把反射整个删掉，金属变成中性灰阶块。必须给它一条合规的反射通道：允许并鼓励边缘一刀切的硬边色块式环境反射，只禁球面连续镜面反射、放射状高光渐变、抛光柔滑过渡。

**四、误判部件结构会白改多版。**
本次曾把剑身上的收束抱箍误判成错位的护手，沿错误假设白改了三版（模型其实一直按参考图画对了）。**判断部件结构、装配顺序、造型细节前，必须先调出原图对照，不能凭第一遍观察下结论。**

**五、大面积金属会触发「整图明度均衡」的稀释失效。**
金属占画面面积过半时（全身板甲、大型金属武器），原金属八条单独套用压不住——模型倾向于做整图明度均衡，金属被稀释。实测症状有四条：
1. 高光亮带变宽变柔：本该是「极窄亮线」的弧顶高光，被画成宽而柔的亮带，观感退化成哑光塑料或锡纸，不再是抛光冲压的钢；
2. 暗侧抹成均匀纯灰：八条里「硬边色块式环境反射」整条被省略，甲片暗侧是一片连续灰调，没有环境互动；
3. 曲面档位被抹成连续渐变：本该 3–4 档跳台阶的冲压硬壳曲面，被喷枪式连续过渡抹平；
4. 跨度被稀释：金属明暗跨度没有压过相邻的布料、皮革、木材，失去「最冷最硬最亮」的材质地位。

解法见 ④-2、④-3：加码「弧顶三明治亮线」与「每块金属强制两块硬边反射色块」，并用「跨度压过全图＋相邻材质反向定档」的对比把金属地位顶出来。小面积件仍走原八条的切面／三段式逻辑。

## 八、工作纪律

1. **先核对原图再下结论**：判断部件结构、装配顺序、造型细节前必须先调出原图对照（见避坑条款四）。
2. **放大核对再汇报**：成品要用 view_image + crop 逐项核对判据是否落地，再向用户汇报，并如实指出未达标之处。
3. **迭代只改出问题的条目**：其余已验证有效的配置原样保留，并在节点标题上用 v2／v3 递增。
4. **引用节点必须有产物**：空节点无法作为图像引用，此时改为把风格文字原样搬进 prompt。
5. **节点生成失败时新建节点承接**：原节点标记废弃，新建节点用同一套参数。
6. **定稿后存入资产库**：设定图存入资产库「角色／场景」分类以便跨画布复用；**原始立绘与质感设定成对入库**，命名区分开（如「XX·原始立绘（设计参考）」与「XX·三视图设定（引擎实机质感）vN」）。

## 九、已知弱项（如实告知用户，不必反复折腾）

裸露的苍白皮肤是模型最强先验所在，色阶往往只能压到 3 档、比其他部位软一档。其他部位（布料、甲壳、头发、金属）都能稳定压硬。若用户纠结此处，可单给皮肤加硬判据，但收益有限且可能让肤色显脏。

## 十、技法模块的跨任务复用

本文第三、四节的判据段是**可摘出的模块**，可直接叠加到其他生成任务：

- **场景**：把「四灯布光」换成该场景实际光源的逐盏点名（主光／补光／底光／轮廓光），材质段换成石材、金属、帷幔、自发光阵纹；暗部必须有暖冷两个色相，不许糊成死黑。保留原图的结构与色调，只移植渲染质感语言。
- **道具／武器**：保留金属八条，另加装配链与各段比例、宽度突变位置、与身体相接处的受力闭塞。**金属占画面面积过半时（大型金属武器、全身板甲）叠加 ④-2 的两条加码判据**。
- **视频片段**：把质感段与排他段原样前置，角色与场景引用换成已定稿的设定图锚点。注意视频模型对长提示词的注意力衰减——越靠后的内容权重越低，约束段要前置。
