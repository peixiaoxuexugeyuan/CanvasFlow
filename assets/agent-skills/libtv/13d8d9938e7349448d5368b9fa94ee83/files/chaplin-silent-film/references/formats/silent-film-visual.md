## 1. 视觉基因（七要素）

每个生成描述必须覆盖以下要素（可合并措辞，不可遗漏）：

1. **年代质感**：1920年代黑白默片，手工胶片颗粒，轻微划痕、尘埃斑点与画面亮度闪烁，胶片跑速略带抖动
2. **灰阶**：低对比度，黑色呈深灰、白色呈米白，灰阶层次柔和丰富，无死黑与过曝
3. **摄影**：固定机位为主（20年代摄影机笨重，少手持），少量平移摇镜；中景与全景为主记录全身动作，喜剧点给面部特写
4. **灯光**：棚拍式柔光，正面平光为主，避免强烈的现代硬光与高对比剪影
5. **场景**：鹅卵石街道、老式面包房、码头、工厂大门、廉价公寓、街头钢琴、报童、马车与早期汽车
6. **服装造型**：圆顶礼帽、过紧的短西装或破旧大衣、肥腿裤、大头破皮鞋、手杖、圆脸化妆式腮红；女性角色波浪卷发、长裙、羽毛帽
7. **表演**：无声表演，动作先于一切，表情放大

## 2. 肢体喜剧表演用词库

**步态与移动**：外八字鸭子步、踮脚疾走、帽子被风吹走追赶、冰面打滑、踩到香蕉皮式的假摔变舞步

**经典桥段**（按需选用，避免堆砌）：
- 与门/旋转门的笨拙搏斗
- 被自动机器捉弄（流水线、喂饭机式）
- 抢一根面包、一枚硬币的追逐
- 用手杖勾回滚落的物品，顺势转身致意
- 逗小孩或小动物，把最后半块面包分出去

**表情节奏**：惊讶（眉毛高挑、后仰）→ 强装镇定（整理帽子与领结）→ 计上心头（眼珠一转）→ 得逞的坏笑；悲伤时嘴角向下但眼睛含笑

**温柔悲情桥段**：把仅有的硬币放进更穷的人手里；透过橱窗看自己买不起的东西；被拒绝后仍脱帽鞠躬再离开

## 3. 插卡字幕规范

- 中文，衬线体或手写体，居中排版
- 黑底白字或米白底黑字，四角装饰性花边框（简洁，不抢戏）
- 用途三类：台词（他哑了哑嗓子，却说不出话）、内心独白、叙事转场（三天后……）
- 全片 ≤5 张，每张 1-2 秒，字数 ≤15 字
- 字幕文案要短、要留白，带一点自嘲或诗意，不解释剧情

## 4. 配乐规范

- 乐器：钢琴为主，小型管弦（小提琴、低音提琴、单簧管）点缀；1920年代拉格泰姆与沙龙音乐气质
- 结构跟随情绪链：欢快跳跃的钢琴（喜剧追逐）→ 弦乐渐入（温柔瞬间）→ 减慢收束、一个未解决的温柔尾音（含泪收尾）
- 无对白、无歌词；音画同步：追逐段落配快节奏切分音，慢镜头配琶音
- 生成时明确"纯音乐，1920年代默片配乐风格，钢琴与小型管弦"

## 5. Prompt 文法模板

### 视频生成描述模板
```
1920年代黑白默片，低对比度柔和灰阶，手工胶片颗粒质感，轻微划痕与画面闪烁，边缘暗角。
[主体：小人物身份+服装造型]，[场景：20年代具体场所]。
[动作：这一拍的身体语言，按肢体喜剧用词写具体]，
[机位：固定中景/全景/面部特写]，[灯光：棚拍柔光]。
无声表演，肢体喜剧风格，动作夸张而优雅，表情丰富。
```

### 图片生成描述模板
```
1920年代黑白默片静帧，低对比度柔和灰阶，手工胶片颗粒，边缘暗角。
[构图：全身/中景]，[主体+服装造型]，[场景]，[正在发生的动作定格]，
棚拍式柔光，无声电影氛围。
```

### 转换路径附加条款
保留参考素材中的主体外观、身份特征与动作结构，将其服装与场景按20年代风格改造（用户要求保留原场景时除外），整体叠加黑白低对比与胶片质感。

## 6. 落 prompt 前自检
- 七要素是否每条都落进描述（可合并，不可漏）
- 动作是否具体到身体部位，而非"他在表演喜剧"这类空话
- 是否包含"无声表演、肢体喜剧风格"
- 灰阶措辞是否为低对比度（避免出现"高对比""黑白分明"）
- 字幕文案是否 ≤15 字且留白
