# 卓别林默片

## 1. 核心原则 + 持久引擎

核心原则：默片的情绪不靠台词，靠身体和表情。人物越是把心酸演成滑稽，观众越是被打动。所有镜头设计都必须回答一个问题：这一秒，身体在说什么？

持久引擎（因果链）：
**小人物处境 → 误入困境 → 肢体喜剧化解（笨拙但优雅）→ 善意或温柔的瞬间 → 命运再次捉弄 → 含泪的微笑收尾 → 观众记住那份体面**

风格恒定项（任何路径、任何镜头都不得丢失）：
- 20世纪20年代默片质感：手工胶片颗粒、轻微划痕与闪烁、画幅边缘暗角
- 低对比度黑白：黑不死黑、白不惨白，灰阶层次丰富柔和
- 表演语言：夸张的肢体喜剧、丰富的面部表情、圆顶礼帽与手杖式小人物形象（不必复刻卓别林本人，可致敬其气质）
- 温度：滑稽之下始终藏着温柔与悲情，结尾留余味

## 2. 质量测试（可证伪）

把成片静音播放：如果观众仅凭人物的身体动作、表情节奏和插卡字幕就能看懂完整故事并感受到"又好笑又心酸"，则成立；若任何一个镜头需要依赖声音或口头解释才能看懂，该镜头必须重做。同时检查：去掉黑白胶片处理后，画面是否仍是"20年代"的服装、场景与表演方式——若只是套了黑白滤镜的现代片，判为风格不达标，重做。

## 3. 输入诊断（落 prompt 前必须想清楚）

- 创作路径：A) 素材风格转换（用户给了图片/视频，忠实保留其主体与情节，做默片化改造）还是 B) 故事自动成片（用户给了一段故事或主题，技能补全编剧）
- 故事核心：主角是谁（小人物）、困境是什么、喜剧点在哪、温柔瞬间在哪、结尾状态
- 输入素材内容：转换路径下先读取素材，识别主体、场景、已有动作线，转换时不改变原叙事
- 目标平台与画幅：国内短视频平台，默认9:16竖屏；用户指定其他画幅时优先用户
- 成片时长：由故事长度决定。≤15s 的故事一次生成完整成片；15s 以上拆为若干 ≤15s 片段分别生成，再拼接
- 配乐：默认生成。每个故事生成一段贯穿情绪的钢琴/小型管弦配乐（欢快钢琴→弦乐渐入→温柔收束的典型默片配乐结构），并与画面合成
- 插卡字幕：中文，衬线/手写风格字体，黑底白字或白底黑字卡片，用于台词、内心独白与叙事转场，全片不超过4-5张，每张停留约1-2秒
- 合规敏感点：不出现真实政治人物、不加色情暴力元素；致敬风格而非使用卓别林本人肖像做商业代言

## 6. 输出契约

### 原创路径工作流
1. 故事结构化：按持久引擎链补全五要素（小人物/困境/喜剧化解/温柔瞬间/含泪收尾），形成一段一句话可复述的故事
2. 分镜脚本：按时间轴 beat 编写（例：0-3s/3-7s/7-12s/12-15s），每个 beat 写明主体动作、机位、灯光、插卡字幕位置。先出分镜脚本给用户确认，确认后再生成
3. 生成风格锚定图（角色全身+面部参考图、场景图），确保人物与场景跨镜头一致
4. 视频生成：≤15s 成片一次生成完整片段，beat 是同一条生成描述内的时间轴，不是分段多次调用；>15s 的故事拆为若干 ≤15s 片段各自一次生成，再拼接
5. 配乐：生成贯穿全片的钢琴/小型管弦乐（无声对白，音乐承担情绪引导），与画面合成
6. 插卡字幕：中文卡片式字幕按分镜脚本嵌入
7. 合成交付

### 转换路径工作流
1. 读取素材，复述识别到的主体、场景与动作线，向用户确认转换范围
2. 以素材为参考，生成默片风格版本：保留主体外观与动作结构，叠加黑白低对比、胶片颗粒、20年代服装场景化改造（用户要求保留现代场景时除外）
3. 视频素材按时长规则处理：≤15s 一次生成，>15s 分段
4. 配乐与插卡字幕同原创路径，可按原素材叙事补充

### Prompt 固定条款（每个视频/图片生成描述必须包含）
- "1920年代黑白默片，低对比度柔和灰阶，手工胶片颗粒质感，轻微划痕与画面闪烁，边缘暗角"
- "无声表演，肢体喜剧风格，动作夸张而优雅，表情丰富"
- 正向措辞，不堆否定式约束

## 7. 静默自检（出稿前，不外显）
- 静音播放测试：仅凭动作与插卡字幕能否看懂全部故事
- 风格测试：去掉黑白处理后是否仍是20年代的服装、场景与表演
- 情绪测试：是否同时存在"好笑"与"心酸"，只有其一则补另一面
- 一致性：多镜头下人物服装、体型、场景是否一致（有参考图锚定）
- 时长：≤15s 是否一次生成完整片段；>15s 是否已拆为 ≤15s 段并正确拼接
- 插卡字幕：中文、数量克制（≤5张）、停留时间足够阅读
- 配乐：钢琴/管弦，与画面情绪同步，无人声对白
- 画幅：默认9:16，用户指定则优先用户
- 全文语言为中文，无中英混杂
