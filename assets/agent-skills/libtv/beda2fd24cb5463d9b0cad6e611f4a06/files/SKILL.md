## name: original-character-face description: 为原创 AI 人物设计脸型、面部比例和识别特征，建立可复用的角色身份卡，并按目标生图工具生成定妆照或角色修改提示词。适用于原创角色捏脸、虚拟人、短剧和漫剧人物开发，以及同一原创角色的换装、换景和出图复盘。

# 原创 AI 角色捏脸

## 目标与边界

从角色用途与视觉意图出发，设计具有辨识度的原创人物面部，交付可直接复制使用的生图提示词，并为后续角色复用保留身份依据。

核心方法：先设计轮廓和比例，再确定识别特征及五官协调，最后配置表情、妆造、构图和光线。覆盖不同年龄、性别外观与艺术风格；不要把年轻女性、灰底影棚或真人写实当作所有任务的固定答案。

本 Skill 默认完成角色设计与提示词编写。用户要求生图时，才使用当前环境实际可用的生成工具；缺少工具时交付提示词，不声称已经生成、检查或保存图片。不要仅因使用本 Skill 就启动批量生图、购买服务或安装组件。

## 一、任务判断与输入

根据用户当前意图选择工作模式，不要求每次完整重做设计：

模式处理方式新建角色先与用户确认角色想法，再分步生成面部图与（可选）全身像，输出身份卡与适配提示词修改角色继承已有身份卡和参考图，只修改指定部分转换工具保持角色定义，重写工具相关的表达、输入字段和参数审看出图查看实际图片，对照要求指出偏差，给出定向修改提示词只要提示词内部完成必要检查，直接交付适配后的可复制内容

从消息、已有角色卡和附件中提取以下信息，不要求用户逐项填写：

- 角色用途与身份：短剧人物、虚拟人、品牌角色、漫剧人物等。
- 年龄或年龄感、性别外观、用户明确指定的肤色及外观特点。
- 希望传达的视觉气质，以及必须保留或避免的特征。
- 艺术风格：真人写实、二维动画、水墨、三维风格化等。
- 景别、视角、背景、画幅、表情、妆造、服装和光线。
- 目标工具、模型或版本、使用入口，以及本次是文生图还是参考图编辑。
- 已有角色卡、选定定妆图及参考图各自的用途。

处理缺失信息：

1. 用户明确要求优先于旧设定；旧设定优先于预设。用户此次明确改变的项目应更新，不把旧设定当作不可修改的禁令。
2. 不影响核心结果的细节直接补全，并用一句话注明主要假设；不要反复询问背景灰度、衣领材质等小项。
3. 年龄、性别外观或风格的歧义足以导致完全不同的角色时，合并提出一个简短问题。用户已授权自由发挥时自行选择并说明。
4. 未指定工具时默认使用 Seedream 5.5 图像模型，并按本 Skill 的画幅默认值配置；不阻塞在工具选择上，也不假定存在负面提示词字段。用户明确指定其他工具或模型时，以用户指定为准。
5. 没有既有角色材料时，明确这是新角色草案，不能假装已继承某个既有身份。

## 二、新建角色流程（分步确认）

新建角色时按以下顺序执行，每一步都要先取得用户确认再继续，不要一次性跑完全部步骤。

### 步骤 1：生成前先确认角色想法

第一次生成前，先询问用户对这个角色的想法，例如用途、年龄与性别外观、气质、风格、造型方向。不要跳过询问直接出图。

如果用户提供的信息不够全面，最多提出 3 个问题，每个问题都要给出可选答案，让用户直接选择自己想要生成的人物形象，而不是让用户从零描述。问题应聚焦最影响面部结果的项目，例如：

- 年龄感与性别外观（提供若干具体选项）。
- 艺术风格（真人写实 / 二维动画 / 水墨 / 三维风格化等）。
- 主要气质与识别特征方向（提供若干具体选项）。

用户选择并确认后，才生成人物面部细节图。面部图默认 **1:1** 比例（与本 Skill 画幅默认值一致）。生成后按身份卡格式记录轮廓、比例、眉眼、鼻部、唇部与识别细节，作为后续复用的身份依据。

### 步骤 2：面部图满意后再询问是否扩展全身像

面部图生成后，先确认用户是否满意：

- 用户表示满意时，再询问是否要扩展生成全身像。不要未经询问就自动生成全身照。
- 用户表示不满意时，按“出图审看与定向修改”处理，先修正面部图，不进入全身像环节。

用户同意生成全身像后，以面部图作为身份参考，比例默认 **9:16**（与本 Skill 画幅默认值一致）。全身照提示词模板如下，保留用户原句：

```text
保持人物一致性，生成这个人物全身照。这位女性的身高是一米75，体重170斤（偏胖，身材匀称）。轻松愉快地面对镜头，站立在拍照。场景不变，保持现在的场景。可以适当改变人物的表情和肢体动作，是自然的状态下拍出来的一张照片。用徕卡摄影，写真纪实摄影
```

模板使用说明：

- **可替换占位项**：性别称谓（如“这位女性”）、身高体重等体形数据（如“一米75、170斤、偏胖、身材匀称”）、表情与肢体动作描述、拍摄风格（“徕卡摄影，写真纪实摄影”）都应按本次角色的实际情况替换，不要照搬示例数值。
- **固定继承要求**：“保持人物一致性”“场景不变，保持现在的场景”属于必须保留的固定要求，用于延续已确认的角色身份与场景，不要删除或改写。
- 全身照生成后，将结果与面部图一并纳入身份卡与后续复用依据。

## 三、原创设计原则

- 不以特定真人、明星、网红或已有影视角色的身份相似度作为本 Skill 的设计目标。若用户要求“像某个人”，说明本 Skill 的原创定位，提炼非身份性的风格、妆造或画面需求，转为原创面部设计；不要在输出中保留该人物姓名作为相似度指令。
- 真人参考图可以用于提取光线、构图、发型类别、妆容和宽泛视觉气质；不要复刻该人的可识别五官组合。自行设计新角色的轮廓、比例及识别特征。
- 用户已有的原创角色图可以作为同一原创角色的身份参考。区分“外部风格参考”和“原创角色身份参考”，不要因禁止复制真人而禁止复用已选定的原创脸。
- 不从外貌推断人物真实品性、智力、职业能力或道德。角色气质是创作意图，面部结构是视觉选择，二者没有必然对应关系。
- “清冷”“亲和”“英气”等词应落实为可见的轮廓、眼神、姿态和造型；不要仅堆叠“好看、精致、高级、有故事感”。
- 不把厚唇、高鼻梁、方下颌、明显颧骨或自然不对称设为通用缺陷。是否采用取决于角色目标与用户偏好。
- 不承诺“绝不撞脸”“全球唯一”或“提示词保证角色一致”。原创设计过程、偶然相似与跨图稳定性是不同问题，需分别判断。

## 四、面部设计

### 1. 轮廓与比例

按当前风格选择有实际作用的结构描述：

- 外轮廓：脸部长宽感、额头与下颌宽度关系、颧骨转折、面颊饱满度。
- 下颌与下巴：转折位置、线条弧度、下巴长度和宽度。
- 纵向关系：中庭、下庭、鼻部与下巴的相对长度。
- 横向关系：眼距、眼裂长度、鼻翼与唇部宽度的关系。
- 局部关系：眉眼距离、眉形走向、面中起伏。

“三庭五眼”只作为描述比例的辅助框架，不作为标准美的硬性指标。优先使用“略短、适中、偏宽”等相对表达；用户需要精确比例时可记录设计目标，但不得声称文字能强制模型精确执行或从遮挡图片测得准确数值。

圆润轮廓、清晰下颌、长中庭等都可以服务多种角色。允许温柔眼神与有力量的轮廓共存，也允许成熟人物保留圆眼和饱满面颊，不自动消除有意设计的反差。

### 2. 识别特征与五官协调

默认选择一个主要识别特征，辅以少量协调特征，避免所有部位同时被强化。“一个主特征、两个辅助”是便于取舍的方法，不是固定配额。

主特征可以来自轮廓、眉眼、鼻部或唇部，不总是眼睛。写出具体形态，例如“宽而圆的下巴”“眉尾平直的短眉”“鼻背轻微弧度”“清晰的上唇唇峰”，而非只写“独特、有辨识度”。

需要时可加入轻微自然不对称、雀斑或痣等细节；不要为了原创强行添加疤痕、缺陷或过量装饰。非必要部位保持协调，不逐项堆满全部解剖术语。

### 3. 表情、妆造与风格

- 表情与身份分开记录。亲和不必微笑，清冷不必皱眉，反派不必五官夸张；用户要求微笑时直接采用。
- “不微笑”优先写成“嘴唇闭合、嘴角平直、面部放松”等明确状态。存在受支持的排除机制时，再补少量对应排除项。
- 发型、眉毛修饰、妆容、服装和配饰服务角色用途；换装或换发型时，保留约定的固定面部特征。
- 将天生眉形与化妆修饰区分，避免换妆时无意改变角色身份。
- 写实风格按需要保留皮肤纹理与年龄细节；二维、水墨和三维风格按各自语言描述，不统一加入毛孔、真实摄影或商业精修。

### 4. 景别与光线

优先用清晰的画面边界定义构图：

景别或用途推荐表述面部近景包含完整面部，按需求交代是否保留头顶、下巴和耳部胸像头顶完整入镜，下沿到上胸，肩颈自然入镜半身明确下沿到腰部或用户指定位置，避免只写模糊“半身”全身从头顶到脚底完整入镜，留出适量边缘空间面部身份基准图平视、表情中性、面部清晰，避免发丝和配饰遮挡关键轮廓

身份基准图优先让五官与轮廓可辨；情绪海报、剧情图可采用用户需要的暗调、侧光或遮挡，不把影棚默认值带入所有场景。

用户需要明亮的伦勃朗布光时，描述为：主光来自侧前上方，鼻影与面颊阴影衔接，在暗侧脸颊眼睛下方留下小面积三角亮区；弱补光保留暗部细节，整体曝光明亮。不要写成“脸颊出现三角阴影”。左右方向有要求时注明“画面左侧”或“人物自身左侧”，避免混淆。

未指定风格和背景、且任务是写实定妆照时，可以采用“简洁中性背景、柔和主光、清晰面部、平视胸像”作为可替换预设，并说明该假设。不要因此锁定女性、年轻化或固定审美。

### 5. 画幅默认值

未指定画幅时，按任务类型采用以下默认比例，并在输出中说明该假设；用户明确指定画幅时以用户指定为准。

- 人脸图片（面部近景、胸像、面部身份基准图等以面部为主的画面）：默认 **1:1**。新建角色流程中生成的面部细节图同样默认 1:1。
- 全身照（从头顶到脚底完整入镜）：默认 **9:16**。新建角色流程中扩展生成的全身像同样默认 9:16。

其他景别（如半身）未指定时，可按画面需要选择合适比例并说明；不要在用户已指定画幅时套用默认值。

## 五、目标生图工具适配（重点）

### 先确定入口能力，再组织提示词

工具名称不等于具体能力。以用户实际使用的网页、应用、工作流或 API 为准，确认会影响交付的项目：

- 是否接受完整自然语言，是否有长度限制或提示词分段约定。
- 是否提供独立负面字段，排除机制是否在当前模型及配置下生效。
- 是否支持输入参考图、身份参考、图像编辑或多轮延续。
- 画幅、尺寸、参考强度等是独立设置、命令参数还是文本要求。

先使用已有会话信息、当前工具说明或用户提供的设置；只有涉及不确定的专属语法、版本兼容或字段时，才查官方资料。不硬编码“最新版本”、默认模型、参考权重和采样参数。本 Skill 的默认模型为 Seedream 5.5；用户未指定工具或模型时按此默认，用户明确指定其他工具或模型时以用户指定为准。

不能查证时，用自然语言通用版并说明尚未加入专属参数。不要虚构负面字段、参考图上传结果、图像 ID、种子、模型版本或功能支持。

### 按实际入口选择交付方式

实际入口提示词组织排除要求参考图与参数自然语言对话或单文本输入用完整句子说明主体、面部、呈现方式和关键限制融入同一文本，优先描述期望状态；不强制另给负面词框实际支持时说明使用哪张输入图及用途；尺寸等按入口提供的字段填写已确认支持正向与负向字段正向写可见特征，负向单独交付只保留当前任务相关的少量项，并确认配置未忽略负向条件按当前模型或工作流规则使用设置，不套用其他模型参数具有命令参数的入口主体描述与专属参数按官方语法组合只用已确认兼容的排除语法参数放在规定位置；不混入其他平台语法参考图编辑或同一角色延续明确身份依据、需要保留的特征和本次变化排除项按该入口能力处理指向实际已提供的原创参考图；角色编号本身不能替代图像输入未知工具或能力不明输出中文自然语言通用版必要限制写进正文不添加专属参数，可用一句话提示后续能够适配

常见工具的处理原则：

- **Seedream 5.5（默认）**：作为本 Skill 的默认图像模型。按该入口实际提供的字段处理参考图、画幅和排除要求；未指定画幅时套用本 Skill 的画幅默认值（人脸 1:1、全身 9:16）。不能仅凭品牌名称推断存在负面词框或身份锁定功能。
- **ChatGPT / OpenAI 图像入口**：优先交付清晰自然语言指令。需要延续原创角色时，使用入口实际支持的输入图或编辑上下文；不要凭空增加独立负面 API 字段，或在正文混入其他平台参数。
- **即梦 / 豆包 / Seedream 等入口**：区分应用与具体 API。根据当前入口实际提供的字段处理参考图、尺寸和排除要求；不能仅凭品牌名称推断存在负面词框或身份锁定功能。
- **Stable Diffusion / SDXL / ComfyUI 等工作流**：明确实际模型和节点如何接收正负条件；“界面有负面输入框”不等于当前模型配置一定采用它。权重括号、采样器和参考适配器按工作流核实，不输出通用神奇参数。
- **FLUX 等模型的不同实现**：不直接继承其他扩散模型的负向条件、权重语法或参考参数；按实际管线说明适配。
- **Midjourney**：需要排除时可在核实兼容性后使用其 `--no` 机制。版本、画幅及角色参考语法按当前入口核实；没有必要时不写版本号，也不把复杂句子机械拆成可能误排主体的排除词。

以上是路由原则，不是永久能力清单。用户切换工具时，重写输入形式，但保留已确认的角色身份定义。

### 正文与排除项的写法

先写希望画面出现什么，再补必要限制。例如“单人胸像，头顶完整，下沿到上胸，双唇闭合”通常比重复多轮“不要全身、不要半身太远、不要微笑”更清晰。

只在当前任务需要时添加排除项，例如：

- 明确不微笑：微笑、露齿笑。
- 明确胸像：全身、腰部以下入镜。
- 明确写实：用户不需要的卡通化处理。
- 明确动画风：用户不需要的实拍摄影表现。
- 已见实际问题：多余人物、重复五官、遮挡关键面部的发丝等。

不维护固定的“通用审美黑名单”，不默认排除厚唇、高鼻梁、方脸、卡通或暗调。把“明星脸、撞脸”写进负面词不能验证原创性；继续依靠原创设计过程与实际图像审看。

## 六、角色身份卡与复用

新角色交付时给出简洁身份卡；只要提示词时可省略展示。身份卡使用明确状态，区分“草案”和“用户已选定”，不要将尚未选定的方案自动称为最终版。

```yaml
角色编号: OC-001
身份版本: v1
状态: 草案
年龄与性别外观: 按需求填写
固定面部:
  轮廓与下颌: 填写可见形态
  关键比例: 填写少量重要相对关系
  眉眼: 填写形态、距离和走向
  鼻部: 填写鼻背与鼻尖形态
  唇部: 填写唇形与上下唇关系
  肤色与识别细节: 按已知信息填写
主要识别特征: 填写一项主特征及必要辅助
可变项目: 表情、发型、妆容、服装、姿态、场景、光线、镜头
原创身份参考: 未选定；选定后填写实际文件名或可用图像标识
当前呈现: 记录本次风格、造型和画面要求
```

上述 YAML 是内部角色记录格式，不是任何生图平台的 API 参数。交付时填入具体内容，不保留“填写”“按需求”等占位文字；未确定项目明确写“未指定”或“未选定”。

新建角色流程中，面部细节图确认后填入“固定面部”“主要识别特征”，并把该图登记为“原创身份参考”；用户满意并扩展生成全身像后，将全身照一并登记为身份参考，并更新“当前呈现”。

复用规则：

1. 用户选定定妆图后，将该图与身份卡一起作为后续依据。仅有提示词时仍视为文字设定，不能声称身份已经锁定。
2. 换装、换景和换表情时保留固定面部，提示词写清本次变化。不要重新设计未被要求改变的眼型、眼距、鼻形和下巴。
3. 用户明确改变固定面部特征时更新身份版本；仅改服装或背景时更新“当前呈现”，不另造一张脸。
4. 使用多张参考图时逐张指定作用：身份、服装、风格或构图。不能把风格图的人脸误当身份参考。
5. 只有实际可用的图像上下文或参考机制才能传递图片身份；“继续 OC-001”这样的文字编号只用于管理。
6. 正面、四分之三侧面和侧面图仅在用户需要时扩展，沿用同一身份依据。可以分图生成后比较，不保证一张多视图就天然一致。
7. 若参考图明显不满足已确认的身份设定，指出差异；用户已选定的图像身份优先作为视觉依据，无法调和的关键冲突再集中询问。
8. 跨艺术风格时保留主要识别特征，并说明风格转换可能改变特征的视觉表达；不承诺几何比例逐像素不变。

## 七、提示词编写与输出

### 提示词内容

按任务需要组合以下信息，不逐段机械填满：

“生成或编辑目标 → 人物与固定面部 → 表情和当前妆造 → 景别与视角 → 背景、光线与风格 → 必要限制”。

内部设计方法不用原样写进提示词。把“一个强项、两个辅助”“五官服务人物气质”等方法改写为具体形态。相同约束表达一次即可；只有确有必要的重点才重复。

已确认的发色、服装等应选定具体值，不在可复制正文里保留“黑色或棕色”“针织衫或衬衫”等多个未决选项。用户要求比较方案时才分别给出完整版本。

### 默认交付

新建角色通常输出：

1. **角色设计摘要**：少量文字说明视觉方向、主识别特征和主要补全假设。
2. **角色身份卡**：使用上述结构，或等价的紧凑表格。
3. **完整提示词**：一个可直接复制的代码块，按实际入口组织。
4. **负面提示词 / 参数**：仅在实际入口支持且任务需要时输出。独立字段分别放入独立代码块，不混入说明文字。

新建角色时，交付顺序与分步确认一致：先确认角色想法，再交付面部图提示词（默认 1:1）；用户满意并同意扩展后，再交付全身照提示词（默认 9:16，沿用上文模板并替换占位项）。

工具未知时默认按 Seedream 5.5 组织提示词，并标注所用模型与画幅默认值；不额外制造一个假想负面字段。目标入口要求整条命令时，给出一条完整可复制命令。

修改任务通常输出“本次改动与保留项”及完整修改提示词；身份有变化时再更新身份卡。用户只要提示词时，仅输出可复制内容及不可缺少的输入图指引，不追加分析或整张身份卡。

参考图编辑时，在代码块外说明应附上哪张实际图片；代码块内用“附上的原创角色定妆图”等自然称呼，不捏造平台图像 ID。图片尚未提供时，明确该提示词需配合参考图使用。

## 八、出图审看与定向修改

只有用户提供实际图片，或生成工具返回可查看图片后，才进行视觉验收。

按任务相关性检查：

- 用户硬性要求：年龄感、风格、人数、景别、表情与背景是否符合。
- 身份特征：轮廓、眉眼、鼻唇关系和识别细节是否延续。
- 可见性与形态：关键面部是否被遮挡，五官是否重复或畸变，头部透视是否异常。
- 呈现质量：写实皮肤或风格化笔触是否符合目标，光线是否妨碍辨认。

只报告可观察的偏差，说明对应修改。例如“下巴比基准图更窄，需保留较宽的圆下巴”，不要只写“不像、没有高级感”。被遮挡或分辨率不足的特征标注“无法判断”。

每轮优先处理影响身份或用户要求的少量问题，保留已满意的部分。支持编辑时优先从选定参考图定向修改；仅能文生图时提供完整修订提示词，并说明需要重新比较身份。

只有文字时可检查提示词冲突和工具兼容性，不能宣称已通过图像验收。没有持续重试授权时，不因尚未满意就自行开启多轮或批量生成；返回当前结果及下一条可执行修改指令。

新建角色流程中，面部图未获用户满意前不要进入全身像环节；用户不满意时回到本节做定向修改。

## 九、交付前自检

- 用户的风格、年龄、性别外观和构图有没有被默认预设覆盖？
- 固定面部有无互相矛盾的描述？主识别特征能否落到可见形态？
- 是否把宽泛气质当成了人物品性的外貌证据？
- 本次输出是否对应真实入口？是否混入不支持的负面字段、权重或参数？
- 未指定工具时是否按默认模型 Seedream 5.5 组织输出，并按任务套用画幅默认值（人脸 1:1、全身 9:16）？
- 参考图是否真实存在、用途明确？是否把角色编号误当身份控制功能？
- 正向与排除项是否互相否定？是否误排用户需要的风格或面部特征？
- 可复制内容是否完整、无未替换占位符、无互斥选项和多余方法说明？
- 是否清楚区分设计草案、用户选定、已生成和已查看图片？
- 新建角色时是否先征得用户选择再生成面部图？
- 是否在用户满意后才询问全身像扩展？

## 十、简短示例

以下示例展示不同任务的处理方式，面部特征不应成为其他角色的默认模板。

### 示例 A：默认模型（Seedream 5.5），中年男性写实角色

用户：“做一个 45 岁左右的男性修表师，温和但有主见，白底胸像，不微笑，只要提示词。”

默认使用 Seedream 5.5，人脸图片默认 1:1，不附独立负面字段：

```text
生成一张原创男性修表师的写实胸像定妆照，年龄约45岁，纯白背景，平视，头顶完整入镜，下沿到上胸，面部清楚可辨，画幅1:1。
脸部外轮廓略宽，下颌转折圆缓，下巴宽而圆，这是主要识别特征。中庭比例自然，眼距适中；眉形较平，眼型略长，鼻背轻微弧度，鼻尖圆钝；上唇略薄、下唇自然饱满。肤色自然偏暖，保留轻微眼尾细纹和真实皮肤纹理。
短深棕发夹少量灰发，穿灰蓝色棉质工装衬衫。双唇闭合，嘴角平直，眉间放松，直视镜头，以温和而专注的眼神表达人物气质。柔和主光配弱侧向阴影，五官与下颌清晰。画面只有一人，不出现文字、水印或遮脸配饰。
```

### 示例 B：二维水墨女性角色

用户：“28 岁女性行商，利落、爱笑，水墨动画，全身白底。入口已确认支持正向和负向字段。”

正向：

```text
原创成年女性行商，约28岁，二维水墨动画角色设计，全身站姿，从头顶到鞋底完整入镜，纯白留白背景，画幅9:16。
脸型偏长、下颌圆缓，眉毛短而平直、眉尾略向下，这是主要识别特征；眼距适中，眼型圆而不过大，鼻梁短直，下唇略饱满。自然微笑，眼神明亮，肩背舒展。
黑发束成低发髻，穿赭石色短外衫、米白内衫与深墨色长裤，腰侧挂简洁布袋。以克制线条和浅墨晕染塑造面部，色彩少而明确，保留手绘笔触，五官在水墨风格中清楚可辨。
```

负向：

```text
实拍摄影，皮肤毛孔特写，三维塑料质感，复杂场景，人物重复，脚部裁切，文字，水印
```

### 示例 C：同一原创角色换装

用户：“用刚选定的原创定妆图，只把上衣换成白衬衫，其余保持。”

若入口支持图片编辑，指引用户附上选定图，输出：

```text
编辑附上的原创角色定妆图，仅将人物上衣替换为简洁白色棉质衬衫，领口自然，面料褶皱与原图光线一致。
保留原图同一人物的面部轮廓、眼型与眼距、鼻形、唇形、肤色和识别细节。保持原有表情、发型、头部角度、人物姿态、构图、光线、背景及画面风格。衣领与颈部衔接自然，不改变脸部结构。
```

若入口只能文生图，不把上述编辑能力当成已经可用；改为继承身份卡的完整文生图描述，并说明独立重生成后仍需比较身份。

### 示例 D：新建角色分步确认

用户：“帮我捏一个原创角色。”

先询问角色想法；信息不全面时最多提 3 个带选项的问题（年龄感与性别外观、艺术风格、主要气质方向）。用户选定后，生成面部细节图提示词，默认 1:1。

用户表示满意后，再询问是否扩展全身像。用户同意时，以面部图为身份参考，按 9:16 交付全身照提示词，沿用模板并替换占位项：

```text
保持人物一致性，生成这个人物全身照。身高一米75，体重170斤（偏胖，身材匀称）。轻松愉快地面对镜头，站立在拍照。场景不变，保持现在的场景。可以适当改变人物的表情和肢体动作，是自然的状态下拍出来的一张照片。用徕卡摄影，写真纪实摄影
```
