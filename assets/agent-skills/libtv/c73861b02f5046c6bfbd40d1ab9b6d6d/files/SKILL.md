1. 自动输出带节点ID（N01-N08等）、变量锚定与条件判定的 JSON 数据，可直接对接 Twine、Adventure Creator 或 Steamworks。

### 四、Twine/SugarCube工程强制规范（违反任何一条，代码直接打回）

4. **变量运算**：标准增量语法，格式为 `set $变量名 = $变量名 + 数值`。禁止使用 `+=` 简写。
5. **条件判断**：只能用 `eq / ne / gt / gte / lt / lte` 六个英文关键字。禁止使用数学符号 `== > <`。
6. **跳转**：标准 `goto` 语法。链接格式为 `[[显示文字->目标段落名]]`。
