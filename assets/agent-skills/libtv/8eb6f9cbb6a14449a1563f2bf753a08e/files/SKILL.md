# 纪实摄影风（Documentary Photography Style）

## 1. 核心原则 + 持久引擎

**核心原则：纪实摄影的力量来自「被看见的真实」。画面必须像被偶然拍到的，而不是被布置出来的——观者要相信这一瞬间在镜头到来之前和离开之后都在继续。**

持久引擎（因果链）： **真实场景与人物 → 环境中固有的张力（劳作、冲突、仪式、代际、消逝）→ 决定性瞬间（动作、表情或关系的峰值被定格）→ 细节证据（衣物、器物、光线、天气）→ 观者代入「我在现场」 → 情感与记忆点**

纪实感的三根支柱，任何一条缺失画面就会变成「摆拍」：

1. **不完美性**：轻微失焦边缘、自然噪点颗粒、瞬间构图带来的倾斜或裁切、被摄者未完全看向镜头的松弛状态。
2. **光的在场**：现场光优先——窗户侧光、阴天散射、路灯钠光、篝火跳动，不追求影棚式的完美布光。
3. **环境的证词**：背景不是虚化的模糊色块，而是交代人物处境的信息层（晾晒的衣物、积水的反光、斑驳的墙）。

## 2. 质量测试（可证伪）

**把画面里的「主要人物 + 一个背景细节」组合成一句事实陈述，如果不能讲出「谁在哪里做什么、处于什么处境」，则纪实感失败，必须重写 prompt。** 例如「老渔贩在黎明鱼市称鱼，秤杆刚抬起」成立；「一个人站在模糊背景前微笑」不成立。另测一条：画面是否可能是摄影师提前 3 秒到场就拍到的？若是，成立；若必须靠摆布才能成立，失败。

## 3. 输入诊断（落 prompt 前必须想清楚的维度）

把用户输入解析为以下参数，缺失项按默认假设并在交付时说明：

- **题材**：街头人文 / 新闻纪实 / 民族与文化 / 劳动与生计 / 日常切片（默认：街头人文）
- **视觉基因**：经典黑白 / 彩色几何 / 人文暖调 / 冲突现场感（默认：按题材自动匹配，见路由表）
- **黑白或彩色**：用户指定优先；未指定时按题材默认（黑白适合新闻、冲突、劳动的重量感；彩色适合民族服饰、市井烟火、异域文化）
- **时间与光**：时刻（黎明/正午/黄昏/夜晚）与光型（窗口光/阴天散射/逆光剪影/人工光源），未指定时选最能强化张力的光
- **地理与文化语境**：地点、季节、服饰、器物需具体可信，避免文化混搭错位
- **产物形态**：图片（单张/组照）还是视频；视频时长与画幅
- **画幅**：用户指定优先；国内短视频平台竖屏 9:16，横屏叙事 16:9，组照/单幅 3:2 或 4:3（贴近相机取景习惯）；未指定平台时不设限制
- **视频时长**：用户指定优先；未指定时默认 15 秒以内
- **镜头语言（仅视频）**：纪实视频以手持跟拍、固定长镜头、缓慢推近为主，忌频繁运镜
- **合规敏感点**：涉及新闻事件避免可识别的真实人物与尚未定论的事实指控；民族题材避免刻板印象与神圣物品的不当使用；儿童题材仅做环境呈现不做特写肖像

## 6. 输出契约

### 图片

每张图 prompt 必须包含五件套：

1. **主体**：谁 + 正在做什么的具体动作（动词优先，含一个进行中的峰值动作）
2. **环境**：具体地点 + 至少两个背景细节证据
3. **光**：时刻 + 光型（现场光描述）
4. **质感**：胶片颗粒/自然噪点/轻微动态模糊（黑白基因注明黑白胶片与高对比；彩色基因注明色彩策略）
5. **取景**：焦段视角（35mm/50mm 纪实常用）+ 构图方式（倾斜、前景遮挡、直出国界裁切均可，保留抓拍感）

prompt 用正向措辞，不堆否定式约束。

### 视频

- 时长 ≤15 秒的成片，用一次视频生成即可拿到完整片段；分镜 beat（如 0-3s/3-7s/…）是同一次生成内部的时间轴描述，不是分段多次调用。只有成片超过 15 秒时才拆成多个 ≤15s 片段分别生成再拼接。
- beat 模板（以 15s 为例）：
  - 0-3s：环境空镜或人物入画，交代地点与光线，手持轻晃
  - 3-7s：主体动作推进，镜头保持距离感（旁观视角）
  - 7-12s：决定性瞬间出现（动作峰值/表情转折），可缓慢推近
  - 12-15s：动作余韵或人物离开画面，环境细节收尾
- 现场同期声：环境音（市集嘈杂、风雨、机器声）优先，忌配乐化处理

### 默认参数约定

画幅、时长、黑白彩色均为可选参数，用户未指定时：黑白彩色按题材自动匹配；视频 15 秒以内；国内短视频平台默认竖屏 9:16，其他平台按其惯例。用户指定值永远优先。

## 7. 静默自检（出稿前，不外显）

- 质量测试通过：能一句话讲出「谁在哪里做什么、处于什么处境」
- 画面可能是「偶然拍到」的吗：没有影棚布光痕迹、没有全员看镜头、没有完美对称摆位
- 环境证据是否具体：至少两个可辨认的背景细节
- 光是否在场且自然：写明了时刻与光型
- 黑白/彩色是否符合题材默认或用户指定
- 质感条款是否写入：颗粒、噪点、轻微动态模糊至少其一
- 视频：是否声明手持/固定机位的旁观视角；环境音是否优先；≤15s 是否一次生成
- 文化语境是否可信无错位：服饰、器物、场景属于同一地理与时代
- 合规：无真实可识别人物指控、无刻板印象、儿童仅环境呈现
- 措辞全为正向，无否定式堆砌
