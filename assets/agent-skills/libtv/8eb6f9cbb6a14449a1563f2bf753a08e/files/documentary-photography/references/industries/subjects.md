# 纪实题材人物与场景词库

按题材组织的主体、动作、环境细节与张力来源。落 prompt 时从中取词并具体化，禁止原样照抄整段。

## 目录
1. 街头人文与市井烟火
2. 新闻纪实与冲突现场
3. 民族与文化
4. 劳动与生计
5. 日常切片

## 1. 街头人文与市井烟火

**人物与动作**：晨练老人打太极收势、卖早点摊主掀开蒸笼、菜贩整理码放蔬菜、小学生追逐跑过巷口、修鞋匠穿针引线、下棋老人伸手落子、洗衣妇人拧干床单、骑车人驮货穿过人缝。

**环境细节**：湿漉漉的青石板路、褪色卷帘门、横跨巷道的电线与晾衣绳、塑料凳与矮桌、手写招牌、泡沫箱堆、井盖冒出的白汽。

**张力来源**：新旧并置（老墙与霓虹）、代际同框、快与慢的对照（外卖骑手擦过散步老人）。

**适用光**：清晨低角度暖光穿巷、傍晚摊位灯泡暖光、雨后反光。

## 2. 新闻纪实与冲突现场

**人物与动作**：记者举话筒逆风前行、消防员背负水带冲入、救援人员抬担架、围观人群中的表情特写、疏散中的牵手、志愿者分发物资、发布会台上的举手。

**环境细节**：警戒线、散落的物品、水洼倒影、应急灯频闪、被风掀动的布告、泥泞脚印。

**张力来源**：秩序与失序的交界、个体在事件中的位置、被定格的紧张瞬间。

**适用光**：闪光灯直打的硬光、警灯红蓝交替、烟雾中的漫射光。
**注意**：不使用可识别的真实人物；不呈现血腥与伤亡细节；冲突止于紧张，不到暴力特写。

## 3. 民族与文化

**人物与动作**：着传统服饰的妇人低头刺绣、老者念诵经文转动手串、舞者起势前整理头饰、孩童踮脚看祭祀供桌、牧民套马、陶匠拉坯到瓶颈、染布人抖开靛蓝布匹。

**环境细节**：经幡与风、火塘与铜壶、织机与线轴、木窗棂透光、香火青烟、谷物铺晒、手工银饰摊。

**张力来源**：仪式的庄严与生活的日常并置、手艺的专注、传统与年青一代的相遇。

**适用光**：火塘暖光、高原强烈日光、寺庙酥油灯、晨雾散射。
**注意**：服饰、器物、建筑须属于同一民族同一地域，不混搭；神圣物品不做戏谑处理。

## 4. 劳动与生计

**人物与动作**：矿工升井眯眼看天、渔民收网时肌肉紧绷、建筑工人在脚手架间递砖、纺织女工换纱锭、环卫工黎明清扫落叶、卡车司机擦挡风玻璃、稻农弯腰插秧。

**环境细节**：工装与汗渍、安全帽与手套、工具的磨损、粉尘在光柱中悬浮、饭盒与搪瓷缸、结霜的睫毛。

**张力来源**：身体的重量与坚持、劳动节奏的美、劳作与休息的间隙。

**适用光**：逆光剪影、顶光下的汗水高光、车间窗格光、清晨冷调。

## 5. 日常切片

**人物与动作**：窗边老人给花浇水、少年伏案写字抬头望窗外、母亲晾衣服回头喊人、理发店里闭眼刮脸的顾客、雨天便利店门口躲雨的陌生人、地铁里打盹的上班族。

**环境细节**：窗台绿植、蒸汽、玻璃上的水痕与倒影、旧沙发、日历与挂钟、桌上的剩茶。

**张力来源**：平凡中的静止诗意、独处与共处的温度。

**适用光**：窗口侧光、室内灯与窗外天光的混合、雨天散射光。

## 落 prompt 前自检
- 动词是进行中的峰值动作，不是站定摆姿
- 背景细节至少两个且服务于处境交代
- 人物服饰与场景属于同一语境
- 新闻与民族题材的合规注意项已过一遍
