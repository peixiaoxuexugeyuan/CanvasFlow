# 纪实视频 prompt 文法

把视觉基因 + 题材词库翻译为视频生成 prompt 的规则。

## 时长与生成方式
- 时长 ≤15 秒的成片：一次视频生成即可拿到完整片段，beat 是同一次生成内部的时间轴描述，不是分段多次调用。
- 成片超过 15 秒：拆成若干 ≤15s 片段，各自一次生成，再做后处理拼接。

## 纪实运镜词库（按需选用，忌堆叠）
- 手持跟拍、轻微晃动：旁观者的在场感
- 固定长镜头：让事件自己在画面里发生
- 缓慢推近：情绪落点，用于决定性瞬间前后
- 环绕半圈（少用）：仅仪式或群体场景
- 忌：快速甩镜、频繁切换、无人机大范围飞行（除非题材明确需要）

## prompt 结构（按顺序组织）
1. **风格声明**：纪实摄影风格 + 选定视觉基因的核心参数（颗粒、光、色调）
2. **场景与主体**：地点、时刻、人物 + 进行中的动作（来自题材词库并具体化）
3. **镜头**：运镜方式（上表选一）+ 视角距离（保持旁观距离）
4. **时间轴 beat**：0-3s 环境与光 → 3-7s 动作推进 → 7-12s 决定性瞬间（可缓慢推近）→ 12-15s 余韵收尾
5. **声音**：现场同期环境音（市集人声、机器声、风雨、脚步），注明无配乐或音乐极简
6. **质感条款**：胶片颗粒、自然噪点、轻微动态模糊

## 示例模板（15s，市集题材）
「纪实摄影风格，彩色纪实，中等饱和，自然噪点与轻微颗粒。清晨的古镇菜市场，卖鱼的摊主正把一筐鲜鱼倒上案板，水花溅起，旁边老主顾弯腰挑选。手持跟拍视角，保持旁观距离，轻微晃动。0-3 秒：巷口晨光穿过蒸汽，行人入画；3-7 秒：摊主利落地分拣鱼类，吆喝声与秤盘声；7-12 秒：秤杆抬起定格在平衡的一瞬，镜头缓慢推近他的手与眼；12-15 秒：买主提鱼离开，摊主擦拭案板，背景里早市的喧闹继续。现场同期声：人声嘈杂、水声、铁秤碰撞。无配乐。」

## 落 prompt 前自检
- 运镜只选了一种主方式
- 时间轴里有一个明确的「决定性瞬间」
- 环境音具体且无配乐（或极简）
- 质感条款已写入
- 时长 ≤15s 为单次生成；>15s 已拆段
- 画幅按用户指定或平台默认
