# 纪实摄影视觉基因库

四套内置视觉基因。落 prompt 时选定一套，把其影像参数翻译进 prompt 措辞，不逐字照抄。

## 目录
1. 经典黑白（决定性瞬间）
2. 彩色纪实（几何构图）
3. 人文暖调（环境人像）
4. 冲突现场感

## 1. 经典黑白（决定性瞬间）

**何时用**：新闻、冲突、劳动、历史感题材；或用户点名黑白。

**影像参数（prompt 措辞要点）**：
- 黑白胶片质感、细密银盐颗粒、高对比硬调
- 决定性瞬间：人物动作与几何元素在画面中恰好交汇的一帧
- 35mm 视角，轻微倾斜的水平线，人物可被画框边缘裁切
- 暗部厚重、高光不过曝，天空压暗
- 后景元素（楼梯、影子、几何线条）与主体形成呼应

**prompt 示例句式**：黑白纪实摄影，35mm 胶片颗粒质感，高对比；[主体+峰值动作]，[背景细节]，[光型]；瞬间的倾斜构图，画框边缘轻微裁切人物，如街头抓拍所得。

## 2. 彩色纪实（几何构图）

**何时用**：街头人文、市井烟火；画面里存在建筑线条、色块与结构的场景。

**影像参数**：
- 彩色纪实风格，中等饱和，色彩克制而准确
- 强几何构图：门框、窗格、斑马线、墙面色块作为画面的骨架，人物作为几何中的变量
- 前景遮挡（柱、帘、玻璃）制造窥视感
- 一次偶然同框：两个不相干的主体在结构中相遇
- 28-35mm 广角，适度景深，背景信息保留

**prompt 示例句式**：彩色纪实摄影，几何构图；[前景结构] 后的 [主体+动作]，[色彩呼应的背景]；克制饱和，画面结构严谨但瞬间自然。

## 3. 人文暖调（环境人像）

**何时用**：民族、文化、日常切片、人物故事。

**影像参数**：
- 暖调自然光人像，肤色温润，环境交代充分
- 50-85mm 视角，人物与环境各占其半，人物沉浸在手头的事情中而非看镜头
- 暖色温偏移、轻微暗角、浅景深但背景细节仍可辨认
- 手部与眼神方向作为情绪支点
- 地域色彩（服饰、器物的固有色）被如实呈现

**prompt 示例句式**：纪实人文摄影，暖调现场光；[主体] 在 [具体场景] 专注于 [动作]，[环境细节]；50mm 视角，人物神情松弛自然，如同未被察觉的观察。

## 4. 冲突现场感

**何时用**：新闻、突发事件、救援场景。

**影像参数**：
- 新闻现场质感：略微失焦的边缘、动态模糊、颗粒明显
- 硬光或频闪光源，色温冲突（冷天光+暖应急灯）
- 紧凑取景，画面局部出框，信息密但主体明确
- 人群的肢体语言与朝向制造紧张
- 禁止：血腥、伤亡、可识别真实人物

**prompt 示例句式**：新闻纪实现场，[事件] 进行中；[主体动作]，[环境证物]；应急光源，轻微动态模糊与颗粒，紧凑构图如抢拍。

## 落 prompt 前自检
- 只选了一套基因，未混用两套的冲突参数（如黑白+几何高饱和）
- 基因的取景焦段、质感条款已写进 prompt
- 黑白/彩色选择符合题材默认或用户指定
