## 新增预设的写法

一条预设必须包含这 6 个要素，缺一不可：

1. **风格锚点**：一部明确的作品 / 流派名（模型靠它定位）
2. **渲染技术词**：Stylized 3D CGI / Cel-shaded 3D / Photorealistic 3D / Toon shading
3. **骨相与皮肤**：脸型基调、肌肤质感、次表面散射
4. **材质与毛发**：发丝、布料、金属的处理方式
5. **色彩基调**：3~4 个主色的关系 + 情绪（质朴浓郁 / 清雅温润 / 明快饱和）
6. **背景**：极简底色（浅灰微暖 / 浅米 / 中性灰）

写好后追加到本文件，并在 `SKILL.md` 的预设清单里同步登记。
