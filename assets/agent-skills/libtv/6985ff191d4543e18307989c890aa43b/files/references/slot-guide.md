# 槽位填写规范

母版见 `@assets/template.md`。下表列出每个槽位**填什么、填多长、怎么算好**。

| 槽位 | 内容 | 长度 | 写法要点 |
| --- | --- | --- | --- |
| `CANVAS` | 画布比例与分辨率 | 1 句 | 默认「横版 16:9，超高清」；竖版改 3:4，方版改 1:1 |
| `SHEET_TONE` | 整张卡的质感定位 | 8~20 字 | 「3D 动画电影官方美术设定集质感，排版工整、信息层级清晰」 |
| `STYLE` | 画风预设全文 | 整段 | 从 `@references/style-presets.md` 整段取用，不自己拼 |
| `HEAD_TOP` | 造型最顶部 | 2~6 字 | 头巾 / 发冠 / 兜帽 / 发髻 |
| `FOOT` | 造型最底部 | 2~6 字 | 麻绳草鞋 / 厚底靴 / 溯水鞋 |
| `BODY` | 体型 + 年龄 + 身份 | 12~25 字 | 「身形圆润微胖、结实灵动的 17 岁穆柯寨伙夫兼寨兵」 |
| `FACE` | 脸型 + 五官 + 表情 + 记忆点 | 20~40 字 | 脸型、眼、鼻、嘴各一词，再加**一个独一无二的细节**（虎牙 / 疤痕 / 柴灰 / 痣） |
| `HAIR` | 发型 + 发饰 + 材质 | 10~25 字 | 「头扎赭石色粗布头巾」——颜色 + 材质 + 物件 |
| `OUTFIT` | 上装 / 下装 / 腰饰，自上而下 | 25~45 字 | 三段式：交领短打单衣 → 灯笼裤 → 腰系围裙 |
| `POSE` | 站姿 + 手持道具 + 重心 | 15~35 字 | 「双手环抱一口生铁双耳大炒锅立定」——动作 + 道具 + 收尾词 |
| `TURNAROUND_LOCK` | 三视图要锁死的项目 | 10~25 字 | 至少含：头饰扎法、补丁位置、服装结构；有标志性细节就写进去 |
| `CLOSEUPS` | 4 个微距特写，顿号分隔 | 60~110 字 | 固定四选：① 面部微距 ② 眼睛特写 ③ 手部握道具 ④ 材质细节（金属/布料） |
| `GEAR_LIST` | 装备清单，顿号分隔 | 5~7 件 | 与主视觉穿戴**一一对应**，每件写「材质 + 物件」 |
| `PALETTE` | 4 个色名 | 4 词组 | 必须能从角色身上找到出处；用「材质 + 色」命名：生铁黑、土褐黄、赭石红、焦麻白 |
| `NAME` / `AGE` / `JOB` | 档案三项 | — | 中文；JOB 写「身份 + 身份」的复合职业更有戏，如「伙夫兼寨兵」 |
| `NEGATIVE` | 负面词表 | 整段 | **默认沿用下方常量，不要删条目**；换画风时可追加，不可删 |

## 默认负面词常量（NEGATIVE）

```
禁止文字，模糊，低清晰度，脸部塑料感，AI感过强，手指畸形，多余手指，身体比例错误，五官崩坏，文字乱码，服装结构混乱，重复人物，多个主角，现代服装，欧美盔甲，抄袭影视角色，过度磨皮，表情僵硬，四宫格合集，多个角色混在一张图里
```

> 「禁止文字」与「配清晰中文小标签 / 中文角色档案」看似冲突，实为原文约定：禁止的是**模型乱生成的错字乱码**，需要的是**干净的中文标签**。保留即可，不要为了自洽删掉它。

## 三条硬规矩

1. **不写空词**。「英俊潇洒」「气质神秘」「充满江湖气息」一律替换成可见的实体：什么样的眉、什么布料的衣、哪只手拿什么。
2. **一次只讲一个人**。所有槽位只描述该角色，不提他人、不提场景剧情（背景用画风预设里规定的极简底色）。
3. **材质优先于颜色**。先定物件是什么做的（生铁 / 粗布 / 棉麻 / 麻绳），颜色从材质里长出来，色彩板再从物件里提——这条链顺了，整张卡就不会散。

## 信息不全时怎么办

用户只给了「一个 20 岁的剑客」时，按**题材 → 身份 → 材质**三级推演补全，并在提示词后用括号标注「以下为补全项，可替换：发型、足履、色彩板」。不要为了追问中断流程。
