## 示例 B — 沈青梧（预设 `white-snake-3d`，跨题材复用示范）

**槽位值（只列与 A 不同的思路）**

```
STYLE           = <white-snake-3d 预设全文>
HEAD_TOP        = 靛蓝布发带
FOOT            = 草编溯水鞋
BODY            = 身形修长矫健、肩臂有常年撑篙练出的薄肌，22 岁江南漕帮女舵手
FACE            = 鹅蛋脸、细长上挑的凤眼，鼻梁挺直，唇角常挂一点不服输的笑意，眉心一颗小痣，鬓角沾着水汽
HAIR            = 乌发高束成马尾，缠靛蓝布发带，额前两缕碎发被江风吹起
OUTFIT          = 身穿靛青粗布对襟短衫（袖口挽至小臂）、玄色束口长裤，腰缠棕黄麻绳腰带并挂一柄黄铜短篙钩
POSE            = 单手拄一支长竹篙立定，另一手叉腰，重心略偏，衣摆被江风吹起一角
TURNAROUND_LOCK = 发带缠绕方式、腰带结法、袖口挽折高度与服装结构
CLOSEUPS        = 3D 面部微距（正脸直视、凤眼上挑的桀骜、眉心小痣与鬓角水汽）、细长凤眼特写、手部握竹篙的指节与薄茧细节、黄铜篙钩的氧化包浆光泽与靛青粗布的水洗纹理
GEAR_LIST       = 对襟短衫、束口长裤、麻绳腰带、黄铜短篙钩、长竹篙、草编溯水鞋
PALETTE         = 靛青蓝、玄墨黑、棕黄麻、水洗月白
NAME / AGE / JOB = 沈青梧 / 22 / 江南漕帮女舵手
```

**与主视觉对应的完整段落**

