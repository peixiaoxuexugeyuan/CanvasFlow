# 03 · 叙事脊柱与风格方向

## 用法

先按**品类**选脊柱（决定讲什么），再按**风格**选表皮（决定怎么讲）。两者正交，可以任意组合。 用户已定方向 → 直接进 STEP 5，不重复推荐。

---

## 一、六类品类脊柱

### 1. AI / SaaS / 工具类

```
用户意图 → 思考/规划 → 能力展开 → 执行 → 有用产出 → 证明 → LOGO
```

- 必须出现至少一条**可读的因果链**：`输入 → 处理 → 结果`
- "处理"段要有可视化：光标移动、面板展开、并行分支、进度推进
- "证明"段用真实产出，不用抽象光效
- 雷区：只拍界面不拍结果；四个功能并排一闪；假 HUD

### 2. 实体产品

```
主角揭示 → 上手交互 → 功能微距 → 使用场景 → 结果 → LOGO
```

- 揭示段用单光源 + 缓推，不要旋转 720°
- 微距段给材质：纹理、反光、接缝、按键行程
- 上手必须有手（或明确的交互动作），空镜过多显得假
- 雷区：全程产品悬空旋转；只说工艺不说解决什么

### 3. 服务 / 公司 / B 端

```
背景 → 流程 → 证据 → 结果 → 承诺 → LOGO
```

- 流程用 3 步以内，多了记不住
- 证据优先真实：客户现场、真实文件、真实会议、可公开数据
- 承诺一句话，不要三个并列
- 雷区：堆"赋能/链接/生态"；用素材库里的假笑脸

### 4. 影像型品牌（服饰 / 美妆 / 餐饮 / 文旅）

```
真实影像 → 视觉母题 → 利益点 → 情绪落点 → LOGO
```

- 母题反复 2–3 次（一种光、一种颜色、一个动作）
- 利益点必须落到实处（面料、成分、口味、路程）
- 情绪落点给一个停顿，不要一直推
- 雷区：全片无信息只有氛围；模特与目标客群不符

### 5. 小店 / 本地生意

```
门面氛围 → 招牌产品特写 → 制作过程 → 人与人的瞬间 → 地址与营业信息
```

- 前 3 秒必须让人知道"这是卖什么的"
- 制作过程是最强信任状，给足 2 个动作
- 结尾必须有：位置、营业时间、怎么下单（这是转化点，不是装饰）
- 竖屏 9:16 为主
- 雷区：只拍装修不拍产品；地址一闪而过

### 6. 个人项目 / 创作者作品

```
动机 → 方法 → 作品细节 → 影响 → 署名
```

- 动机一句话，别写自传
- 方法展示 1 个独特点即可
- 作品细节给 3 个不同角度，证明"真的做了"
- 署名 + 一个联系方式
- 雷区：抒情过度；全程只有成品没有过程

## 二、九种风格方向

选 1 种为主，最多叠 1 种为辅。叠两种以上会散。

### S1 · Hero Reveal 主角揭示

- 适用：硬件、包装、单一强产品
- 脊柱：实体产品（压缩为 揭示 → 微距 → 场景 → LOGO）
- 节拍偏好：少而重，15 秒走 5–6 拍，前 3 秒必须完成揭示
- 动效母题：单光源横扫、金属反射爬升、尘埃在光柱中浮动、缓推
- 音频：低频铺底 + 一次上扬；无旁白
- 雷区：转成 360° 旋转；光源乱扫造成频闪

### S2 · Kinetic Typography 动态字体

- 适用：口号驱动、活动预告、个人品牌
- 脊柱：以文字为主轴，画面为其服务
- 节拍偏好：密，15 秒可到 8 拍，一拍一词组
- 动效母题：字重变化、字距呼吸、行距推移、遮罩擦除、字块撞击
- 音频：节拍点与文字落地严格对齐
- 雷区：满屏字（每镜 ≤ 12 字）；字与产品脱节

### S3 · UI Walkthrough 界面漫游

- 适用：App、SaaS、小程序、网站
- 脊柱：AI/SaaS
- 节拍偏好：中，15 秒 6–7 拍，每拍一次交互
- 动效母题：光标呼吸、面板从边缘滑入、列表滚动、状态切换、卡片微浮
- 音频：UI 音效（点击、切换、完成），轻到不抢戏
- 雷区：编造不存在的界面；同帧多个弹窗；滚动速度过快看不清

### S4 · Macro Detail 微距质感

- 适用：美妆、食品、材料、工艺
- 脊柱：影像型
- 节拍偏好：慢，15 秒 5 拍，单拍停留 2.5–3 秒
- 动效母题：极浅景深推移、液体流动、粉末落下、织物纤维起伏
- 音频：ASMR 级细节声（摩擦、倾倒、脆响）
- 雷区：微距无信息（只有模糊色块）；全程同一种质感

### S5 · Life-in-Context 生活切片

- 适用：消费品、家电、出行、教育
- 脊柱：实体/服务
- 节拍偏好：中偏快，15 秒 7 拍，每拍一个生活瞬间
- 动效母题：跟随运动、手持轻微晃动、自然光变化、人物视线引导
- 音频：环境声为主（街道、厨房、咖啡店），配乐退后
- 雷区：演员表演过度；场景与客群错位

### S6 · Blueprint / Schematic 蓝图解析

- 适用：技术产品、工业、硬科技、系统架构
- 脊柱：服务/公司
- 节拍偏好：中，15 秒 6 拍，拆解节奏清晰
- 动效母题：爆炸视图、线框生成、标注引出、剖面渐显、参数滚动
- 音频：精密机械声 + 低频脉冲
- 雷区：假蓝图（无实际对应结构）；标注字体过小

### S7 · Data Motion 数据动效

- 适用：有可核验数据的 B 端、金融、效率工具
- 脊柱：服务/公司
- 节拍偏好：偏慢，15 秒 5–6 拍，一个数字一拍
- 动效母题：柱状生长、折线延伸、数字滚动、对比条拉长
- 音频：数字落定音、计数脉冲
- 雷区：**编数据**（绝对禁止）；一屏三个以上数字；无口径

### S8 · Storefront Story 门店烟火

- 适用：餐饮、小店、地方品牌
- 脊柱：小店/本地
- 节拍偏好：中偏快，15 秒 7–8 拍，信息密度高
- 动效母题：蒸汽升腾、油光反射、手部操作特写、人群穿行
- 音频：现场同期声为主，配乐为辅
- 雷区：没有价格/位置信息；只拍环境

### S9 · Long-form Narrative 剧情长片

- 适用：&gt;60 秒的品牌故事、创始人故事、项目纪录
- 脊柱：任意品类 + 双环结构
- 节拍偏好：疏，按 `8 + 0.10×(T−30)` 外推，单拍可长
- 动效母题：镜头语言优先（景别变化、机位切换），动效退为辅助
- 音频：旁白 + 环境 + 配乐三层，旁白是主线
- 雷区：把 30 秒广告拉长成 90 秒（必须加人物弧光或第二叙事循环）

## 四、方向提案的写法（给用户看的三选一）

每个方向三行，不超过 60 字：

```
【方向 A · 名字】
一句话叙事：
视觉记忆点：
适合因为：
```

推荐项标 `（推荐）`，并给一句理由——理由要落在"你的推广重点"上，不是"我觉得好看"。

例：

```
【方向 A · 窗口里的三秒】（推荐）
一句话叙事：真实用户从打开到拿到结果的完整三秒，全程不切镜。
视觉记忆点：光标的一次呼吸，引出整块界面展开。
适合因为：你的重点是"快"，这条片用一次不中断的操作证明了快。
```

## 五、方向选定后的锁定

选完即锁，后续不再改脊柱。要改方向必须回 STEP 4 重来，**不允许在节拍规划阶段偷偷换故事**——那会让已排好的节拍全部作废。

锁定后记录：

```
锁定方向：S? + 品类脊柱?
叙事一句话：
视觉记忆点：
情绪落点：
```
