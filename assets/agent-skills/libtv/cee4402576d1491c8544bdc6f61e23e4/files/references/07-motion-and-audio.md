# 07 · 动效语言与音频策略

## 一、动效三原则

1. **有主**：每一拍只有一个视觉主人。两个东西同时在动，观众两个都没看见。
2. **有因**：转场由画面内的东西驱动——产品运动、光标路径、界面流、光线方向、滚动物、物体边缘、匹配几何。不允许"无缘无故地擦一下"。
3. **有落**：高能之后必须落。峰与峰之间至少一拍 brake 或 settle。

---

## 二、色态系统

全片 **2–5 档色态**，每档绑定一个叙事含义。超过 5 档等于没有色彩策略。

| 档 | 含义 | 典型用色 | 出现位置 |
|---|---|---|---|
| C1 冷静 | 背景、铺垫、思考 | 低饱和冷灰 / 深蓝 | 开场、过渡、机制说明 |
| C2 激活 | 动作发生、被点亮 | 品牌主色 | 交互点、按钮、选中 |
| C3 扩散 | 能力展开、并行 | 主色 + 辅助色渐变 | 能力段、面板展开 |
| C4 高潮 | 最强证据、情绪峰 | 高亮主色 / 暖白 | 证明段、数据落定 |
| C5 落地 | 品牌定格 | 品牌标准色 + 中性底 | LOGO 落版 |

### 规范

- 相邻两档之间必须有过渡（光变化、材质变化、色块推移），不能硬跳
- C4 全片只出现 1–2 次，多了就廉价
- C5 必须是品牌官方色，不许"调亮一点"
- 每拍只主导一档，允许一档作辅助

### 写进提示词的方式

在 `detailed_description` 每镜末尾写色态，不单独开段落：

```
...the palette sits in C1 cool grey with the button already carrying C2 brand red...
```

## 三、运镜词表

### 安全词（只能从这里选）

```
slow push-in / slow pull-back / slow pan / slow tilt / steady dolly / gradual crane
constant gentle speed / very slow drift / slow orbit at constant radius
shallow rack focus over 1.5 seconds / slow parallax
```

### 禁用词（出现即扣分）

```
fast / rapid / quick / whip / snap / spin / swish / zoom in hard / crash zoom / shake / flicker
```

### 理由

禁用词会让模型在两帧之间补出巨大的位移，产生虚影、拖尾、结构崩坏。品牌片要的是"看得清"，不是"很刺激"。**刺激感来自节拍密度与信息强度，不来自速度。**

### 若必须要快

用**剪辑**制造快，不用运动制造快：把 0.8 秒的快切分成 3 个 0.27 秒的稳镜，每镜内部仍是 slow。这样既快又不虚。

---

## 四、微动清单（每镜必填至少一项）

**定镜不等于静止。** 定镜里也必须有可见的微动，否则成片像幻灯片。

| 题材 | 微动来源 |
|---|---|
| 人物 | 呼吸时肩线起伏、眨眼、手指轻微调整、重心转移、发丝晃动 |
| 手部交互 | 指尖压力导致的皮肤形变、手腕微转、按下回声 |
| 界面 | 光标呼吸、输入光标闪烁、进度微推进、卡片极缓浮动、加载点跳动 |
| 饮品 / 食物 | 蒸汽上升的慢卷、液面涟漪、油光游移、冷凝水珠下滑 |
| 织物 | 布料随呼吸起伏、边缘随风轻摆、褶皱缓变 |
| 室内 | 窗帘呼吸、灯光微颤、尘埃在光柱中浮动 |
| 户外 | 树叶微摆、水面细纹、云影缓移、远处人影走动 |
| 产品静物 | 高光沿表面缓慢游移、倒影轻微晃动、灰尘颗粒在光中飘 |
| 纯动效 | 渐变缓慢流动、粒子持续漂移、栅格轻微呼吸、辉光起伏 |

在 `detailed_description` 里把微动**写死到具体位置**，不要只说"画面有动感"。

## 五、转场手法库

| 手法 | 触发物 | 时长 | 适用 |
|---|---|---|---|
| 匹配剪辑 | 同形状 / 同运动 / 同构图 | 0 帧（硬切） | 空间跳转的最优解 |
| 光扫 | 光源移动、高光扫过 | 0.4 s | 场景切换、段落过渡 |
| 色块擦除 | 品牌主色块推过画面 | 0.5 s | 长片段落之间 |
| 遮挡转场 | 人物 / 物体从镜头前经过 | 自然 | 场景切换，最自然 |
| 失焦转场 | 焦点拉走再拉回 | 0.6 s | 情绪切换 |
| 反向推拉 | 构图对称 | 1.0 s | 呼吸感换景 |
| 界面驱动 | 面板推开、卡片翻页 | 0.4–0.8 s | SaaS / App |
| 声音先行 | 下一段的声音提前 0.3 s 进入 | 0.3 s | 任何硬切的软化 |

全片 Bridge 类（光扫 / 色块 / 失焦）合计不超过 2 次。

## 六、音频决策树

```
用户明确要独立可控的旁白/配音？ ──是──→ 单独 synthesize_speech，video 原生音频关
│
├─ 用户要可替换的独立 BGM？ ──是──→ 单独 generate_music，时长按总时长精确对齐
│
├─ 音乐时长需独立于画面（如配合已有曲）？ ──是──→ 单独 generate_music
│
├─ 需要后期混音 / 分轨交付？ ──是──→ 分轨生成
│
└─ 以上都不是 ──→ 走视频原生音频
                  generate_audio = true
                  在 overall_soundscape 与 non_diegetic_music 里写清
```

### 视频原生音频（默认路径）

- 在提示词里写清：器乐、无人声、无歌词、brand-safe
- 环境声与配乐在同一段里分配好"谁在前景"
- 跨段音乐不解决（除末段）

### 单独音频（例外路径）

- 时长必须 = 对应段时长，误差 ≤ 0.1 秒
- 旁白语速：中文约 4.5 字/秒，英文约 2.5 词/秒。写旁白前先按这个算字数
- 旁白与画面文字的语种一致

### 双份禁令

同一条音轨**不要**既有视频原生音频又有单独生成。二选一，在文件头的 `AUDIO NOTE` 里写死。

## 七、音效点位规范

音效要标到秒，不标秒等于没标。

```
00:01.4  按钮按下        one soft mechanical tick, dry, no reverb
00:07.8  面板展开        smooth low whoosh, rising, resolves at 00:09.2
00:09.6  光标落定        barely audible dry tap
```

三类必须有：

1. **动作音**：每个主动作一个
2. **环境底**：全程不断的声床
3. **转场音**：每个接缝一个（若用 Bridge 类转场）

---

## 八、旁白写作（仅当用户要求）

| 项 | 规范 |
|---|---|
| 长度 | 按语速换算，留 20% 余量。15 秒片旁白 ≤ 34 个中文字 |
| 句式 | 短句。一句话一个意思。不用从句套从句 |
| 时态 | 现在时为主 |
| 禁用 | 绝对化用语、未获批宣称、行业黑话 |
| 落点 | 最后一句必须落到行动号召或品牌名 |
| 与画面关系 | 旁白说"为什么"，画面给"是什么"。不要互相复述 |

---

## 九、动效语言交付形态

节拍表之外，额外给一张**动效母题表**：

| 母题 | 形式 | 出现节拍 | 作用 |
|---|---|---|---|
| 光标呼吸 | 光标每 2 秒极缓脉动一次 | 全片 | 贯穿的视觉指纹 |
| 光从右来 | 主光始终来自画面右侧 | 全片 | 空间一致性 |
| 面板推开 | 面板从边缘推入 | 3、5、7 | 产品语言 |
| 色块擦除 | 品牌主色横扫 | 环一→环二 | 段落符号 |

母题的作用是让片子**看起来是一个品牌做的**，而不是四条素材拼的。至少定 3 条贯穿母题。
