# 09 · 自检与交付

## 一、交付前检查表（14 项，逐条打勾）

### 事实类

- [ ] **1. 身份型素材来源**：LOGO、产品 UI、包装、吉祥物、人物，全部来自 `verified` 或 `user-supplied` 或 `licensed`，无 `blocked` 混入
- [ ] **2. 名称准确**：产品名的大小写、连字符、空格与官方一致
- [ ] **3. 宣称有出处**：每一个数字、排名、"首个/唯一/最"都能指回事实表的一行；指不回的已删除或标为概念文案
- [ ] **4. 免责声明在位**：需要免责的品类（健康、金融、教育、效果类）已包含

### 时间类

- [ ] **5. 时长加总**：`Σ 各段时长 = 诉求总时长`，误差 0 秒；`Σ 帧数 = 总秒数 × 30`
- [ ] **6. 时间戳格式**：全部为 `mm:ss`（如 `00:11.5`），无 `01:70` 类写法
- [ ] **7. 时间戳连续**：每镜首尾相接，无缝隙无重叠；全局时间轴跨段连续

### 结构类

- [ ] **8. 节拍数达标**：实际节拍数落在标准区间内（5s→1–2，10s→2–4，15s→5–8，30s→8–12，更长按外推）
- [ ] **9. 段边界对齐**：每个切点落在节拍边界上；无 1–2 秒碎片段
- [ ] **10. 接缝有指名**：每个接缝标明了 L1–L5 中的一种，且相邻两段的 IN/OUT-POINT STATE 互相呼应
- [ ] **11. 画布节点数**：视频节点数 = 段数；命名、时间区间与分段表一致

### 提示词类

- [ ] **12. 六段式完整**：`subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music`，顺序正确，无缺失
- [ ] **13. 防虚影三律**：无 `fast/rapid/whip/spin` 类词；每镜都有微动来源；一镜到底需求已声明 `no hard cuts`
- [ ] **14. 排版合规**：正文全英文；不做手动断行（一字段一行、一镜一行）

### 可读性

- [ ] 画面文字每镜 ≤ 12 字，停留 ≥ 1.2 秒
- [ ] 末段 LOGO 未拉伸、未裁切、未重绘，安全边距内，定格 ≥ 1.5 秒
- [ ] 一镜一个主动作

## 二、交付清单（七件）

| # | 交付物 | 形态 |
|---|---|---|
| 1 | **提示词文件** | 每段一份 `.txt`，命名 `S<i>_<t0>-<t1>.txt` |
| 2 | **节拍表** | 八列，逐节拍 |
| 3 | **分段表** | 每段一行 + 核算行 |
| 4 | **画布节点计划** | 节点表 + 排布说明 |
| 5 | **溯源摘要** | 身份型素材的来源与状态 |
| 6 | **时长核算** | 一行等式，秒级与帧级各一条 |
| 7 | **下一轮建议** | 3–5 条具体的、可执行的 |

第 7 项不要写"可以进一步优化节奏"这类空话。要写"第 5 拍的停留从 2.0 秒加到 2.5 秒，让数据读得完"。

## 三、交付话术模板

```
已完成。<品牌>《<项目名>》，总时长 <T> 秒，<画幅>，<N> 段。

■ 时长核算
  <s1> + <s2> + ... + <sN> = <T> 秒 = <T×30> 帧   ✓

■ 分段与衔接
  S1 <t0>-<t1>  <拍数> 拍  →  L2 动作匹配  →  S2
  S2 <t0>-<t1>  <拍数> 拍  →  L1 尾帧续接  →  S3
  ...

■ 节拍
  实际 <n> 拍 / 标准区间 <lo>–<hi>   ✓

■ 画布
  <N> 个视频节点 + 1 个合成节点，已归入 group <group_name>

■ 提示词
  <N> 份，均为六段式，可直接提交

■ 素材来源
  LOGO / 产品图 / 界面：<状态>

■ 下一轮可以改的
  1. ...
  2. ...
  3. ...
```

## 四、返修建议怎么写

按"改哪里 / 改成什么 / 为什么"三截写。

| 差 | 好 |
|---|---|
| "节奏可以再紧凑些" | "第 3 拍停留 3.2 秒偏长，压到 2.6 秒，把省出的 0.6 秒给第 6 拍的产品收益，那里需要一个呼吸点" |
| "文字有点多" | "第 5 拍画面文字 18 字，拆成两拍各 9 字，或删掉副标题只留主标题" |
| "音频可以再优化" | "第 8 拍的 UI 音效被配乐盖住，把配乐在该拍降 3 dB，或把音效换成更高频的点击音" |
| "LOGO 再突出些" | "末段 LOGO 占比从画面宽度的 18% 提到 24%，但保持安全边距不变；同时把定格从 1.5 秒加到 2.0 秒" |

## 五、验收失败时的处理

| 失败项 | 处理 |
|---|---|
| 时长对不上 | 回 STEP 6 重算，**不许**用"剪辑时拉一拉"补救 |
| 接缝看得出来 | 先试升级到 L1；不行退回去重写 OUT-POINT STATE |
| LOGO 走形 | 删掉重出，或改用官方文件叠加（不做生成） |
| 画面假 | 换真实素材，不打磨仿制品 |
| 节拍超区间 | 删拍，不压缩单拍 |
| 中文混入英文正文 | 整段重写该镜 |
| 文字读不完 | 减字，不加时长（加时长会破节拍） |

## 六、交付后的存档

把五份东西一起放，方便下次复用：

```
deliverables/<brand>_<project>/
├── prompts/S1_0.0-11.5.txt ...
├── beat_sheet.md
├── segment_plan.md
├── node_plan.md
├── provenance.md
└── README.md            （时长核算 + 交付话术 + 下一轮建议）
```

下一轮改版时，改的是 `beat_sheet.md` 与 `segment_plan.md`，提示词随之重生成。**不要直接手改提示词文件**——会让它与节拍表脱钩。
