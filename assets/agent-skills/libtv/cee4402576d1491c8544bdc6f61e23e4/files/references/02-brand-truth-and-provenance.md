# 02 · 品牌事实表与溯源清单

## 目的

把"品牌长什么样、能说什么话"固定下来，让后续所有提示词都有出处。这两张表是提示词的事实底座——写了表里没有的东西，就是编造。

---

## 一、取材可信度分级

| 级 | 来源 | 可作身份型素材 |
|---|---|---|
| 1 | 用户提供的原始导出（AI/SVG/PSD/原始渲染） | 是 |
| 2 | 官网、新闻室、品牌门户、媒体资料包、官方 GitHub | 是 |
| 3 | 公司自营媒体库、官方社媒原图 | 是 |
| 4 | 已授权图库、合作方素材包 | 是（须标 licensed） |
| 5 | 聚合站、搜索缩略图、粉丝再创作、Pinterest 转发 | **否** |
| 6 | AI 生成的形似替代品 | **否** |

5、6 级只能作**非具象动效层**：遮罩、渐变、色场、栅格、辉光、粒子、拖尾、字体、可核验数据图表、转场几何。

## 二、品牌事实表字段

```
── 身份 ──────────────────────────────
品牌名（官方写法）     ：

LOGO 禁用方式          ：拉伸 / 旋转 / 加描边 / 改色 / 加投影

惯用句式               ：

口号（官方）           ：
行动号召（官方）       ：

── 产品 ──────────────────────────────
产品全名               ：
一句话定位             ：
功能清单（可公开）      ：逐条，标是否已上线
使用场景               ：
可公开数据             ：数值 + 出处 + 统计口径
价格/优惠（如适用）     ：
免责声明               ：

── 视觉资产 ──────────────────────────
```

**每一行都必须能指回一个来源。** 指不回去的写"未知"，不写推测。

## 三、溯源清单

一个身份型素材一条记录，用表格或文本节点均可。

| 字段 | 说明 |
|---|---|
| `asset_id` | 稳定短 ID，如 `logo_main`、`ui_01`、`prod_hero` |
| `role` | logo / product / ui / packaging / person / footage / typography |
| `locator` | 本地路径 或 画布节点 ID |
| `source` | 来源 URL 或"用户提供" |
| `source_type` | official-site / media-kit / user-original / licensed-stock / social-official |
| `verify_target` | 用什么比对真实性（如"与官网首页 LOGO 逐像素比"） |
| `rights_note` | 权利与发布提示 |
| `status` | verified / user-supplied / licensed / blocked |

### 模板

```
asset_id       :
role           :
locator        :
source         :
source_type    :
verify_target  :
rights_note    :
status         :
```

## 四、核验动作（三步，很快）

1. **LOGO 核验**：把用户给的文件与官网当前 LOGO 并排看——字体细节、字距、图形比例、颜色。有差异就问一嘴。
2. **产品名核验**：大小写、连字符、空格、是否带版本号。这些是最常见的错。
3. **宣称核验**：任何数字、排名、"首个/唯一/最"都要有官方出处；找不到出处就删掉或改成定性描述。

## 五、能说什么 / 不能说什么

| 情况 | 写法 |
|---|---|
| 官方明示的功能 | 直接说，可配界面演示 |
| 官方数据但口径不明 | 说"官方数据"，不引申 |
| 行业通用能力，非官方明示 | 说"可以做到"，不说"最好的/唯一的" |
| 用户口头描述，无官方依据 | 标为 `概念文案`，交付时说明 |
| 医疗/金融/教育资质类宣称 | 必须有批文编号，否则删除 |
| 竞品对比 | 不点名，不说"比 X 好" |

概念文案不是错，隐瞒才是错——所有非官方出处的文字，在交付说明里列出来。

---

## 六、权利边界

溯源清单**不授予发布权**。它只记录"这是谁的东西"。

- 全部 `verified` → 可正常交付
- 含 `user-supplied` → 交付时一句："素材由你方提供，商用投放前请确认授权范围"
- 含 `licensed` → 标注授权到期日或范围限制
- 含 `blocked` → 该素材不进成片
- 授权状态不明 → 成片标为「非官方概念片」，明确写"商用发布需取得品牌方许可"

这段话放在交付说明里，不要塞在附件深处。

---

## 七、事实表怎么进提示词

事实表不直接变提示词，它过滤提示词：

1. `subject_definitions` 里的品牌名、产品名、LOGO 描述 → 全部来自事实表「身份」段
2. `summary` 的一句话 → 来自「产品 · 一句话定位」
3. `retention_analysis` 的卖点 → 来自「功能清单」，只取已上线的
4. `detailed_description` 的画面文字 → 来自「口号 / 行动号召 / 可公开数据」
5. 任何画面文字想要越界 → 回事实表看有没有出处，没有就改

这条链路保证：**提示词里出现的每一句人话，都能在事实表里找到一行。**
