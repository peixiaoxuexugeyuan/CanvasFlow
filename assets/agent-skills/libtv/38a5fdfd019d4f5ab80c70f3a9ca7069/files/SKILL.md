# 晚清国漫漫剧分镜生产包

## 定位

输入小说原文，输出一套**能直接拿去出图、能拿原稿逐段对账**的漫剧生产包。两条验收线，缺一条就返工：

1. **原文零删节**：原稿每一段都能在生产包里找到落点，一字不删、一字不改。
2. **可开工**：场景、人物、道具、每镜提示词都能直接贴进出图工具，且同一场景、同一人物在各镜之间不漂移。

## 与已有技能的边界

- 只要一张通用分镜表、不要求场景空间图与人物设定版式时，走 `guofeng-manga-storyboard` 或 `manhua-drama-script-generator`。
- 本技能负责**重资产版**：场景俯视结构图 + 九宫格机位图 + 人物版式图 + 道具图 + 零删节核对，适合要长期复用同一套场景与角色的系列漫剧。
- 用户明确要求"原文不许删改"，一律走本技能。

## 交付物清单（十件，顺序固定）

编号交付物作用0原文段落编号表零删节的唯一坐标（P1…PN）1全局风格锁 + 通用负面词全片逐字复用的风格底座2场景库（每场景含俯视空间结构图提示词 + 九宫格机位图提示词）锁空间关系3人物设定卡（含人物设定版式图提示词）锁脸、锁骨骼、锁服饰4道具库（道具设定图提示词）锁材质与形制5分集大纲（每集标注覆盖 P??—P??）节奏与零删节骨架6逐镜分镜表（11 个内容列 + 镜号）可执行的分镜7分镜提示词汇总（一镜一行，可整段复制）直接出图8原文覆盖核对表（P 段 ↔ 镜号）对账凭证9交付自检结果合规证明

## 执行流程

### 第 0 步：原文入库，先编号再动笔

1. 把小说原文按**自然段**切分，逐段编号 P1、P2……PN，写入工作文件 `原文编号.txt`（一行一段，保留原始标点与空格）。
2. 编号表是全流程唯一坐标。之后所有大纲、分镜、核对表都引用 P 号，不再引用"第几章第几段"。
3. 原文有章节标题、题记、作者按语，也单独编号，不许丢。

**硬规则（贯穿全流程）**

- 台词、旁白、书信、告示、唱词：**逐字照抄**，只允许在行首加角色标注（如 `沈砚：`），不许改字、删字、并句、缩句。
- 原文的引号（「」/“”）只是对话标记，允许换成角色标注时去掉**引号本身**，引号里的字一个都不能动。
- 一段可拆成多镜，**不许把多段并成一镜丢内容**。
- 原文的心理描写不作改写，整句原样转成旁白或内心独白镜。
- 允许新增：环境、道具、光影、机位、动作细节、情绪词。新增内容不得覆盖或改写原文事实（人物、时序、因果、地点）。
- 原文缺环境/服饰细节时按晚清时代考据补全，并在开头写一行「设定补全」说明补了什么、依据是什么。

### 第 1 步：锁定全局风格（逐字复用，不许中途换词）

```
画面风格锁（每镜提示词开头逐字复制的字符串）：
国漫线条风，赛璐璐平涂，细腻设色，电影级质感，二次元，晚清时代风格，清晰黑边描边，8K超清
```

- 全片只用这一串。要改风格＝改整包，不许单镜换词。
- 通用负面词固定一段（见 `references/prompt-templates.md`），每镜提示词尾部追加本镜专属负面词。
- 晚清考据只认 1840—1912：物件、服饰、建筑、发型按 `references/prompt-templates.md` 的「晚清道具与服饰词库」取词，现代物件一律进负面词。

### 第 2 步：建场景库（先有空间，再有镜头）

原文出现的每个地点都建一条场景卡，字段固定：

- 场景编号 + 名称 + 内外景 + 时间 + 天气
- 空间布局（方位化描述：上北下南、东厢西厢、前院后院、几进几出）
- 建筑结构（屋顶形制、墙体、梁架、门窗、台阶、院墙）
- 主要景物（树、井、影壁、石阶、匾额……写清位置）
- 主要家具陈设（条案、八仙桌、太师椅、炕、柜、屏风……写清朝向与相对位置）
- 出入口（院门、角门、后门、侧窗，写清朝向与彼此关系）
- 动线关系（人物从哪个门进、穿过什么、停在哪，写成一句路径）
- **场景固定关键词块**（20—40 词，供每镜提示词逐字复用）

每个场景出两张参考图提示词：

1. **俯视空间结构图**：正交俯视，整院/整屋全貌，标出布局、结构、景物、家具、出入口、带箭头的动线。用来建立空间关系大全景。
2. **九宫格多角度参考图**：3×3，九格同一场景、平视视角，只改机位位置与水平角度，空间结构、家具、出入口位置一格都不许变。

两条提示词的完整模板、九格默认机位分配表、负面词，见 `references/prompt-templates.md`，逐字套用后再替换场景变量。

### 第 3 步：建人物库（先有脸，再有戏）

每个出场角色（含主要反派、关键配角）一张设定卡：

- 姓名 + 身份 + 年龄 + 身高体态
- 面部骨骼参数：脸型、眼距（宽/中/窄）、眼型、鼻梁高度与鼻头形、下颚角形状与下颌线、耳位、发际线、眉形、唇形
- 发型与发饰（晚清：辫发、旗头、鬅头、发簪、抹额）
- 常服/礼服两套造型：形制、面料、纹样、缘边、盘扣、腰带佩饰、鞋履、磨损痕迹
- 标志识别细节（疤、痣、断眉、旧伤、戒指、扳指，写清位置）
- 情绪基线（平时神态、习惯小动作）
- **人物固定关键词块**（20—40 词，锁定"谁"，每镜逐字复用）
- **专属负面词**（该角色最易崩的点：如"禁止双眼皮变单""禁止下颚变尖""禁止发际线后移"）

每个角色出一张**人物设定版式图**提示词，版式严格按下述位置排布，不许改版：

```
纯白底，无背景，无投影，无文字标注。
左侧 1/3：人物半身特写（腰部以上，正面偏四分之三）。
右上：全身三视图，横排三格——正面 | 左侧面 | 背面，等高等宽，脚底同一条基线。
右侧中排：6 个头部情绪特写，2 行 × 3 列，依次为 惊惶、谨慎、悲切、迷茫、隐忍、落泪。
右侧中下：3 个关键头部角度——四分之三侧脸、低头、抬头。
右下：服饰细节特写 3 组——领口盘扣与缘边、袖口与手部、腰带佩饰/下摆纹样与鞋履。
一致性：与参考图人物面部特征 100% 相同，骨骼结构、眼距、下颚几何形状、鼻梁、耳位、发际线完全一致；
禁止美化，禁止磨皮，禁止改变年龄、脸型、体型、肤色。
风格：二次元国漫线稿风格，线稿为主、平涂设色为辅，赛璐璐平涂，细腻设色，电影级质感，晚清时代风格。
画质：32K 超清细节，线条干净无锯齿，白底纯净。
```

有原作人设图/演员参考图时，必须用图生图（带参考图）跑版式图，并在提示词里写明"面部特征 100% 与参考图相同"。完整版式模板见 `references/prompt-templates.md`。

### 第 4 步：建道具库

每件推动剧情的道具（信件、玉佩、刀、灯、药碗、匾额、账册……）一条：

- 名称 + 归属 + 剧情作用 + 首次出现镜号
- 形制尺寸、材质、工艺纹样、使用痕迹、日常摆放位置
- 道具固定关键词块 + 道具设定图提示词（纯色浅灰底、三分之四俯视微距、主体居中全貌完整、均匀柔光无硬阴影）

道具在场景里怎么摆、在人手里怎么握，必须与场景固定关键词块、人物手部描述一致——这是后续镜头不出"第二个玉佩"的唯一办法。

### 第 5 步：分集大纲（零删节的骨架）

- 按「单集一个完整小情节 + 结尾留钩子」拆集，单集 1.5—2 分钟、8—12 镜。
- 每集必写：集数 + 标题（≤8 字）+ 核心事件一句话 + 起/转/爆三节点 + 结尾钩子 + **覆盖 P??—P??**。
- 各集覆盖区间首尾相接、不留空档、不重叠，就是零删节的书面凭证。
- 万字以上原文：先把总纲（风格锁＋场景库＋人物库＋道具库＋全部集数大纲）一次出完，再按 8—12 集一批出逐镜表。不要为凑集数稀释每镜颗粒度。

### 第 6 步：逐镜分镜表（11 个内容列 + 镜号 = 12 列，表头不许改）

镜号景别运镜场景人物动作情绪道具台词・旁白转场时长画面生成提示词

字段口径：

- **镜号**：`集号-镜号`，如 `1-03`，集内连续，不跳号。
- **景别**：远景／全景／中景／近景／特写／大特写，六选一，不许写"中近景"这类混合词。
- **运镜**：固定／推镜／拉镜／摇镜／慢移／跟镜／升降／环绕／手持／闪切，十选一。竖屏偏爱推镜与上下慢移。
- **场景**：写场景编号 + 名称，与场景库完全一致（`S03 前院`）。
- **人物**：出场角色名 + 姿态朝向，写"谁在哪、朝哪、身体什么状态"。
- **动作**：可拍的具体肢体动作与物体运动，不写"气氛紧张""十分悲壮"。
- **情绪**：角色此刻情绪 + 外化表现（眼、眉、嘴角、呼吸、手指）。情绪名从人物卡的六情绪体系取词，便于对应设定图。
- **道具**：本镜出现的库内道具编号与名称；没有写"无"。
- **台词・旁白**：原文逐字照抄，行首加角色标注；无台词写"无"。一镜最多两句，单句≤18 字（超长原文句拆镜，不缩写）。
- **转场**：硬切／淡入／淡出／叠化／闪白／闪黑／遮罩转场／甩镜转场／动作接／声音先入／黑场，十一选一，写清"由什么遮什么"。
- **时长**：具体秒数（`3s`），单集累加落在 90—120s。
- **画面生成提示词**：固定结构——

```
风格锁 + 场景固定关键词块 + 画面内容（景别/机位/角度）+ 人物固定关键词块（逐字） +
动作与情绪 + 道具固定关键词块 + 光影氛围 + 画质参数
```

提示词只写能落到画面上的词。禁止"史诗感""绝美""高级感""氛围感拉满"。

### 第 7 步：提示词汇总

按集分块，一镜一行编号列表（`1-01｜……`），行首统一 `- `，方便整段复制。每行末尾附一行负面词：通用负面 + 本镜专属。

### 第 8 步：原文覆盖核对表 + 自检

```
| 段落 | 镜号 |
| P1–P4 | 1-01~1-03 |
```

- 每段至少落在一镜里，允许一段多镜，不允许一段落空。
- 交付前必须跑校验脚本（见下），把结果贴进交付物第 9 项。

## 脚本校验（必跑）

```powershell
python "<skill目录>\scripts\validate_storyboard.py" "<分镜稿.md>" --total-paragraphs <N>
```

脚本检查：表头 12 列（含镜号）是否齐全、景别/运镜/转场是否越界词表、时长是否合规且单集合计落在区间、每镜提示词是否含风格锁三要素（国漫线条/赛璐璐/晚清）、原文段落 1…N 是否全部被覆盖、覆盖区间是否连续无重叠。全部通过打印 `PASS`，否则逐条打印镜号或段落号。

## 出图执行（用户要求直接出参考图时）

1. 先读 `doubao-creative-design` 的 SKILL.md，按其交付流程走。
2. 场景俯视图、九宫格用文生图；人物版式图、道具图优先用图生图带参考图，锁脸与锁形制。
3. 同一场景/同一人物连续出图时，每张都带上对应固定关键词块，并附同一组负面词。
4. 出完抽检：九宫格里九格结构是否一致、人物版式图眼距与下颚是否漂移、是否有过锐化/色偏/噪点/碎块/畸变。不一致就按提示词定位问题重出，不接受"凑合能用"。

## 交付前自检（逐条打勾）

 1. 十件交付物齐全、顺序未变。
 2. 原文段落 1…N 全部被覆盖，覆盖表与大纲区间首尾相接。
 3. 台词/旁白与原文逐字一致，没有改写、缩写、漏句。
 4. 每个场景都有俯视结构图 + 九宫格两套提示词，且含"避免过度锐化、色偏、噪点、碎块、畸变"。
 5. 每个人物都有设定版式图提示词，版式位置与规定一致，含 6 情绪 + 3 关键角度 + 服饰细节 + 100% 面部一致声明。
 6. 每镜提示词都含风格锁三要素与场景、人物、动作情绪、道具、光影、画质六项。
 7. 景别、运镜、转场用词都在词表内，无混合词。
 8. 单集时长累加在 90—120s，镜数 8—12。
 9. 全片无晚清穿帮物件（现代拉链、塑料、水泥、电线、印刷体招牌、现代发型等）。
10. 校验脚本输出 PASS，结果已贴入交付物。

## 常见错误

- **把"零删节"理解成"剧情不删"**：要的是文字级不删。台词改一个字就是违约。
- **场景只写文字不建空间图**：后面每镜都在猜方位，九宫格必然一塌糊涂。
- **人物卡只写"清秀少年"**：不写眼距、下颚形状、耳位，出图必换脸。
- **提示词堆形容词**：删掉所有落不到画面的词。
- **九宫格真画成九种布局**：九格是机位不同，不是场景不同。
- **人数/年龄随意变**：同场景出场人数、角色年龄在整包内锁定。

## 输出与交付

- 单文件 Markdown 成稿：`<故事名>_漫剧生产包_v1.md`，十件交付物按编号顺序排在同一文件内，表格保留原始 Markdown，不转图片、不转截图。
- 原文编号表另存 `<故事名>_原文编号.txt`，一行一段，作为对账原件随包交付。
- 原文超过一万字：先出总纲（0—5 件）交用户确认方向，再按 8—12 集一批补 6—8 件；每批单独跑校验，不要把未校验的半成品当成品交付。
- 用户只要"先看一集"时：出全局风格锁 + 全部场景卡与人物卡 + 第 1 集完整分镜表与覆盖表，其余集数留占位标题。
