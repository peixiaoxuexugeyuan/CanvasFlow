# 暗黑童话角色分离设定图

## 这个 Skill 做什么

使用者给一段角色描述，直接产出一张「服装与人物分离展示」的三联角色设定图，用于固定角色形象、制作角色卡或设定集。

**不适用**：需要多角度旋转展示、多套服装切换展示的场景，不要用这个 Skill。

## 输入

只接受一段角色描述，通常包含：年龄、族裔、五官、发色发型、身型、服装、饰品、气质表情。

使用者**不提供**布局、风格、比例、背景、镜头、模型等任何设置——这些全部由本 Skill 固定，不要向使用者追问，也不要因为使用者没提就自行放宽。

使用者描述中若混入写实摄影措辞（如 85mm 镜头、浅景深、电影级人物肖像、高级时尚大片、烛光与血月、匀称自然比例等），一律只提取其中的**角色特征**（年龄、族裔、五官、发色发型、身型、服装、饰品、气质表情），这些摄影与氛围措辞不得改变本 Skill 固定的渲染风格、比例与背景。

## 产出

一张 16:9 横向三联角色设定图（默认 2K）。

## 工作流

1. **解析角色描述**：从使用者输入中提取角色特征，整理为可填入模板的要素：年龄与族裔、五官（脸型/眼型/唇型/肤色）、发色发型、身型、服装、饰品、气质与表情。描述中没提到的要素不要自己编造，保持模板中对应位置的留白或中性表述。
2. **拼装提示词**：把角色要素填入下方「提示词模板」的 `{{角色描述}}` 槽位，其余部分原样保留，**包括开头的风格段与结尾的风格复述段**。
3. **生成图像**：调用 `lib-image-2.5-pro`，按模板生成一张图。
4. **自检**：对照下方「硬约束」逐条检查产出，任何一条不满足就重新生成，不要直接交付。**首要检查项是「6 头身量化比例」与「真实材质」这两条**——它们是本 Skill 最容易漂移的地方，且会互相牵制（拉回卡通比例时常伴随材质衰减）。
5. **交付**：输出图像，并简要说明这张图对应的角色要素。

## 硬约束

以下三条是死规则，每条都必须满足，不满足则重新生成：

1. **同一角色**：左、中、右三部分必须是同一角色，发色发型、体型、服装完全一致。
2. **左中对齐**：左侧与中间的身高体型严格一致，脚底处于同一水平线。
3. **纯灰背景**：背景只能是纯灰无缝影棚，不得出现场景、道具或其他元素。

以下四条同样不可放宽：

4. **左侧无头处理**：左侧必须是「有手有脚、肩部以上自然收住」的无头展示，不能出现头部断面、不能出现头部、也不能退化成没有手脚的服装模特。
5. **右侧完整**：右侧头部特写必须整个头部完整入画，不能被画面边角裁切。
6. **6 头身量化比例（可验收）**：必须满足以下全部条件——
   - 头部（颅顶到下颌）占全身高度约 1/6；
   - 单眼虹膜直径约占面宽 1/4，眼睛大而圆；
   - 鼻与耳体积放大，形状圆润或尖形夸张；
   - 躯干短圆厚实，腿长不超过全身高度的一半；
   - 四肢为圆柱形几何原语（末端收细、关节圆滑），剪影清晰可读。

   出现 7 头身以上修长比例、时尚八头身、写实真人比例或写实电影 CG 人体比例，即视为不满足，必须重新生成。
7. **真实材质（可验收）**：毛孔、面部细微绒毛、根根分明的发丝簇、SSS 次表面散射透光（如耳廓透光）四项，任一缺失、或整体退化为平滑塑料感与插画平涂感，即视为不满足，必须重新生成。

## 固定风格基调（使用者不可改）

**风格锚点**：皮克斯/迪士尼 3D 动画电影角色设定图，**stylized 3D CG animation render**（皮克斯动画电影渲染），Pixar/Disney dark fantasy fairy-tale animation style，暗黑童话动画片的角色造型语言——不是写实电影 CG，也不是 2D 插画。

**两层要求必须同时满足、互不抵消**：

- **形体与比例走卡通化**：stylized cartoon proportions，6 头身（头占全身约 1/6），颅腔放大、额头饱满、下颌短圆，躯干短圆厚实，腿长不超过全身一半，圆柱形四肢几何语言，圆润饱满的卡通形体，放松中性站姿，双臂自然垂于体侧。
- **材质与皮肤走真实化**：PBR + 皮肤次表面散射（SSS），耳廓透光，面颊与鼻梁可见毛孔与细微绒毛，根根分明的发丝簇带高光，毛发与胡须根根分明，布料织纹与磨损细节，金属宝石 PBR 反射；不磨皮，不做塑料感，不做平滑插画平涂。

即「卡通的比例 + 真实的材质」，不要笼统写成「电影级写实」。

**光影与氛围**：冷色边缘光，深邃阴影，低饱和情绪基调，体积雾，怪异柔和的光晕，胶片颗粒感。这些氛围元素服务于卡通形体，不得把比例拉回写实。

**已知漂移风险（两处，方向相反，需同时盯住）**：

- 深邃阴影 + 低饱和 + 极致细腻质感这类暗黑写实氛围，会把模型推向真人写真比例；
- 反过来，一旦过度强调卡通化，材质又会衰减成平滑插画感，毛孔绒毛消失。

因此卡通比例条款在提示词开头与结尾各出现一次（首尾夹逼），量化指标写进模板，并配负面约束压制；同时把材质条款拆成独立硬约束，避免被比例条款挤掉。不要删减这些复述与量化描述。

### 结论

- v1「偏写实」→ v2「拉回动画但挤掉材质」的此消彼长，被量化条款打破：**「6 头身量化比例 + 真实材质」双约束在三个测试角色（老年男性反派 / 女性黑魔王 / 吸血鬼公主）上均稳定生效**，跨性别、跨年龄泛化良好。
- 量化模板对最初的样例角色同样生效且未过冲。**修正闭环成立，本轮迭代完成。**
- v1 / v2 的失败记录保留为回归基准；后续若改动模板，优先复跑「古代黑魔王」用例，同时盯住比例与材质两端。
