# 脚本转人物资产与分镜

## 这个 Skill 做什么

输入一份剧本/脚本，按固定链路推进到分镜表格为止，产出交给用户自己做后续成片：

**脚本 → 抽取人物 → 生成人物资产图 → 生成分镜表格**

这是一个流程编排器：跨越多种阶段性产出，**每一步完成后都必须停下来等待用户确认，再进入下一步**，不要一路跑到底。

## 触发条件

- 应该用：用户提供了一份剧本/脚本，希望从中抽出人物、生成人物资产图，并继续产出分镜。
- 不应该用：用户只想要单张图片、没有脚本可依据、或只需要其中某一个环节而不需要整条链路时。

## 执行链路

### 第 1 步：抽取人物

- 读取用户提供的脚本，自动抽取其中的人物。
- 抽取范围：**有台词或出场的人物**。
- 输出一份人物清单（角色名 + 简要身份/出场信息），停下来等用户确认名单，再进入下一步。

### 第 2 步：生成人物资产图

- 为名单中的每个角色生成人物资产图。
- **必须套用下方「统一视觉风格规范」「光线分档规范」与「空气悬浮感规范」**，不得自由发挥。
- 停下来等用户确认人物资产图，再进入下一步。

### 第 3 步：生成分镜表格

- 依据脚本与已确认的人物资产，产出分镜表格。
- 表格字段固定为：**镜号 / 画面描述 / 台词 / 人物**。
- **必须套用下方「统一视觉风格规范」「光线分档规范」与「空气悬浮感规范」**，不得自由发挥。
- 画面描述字段如需体现空气层次，应写明该镜头的光线来源与空气介质表现（侧光 / 逆光 / 窗边光等），以便后续生成时不丢失这层信息。
- 每个镜头的画面描述字段应标注所属光线档位（室内白天 / 室内夜晚 / 室外阴天 / 室外晴天柔光），便于生成时直接套用。
- 到此为止，不合成成片（成片由用户自己做）。

## 硬约束（不可让步）

- **角色一致性**：同一个角色在所有分镜中的形象、服装、风格必须保持一致，不能每个镜头都变样。
- **全片风格统一**：画风、色调、光影在全片范围内保持统一，具体以「统一视觉风格规范」为准。
- **全片统一视觉风格**：第 2 步（人物资产图）与第 3 步（分镜表格）都必须套用「统一视觉风格规范」，不得自由发挥。
- **光线分档**：第 2 步、第 3 步及后续任何镜头生成，都必须先判定该镜头属于哪一档（室内白天 / 室内夜晚 / 室外阴天 / 室外晴天柔光），再套用「光线分档规范」中对应的光线描述，不得自由发挥。
- **空气悬浮感**：第 2 步（人物资产图）与第 3 步（分镜表格）都必须套用「空气悬浮感规范」，不得自由发挥。
- **风格优先级**：若脚本自身或已定稿场景实图对某镜光源已有明确规定，以脚本 / 实图为准；本规范作为其余镜头与新增镜头的默认。
- 生成人物资产图与分镜时，都要以上一步已确认的结果为准，不要重新自由发挥。

## 统一视觉风格规范

中性自然、温润真实、克制高级的中国现实主义真人短剧电影风，带央视公益短片质感，生活化写实影像，真实中国北方人物与环境，画面安静、有呼吸感、有生活痕迹。

**光线（总纲）**：整体采用柔和自然光。室内为窗外冷光与室内暖色实用灯混合照明，构成自然层次；室外以阴天柔光或经过柔化处理的自然日光为主。高光轻微晕染，暗部保留层次与细节。此句为总纲，具体执行以「光线分档规范」为准。

**色彩**：整体低饱和、中低反差、中性偏暖，带适度轻微冷暖对比；不要高饱和、不要强烈橙蓝大片感、不要过度暖黄。

**镜头质感**：35mm/50mm 电影镜头视角，浅景深但环境仍清晰可辨、保留空间信息；带 subtle black mist / black pro-mist diffusion 质感、soft halation、轻微电影颗粒；肤色自然温润、不过分修饰、不过度磨皮。

**负面清单**：避免网红感、避免短视频感、避免短视频滤镜感、避免过度商业化与过度商业广告感、避免廉价电视剧感与廉价网剧感、不要硬质补光、不要假 CG 感、不要塑料肤质、不要背景糊成一片、不要夸张摆拍姿态、不要情绪过度戏剧化。

> 待用户确认：「不要韩系奶油质感」一项源自用户原文的乱码还原，需用户确认后再定稿。

## 光线分档规范

先判定镜头属于以下哪一档，再套用对应光线描述。本规范在「光线」维度上优先级高于「统一视觉风格规范」中笼统的光线总纲，后者作为总纲保留，具体执行以本规范为准。

### 室内白天场景

真实中国生活空间，窗外自然冷光作为主光，室内暖色台灯 / 落地灯作为辅助实用光，整体光线柔和通透，人物脸部受光自然，暗部保留细节，空间安静、生活化、真实，有轻微冷暖对比。色彩以米白、浅木、灰蓝、浅棕为主，低饱和、中性偏暖，带 subtle black mist 扩散感和轻微高光晕染，真人短剧质感，克制高级，35mm/50mm 镜头视角，浅景深但环境清楚。

### 室内夜晚场景

低照度生活化电影光线，以暖色台灯、落地灯或室内实用灯为主要光源，局部可有微弱窗外冷色环境光，整体氛围安静、沉静、克制，暗部有层次，不能死黑。高光有轻微柔化和晕染，带 subtle black mist / black pro-mist 质感，色彩中性偏暖，低饱和，人物肤色真实温润，画面有等待感、夜晚陪伴感与轻微孤独感，35mm/50mm 电影镜头视角。

### 室外阴天场景

中国北方现实生活外景，天光柔和均匀，整体低反差，空气中带轻微湿度感或雾感，色彩以灰蓝、青灰、枯绿、浅褐为主，低饱和、中性偏冷，但人物肤色保持自然温润，画面真实、安静、克制，有生活质感和轻微诗意，带 subtle black mist 扩散感，轻微高光柔化，人物与环境关系清晰，35mm/50mm 视角，浅景深但环境仍然可辨认。

### 室外晴天柔光场景

采用自然日光但经过柔化处理，整体明亮通透但不刺眼，高光顺滑不过曝，暗部依然保留细节，色彩低饱和、中性偏暖，环境可带少量冷色空气感，人物肤色自然温润，带 subtle black mist / black pro-mist 扩散感与轻微高光晕染。画面具有开阔感和真实生活感，不是旅游广告风，不夸张，不艳丽，保持克制、自然、电影化，35mm/50mm 视角，浅景深但空间关系清晰。

### 与其他规范、优先级的关系

- 与「风格优先级」：脚本自身或已定稿场景实图对某镜光源已有明确规定时，仍以脚本 / 实图为准，四档作为其余镜头与新增镜头的默认。**示例**：若某镜的实景参考图已确定主光为窗边暖黄自然光，则该镜不因「室内白天」档写「窗外冷光为主」而被改回冷光。
- 与「空气悬浮感规范」：两者并行使用——光线档位决定光源类型与色温，空气介质决定颗粒与大气透视层次，执行时必须同时满足，不得只做其一。

## 空气悬浮感规范

**核心一句话：不是给画面加颗粒，而是让摄影机和人物之间真的有一层空气。**

画面空气不能过于干净透明，必须存在真实、自然、具有空间层次的悬浮颗粒，包括极细微灰尘、空气尘埃、轻微水汽、柳絮、煤尘或环境中合理存在的微小颗粒。颗粒大小必须不完全一致，分布随机、不规则，前景颗粒稍大并偶尔失焦，中景颗粒最清晰，远景逐渐融入空气透视，形成明确的前、中、后景空间层次。

颗粒只在侧光、逆光、窗边光线、矿灯或阳光穿过空气时自然显现，部分颗粒缓慢漂浮、轻微旋转、上下沉降，运动速度各不相同，不能像统一方向飘动的特效粒子。光线穿过空气时允许出现非常克制、自然的 volumetric light / subtle Tyndall effect，但不要形成夸张光柱。

加入轻微空气雾化和真实大气透视，使远处对比度略微下降，让人物与背景之间真正存在一层「空气」。同时保留细腻、不规则的有机 35mm 胶片颗粒，但胶片颗粒与空间中的悬浮灰尘必须明确区分：胶片颗粒属于影像质感，空气颗粒必须真实存在于三维空间中并具有景深变化。配合 subtle black mist / black pro-mist diffusion，让逆光颗粒、高光和空气边缘产生非常轻微的柔化与晕染。

整体必须真实、克制、有呼吸感。禁止：漫天特效灰尘、雪花状颗粒、均匀噪点、闪烁粒子、过度丁达尔、CG 烟雾、鱼鳞纹、涂抹感、廉价电影滤镜感。

**与其他规范的关系**：本规范与「统一视觉风格规范」同属全片视觉硬约束；空气悬浮感是视觉风格在空间层次与介质上的具体化，执行时一并套用。若脚本自身另有相关规定，仍沿用「风格优先级」——脚本内规定优先、本规范兜底。

## 关键行为

- 每一步完成后停下等待用户确认，得到确认才继续下一步。
- 用户对某一步提出修改时，只重做该步并再次等待确认，不要跳步。
