## 这个技能干什么

把「**1 段源视频 + 1\~2 张参考图**」变成一条可直接粘贴进 Seedance 2.5（或 Seedance 2.0 Fast）的中文提示词。核心四件事：

1. **先把源片看透** —— 实测画幅、帧率、时长、硬切点或一镜到底运镜轨迹、每个阶段拍什么动作、音乐 BPM 与起音点。
2. **严格执行置顶** `--cfg` **与** `CFG=5.0` **铁律** —— 提示词顶部固定带 `--cfg` 参数块（`seed=-1`）及未开通豆包会员切换 `seedance2.0_fast` 的提示；参数行统一写 `CFG=5.0`（严禁出现 `C=5.0` 或 `C=0`）。
3. **全文整数秒铁律** —— 正文所有时间描述（总时长、阶段首尾区间、切点、动作时间点）一律四舍五入归为**整数秒**（如 `7.8秒` 写 `8秒`，`0.0–1.2秒` 写 `0–1秒`，**严禁出现任何带小数点的秒数**）。
4. **精准外观锁定与姿态分离** ——
   - **仅提供【图1】要求“锁定图一五官”时**：100% 锁定【图1】面部骨相与五官特征，彻底剔除【图1】的发型、头饰、服装与静态背景；发型、眼镜、穿搭、鞋履、美甲与运镜动作 100% 复刻源视频。
   - **同时提供【图1】与【图2】用于换脸+换装时**：固定以「【图1】作为面部五官参考、【图2】作为身材与服装参考」写入成稿（美甲颜色默认匹配所选服装参考图中的美甲或服装配色），严禁出现“按新参考图更新”“本轮新服装”等过程性字眼。
