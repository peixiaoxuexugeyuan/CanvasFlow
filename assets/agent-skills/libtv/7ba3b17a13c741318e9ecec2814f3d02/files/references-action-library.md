# **七、动作词汇表**

## **核心单动词**

**• 踏**（stomp）：蓄力，脚踩实地面

**• 盘**（coil）：蓄力，身体蜷缩蓄能

**• 扫**（sweep）：爆发/穿插，水平弧线攻击

**• 劈**（cleave）：爆发，垂直下劈

**• 刺**（thrust）：爆发/穿插，直线穿刺

**• 挑**（slash upward）：爆发，由下向上斜挑

**• 冲**（charge）：冲刺，全力冲锋

**• 跃**（leap）：冲刺，跳跃突进

**• 旋**（spin）：爆发/穿插，旋转身体或武器

**• 闪**（dodge）：穿插，闪避攻击

**• 格**（parry）：穿插，格挡兵器

**• 破**（break through）：穿插，强行突破

**• 穿**（pierce through）：穿插，穿透敌阵

**• 奔**（sprint）：奔跑，全速奔跑

**• 拖**（drag）：蓄力/奔跑，武器拖地

**• 撞**（charge into）：冲刺，身体冲撞

**• 拨**（deflect）：穿插，拨开攻击

**• 踢**（kick）：穿插，腿部攻击
