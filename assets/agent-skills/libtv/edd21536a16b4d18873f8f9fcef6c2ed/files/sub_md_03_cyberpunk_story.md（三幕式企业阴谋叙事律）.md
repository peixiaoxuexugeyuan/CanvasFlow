# 附MD 3 | 三幕式企业阴谋叙事律

## #做什么

确保赛博朋克故事不流于表面，注入深层的社会批判与“困兽法则”。

## #需要什么输入

- 故事大纲或互动影游分支。

## #怎么做

### 一、 核心赛博冲突

- 主角面临的绝境必须与“数据篡改、记忆伪造、企业洗脑、阶级压迫”相关。
- **困兽抉择**：选择揭露真相会害死亲友，选择保持沉默会成为企业的傀儡。

### 二、 三幕式节奏控制

- **第一幕（0-5s 钩子）**：一个极其反常的科技现象（如：主角的机械义眼看到了不属于自己的记忆）。
- **第二幕（冲突升级）**：遭到巨型企业（Megacorp）的追杀，必须潜入暗网或地下黑市寻找线索。
- **第三幕（高潮反转）**：最大的视觉冲击（如：拉开企业高管的皮囊，发现底下是仿生机器人；或者发现自己才是那个被伪造出来的“假冒伪劣品”）。

### 三、 对白风格

- 冷酷、短促、带有黑色幽默或虚无主义。
- 避免长篇大论，多用指令性语言或自言自语。
