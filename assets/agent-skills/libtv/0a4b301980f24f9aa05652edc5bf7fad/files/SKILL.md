# 图像逆向绘图提示词

把一张已完成的图像逆向翻译成一段可直接使用的中文 AI 绘图提示词。**只输出提示词文本，不生成图片。**

## 输入

- 必填：一张图片（用户上传，或画布上指定的图片节点）。
- 选填：画面比例、需要重点还原的区域、目标绘图工具（默认按通用中文 AI 绘图工具的逻辑写）。

若用户只给了一张图、没有别的说明，直接开始，不要反问。

## 输出

**一段完整连贯的中文描述文本**，不是分点清单、不是表格、不是多段小标题。所有要素融合成一段话，读起来像一句长提示词。

## 执行步骤

1. **读图**：先整体后局部。整体判断这张图属于哪一类（海报／封面、人物摄影、产品图、场景概念图、插画等），再逐区域细看。
2. **按九大维度逐项提取**，确保画面所有核心内容都被覆盖：
   - **风格定位**：写实摄影／三维渲染／扁平插画／国潮／赛博朋克／极简商业等，以及整体质感定位。
   - **画面视角**：平视／俯视／仰视／等距视角／微距／广角，镜头焦段倾向（如 35mm 广角、85mm 人像）。
   - **构图方式**：居中对称／三分法／对角线／S 形引导／满版留白／上下分层等。
   - **场景呈现**：环境是什么、空间关系、纵深与层次。
   - **元素摆放**：各元素在画面中的相对位置（左上、右下、中段等）与主次关系。
   - **元素承载物**：元素附着在什么之上（台面、玻璃方块表面、墙面、纸张、悬浮空间等）。
   - **场景元素的形态与布局**：形状、数量、走向、排列方式、疏密关系。
   - **材质触感表现**：玻璃、金属、磨砂、丝绸、液态、纸质等，写清反光方式与触感。
   - **整体色彩搭配 + 背景细节**：主色、辅色、渐变方向、明度倾向；背景的纹理、光晕、台面线等细节。
3. **文案排版设计描述**：如果图中有文字，必须描述其排版设计——位置、层级（主标题／副标题／辅助小字）、字体气质（超粗黑体／细体／衬线）、字色、描边或发光、对齐方式、与图形元素的关系。**只描述排版与视觉特征，不要试图逐字复刻长段文字内容**；短标题可原样引用。
4. **补充专业术语**：在描述中自然嵌入摄影或渲染领域的术语，例如：柔光箱布光、轮廓光、景深虚化、体积光、环境光遮蔽、次表面散射、镜面反射、法线细节、高调／低调影调、色温倾向、胶片颗粒等。术语要贴合画面实际，不要堆砌。
5. **整合成一段**：把上面所有信息串成一段连贯描述，按"风格 → 视角与构图 → 场景与主体 → 元素与承载 → 材质 → 色彩与光影 → 背景 → 文案排版 → 画质与术语收束"的自然顺序推进。
6. **自检**：回读这段提示词，逐项核对九大维度是否都有落点、画面里有没有明显被漏掉的元素、是否混入了图里并不存在的东西。发现遗漏就补，发现臆造就删。

## 约束

- **只输出提示词，不调用生图**。用户明确说"不需要生图"时，绝对不要顺手生成图片。
- **忠实于原图**：只描述画面里真实存在的内容，不添加原图没有的元素、不美化、不脑补。
- **符合中文 AI 绘图工具的提示词逻辑**：用中文自然语言长句，修饰语前置、名词在后，避免英文标签堆叠和逗号分隔的关键词罗列；避免否定式表述（如"没有…"），改用正向描述。
- **一段话**：不要输出分点、不要输出多个标题段落。
- 若图片本身模糊或信息不足，在提示词末尾用一句话说明哪些部分属于推测，不要静默编造。
