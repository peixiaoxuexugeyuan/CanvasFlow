# 凤火照日月·分场景视频生成

把《凤火照日月》剧本按集/场拆解，标注每场戏种，套用对应的运镜与表演模块，产出该场的分镜与视频提示词。全片统一风格作为锚点固定不变，只有"戏种模块"随剧本内容切换。

---

## 一、总原则

1. **先拆解、后生成**：拿到剧本先按集/场拆解并标注戏种，再据此选模块、出分镜、写 prompt。不要跳过拆解直接生成。
2. **台词逐字保留**：剧本台词一字不改。**画外音、内心声、声音先行（凿击声、骂声、夜巡者吆喝等）不得当成当面台词处理**——它们不进"说话者口型同步"逻辑，按声音层单独标注。
3. **风格锚点不随戏种变化**：下面的"全片统一画面风格"与"统一运镜"是全片常量；只有"分场景节奏策略"随戏种切换。
4. **对话剧情必须有镜头感**：凡是对话、剧情推进的场次，镜头设计必须具备电影感的机位、景别与运镜变化（过肩、特写、推拉摇移、反应镜头等），**不得平铺直叙，不得使用普通、呆板、从头到尾不变化的固定双人镜头**。镜头要参与叙事，随台词、情绪与人物关系变化而变化。
5. **硬性技术约束**：视频比例 **9:16**；**不做尾帧衔接**——不使用首帧/尾帧承接方式，镜头之间靠人物位置、视线方向、动作方向与场景空间的连续性，以及动作匹配剪辑来衔接。

## 二、工作流（每次执行按此顺序）

**第 1 步：拆解与戏种标注**按剧本的"第X场 场景 时段"逐场拆解，为每场标注戏种标签之一：

戏种标签判定依据对应模块危机动作撤离、格挡、关门、器械对抗、争分夺秒§四·模块A谈判权谋隔门对峙、身份牌、契书验证、赌约、反将一军§四·模块B情感母子、愧疚、隐忍、情绪爆发、道德抉择§四·模块C民生过场街巷、货棚、粮铺、河埠码头、市井生活流动§四·模块D穿越视觉转换现代→明代的视觉过渡场§四·模块E

一场戏可同时带多个标签（如"危机动作＋空间对峙"），按主次排出主戏种与次戏种。

**第 2 步：选模块**按上表为每场选定运镜模块（§三统一运镜 + §四分场景节奏），并确定该场的表演重点（哪种情绪、谁说话谁倾听）。

**第 3 步：出分镜**每场输出分镜表，每镜包含：镜号、景别、机位/运动、时长、画面内容、人物动作与表演要点、台词（逐字，标注说话者/画外音/内心声）、音效、衔接方式（动作匹配/视线匹配/位置连续）。 **对话/剧情场额外要求**：分镜必须体现镜头设计变化——同一场戏内应包含不同景别与机位的组合（如双人中景交代关系 → 过肩镜头 → 单人近景/面部特写 → 倾听者反应镜头），并明确写出每镜的机位与运动（推、拉、摇、移、跟等）；**不得整场只用同一个固定双人镜头平铺直叙**。

**第 4 步：写视频 prompt**每镜一条 prompt = `统一画面风格（§五）` + `统一运镜（§三）` + `该场戏种模块（§四）` + `本镜具体内容` + `负面约束（§六）` + `技术参数（9:16，不做尾帧衔接）`。 对话/剧情场的 prompt 必须写明本镜的机位、景别与运动方式，体现电影感镜头调度。

**第 5 步：连续性自检**输出前逐条核对 §七 连续性清单。

## 三、全片统一运镜（常量，八大项）

**整体运镜风格**：真人电影级历史穿越剧摄影风格，成熟的影视剧镜头语言，电影级摄影构图与真实摄影机运动逻辑，运镜自然流畅，镜头调度具有明确的叙事目的。根据人物情绪、剧情节奏、场景空间和戏剧冲突灵活调整景别、机位、焦段及运动方式。拒绝无意义的镜头晃动、机械式推拉摇移、频繁旋转镜头和炫技式运镜。镜头运动要有起始、有过程、有停顿、有落点，保持画面稳定、空间关系清晰、人物位置连续。

**一、人物出场运镜**：环境交代镜头与人物特写相结合。先以远景或全景展现人物所处的时代环境与空间位置，再按剧情缓慢推进至中景、近景或面部特写。重要人物出场可用低机位缓慢推进、侧面跟拍、逆光轮廓镜头增强气场。**沈念慈出场以平稳推进和精准构图为主，突出冷静、果断、独立的女强人气质，不使用刻意夸张的仰拍和慢动作。** 人物进入场景时镜头跟随自然移动，保持人物在画面中的空间位置稳定，避免移动方向突然改变。

**二、人物对话运镜（对话/剧情戏的镜头感核心）**：电影级正反打镜头语言，**对话与剧情推进必须有镜头感，严禁平铺直叙、严禁整场使用普通呆板的固定双人镜头**。必须组合运用双人中景、单人近景、过肩镜头、面部特写、反应镜头以及推、拉、摇、移、跟等运镜变化，让镜头随台词、情绪与人物关系推进而改变。

- **开场**：优先用双人中景交代站位、视线方向与距离，快速建立人物关系与空间，但不长时间停留于此。
- **过程**：按情绪切换过肩镜头与面部近景；机位与景别持续变化，避免同一机位、同一景别反复或长时间不变。
- **重点**：重要台词、情绪转折或心理变化时缓慢推进至面部特写。
- **表演**：说话者镜头捕捉嘴角、眉毛、眼神、呼吸与细微面部变化；倾听者也要有真实反应镜头，表现眼神变化、短暂停顿、下意识动作与情绪压抑。
- **对峙**：可用正反打逐渐缩短景别，配合轻微推进，逐步增强心理压迫感。
- **原则**：人物情绪越激烈，镜头越精准克制，不用无规律晃动代替表演；但镜头设计本身必须有电影感，不能靠一个固定双人镜头从头拍到尾。

**三、商战与权谋运镜**：稳重、克制、富有压迫感的镜头调度。利用对称构图、桌面纵深构图、过肩镜头和低角度近景表现双方力量关系。通过缓慢推镜突出关键人物眼神变化，通过细节特写呈现手指敲桌、账册翻页、银钱交接、握拳、停顿等细节。占据主动权时用稳定正面构图与缓慢推进；陷入被动时用侧面构图、前景遮挡与略带压迫感的机位。重要信息揭露时先给人物反应，再切关键物品或证据特写，最后回到人物面部。

**四、情感戏运镜**：细腻、克制为主。优先固定镜头、缓慢推近、浅景深近景与面部特写，捕捉眼眶变化、眼神躲闪、嘴唇颤动、呼吸停顿、手指收紧等真实细节。情绪积累时镜头缓慢靠近；爆发时短暂切入特写；平复时适当拉开，重新交代人物与环境关系。悲伤场景不滥用慢动作，不使用夸张环绕运镜。

**五、打斗与动作戏运镜**：强调动作力量、速度、方向、受力反馈与空间连续性。开打前用全景或中景交代双方站位、距离、攻击方向及周围环境；动作开始后用侧面跟拍、横向移动、快速摇镜和短促推进捕捉攻击与躲避。关键攻击可切入局部特写（拳头握紧、刀锋划过、手腕被抓住、身体受撞击、脚步滑动）。近身搏斗用中近景与局部特写交替，确保看清每次出招、格挡、闪避、反击与受力。动作衔接必须符合人体运动规律，保持人物左右位置、移动方向与动作前后关系一致。关键打击瞬间可用短暂速度变化或轻微镜头震动表现力度，但不能持续抖动或影响动作辨识度。动作结束后及时回到稳定镜头，展现身体状态、呼吸变化、受伤情况与胜负结果。

**六、历史环境与场景运镜**：明末苏州街巷、棚区、商铺、宅院、粮铺、码头等用电影级环境交代镜头。通过远景、全景和缓慢横移展现建筑布局、街道纵深、人物活动及时代生活气息，利用前景遮挡、中景人物活动和远景建筑形成层次。街道场景用平稳跟拍、横向移动和缓慢推进；室内场景用门框构图、窗棂前景、侧向滑轨增强空间纵深。现代金库场景用更冷静、精准的镜头语言，突出金属结构、空间秩序与现代环境的冷峻质感；穿越至明末后，镜头节奏与构图逐渐转向更具生活气息和历史厚重感的表达。

**七、镜头衔接与剪辑节奏**：镜头之间保持动作连续、视线连续、人物位置连续、空间方向连续。人物转身、起身、走动、递交物品、开门、拔刀等动作尽量用动作匹配剪辑。对话戏以情绪节奏控制剪辑速度；商战戏以信息揭露和人物反应控制剪辑速度；情感戏适当延长镜头停留时间；打斗戏按攻防节奏快速切换，但每个关键动作必须完整、清晰。**避免同一场景反复使用相同机位，避免连续镜头景别完全雷同，避免无目的的快速切镜；对话/剧情场尤其要避免整场固定双人镜头，必须通过机位、景别与运镜变化保持镜头感。**

**八、摄影机运动与画面质量要求**：摄影机运动符合真实电影摄影设备的物理运动规律，推、拉、摇、移、跟、升、降、环绕等运动自然平顺，起停柔和，速度变化合理。保持人物面部清晰、主体突出、背景层次分明，景深变化自然，焦点准确跟随人物或关键动作，不出现无故失焦、焦点跳动和画面畸变。全片运镜服务于人物表演和剧情叙事，不为炫技而运动，不为制造电影感而过度使用慢动作、旋转镜头和大幅度环绕镜头。

## 四、分场景节奏策略（核心调度规则，按戏种切换）

**全片不得一律快节奏。** 按戏种分配节奏：

- **沈念慈的商战与权谋戏 → 要稳**：稳重、克制、压迫感，缓慢推镜与对称/纵深构图，靠停顿与眼神博弈，不用快切。
- **人物情感戏 → 要细**：细腻、克制，固定镜头与缓慢推近，延长镜头停留，捕捉微表情与呼吸。
- **林风的打斗戏 → 要快而清楚**：快节奏但每个关键动作完整清晰，攻防节奏有层次，不糊、不丢动作。
- **明末街市与民生场景 → 要有真实的生活流动感**：平稳跟拍、横向移动、缓慢推进，展现时代生活气息。

**对话/剧情戏共通要求（覆盖模块B、模块C）**：无论节奏是"稳"还是"细"，镜头设计都必须有电影感，靠机位、景别与运镜的变化参与叙事，**不得平铺直叙、不得整场固定双人镜头**。节奏稳≠镜头不动，节奏细≠画面呆板。

由此兼顾历史剧的厚重感与短剧需要的戏剧冲击力。

### 模块A｜危机动作戏（林风打斗线）

节奏：快而清楚。开打前全景/中景交代站位与方向；动作中侧面跟拍＋横向移动＋快速摇镜＋短促推进；关键攻击切局部特写；中近景与特写交替，确保看清出招—格挡—闪避—反击—受力全过程。攻防节奏层次：短暂对峙—突然发力—连续攻防—短暂僵持—反击制敌。关键瞬间可短暂慢动作或轻微震动，不持续抖动。结束回到稳定镜头交代呼吸、伤情、胜负。人物位移、左右位置、武器位置全程一致。

### 模块B｜谈判权谋戏（沈念慈商战线）

节奏：稳。对称构图、桌面纵深、过肩镜头、低角度近景表现力量关系；缓慢推镜突出眼神；细节特写呈现手指敲桌、账册翻页、契书、银钱交接、握拳、停顿。占主动→稳定正面构图＋缓慢推进；陷被动→侧面构图＋前景遮挡＋压迫机位。信息揭露顺序：人物反应 → 关键物品/证据特写 → 回到人物面部。对峙可用正反打逐渐缩短景别＋轻微推进，增强压迫感。用短暂停顿与细微眼神变化表现心理博弈，不靠晃动。 **镜头感要求**：本模块是对话为主的戏，必须靠过肩、单人近景、面部特写、反应镜头与推拉摇移的变化组织镜头，**严禁整场只用固定双人镜头平铺直叙**；"稳"体现在机位精准、运动克制，而不是画面僵死不变。

### 模块C｜情感戏

节奏：细。固定镜头、缓慢推近、浅景深近景、面部特写，捕捉眼眶变化、眼神躲闪、嘴唇颤动、呼吸停顿、手指收紧。情绪积累→缓慢靠近；爆发→短暂切入特写；平复→适当拉开。不滥用慢动作，不用夸张环绕。倾听者必须有反应镜头，禁止木偶式站立。 **镜头感要求**：情感戏同样是对话/剧情戏，必须有过肩、近景、特写、反应镜头与缓慢推近等变化，**不得整场固定双人镜头**；"细"体现在镜头克制与停留，而不是缺少镜头设计。

### 模块D｜民生过场戏

节奏：生活流动感。远景/全景＋缓慢横移展现街巷、货棚、粮铺、河埠码头的建筑布局与人物活动；前景遮挡＋中景人物＋远景建筑形成层次；街道用平稳跟拍与横向移动。时代物品、市井声音（如夜巡者吆喝"天干物燥，小心火烛——"）作为氛围层，不得出现现代物品。

### 模块E｜穿越视觉转换

现代金库：冷峻、简洁、真实的现代工业摄影风格，冷白灯、金属结构、空间秩序。明代：自然、沉稳、历史厚重感的电影色彩。转换要自然连贯，镜头节奏与构图从冷峻精准逐渐转向生活气息与历史厚重感。

## 五、全片统一画面风格（常量，写进每条 prompt）

**真人实拍电影级视觉风格**，中国明末历史穿越题材，明代崇祯十六年历史背景，高规格古装历史电影摄影美学，真实真人演员质感，真实人体比例与骨骼结构，东方人物自然面部特征，人物五官具有辨识度，保留真实皮肤纹理、毛孔、细微瑕疵、自然肤色变化与真实皮肤次表面散射效果，真实发丝、眉毛、睫毛和布料材质，拒绝塑料皮肤与过度磨皮。整体采用电影级摄影机成像质感，真实光学镜头效果，合理的焦距、景深、透视关系和空间层次，电影级构图，成熟的影视镜头调度。

**历史环境与时代质感**：明末崇祯年间真实历史环境，苏州府古城风貌，明代建筑结构、青砖灰瓦、木质门窗、榆木家具、石板街道、传统商铺、货棚、民居、河埠、码头等场景具有真实历史生活质感。建筑比例符合真实空间逻辑，材质呈现自然岁月痕迹，避免过度破败和刻意脏乱。街道、房屋、家具、器物、交通工具及人物生活细节符合明代时代背景，**不出现现代建筑、现代家具及不符合时代的物品**。现代金库＝冷峻、简洁、真实的现代工业摄影风格；明代场景＝自然、沉稳、富有历史厚重感的电影色彩；穿越前后视觉转换自然连贯。
