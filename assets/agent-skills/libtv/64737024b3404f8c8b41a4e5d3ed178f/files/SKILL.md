# 深度视频换装重绘

以深度／动作捕捉视频为结构与运动基准，替换画面里的物件、材质或角色形象，重新生成一条**原运镜与动作完全不变**的新视频。

---

## 适用场景

- 手上有（或能拿到）一条深度图／动捕视频，它有正确的运镜与动作，但内容是灰模或错误的对象，需要重新出片。
- 只想替换某一类元素（地毯、窗帘、面料、器物、人物、动物），其余一切照旧。
- 需要指定角色形象，甚至**跨品种／跨形体替换**（如深度里是金毛轮廓，目标角色是边牧）。
- 需要多段成片之间连戏（同一房间、同一角色）。

**不适用**：要改运镜、改动作、改叙事结构的需求；没有深度／动捕基准的纯文生视频；需要重写剧本或分镜的需求。

---

## 一、先归档素材：四类素材职责分离是整套方法的地基

prompt 开头必须**逐条写清每个引用节点只负责什么、明确它不负责什么**。不写这一层，模型会把结构参考的轮廓当成造型依据，拿深度剪影当形体去「补」造型。

槽位唯一职责必须在 prompt 中显式声明的「不负责」{{深度视频}}唯一结构与运动基准：镜头运动轨迹、机位高度、景别变化、推拉节奏、空间透视关系、动作发生的时序，逐帧对齐深度图中的剪影是动捕留下的粗略轮廓，**一律不作为任何生物或物件的造型依据，不决定头型、耳型、四肢比例、体态或器物外形**{{内容参考视频}}画面情节基准：具体动作内容、表情节奏、出画时点、各段切换时机与停留时长不负责场景陈设、不负责光线风格{{场景基准视频/图}}室内陈设逐项一致：家具款式、数量、朝向、摆放位置全部照搬不负责运镜；并且必须写死一句「**画面中不出现任何该场景里没有的新增物件、家具、摆件或装饰品**」——这条是防止模型自由发挥补东西的关键{{形象参考图}} / {{材质参考图}}角色外貌基准／被替换对象的外观基准不负责构图、不负责画幅

**跨段连戏**：多段成片时，用**上一段已完成的成片节点**作为本段引用，并写明「场景与陈设延续上一段成片的同一间房间」。

**归档时的硬规则**：本段不需要的角色、动物，**不要放进引用列表**；并且仍要在 prompt 里补一句正向排除声明（见第二节 ⑦）。

## 二、执行链路

### Step 1 · 读素材，先看清再动笔

- `view_video` 抽帧看 {{深度视频}}：确认实际秒数、帧率、画幅、动作内容、有无人物／动物、是否多镜头、镜头是否贴地。
- `view_video` 看 {{内容参考视频}}：记录动作、出画时点、段落切换点。
- `view_image` 看场景基准与形象／材质参考：记录被替换对象的**原始形态**（如原来铺的是素色剑麻毯），记录场景里能不能找到窗外视野。
- 关键：**时长和画幅都必须从素材实测得出，不要凭视觉估。**

### Step 2 · 归位槽位，列引用清单

把四类素材落到第一张表的槽位，写出本段实际引用节点清单，并检查缺口：

- 有深度视频、缺场景基准 → 问用户要，否则陈设会自由发挥。
- 深度里是 A 品种、形象参考是 B 品种 → 直接判定为「跨品种重建」，必须走 ⑥ 的解剖对照写法。
- 本段要出现人物／动物但没有对应形象参考 → 问用户要或确认走排除项。

### Step 3 · 按八段模板写 prompt

模板见第三节，顺序固定，不要调换、不要合并段落。

### Step 4 · 建节点，参数按素材定

参数规则画幅**跟随深度视频**（本方法实测为 16:9 横构图）。不要让竖构图的风格参考去决定构图，参考图只贡献风格与材质时长取深度视频的实际秒数并取整为整数秒（例：7.05s→7s、10.7s→11s）。**不要凭视觉估、不要写短**——写短会截掉尾段空镜，镜头没有落点分辨率样片阶段可先 720p／480p 验证运镜与构图，正式成片取 1080p（低分辨率下纹样对比会明显衰减）引用列表只放本段真正要用的节点输出顺序先出样片核对运镜与构图，通过后再提分辨率／换正式模型

### Step 5 · 出片前先确认，出片后逐帧回看

- 运行生成节点属于消耗资源操作，**先向用户确认再跑**。
- 每次生成后**必须逐帧回看成片再给结论**，重点核对（详见第六节清单）。
- 发现问题时**只改对应那一段描述，其余信息不动**，避免连带破坏已达标的部分。

### Step 6 · 跨段成片

多段叙事时复用同一套形象／场景节点，逐段用上一段成片做引用，保持房间、光线、角色、服装一致。

顺序固定：①结构运动基准 ②内容情节 ③场景陈设 ④光线曝光 ⑤被替换物件尺幅 ⑥角色形象与解剖重建 ⑦排除项 ⑧收尾质感与一致性。

### ④ 光线曝光：这一步有正反两面，反面是实拍踩过的坑

**错误写法（会导致画面发闷灰暗，不要写）**

- 「整体曝光明显压低」
- 「画面偏柔和内敛」
- 「像阴天北向窗前」

**正确写法：三步，顺序不能乱**

1. **先给亮度**：「明亮通透的日间自然光，照度充足，白墙、浅色织物与原木地板呈现干净的浅色调，画面明快开阔，不发闷、不灰暗、不压暗」。
2. **再给光质**：「柔和的漫射光，所有物体表面高光过渡平缓，织物、皮肤、头发、石材、原木、金属面板上不出现刺眼的镜面反光、烧白亮斑或死白溢出；阴影柔和且边缘虚化，暗部保留细节与层次，明暗对比低」。
3. **最后一句锚定观感**：「如同晴天上午大面积窗光经白纱帘充分扩散后的均匀照明：亮，但柔」。

**窗外必须两条同时约束**

- 亮度：与室内接近、略高一线，是自然采光来源，但**绝不烧白、不过曝、不成纯白高光块**，窗框轮廓始终清晰可辨。
- 内容：窗外**必须有真实可辨内容而非空白**，指定为典型美国小镇住宅外景——安静街道、对面独栋木屋屋顶与侧墙、草坪、树篱与枝叶，色调柔和灰绿与暖白，景深轻微虚化，随镜头移动呈现合理视差。

> 注：想要柔光**不能靠「降低曝光」实现**。压低曝光的结果是整场景偏暗，这是本方法实测踩过的坑——柔光要写在光质（漫射、高光平缓、阴影虚化、低对比）上，亮度必须单独、正向地写足。

### ⑤ 被替换物件：用真实物理尺幅锚定，不能用画面占比

以地毯为例（可直接套用到其他有确定尺寸的物件）：

- 给出**现实尺寸**：宽 2.4 米、长 3 米。
- 要求按这一实际尺幅铺在**指定区域的水平地面上**，**边缘与周边家具脚的相对位置符合该占比**，明确「不铺满整个房间、也不缩成小块」。
- 推导出**纹样尺度必须随镜头角度与远近连续变化**：全景高位时，整块毯与全套边框收在小面积地面上，图案细密完整；镜头推近、机位降低时，毯面占据前景，中央奖章纹与藤蔓边框**按同一物理尺度等比放大**，笔触与织面细节变清晰。
- 列出禁止项：图案忽大忽小、尺度跳变、漂移、平铺贴图感、闪烁。
- 若全程为**贴地极低机位**，改写为：「毯面长期占据前景，纹样放大到接近特写，被裁出画框属正常，但可见部分的尺寸与走向须连贯」。
- 接触关系：「家具脚与被替换物件的接触处自然压在其上，带柔和投影与环境光反弹」；物件被压过时要有轻微形变／绒毛倒伏。

### ⑥ 角色形象与解剖重建

**(a) 人物**：写到发型、发色、瞳色、面部特征、服装款式与面料、装饰细节（如胸前三维立体花饰与茎线）、是否赤脚、气质；并声明全片相貌、发型、服装与配饰前后一致。

**(b) 跨品种／跨形体替换（本方法最关键的一条经验）**

当深度视频捕捉的是 A 品种（如金毛）、目标角色是 B 品种（如边牧）时，必须：

1. **点破二者是完全不同的品种与体格**，明确「不能把 A 的身体换成 B 的配色来交差，必须按 B 自身的真实解剖结构重新构建这具身体」，并声明**这是本段最重要的要求**。

2. **逐项写出可判定的解剖差异对照**，不给模型含糊空间。金毛 → 边牧的对照：

   部位目标（边牧）明确不要（金毛）头部楔形头、颅骨平坦、口吻尖细且长度与颅骨相当宽圆头、厚实方形口吻耳半立耳，耳根竖起、耳尖向前折垂贴于头侧的长垂耳体型轻盈紧凑、胸深而腰线上收、体长略大于肩高骨架粗壮、胸腹浑圆四肢细长、骨骼纤细、脚掌小而椭圆、趾间紧凑粗短厚重、脚掌宽大被毛双层中长毛，颈胸有鬃毛围脖，四肢后侧与尾部有羽状饰毛整体浓密蓬松长毛其他毛色花纹逐处指明分布；眼睛形状与颜色、鼻头质感—

3. **连运动方式一起换**：站姿、低头取食时颈背弧线、重心分配与肢体运动都要符合目标体型的真实力学，**动作轻灵敏捷而非原品种的沉稳厚重**。

4. **收尾声明**：全片品种、毛色花纹、体型与配饰保持一致，从头到尾不改变、不退化为其他品种样貌。

### ⑦ 排除项：某段不需要的角色要主动「正向声明」

若该段深度里没有人物、或没有动物：

- 除了**不把对应形象参考放进引用列表**，
- 还要在 prompt 里单独一句正向声明：「**本段画面中只有××一个人／没有人物出现，不出现任何动物、宠物或第二个人物，也不出现与之相关的物件（食盆、牵引绳、玩具、毛发现象等一概没有）**」。

不写这句，模型会凭空补出来。

### ⑧ 收尾质感与一致性

一致性声明（角色／品种／服装／房间）＋ 写实影像质感 ＋ 画质与帧率。

## 四、多镜头段落的写法

若深度视频是一条多段叙事（示例：洗衣机旋钮近景 → 滚筒圆形特写 → 毯面大特写 → 客厅全景人犬互动）：

1. **按深度轨迹逐段拆开**，各自标注**大致起止秒数与内容**。
2. 说明段与段的**切换时机**、圆形特写的出现与消退、中段空转过渡，**都严格跟随深度轨迹**。
3. **独立空间单独声明**：若某几段发生在与主场景不同的空间（如洗涤区），要写明该段**只出现相关器物与局部、不与客厅家具同框、也不改动客厅布置**。否则模型会把洗衣机塞进农舍客厅。
4. **因果衔接**：滚筒里翻洗的物件应与后续「洁净铺平」的特写构成洗后归位的逻辑。

---

## 五、时长与画幅

- **时长**：取深度视频的实际秒数向上／取整为整数秒（如 7.05s→7s，10.7s→11s），不要凭视觉估。写短会截掉尾段空镜，导致镜头没有落点。
- **画幅**：跟随深度视频（本次为 16:9 横构图），不要让竖构图的风格参考去决定构图。

## 七、常见失败模式与处理

## 八、逐帧核对清单（每次生成后必做）

**必须逐帧回看成片再给结论**，不要只看首帧或截屏。

- \[ \] 运镜与动作是否贴合深度轨迹（机位高度、推拉节奏、景别变化、动作时序）
- \[ \] 有没有凭空新增物件、家具、摆件、装饰品
- \[ \] 被替换物件的**真实尺幅**与**纹样透视**是否全片稳定（不铺满、不缩块、不跳变）
- \[ \] 曝光与光质是否达标（明快不灰暗、高光不烧白、阴影有层次）
- \[ \] 窗外是否有真实内容且不烧白
- \[ \] 角色外貌／品种／毛色是否前后一致，跨品种是否真按目标解剖重建
- \[ \] 该空的段落是否真的没有多余角色与相关物件
- \[ \] 多段叙事的分段、切换点、因果衔接是否正确
- \[ \] 尾段空镜是否完整、镜头是否有落点

**修正铁律**：只改对应那一段描述，其余信息逐字不动。改完再跑一次同样的核对清单。

## 九、什么写成锚点，什么留成槽位

固定不动的工艺（职责分离声明、亮度→光质→锚定句、真实尺幅锚定、解剖对照法、排除项声明、逐帧核对）是**锚点**；素材、尺寸、品种、地名、家具清单、秒数是**槽位**。换项目时只替换槽位，锚点原样保留。
